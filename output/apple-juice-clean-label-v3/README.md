# 사과주스 라벨 정리 v3

작은 원본 라벨 그림을 확대해 생긴 흐림과 그림에 포함된 주황색 병/테두리 잔여 부분을 없앴다. 크림색 바탕·빨간 사과와 잎·아래 두 잎가지의 구성을 벡터 경로로 다시 그렸다. 얇고 일정한 금빛 경계와 둥근 모서리, 단순한 사과 하이라이트를 사용하며 원본 그림의 붓 번짐·원근 그림자는 포함하지 않았다. 브랜드명이나 글씨는 추가하지 않았다.

같은 경로로 편집 가능한 SVG와 안티앨리어싱한 1024×1536 PNG를 만들었다. PNG는 GLB 안에 포함된다. 라벨 곡면의 반지름을 실제 병 몸통·어깨 반지름에 맞춰, 위쪽이 들떠 보이는 간격도 줄였다. 병·주스·뚜껑·목 씰은 v2와 동일하다.

최종 GLB 헤더·길이, Blender 재수입, 유한 좌표, 퇴화면 0개와 내장 라벨 이미지 디코딩을 검증했다. 전체와 재수입 후 라벨 확대를 렌더해 확인했다. 정확한 수치와 해시는 `validation.json`을 따른다. v2는 이력으로 보존하고 이번 v3를 사과주스 후속 제작본으로 사용한다. 게임 적용과 사용자 최종 외형 검수는 별도다.
