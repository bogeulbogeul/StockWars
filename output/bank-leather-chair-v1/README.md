# 은행 가죽 의자 v1

참고 이미지의 따뜻한 갈색 가죽, 둥근 등받이, 네 개의 단추와 들어간 주름을 실제 곡면 메시로 제작했다. 목재 프레임과 네 다리, 부드러운 좌판을 포함한다.

- 독립 모델: `Bank-leather-chair.glb` (바닥 중앙 원점)
- 룸 조합: `Bank-chair-room-preview.glb`, `Bank-chair-room-preview.blend`
- 미리보기: `room.png`, `chair-close.png`
- 재현: `build_chair.py`, `manifest.json`
