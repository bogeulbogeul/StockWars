# 우체국 외관 디자인 v1 — 2026-10-21

우체통 곡면 후속: 몸체·뚜껑·기둥·받침·소형 부품의 모서리를 12분할 곡면과 부드러운 표면 노멀로 정리했다. 몸체·뚜껑 라운드를 조금 키우고 수거문은 둥근 사각 윤곽 메시로 교체했다. 문 둘레 어두운 이음선의 대비를 줄였다. 봉투 문양·몰딩 밖 위치·투입구 구성은 유지한다.

우체통 디테일 후속: 투입구는 실제 개구부·안쪽 음영·연속 황동 프레임·작은 빗물막이로 정리했다. 뚜껑 아래 턱과 기둥 연결 마감을 추가하고 앞면에 얕은 수거문 이음선·작은 경첩·열쇠구멍을 넣었다. 봉투는 간판의 현행 종이 접힘 메시를 그대로 축소 재사용하며 봉인·각인을 넣지 않았다. 몰딩 밖 배치는 유지하고 `mailbox-close.png`로 확대 검토한다.

봉투 후속 정정: 봉투의 금빛 선·붉은 봉인·각인과 겹겹의 두꺼운 외곽을 제거했다. 얇은 단일 종이 몸체에 좌우 접지·아래 접지·둥근 끝의 상단 덮개를 실제 깊이 차로 겹쳤다. 아래 대각선은 외곽 모서리에서 중앙으로 이어져 덮개 아래에 숨으며, 종이 면과 얕은 그림자로 봉투를 표현한다. 간판 목재 테두리와 금빛 인레이는 유지한다. 아래 봉인·각인 추가 기록을 대체한다.

간판 디테일 후속: 연속된 돌출 목재 테두리·안쪽 금빛 인레이·작은 황동 고정핀을 추가했다. 봉투는 종이 단면·겹친 옆 접지·상단 덮개를 별도 깊이로 조형하고 가는 금빛 마감과 붉은 봉인·작은 금빛 각인을 더했다. 기존 간판 크기와 봉투 상징을 유지하며 `sign-close.png`에서 확대 확인한다.

입구 접합 재마감: 얇게 덧댄 문턱을 없애고 상단 계단·문턱·건물 기초를 실제 메시 합집합으로 연결했다. 문턱과 상단 계단 윗면을 같은 높이로 맞추고 벽 하단을 기초 안쪽까지 연장해 문틀 옆 틈을 막았다. `entry-joint-close.png`에서 확대 검토한다. 아래 별도 문턱을 덧댄 기록을 대체한다.

문 하단 후속: 문틀·벽·계단 접합부에 노출된 어두운 문 안쪽 면을 연속된 돌 문턱으로 가렸다. 문턱은 지면부터 채우고 양쪽 문틀 발과 벽 하단에 겹쳐 검은 틈을 막았다. 외관 모델과 렌더에 반영했다.

우체통 배치 후속: 수집함 몸체·장식·기둥·돌 받침 전체를 앞으로 0.24 모델 단위 이동했다. 돌 받침 뒤쪽과 건물 하단 몰딩 앞면 사이에 0.10 단위 간격을 확보했다. 모델·렌더에 반영하며 게임 배치는 대기다.

현행 서점 외관을 표현 방식 참고로 사용했다. 크림색 무광 벽·꿀색 목재·부드러운 모서리·곡선 기와지붕·아치 문과 안쪽 유리창·지면에 닿는 돌 계단을 공유한다. 우체국의 구분 요소는 테라코타 지붕, 봉투 부조 간판, 출입구 오른쪽 빨간 수집 우편함이다. 후면은 창 없는 벽이다.

- `PostOffice.glb`: 프리뷰 지면·조명·카메라를 제외한 외관 모델.
- `PostOffice.blend`: 모델과 렌더 스튜디오 제작 원본.
- `front-right.png`, `front.png`, `rear.png`: 검토용 이미지.
- `build_post_office.py`: 기존 건물 제작 유틸리티를 재사용한 재현 스크립트.

우체국 이름·담당 주민·지도 위치·개방 시점은 확정하지 않았다. 이 외관은 우편 기능 구현이나 휴대폰 선물 기능 이관 완료를 뜻하지 않는다. 건물 옆 우편함은 우체국 수집함 디자인이며 집 앞 수신 우편함의 위치·기능을 대신 확정하지 않는다.
