# 마을 고정 충돌체 적용

P1 · ✅ 웹·기존 실행본 적용 및 자동 검증 / ⏳ 사용자 시각·플레이 검수

나무·꽃·벤치·게시판·정류장 등 모든 배치 소품에 실제 GLB 메시를 기반으로 한 고정 충돌체를 추가했다. 캐릭터 지면 높이 1~100 구간과 겹치는 삼각형을 잘라 메시별 지면 경계로 투영한다. 높은 지붕/수관만 있는 공간은 막지 않는다. 소품에는 몸통 여유 28을 적용하고 기존 건물 충돌 및 출입 접근 거리는 유지한다. 별도 중력/동적 물리 엔진을 도입하지 않고 기존 캐릭터 이동·축별 미끄러짐·8단위 이하 이동 분할에 연결한 static rigid-body 방식이다. 메시별 직사각형 근사이므로 곡면 모서리에는 여유가 있다.

가구점 앞 꽃마당 중심 X를 650에서 1000으로 이동해 입구 접근을 확보했다. 건물·캐릭터 모델·경제·저장은 변경하지 않았다. 실내는 기존 실내 충돌 처리를 유지하며 이번 신규 적용은 마을 소품 대상이다.

`node --test web/tests/townPropBodies.test.mjs`: 높은 지붕 제외와 사방 달리기 관통 방지 2개 테스트 통과. `scratch/check-current-exteriors.cjs`의 rigidbody 모드로 웹/기존 실행본에서 모든 소품의 충돌체 존재·차단, 건물 9곳 입구 접근/도달, 모델 배율·시계·작은 화면·JavaScript 오류를 확인했다. 결과는 `web-checks.json`, `desktop-checks.json`이다. 설치 프로그램은 재빌드하지 않았다.

기존 길 검사의 일부 중심선/모서리는 이제 실제 소품 충돌 영역과 겹쳐 차단된다. rigidbody 검증은 이를 결과 JSON에 기록하고 모든 입구의 우회 도달 가능성을 검사한다. 길 전체가 차단 0건이라고 주장하지 않으며 길 모양 재편은 이번 작업에 포함하지 않았다. 최종 접촉 모습은 실제 플레이 검수가 남아 있다.
