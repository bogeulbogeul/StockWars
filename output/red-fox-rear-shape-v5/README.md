# 붉은여우 뒤 외형·꼬리 형태 v5

사용자 미채택: 뒤 외형·색 변경과 꼬리 옆 이동이 요청과 달랐다. 게임은 v4로 복원했다. 아래 설치 기록은 복원 이전 이력이다. v5를 다시 설치하지 않는다.

뒤 머리·목덜미와 몸통에 기존 주황 팔레트 내 약한 털 결·명암을 추가했다. 꼬리는 사용자 첨부 중립의 둥근 쉼표형과 왼쪽 위 아이보리 끝을3프레임 모두 유지하도록 네이티브 이미지 편집했다. 전체를 반전해 흰 끝 방향을 바꾸는 초기 생성본은 미채택이다.

뒤 정지·걷기4논리 프레임을 교체하고 다른15개 PNG는 v4와 바이트 동일하다. 기존371색·3그림·A→중립→B→중립·160ms와 운반 v4는 유지한다. 게임 슬롯에 설치했으며 PNG·팔레트 동일성과 다른 숲속5종 보존을 검사했다. 시트 무결성·미리보기 렌더 경로·관련 회귀18검사를 통과했다. 실제 브라우저 재생의 형태·색 연속성과 게임 접촉 검수는 별도다.

생성 도구와 프롬프트는 generation.json, 설치 기록은 game-installation.json, 보존 기록은 preservation.json을 참조한다.
