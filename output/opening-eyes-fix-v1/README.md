# 오프닝 두 번째 장면 눈 합성 수정 — 2026-10-26

나무 아래에서 잠들었다 깨어나는 장면의 `.sleep`에 있던 고정 타원 clip-path가 눈 일부를 잘라, 왼쪽 눈이 C자처럼 보이고 눈 뜬 그림과 어긋나게 합성됐다. 특히 원본과 다른 화면 비율에서는 object-fit:cover의 자르기와 타원의 위치가 따로 계산됐다.

해당 타원만 제거하고 기존 눈 감은/뜬 전체 그림의 같은 위치 겹침과 4.32~5.44초 페이드를 사용한다. 원본 PNG·대사 클릭·장면 순서·확대·새벽빛은 유지한다. 웹과 기존 win-unpacked/resources/web의 scene.html에 적용했다. 설치 프로그램 재빌드와 전체 영상 재촬영은 하지 않았다. 앞선 playthrough-qa-v1 영상은 수정 전이다.

실제 Edge에서 웹/실행본 리소스 각각 4.2초(감음)·4.88초(전환)·6초(뜸)를 렌더했고, 1280×800·1920×1080·390×844에서 clip-path 없음과 자막 클릭 완료 1회·pageerror 0을 확인했다. web-before.png는 기존 타원을 검수 페이지에서 재현한 비교 화면이다. web-closed.png/web-transition.png/web-open.png와 desktop 대응 화면을 참고한다.
