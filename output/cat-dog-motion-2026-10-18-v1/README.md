- ✅ 완료: 비투명 RGB42색 제한, 팔레트 밖0색, 색 변환 전후 알파 동일, 중립/정지 일치 검사.
- 🔄 진행중: 사용자 최종 외형·모션 승인. 생성한 자세는 강아지 참고에 맞춘 것으로 관절 좌표의 픽셀 동일성을 보장하지 않는다. 고양이 꼬리의 형태·위상은 강아지와 다르다.
- ⏳ 대기: 게임 설치와 실제 이동·좌석·화물 접촉 검수. 이번 제작으로 삭제된 고양이 게임 슬롯을 복원하지 않았다.

## 전달 파일

- `sprite-sheet-alpha.png`: 최종 투명 시트. `manifest.json`: 실제 재생 좌표·160ms.
- `frames/`: 최종 RGB 프레임. `palette-source.json`: 사용한 부위별 RGB 원본.
- `preview.html`: 강아지와 고양이 동시 재생·일시정지·프레임 이동. 같은 폴더 구조를 유지해 연다.
- `dog-cat-comparison.png`: 행별 정적 자세 비교. `*-walk.gif`, `right-carry.gif`:160ms 루프.
- `validation.json`, `qa-notes.md`: 검사 범위와 미완료 사항.
- `run/`: canonical 생성·추출·큐레이션·조합 원본. `references/`: 강아지 동작 참고 행과 고양이 정면 외형.

색상 변환은 sprite-gen의 전체 최근접 RGB 매핑이다. 부위별 단색 마스크 고정이나 시간적 명암 변화의 완전 제거를 뜻하지 않는다. 추출·팔레트·좌표 검사를 게임 접촉 검수로 대신하지 않는다.
