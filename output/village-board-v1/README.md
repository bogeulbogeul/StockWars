# 마을 게시판 UI v1

아이보리 종이·나무 테두리·파스텔 공고 3개의 HTML/CSS 화면. 봉봉 포장 알바, 모아 안내소, 벤치 사용 안내를 담는다. 의뢰 수락·칭호·신규 보상·저장 변경은 없다.

전시의 notice 활동에서 열리며 공고 확인 버튼으로 기존 다음 단계에 연결된다. 닫기만 하면 진행하지 않고 게시판 살펴보기로 다시 열 수 있다. 일반 마을에서는 현행 게시판 좌표 근처의 F키/화면 버튼으로 연다. 자동 이동 중 열기는 추가하지 않았다.

웹 및 기존 실행본 resources/web에 변경 파일을 반영했다. 설치 프로그램은 재빌드하지 않았다.

검증: node web/tests/villageBoard.browser.cjs
공고 선택, 확인 콜백 1회, Esc, 닫기, 390px 모바일 가로 넘침, JS 오류 0건 통과. desktop.png/mobile.png는 독립 UI 렌더다. 전체 전시 플레이 및 일반 마을 현장 상호작용의 사용자 최종 검수는 별도다.

## 붙인 공고 형태 수정

나무 프레임·코르크 바탕 위에 압정으로 고정한 종이 3장을 엇갈려 배치했다. 처음 열 때 상세 패널은 없으며 종이를 클릭하면 별도 큰 공고문을 연다. 게시판으로 버튼 또는 첫 Esc는 큰 공고만 닫고 다음 Esc는 게시판을 닫는다. 포장 공고 확인만 기존 이야기 진행 콜백을 실행한다. 웹·기존 실행본 반영. 데스크톱/390px 화면, 확대/복귀, 진행/닫기 검증 통과. pinned-board.png 및 mobile-reader.png 참고.
