# 원본 미소·둥근 배 복원

원본 미소를 보존하라는 첨부 참고와, 먹을 때 배 옆면이 납작해진다는 후속 피드백을 함께 반영한다. 게임 설치 없이 제작본만 저장한다.

- 웃는 구간: 기존 본체의 원본 입 텍스처·재질을 그대로 표시한다. 별도로 근사한 U자 미소를 사용하지 않는다.
- 먹는 구간: 이전 소망이의 세로 타원 입을 표시한다. 원래 미소는 임시 가림 메시로 가리고, 웃을 때 가림 메시와 먹는 입은 머리 안에 숨긴다.
- 배: 팔·어깨 보정에 끌려 납작해진 표면을 원본 Basis 좌표로 되돌린다. 배·아랫몸의 18,451정점을 원본 좌표로 유지하고, 상부 연결은 부드럽게 전환한다. 팔 아래의 접힌 표면은 별도로 전환하여 이전 겨드랑이 돌출을 복원하지 않는다.
- 팔·머리 모션과 빵의 크기·위치 트랙은 직전 버전을 유지한다.
- 중복된 경계 좌표를 같은 비율로 보정하고 팔 연결부에서 보정량을 0으로 낮춘다. 91프레임 경계 틈 최대 0, 원본 배 좌표 오차 0 (`validation.json`). 삼각형의 전체 충돌·교차 검사는 아니다.
