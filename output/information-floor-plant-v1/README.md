# 안내소 소파 옆 바닥 화분 v1

P1 (Major) · ✅ 3D 제작·배치 / ⏳ 사용자 검수·게임 적용

사용자 참고처럼 둥근 크림색 도자기 화분과 넓은 잎이 3개 층으로 모인 식물을 제작했다. 화분 안쪽 벽·낮게 들어간 흙·줄기·두께 있는 잎 12개는 모두 메시다. 소파 뒤쪽 끝 옆 (3.24,.30,.022)에 배치했다. 기존 작은 화분 v2의 재질 방향을 이어간 별도 바닥용 모델이다.

- `Cream-floor-plant.glb`, `Cream-floor-plant.blend`: 독립 모델/원본
- `plant.png`: 단독 확대
- `waiting-corner.png`, `Office-floor-plant-preview.blend`: 두 캐릭터가 앉은 소파 옆 배치
- `build_floor_plant.py`, `manifest.json`: 재현·상태

게임과 기존 모델은 변경하지 않았다. 잎의 전체 표면 충돌·캐릭터 이동 검수는 별도다. 임시 제작 단위를 사용한다.
