# 인사 손끝 둥글게 수정 v3 — 2026-10-19

사용자 요청으로 길쭉한 타원형 팔의 좁아진 손끝을 더 둥근 캡 형태로 수정했다. 팔 끝 반경은 0.122이며 팔의 길이 방향 좌표와 끝 도달 위치는 유지한다. 어깨 구간·본·웨이트·키프레임·웃는 얼굴과 v2의 둥근 배는 그대로다. 손가락이나 별도 손목은 만들지 않았다.

- `wave-front.gif`, `wave-side.gif`: 실제 인사 재생.
- `somangi-wave.glb`, `somangi-wave.blend`: 수정 모델과 편집본.
- `hand-repair.json`: 양팔 손끝의 반경 변경·길이 방향 보존 수치.
- `validation.json`: 전체 동작의 팔 길이·머리 침투 표본·어깨 겹침·몸통/발 고정·루프·GLB 재수입 검사.

먹기에도 같은 손끝 보정을 별도 `somangi-eat-v5`로 적용했다. 이전 인사·먹기·걷기·앉기 및 게임 파일은 변경하지 않았다. 재생성 스크립트는 `round_hands.py -- wave` 또는 `-- eat`로 해당 복사본을 생성한다.
