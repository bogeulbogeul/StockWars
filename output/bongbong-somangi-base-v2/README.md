사용자 요청 “소망이 캐릭터 가져와서 봉봉 캐릭터 만들자”에 따라 최신 소망이 제작 원본 `../somangi-game-v1/somangi-walk.blend`를 가져왔다. 큰 머리·몸통·팔·다리의 정점과 기본 얼굴을 보존하고 살구색 몸 `#FFC394`, 코랄색 꽃봉오리 `#F97566`를 만들었다. 기존 `../bongbong-somangi-base-v1/front.png`는 색과 세 꽃잎 구성만 참고했다. 최신 의상 제작 중단 결정을 따라 앞치마는 만들지 않았다.

세 이미지는 전달 GLB를 다시 불러온 실제 모델의 휴지 자세 렌더다. 같은 정투영 배율을 사용한다. 원본 몸체 정점 변화는 0이며 꽃봉오리 세 메시만 기존 Head 본에 연결했다. 원본 걷기를 전달하되 새 꽃봉오리 모션·표정 14종 전달본·모든 동작 접촉 검사는 이번 작업 범위에 포함하지 않는다.

소망이 원본·웹·기존 로컬 실행본·저장은 변경하지 않았다. 이번 제작 요청과 게임 적용 요청을 구분하며 봉봉 게임 삭제 상태는 유지한다.
