# 은행 룸 게임 연결

최신 bank-complete-furniture-v4 룸을 웹 및 win-unpacked 실행본 리소스에 설치했다. 마을 은행 앞 F 입장, WASD/방향키 이동, 중앙 출입구 또는 Esc 복귀. 금융 기능·착석은 포함하지 않는다.

은행 독립 데이터/충돌·룸 로더·진입 모듈을 추가하고 기존 3D 씬 공통 이동/표시를 재사용했다. ui-paused 상태에서도 은행 화면과 입장 안내가 표시된다.

✅ 경로 탐색/출입구/가구 충돌 및 기존 마을 전환 테스트 2건 통과. 헤드리스 Chrome에서 F 입장·모델/텍스처 로드·이동·Esc 복귀·재입장·출입구 복귀 및 화면 가시성 확인, 페이지 오류 없음. game.png는 실제 게임 캡처. 실행본 8개 리소스 해시 동일성 확인.

⏳ 사용자 최종 시각 검수. 은행 내부 NPC, 온라인 룸 공유, 금융 동작, 가구 착석은 별도다.
