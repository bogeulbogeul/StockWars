# 소망이 먹기 모션 시안 v1

걷기 v3 원본 모델을 바탕으로 양손에 든 빵을 입 가까이 가져가고 두 번 고개를 숙인 뒤 다시 내리는 `Eat` 클립을 제작했다. 고정 눈·미소를 유지한다. 표정 교체·입 벌림·음식 소모·게임 회복 효과는 구현하지 않았다.

## 최종 파일

- `somangi-eat.glb`: 원래 캐릭터 몸체·웨이트에 음식 소켓 본과 별도 빵 메시를 추가한 먹기 시안.
- `somangi-eat.blend`: 편집본. 프리뷰 바닥·카메라·조명 포함.
- `eat-front.gif`, `eat-side.gif`: 정면·정측면 실제 모델 프리뷰.
- `eat-front.png`, `eat-side.png`, `eat-angle.png`: 먹는 자세 확인.
- `validation.json`: 73프레임 유한 좌표·다리 고정·루프·원본 메시 좌표 보존·GLB 재수입 검사.

## 동작과 상태

- 24fps, 73키 프레임, 3초 클립. 프리뷰는 12fps, 36장으로 조합한다.
- 기존 7본에 `Food` 본 1개를 추가하고 빵을 별도 메시로 연결했다. Food 본의 위치를 양손 끝의 중간 위치에서 계산해 키프레임으로 구웠다.
- 원래 머리·몸체·팔다리의 정점 좌표와 기존 게임 파일·걷기·앉기 파일은 변경하지 않았다.
- 머리는 기본 자세에서 최대 약 28도 숙이며 고정된 미소를 유지한다. 팔을 과도하게 위로 들지 않도록 낮은 들기 자세와 고개 움직임을 함께 사용한다.
- **남은 한계:** 팔을 든 자세에서 어깨·겨드랑이의 스킨 주름이 보인다. 캐릭터 외형과 연결 상태의 최종 검수 통과본으로 취급하지 않는다. 입을 여닫거나 실제로 빵이 줄어드는 완성 식사 연출은 포함하지 않는다.

✅ 먹기 클립·소품·전달 파일·기본 수치 검사 / 🔄 어깨 변형 품질 보정 / ⏳ 게임 상호작용·소모/회복·전환·실시간 접촉 검수.

`weights.py`는 검토 과정의 미채택 어깨 분리·몸통 재구성 실험 코드다. 최종 `build.py`에서는 호출하지 않으며 최종 GLB/Blend는 이 재구성을 포함하지 않는다. 새 화풍·캐릭터 외형으로 채택하지 않는다.
