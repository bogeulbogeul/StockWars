# 원본 표면 복귀와 고정된 양손 식사 v26

최신 요청: 음식 크기에 따라 손을 모으지 않는다. 처음부터 양손을 모은 자세를 고정하고 음식만 균등 축소한다. 음식을 다 먹으면 원본 기본 자세로 돌아온다.

과도한 몸통 재구성과 변형된 팔을 기준으로 삼던 v25 대신, `somangi-black-eyes-v1/somangi-black-eyes.blend`의 원본 계열 표면을 사용했다. 원본 외부 정점 43,703개의 좌표는 그대로 보존했다. 팔은 단일 본 100% 가중치로 강체 이동하며, 식사 중 고정되어 있다. 1.9초 이후 0.8초 동안 원래 팔 자세로 돌아온다. 표정은 원본 얼굴 표면에 다시 투영했다. 게임에는 설치하지 않았다.

검증: `fixed-hold-verification.json`. 식사 구간 115시점 팔 행렬 차이 0, 마지막 기본 자세의 원본 외부 정점 최대 차이는 수치 오차 범위. 빵 크기는 초기 크기의 1, 2/3, 1/3, 0을 확인했다. 머리·몸통·다리 형상은 애니메이션으로 바뀌지 않는다.

**미완료:** 팔을 들어 드러난 겨드랑이 구멍을 닫는 보조 면을 추가했으나, 측면에서 연결부의 마감과 음영이 아직 거슬린다. 이 부분을 완성됐다고 주장하지 않는다. 원본 표면 자체를 다시 조형해 해결한 것으로 취급하지 않으며 최종 채택·게임 설치용 완성본으로 확정하지 않았다.

`eat-front.gif`, `eat-side.gif`는 실제 GLB 재수입 촬영이다. 원본과의 조명·카메라 차이는 외형 복원과 구분한다.
