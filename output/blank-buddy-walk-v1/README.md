# 소망이 새 비율 — 자국 제거·걷기 v1

## 측면 눈색 수정 후속

후속 정정: 재질 변경만으로 GIF의 눈색 문제가 해결되지 않았다. `check_preview_colors.py`로 비교한 결과 원본 PNG 눈 평균은 약 RGB 7~9인데 이전 GIF에서는 약 47~89로 밝아졌다. 작은 검은 영역이 적응형 GIF 팔레트에서 탈락한 것이 직접 원인이다. `encode_color_safe_preview.py`에서 어두운 회색 64단계를 예약한 공통 팔레트를 사용하고 디더링·팔레트 최적화를 끈 `walk-side-color-safe-v2.gif`를 만들었다. 24프레임을 다시 디코딩해 눈 픽셀의 채널 오차 최대 5 이하와 눈 평균 15 미만을 검사했다. `walk-side-lossless-v2.webp`는 무손실 대안이다. 모델을 다시 바꾸지 않고 표시 파일을 수정했다. 아래 재질 변경 기록의 원인 판단·해결 주장은 이 검사로 정정한다.

사용자 지적에 따라 `somangi-walk-eye-fixed.blend`와 `somangi-walk-eye-fixed.glb`를 별도 저장했다. 공통 재질의 금속성·반사로 검은 눈이 측면에서 밝아지는 현상을 줄이기 위해 Metallic 0, Roughness 1, Specular IOR Level 0의 무광 재질로 변경했다. 기존 색상 텍스처·메시·리그·걷기 클립은 유지했다. 몸에도 같은 무광 설정이 적용된다. `front-eye-fixed.png`·`side-eye-fixed.png` 정면/측면 비교와 `walk-side-eye-fixed.gif` 24프레임 측면 프리뷰가 수정본이다. GLB의 금속성·거칠기·스킨·걷기 클립 보존을 검사했다. 이전 파일과 프리뷰는 수정 전 이력으로 보존한다.

사용자 제공 `Meshy_AI_Blank_Buddy_1018082424_texture.glb`에서 제작했다. 다운로드 원본과 기존 작업본·게임 파일은 변경하지 않았다.

## 결과와 사용

- ✅ 완료: 뒤통수의 옅은 눈 모양 자국 원인을 분리 검사했다. `back-no-normal.png`와 `back-plain.png`에서 자국이 사라져 생성 노멀맵 문제로 확인했다. 노멀맵 연결을 제거하고 원본 메시 노멀을 사용한다. 색상·거칠기 텍스처와 앞쪽 눈·미소는 유지했다. 이 조치로 노멀맵의 다른 미세 요철도 함께 제외된다.
- ✅ 완료: 7본과 전체 정점 웨이트. 정점 60,654개·삼각형 108,618개 및 원래 메시 좌표를 유지했다. 팔꿈치·무릎 본은 추가하지 않았다.
- ✅ 완료: `Walk_InPlace` 제자리 걷기 루프. 24fps, 24개 재생 프레임, 25프레임에 1프레임과 동일한 연결 키를 넣어 클립 길이 1초를 유지했다. Blender 재생 범위는 1~24프레임이다. 작은 보폭, 팔·다리 반대 교대, 발 들기와 작은 상체 움직임을 포함한다.
- ✅ 완료: 주요 정면·측면 자세와 24프레임 사선 렌더 출력. 수치 검사는 모든 25키 프레임의 유한 좌표, 전체 정점 웨이트, 루프 양 끝 일치와 지지발 높이를 확인했다. 실제 결과는 `validation.json`을 따른다.
- ⏳ 대기: 게임 내 이동 속도·캐릭터 배율·전환 블렌딩 및 실시간 충돌 검수. 이번 파일 제작은 게임 설치 완료가 아니다. 인사·먹기·앉기와 성장 장식은 포함하지 않는다.

## 전달 파일

- `somangi-walk.glb`: 텍스처·본·웨이트·걷기 클립이 포함된 전달본. 프리뷰 바닥·카메라·조명은 제외했다.
- `somangi-walk.blend`: 텍스처를 내장한 편집본. 기본 선택 리그는 `Somangi_Rig`이고 Walk_InPlace가 활성화되어 있다.
- `walk-preview.gif`: 24프레임을 약 1초로 반복하는 실제 모델 렌더 미리보기.
- `walk-contact-sheet.png`: 8자세 정적 비교.
- `clean-front.png`, `clean-back.png`: 수정 후 기본 자세.
- `build-report.json`, `validation.json`: 제작·검증 수치.

GLB에서는 `Walk_InPlace`를 반복 재생한다. Root는 클립 안에서 이동하지 않는다. 지지 구간 발의 후방 이동을 상쇄하려면 이 원본 좌표 크기에서 전진 속도 약 0.28단위/초를 시작점으로 조정한다. 크기를 바꾸면 이동 속도도 비례 조정하고 실제 게임에서 발 미끄러짐을 다시 확인한다. Blender 전방은 -Y, glTF 전방은 +Z다.

## 재현

Blender 5.2에서 `diagnose.py`, `build_walk.py`, `validate_walk.py`를 순서대로 백그라운드 실행한다. `make_preview.py`는 Pillow가 설치된 Python으로 렌더 프레임을 GIF·컨택트 시트로 조합한다. 셰이더·본·애니메이션과 실제 모델 렌더를 사용했으며 생성 이미지로 모델 검수를 대체하지 않았다.
