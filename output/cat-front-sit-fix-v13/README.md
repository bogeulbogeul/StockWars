# 고양이 정면 앉기 자세 수정 v13

기반 v12의 정면 앉기는 팔이 길게 늘어져 무릎을 가리는 네발동물 앉기처럼 보였다. 사용자 지적에 따라 강아지의 정면 앉기 그림을 자세 기준으로 built-in GPT imagegen 편집했다.

- ✅ 완료: 굽힌 양 무릎 위에 손을 얹고, 짧은 정강이와 바닥을 향한 두 발이 구분되는 이족 앉기 자세로 수정.
- ✅ 완료: 원본 y286 위의 머리·얼굴·귀·눈·눈썹 RGBA를 그대로 보존. 수정은 정면 앉기의 목 아래 몸 부분만 적용했다.
- ✅ 완료: 다른 모든 상태와 수정 범위 밖 RGBA 동일, 시트 좌표·재생 계약 동일 검사. 앉기는 기존1그림 유지 자세다.
- ✅ 완료: 전체 미리보기 및 기존 걷기/운반160ms GIF 확인.
- ⏳ 대기: 사용자 최종 외형 확인. 게임에는 설치하지 않았다.

sprite-sheet-alpha.png, manifest.json이 전달본이다. sit-before-after.png는 왼쪽 이전/오른쪽 수정 비교, preview.html은 강아지와 나란히 재생한다. sit-generated.png는 GPT 편집 원본이며 package_sit.py가 원본 머리를 보존하며 정면 앉기 하체만 반영했다. prompt.txt와 validation.json에 요청과 검증을 보관한다.
