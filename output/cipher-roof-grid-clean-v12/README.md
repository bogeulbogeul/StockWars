# 증권사 기와 내부 분할선 제거 v12 — 2026-10-25

사용자가 v11의 중앙 지붕 확대에서 두께/선이 일정하지 않음을 지적했다. v11의 법선 두께 검사만으로 시각적 균일성까지 통과했다고 판단한 것은 부정확했다.

원인: 중앙 지붕은 교차 영역 처리를 위해 Y=-1.08, 0, 1.08에서 조각으로 나뉘었으며, 평기와에도 그 분할과 개별 베벨을 적용했다. 실제 기와 한 장 안에 추가 줄눈/모서리가 생겼다. 날개는 X=±1.17의 제작용 분할 경계가 같은 문제를 만들 수 있었다.

- `polygon_finish.py`에서 절단된 평면 영역의 경계를 합치고 내부 중복 선·일직선 분할 정점을 제거한 뒤 한 장의 기와를 만든다. 지붕 바탕판도 같은 방식으로 합쳐 제작용 경계의 추가 홈을 제거한다.
- 평기와는 법선 두께 0.018·돌출 0.009와 표면 배치 0.280×0.200·줄눈 0.005를 유지한다. 모서리 베벨은 모든 기와에서 0.0012로 통일하고 실제 외곽에만 적용한다.
- `verify.py`는 기존 부재 86개 보존과 온전한 직사각형 기와 크기를 검사한다. 두께 정점 검사는 `tile-thickness-validation.json`에 기록한다. 수치 검사는 사용자 시각 검수와 구분한다.

실제 모델 `CipherSecurities-clock.glb`, 편집 원본 `CipherSecurities-roof-reference.blend`, 재현 `build.py`.
중앙 확대 `central-close.png`, 전체 지붕 `reference-angle.png`, 다른 각도/접합부 `front-right.png`, `front.png`, `rear.png`, `junction-close.png`, `ridge-close.png`.
