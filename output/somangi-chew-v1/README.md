# 소망이 입 벌리기·오므리기 루프 — 2026-10-19

사용자 요청으로 입을 크게 벌렸다가 작게 오므리는 동작을 3초에 네 번 반복한다. 기본 타원 눈과 머리·몸·팔다리는 고정한다. 원래 입 텍스처만 지우고 머리 표면을 따라가는 검은 입 메시를 추가하여 `Mouth_Open` 모프로 변화시켰다. Head 본에 100% 연결한 표면 그래픽이며 입체 구강을 만드는 방식은 아니다.

- `chew-front.gif`: 정면 3초 반복 미리보기.
- `somangi-chew.glb`: `Mouth_Chew` 단일 모프 애니메이션 클립 포함.
- `somangi-chew.blend`: 편집본.
- `mouth-clean-basecolor.png`: 기존 눈을 유지하고 입 부분을 비운 Base Color.
- `validation.json`: 73프레임 유한 좌표·몸체 고정·입 루프 및 GLB 모프 애니메이션 내보내기/재수입 검사.

기존 음식 들기 클립과 합친 버전은 아니며 게임에는 설치하지 않았다. 기존 기본/웃는 표정·걷기·앉기·먹기 파일은 변경하지 않는다. 런타임에서 모프 애니메이션 재생이 필요하다.
