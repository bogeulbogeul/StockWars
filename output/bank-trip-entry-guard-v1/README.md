# 은행 이동 중 다른 실내 진입 차단

사용자는 안내소를 나와 은행으로 가는 동안 안내소 재입장 후 실내에서 나가지 못하는 문제를 제보했다. 기존 DestinationWalk의 F/이동 안내 외에, 은행 여행이 진행 중일 때 별도의 Scenes.show 호출이 다른 실내로 전환하지 못하도록 중앙 정책을 추가했다. 이 중앙 차단은 이전 코드에서 호출 경로 단위로 재현 가능한 누락이었으며, 사용자 당시 호출자가 무엇이었는지 확정한 것은 아니다.

InformationBankTravel 시작부터 은행 실제 입장 종료까지 bankTripPending 및 공유 목적지 guard를 유지한다. 은행 이외 재진입 시도는 현재 실내/야외 상태를 바꾸지 않고 소망이의 '우선 은행에 가보자.'를 표시한다. 야외 F/접근 감지도 같은 guard를 사용하며 문 앞 범위의 아래쪽 경계도 포함한다. 은행 중복 요청은 새 전환을 시작하지 않는다. 입장 완료/오류 시 잠금과 대화 리소스를 해제한다. 모아의 안내소 숨김·은행 대기·플레이어 WASD/F는 유지한다.

검증:
- 관련 Node30개 통과: 중앙 재진입 차단/중복 은행 요청/종료 후 일반 이동·모든 건물의 문 오프셋·입장 범위 끝·이야기 회귀.
- scratch/check-bank-trip-entry-guard.cjs [--packaged]: 안내소 대화 후 실내 상태를 직접 준비하는 집중 fixture다. 이후 실제 WASD/F로 안내소 퇴장→같은 문 앞 F 재입장 시도→소망이 안내·실내 미진입을 확인했다. 추가로 직접 scene show를 안내소/집/잡화점/증권사에 호출해 야외 유지·대화 표시를 검증했다. 모아의 안내소 숨김 유지 확인 후 실제 WASD/F로 은행 도착/입장·잠금 해제·오류0을 확인했다. 웹 및 기존 실행본 리소스 양쪽 통과. 처음부터 전체 플레이 재현은 아니다.
- 실내에 이미 갇힌 실행 중 상태를 외부에서 변경하지 않았다. 재실행하면 수정 리소스와 기존 저장 진행을 읽는다. 경제/보상/저장 형식 변경 없음. 설치 프로그램 재빌드/실제 EXE 검증은 하지 않았다.
