# 소망이 게걸음 v3

✅ 모션 제작·좌우 검사 / ⏳ 사용자 시각 검수·게임 연결

사용자 정정에 따라 v2의 앞으로 걷기를 폐기하고, 몸의 정면을 유지하면서 옆으로 디디는 게걸음으로 변경했다. 몸은 90도 옆으로 돌리고 두 팔은 배 앞에 모은 자세다. 다리는 앞뒤 X축 회전 대신 좌우 Y축 회전을 사용하며 작은 수직 들기만 추가한다. 좌우 수평 위치 이동이나 다리 스케일 변경은 사용하지 않는다.

- `somangi-crab-walk.blend` / `somangi-crab-walk.glb`: 편집 원본·모션 모델.
- `Crab_Enter`/`Crab_Exit`: 0.5초 몸 돌리기·팔 모으기/복귀.
- `Crab_Right`/`Crab_Left`: 좌우 각 1초 게걸음 루프.
- `crab-face.gif`: 캐릭터의 정면에서 옆 디딤을 확인하는 프리뷰.
- `crab-angle.gif`: 옆으로 돌린 몸과 배 앞의 팔을 확인하는 사선 프리뷰.
- `validation.json`, `validation-left.json`: 각 방향 97시점 접지·다리 길이·배 형상·루프·이동 축 검사. 앞뒤 발 이동 오차 약 1e-7, 옆 디딤 약 0.136, 루프 오차 0.

프리뷰는 제자리 반복이다. 게임의 실제 이동·통로 자동 감지·속도 동기화·충돌 폭 변경은 연결 전이며 설치된 기존 동작은 바꾸지 않았다. v1/v2는 폐기 이력으로 보존한다.
