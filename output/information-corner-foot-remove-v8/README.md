# 안내소 모서리 돌출 받침 제거 v8

P2 · ✅ 모델 수정 / ⏳ 사용자 시각 검수·게임 적용

v7의 지붕·수평 몰딩·문·계단을 유지하고, 사용자 첨부의 건물 모서리 크림색 돌출 받침을 네 모서리에서 제거했다. 목재 기둥의 하단만 .016 내려 기초에 묻어 접촉시켰다. 현관 두 기둥 받침은 유지한다.

다른 메시 정점 해시 대조, GLB 재로딩·제거 노드 없음·현관 받침 두 개 유지·유한 좌표 검사를 수행한다. 전체/모서리 확대/후면 실제 렌더와 `Information-clean.glb`, `Information-flush-corners.blend`를 저장한다. 웹·실행본은 교체하지 않았다.
