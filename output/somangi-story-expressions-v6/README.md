# 소망이 표정 14종 · v6

사용자 요청으로 울먹임의 눈을 기본 미소의 원래 눈 크기·위치로 맞췄다. 눈을 새 타원으로 추정해서 그리지 않고 기본 표정 UV의 눈 픽셀을 복원했다. 눈썹과 처진 입은 유지하고 눈물은 기존 모양을 유지한 채 커진 눈 바로 아래로 위치를 맞췄다. 앞으로 눈 크기는 현재 채택 크기를 유지한다.

다른 13종의 초상화·텍스처·GLB는 v5 파일과 해시가 동일하다. 삭제한 시무룩·뿌듯함은 포함하지 않는다. 14종 전체표와 정지 GLB·UV 텍스처·Blender 재질 라이브러리를 갱신했다. 기본 U자 입·캐릭터 외형·본·원본 모션을 변경하지 않았으며 게임 설치와 자동 표정 전환은 포함하지 않는다.

`teary-eye-comparison.png`는 기본 눈, 이전 울먹임, 수정 울먹임을 같은 카메라로 비교한 것이다. `eye-size-verification.json`에 실제 렌더의 양쪽 눈 경계가 기본 표정과 일치하는 검사 결과를 기록한다. 재현은 prepare → rebuild_teary → merge_teary → fix_glb_ink → verify_eyes → package 순서다. adjust_teary.py는 채택하지 않은 부분 패치 실험 기록이다.
