# 소망이 은행 가구 크기 확인

게임 wave.glb의 첫 자세를 사용해 책상·소파·금고 옆에 동일 크기의 비교용 소망이를 배치했다. Blender 가져오기에서 생성되는 Icosphere 본 표시용 객체는 제외했다.

게임 SOMANGI_HEIGHT=100, 원본 스케일 나눗수 1.95를 적용했다. 룸 1단위=게임 100단위 환산은 이번 비교의 가정이며 은행 런타임 설정은 아직 없다.

소망이 기준 키 약 1, 소파 좌판 바닥 대비 높이 .441, 좌판 폭 1.964, 책상 높이 .766, 금고 높이 1.600, 창턱 높이 약 .95. 소파·금고는 시각적으로 자연스러운 크기, 책상은 일반 책상보다 높은 창구 카운터에 해당한다. 낮은 손 위치에 비해 높으므로 실제 상호작용 시 별도 검토가 필요하다.

✅ 비교용 모델 배치·렌더 확인 / ⏳ 착석 자세·캐릭터 충돌·게임 단위 확정. 기존 가구 크기는 변경하지 않았다.
