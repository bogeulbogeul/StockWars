# 고양이 모션 색·눈썹 국소 보정 v2

2026-10-18 사용자 피드백 반영. 원본은 `../cat-dog-motion-2026-10-18-v1/`이며 원본을 덮어쓰지 않는다.

- ✅ 완료: 정면 걷기3그림의 몸·팔다리 기본색을 디자인 시트 RGB(65,59,62)/#413B3E로 고정했다. 기존 짙은 윤곽·관절 그림자는 유지한다. 정면 정지도 수정 중립과 공유한다.
- ✅ 완료: 정측면 걷기 가슴털 내부의 유사한 회색 조각을 같은 기본색으로 정리했다. 털 외곽과 팔 가림·자세는 유지한다. 측면 정지도 수정 중립과 공유한다.
- ✅ 완료: 운반4그림의 기존 눈썹 하이라이트 영역을 디자인 시트 RGB(92,81,85)/#5C5155로 통일했다. 원본 생성본의 눈썹 영역을 사용하며 눈·얼굴 형태를 새로 그리지 않았다.
- ✅ 완료: alpha·좌표·프레임 순서·160ms 동일, 지정 색 영역 밖 RGBA 동일, 뒤 모션·앉기·초상화 동일 검사. 정면 공통 몸통 표본의 프레임간 RGB 차이0 검사.
- ✅ 완료: 로컬 브라우저에서 수정 정면·측면 걷기와 운반을 재생하여 기본색·가슴털 얼룩·눈썹 대비를 확인했다. 기존 관절·가림 그림자는 별도로 유지한다.
- ⏳ 대기: 사용자 최종 색감 확인·게임 적용·실제 플레이 접촉 검수.

보정은 sprite-gen의 exact-RGB 유틸리티를 부위별 마스크에 적용했다. `repair_colors.py`에 영역·조건·색 대응, `baked/*report.json`에 실제 색 치환 기록을 남겼다. `validation.json`의 팔레트 검사는 프레임 전체의 모든 명암이 같다는 뜻이 아니다. 가림·관절의 기존 짙은 그림자는 유지한다.

`sprite-sheet-alpha.png`와 `manifest.json`이 전달본이다. `before-after.png`는 상태별 위가 이전, 아래가 수정본이다. `preview.html`은 강아지와 수정 고양이를160ms로 동시 재생한다. `down-walk.gif`, `right-walk.gif`, `right-carry.gif`에서 수정 루프를 확인할 수 있다.
