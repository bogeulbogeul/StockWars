# 자연스러운 정면 걷기 리듬 v16

사용자가 v15의 머리 별도 기울임을 과하다고 지적해 해당 머리 편집을 철회했다. 정면 세 그림은 v14의 자연스러운 얼굴을 복원하고 v15의 공통 색면 정리만 적용했다. 머리를 따로 회전·변형·재생성하지 않는다.

완성 프레임 전체에 접지 A(-1,-1), 중립(0,0), 접지 B(1,-2)px의 작은 위치 변화만 적용했다. 머리·목·몸의 상대 연결과 얼굴 형태를 유지한다. 3고유그림 A→중립→B→중립/160ms는 그대로다. 정지는 중립과 동일하다.

✅ 정면 외 모든 상태 RGBA 동일, 좌표·재생 구성 동일, 작은 전체 프레임 이동과 머리 회전0도 확인. 기존 정면 앉기와 색면 정리 유지. 게임에는 설치하지 않았다.

sprite-sheet-alpha.png, manifest.json이 전달본이다. preview.html과 down_walk.gif로 재생을 확인한다. package_walk.py는 이전 clean 함수만 재사용하며 v15의 머리 편집은 실행하지 않는다. validation.json에 검사 기록을 보관한다.
