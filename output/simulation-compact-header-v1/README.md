# 주식 체험 상단 간소화 — 2026-10-28

사용자 스크린샷에서 종목/차트를 밀어내던 상단을 줄였다. 도전 제목·가상 자금 반복·긴 초반 설명·이미 본문에 있는 업종 필터의 별도 바로가기를 제거했다. 자산·손익·매수/매도 상태·뉴스 진행과 필수 버튼을 작은 한 줄로 모았다. 처음에는 짧은 매수 안내만 보인다. 뉴스가 생기면 제목만 표시하고 클릭해 내용을 펼친다. 결과도 요약/버튼만 보이고 계산 상세는 펼치기로 제공한다.

체험 내부의 중복 증권사 제목을 숨기고 지수 카드를 한 줄에 가깝게 줄였다. 일반 게임과 첫날 수업에는 이 축소 스타일을 적용하지 않는다. 거래/뉴스3회/실제 매수·매도/결과·재도전 조건은 유지한다.

SimulationChallengeView.js·title-simulation.css를 웹과 기존 실행본 리소스에 동기화했다. 설치 프로그램은 재빌드하지 않았다.

scratch/check-simulation-compact.cjs로 웹1440×1000, 실행본 리소스1440×1000, 모바일390×844에서 매수→뉴스3회→매도→결과→내역→재도전→종료/재입장을 통과했다. 추가로 최종 지수/제목 축소 후 웹 전체 경로 및 모바일 배치를 재검증했다. browser-checks.json·isolation-checks.json과 PNG를 따른다. pageerror0건, 이야기 상태와 일반 계좌 보존 확인. 뉴스/결과의 숨겨진 상세는 기본 HTML details로 유지한다. 실행본 리소스 검증은 브라우저에서 진행했다.
