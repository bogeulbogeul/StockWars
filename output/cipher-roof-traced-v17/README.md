# 증권사 첨부 윤곽 기반 지붕 재제작 v17 — 2026-10-25

사용자의 재정정 “아니 이런 모양으로 만들어달라니까?”와 첨부 `reference.png`를 기준으로 한다. v16의 임의 전체 높이 28% 압축과 v15의 마루 단면 위주 해석을 채택본으로 사용하지 않는다. v14의 압축 전 건물에서 지붕 형상만 새로 제작했다.

## 제작과 대조

- 중앙 박공 앞 꼭짓점/좌우 끝, 뒤 용마루 끝, 좌우 처마 끝, 좌우 가로마루 끝 등 눈에 보이는 9개 윤곽 기준점을 직접 지정했다. 가려진 교차점을 실제 꼭짓점인 것처럼 맞추지 않는다.
- `fit_roof.py`가 카메라와 중앙 폭·높이·처마 높이·뒤 길이/뒤쪽 기울기, 좌우 지붕 깊이·마루 높이·바깥 마루 위치를 함께 맞춘다. 임의의 전체 압축률은 사용하지 않는다.
- 모델 수치/카메라의 기준점 투영 RMS 약 3.57픽셀(775×287 기준). 이 값은 지정한 윤곽점 오차이며 전체 이미지/표면·재질 완전 일치 판정이 아니다.
- `roof_geometry.py`에서 실제 경사면과 교차선을 새로 계산해 중앙/좌우 기와를 잘라 맞춘다. 중앙 박공 틀·연속 파란 끝 마감·중앙 처마 하부·좌우 소핏·얕은 교차 마감을 새 형상에 맞췄다.
- 중앙은 앞 박공이 선 형태를 유지하며 뒤쪽으로 완만하게 내려가는 지붕이다. 좌우는 가로마루와 바깥쪽 사면을 가진 넓은 형태다. 상세 치수는 `roof-fit.json`, `manifest.json`에 기록한다.
- 기와 실제 법선 두께 0.018을 유지하고 제작된 기와 411개를 검사했다. 재질/조명도 시안의 밝은 클레이와 파란 지붕에 맞춰 조정했다.
