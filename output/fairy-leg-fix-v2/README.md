# 좁힌 체형 다리 연결 보정 v2 — 2026-10-22

P1 (Major) · ✅ 다리 보정·기존 모션 검사·웹/실행본 리소스 반영 / ⏳ 사용자 최종 시각 검수.

몸통 폭을 줄인 v1에서 다리의 넓은 윗단이 배 옆으로 노출되어 잘린 듯 보였다. `Somangi_Body`의 다리 상부만 높이에 따라 부드럽게 좁히고 위로 연장해 몸통 안에 넣었다. 발바닥에서 .11 이하는 그대로 두고 .22 높이 구간에서 보정량을 전이하며, 위쪽 최대 폭/깊이 80%·높이 +.16을 적용한다. 단위는 원본 모델 좌표다. 별도 몸통·다리 메시의 겹침 연결이며 하나의 용접 메시로 바꾸지는 않았다.

좁힌 몸통·머리·얼굴·팔·의상·발바닥·리그·웨이트·기존 모션 키는 v1과 동일하다. `build.cjs`는 선택한 다리 정점의 위치와 변형에 따른 법선만 바꾸고 나머지 바이너리 바이트의 동일성을 검사한다. 머리/발바닥 보존 정점 수·SHA-256은 `geometry-validation.json`에 기록한다. v1 제작본은 그대로 보존했다.

## 검증

- 네 캐릭터 실제 GLB의 정면·측면 렌더에서 다리 윗단 노출이 해소된 것을 확인했다. `*-front.png`, `*-right.png`.
- 소망이 걷기·인사·먹기·점프·게걸음 진입/유지/이탈·의자 앉기, 모아 걷기·앉기/일어서기·졸기·잎 동작, 봉봉 걷기 등 기존 애니메이션 33개와 토리 정지 자세를 검사했다. 모델 간 중복 클립을 포함한 개수다.
- 24fps 간격과 끝점을 포함한 총 1,104개 시점에서 양쪽 다리 윗단 표본 32개를 변형된 몸통의 로컬 좌표로 변환하고, 양면 삼각형 레이 교차로 내부 여부를 검사했다. 표본 이탈 0, 비정상 좌표 0, 브라우저 오류 0. 연속 시간의 모든 표면을 증명하는 검사는 아니다. `motion-validation.json`, `motion.log`.
- 모든 클립의 6개 시점 정면·측면 이미지를 `*-poses.png`로 저장했다. 걷기·먹기·점프·게걸음·의자 앉기·모아 앉기/일어서기/졸기 등을 시각 확인했다. `somangi-walk-preview.gif`, `moa-sit-preview.gif` 및 WebM은 실제 Three.js 모델 재생이다.
- 웹과 로컬 실행본 리소스의 기존 조작(걷기·인사·먹기·점프·게걸음), 집·잡화점·안내소·증권사 로딩이 통과했다. `browser-web.log`, `browser-runtime.log`. 실행본 리소스는 브라우저로 검사했으며 설치 프로그램은 재빌드하지 않았다.

소망이 6종·모아 2종·토리·봉봉·안내소 내장 모아의 11개 GLB를 게임에 반영했다. 다른 여섯 주민의 제작은 사용자 요청으로 보류한 상태다.
