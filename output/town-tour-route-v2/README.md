# 마을 소개 동선 v2

2026-10-25 사용자 요청으로 소개 순서를 현행 건물 배치에 맞춰 변경했다.

정류장 → 우디 가구점 → 두리 우체국 → 소망이네 집 → 토리 증권사 → 도란 쉼터 → 봉봉 잡화점 → 포포리 나무 → 소담 서점 → 차곡 은행 → 모아 안내소.

- 실제 sceneryCanStand 충돌 검사와 TourRoute의 경로 길이로 장소 간 비용을 측정했다. 정류장 출발·안내소 마지막을 고정한 순서 탐색 결과 이전 21,242 → 11,169 월드 단위, 약47% 감소했다. 이는 현재 격자 경로 기반 계산값이며 플레이어의 실제 걸음 거리/시간을 보장하는 수치는 아니다.
- 원고의 구간 경계와 이동 순서를 분리해 장소별 대사를 모두 보존했다. 첫 안내는 가까운 가구점으로 향하도록 일치시켰다. 은퇴한 옷가게 소개는 복원하지 않는다.
- 모아가 먼저 움직이고 플레이어가 WASD로 직접 따라가는 방식은 유지한다.
- 웹·기존 실행본 리소스의 충돌 경로 계산 결과 일치. 소개10곳 중복/누락 없음·원 대사 보존·첫 장소·안내소 마지막을 포함한 기존 테스트9개 통과.
- 계산 자료: route-analysis.json. 최종 사용자 플레이 검수는 별도다.
