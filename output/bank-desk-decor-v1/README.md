# 은행 데스크 소품 v1

사용자 참고의 가죽 데스크 매트·펜꽂이/펜/깃펜·황동 호출벨·목재 서류 트레이와 종이를 제작해 상판에 배치했다. 매트 테두리, 펜꽂이 내부, 벨 버튼, 종이 층을 포함한다.

- `Bank-desk-decor.glb`: 소품 세트 (설치 좌표)
- `Bank-decor-room-preview.blend`, `Bank-decor-room-preview.glb`: 최신 은행 룸 조합
- `desktop-close.png`, `room.png`: 미리보기
- `build_decor.py`: 재현 원본

✅ 모델·배치 렌더 / ⏳ 사용자 검수·게임 적용·호출벨/서류 상호작용. 데스크의 제거한 상판 난간/황동 끝장식은 복원하지 않았다.
