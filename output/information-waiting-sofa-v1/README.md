# 안내소 대기 소파 v1

P1 (Major) · ✅ 모델 제작 / ⏳ 사용자 검수·실내 배치·착석·게임 적용

상단 접합 후속: 양쪽 등받이 기둥의 높이를 늘려 상단 가로대 안으로 맞물리게 하고 깊이도 정렬했다. 둥근 기둥 끝이 가로대 아래에서 떨어져 보이던 틈을 없앴다. 가로대보다 기둥 앞면을 약간 안으로 넣어 겹치는 면의 렌더 오류도 피한다.

쿠션 후속: 딱딱한 상자형/평평한 면 대신 볼록한 초타원체 메시와 부드러운 노멀로 좌판·등받이·작은 쿠션을 재조형했다. 좌판 두께 .19, 등받이 .23, 작은 쿠션 .22로 볼륨을 늘렸다. 최신 좌판 상단은 .61이며 아래 최초 제작 치수보다 우선한다. 목재 프레임은 유지하고 체크 텍스처를 다시 베이크했다.

사용자 참고의 밝은 목재 프레임·연초록 2인 좌판/등받이·평평한 목재 팔걸이를 따른다. 크림색 작은 쿠션과 연초록 체크무늬 쿠션을 함께 제작했다. 체크무늬는 512px Base Color로 베이크해 GLB에 포함했다.

- `Waiting-sage-sofa.glb`, `Waiting-sage-sofa.blend`: 모델/원본
- `sofa.png`: 단독 미리보기
- `gingham-basecolor.png`: 체크 쿠션 색상 텍스처
- `build_sofa.py`, `manifest.json`: 재현과 상태

임시 제작 크기 약 폭 1.99·깊이 .86·높이 1.145, 좌판 상단 .58이다. 미리보기 바닥/조명/카메라는 GLB에서 제외했다. 기존 가구와 게임은 변경하지 않았다. 캐릭터 착석 접촉과 러그를 포함한 실내 배치는 별도다.
