# 소망이 먹기 — 원본 연결부 복원 v15

P1 (Major) · ✅ 보정·내보내기 / ⏳ 사용자 외형 검수

v14에서 아래로 내려간 팔 연결부와 좁아진 몸통 윗부분 때문에 목이 드러나 보이던 부분을 수정했다. 원본 v3의 몸통 단면 폭·깊이를 참고해 윗부분을 연속 곡면으로 복원하고, 팔 윗단은 머리 아래 안쪽에 겹쳐 연결했다. 머리를 내리거나 확대하지 않았다.

- 머리의 정점·얼굴 텍스처·검은 눈과 원래 미소 유지. 181개 시점에서 기존 머리 모션과 최대 좌표 차이 0.00000012.
- z ≤ -0.26의 배·다리는 v13과 동일. 상체 연결과 팔 윗단은 보정되므로 원본 전체와 정점 단위 동일한 모델이라는 뜻은 아니다.
- 빵 전체와 윗면 장식까지 검사. 양손 접촉 오차 최대 0.00292 모델 단위.
- 웃는 입과 먹는 입, 한 입마다 빵 크기 감소 유지.
- 게임에 설치하지 않음. 이전 제작본 보존.

`somangi-eat.glb`는 전달용, `somangi-eat.blend`는 편집용이다. 정면·측면 GIF는 내보낸 GLB를 다시 불러와 촬영했다. 검사 수치는 `validation.json`, `export-validation.json` 참고.
