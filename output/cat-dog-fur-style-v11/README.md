# 강아지 기준 털 표현 통일 v11

사용자 요청: 고양이의 털 표현을 RGB 강아지와 통일한다. 강아지를 털 묘사의 단독 화풍 기준으로 삼고, 진한 볼털 지그재그와 이중 가슴털 무늬를 간결한 털 경계로 교체했다.

- built-in GPT imagegen 편집: 기존 고양이16자세 모아보기를 대상, 강아지16자세 모아보기를 그림체 참고로 사용.
- 고양이 외형·색·자세·투명도·눈·귀·눈썹·손 표현과 v10의 옆 허리 윤곽 보정 유지. 털 기본색 RGB(65,59,62), 경계 RGB(51,45,48) 유지.
- 이전 털 무늬 위에 추가하지 않고, 해당 볼털·가슴털 부분을 새 묘사로 교체했다. 뒤는 기존 간결한 털 표현을 보존했다.
- 검증: 전체10상태·16고유자세, alpha 동일, 털 표현 변경 범위 밖 RGBA 동일, 뒤 동일, 좌표·재생 계약 동일, 걷기/운반160ms GIF 확인.
- 게임 설치와 최종 사용자 채택은 별도다. 다른 동물 에셋은 변경하지 않았다.

전달본: sprite-sheet-alpha.png, manifest.json. preview.html은 강아지와 비교 재생, overview.png는 전체16자세다. fur-style-generated.png는 GPT 중간 원본이며 package_fur.py가 원본 색·형태를 보존하면서 털 표현을 반영했다. validation.json에 변경 범위 검사를 기록한다. prompt.txt는 편집 요청이다.
