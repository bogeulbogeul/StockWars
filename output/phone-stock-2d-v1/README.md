# 주식 앱 2D UI 적용 v1 — 2026-10-25

후속: 사용자가 성장 기업 16개·동일 비중을 승인해 새싹 성장지수의 실제 수치 표시를 적용했다. 아래 구성/산식 미정 기록은 이전 이력이며 현행 구성·산식은 [새싹 성장지수 v1](../sprout-growth-index-v1/README.md)을 따른다.

P1 (Major) · ✅ 웹·기존 실행본 적용 및 자동 검증 / ⏳ 사용자 최종 시각·플레이 검수

사용자가 채택한 아이보리·평면 2D 시안을 `web/js/components/phone/stock/`에 구현했다. Blender·시안 PNG를 UI로 쓰지 않고 HTML/CSS/SVG를 사용한다. 데이터 형식/표시·홈/시장/계좌·차트·기업 정보·주문·소식 이전·상위 조정을 모듈로 분리했다. 기존 573줄 marketEngine과 447줄 TradeModal에 기능을 덧붙이지 않고 기존 엔진 API를 별도 데이터 어댑터에서 호출한다. 구형 네온 UI·실행 메서드는 계속 비활성 상태다.

## 적용 내용

- 홈: 총자산·보유 현금·주식 평가금·손익·최근 조회 종목. 최근 조회는 앱을 닫고 다시 열어도 세션에서 유지한다.
- 주식 거래: 72개 회사 검색, 관심 저장, 8업종 필터, 인기/변동률/가격/이름 정렬, 기존 추천 종목 노출.
- 내 계좌: 섹터별 투자 비중, 보유 슬롯, 보유/평균가/평가금/손익, 현물·공매도·배율 표시, 최신순 거래 이력과 수수료·현금 변동·실현 손익·체결별 수량/가격.
- 상세: 실시간/1일/1주/1달/1년 차트, 확대/가로 스크롤, 시각·가격 포인터, 최고/최저/평균, 호가 선택으로 지정가 주문 전환.
- 주문: 현물/공매도, 레벨 잠금 및 즉시 해제 반영, 1/2/3/5배, 시장가/지정가, 수량·MAX, 실제 엔진의 예상 수수료/부분 체결/매도 수령·손익, 매수/매도/공매도, 지정가 대기와 취소. 매도 지정가는 기존대로 1배로 전달한다.
- 기업 정보: 개요와 PER/PBR/ROE/배당률/시가총액/52주 최고·최저/위험도/변동성. 관련 공시·뉴스는 소식 앱으로 이동하며, 소식 앱에서 종목 상세로 돌아올 수 있다.
- 하단은 홈·주식 거래·내 계좌의 3개 탭이다. 뉴스 탭은 새 주식 UI에 없다. 화폐 표시는 잎, 지수 단위는 pt다.

## 지수

기존 `getCipherIndex()` 계산 결과의 표시 이름을 **리프 종합지수**로 사용한다. 내부 메서드 계약과 산식은 변경하지 않았다. **새싹 성장지수**는 사용자 채택 이름을 반영하되 구성 종목·산식이 확정되지 않았으므로 `— · 구성 준비 중`으로 표시한다. 임의의 성장주 편입이나 모의 지수 수치를 추가하지 않았다.

## 전시 모드

기본 전시도 같은 주식 UI를 사용한다. 휴대폰 수령 전 및 투자 자격증 전의 접근 제한을 유지한다. 전시의 현금·주식·거래 기록은 기존 전시 저장에서 읽는다. 첫 매수 활동의 버튼은 새 주식 앱으로 연결되며, 기존과 같은 첫 6개 적격 종목 중 현물 1주·수수료 0·첫 거래 1회로 제한한다. 성공하면 기존 `next('trade', data)`의 저장·진행 흐름을 사용한다. 그 외 전시 단계에서는 조회만 가능하며 일반 게임 거래 엔진/잔액과 섞지 않는다. 일반 게임에서는 기존 거래 엔진의 전체 기능을 사용한다.

## 검증·배포

`scratch/check-phone-stock.cjs`를 웹 및 `electron-app/dist/win-unpacked/resources/web` 양쪽에 실행한다. 72개 검색·업종·관심 저장·정렬·3탭·뉴스 분리/복귀·차트 확대/포인터·8개 기업 지표·실제 매수/매도·예상 수수료 일치·지정가 등록/취소·입력 오류·레벨 잠금/해제·모바일 세로/가로 스크롤·컴포넌트 구독 정리·전시 첫 매수 저장/진행/일반 계좌 분리를 검사한다. 결과는 `web-checks.json`·`desktop-checks.json`, 실제 렌더는 `*-home.png`·`*-market.png`·`*-account.png`·`*-chart.png`·`*-order.png`·`*-info.png`·`*-order-390.png`·`*-order-844.png`다.

기존 전시·호가 체결·지정가·거래 기록·차트 기간 테스트 21개를 통과했다. 배포 파일은 `synced-files.txt`의 21개이며 웹과 실행본 SHA256 일치를 확인한다. 설치 프로그램은 재빌드하지 않는다. 사용자 최종 시각·플레이 검수와 자동 검증을 구분한다. 다른 앱의 신규 구현·구형 설정/업적/의뢰/칭호 복원은 이번 범위에 포함하지 않는다.
