# 집 재디자인·오른쪽 우체통 3D 에셋 — 2026-10-25

사용자 요청으로 집 이미지 시안을 네이티브 3D로 제작했다. 참고 이미지의 우체통은 왼쪽이지만 후속 결정대로 **계단 오른쪽**, 모서리 기둥에서 떨어진 지면에 배치한다.

- 붉은 박공 기와·용마루, 크림 벽·굴뚝, 꿀색 목재 처마·모서리 기둥과 접지 받침.
- 원형 유리의 나무 문과 음각 하단 패널, 연속 아치 창틀과 안쪽 목재 테두리. 후면은 창문 없는 벽이다.
- 붉은 우체통에 실제 투입구·닫힌 앞문·봉투 부조·황동 손잡이, 나무 기둥·크림 받침을 제작했다. 현관 계단 통로와 간격을 둔다. 수신/보상 기능은 구현하지 않았다.

납품 파일: `Home-redesign.glb`(집 단독), `Mailbox-right.glb`(우체통 단독·받침 바닥 원점), `Home-with-right-mailbox.glb`(오른쪽 배치 통합), `Home-redesign.blend`(편집 원본). `build.py`로 재생성하고 `verify.py`로 GLB 재로딩·유한 좌표·접지·우체통/계단 간격을 확인한다. 실제 모델 전체·후면·우체통 확대 렌더를 제공한다.

P1 (Major) · ✅ 3D 에셋 제작 / ⏳ 사용자 최종 시각 검수·게임 적용. 이번 요청 범위는 에셋 제작으로 게임 파일과 기존 로컬 실행본은 교체하지 않았다. 기존 집 제작 원본도 보존한다.
