# 대출 상환 질문 답변·신청서 순서 수정

기존에는 '언제까지 갚아야 해?' 직후 loan 활동이 실행돼 서류부터 표시되고, 대본의 상환 답변은 빈 밑줄 placeholder로 빠져 있었다. 새 흐름은 질문→차곡의 현재 체험 조건 설명→기존 모아/차곡의 질문·결정 안내→소망이의 신청 의사→차곡의 서류 안내→loan 활동→실제 제출 완료 후 입금 대사다.

답변은 기존 대출 신청서와 같은 규칙(첫날 체험에서 기한/이자 적용 없음, 빌린5,000잎은 대출 원금으로 기록)을 설명한다. 새 기한·이율·상환 시스템을 추가하지 않는다. 동의 체크·실제 제출·5,000잎 현금/부채1회 반영은 유지한다. 원문과 이전 순서는 oldLoanFlow 옵션으로 숫자 커서 이관용 보존하며 현행 새 계획에는 쓰지 않는다. tourDialogueVersion5로 v3/v4 저장을 활동/대사 기준 이관하고 v2 이관도 유지한다.

- 관련 Node 테스트25개 통과: 양쪽 활동 순서의 질문 답변/신청 의사/서류 순서, v4 활동 커서/이미 받은 대출 현금·부채 보존, 과거 저장 이관/진행/보상 회귀 포함.
- scratch/check-loan-dialogue-order.cjs: 은행 질문 시점을 직접 준비하는 집중 fixture에서 실제 대화 버튼을 누르고 각 문구가 서류 전에 표시됨을 확인했다. 동의·제출 후 추가 클릭 없이 입금 대사로 넘어가고 현금/부채 각5,000을 확인했다. 웹/기존 실행본 리소스 양쪽 오류0. 전체 은행 진입 전후 플레이 검증은 아니다.
- Plan.js·State.js 동기화. 설치 프로그램 재빌드하지 않음.
