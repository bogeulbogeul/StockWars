# 정착 안내소 룸 틀 v1

P1 (Major) · ✅ 빈 룸 모델 제작 / ⏳ 사용자 검수·가구·창문·게임 적용

2026-10-20 후속: 하단 벽판·상부 몰딩·걸레받이를 각각 하나의 연속 U자 형상으로 변경했다. 뒷기둥 앞까지 두께를 확보하여 모서리 기둥 때문에 몰딩이 끊겨 보이던 부분을 이어주었다. 방 벽의 직각 구조는 유지한다.

직사각형 바닥, 크림색 벽 3면, 목재 하단 벽판과 상단 테두리, 머리/받침이 있는 모서리 기둥 4개, 전면 기둥 연초록 포인트, 중앙 출입 통로로 구성한다. 가구·소품·NPC·창문은 아직 넣지 않았다. 앞벽과 천장은 실내 확인용으로 열려 있다.

- `Information-room-shell.blend`: 편집 원본과 미리보기 카메라/조명
- `Information-room-shell.glb`: 카메라·조명을 제외한 룸 모델
- `front.png`: 정면 중심의 높은 시점 미리보기
- `build_room.py`: Blender 5.2 제작 스크립트
- `manifest.json`: 구조·검증·완료 범위

제작 단위 8×6×2.8은 임시 모델링 값이다. 벽은 월드 축과 평행하게 만들었으며 실제 구석 각도는 90도다. 원근 때문에 화면에서 보이는 선의 각도와 구분한다. 스크립트에서 벽 정렬·좌표 유효성을 확인한다. 출입 통로와 바닥 접점은 같은 높이다. 실제 게임 이동·충돌·출입 연결은 아직 검증하지 않았다.

외형 참고: 사용자 선호 안내소 실내 시안의 크림색/목재/연초록. 구조 참고: `../basic-pillar-room-v2/front.png`. 외관·기존 게임 리소스는 변경하지 않는다.
