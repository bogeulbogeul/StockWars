# 안내소 주변 여백·게시판 수정 v3

P1 · ✅ 웹·기존 실행본 반영·자동 검증 / ⏳ 사용자 최종 시각·플레이 검수

가구점과 안내소가 가깝고 게시판이 남아 있다는 사용자 피드백을 반영했다. 안내소를 `(1400, 2100)`에서 `(1520, 2200)`으로 옮기고 게시판을 `(1440, 2200)`에서 `(1830, 2210)`으로 이동했다. 게시판 좌표는 `townModelProps.js`에서 현행 안내소 좌표에 상대 `(310, 10)`을 더해 계산한다. 전시 스토리 위치도 기존 동적 연결을 따른다.

안내소 앞길을 새 위치에 연결하고 중앙 진입로를 X=1990으로 옮겨 게시판 옆에 통로를 확보했다. 정류장·모아·다른 건물의 위치와 외관·배율은 유지한다.

실제 모델의 Box3 외곽을 지면 좌표로 투영해 측정한 최소 간격은 안내소/가구점 약260.06, 안내소/정류장 약166.22 게임 단위다. 게시판과 안내소 외곽은 약16.27 단위 떨어져 있다. 이는 시각적 거리의 최종 사용자 채택을 뜻하지 않는다.

`townModelBuildings.js`, `townLandscapeLayout.js`, `townModelProps.js`를 웹과 기존 실행본에 동기화했다. `scratch/check-current-exteriors.cjs`의 웹·실행본 검사에서 건물 겹침 0건·길 10단위 표본 차단 0건·도착 지점에서 모든 입구 도달·9종 로딩/폭/문/시계·작은 화면·JavaScript 오류 없음이 통과했다. `web-checks.json`, `desktop-checks.json`, `web-overview.png`에 결과를 저장했다. 설치 프로그램은 재빌드하지 않았다.
