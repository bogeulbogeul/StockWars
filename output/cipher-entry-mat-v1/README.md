# 증권사 현관 로고 매트

Blender에서 만든 얇은 입체 매트와 직접 그린 로고 텍스처입니다.
파란 바탕·아이보리 테두리·외관과 같은 막대/상승 화살표 문양을 사용합니다.

- `Cipher-entry-mat.blend`: 편집 가능한 원본. 텍스처 포함.
- `Cipher-entry-mat.glb`: 게임용 텍스처 포함 모델.
- `mat-texture.png`: 로고와 테두리 텍스처.
- `mat-preview.png`: 모델 렌더.
- 제작 스크립트 2개 및 `exterior_geometry.py`: 재제작용.

Blender 크기 1.8 × 0.95 × 0.015, 바닥 z=0입니다.
게임은 폭 220으로 스케일해 현관 안쪽 z=302에 배치합니다.
바닥 위를 걸을 수 있으며 별도 충돌을 추가하지 않습니다.
실행본 리소스에도 설치했으며 로비 회귀 검증을 통과했습니다.
