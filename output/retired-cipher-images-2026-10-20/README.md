# 이전 증권사 이미지 에셋 · 폐기 보관

2026-10-20 사용자 요청으로 이전 2D 증권사 외관·로비·가구 이미지와 관련 제작 자료를 게임 리소스에서 제거했습니다.
이 폴더는 제작 이력을 보존하는 보관본이며 현행 에셋이나 자동 복원 대상으로 사용하지 않습니다.

- `web/`: 소스 리소스에서 옮긴 원본.
- `electron-app/`: 실행본 리소스에서 옮긴 이전 배포 파일.
- `manifest.json`: 보관 전 경로와 SHA-256. 양쪽 리소스 합계 358개 파일.

현재 `CipherSecurities-clock.glb`, 로비 3D 구성, 로고 매트, 트레이닝·경쟁 UI, 저장 데이터는 유지합니다.
기존 2D 소스 및 과거 테스트에 남은 구 이미지 경로는 제작 이력입니다. 해당 이미지는 현재 실행 경로에서 로딩하지 않습니다.
