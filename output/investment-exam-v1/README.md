# 투자 자격시험 UI v1

토리 증권사 청회색/아이보리 시험지. 응시자·문항 진행·자료·질문·4개 라디오 선택지·답안 확인·정답/해설·다음 문항을 구현했다. ACCOUNT_QUIZ의 기존 3문항·정답·해설을 재사용하고 기존 certificate 활동에 연결한다. 선택 후 별도 확인으로 답안을 저장하며 저장 실패 시 answers를 되돌리고 재시도한다. 해설 확인 후 다음 문항, 3문항 완료 후 기존 투자 자격증으로 연결한다. 기존 정답 수와 무관한 발급·분석력/저장 계산을 유지한다.

웹/기존 실행본 4파일 동기화. 설치 프로그램 재빌드 없음. scratch/check-investment-exam.cjs에서 1280×900·390×844·844×390 경계·미선택 제출 차단·답안 콜백·정답/해설·다음 콜백 검증. 전시 상태 테스트 6개 통과. PNG는 독립 UI 브라우저 렌더이며 게임 내 최종 사용자 플레이 검수는 별도다.
