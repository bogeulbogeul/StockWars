# 걷기 v3 — 짧은 다리 회전

사용자 요청으로 발 위치를 앞뒤·위로 독립 이동하던 방식을 제거했다. `blank-buddy-walk-v2`의 배 안정화·무광 재질·노멀맵 자국 제거·고정 얼굴을 유지한다.

- 골반에서 다리 전체를 앞뒤 최대 6도 회전한다. 다리 본의 위치 이동과 스케일 변화는 없다.
- 골반 아래의 다리·발은 한 덩어리로 움직이게 웨이트를 정리했다. 골반 접합부의 짧은 블렌딩 구간은 남아 있다.
- 바닥 쪽 발바닥 높이에 맞춰 Root로 캐릭터 전체 높이만 보정한다. 발을 별도로 들어 올리거나 옆으로 벌리지 않는다.
- 팔 흔들림은 최대 5도이며, 같은 쪽 팔과 다리는 반대로 움직인다. 24fps·1초 반복을 유지한다.
- 원본 메시 형상·텍스처는 유지한다. 기존 버전과 게임 파일은 변경하지 않는다.

## 검증 범위

`validation.json`은 25개 키 프레임에서 다리 본 길이·위치/스케일, 다리 아래쪽 메시 에지 길이, 배 중심 변형, 최소 발바닥 접촉·바닥 침투, 루프 연결, GLB 재수입을 검사한다. 골반 블렌딩 구간까지 완전 강체라는 판정은 아니다. 작은 회전으로 연결부 변형을 줄인 제작본이며 게임 이동 속도와 전환 블렌딩에 따른 발 미끄러짐 검수는 별도다.

## 파일

- `somangi-walk.glb`: 수정 걷기·7본·웨이트·재질 전달본.
- `somangi-walk.blend`: 수정 편집본.
- `walk-front.gif`, `walk-side.gif`: 검은 눈을 보존한 공통 팔레트 프리뷰.
- `contact-sheet.png`: 정면·측면 주요 자세.
- `motion.json`, `validation.json`, `preview-validation.json`: 제작·검증 기록.
