# 팔과 얼굴 간격 조정 v23

v22 먹기 모션에서 팔이 얼굴 밑면을 가로지르는 문제를 줄이기 위해 양팔과 빵을 같은 회전으로 낮췄다. 머리·몸통·다리·표정 형상은 그대로이며 팔의 길이·두께·표면도 강체 회전으로 유지한다. 정지 자세는 기존과 동일하다.

빵의 초기 크기 기준 100% → 2/3 → 1/3 → 0 축소를 유지한다. 마지막 사라지는 구간의 손과 빵 사이 간격은 v22에 남아 있던 별도 문제로 이번 팔 위치 조정에서 해결했다고 주장하지 않는다.

`eat-side.gif`, `eat-opposite-side.gif`는 실제 GLB를 불러와 촬영한 양쪽 측면이다. `contact-verification.json`은 181개 시점의 팔·음식과 머리 표면 교차 검사다. 팔 검사는 의도적으로 머리 아래에 묻힌 어깨 부착부(앵커 반경 0.18)를 제외한다. 표면 교차 검사이므로 모든 내부 포함이나 시각적 접촉의 완벽함을 보장하지 않는다.

제작 출력만 저장했으며 게임에는 설치하지 않았다.
