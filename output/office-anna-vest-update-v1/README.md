# 안내소 조합 장면 안나 참조 수정

이전 `anna-chair-fit-v1`이 `anna-sit-v1`의 수정 전 긴 조끼를 불러와 후속 스툴/소망이 배치 미리보기에도 전파되었다. 최신 `anna-meshy-short-vest-v5/Anna-meshy-short-vest.blend`의 캐릭터와 `Seated` 클립으로 교체했다. 기존 위치·임시 배율 .65·가구·소망이는 유지한다. 캐릭터 형상을 재수정한 작업이 아니다.

최신 조합은 `Office-latest-anna-preview.blend`, 전체는 `desk-preview.png`, 안나 확대는 `anna-detail.png`다. `anna-chair-fit-v1/inspect_fit.py`의 입력도 v5로 수정하여 재실행 시 오래된 조끼를 읽지 않게 했다. 과거 렌더는 수정 전 이력이며 현재 조끼 상태의 근거로 쓰지 않는다.

정지 착석 렌더 검수이며 전체 모션 충돌·게임 적용은 별도다.
