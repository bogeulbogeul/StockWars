# 소망이 게걸음 v4 — 팔 벌리기

2026-10-20 자동 전환 후속: 이동 방향 양쪽 여유를 기존 충돌 함수로 탐색해 좁은 통로에서 자동 게걸음, 넓은 곳에서 일반 걷기로 전환한다. 진입/해제 탐색 폭을 구분해 경계 반복 전환을 줄이고 한쪽 벽·정면 막다른 벽은 제외한다. `3` 키 수동 모드는 유지한다. 아래 통로 자동 감지 미구현 기록은 이전 이력이며 최신 상세·검사는 [정령 기준](../../Docs/SPIRIT_CHARACTER_BASELINE.md)을 따른다.

✅ 양팔 자세 수정·모션 검사·게임 연결 / ⏳ 사용자 최종 플레이 검수

사용자 요청으로 v3의 배 앞에 모은 팔을 양옆으로 벌린 자세로 변경했다. 어깨에서 손끝까지 약 20도 아래로 향하게 벌려 균형을 잡는다. 몸의 90도 회전·좌우 게걸음·발 디딤·속도·얼굴·둥근 배와 손끝은 v3와 동일하다.

- `somangi-crab-walk.blend` / `somangi-crab-walk.glb`: 수정 원본·모션 모델.
- `Crab_Enter`, `Crab_Right`, `Crab_Left`, `Crab_Exit`: 진입·좌우 반복·복귀.
- `crab-face.gif` / `crab-angle.gif`: 캐릭터 정면·사선 프리뷰.
- `validation.json`: 97시점 접지·다리 길이·배 형상·루프와 이동 축 검사 통과.

2026-10-20 게임 후속: `web/assets/characters/3d/somangi/crab.glb`로 설치하고 `3` 키 토글에 연결했다. WASD/방향키로 몸을 이동 방향에 옆으로 세워 게걸음하며 이동 속도는 14, Shift 가속은 적용하지 않는다. 실제 이동 거리 기준으로 재생 속도를 맞추고 멈추면 발 동작을 정지한다. 인사·먹기·점프 시작 및 입력 차단/착석 시 모드를 해제한다. 공유 캐릭터를 사용하는 집·잡화점·증권사 실내에도 같은 키와 속도를 사용한다. 기존 충돌 폭은 유지하며 좁은 통로 자동 감지는 구현하지 않았다. v3는 팔 모으기 이전안으로 보존한다.

웹 및 실행본 리소스를 각각 브라우저에서 검사했다. `3` 전환·네 방향 느린 이동·정지 시 재생 정지·Shift 입력 유지·인사 시 해제·기존 먹기/걷기/점프·단일 캐릭터 표시와 런타임 오류 없음이 통과했다. 기록: `scratch/check-somangi-game.cjs`, `scratch/somangi-game-crab.png`. 실행본 리소스 해시는 웹과 동일하다. 각 실내 통로의 실제 접촉 검수·Electron 프로세스 직접 실행·설치 프로그램 재생성은 이번 검증에 포함하지 않는다.
