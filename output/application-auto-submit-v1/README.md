# 신청서 제출 후 자동 진행 통일

2026-10-31. 사용자 스크린샷의 계좌 신청서 '신청서를 건네는 중…'은 BankApplication이 상태 문구의 추가 클릭을 무기한 기다려 발생했다. 같은 모듈의 대출 신청서도 동일했다.

BankApplication의 전달 문구는 입주 신청서와 같이 1.2초 후 자동 완료한다. 문구 클릭/Enter/Space로 즉시 진행할 수 있다. 빈 이름/대출 동의 필수·중복 제출 차단·기존 상태/서류 저장·대출 금액 조건은 유지한다. 마운트 시 대화창 테마도 제거한다. 신청서 외 연출의 클릭 전용 진행은 변경하지 않았다.

검증: scratch/check-application-auto-submit.cjs는 실내/활동을 직접 준비하는 집중 fixture다. 입주 신청서의 빈 이름 차단/이름 입력 후 자동 완료와 계좌/대출의 실제 Activities.run→제출 버튼→Exhibition.next→다음 대사 렌더를 확인했다. 전달 상태 문구 추가 클릭은 하지 않았다. 대출 미동의 차단·동의 후 제출·중복 submit 시 대출 현금/부채 각5,000만 반영·오류0을 웹과 기존 실행본 리소스 양쪽에서 확인했다. checks.json 및 완료 스크린샷 참고. 관련 Node 진행/경제 테스트21개 통과.

BankApplication.js를 기존 실행본 리소스에 동기화했다. 처음부터 전체 게임 플레이 검수·실제 EXE 실행·설치 프로그램 재빌드는 하지 않았다.
