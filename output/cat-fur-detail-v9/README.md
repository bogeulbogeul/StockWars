# 고양이 볼털·가슴털 복원 v9

사용자 지적에 따라 v8에서 사라진 내부 볼털 결과 가슴털 경계를 복원했다. 그림체·셀 명암은 RGB 강아지 시트를 계속 기준으로 사용한다. 고양이 디자인 시트는 볼털과 가슴털의 형태만 참고했다.

- ✅ 완료: built-in GPT imagegen으로 기존16자세 모아보기의 볼털·가슴털만 편집했다. 생성된 털 경계 모양을 원본 내부 털에 공통 그림자색 RGB(51,45,48)로 복원했다.
- ✅ 완료: 정면·옆 걷기, 운반, 앉기와 얼굴 초상화의 보이는 털 결 복원. 뒷모습은 수정하지 않아 등쪽 가슴털 무늬를 추가하지 않았다.
- ✅ 완료: 기존 기본색·셀 명암·눈·귀·눈썹·손·실루엣·alpha·좌표·재생 계약 유지 검사. 털 기본색 밖 픽셀 동일 검사 통과.
- ✅ 완료: 걷기3그림 A→중립→B→중립, 운반4그림,160ms GIF 검증.
- ⏳ 대기: 사용자 외형 확인. 게임에는 설치하지 않았다.

전달: sprite-sheet-alpha.png, manifest.json. preview.html은 강아지와 비교 재생, overview.png는16자세 모아보기다. 검증은 validation.json, 편집 프롬프트는 prompt.txt에 기록한다. fur-detail-generated.png는 GPT 원본이며 최종 게임 시트가 아니다. restore_details.py가 원본 색과 자세를 보존하며 털 결만 복원했다.
