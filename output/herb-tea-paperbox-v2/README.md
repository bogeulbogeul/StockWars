현행 `web/assets/items/packing-v1/items.png`의 `10,490,410,235` 영역을 직접 확인했다. 원본의 낮고 넓은 초록색 상자·삼각형 접이 뚜껑·크림색 띠·중앙 원형 잎 문양·양옆 작은 가지와 뚜껑 표식을 따랐다. 꽃잎 차의 높은 봉합형 상자로 바꾸지 않았다.

상자·삼각 뚜껑·양옆 접힘·얇은 앞쪽 접힌 끝·뒤 풀칠 겹침·밑면 접기는 실제 메시다. 약 0.003 상대 단위의 얇은 종이 두께와 거친 무광 재질을 사용한다. 중앙 잎과 원형 테두리·양옆 가지는 새로 정리한 평면 인쇄이며 원본의 색·배치를 유지한다. 이전 모델의 두꺼운 라벨이나 입체 잎 장식은 사용하지 않았다. 뚜껑 인쇄는 실제 면 비율을 고려해 제작했다. 인쇄 PNG 3개는 GLB와 Blender에 내장했다.

GLB 구조·Blender 재수입·유한 정점·퇴화면 0개·내장 이미지 실제 디코딩을 검증하고 전체·재수입 확대·후면 렌더를 확인했다. 정확한 수치와 해시는 `validation.json`을 따른다. 사용자 최종 외형 검수는 별도다.

이번 개별 수정본을 기존 12종 모음의 허브차보다 우선하는 후속 제작본으로 사용한다. 다른 상품·가격·저장·상점/포장 UI·기존 실행본은 변경하지 않았다. 게임 적용은 별도다. GLB는 상품만 포함하고 `.blend`는 촬영용 조명·카메라·바닥을 포함한다.
