# 게시판 2D v4 · 상단 비율 수정

사용자 피드백에 따라 큰 아이보리 사각 제목판을 제거했다. 새싹 표식과 제목을 곡선 나무 머리판 안으로 통합하고 머리판을 142px(모바일 102px)로 줄였다. 전체 폭 900px, 프레임/종이 여백과 작은 분류표를 정리했다.

웹 및 기존 실행본 resources/web의 CSS/컴포넌트 반영. 공고 확대·복귀·확인·Esc·모바일 가로 넘침 테스트 통과, JS 오류 0건. preview.png/mobile.png 실제 브라우저 렌더 확인. 근접 상호작용 및 이야기 흐름 코드는 변경하지 않았다. 사용자 최종 시각 검수는 별도다.
