# 내 정보 플레이어 레벨·코드 추가 v2

사용자 요청으로 프로필 아래에 플레이어 레벨/경험치와 플레이어 코드를 추가했다. 분석력과 플레이어 레벨을 구분한다.

일반 모드 레벨은 ItemEngine.playerLevelProgress()의 실제 경험치 계산을 읽는다. 최고 레벨은 최고 레벨 문구를 사용한다. 첫날 체험은 별도 플레이어 경험치 지급이 없어 공통 PlayerGrowth의 초기 경험치 기준 Lv.1을 표시한다. 경험치나 레벨을 새로 지급하지 않는다.

플레이어 코드는 연결된 서버 stockWarsPresence.state().snapshot.playerId의 실제 값을 #ID로 표시한다. 인증 토큰을 표시하거나 임의 코드를 생성하지 않는다. 로컬/전시는 서버 ID가 없어 코드 미발급으로 표시한다. 서버 ID는 앱 진입 및10초 간격으로 읽고 cleanup 시 타이머를 해제한다. 서류/분석력의 기존 동작은 유지한다.

synced-files.txt의5개 파일을 웹/기존 실행본에 동일 해시로 적용했다. check-phone-profile-level.cjs는 격리 브라우저에서 실제 경험치150의 Lv.2 계산 및 서버 bridge fixture ID2468 표시를 확인하고 원본 은행 서류/분석력 회귀 검사를 수행한다. 이름·경험치·ID 검증 값은 사용자 실제 데이터가 아닌 격리 테스트 값이며 게임 코드는 항상 실제 소스를 읽는다. 설치 프로그램 재빌드는 하지 않았다.
