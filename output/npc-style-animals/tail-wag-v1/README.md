# 강아지 모션별 정리 및 정면 걷기 꼬리 수정

1920×4000,6열10행. 정면 대기/걷기 → 사선 대기/걷기 → 뒤 대기/걷기 → 운반 → 정면 앉기 → 사선 앉기 → 얼굴. 운반 행만6칸(걷기4+꼬리대기2), 나머지3칸. 서로 다른 동작을 빈 칸에 끼워 넣지 않는다. 정면 걷기A/B의 꼬리도 변경했다. 기존 몸·얼굴·손발·중립과3프레임160ms는 유지한다.

재생 확인: ../unified-v2/preview.html. 재조합: front-walk.py 원본이미지경로 → compact.cjs. build.py는 최초 대기 생성 재구성용으로 정면 걷기 수정은 이후 front-walk.py로 적용한다.
