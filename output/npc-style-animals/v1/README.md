# NPC 그림체 동물 기본 에셋

사용자 요청에 따른 시고르자브종 강아지와 검은 고양이의 기본 직립 일러스트. 옷 없이 꼬리가 몸에 연결된 형태로 제작했다.

러시안블루 NPC는 동물 체형·선·명암 참고, 비비안은 선·명암 보조 참고로 사용했다. 생성은 내장 image_gen 도구를 사용했다. dog-prompt.txt, cat-prompt.txt, cleanup-prompt.txt에 생성·투명 배경 정리 프롬프트를 보존한다.

현재 결과는 단일 기본 자세 PNG다. 방향별 그림, 모션, 파츠 분리와 본 제작, 게임 적용은 완료 범위에 포함하지 않는다. 기존 플레이어 에셋과 최종 기준 문서는 교체하지 않았다. 월드 적용 시 몸체의 정수리부터 접지선까지 균일 배율로 H=90을 맞추며 귀·꼬리·투명 여백으로 크기를 정하지 않는다.
