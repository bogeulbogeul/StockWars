# v2 시각 검수

## 들린 다리와 옆면 색 보정

사용자 요청으로 2·5번 들린 다리를 낮추고 허벅지→무릎→종아리→발 연결을 다시 그렸다. 무릎이 골반 아래에 있고 발은 접지선 가까이 지나가도록 수정했다. 3·6번 통과 자세도 낮은 발 위치로 정리했다. 기존 팔 위치와 스윙은 유지하도록 지정했다. 정면 정지의 털색을 참조하여 별도 색상 편집을 추가했으며 강한 주황을 완화한 밀색 베이지으로 조정했다. 6그림 접촉 시트에서 발 높이가 낮아지고 종아리 연결이 보이는 것을 확인했다. 프롬프트: right_walk-leg-color-fix.txt 및 right_walk-palette-fix.txt. 이전 원본은 raw/right_walk-before-leg-color-fix.png에 보존. 내장 image_gen 편집, canonical extract·compose-atlas·compose-gif 및 비교 화면 재빌드. 추출 오류·경고 없음. 팔/다리 교대 전체와 실제 게임 접지·속도 검수는 별도다.

## 오른팔 스윙 수정

사용자 지적에 따라 기존 6자세 행을 내장 image_gen으로 팔만 지정 편집했다. 1·2번 가까운 팔은 꼬리 쪽 뒤, 3번은 아래, 4·5번은 주둥이 쪽 앞, 6번은 아래로 이동한다. 먼 팔은 반대 방향으로 움직이며 몸통에 가려진 구간에는 별도 가까운 팔을 추가하지 않는다. 6프레임 접촉 시트에서 가까운 팔의 뒤→아래→앞→아래 위치 변화와 관절 연결을 확인했다. 프롬프트는 prompts/right_walk-arm-fix.txt, 이전 행은 raw/right_walk-before-arm-fix.png다. 꼬리·머리·기존 다리 자세를 유지했다. canonical extract는 오류·경고 없이 통과했고 아틀라스·GIF·비교 화면을 새로 빌드했다. 이 팔 수정 확인은 발 교대·실제 이동 속도 검수의 완료를 뜻하지 않는다.

- 외형 기준: v1 추출 정면 정지. 사용자 곰 시트는 옆 걷기 동작용 참고이며 의상·색·머리 외형은 전용하지 않았다.
- right_walk: 6그림 프레임 추출·동작 변화·연결 파일 확인. 기존 중립 정지 삽입을 제거하고 통과 자세를 포함했다. 접지/통과 실루엣은 달라졌으나 해부학적 양발 교대의 확정 판정 및 움직이는 루프의 시각적 최종 합격은 보류한다. experimental.
- down_walk: v1 재사용, 발 교대 그림 존재. experimental.
- up_walk: v1 재사용. experimental.
- down_idle/right_idle/up_idle: 단일 정지 자세. v1 재사용.
- right_carry: v1 재사용, 이전 같은 다리 반복 문제 미해결. FAIL/experimental, 최종 적용 제외.
- down_sit/right_sit: v1 유지 그림 재사용. 실제 좌석 접촉과 가림 검수는 보류.

정적 프레임 검수와 GIF 생성/재생 코드 검증을 자연스러운 실제 게임 이동 합격으로 대신하지 않는다. 변경 행의 추출은 경고 없이 통과했고 전체 inspect는 단일 유지 자세의 움직임 부족 경고만 반환했다.
