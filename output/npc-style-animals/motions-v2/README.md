# NPC 스타일 동물 모션 수정 v2

사용자 지적: 고양이 정면·뒤의 색상과 그림체 차이, 두 동물의 어색한 옆 걷기. 사용자 첨부 곰 걷기 그림을 외형이 아닌 **동작 참고**로 사용했다.

## 변경

- 강아지·고양이 오른쪽 걷기를 3자세에서 6자세 한 주기로 다시 생성. 멈춤 삽입 대신 접지·뒤꿈치 들기·통과 자세를 포함했다. 왼쪽은 반전 재사용.
- 고양이 정면 정지를 색·명암·선 기준으로 고정하고 뒤 정지와 뒤 걷기를 다시 생성. 뒤 걷기는 수정한 뒤 정지와 정면을 함께 참조했다.
- 다른 걷기·운반·앉기 행은 v1의 추출 프레임을 그대로 재사용. 운반의 기존 발 교대 문제와 좌석·화물 정렬은 이번 수정에서 해결 완료로 표시하지 않는다.

## 제작 기록

GPT 이미지 행 방식 유지. sprite-gen prepare로 6자세 레이아웃을 만들었다. gen-set은 추가 동작 참조 인자를 지원하지 않아 이번 변경 행은 같은 sprite-gen gen --provider codex를 행별 호출하고 정체성·레이아웃·사용자 동작 참고를 각각 전달했다. 생성 프롬프트와 참조 경로는 각 run/prompts, generation-*-v2.json에 보존했다. 잘라내기·투명화·배치는 canonical extract, 아틀라스는 compose-atlas, GIF는 compose-gif/preview_animation으로 처리했다.

merge_v2_frames.py는 재사용 행의 파일·메타데이터를 v2로 합친 어댑터다. 이미지 픽셀이나 추출·배치 알고리즘을 바꾸지 않는다. 새 변경 행과 기존 행의 키 색이 다를 수 있으므로 전체 raw를 새 키로 다시 추출하지 않는다.

두 시트는 각9행·21그림, 셀320×400, 시트1920×3600이다. 옆 걷기는6그림 순차 반복(8fps 시험값), 정면·뒤는3그림 A→중립→B→중립이다. H=90은 정면 정지의 기존 공통 배율을 유지한다. 최종 모션 합격이나 게임 적용 완료를 뜻하지 않는다. 개별 그림 간 비율·동작 교대와 접지는 계속 검수 대상이다.
