# v2 시각 검수

## 앞발 끝 정리

사용자가 지적한 3·6번 겹친 손 윤곽을 내장 image_gen으로 수정했다. 가까운 앞발은 손가락 선 없는 작은 둥근 윤곽 하나로 정리하고 먼 앞발은 몸 뒤에 가린다. 다른 자세의 앞발 끝도 같은 둥근 형태로 통일했다. 6그림 접촉 시트에서 중복 앞발 윤곽 제거와 기존 팔 스윙·낮은 다리 자세 유지를 확인했다. 프롬프트는 right_walk-paw-fix.txt, 이전 행은 raw/right_walk-before-paw-fix.png다. canonical 추출 오류·경고 없음, GIF·아틀라스·비교 화면 갱신.

## 강아지 동작 참조와 고양이 팔 수정

사용자 요청으로 현행 강아지 6자세를 동작 참고, 정면 고양이를 색·외형 참고로 전달해 고양이 행을 내장 image_gen으로 편집했다. 얼룩 형태의 작은 명암을 줄이고 큰 차콜 색면으로 정리했다. 첫 편집에서도 가까운 팔이 앞에 남아 추가 지정 편집했다. 최종 접촉 시트에서 1·2번 가까운 팔 뒤, 3번 아래, 4·5번 앞, 6번 아래 위치를 확인했다. 낮은 발 위치와 기존 고양이 귀·얼굴·꼬리는 유지했다. 프롬프트는 right_walk-dog-motion-fix.txt와 right_walk-near-arm-target.txt다. 이전 행은 raw의 before 파일로 보존한다. canonical extract는 오류·경고 없이 통과, 6프레임 GIF와 아틀라스·비교 화면 재빌드. 전체 모션의 발 교대/월드 이동 최종 합격과 구분한다.

## 들린 다리와 옆면 색 보정

사용자 요청으로 2·5번 들린 다리를 낮추고 허벅지→무릎→종아리→발 연결을 다시 그렸다. 무릎이 골반 아래에 있고 발은 접지선 가까이 지나가도록 수정했다. 3·6번 통과 자세도 낮은 발 위치로 정리했다. 기존 팔 위치와 스윙은 유지하도록 지정했다. 정면 정지의 털색을 참조하여 별도 색상 편집을 추가했으며 더 밝은 차콜 중간톤으로 조정했다. 6그림 접촉 시트에서 발 높이가 낮아지고 종아리 연결이 보이는 것을 확인했다. 프롬프트: right_walk-leg-color-fix.txt 및 right_walk-palette-fix.txt. 이전 원본은 raw/right_walk-before-leg-color-fix.png에 보존. 내장 image_gen 편집, canonical extract·compose-atlas·compose-gif 및 비교 화면 재빌드. 추출 오류·경고 없음. 팔/다리 교대 전체와 실제 게임 접지·속도 검수는 별도다.

- 외형 기준: v1 추출 정면 정지. 사용자 곰 시트는 옆 걷기 동작용 참고이며 의상·색·머리 외형은 전용하지 않았다.
- right_walk: 6그림 프레임 추출·동작 변화·연결 파일 확인. 기존 중립 정지 삽입을 제거하고 통과 자세를 포함했다. 접지/통과 실루엣은 달라졌으나 해부학적 양발 교대의 확정 판정 및 움직이는 루프의 시각적 최종 합격은 보류한다. experimental.
- down_walk: v1 재사용, 발 교대 그림 존재. experimental.
- up_walk: 정면과 수정 뒤 정지를 참조하여 털색·명암·선을 다시 생성. 뒤꿈치와 반대 발 들어올림 확인. experimental.
- down_idle/right_idle/up_idle: 단일 정지 자세. up_idle 색·선·명암 재생성.
- right_carry: v1 재사용, 이전 같은 다리 반복 문제 미해결. FAIL/experimental, 최종 적용 제외.
- down_sit/right_sit: v1 유지 그림 재사용. 실제 좌석 접촉과 가림 검수는 보류.

정적 프레임 검수와 GIF 생성/재생 코드 검증을 자연스러운 실제 게임 이동 합격으로 대신하지 않는다. 변경 행의 추출은 경고 없이 통과했고 전체 inspect는 단일 유지 자세의 움직임 부족 경고만 반환했다.
