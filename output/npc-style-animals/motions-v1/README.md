# NPC 스타일 동물 모션 시트 시안

시고르자브종 강아지와 검은 고양이의 꼬리 포함 시트. 각 캐릭터 9행·18그림, 320×400 셀, 1280×3600 투명 PNG다. 게임 연결 및 본 리깅 원본은 이번 범위에 포함하지 않는다.

- 정면·오른쪽·뒤 정지: 방향별 1장
- 정면·오른쪽·뒤 걷기: 방향별 3장, 미리보기 A→중립→B→중립
- 오른쪽 운반: 4장, 왼쪽 반전
- 정면·아이소메트릭 오른쪽 앉기 유지: 각 1장, 왼쪽 반전
- 상자·의자는 분리한다. 운반 상자는 비교 화면에서 별도 PNG로 표시하며 손 정렬은 임시값이다.

[재생 비교 화면](preview.html), [강아지 시트](dog/run/sprite-sheet-alpha.png), [고양이 시트](cat/run/sprite-sheet-alpha.png).

## 제작과 검수

sprite-gen prepare → gen-set --provider codex → extract → compose-atlas → preview_animation 파이프라인을 사용했다. 마지막 문제 자세의 편집만 내장 image_gen으로 시도했다. 편집 결과는 크기 오류와 미해결 교대로 채택하지 않았고 rejected-v1에 보존했다. 직접 픽셀 수정이나 임의 프레임 절단은 하지 않았다. 프롬프트는 각 run/prompts, 요청은 request.json에 저장했다.

투명 프레임 추출은 오류·경고 없이 통과했다. 자동 inspect에서 단일 정지·앉기 행의 움직임 부족 경고는 고정 자세라 예상된다. 시각적 동작 검수는 별개다.

**옆 걷기·운반은 실험 시안이며 모션 연속성 합격이 아니다.** 두 번의 행 생성과 한 번의 지정 자세 편집에도 근접 다리가 1·3번에서 반복 전진하는 문제가 남았다. 완성된 자연스러운 양발 교대라고 표시하거나 게임 기본 모션으로 교체하지 않는다. 정면·뒤는 반대쪽 발 그림이 있으나 꼬리 흔들림 폭·전체 비율·게임 이동 속도 동기화는 실제 재생 검수가 남는다. 앉기는 유지 그림만 제작했으며 앉기 진입·일어나기는 포함하지 않는다.

비교 화면은 중립 정면 그림에서 시각적으로 측정한 정수리~접지 구간(강아지 약330px, 고양이 약307px)을 H=90으로 맞춘 공통 배율을 사용한다. 귀·꼬리로 기준 키를 정하지 않고 각 프레임을 별도로 H=90에 맞추지 않는다. 추출 행 사이 몸통·머리 비율과 좌석 정렬은 후속 검수 대상이다.
