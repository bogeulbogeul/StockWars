# 강아지·고양이 모션 외형 통일

2026-10-16 최신 게임/캐릭터 시트 기준. 정면 기준으로 모든 방향·행동과 얼굴 초상화를 GPT로 행별 보정하고 sprite-gen으로 추출·조합했다. 방향별 정지는 걷기의 중립 프레임과 바이트 동일하며 렌더러도 해당 좌표를 직접 사용한다.

걷기3자세, 재생0→1→2→1·160ms, 운반4자세, 오른쪽 사선 및 왼쪽 반전 유지. 셀320×400,4열10행,1280×4000 RGBA. 이전 시트는 portraits-v1, 이전 게임 원본은 before-game에 보존.

preview.html에서 정지/이동, 방향, 행동 및 이전 시트 비교 가능. generation.json은 프롬프트·원본 경로 기록이며 raw에 작업 원본을 복사했다. 각 run의 transition-verification.json에서 정지/중립 일치 검증 결과를 확인한다. inspect 오류 없음; 정적1프레임 상태의 낮은 모션 경고는 예상 결과다. 실제 가구·화물 접촉과 발 미끄러짐의 세부 검수는 별도다.
