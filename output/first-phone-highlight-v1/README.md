# 첫 휴대폰 토글 강조·배경 페이드

사용자 스크린샷의 openPhone 활동에서만 배경을 약0.45초 동안 어둡게 페이드하고, 오른쪽 아래 실제 휴대폰 토글을 아이보리 배경·초록 테두리·은은한 빛과 '여기를 눌러주세요' 문구로 강조한다. 기존 왼쪽 위 설명은 읽을 수 있게 유지한다. 배경 오버레이는 버튼보다 아래이며 버튼의 실제 클릭/P키 열기를 유지한다.

폰을 열 때 즉시 효과를 해제하며, 닫기 후 기존 활동 완료 1회와 취소/재시작 시 클래스 정리를 유지한다. prefers-reduced-motion에서는 페이드/빛 애니메이션 없이 같은 최종 상태를 표시한다.

scratch/check-first-phone-highlight.cjs는 안내소/휴대폰 활동을 직접 준비하는 집중 fixture다. 웹/기존 실행본 리소스의 1440×1000 및390×844에서 실제 버튼 클릭 가능·배경 페이드 완료·버튼 화면 안 배치·열기 시 효과 제거·닫기 후 완료1회·취소 정리·브라우저 오류0을 확인한다. 처음부터 휴대폰 수령까지 전체 플레이 검증은 아니다. 검증 초기의 애니메이션 중간값/활동 커서가 다른 fixture 오류를 수정한 최종 결과는 checks.json이다.

FirstPhonePrompt.js·exhibition.css·first-phone-prompt.css를 웹/기존 실행본에 동기화했다. 설치 프로그램 재빌드 및 실제 EXE 검증은 하지 않았다.
