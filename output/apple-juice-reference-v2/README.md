# 사과주스 원본 이미지 보정 v2

라벨 후속 수정은 [v3](../apple-juice-clean-label-v3/README.md)를 따른다. 이 폴더는 라벨 수정 전 이력이다.

2026-10-25 사용자 요청: 사과주스 에셋을 앞선 상품처럼 원본 이미지에 맞춰 다듬기.

현행 상점 공통 이미지 `web/assets/items/packing-v1/items.png`의 사과주스 영역 `920,35,155,355`을 직접 확인했다. 길쭉한 원통 몸통·둥근 어깨·좁아진 목·두꺼운 바닥을 실제 회전체로 만들었다. 속이 있는 유리벽과 안쪽 주스가 분리되어 있으며, 초록 뚜껑의 작은 홈·윗면 안쪽 원·금빛 개봉 방지 띠·크림색 목 씰을 추가했다.

기존 두 개의 구형 사과 장식과 두꺼운 사각 배지는 제거했다. 원본의 사과·잎·크림색 테두리 라벨 그림을 추출해 병을 따라 휘는 얇은 종이에 적용했다. 라벨 PNG는 GLB와 Blender 파일에 내장한다. 주스는 원본의 황금빛을 따르며 유리·주스의 투과와 약한 색 보정을 사용한다. 런타임에서 같은 투과 표현을 보려면 glTF 전송 재질 확장을 지원하는 렌더러가 필요하고, 이번 작업에서 실제 게임 적용·조명 일치 검증은 하지 않았다.

GLB 재수입·유한 정점·퇴화면 0개·내장 라벨 디코딩을 검증하고, 전체·후면과 재수입 후 뚜껑/목 확대를 렌더한다. 정확한 메시 수·삼각형 수·해시는 `validation.json`을 따른다. 사용자 최종 외형 검수는 별도다.

기존 12종 모음의 사과주스는 이전 이력으로 보존하며 이번 개별 수정본을 후속 제작 기준으로 사용한다. 꿀쿠키·꽃잎 차와 다른 상품은 변경하지 않았다. 상점 UI·게임 리소스·저장·가격·포장 퍼즐은 변경하지 않았다. GLB는 상품만 포함하고 `.blend`는 촬영용 조명·카메라·바닥을 포함한다.
