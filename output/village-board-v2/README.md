# 게시판 에셋 기준 UI

실제 게임 NoticeBoard-clean.glb의 제작 원본 NoticeBoard-clean.blend를 정면·투명 배경으로 렌더하여 사용한다. 곡선 머리판·새싹 메달·나무 기둥·받침·아이보리 종이 6장·황동 압정을 원형대로 유지한다. 기존 공고 3개를 위쪽 종이 3장에 연결하고 아래쪽 빈 종이는 에셋 그대로 남겼다. 공고 클릭 시 큰 글씨 원문, 게시판 복귀, Esc, 이야기 확인 흐름을 유지한다. 게임 GLB는 변경하지 않았다.

웹 및 기존 실행본 resources/web에 반영. villageBoard.browser.cjs의 공고 선택·확대·복귀·진행·모바일 가로 넘침·오류 검사 통과. 사용자 최종 시각/게임 플레이 검수는 별도다.

## 접근 상호작용

전시 모드에도 공통 게시판 상호작용을 설치했다. 현재 게시판 앞 기준점 125 게임 단위 이내에서 F키 또는 화면 버튼으로 연다. 타이틀·실내·자동 안내 이동·장면 전환·다른 모달 중에는 열지 않는다. 게시판 활동의 자동 열기를 제거했고 그 단계에서는 WASD로 접근/이탈할 수 있다. 공고 확인만 기존 notice 완료로 연결되며 단순 닫기는 진행하지 않는다. 모달 중 이동 입력을 정리하고 닫으면 이동을 재개한다. 버튼은 전시 대화창 위에 배치했다.

실제 웹 마을 검사: node web/tests/villageBoardInteraction.browser.cjs
먼 거리 F 차단, 가까운 거리 F 열기, 마우스 버튼 열기, 모달 중 이동 차단, 닫은 후 WASD 재개, JavaScript 오류 0건 통과. 웹과 기존 실행본 소스를 동기화했다. 설치 파일 재빌드는 하지 않았다.

기존 실행본 브라우저 검사는 로컬 마을 로딩 대기로 완료되지 않았다. 실행본의 기능 검증 통과로 기록하지 않으며 웹 결과와 소스 동기화만 확인했다.
