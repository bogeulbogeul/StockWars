# 노드 은행 재디자인 v2

P1 · ✅ 채택 이미지 기반 네이티브 3D 제작 / ⏳ 사용자 최종 시각 검수·게임 적용

사용자 요청 “그럼 이렇게 에셋 변경해줘”에 따라 `approved-reference.png`를 기준으로 은행 외관을 제작했다. 이 이미지는 내장 imagegen으로 제작한 시안이며 원래 외형 참고는 `bank-exterior-clean-v1/front-right.png`, 무광 클레이 표현 참고는 `furniture-redesign-concept-v1/concept.png`다.

- 금빛 주 지붕은 좌우 방향 용마루를 갖춘 박공지붕, 현관은 전후 방향의 작은 박공지붕으로 만들었다. 교차선으로 양쪽 기와/지붕 바탕을 잘라 맞추고 닫힌 골 마감을 넣었다.
- 크림색 두 기둥·원형 새싹 음각 동전·목재 양문·정면 두 아치창과 오른쪽 아치창·반원 두 단 계단을 유지했다. 후면 창이나 벽 조명은 추가하지 않았다.
- 네 문 패널을 실제 음각과 밀착 몰딩으로 만들고 문/창 아치를 연속 메시로 정리했다. 측면 박공은 벽 몸체와 합쳐 수평 이음선을 없앴다.
- 결과는 `Bank-clean.glb`, `Bank-redesign.blend`; 정면/사선/후면/지붕 교차부/출입구는 실제 모델 렌더다. `verify.py`는 GLB 재로딩·새 지붕/문/목재의 닫힌 형상·수량·유한 좌표·접지를 검사한다.

웹·기존 실행본 모델, 시설·실내·저장·금융 기능은 변경하지 않았다. 게임 반영·배율/충돌/로딩 검증은 후속 적용 단계다.
