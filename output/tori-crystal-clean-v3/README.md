보석과 머리의 접촉을 위한 내부 삽입은 유지하며 외부로 드러나는 파란 띠를 제거했다. 확인한 정지 자세 확대 렌더에서는 중복 면 얼룩이나 이중 테두리를 발견하지 못했다. glTF의 재질/법선/UV 이음 분리 정점을 검사 메모리에서만 1e-6 이내 병합한 뒤 경계·비다양체·면적 0 면을 검사했다. 이 검사는 임의 메시 사이의 모든 교차가 없음을 증명하지 않는다. 모든 모션의 접촉 검사·사용자 최종 시각 검수와 게임 적용은 별도다. 게임 파일·저장 변경 없음.
