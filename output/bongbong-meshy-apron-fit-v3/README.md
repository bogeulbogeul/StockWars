# 봉봉 앞치마 끈·어깨 마감 v3

2026-10-22 · P1 (Major) · ✅ 끈 연결·어깨 마감 수정·6방향 렌더·GLB 재수입 검사 / ⏳ 사용자 시각 확인·전체 모션 접촉 검수·게임 적용.

사용자 요청: 허리끈을 앞판 뒤쪽에 붙이고 끈을 깔끔하게 연결하며 어깨를 마감한다.

제공 Meshy 앞치마의 앞판·주머니와 봉봉 몸체를 유지했다. 기존 짧은 어깨끈·노출된 뒤 허리끈 끝부분은 제거하고, 허리끈은 앞판 뒤에 들어가는 끝에서 뒤 리본까지 연속 곡면으로 다시 구성했다. 앞쪽 끝을 깊이 방향으로 안쪽에 묻고, 기존 연장부의 겹친 단차를 정리했다. 뒤 리본은 보존하되 새 허리끈 바깥에 놓이도록 조정했다.

어깨끈은 부드러운 곡선의 아이보리 중심·코랄 테두리로 재구성했다. 앞쪽은 가슴판 뒤에, 뒤쪽은 허리끈 안쪽에 들어가도록 마감하고 제거 후 남은 작은 끈 조각을 정리했다. 원본 앞치마 재질에서 아이보리·코랄 텍셀을 공유하며 기존 Body 본에 연결한다.

- `Bongbong-finished-apron.blend`: 편집 원본.
- `Bongbong-finished-apron.glb`: 착용 모델·공통 리그·기존 걷기 클립.
- `Apron-finished.glb`: 앞치마와 공통 리그.
- `front.png`, `left.png`, `right.png`, `back.png`, `three-quarter.png`, `rear-quarter.png`: 실제 렌더.
- `finish.py`, `validation.json`, `export-validation.json`: 생성 및 검사 기록.

정면·양측면·후면·앞뒤 사선에서 연결부를 시각 확인했다. GLB 재수입 시 허리끈 좌우 2개·어깨끈 2개·단일 리그·걷기 클립을 검사했다. 끈과 앞판의 결합은 가려지는 부위에 묻어 연결하는 별도 메시 구조이며 단일 용접 토폴로지로 바꾼 작업은 아니다. 전체 모션의 어깨·팔 접촉 검수와 게임 적용은 수행하지 않았다. 이전 버전은 보존한다.
