# 아이보리 하트 HUD 게임 적용 — 2026-10-25

사용자가 선택한 아이보리 카드형 하트 UI를 웹과 기존 실행본 resources/web에 반영했다. 설치 프로그램은 재빌드하지 않았다.

- `components/HeartHUD.js`와 `css/heart-hud.css`: 아이보리 카드·코랄색 하트·체력 숫자, 소모한 칸은 빈 하트로 남긴다. 표시 전용이며 클릭과 이동을 가로채지 않는다.
- 일반 게임은 MainHUD.renderHearts/updateStamina를 통해 기존 ItemEngine의 실제 체력 감소·회복을 표시한다. 최대 3칸은 COMMON_PLAYER_RULES를 따른다. 경제·소모·회복·저장 스키마를 변경하지 않았다.
- 첫날 전시는 기존에 체력 소모 시스템이 없으므로 공통 시작 체력 3/3을 표시한다. 전시 저장에 새 체력 필드나 소모/회복 이벤트를 추가하지 않았다.
- 기본은 왼쪽/위 24px, 카드 폭 208px. 작은 화면은 여백 12px, 폭 180px. 게임 전체 배율을 상쇄한다.
- 안내 카드·현금·대화·착석/게시판·스마트폰 등 주요 UI의 실제 화면 영역을 확인해 아래 빈 공간에 배치한다. ResizeObserver와 DOM 상태 변경으로 재배치하고, 화면에 자리가 없으면 하트를 숨긴다. 타이틀·열린 dialog(스마트폰/게시판/포장 게임 등)·상점 구매·전시 엔딩에서는 숨긴다. 안내창과 현금 UI 자체의 위치/공개 조건은 유지한다.

## 검증

`node scratch/check-heart-hud.cjs` 및 `node scratch/check-heart-hud.cjs electron-app/dist/win-unpacked/resources/web`로 검사했다. 기존 실제 게임 화면을 로드해 안내창 아래 배치·현금 UI와 비겹침·320/360/600px 및 900×500 가로 화면·빈 하트·스마트폰 숨김/복귀·타이틀 숨김·일반 체력 상태의 1/3→3/3 갱신을 확인했다. 실행본 대상 검사에는 320px 화면의 대화창 표시/숨김과 재배치도 포함한다.
