# 꼬리 좌우·색면·얼굴 초상화 v19

사용자 요청으로 세 항목을 수정했다.

- 뒤 걷기 A는 화면 왼쪽으로 휜 긴 꼬리, B는 화면 오른쪽으로 휜 긴 꼬리로 편집했다. 이전처럼 오른쪽 안에서 끝 높이만 바꾸지 않는다. 현재 중립은 오른쪽으로 모인 C자 형태다. 골반 연결은 시각 참고했으며 정확한 뿌리 좌표 동일을 자동 검사했다고 주장하지 않는다.
- 전체 털은 공통 기본(65,59,62), 그림자(51,45,48), 밝은 면(73,66,70)으로 정리하고 미세 색 조각을 제거했다. 눈썹은 해부학적 위치에서만(92,81,85), 귀 안쪽은(254,157,120)으로 고정했다. 다리의 떠 있는 작은 명암 조각도 기본색으로 정리했다.
- 얼굴 초상화는 턱 아래 가슴털을 제거해 얼굴과 귀만 남겼다. 몸이 있는 다른 상태의 가슴털은 유지한다. 초상화 alpha 하단은 y444 이전이다.

기존16자세 모아보기를 built-in GPT imagegen으로 편집 후 색면을 정리했다. 모든 그림이 셀 내부에 있고 투명 배경·좌표 계약·걷기3고유그림 A→중립→B→중립·운반4그림·160ms를 유지한다. 새 편집본의 외형/alpha는 이전 픽셀과 동일하지 않다. 게임에는 설치하지 않았다.

sprite-sheet-alpha.png, manifest.json, frames/가 전달본이다. up_walk.gif와 preview.html로 꼬리 움직임을 확인한다. tail-color-portrait-generated.png는 GPT 원본, prompt.txt는 요청, materials.py는 재질 색면 정리, package_sheet.py는 기존 모아보기 셀의 atlas 조합이다. validation.json의 좌우 바깥쪽 tail pixel 수로 A/B의 방향 차이를 기록한다.
