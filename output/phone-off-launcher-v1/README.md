사용자가 스마트폰 버튼으로 사용할 꺼진 화면의 UI를 요청했다. 기존 둥근 검정 스마트폰 형태를 2D 인라인 SVG로 단순화하고 검정 액정·삽입 베젤·상단 수화부·측면 버튼을 표시했다. 앱·시계·문자·발광은 넣지 않았다. Blender나 이미지 생성은 사용하지 않았다.

`PhoneLauncher.js`의 공통 그림을 일반 게임의 기존 오른쪽 아래 버튼과 전시의 기존 오른쪽 위 버튼에 적용했다. 버튼 크기는 72×112px, 실제 아이콘은 64×100px다. 클릭·P 단축키·휴대폰 홈·닫기 후 포커스 복귀와 전시 수령 전 숨김을 유지한다. 보조기기 이름은 ‘스마트폰 열기’이며 키보드 포커스 테두리를 제공한다.

`scratch/check-phone-launcher.cjs`로 양쪽 리소스의 실제 렌더·타이틀 중 숨김·클릭 열기·Escape 닫기·포커스 복귀·모바일 화면 경계·전시 수령 조건을 확인한다. `*-checks.json`과 실제 게임 `*-game.png`·`*-exhibition-mobile.png`를 따른다. `*-preview.png`는 같은 SVG를 3배로 보여주는 UI 미리보기다. `synced-files.txt`의 5개 파일은 웹/실행본 해시가 일치하며 설치 프로그램은 재빌드하지 않았다.
