# v9 길 배치 지도 일괄 반영 v4

P1 · ✅ 웹·기존 실행본 적용·네 표시 경로 검증 / ⏳ 사용자 최종 시각·플레이 검수

사용자 요청 “지도들도 업데이트 해줘”에 따라 다음을 갱신했다.

- 안내소 거치대: `popori-map-path-v9-v3/map.png`를 현행 `Information-furnished-room.glb`에 내장했다. 이미지 이름은 `Popori_Village_Map_Path_v9`다.
- 안내소 지도 보기: 거치대 공통 텍스처를 읽어 같은 새 그림을 표시한다.
- 스마트폰 지도·모아 지도 소개: 공통 `MapSvg.js`가 `MapPaths.js`의 세계좌표100단위 코너 곡선을 사용한다. 실제 v9 경로/길별 폭·정류장 소품 좌표·차도 중심/폭을 반영하고 검색/선택/내 위치 기능은 유지했다.

현행 실내 모델의 지도 이미지 참조만 교체하고 기존 바이너리/메시/노드/UV/가구/충돌/모아는 유지했다. 교체 전 모델과 원본/대상 해시는 이 폴더에 보존했다. 기존 실행본 모델은 웹과 동일하며 `MapSvg.js`·`MapPaths.js`도 동기화했다. 이전 제작본·과거 GLB는 이력으로 보존하며 일괄 덮어쓰지 않았다.

`scratch/check-information-map-update.cjs`를 웹·기존 실행본에 실행해 내장 새 이미지1402×1122·거치대/지도 보기 실제 픽셀 일치·스마트폰/모아 지도 소개를 실제로 열어 모든 최신 경로 d값 일치·JavaScript 오류 없음 검사를 통과했다. `web-checks.json`·`desktop-checks.json`, 거치대 확대 `web-map-display.png`에 기록했다. 지도 엔진 테스트3개도 통과했다.

기존 전체 `check-phone-map.cjs`의 일반/전시 복귀 회귀 시나리오는 숨겨진 홈 복귀 버튼에서 시간 초과해 완료하지 못했다. 지도 경로 일치와 실제 열기는 위의 대상별 검사로 별도 확인했으며 전체 스마트폰 회귀 통과로 기록하지 않는다. 설치 프로그램은 재빌드하지 않았다.
