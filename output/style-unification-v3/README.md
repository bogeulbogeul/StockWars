# 동물 8종 스프라이트 색·그림체 보정

최신 후속 수정: `output/motion-color-restore-v2/`에서 강아지 기준 모션 보정 중 진해진 7종의 털색·명암을 기존 승인색으로 다시 편집했다. 토끼 뒤 걷기3그림과 뒤 정지에도 둥근 머리 외형을 반영했다. 현재 run·비교 페이지·전체 ZIP은 해당 후속 수정을 포함하며 강아지 PNG는 유지한다. 실제 프롬프트·직전 보존본·검수 범위는 v2 기록을 따른다.

후속 수정: 유럽토끼 사선 얼굴의 고양이 같은 뾰족한 볼·눈매를 `output/rabbit-face-v2/`에서 둥근 토끼 형태로 수정했다. 걷기·대기·운반·앉기 9논리 프레임에 적용했으며 몸·발동작과 기존 코 색은 유지했다. 현재 미리보기·시트·ZIP은 이 수정까지 포함한다. 머리 편집과 이전 코 픽셀 복원 기록은 해당 폴더의 README·generation.json·verification.json을 따른다. 원본 네이티브 보드를 재추출하는 경우 후속 머리 수정을 다시 적용해야 한다.

2026-10-16. 강아지·고양이·붉은여우·시베리아다람쥐·너구리·유럽오소리·불곰·유럽토끼의 실제 PNG 프레임을 보정했다. 각 캐릭터의 기존 정면 정지를 외형·털색·눈색·명암 기준으로, 강아지·고양이를 공통 선·렌더링 참고로 사용했다. 최종 프레임은 각 종의 고유 외형과 기존 동작을 유지하며 모션별 색·선·명암의 차이를 줄인 네이티브 이미지 편집본이다.

- `preview.html`: 8종 전체 보정 전후, 모든 공통 모션, 강아지 꼬리 대기, 한 프레임 보기, 자동 모션 전환, 작은 크기와 좌우 반전.
- `overview.png`, `comparison.png`: 보정 후 모아보기와 보정 전후 비교.
- `<id>/run/`: 최종 투명 시트, 개별 프레임, manifest, 정확한 재생 순서의 GIF와 검증 기록.
- `generation.json`: built-in image_gen의 실제 프롬프트 9개와 생성 파일 경로. 각 캐릭터 폴더에 편집 입력·기준 정면·네이티브 편집 결과를 보존했다. 추가 강아지 꼬리 보정은 6상태 전체를 포함한다.
- `<id>/before/`: 보정 전 시트·프레임·manifest. 강아지 정적 기본형의 이전 파일도 보존했다.

제작: 기존 16고유자세를 4행 편집 보드에 모아 색·그림체만 image_gen으로 보정했다. 새로운 그리드 애니메이션 생성이 아니다. 한 줄 단위로 어댑트하고 sprite-gen의 chroma 제거·연결 컴포넌트 추출 함수를 사용했다. 이후 보드 전체에 같은 균일 배율을 적용하고 기존 프레임의 발밑 선과 중심에 배치했다. 프레임마다 높이를 강제로 같게 맞추지 않았다. 기존 manifest의 실제 좌표로 조합해 강아지의 공유 셀·10행 배치를 유지했다. 이 배치와 꼬리 영역 조합은 프로젝트 전용 수작업 어댑터이며 표준 compose-atlas를 실행했다고 주장하지 않는다.

강아지 꼬리 대기는 새로 보정한 몸·머리·팔다리를 동일하게 고정하고 네이티브 보정본의 꼬리 영역만 완성 프레임으로 합쳤다. 고양이 대기 꼬리 애니메이션은 추가하지 않았다. 모든 동물의 발바닥 패드 금지를 유지했다.

색 수 제한 및 주요 색의 정수 RGB 교체를 sprite-gen recolor로 시험했으나 눈의 희귀 색 손실·미세 명암의 입자감을 발견해 **둘 다 미채택**했다. 최종 PNG는 추출·정렬된 네이티브 보정 RGB 그대로이며 팔레트 강제 축소를 적용하지 않았다. `run/variants`, `recolor.*`, `reference-palette.json`은 실험/분석 기록이며 최종 채택본이 아니다. `rejected-processing.json` 참조.

검증: 8종의 170논리 프레임 항목(중복 중립 포함), 기존 시트 좌표·상태 수·재생 설정 유지, 정지와 걷기 중립 일치, 잘림·빈 프레임 없음, GIF 재생과160ms, 강아지 꼬리 밖 몸 픽셀 동일. 전체 자세·후면 발·꼬리 비교 이미지를 확인했다. 프레임의 픽셀 외형은 이미지 편집으로 바뀌었으며 원본 알파까지 동일하다는 주장은 하지 않는다. RGB 후처리 없이 채택한 네이티브 추출본과 최종 PNG의 RGBA는 동일하다.

강아지·고양이는 기존 게임 PNG에 반영했다. 숲속 친구들 6종은 판매용 에셋 보정까지이며 게임 통합은 수행하지 않았다. 실제 가구·화물 접촉, 세부 발 미끄러짐과 실내외 연결의 게임 내 시각 검수는 별도다. preview-verification은 DOM/canvas 경로 스모크 테스트로 실제 브라우저 시각 검수와 구분한다. inspect의 정적 상태 저모션 경고 및 강아지 뒤 꼬리의 작은 움직임 경고는 inspect-summary에 남겼다.
