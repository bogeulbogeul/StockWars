# 소망이 빵·컵 손 접촉 보정

P1 (Major) · ✅ 제작·캐릭터 데이터 동일성·손 접촉 검사 / ⏳ 사용자 최종 시각 검수

기준은 `../somangi-eat-drink-shoulder-v2/`의 수정 모델이다. 소품이 예전 본 끝 위치와 별도 오프셋을 따라가 실제 보정된 손 표면에서 떨어져 보이던 문제를 수정했다. 실제 손 끝 표면의 고정된 정점 패치를 접촉 기준으로 삼는다.

**소망이의 기본 메시·UV·법선·모든 모프 형상·캐릭터 모프 애니메이션 데이터는 이전 GLB와 동일하다.** 어깨 보정과 검은 눈을 유지했다. 소품의 위치·회전·크기만 변경했으며 기존 파일과 게임 파일은 변경하지 않았다.

- `somangi-bread.glb` / `.blend`: 양손 접촉점 사이에 빵을 배치하고, 손의 움직임에 맞춰 방향을 조정한다. 양손 간격에 맞게 빵 크기를 고정 조정했다.
- `somangi-drink.glb` / `.blend`: 컵 아래쪽의 잡는 지점을 손 표면에 고정한다. 컵을 입으로 기울일 때도 그 지점을 기준으로 회전한다. 손과 입 사이에 맞게 컵 크기를 고정 조정했다.
- `bread-side-motion.gif`, `drink-side-motion.gif`: 수정 GLB를 직접 재생해 촬영한 정측면 3초 반복 미리보기.
- `bread-front-motion.gif`, `drink-front-motion.gif`: 같은 수정 GLB의 정면 3초 반복 미리보기. 모델·모션 변경 없이 카메라만 정면으로 옮겨 각 36프레임을 촬영했고, 올리기·입에 대기·내리기 자세에서 손 접촉을 시각 확인했다.

## 검증

`export-validation.json`: 이전 GLB와 새 GLB에서 캐릭터의 기본 형상·법선·UV·모프 형상/법선과 모프 재생 트랙이 바이너리 기준 동일함을 확인했다. 각 모델에서 형상 속성 버퍼 70개를 비교했다.

`grip-validation.json`: 각 동작 181개 시점에서 고정된 손 표면 패치를 기준으로 접촉을 검사했다. 빵의 접촉점은 타원체 표면 안쪽의 작은 여유 범위에 유지됐고 바깥 틈 추정값은 0이었다. 컵의 고정 접촉점과 손 표면 패치 중심 사이 최대 차이는 약 0.002 모델 단위(캐릭터 키 약 1.95 기준 약 0.1%)였다. 이는 접촉 기준점 검사이며 모든 손·소품 삼각형 사이의 충돌을 검증한 결과는 아니다. 실제 정측면 렌더도 확인한다.

GLB는 기존과 같은 모프 애니메이션 방식이다. 캐릭터 weights 트랙과 소품 transform 트랙을 함께 재생한다. 소품 배율은 동작 중 변하지 않는다.
