# 정적인 크레파스 타이틀 — 2026-10-28

사용자 첨부의 크레파스 로고·아이보리 종이·손 흔드는 소망이·새싹 분위기를 유지하며 타이틀 레이아웃을 정리했다. 새 그림을 생성하거나 기존 이미지를 변형하지 않고 기존 frame-0.png를 그대로 재사용한다.

- TitleScreen.js의 animateTitle import/호출/종료 호출을 제거했다. 추가 플립북 이미지를 불러오거나 교체하지 않는다. 기존 TitleMotion.js와 원본 PNG는 제작 자료로 남긴다.
- 그림 폭을 최대1440px로 제한하고 중앙 여백을 확보했다. 실제 메뉴 nav를 추가해 버튼 간격/폭을 통일했다. 기본 버튼은 차분한 초록색, 보조 버튼은 아이보리와 얇은 초록 테두리다.
- 세로 모바일은 그림 아래 메뉴를 배치한다. 키보드 포커스 표시는 유지하며, 기존 엔딩용 그림 버튼은 한 개만 표시하고 별도 높이를 확보한다.
- 게임 시작/오프닝/버스와 주식 체험/타이틀 복귀 연결은 유지했다. 타이틀의 무음 정책도 유지한다.

웹 및 electron-app/dist/win-unpacked/resources/web의 TitleScreen.js·crayon-title.css를 동기화했다. 설치 프로그램은 재빌드하지 않았다.

scratch/check-static-title.cjs로 웹과 기존 실행본 리소스를 각각 검증했다. 1920×1080,1366×768,390×844,844×390에서 메뉴 영역이 화면 안에 있음을 확인하고 PNG를 저장했다. 2.5초 이상 대기 후 정적 그림1장/추가 프레임0장, Tab으로 주식 체험 선택→Enter 실행→Escape 복귀, 시작하기→오프닝 연결을 확인했다. pageerror0건이다. checks.json 및 packaged/checks.json을 따른다. 기존 실행본 리소스를 브라우저로 검사했으며 EXE 자체 검수와는 구분한다.
