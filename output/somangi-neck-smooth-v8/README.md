# 소망이 얼굴 밑선·목 연결 정리 v8 — 2026-10-23

사용자의 확대 참고(`reference.png`)에서 보이는 울퉁불퉁한 얼굴 밑선을 정리했다. 머리 하부 정점을 UV 경계에서 연결해 평활화하고 낮은 밑면을 연속적인 둥근 곡면으로 보정했다. 정면·후면 모두에 적용하며 얼굴 표정 영역은 보호한다. 목을 길게 만들지 않는다.

몸통 폭·두께·밑선과 v7의 팔 위치·다리는 유지한다. 본·웨이트·모든 모션 트랙·UV·삼각형 인덱스를 변경하지 않았다. 수정 대상은 `Somangi_Body`의 머리 하부 위치와 법선이다. 원본 6개 GLB는 `original/`에 보존하고 `build.mjs`로 재현한다.

P1 (Major) · ✅ 6개 GLB 웹·실행본 리소스 반영 및 해시 확인. 9개 모션 304시점에서 기존 다리 상단·어깨 연결 검사 통과, 비정상 좌표와 브라우저 오류 없음. 이 검사는 머리와 몸통 사이의 모든 동작별 접촉을 수학적으로 보장하는 검사는 아니다. ⏳ 사용자 최종 외형·플레이 검수.
