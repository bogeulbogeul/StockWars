# 새 몸통에 맞춘 의상 사이즈 조절 v4 — 2026-10-22

P1 (Major) · ✅ 의상 조절·렌더/기존 모션 검증·웹/실행본 리소스 반영 / ⏳ 사용자 최종 시각·플레이 검수.

사용자 요청으로 매끈한 몸통 v3에 맞춰 모아·토리 조끼와 봉봉 앞치마를 다시 조절했다. 몸통·머리·얼굴·팔다리·본·웨이트·모프·기존 모션 키는 v3 그대로다. 의상의 정점 위치와 법선만 바꾸며 나머지 바이너리 동일 검사를 `geometry-validation.json`에 기록한다. 기존 제작본은 보존한다.

## 조절

- 조끼는 몸통 표면에 맞춰 품·앞뒤 여유를 정리하고 밑단을 원본 단위 최대 .035 올렸다. 새 표면에서 의상 표본의 여유는 약 .0105~.0352다. 초록/남색, 앞트임·테두리·암홀을 유지한다.
- 앞치마는 밑단을 최대 .045 올리고 앞판·주머니의 도드라짐을 유지하면서 과한 돌출을 줄였다. 어깨끈과 허리끈은 몸통 바깥으로 나오게 간격을 다시 맞추고 뒤 리본을 유지했다. 봉봉 의상 표본 여유는 약 .0109~.0839이며 큰 값에는 주머니·리본의 돌출이 포함된다.
- 수치는 원본 모델 좌표다. 의상/피부에 다른 크기 배율을 적용하거나 의상의 재질·색을 바꾸지 않았다.
- 높이 구간별 보정에서 발생할 수 있는 수평 꺾임을 피하도록 연속 함수로 간격을 조절하고 변형에 맞춰 법선을 계산한다.

## 검증

- 실제 GLB의 정면·측면·후면·사선 12장을 렌더했다. `moa-*.png`, `tori-*.png`, `bongbong-*.png`. `overview.png`는 왼쪽부터 모아·토리·봉봉이다.
- 기존 애니메이션 24개(모델 간 중복 포함)와 토리 정지 자세를 24fps 간격과 끝점, 총 800개 시점으로 검사했다. 다리 윗단 이탈·어깨 연결 겹침 소실·비정상 좌표·브라우저 오류 0. 모아/토리 의상 129개, 봉봉 의상 683개 표본 정점을 매 시점 검사하여 몸통 내부로 들어간 표본이 없음을 확인했다. `motion-validation.json`, `motion.log`.
- 모아 걷기·앉기/일어서기·졸기, 봉봉 걷기의 정면·측면 키포즈를 시각 확인했다. 각 클립의 6개 시점은 `*-poses.png`다. 모든 표면 사이의 연속 충돌이나 모든 가구와의 접촉을 증명하는 검사는 아니다.
- 웹/실행본 리소스의 기존 걷기·인사·먹기·점프·게걸음 전환, 집·잡화점·안내소·증권사 로딩을 확인했다. `browser-web.log`, `browser-runtime.log`.
- 모아 벤치 앉기/졸기 2개, 토리, 안내소 내장 모아, 봉봉 등 5개 GLB를 웹과 `electron-app/dist/win-unpacked/resources/web/`에 설치했다. `install-validation.json`에 제작본과 양쪽 게임 리소스의 SHA-256 동일 여부를 기록한다. 소망이 모델과 기존 게임 로직은 이번 조절에서 변경하지 않았다. 실행본 리소스는 브라우저로 검증했으며 설치 프로그램은 재빌드하지 않았다.
