# 안나 착석 공간 배치 v2

P1 (Major) · ✅ 배치 수정 / ⏳ 안나 착석 정합·게임 적용

검수: `inspect_seating.py`로 저장된 조합 장면을 다시 열어 실측했다. 의자 앞~상판 뒤 .435, 의자 뒤~벽판 .205, 좌판~상판 아래 .295이며 데스크 다리 공간 폭 1.45는 의자 폭 .79보다 넓다. 다리 공간 방향 레이 검사는 전면 안쪽 벽까지 가로막힘 없이 통과했다. 결과는 `seating-inspection.json`, 측면 미리보기는 `seating-side-check.png`다. 안나 후보 모션 GLB의 클립은 `Idle`·`Walk_InPlace`뿐으로 앉기 클립이 없다. 최종 안나 배율과 착석 자세가 없어 캐릭터 관통·발 접지·책상 손 접촉은 미검증으로 남긴다.

소품이 올라간 기존 데스크 배치는 유지하고 의자를 뒤로 .38 이동해 중심 y=2.23에 놓았다. 데스크 뒤끝과 의자 앞끝 사이에 약 .435의 빈 공간을 확보했다. 뒷벽 하단 벽판 앞에도 여유가 남도록 경계 좌표를 확인했다. 임시 모델링 단위이며 실제 안나의 앉은 체형/손/발 접촉 검증과 구분한다.

- `Room-seating-space.blend`: 최신 룸·의자·데스크·소품 조합 배치
- `room-preview.png`, `desk-detail.png`: 전체/확대 미리보기
- `adjust_layout.py`, `manifest.json`: 재현 및 실측 간격

의자·데스크·소품의 독립 GLB와 게임은 변경하지 않았다. 최신 조합 배치는 이 폴더를 사용한다. 이전 제작 폴더의 배치 미리보기는 수정 전 이력이다.
