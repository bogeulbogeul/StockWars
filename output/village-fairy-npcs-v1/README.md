![두리 우체국 요정 정면 시안](09-duri-proposal.png)

**P1 (Major) · ✅ 정면 이미지 제작·사용자 외형 확정·문서 반영 / ⏳ 측후면·모델·모션·게임 적용·검수.** 두리의 정면 이미지 외형을 2026-10-21 사용자 확정했다. 말을 고르는 상대를 재촉하지 않고 기다리는 다정하고 꼼꼼한 편지 안내자로 제안한다.

확정 외형은 짧고 통통한 요정 체형·옅은 하늘색 몸·봉투 문양의 작은 테라코타색 우편 모자·크림색 조끼·갈색 옆가방이다. 모자와 가방으로 다른 주민과 구분하며 날개·비행은 필수로 추가하지 않는다. 2026-10-21 사용자가 이 정면 이미지의 외형을 확정했다. 색·비율·검은 타원 눈·작은 미소·분홍 볼·의상·소품을 유지하고 갈색 가방은 두리 왼쪽(화면 오른쪽)에 둔다. 내장 imagegen으로 봉봉 정면을 체형·표현 참고로 사용해 시안 1장을 제작했다. 정면 전신·하늘색 몸·모자 봉투 표식·크림 조끼·갈색 가방과 잘림 없음을 시각 확인했으며 외형 기준으로 채택했으며 게임용 모델·모션 제작과 게임 적용은 대기다. 생성 프롬프트는 [duri-prompt-v1.txt](duri-prompt-v1.txt)에 보존한다.

우체국에서 편지 작성·대상 선택·선물 첨부·발송을 안내하고 집 앞 우편함 수신을 소개한다. ‘미래의 나에게 첫 편지 쓰기’ 첫 방문 이야기 후보의 안내를 맡는다. 대표 대사 초안: “어떤 말부터 쓸지 모르겠으면, 오늘 있었던 일부터 적어볼까요?” 첫날 필수 방문·우편 요금·배송 시간·발송 한도·개방 시점은 이번 주민 추가로 확정하지 않는다.

모든 시안은 내장 imagegen으로 제작했습니다. 짧고 통통한 요정 체형을 공유하며 두리는 정면 이미지의 외형이 사용자 확정되었으며 다른 주민의 채택 상태는 각 제작 기록을 따릅니다. 측후면·소품 없는 모델링 자세·표정 텍스처·모션 및 게임 적용 검수는 후속 작업입니다. 안경 두께와 머리 장식 크기는 실제 게임 표시 크기에서 확인합니다. 은행 소품은 금융 기능 확정을 뜻하지 않습니다.
