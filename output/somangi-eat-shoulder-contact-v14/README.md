# 소망이 어깨 끝·빵 접촉 보정 v14

어깨 끝에 남던 얇은 접힘과 빵·윗장식의 얼굴 관통을 수정한다. 기존 제작본은 별도 폴더에 보존하며 게임에는 설치하지 않는다.

- 직전 v13의 머리·몸통·다리 곡면과 원래 미소를 유지한다. 몸통 정점 비교 오차 0.
- 팔의 기존 원위부·손을 유지하고, 접히던 어깨 끝을 잘라 둥근 연결 곡면으로 교체한다. 절단 둘레를 매끈하게 맞추고 국소적으로 정리한다. 연결 끝은 닫힌 몸통 안에 둔다. 어깨와 손 위치 트랙은 바뀌며 원본 팔과 정점·토폴로지가 완전히 같은 버전은 아니다.
- 빵을 얼굴 쪽으로 젖히던 방향에서 앞으로 약 20도 기울이는 방향으로 바꾼다. 양손 사이에 다시 맞추고, 얼굴 전면과 겹치는 구간만 추가로 앞으로 옮긴다. 양손도 같은 만큼 따라간다.
- 빵 전체가 100% → 95% → 90% → 85%로 작아지는 동작은 유지한다. 윗부분 장식까지 충돌 검사에 포함한다.
- 원본 미소는 기존 얼굴 텍스처 그대로 표시한다. 먹을 때만 쓰는 가림 면에는 원래 얼굴 UV·재질을 맞추고, 원본을 복사한 별도 텍스처에서 미소 부분만 지운다. 기존 얼굴·눈 텍스처는 수정하지 않는다.

`validation.json`: 181시점(정수·중간 프레임)의 얼굴/빵 삼각형 교차 0, 얼굴 앞 방향 간격, 손바닥 중심 접촉 오차, v13 몸통 동일성 검사.
`export-validation.json`: 최종 GLB를 재수입하여 같은 181시점을 검사한 별도 결과.
앞 방향 간격은 Y축 기준이며 유클리드 최단거리와 다르다. 손 접촉 수치는 손바닥 패치 중심과 빵 타원체 기준으로, 손 전체의 충돌 검사는 아니다.

정면·왼쪽 측면 각 36프레임 GIF와 확대 검수 이미지는 최종 GLB 재수입 렌더다.
