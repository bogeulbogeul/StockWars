# 소망이 방문객 스툴 v1

P1 (Major) · ✅ 모델 제작 / ⏳ 사용자 검수·소망이 착석·게임 적용

안내데스크 앞 방문객 자리용 작은 원형 스툴. 밝은 목재 좌판/짧은 다리 4개·연초록 방석·낮은 다리 연결대를 사용한다. 등받이와 팔걸이는 없다.

- `Somangi-visitor-stool.glb`: 독립 3D 모델, `Somangi_Visitor_Seat_Anchor` 포함
- `Somangi-visitor-stool.blend`: 편집 원본과 스튜디오 미리보기
- `stool.png`: 의자 단독 미리보기
- `desk-preview.png`, `Room-visitor-stool-preview.blend`: 데스크 앞 배치
- `build_stool.py`, `manifest.json`: 재현 스크립트·임시 크기·배치

폭/깊이 .66·높이 .49로 안나 의자보다 낮고 작다. 중심 y=-.40, 룸 바닥 z=.022에 배치하며 데스크 앞까지 약 .48의 간격을 둔다. 임시 모델링 값이며 소망이의 실제 앉기 자세와 체형에 맞춘 접촉 검수는 아직 하지 않았다. 미리보기의 안나는 기존 바닥 앉기 모션을 임시 배율로 의자에 올린 검수본이다. 게임과 기존 모델 원본은 변경하지 않았다.
