# 초기 가독성 형태 복원 v6

사용자 선호에 따라 최초의 왼쪽 파스텔 공고 목록·오른쪽 아이보리 상세 화면을 복원했다. 공고 선택 즉시 오른쪽 내용을 갱신하고 크게 보기 버튼으로 확대한다. 근접 F/화면 버튼 열기, 이야기 확인, Esc/닫기와 모바일을 유지한다. 웹·기존 실행본 resources/web 동기화. 목록 전환·상세·확대·복귀·확인·닫기·모바일 가로 넘침 및 JS 오류 0건 검증 통과. preview.png는 실제 브라우저 렌더다.

## 사용자 디자인 확정 · 2026-10-25

사용자 요청 “게시판 UI는 이 디자인으로 확정해줘.”에 따라 이 v6를 현행 확정 디자인으로 채택한다. 왼쪽 파스텔 공고 목록·오른쪽 아이보리 상세 내용, 공고문 크게 보기 및 근접 상호작용을 유지한다. 이전 v2~v5는 이력으로 보존한다. 이번 확정은 시각 디자인 채택이며 전체 게임 플레이 검수와 구분한다. 확정 기록 작업에서 게임 소스와 에셋은 변경하지 않았다.
