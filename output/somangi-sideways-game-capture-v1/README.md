# 실제 게임 통로의 옆걸음 전환 촬영

사용자 요청: 실제 게임에서 좁은 통로에 들어갈 때 옆걸음으로 바뀌고 넓은 공간에서 일반 걷기로 돌아오는지 확인.

현재 웹 게임의 실제 `VivianModelScene` 잡화점·진열대·계산대·기존 카메라·충돌을 사용했다. 별도 통로를 제작하거나 가구/캐릭터 외형·충돌 판정을 변경하지 않았다. 게임 소스 수정은 없다.

`scratch/capture-sideways-in-game.cjs`가 실제 합법 바닥에서 연속 동선을 찾고, 실제 컨트롤러의 S 이동 입력과 룸 업데이트를1/30초씩 진행해 촬영했다. 모션 상태를 강제 지정하지 않았으며 자동 감지의 결과를 화면 왼쪽 위에 표시한다. 촬영 중 이야기 패널만 숨겼다.

- 동선: X=-180, Z=-175→160. 진열대와 계산대 사이를 통과한다.
- `capture.json`: 실제66프레임의 위치·합법 판정·상태·몸 방향을 보존한다. 전환 순서는 `walk → sideways → walk`, 모든 위치가 기존 충돌 판정을 통과하며 실행 오류는 없다.
- `actual-store-passage.gif`: 실제 게임 화면의 연속 촬영. 전환을 읽기 쉽도록 첫/마지막 프레임만350/500ms 더 유지한다. 이동 구간은30fps다.
- `three-phases.png`: 일반 걷기·옆걸음·넓은 곳에서 일반 걷기 복귀의 실제 세 시점.

이 촬영을 위해 게임 배치나 실행본을 변경하지 않았다. 적용 기능은 `../somangi-sideways-v1/README.md`를 따른다.
