# 포포리빵 원본 실루엣 복원 v5

2026-10-25 사용자 요청: 원본과 비슷한 통통한 몸통·작은 둥근 끝을 살리고, 연결을 덜 잘록하게 하며 반대쪽은 납작한 면 없이 둥글게 변경.

기준은 `web/assets/items/packing-v1/popori-bread-v2.png`다. v4에서 원본의 작은 둥근 끝까지 사라진 점을 수정했다. 몸통에서 작은 끝까지 넓고 완만한 연결 곡면으로 이어지는 한 메시이며, 따로 붙인 구형 물체·가느다란 목·분리된 경계는 없다. 끝은 짧고 둥글게 닫히고, 넓은 반대쪽은 v4의 둥근 곡률을 유지한다. 원본의 특징을 보존하면서 두 끝의 인위적인 경계만 줄이는 범위다.

v3의 구움 색·미세 기공·거칠기·얇은 윤기 맵, 꽃/잎 인쇄의 크림색 종이 포장, 조명과 촬영 기준은 유지했다. 재현에는 이 폴더의 PNG와 `build.py`를 사용한다. `compare.py`는 원본과 실제 렌더를 나란히 배치한다.

GLB 파일 구조·재수입·유한 정점·퇴화면 0개·내장 이미지 디코딩과 전체/양 끝 확대 렌더를 확인했다. 수치와 해시는 `validation.json`을 따른다. 사용자 최종 외형 검수는 별도다. 이 v5를 포포리빵 후속 제작본으로 사용하며 기존 v2~v4는 이력으로 보존한다. 게임 적용·저장·가격·다른 상품은 변경하지 않았다.
