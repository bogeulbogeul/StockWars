# 강아지 주민 스프라이트 시험

기존 NPC 비비안의 윤곽·따뜻한 색감·셀 음영과 사용자 동물 참고의 단순 체형을 구분해 적용했다. 세계관·최종 화풍·캐릭터 제작 방식 변경을 문서에 확정하지 않았다. 본 방식 대신 완성 프레임 생성은 사용자가 요청한 이번 실험 범위다.

GPT/codex row 생성 → sprite-gen extract → compose-atlas → preview_animation → inspect. 256×320 셀, 걷기6/운반6/앉기4. 전체16프레임, 투명 배경 아틀라스와 명시 프레임 좌표 manifest. 자동 추출/아틀라스/inspect 오류·경고 없음.

기준 그림은 오른쪽 3/4. 한 기준 그림에서 각 모션을 독립 생성한 실험이며 전체 방향 앵커 체인은 구현하지 않았다. 왼쪽은 미리보기에서 반전한다. 앞/뒤는 미제작.

시각 검수: 얼굴·귀·옷은 대체로 일관. 상태별 눈·주둥이·몸 크기 차이는 미세하게 남음. 앉기: best-effort, 진입/유지 자세 읽힘; 의자 연결 미검증. 걷기와 운반: experimental / motion fail, 후반부 일부 발 자세가 반복되어 정확한 양발 교대와 루프 자연스러움을 확정할 수 없음. 첫 생성의 몸 방향 전환은 수정에서 감소. 프레임 타이밍 변경이나 임의 그림 교체로 실패를 숨기지 않았음.

운반 상자는 생성 그림에 베이크된 시각 테스트다. 실제 게임의 별도 화물 오브젝트·손 연결·상자 집기/내려놓기를 구현한 결과가 아님. 앉기에는 의자를 그리지 않아 별도 좌석에 맞춰야 함. 바닥 정렬은 자동 추출 시작값으로 실제 게임 이동 속도의 접지와 동일하지 않음.
