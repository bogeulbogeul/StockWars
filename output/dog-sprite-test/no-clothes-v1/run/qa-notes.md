# 옷 없는 강아지 · 별도 상자 더미 운반

사용자 요청에 따라 옷·신발 제거, 금색 털·크림 배·짧은 발로 변경. 기존 캐릭터/NPC 화풍 참고. 기존 게임 구현 확인: LogisticsRenderer는 상자1–4개를 별도로 생성하고 각 단의 흔들림을 계산함. 운반 프레임은 상자 없이 두 앞발을 내밀어 아래에서 받치는 형태로 제작.

GPT row 생성, sprite-gen 추출·아틀라스·GIF 구성 성공. 256×320셀, 걷기6/받치며걷기6/앉기4. 상자와 의자는 캐릭터 PNG에 포함하지 않았음.

외형 변경 확인: 옷/신발 없음, 얼굴/귀/금색 털색 대체로 유지. 운반의 두 앞발이 모여 손바닥을 위로 향함. 걷기/운반 일부 자세가 후반부에 반복되며 양발 교대·루프 자연스러움 판정은 experimental. 앉기는 땅에 앉은 형태에 가까워 기존 의자용 앉기로 채택하지 않음.

별도 PNG 상자0–4개를 운반 프레임 위에 올리는 시험 UI 추가. 상자는 web/assets/minigames/logistics/parcel.png의 실제 게임 에셋이며 손끝 연결점 [캐릭터 중심+62, y198]은 임시 배치값임. 프레임별 정밀 소켓/가림/흔들림·이동속도 연동은 미검증. 실제 미니게임에는 적용하지 않음. 생성된 꼬리와 체형의 상태 간 미세 차이는 후속 검수 대상.

세계관·상품 정책·공통 제작 방식 문서를 변경하지 않은 일회성 스타일 실험. 이전 옷 입은 에셋 보존.
