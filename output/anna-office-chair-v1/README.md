# 안나 안내소 의자 v1

P1 (Major) · ✅ 모델 제작 / ⏳ 아트 검수·안나 착석 정합·게임 적용

안내소 실내 시안의 밝은 꿀색 목재·연초록 쿠션·둥근 아치 등받이를 따른 팔걸이 없는 4다리 의자다. 임시 크기는 폭 .79·깊이 .73·높이 약 1.235이며 룸 틀과 같은 제작 단위를 사용한다. 안나의 현재 짧고 통통한 요정 외형을 참고했으며 실제 착석 모델 크기·발 접지·책상 간격은 후속 검증 대상이다.

- `Anna-office-chair.glb`: 독립 의자 에셋, `Anna_Seat_Anchor` 포함
- `Anna-office-chair.blend`: 편집 원본과 스튜디오 미리보기
- `front-right.png`, `rear.png`: 앞/뒤 미리보기
- `room-preview.png`, `Room-chair-preview.blend`: 룸 뒤쪽 중앙에 배치한 확인용 장면
- `build_chair.py`, `manifest.json`: 재현 스크립트와 제작 상태

룸 틀 원본과 게임 리소스는 변경하지 않는다. 앉는 위치는 임시 좌판 상단 중심이며 안나의 골반 본 좌표로 확정한 값이 아니다. 캐릭터와 가구의 착석 접촉은 아직 검증하지 않았다.
