# 소망이 스토리 표정 16종 v2

웃는 눈의 선 폭을 v1의 두 배로 보강했다. 안도·졸림 등 선으로 표현하는 닫힌 눈도 같은 굵은 스타일에 맞췄다. 기존 타원 눈·U자 입과 머리/몸체·모션은 유지한다. 뿌듯함은 넓고 편안한 눈과 거의 없는 홍조, 쑥스러움은 짧게 오므린 눈과 진한 홍조로 구분한다. 뿌듯함은 스스로 해낸 만족감, 쑥스러움은 칭찬받거나 관심을 받았을 때의 수줍음이다. 이전 v1은 보존한다.

P2 (Polish) · ✅ 표정 텍스처·실제 모델 비교 렌더 제작 / ⏳ 사용자 외형 채택

현재 대화에서 다듬은 `somangi-rear-junction-v43` 모델의 기존 UV에 얼굴 표정만 제작했다. `Docs/ART_STYLE_GUIDE.md`, `Docs/part_separation_guide_512.md`, `output/opening-dialogue-v1/opening.txt`, `activities-and-ending.txt`를 확인해 첫 만남·새 일에 대한 걱정·알바 성취·감사·쿠키·귀가와 취침에 쓸 수 있도록 구성했다. 울먹임·삐침 등은 후속 스토리용이며 대본에 새로운 사건을 확정하는 의미는 아니다.

기본 미소, 기쁨, 차분함, 궁금함, 놀람, 걱정, 시무룩, 울먹임, 삐침, 결심, 쑥스러움, 뿌듯함, 안도, 감동, 졸림, 맛있음이다. 웃는 계열의 입은 기존 U자 미소 텍스처를 그대로 유지한다. 감정에 따라 얇은 눈썹·옅은 볼 홍조·눈물만 제한적으로 더했다. 눈은 검은색을 유지한다.

`expression-sheet.png`는 실제 모델의 같은 자세·카메라·조명으로 촬영한 16종 비교표다. `portraits/`는 각 표정의 512px 정면 렌더, `textures/`는 기존 모델 UV에 맞는 2048px Base Color 텍스처다. 얼굴만 떼어 놓은 알파 스티커가 아니므로 다른 모델에 좌표 조정 없이 적용할 수 있는 범용 이미지로 해석하지 않는다.

`somangi-expressions.blend`에는 원래 메시·본·모션과 16쌍의 표정 재질을 보존한다. 몸체 재질 슬롯 0/1을 manifest에 적힌 같은 표정의 skin/ink 재질로 함께 바꾸면 선택할 수 있다. 먹기용 별도 입·가림막·소품은 비교 촬영에서만 숨겼다. 기본 표정으로 저장하며 원본 메시 좌표·웨이트 동일성을 제작 스크립트에서 검사한다.

표정 선택 UI·대사에 따른 자동 전환·깜박임/표정 애니메이션·게임 설치는 포함하지 않는다. 기존 제작 원본과 폐기된 게임 에셋 상태는 유지한다.

`models/`에는 각 표정이 적용된 정지 자세 GLB 16개를 별도로 제공한다. 머리·몸체 메시와 4개의 본을 그대로 유지하며 먹기 소품·별도 입·표정 애니메이션은 포함하지 않는다. 원래 모션은 Blend 파일에 보존한다. ZIP은 텍스처와 초상화 묶음이며 GLB는 개별 파일이다.

`somangi-expression-models.zip`에는 개별 GLB 16개를 묶었다. 내보내기 과정의 검은 선 하이라이트 차이를 막기 위해 GLB에 얼굴 잉크용 specular 알파 마스크를 내장했다. `verify_models.py`에서 16개 파일의 4본·텍스처 내장을 확인하고 기쁨 GLB를 다시 불러와 검은 눈·입과 실제 렌더를 점검했다. 재현 순서는 build → export_models → fix_glb_ink → verify_models → package다.
