# 새 앉기 모션의 의자 배치 검수

`anna-sit-v1/Anna-sit.blend`의 `Seated`를 최신 데스크/의자 장면에서 확인했다. 원본 모션은 바닥 앉기다. 원본은 수정하지 않고 임시 배율 .65로 몸통 하단을 좌판 상단 z=.587에 맞췄다. 이 배율은 사용자 채택값이 아니다.

⏳ 의자 전용 자세·정식 배율·정밀 표면 충돌·게임 적용

발을 앞으로 들어 올린 바닥 앉기 자세가 유지되어 발이 바닥보다 약 .564 높다. 의자에서 다리를 내려놓는 자세나 별도 발받침을 쓰는 자세로 검증한 것은 아니다. 데스크 쪽 최전방 캐릭터 정점 y=1.877이며 상판 뒤끝 y=1.43보다 뒤에 있어 해당 배치의 데스크 바운딩 영역과 겹치지 않는다. 등받이와 조끼/머리의 정밀 표면 관통 검사는 아직 하지 않았다. 정지 유지 자세만 확인했으며 앉기/일어서기 전체 전환 검수는 별도다.

`front.png`·`side.png`는 검수 미리보기, `Anna-chair-fit-preview.blend`는 임시 조합 장면, `fit-report.json`은 실측 기록이다. 게임이나 기존 가구/캐릭터 원본은 변경하지 않았다.
