# 안내소→은행 직접 이동

모아는 은행 실내에 먼저 준비하고 안내소에서 사라진다. 플레이어는 의자에서 일어난 뒤 WASD로 출입문에 가서 F로 퇴장하고, 야외에서 은행까지 직접 이동해 F로 입장한다. 기존 문 경계의 짧은 페이드만 유지한다. 다른 건물에는 우선 은행으로 가보자는 안내를 표시한다. 대사와 경제/활동 조건은 유지하며 이동 안내 한 줄만 새 흐름으로 수정했다.

검증: `scratch/check-manual-bank-travel.cjs`는 안내소 대화 후 실내 상태를 직접 준비하는 집중 fixture다(처음부터 전체 플레이 아님). 이후 실제 WASD/F로 먼 위치 F 퇴장 차단, 입력 전 실내 유지, 모아 은행 대기, 문 근처 F 퇴장, 야외 은행까지 이동 및 F 입장, 브라우저 오류 0건을 확인했다. bank.png에서 먼저 도착한 모아와 플레이어 입장을 확인했다. 관련 Node 테스트 28개 통과. 웹 4개 JS를 기존 실행본 리소스에 동기화했으며 실제 EXE 및 설치 프로그램은 실행/재빌드하지 않았다.
