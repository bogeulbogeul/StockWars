# 서점 항공샷 지붕 접합 정리 v3

P1 · ✅ 모델 보정·웹/기존 실행본 반영·자동 확인 / ⏳ 사용자 최종 시각/플레이 검수

사용자가 마을 항공샷에서 발견한 서점 지붕 교차부를 정리했다. 기존 폭/깊이·박공 높이·보라색·문/창·간판·계단·배치는 유지한다.

- 주/보조 지붕의 원래 경사와 교차선으로 닫힌 바탕판·기와를 다시 제작했다. 잘린 폴리곤의 중복 점을 제거하고 기와 간격과 교차선 여유 폭을 줄였다.
- 넓고 검게 보이던 열린 골 대신, 양쪽 지붕 경사를 정확히 따르는 얕고 닫힌 보라색 골 마감을 넣었다. 위쪽 303개 표본 광선에서 지붕 아래 다른 부재가 노출된 곳은 0개다(`seam-samples.json`).
- 보조 지붕은 앞/뒤 경사 영역을 먼저 나눈 후 교차선으로 절단한다. 반대로 처리했을 때 생기던 바탕판의 삼각형 누락을 제거했고, 게임에서 벽이 드러나던 4개 항공샷 표본이 모두 지붕 면을 가리키는지 확인했다.
- 용마루는 기존 높이 범위 안에서 둥근 솔리드 단면으로 정리했다. 변경 대상 외 메시 정점 해시는 유지했다.
- `Bookstore-clean.glb`, `Bookstore-clean-aerial-roof.blend`와 실제 전체/위쪽/접합부/후면 렌더를 저장했다. `verify.py`의 GLB 재로딩·새 지붕/기와/용마루/골 닫힘·유한 좌표 검사 통과.

## 게임 반영과 검증

마을에서 발견된 지붕 문제 수정으로 웹과 기존 실행본의 `assets/buildings/3d/Bookstore-clean.glb`를 같은 수정본으로 교체했다. 배치·배율·입구·충돌 정의·실내·저장은 바꾸지 않았다. 세 모델의 해시 일치는 `hashes.json`에 기록했다.

`scratch/check-bookstore-clean-roof.cjs`로 양쪽에서 새 지붕 노드·실측 폭 455.6233·문/창/책 간판/계단·작은 화면·JavaScript 오류 없음을 확인했다. `web-aerial.png`, `desktop-aerial.png`는 마을에 실제 로딩한 모델의 위쪽 렌더다.

충돌 표본은 웹에서 차단됨을 확인했다. 기존 실행본의 해당 표본은 차단되지 않았으며, 서버 응답만 수정 전 v2 모델로 바꾼 비교에서도 같은 결과였다(`desktop-baseline-check.log`). 따라서 실행본의 기존 충돌 표본 결과는 이번 지붕 교체로 달라지지 않았으며, 기존 실행본의 충돌 문제 해결/최종 플레이 검수 완료를 뜻하지 않는다. 설치 프로그램은 재빌드하지 않았다.
