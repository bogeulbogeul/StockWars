# 봉인된 소식 봉투 색감의 찌라시 UI

**이전 시안:** 과거 봉투 이미지를 참고한 결과다. 현재 채택·적용본은 [상점의 크림·올리브·갈색 봉투 기준 수정](../rumor-olive-ui-2026-10-25/README.md)을 따른다.

**2026-10-25 · P2 (Polish/Post) · ✅ 완료: 웹·기존 로컬 실행본 리소스 반영·브라우저 검증 / ⏳ 대기: 사용자 최종 시각·플레이 검수.**

게임의 `web/assets/items/vivian-front-v1/item_premium_rumor.png`를 실제로 확인하고 크림 편지지·자주색 봉투·주황 봉인·남색 윤곽을 UI 색으로 사용했다. 원본 이미지를 머리말에 재사용하며 새 이미지 생성은 하지 않았다. 본문은 테이프를 붙인 편지지, 퀴즈는 연한 분홍 메모, 주요 버튼은 주황 봉인색으로 구성했다. 호재·악재를 색으로 노출하지 않으며 희귀도 문구는 유지하고 배지 색을 통일했다.

현재 단계 본문·퀴즈·기존 보상·열람 감가·저장 로직을 유지했다. `RumorPopup.js`의 제목·장식·닫기 문구와 `RumorQuizCard.js`의 제목만 변경하고 디자인은 독립 CSS `rumor-letter.css`에 분리했다. CSS 라우터는 47줄을 유지한다.
