# 기존 나무로 숲 경계 재정리 — 2026-10-21

P1 (Major) · ✅ 웹·실행본 반영·실제 렌더 검증 / ⏳ 사용자 최종 시각 검수.

v10의 거대한 수풀 배경은 미관에 맞지 않아 사용을 철회했다. `TownLandscape.js`의 배경 메시 생성과 연결을 제거하고 기존 `CommonTree-clean.glb`만 크기·간격·깊이를 달리해 여러 겹 배치했다. 기존 충돌 경계와 남쪽 차도는 유지한다.

실행본에서 건물 9개·장식 340개 정상 로딩, 건물 입구 접근 가능, 차도 침범 없음·브라우저 오류 없음 확인. 경계 충돌 테스트 2개 통과. 전체 화면과 플레이어 시점 화면은 이 폴더에 보관한다. v10 수풀 이미지는 이전 미채택 기록이다.
