# 마을 벤치·실내 의자 착석 확대

P1 · ✅ 웹·기존 실행본 적용·자동 검증·대표 렌더 확인 / ⏳ 사용자 최종 플레이 검수

## 추가 좌석

기존 정류장 왼쪽 좌석 외에 다음 13자리를 추가했다.

| 장소 | 빈자리 |
|---|---:|
| 마을: 광장 서쪽/동쪽·집 주변·서점 옆·정류장 쉼터 벤치 | 5 |
| 안내소: 스툴·사무 의자 | 2 |
| 은행 대기 소파 | 2 |
| 증권사 로비 대기 의자 | 2 |
| 트레이닝룸·모의투자룸 업무 의자 | 2 |

차곡이가 앉아 있는 은행 창구 의자는 점유 상태로 제외한다. 현재 집·잡화점 모델에는 빈 의자가 없어 가구를 새로 추가하지 않았다.

좌석에 가까이 가서 **E키 또는 화면 버튼으로 앉고**, **E키/버튼 또는 WASD로 일어난다**. 기존 캐릭터 모델의 다리 자세를 일시 조정하고 좌판 윗면을 실측해 접촉 높이를 맞춘다. 좌석의 방향에 맞춰 앉으며 일어서면 원래 다리 자세로 복구한다. 정면 공간이 좁은 업무 의자는 옆쪽의 유효한 출구를 사용한다. 현재 좌석 모델의 충돌을 걷기 중에 무시하지 않는다.

## 함께 처리한 문제

- 전시 대화의 캡처 단계 키 처리에서 E/WASD를 먼저 소비하고 있어, 활성 좌석 컨트롤러로 먼저 전달하도록 연결했다. 좌석이 있는 장소에서 걸어 접근할 수 있으며 자동 안내 이동·장면 전환 중에는 좌석 입력을 막는다. F/Enter 대화 진행·P 휴대폰 흐름은 유지한다.
- E가 시점 회전에도 쓰이는 곳은 좌석 근처일 때만 착석/일어서기를 우선한다.
- 서점 옆 벤치가 건물과 겹쳐 착석 캐릭터가 가려졌다. 해당 벤치만 `(2880,1760)`→`(2960,1760)`으로 동쪽 80 이동해 외벽에서 분리했다. 다른 건물·정류장·나무는 옮기지 않았다.
- 착석 중 대화가 캐릭터를 NPC 쪽으로 회전시켜 등받이에 파묻히지 않게 했다. 이야기상 먹기 연출은 안전하게 일어선 다음 실행한다. 수동 점프/먹기는 앉은 상태에서 실행하지 않는다.
- 다른 벤치를 사용한 뒤 정류장 좌석으로 돌아가도 활성 좌석 상태가 올바르게 교체된다. 장면을 바꾸면 이전 좌석의 자세와 버튼을 정리한다.

`SeatSurfaces.js`는 좌석/방향/점유 판정에 쓸 모델 정보를 만들고, `SeatPose.js`는 자세/접촉 높이, `SeatInteraction.js`는 상태/출구/접근, `SeatControls.js`는 버튼·입력 연결을 담당한다. 구형 거래·터미널 화면, 회복/경제 보상, 착석 저장 기능은 추가하지 않았다. NPC의 자리·모델·확정 착석 자세·저장 스키마는 유지한다.

## 검증

- 웹·기존 실행본에서 추가한 13자리 모두 착석 및 유효 위치로 일어서기를 확인했다. 점유된 은행 창구 의자 1개는 제외됐다.
- 모든 좌판의 몸체 하단은 윗면보다 약 0.3 위에 위치한다. 실제 스킨 정점 표본과 주변 가구의 삼각형 레이 검사에서 침입 표본은 0개였다. 모든 연속 메시 교차의 수학적 보증과는 구분한다.
- 마을 5곳의 착석 위치는 건물 외벽 충돌 영역과 겹치지 않는다. 이동한 서점 벤치·광장 벤치, 안내소 의자, 은행 소파, 증권사 대기 의자, 업무 의자의 실제 렌더를 열어 확인했다.
- 마을·안내소·증권사·트레이닝룸에서 실제 E키 착석/일어서기, 마우스 버튼 착석, 이동키 일어서기 및 실제 걷기를 확인했다. 정류장으로 돌아와 E키를 다시 사용하는 회귀 검사도 통과했다.
- `seatedStory.test.mjs`와 기존 충돌·점프·정류장·대화 배치 회귀 테스트를 포함해 선택한 단위 테스트 24개가 통과했다. JavaScript 오류는 0건이다.

```
node web/tests/arrivalBench.browser.cjs web output/all-seats-v1
node web/tests/arrivalBench.browser.cjs electron-app/dist/win-unpacked/resources/web output/all-seats-v1
```

`web-seats.json`·`desktop-seats.json`에 좌석별 접촉/교차/점유/입력 결과를 기록했다. `*-seat-0.png`부터 `*-seat-13.png`까지 실제 좌석 렌더가 있으며 점유된 7번은 렌더에서 제외한다. 제작 GLB는 변경하지 않고 기존 실행본 resources/web의 소스/CSS에도 반영했다. 설치 프로그램은 재빌드하지 않았다. 사용자 최종 시각·플레이 검수는 별도다.
