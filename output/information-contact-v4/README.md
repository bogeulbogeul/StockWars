# 안내소 접합부 마감 v4

P2 · ✅ 에셋 접합부 수정 / ⏳ 사용자 시각 검수·게임 적용

- 원본은 `information-roof-crafted-v3/Information-crafted-roof.blend`다. 초록 기와·용마루의 개선 형태를 유지한다.
- 현관 박공 앞뒤 목재 프레임·양옆 처마·가로보를 연속된 삼각 개구부의 단일 솔리드로 다시 만들었다. 크림 벽판은 전체 테두리 뒤를 덮도록 맞춰 모서리 틈을 막았다.
- 기초와 두 단 계단을 하나의 솔리드로 합쳐 겹치는 상면을 제거했다. 문 양옆 벽 하단의 베벨 뒤 빈 부분을 기존 벽과 합쳤다.
- 문과 크림 문틀의 하단 정점만 내려 계단 안에 연결했다. 문 패널·손잡이·창문·새싹 표식은 유지한다.
- 전체 사선·박공 확대·출입구 사선/정면을 실제 모델로 렌더했다. 합친 목재와 기초의 경계/비다양체 모서리 수는 `validation.json`에 기록한다.
- 수정본: `Information-clean.glb`, `Information-sealed-contact.blend`. 웹·실행본은 교체하지 않았다.
