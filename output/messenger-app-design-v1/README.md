# 메신저 앱 2D 시안 v1

아이보리 화면·검정 프레임·파스텔 프로필의 목록/채팅 화면 시안. 상단 ‹ 홈 화면 유지, 하단 홈 버튼·프레임 X 없음. 모아/토리/차곡이/봉봉의 상징을 평면 SVG로 표현했다. 대화 및 시간은 디자인용 예시이며 실제 게임 사건·보상·메시지 저장과 연결하지 않았다. 게임 적용 전 디자인 검토 단계다.

목록: 큰 이름, 마지막 대화, 시간, 안 읽음 표시, 이름 검색, 안 읽은 대화 필터.
채팅: 상대 프로필·이름·장소, 날짜, 아이보리 수신 말풍선·연두색 답장, 선택형 답장.

index.html을 로컬 서버에서 열어 확인한다. scratch/capture-messenger-design.cjs로 대화4개, 필터2개, 검색, 상대 전환, 답장 표시 및 페이지 오류 없음 확인 후 preview.png를 촬영했다. 게임 파일과 기존 실행본은 변경하지 않았다.
