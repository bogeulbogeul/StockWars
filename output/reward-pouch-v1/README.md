# 보수 주머니 3D v1

2026-10-26 · P1 (Major) · ✅ 모델 제작·GLB 재불러오기·메시 검사 / ⏳ 사용자 외형 검수·게임 적용·전달 시 손 접촉.

채택한 `reference.png`의 갈색 복주머니·베이지색 매듭끈·연두색 새싹을 실제 3D 메시로 제작했다. 표면은 매끈한 무광이며 별도 천 노이즈나 거친 질감은 없다. 앞면 새싹은 `output/information-sprout-mark-v1/Information-sprout-wall-mark.glb`의 잎 2개와 줄기 원본 메시를 가져와 주머니 곡면에 맞췄다. 간판 테두리·바탕은 제외했다. 뒷면에는 문양이 없다.

- `RewardPouch.glb`: 재질 포함 독립 모델. 외부 텍스처 불필요.
- `RewardPouch.blend`: 편집 원본과 렌더 스튜디오. 스튜디오 바닥·조명·카메라는 GLB에 포함하지 않는다.
- `preview.png`, `front.png`, `back.png`: 실제 모델 사선·정면·후면 렌더.
- `build.py`, `manifest.json`: Blender 5.2 재현 스크립트와 치수·검사 기록.

밑면 중앙이 원점이며 Blender Z-up/정면 -Y, glTF Y-up/정면 +Z다. H=1 기준 약 폭 0.320H·깊이 0.230H·높이 0.368H의 임시 제작값이다. 목 중앙에 `Handover_Anchor`를 넣었다. 실제 게임 배율·손 접촉·보수 지급/중복 방지·저장 연동은 후속 대상이다. 주머니 열기나 천 시뮬레이션은 포함하지 않는다.

메시별 유한 좌표·비매니폴드 모서리 0개를 확인하고 GLB를 다시 불러와 메시 수와 치수를 기록했다. 구성 메시 사이의 의도된 겹침은 유지한다. 게임 코드·기존 배포 모델·보수 금액·저장은 변경하지 않았다.
