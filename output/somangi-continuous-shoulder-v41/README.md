# 소망이 측면 접합부 정리 v41

P1 (Major) · ✅ 제작·수치 검사·실제 GLB 양측 촬영 · ⏳ 사용자 최종 외형 확인

## 변경

직전 v39 외형과 먹기 동작을 기준으로 한다. 머리와 양팔의 원래 보이는 표면은 보존했다. 어깨 아래 몸통의 중복 표면·가는 절단 흔적을 제거하기 위해 몸통 스킨을 한 표면으로 다시 구성하고, 원래 단면의 폭·깊이·중심을 따라 매끈한 곡면으로 맞췄다. 하체 바깥 표면은 원래 표면에 재투영했다. 눈·미소·음식·모션 트랙은 유지했다.

팔은 뿌리부터 끝까지 각각 단일 팔 본에 100% 연결한다. 팔꿈치 본이나 팔을 휘게 하는 혼합 가중치는 없다. 숨겨진 접합 면은 팔과 함께 움직이며, 몸통과의 겹침으로 연결을 가린다. 전체는 하나의 메시 오브젝트다.

## 검증

- 원래 머리 9,044개 정점과 보이는 원래 팔 정점(왼쪽 3,974개·오른쪽 4,182개)의 위치 차이는 0이다. `appearance.json` 참고.
- 몸통은 접합 표면을 재구성했으므로 전체 정점 좌표가 원본과 동일하다는 의미는 아니다. 원래 몸통 표면과 비교한 가시 표면 표본의 95백분위 거리는 약 0.00360, 99백분위는 약 0.00727, 최대는 약 0.01196이다. 원래 흠집과 중복 면을 정리한 부위도 포함한다. 비교 모델의 전체 높이는 약 1.90이다.
- 271개 반 프레임에서 팔 전체의 단일 강체 변환 대비 최대 좌표 오차는 약 0.000000171이다. 종료 기본 자세의 오차는 약 0.000001252이다. `rigidity.json` 참고.
- 같은 271개 시점에서 어깨 접합부를 제외한 팔과 머리, 빵과 머리, 빵과 고정 몸통 사이의 표면 교차는 0회다. 숨겨진 어깨 안쪽의 의도적인 겹침은 제외한다. `contacts.json` 참고.

## 결과와 재현

`somangi-eat.glb`를 다시 불러 양쪽 정측면에서 촬영했다. `eat-both-sides.gif`는 4.5초 전체 동작이며, 각 방향은 `eat-left.gif`·`eat-right.gif`로도 볼 수 있다. `both-sides-peak.png`는 한입 먹는 최대 자세다.

`build.py`가 최종 모델을 만들고 `render.py -- --side` 및 `render_reverse.py -- --side`가 각각 36장씩 촬영한다. `package_preview.py`가 GIF를 만든다. `verify_appearance.py`, `verify_rigid.py`, `verify_contacts.py`가 검증 스크립트다. `render_region.py`는 진단용 색상 표시로 최종 촬영에 사용하지 않는다.

입력은 보존한 v40 `pre-body-remesh.blend`·`vertex-map.json`과 v39 제작 모델이다. 이전 v40 실험은 완료 모델이 아니다. 게임에 설치하거나 삭제된 캐릭터 에셋을 복원하지 않았다.
