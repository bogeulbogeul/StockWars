# 증권사 대화 중 안내데스크 표시 복구

대화 가림 제거가 토리의 다리를 가리는 안내데스크 메시 하나를 감지하면 cipher-cozy-desk 전체를 숨기면서 책상이 사라지고 별도 모니터만 남았다. 데스크 root의 dialogueOcclusionMinHeight=80을 이용해 얼굴·상체 높이 표본을 가릴 때만 해당 가구를 숨긴다. 일반 소품/다른 실내의 기존 가림 판정과 가구 묶음 숨김은 유지한다. 충돌/모델/가구 위치는 변경하지 않았다.

Node 회귀 테스트9개 통과: 다리만 가리는 안내데스크는 유지·높아져 얼굴을 가리면 숨김·가림 종료 복구·일반 가구 숨김·토리 창구 범위 및 팔 안내 유지. scratch/check-securities-desk-visible.cjs는 증권사 실제 실내/토리 환영 대화를 직접 준비하는 집중 fixture다. 웹/기존 실행본 리소스에서 안내데스크5개 메시 모두 표시·브라우저 오류0, 스크린샷을 확인했다. 실제 처음부터 증권사 방문한 전체 플레이 검증은 아니다.

CipherLobbyDesk.js·IndoorOcclusion.js 웹/기존 실행본 리소스에 반영. 실제 EXE 및 설치 프로그램 재빌드하지 않음.
