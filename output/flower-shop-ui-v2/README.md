# 봉봉 잡화점 단일 진열대 — 2026-10-24

**P1 (Major) · ✅ 웹·로컬 실행본 리소스 반영·브라우저 검증 / ⏳ 사용자 최종 검수**

최신 판매 목록 11종을 분류 없이 한 진열대에 표시한다. 먹거리 8종 각 200잎, 반짝가루 500잎, 로또 500잎, 봉인된 소식 봉투 1,000잎. 별가루는 가격 보류로 판매 제외다. 기존 보유품·저장은 유지하고 폐기된 물류 패스를 판매하지 않는다. 먹거리 회복·최대 체력 시 비소비, 기존 보유품 사용, 로또 변경 가격·추첨과 구매·영수증을 포함한 관련 테스트 23개 통과.

`node scratch/check-flower-shop.cjs` 및 실행본 리소스 인자로 동일 검증을 수행했다. 단일 진열대 11종·키보드 선택·탭 없음·모바일 이동·수량·구매·영수증·대화, 브라우저 오류 없음 확인. 관련 리소스 13개의 웹/실행본 바이트 일치 확인. 설치 프로그램 재빌드는 포함하지 않는다.

`desktop.png`, `mobile-shelf.png`, `mobile-checkout.png`는 현행 3D 실내를 배경으로 실제 구매 DOM을 촬영했다. 판매 상품은 기존 포장 아트를 임시 재사용하며 신규 3D 상품 제작 완료를 뜻하지 않는다. 반짝가루의 해석 단계 20 확장과 새 감가 정책은 별도 구현 대상이다.
