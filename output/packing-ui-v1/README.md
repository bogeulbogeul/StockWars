## 이전 제작·검증 이력

**P0 (Core) · ✅ UI·플레이 구현·자동 검증 / ⏳ 사용자 실제 플레이 검수.**

화면·입력 후속: 화면 높이에 맞춘 헤더/작업대/하단 버튼 구획과 가변 상자·상품 크기로 스크롤 없이 표시한다. 1440×900, 1280×720, 1024×600, 800×600, 390×844, 360×740에서 10개 패턴 전체의 표시 영역을 검사했다(`scratch/check-packing-fit.cjs`). 드래그 시작은 원본 PNG 알파와 SVG 표시 좌표로 판정해 아이템 그림의 불투명 부분에서만 허용하며 카드 여백·이름·투명 영역은 제외한다. 원본 이미지 파일은 변경하지 않는다.

최신 조작 단순화: 회전 버튼·R키·드래그 중 회전을 제거하고 패턴 해답에 맞는 방향으로 상품을 미리 제공한다. 물건은 이동/반환/모두 꺼내기 중에도 방향을 유지한다. 아래 회전 구현·검증 내용은 이전 기록이다. 10개 패턴의 고정 방향 해답과 초기화 후 재풀이를 단위 검사한다.

조작 버튼 후속: 개별 ‘물건 꺼내기’와 ‘다시 놓기’를 **‘모두 꺼내기’** 하나로 합쳤다. 상자의 모든 물건을 준비 공간으로 돌리고 회전·선택을 초기화한다. 빈 상자에서는 비활성화한다. 개별 물건은 계속 준비 공간으로 드래그해 꺼낼 수 있다.
