# 앉기 입력·버튼 복구

사용자 보고: 앉기가 작동하지 않음.

**P1 (Major) · ✅ 웹·기존 실행본 수정·실제 좌석 조작 검사 / ⏳ 사용자 최종 플레이 검수.**

## 재현한 원인

1. 정류장 좌석이 전시 도착 구간에서만 활성화돼 도착 이후에는 좌석 앞의 합법 위치에서도 사용할 수 없었다.
2. 정류장 키 리스너가 공통 좌석 입력 라우터에 등록되지 않아 전시의 상위 키 캡처가 E를 막았다.
3. 정류장 앉기 버튼이 이야기 패널 뒤의 하단에 있어 실제 클릭이 패널에 가로막혔다. 강제 클릭 없이 재현했다.

## 수정

- 일반 플레이에서도 정류장 좌석을 활성화하고 `SeatControls`의 공통 라우터에 등록했다. 자동 이동/장면 전환·휴대폰/모달·입력창에서는 기존 차단을 유지한다.
- 기존 공통 좌석 버튼 위치인 오른쪽 위를 사용해 이야기 패널과 겹치지 않게 했다. 정류장 좌석 바로 앞에서는 다른 벤치 버튼이 겹쳐 뜨지 않게 했다.
- E/버튼으로 앉기, E/이동키로 안전한 위치에 일어서기를 유지한다. 긴 E 입력은 중복 토글하지 않는다.
- 모델·외형·기존 앉기 자세·본·웨이트·좌석 배치·충돌·저장·대화 진행은 변경하지 않았다.

## 검증

`scratch/check-seat-input-recovery.cjs`를 웹과 기존 실행본 각각 실행했다.

- 정류장에서 도착 이후 실제 E 앉기/일어서기, 실제 버튼 클릭, W로 일어서기 통과.
- 별도로 마을 벤치5곳, 안내소2곳, 은행 대기 소파2자리, 증권사 대기 의자2곳, 트레이닝룸/모의투자룸 각1곳, 총13개의 빈 좌석에서 실제 E 앉기/일어서기 통과.
- 모든 일어서기 결과가 기존 충돌 판정상 합법 위치이며 양쪽 다리의 위치·회전이 앉기 전 값으로 복원됐다. NPC가 사용하는 좌석은 제외한다.
- `seatInputRecovery.test.mjs`, `seatedStory.test.mjs`, `busStopGround.test.mjs`, `somangiClearance.test.mjs`의11개 검사 통과. 도착 후 사용, 입력 라우팅, 반복 입력 방지, UI/자동 이동 차단, 착석 중 대화 방향과 먹기/점프 정책 등을 검사한다.

관련3개 모듈을 기존 실행본에 반영했다. 설치 프로그램 재빌드는 하지 않았다.
