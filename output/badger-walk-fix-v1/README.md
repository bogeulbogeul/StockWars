# 오소리 걷기 수정

승인본 정면 걷기 A/B가 같은 발을 드는 오류와 사선·뒷걷기의 머리 위치 이동을 수정한다. 정면·사선·뒤의 접지 A/B 6그림만 변경하며 중립, 정지, 운반, 앉기, 초상화는 원본 PNG 그대로다. 각 방향의 얼굴/머리는 승인 중립 RGBA를 그대로 사용해 좌우 흔들림을 없앤다. 3그림·0→1→2→1·160ms·시트 좌표는 유지한다.

built-in image_gen으로 완성 자세를 편집하고 sprite-gen 크로마/연결요소 추출을 사용한다. 초기 정면 행은 같은 발 문제가 남아 미채택이다. 단독 B 편집도 비율이 맞지 않아 미채택이다. 최종 정면은 반대 접지를 포함한 준비용 참고 행을 입력으로 다시 편집했다. 참고를 준비할 때 승인 A를 반전해 B의 자세를 명확히 전달했으며 최종은 그 참고를 재편집한 네이티브 자세를 추출한다. 몸·팔·다리를 리깅하거나 보간·리타이밍하지 않았다. generation.json, front-B-generation.json, front-final-generation.json에 실제 생성 이력이 있다.

생성 RGB를 그대로 사용해 털색이 바뀌지 않도록, body overlay의 모든 RGB를 승인 몸 픽셀의 전체 연속 RGB 샘플에 대응하는 명시적 맵으로 만들어 sprite-gen recolor로 베이크했다. 작은 고정 팔레트로 양자화하지 않는다. recolor 보고서는 color-bake/recolor.report.json이다. 알파는 베이크 전후 동일하며 머리에는 이 맵을 적용하지 않는다. 승인 중립 머리 합성·공통 기준점 등록은 프로젝트 수작업 어댑터로 명시하며 자동 엔진 보정이라고 주장하지 않는다.

정면 반대 발 실루엣, 방향별 머리 고정, 비대상 프레임 바이트 동일, 승인 RGB 사용과 잘림/좌표/순서/시간을 검증한다. 실제 브라우저 재생과 게임 내 발 미끄러짐/접촉 검수는 별도 미검증이며 physical stride는 미검증이다. preview.html은 수정 전후를 동일 박자로 비교한다. 게임에는 오소리 PNG만 교체하며 다른7종의 런타임 PNG는 바이트 동일을 검사한다.
