# 소망이 팔 전체 회전 수정 v35

사용자 요청: 관절이 꺾이지 않도록 수정. v34에서는 어깨에 위팔 일부가 고정되어 움직이는 팔과 꺾인 형태를 만들었다. 이 고정 구간을 제거하고 원본 팔의 위쪽 뿌리까지 하나의 움직이는 영역으로 다시 지정했다. 팔 중간 절단·팔꿈치·아래팔 본은 없다. 팔은 각각 한 본의 가중치 1로 통째로 움직이며 길이나 굽힘은 바꾸지 않는다.

어깨 안쪽의 구체 보충 메시도 제거했다. 숨은 팔 안쪽 면을 다시 닫았고, 원본 팔 바깥 윤곽과 머리·몸통·다리의 연결부 밖 좌표는 유지한다. 연결부의 위상과 안쪽 면은 v34와 동일하지 않다. 기본 외형의 재디자인과 구분한다.

팔을 드는 각도를 낮춰 몸 앞에서 빵을 들게 하고, 작은 입 움직임과 최대 약 5도 고개 움직임으로 먹는 느낌을 준다. 빵은 같은 선형 비율로 세 번 줄어들며 끝에는 기본 자세로 돌아간다. 빵 위치는 몸통을 피하도록 소폭 앞에 둔다.

원본 팔/고정 영역의 위치 보존 검사는 `../somangi-whole-root-base-v35/preservation.json`에 있다. 최종 애니메이션의 강체 팔·머리, 고정 몸통, 팔 끝쪽/얼굴·빵/얼굴·빵/몸통의 181개 반 프레임 검사는 `verification.json`을 따른다. 의도적인 어깨 안쪽 겹침은 팔 끝쪽 검사에 포함하지 않는다.

정면·양쪽 옆 미리보기는 최종 GLB를 다시 불러온 렌더다. 게임에는 적용하지 않았다.
