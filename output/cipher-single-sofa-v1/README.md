# 사이퍼 증권 소망이용 1인 소파 v1

파란 좌판/등받이 쿠션·통통한 아이보리 팔걸이/몸체·짧은 목재 다리의 독립 Blender 소파입니다.

- `Cipher-single-sofa.blend/.glb`: 수정 가능한 원본/게임용 모델.
- `sofa-preview.png`: 독립 모델 렌더.
- `game-sofas.png`: 로비 양쪽 기존 2인 대기석을 교체한 화면.
- 제작 스크립트와 `exterior_geometry.py`: 재제작용.

게임에서 100배로 설치하며 외곽 폭 약 122, 깊이 98, 높이 약 99입니다.
좌판 폭 82·깊이 77·상면 높이 49로 소망이 키 100에 맞춘 제작 크기입니다.
`Seat_Contact_Point`는 좌판 중앙 근처의 착석 골반 정렬 기준점입니다.
현재는 소파 제작/배치/충돌과 기준점까지이며 소망이 앉기 모션·F키 착석은 미구현입니다.
기존 현관·문·엘리베이터 동선과 화분 위치는 유지했습니다.
게임과 실행본 배치 및 로비 이동/출입 회귀 검증을 통과했습니다.
