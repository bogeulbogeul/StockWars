# 유럽토끼 캐릭터 디자인 시트

2026-10-17 사용자 요청으로 제작한 정적 외형 검토용 시트다. 기존 유럽토끼 정면의 옅은 갈색 털·아이보리 무늬·갈색 눈·분홍 귀 안쪽을 참고했다. 최신 토끼 뒤 머리의 둥근 형태를 확인하고 적용했다. 내장 image_gen으로 생성했으며 전체 프롬프트·원본·시각 참고 경로는 `generation.json`에 보관한다.

`design-sheet.png`에 정면·사선·정측면·뒷모습, 얼굴과 귀만 포함한 초상화, 골반 뒤 중앙의 짧은 꼬리 연결과 매끈한 뒤꿈치 확대도를 담았다. 뒷발에 발가락 선이나 발바닥 패드가 없는지, 얼굴이 고양이 형태로 바뀌지 않았는지와 방향별 외형을 시각 확인했다. 색 견본은 생성된 시트의 시각 참고이며 기존 게임의 정확한 RGB 팔레트를 새로 채택하거나 검증한 자료는 아니다.

이는 디자인 시트이며 애니메이션 atlas·걷기 프레임 제작이나 게임 반영 결과가 아니다. 기존 토끼·다른 동물 PNG와 공통 모션 기준은 변경하지 않았다. 추후 동작 시트 제작에는 강아지 v9의 자세·프레임·순서·속도를 공통 기준으로 사용한다.
