# 소망이 방문객 스툴 착석 미리보기

기존 `somangi-bench-sit-v2`의 `Bench_Seated` 유지 자세를 작은 스툴 위에 배치했다. 안나를 바라보도록 +Y 방향이며, 안나 검수 장면과 동일한 임시 배율 .65를 사용했다. 원본 메시/모션·게임은 변경하지 않는다.

엉덩이 접촉 정점은 원본 `seat.json`의 몸통 기준 정점을 사용한다. 좌판 높이 .512에 표면 간격 .001을 두었고 캐릭터와 데스크 앞면의 Y축 간격을 확인한다. 발은 기존 앉기 자세대로 앞쪽에 모여 있으며 바닥 접지 자세로 보정하지 않았다. 실제 올라앉기/일어서기 전환·모든 표면의 충돌·정식 배율·게임 적용은 미검증이다.

- `desk-preview.png`, `side.png`: 조합 장면 미리보기
- `Somangi-stool-fit-preview.blend`: 소망이·안나·가구 조합
- `fit-report.json`: 좌판 접촉·데스크 간격 실측
- `place_somangi.py`: 재현 스크립트
