# 가이드북 책 형태 UI v2

사용자 요청으로 기존 가이드북에 펼친 책 형태의 2D HTML/CSS UI를 적용했다. 아이보리 본문·연한 초록 목차·새싹 표식·책장 가장자리·큰 제목·번호가 있는 본문 구획을 사용한다. 본문 내용과 지도 근처에서 F/버튼으로 여는 조건은 유지했다.

데스크톱은 왼쪽 5개 목차/오른쪽 읽기 페이지, 작은 화면은 가로 스크롤 목차/세로 본문이다. 본문만 스크롤하며 하단 이전·다음 버튼과 페이지 번호는 고정한다. 좌우 방향키도 장 이동에 쓴다. 처음/마지막 장에서는 해당 방향 버튼이 비활성화된다. Esc/닫기와 게임 입력 차단을 유지하고 동작 줄이기 설정에서는 등장 애니메이션을 생략한다.

웹과 기존 실행본 resources/web의 InformationGuidebook.js 및 information-guidebook.css에 반영했다. 다른 모듈/모델/저장은 변경하지 않았다. CSS 캐시 버전은 book-v2다. `scratch/check-information-guidebook-ui.cjs`를 양쪽에 실행해 기존 근접 열기·읽기 중 이동/대사 차단·닫기/재열기·모바일 폭·장면 종료 시 닫기와 새 다음 버튼/방향키 페이지 이동을 확인했다. JavaScript 오류는 0건이다. 실제 데스크톱/모바일 PNG를 열어 시각 확인했다. 사용자 최종 디자인·플레이 검수와 설치 프로그램 재빌드는 별도다.
