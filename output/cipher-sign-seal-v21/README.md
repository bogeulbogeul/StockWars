# 증권사 간판 틈·마크 테두리 보정 v21

사용자 첨부의 중앙 간판 주변 검은 틈과 사각 테두리를 넘는 상승 차트 마크를 수정했다. v20의 지붕·전체 비율을 유지한 후속 에셋이며 게임 파일은 교체하지 않았다.

- 간판 뒤 상부 벽과 보 아래 천장을 닫힌 크림색 솔리드로 채워 뒤쪽 빈 공간이 검게 보이지 않도록 연결했다.
- 좌우 한 쌍씩 맞닿은 기둥 상단의 사각 받침도 연속 부재로 정리해 베벨 사이의 검은 세로 틈을 없앴다. 원기둥 네 개는 유지한다.
- 화살표·상승선·여섯 막대를 하나의 조합으로 축소하고 남색 판 중앙에 정렬했다. 전체 마크의 실제 월드 바운드로 사방 여백을 검사한다. 정확한 여백과 축소율은 `manifest.json`에 기록한다.
- `sign-front.png`, `sign-detail.png`는 정면·사선의 실제 3D 확대 렌더다. `front-right.png`는 건물 전체다.
- 전달 모델 `CipherSecurities-clock.glb`, 편집 원본 `CipherSecurities-sealed-sign.blend`, 재현 스크립트 `build.py`, 구조 검사 `validation.json`을 제공한다.
