# 서랍장 위 장식 v1

P1 (Major) · ✅ 3D 소품 제작 / ⏳ 사용자 검수·게임 적용

사용자 참고처럼 왼쪽에는 끈으로 묶은 서류 묶음과 작은 크림색 화분, 오른쪽에는 나무 서류 트레이와 3개 파일철을 배치했다. 기존 통로 확보 v3의 가구 위치와 최신 짧은 조끼 v5 안나를 유지한다.

- `Bound-documents.glb`: 표지·종이·묶음 띠·앞면 라벨의 3단 서류 묶음
- `Small-potted-plant.glb`: 속이 있는 화분·흙·줄기·둥근 잎 7개
- `Cabinet-paper-tray.glb`: 목재 트레이와 종이 5장
- `Standing-files.glb`: 연초록/짙은 초록/크림색 파일철 3개와 등 라벨
- `Cabinet-decor-source.blend`: 독립 소품 편집 원본
- `Office-cabinet-decor-preview.blend`: 최신 조합 장면
- `room-preview.png`, `left-detail.png`, `right-detail.png`: 전체/양쪽 확대
- `build_decor.py`, `manifest.json`: 재현과 배치 기록

각 소품은 바닥 z=0을 기준으로 만들고 서랍장 상판 z=.882에 배치한다. 가구의 통로 간격은 유지하며 장식은 상판 안에 놓았다. 크기는 임시 제작 단위다. 게임과 기존 가구 원본은 변경하지 않았다.
