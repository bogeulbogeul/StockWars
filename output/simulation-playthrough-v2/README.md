## 실제 플레이

타이틀→주식 체험→에너지 기업 정보→IT 기업 정보/차트 교차선→베리클라우드2주 매수→뉴스1→차트 변화→리프에너지5주 매수→뉴스2→두 업종 계좌→베리클라우드2주 매도→뉴스3→리프에너지5주 매도→결과→체결4건 내역→재도전5,000잎→타이틀 복귀.

스크립트는 실제 화면 버튼/입력만 사용했다. 잔액·보유량·주가·진행 상태를 직접 변경하거나 완료 플래그를 주입하지 않았다. 일반적인 실시간 시세 변동은 촬영 중에도 그대로 진행됐다.

## 발견·수정

첫 촬영(output/simulation-playthrough-v1)에서 매우 작은 음수 지수 변동이 소수 둘째 자리 반올림으로 ‘-0%’로 표시됐다. StockFormat.change에서 절댓값0.005 미만을0으로 정규화했다. 웹/기존 실행본 리소스 모두 반영했으며 -0, -0.0001, -0.0049, 0, +0.0049는 +0%, -0.01과 +1.23은 부호·값 유지됨을 확인했다. 최종 영상은 이 수정 후 새 세션을 재촬영한 것이다. 거래/경제 규칙은 변경하지 않았다.

이번 두 종목 시장가 경로에서는 진행 막힘·화면 깨짐·거래 중복·결과 불일치를 발견하지 못했다. 모든 가능한 종목/지정가 조건이나 EXE 자체를 이번 영상 하나로 검수한 것은 아니다. 앞선 별도 검증 범위는 ../simulation-challenge-v1/README.md를 참고한다.
