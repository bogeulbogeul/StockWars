# 채택 시트 게임 연결

강아지·고양이·숲속 친구들6종의 PNG/manifest를 web/assets/characters에 반영했다. 토끼는 rabbit-rear-locked-v1의 뒤 머리 수정본, 다른7종은 dog-motion-match-v1/<id>/before의 승인 원본이다. verification.json은 모든 게임 PNG의 바이트 일치·해시 검사다. 재생성·재색상화는 수행하지 않았다.

숲속6종의 기존 살롱 미리보기 이미지도 같은 경로이므로 최신본이 표시된다. ForestCharacterStyles가 기존 상점 좌표를 공통 플레이어 렌더러에 등록해 저장된 styleId로 마을·실내·물류의 걷기/앉기/운반을 표시한다. 숲속 초상화는 시트의 face_portrait을 사용한다. 기본 캐릭터 생성 선택은 기존 강아지/고양이만 유지한다. 판매 일정·가격·구매 준비 중 상태·보유 데이터는 변경하지 않았다. 다른 방향에서 운반할 때도 실제 제공된 오른쪽 운반 행을 사용한다.

캐릭터 렌더러·꼬리 및 숲속 렌더링 통합 테스트11개 통과. 검증은 승인 PNG/atlas 좌표/프로필 스타일 전달/걷기 중립/좌우 반전/걷기3그림160ms/운반4그림/초상화다. 종별 숲속 표시 배율은 우선 기존 강아지 공통 배율을 사용하며 실제 게임 내 귀를 제외한 키·가구 및 화물 접촉·발 미끄러짐 시각 검수는 미완료다. 실제 브라우저 플레이 완료로 해석하지 않는다.
