기존 글자 없는 색연필 지도 화풍·건물9종과 상대 위치를 유지하고 v9의 단순한 정류장 직결길·광장 남쪽 T자/동서 연결·제거한 하단 반복 루프를 반영했다. 게시판은 안내소 옆, 벤치는 차도 밖 잔디에 표시한다. 지도는 읽기 쉬운 그림으로 해석한 것으로 좌표 정밀 충돌 지도가 아니다.
