# 소망이 겨드랑이 경계 정리 v33

v32의 팔 전체 회전·빵 먹기 모션을 유지하고 겨드랑이 안쪽 연결면을 정리했다. 팔꿈치 본이나 팔 중간 관절을 추가하지 않는다. 팔은 Body / Arm.L / Arm.R 중 해당 팔의 단일 가중치 1을 사용하며 통째로 회전한다.

## 수정

- 보충 면 가장자리의 중복 정점을 연결하고 경계 법선을 정리했다.
- 경계 양쪽 곡면의 기울기를 이용해 연결면을 만들었다.
- 원형 패치처럼 드러나던 겨드랑이의 고정 면을 주변 원본 몸통 단면에 이어지도록 정리했다. 이 국소 부위의 곡면·안쪽 면은 수정했으며, 연결부 밖의 체형을 다시 디자인하지 않았다.
- 겹친 보충 면의 안쪽 위치를 미세하게 조정해 표면이 교차하며 생기는 점 형태의 음영을 줄였다.

## 검증

`preservation.json`은 초기 원본 표면을 이용한 위치 비교다. 팔 원본 좌표 최대 차이는 왼쪽 2.98e-8, 오른쪽 1.91e-7 모델 단위다. 연결부 밖의 머리·몸통·다리 등 29,424개 표면 정점은 최대 2.00e-6 모델 단위 차이이며, 이 차이는 근접 정점 연결 허용오차 안이다.

181개 반 프레임 표본에서 고정 영역의 위치 변화는 0이다. 팔/얼굴, 빵/얼굴, 빵/몸통 교차 표본은 0이다. `verification.json`의 `forearm*` 키는 이전 검사 도구의 이름으로 이번 모델에서는 팔 전체를 뜻한다. 팔 모서리 길이 상대 수치 오차 최대 약 0.075%는 짧은 모서리를 포함한 부동소수점 계산 결과다. 팔 길이나 굽힘을 바꾸는 애니메이션 키는 없다.

팔/몸통 검사는 의도적으로 겹친 안쪽 연결면까지 포함하므로 0개 통과로 표시하지 않는다. 메시 전체를 원본과 동일한 위상이라고 주장하지 않는다. 정면·양 측면 미리보기는 내보낸 GLB를 다시 불러온 렌더다. 게임에는 적용하지 않았다.

- `somangi-eat.blend`: 작업 원본
- `somangi-eat.glb`: 애니메이션 모델
- `eat-front.gif`, `eat-both-sides.gif`: 정면·양쪽 옆 미리보기
