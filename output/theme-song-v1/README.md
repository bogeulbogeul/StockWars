# 작은 잎의 내일 — StockWars 테마곡 v1

후속 사용자 요청으로 게임 타이틀에 적용했다. 현재 연결과 검증은 [타이틀 적용 기록](../title-theme-game-v1/README.md)을 따른다. 아래는 최초 제작 당시 기록이다.

소망이가 마을에 도착해 작은 일과 배움, 이웃과의 만남으로 내일을 만들어가는 모습을 담은 오리지널 연주곡 초안.

- D장조 · 96 BPM · 4/4 · 약 84.5초
- 오르골 계열 주선율, 기타 계열 발현 반주, 부드러운 베이스와 패드, 작은 브러시 타격음
- 구성: 첫걸음 8마디 → 이웃과의 하루 8마디 → 내일을 향한 확장 8마디 → 주제 재현 8마디 → 종지
- `small-leaf-tomorrow.wav`: 외부 샘플 없이 합성한 스테레오 감상용 데모. 보컬 없음.
- `small-leaf-tomorrow.mid`: 편곡용 4개 악기 트랙과 템포/박자/조성. 재생 악기에 따라 WAV와 음색이 달라짐. 브러시 트랙은 MIDI에서 생략.
- `compose.py`: 재생성 가능한 작곡/합성 스크립트. Python 표준 라이브러리만 사용.
- `validation.json`: 길이·포맷·피크 기록.

음원 제작 초안이며 게임의 오디오 연결이나 기존 실행본은 변경하지 않았다. 끝맺음이 있는 감상용 버전으로 무봉제 루프용은 아니다. 실제 청취와 사용자 음악 검수는 별도다.
