# 고양이 정면 머리 리듬·색면 정리 v15

v14의 기본색 일치 검사는 미세한 RGB 변화로 생기는 얼룩과 고정된 정면 머리 표현을 놓쳤다. 사용자 피드백에 따라 두 항목을 별도로 수정했다.

- 정면 걷기 머리는 built-in GPT imagegen으로 강아지3자세를 참고해 편집했다. 생성된 과도한 기울임은 강아지의 눈 높이 기울기를 측정해 보정했다. 머리만 분리해 목에 연결하고 몸·손발·꼬리는 기존 자세를 유지했다.
- 강아지 눈선 A/중립/B는 약0.33/-2.90/0.75도, 보정한 고양이는 약0.41/-2.89/0.86도다. 눈선 일치는 전체 머리 형태·접촉의 픽셀 동일을 뜻하지 않는다.
- 전체 털은 기본(65,59,62), 그림자(51,45,48), 밝은 면(73,66,70)의 공통 색면으로 정리했다. 분류 전 중앙값 필터 및 작은 색 조각 제거로 미세한 색 잡음을 억제한다. 귀 안쪽도 한 기본색으로 정리해 반점식 명암을 제거했다.
- 정면 머리/목 외 alpha 유지, 정면 하체 alpha 유지, 시트 좌표·재생 계약·걷기3그림/운반4그림/160ms 검증. 정면 앉기 수정 자세 유지.
- 게임에 설치하지 않았다. 최종 외형 채택은 사용자 확인 후 별도다.

sprite-sheet-alpha.png와 manifest.json이 전달본이다. frames/는 개별 PNG, overview.png는 전체 자세, preview.html은 강아지와 비교 재생한다. front-head-generated.png는 GPT 편집 원본, prompt.txt는 요청, package_clean.py는 머리 분리·각도 보정·색면 정리 및 조합, validation.json은 검사 기록이다.
