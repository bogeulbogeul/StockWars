# 떠다니는 구름 v3

P2 · ✅ 웹·기존 실행본 적용·자동 검증 / ⏳ 사용자 최종 시각 검수

사용자 새 요청으로 시간대별 하늘 위에 둥근 구름4개를 추가했다. `Docs/ART_STYLE_GUIDE.md`의 2D 하늘/3D 건물과 깔끔한 둥근 표현을 따르는 Canvas 코드 형상이다. 별도 생성 이미지나 다운로드 에셋은 사용하지 않는다. 구름 형상/위치/색/이동은 독립 `TownClouds.js`, 기존 그라데이션/시간 전환은 `TownSky.js`가 관리한다.

구름은 각기 다른 크기·높이·속도로 오른쪽으로 천천히 흐른다(화면 폭 기준 초당0.21~0.38%). 완전히 화면 밖으로 이동한 뒤 반대편에서 이어져 화면 안 순간이동을 피한다. 현재 혼합 중인 하늘색에서 색조를 구해 시간대 전환에 맞춘다. 시스템 동작 줄이기 설정에서는 구름 위치를 고정한다. 주황 노을 v2·다른 시간대·기존12초 전환은 유지한다.

1024×512 공통 Canvas 텍스처 한 장을 최대초당10회 갱신하며 별도 애니메이션 타이머나 DOM 레이어는 추가하지 않았다. 일반 마을·전시/도착의 공통 TownLandscape에서 사용한다. 건물/조명/배치/저장은 변경하지 않았다.

웹과 기존 실행본에 `TownSky.js`·`TownClouds.js`를 동기화했다. `scratch/check-current-exteriors.cjs`를 양쪽에 실행해 구름 위치 이동·30초 후 실제 픽셀 변화·장시간 순환 범위·동작 줄이기 위치 고정·네 시간대 구분·색 전환 시작/중간/종료와 기존 로딩/길/입구/시계/작은 화면/JavaScript 오류 검사를 통과했다. 정적 캡처 `web-sky-day.png`·`web-sky-sunset.png` 등은 검사 카메라 렌더이며 움직임 검증은 브라우저 assertion으로 수행했다. 설치 프로그램은 재빌드하지 않았다.
