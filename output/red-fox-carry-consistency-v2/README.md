# 붉은여우 운반 얼굴·색 보정 v2

운반 4프레임의 볼·주둥이와 눈 비율을 기존 사선 정지 외형에 맞춘 네이티브 이미지 편집본이다. 편집된 머리 영역만 조합하고 몸·손발·꼬리의 기존 자세를 유지했다. 팔 뒤 그림자를 초콜릿 털로 잘못 분류했던 부분은 기존 주황 RGB로 복원했다.

- 기존 공통371색 유지. 팔레트 밖 RGB 0.
- 다른15개 논리 프레임 PNG 바이트 동일.
- 강아지 v9와 시트 좌표·재생 구성 동일, 운반4그림·160ms 유지.
- 정적 모아보기와 출력 무결성·미리보기 렌더 경로 검사 완료. 실제 브라우저 재생 연속성 검수는 별도.
- 게임에는 설치하지 않았다.

생성 프롬프트와 도구는 generation.json, 보존 범위는 carry-fix-verification.json을 참조한다.
