# 봉봉 앞치마 곡면 보강 v3

2026-10-22 · P1 (Major) · ✅ 곡면 수정·정면/좌우/뒤/사선 렌더·GLB 재수입 검사 / ⏳ 사용자 시각 검수·전체 모션 접촉 검수·게임 적용.

사용자 요청: 이미지 시안처럼 더 굴곡진 앞치마. `../bongbong-apron-views-v1/front.png`를 다시 열어 확인하고 v2에서 별도 버전으로 수정했다.

- 옆선은 아래로 넓어지며 밑단의 둥근 곡선으로 접선 방향이 이어지도록 변경했다.
- 밑단 가운데를 더 낮춰 둥근 볼 형태를 강조했다.
- 앞판의 배를 감싸는 깊이와 중앙 볼륨을 늘렸다.
- 주머니 윗선에 약한 처짐을 주고 중앙 곡면을 도톰하게 만들었다.
- 앞판과 주머니에 1단계 곡면 보간을 적용해 면 사이 꺾임을 완화했다.

파일: `Bongbong-apron.blend` 편집 원본, `Bongbong-apron.glb` 착용 모델·기존 걷기, `Apron-only.glb` 별도 앞치마·공통 리그. `front.png`, `left.png`, `right.png`, `back.png`, `three-quarter.png`는 실제 모델 렌더다. 생성 스크립트는 `build.py`다.

원본 소망이 몸체 정점 좌표 불변 검사를 통과했다. 앞치마 평가 삼각형은 곡면 보강으로 8,400개(v2 5,784개)이며, 꽃봉오리 864개와 기존 몸체 73,602개는 유지했다. 검사 기록은 `validation.json`, `export-validation.json`이다. 단일 리그와 걷기 클립의 GLB 재수입을 확인했다. 모든 동작에서의 관통 및 실제 게임 검수는 미완료다. 게임/실행본은 변경하지 않았으며 이전 버전은 보존한다.
