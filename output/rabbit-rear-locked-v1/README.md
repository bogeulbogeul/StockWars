# 토끼 뒤 머리만 통일 · 승인색 고정

사용자 요청으로 기존 승인본의 토끼 뒤 머리만 정면·사선의 둥근 외형과 통일했다. 뒤 걷기3그림과 공유 뒤 정지1그림이 대상이다. 다른 방향·걷기·운반·앉기·초상화는 승인 PNG와 바이트 동일하고 뒤 프레임의 y=200 아래 몸·다리도 RGBA 동일하다. 나머지7종은 승인 시트와 바이트 동일하다. 3프레임·0→1→2→1·160ms와 시트 좌표를 유지한다.

built-in image_gen의 국소 외형 편집1회가 머리 실루엣/윤곽선 마스크를 제공한다. 실제 프롬프트·참조·원본은 generation.json이다. 생성된 RGB는 최종본에 채택하지 않았다. 승인색이 반복해서 바뀌었던 문제를 막기 위해 머리 내부는 기존 승인 픽셀을 보존하고 새 가장자리는 같은 원본의 내부 털색 샘플/승인 윤곽색을 조합했다. 원본 가장자리의 안티앨리어싱 색이 줄무늬로 재사용되지 않도록 충분히 안쪽 털색에서 가져온다. 모든 최종 불투명 RGB가 해당 승인 프레임에 존재하는 RGB인지 검사했다. 색을 적은 팔레트로 양자화하거나 전체 밝기/채도를 조절하지 않았다.

크로마·완성 요소 분리는 sprite-gen 함수를 사용한다. 같은 행의 동일 배율, 머리 기준점 정렬과 색 보호 마스크 조합은 프로젝트 전용 수작업 어댑터이며 엔진 자동 색 복원 기능이라고 주장하지 않는다. 새 걷기나 리깅을 만들지 않는다. 뒤 머리3자세 비교 이미지를 검수했고 몸·색 샘플 출처·비대상 모션의 픽셀 보존·GIF 순서/시간을 확인한다. 실시간 브라우저 재생 및 게임 내 접지 검수는 별도 미검증이다.

preview.html에서 모든 토끼 모션을 승인본과 비교하며 기본은 뒤 걷기다. before/는 수정 직전 승인본 보존본이며 run/이 뒤 머리 수정본이다. 다른 종/게임 런타임은 수정하지 않는다.
