# 스토리 다이어리 3D v1

2026-10-26 · P1 (Major) · ✅ 닫힌/펼친 모델 제작·메시 검사·GLB 재불러오기 / ⏳ 사용자 외형 검수·게임 적용·전달/필기 접촉.

모아에게 받아 첫 기록을 남기는 용도의 소품 시안이다. 세이지 그린 표지·짙은 초록 책등·아이보리 빈 속지·베이지 책갈피를 사용한다. 닫힌 표지의 작은 아이보리 라벨도 비워두며 제목·날짜·가짜 글자·새 문양을 넣지 않았다. 펼친 모습은 두 페이지가 비어 있다.

- `StoryDiary-closed.glb`, `StoryDiary-closed.blend`, `closed.png`: 닫힌 전달/보관용 모델·편집 원본·실제 렌더.
- `StoryDiary-open.glb`, `StoryDiary-open.blend`, `open.png`: 펼친 기록 연출용 모델·편집 원본·실제 렌더.
- `build.py`, `manifest.json`: Blender 5.2 재현 스크립트와 치수/메시 검사 기록.

두 가지 정적 모델이며 펼치기 애니메이션/리깅은 없다. H=1 임시 단위로 닫힌 표지 폭 0.225H·길이 0.302H·두께 약 0.044H다. 원점은 눕혀 놓은 밑면 중앙, Blender +Z 위쪽/+Y 책 상단, glTF +Y 위쪽/-Z 책 상단이다. 스튜디오 바닥·조명·카메라는 GLB에 포함하지 않는다. 실제 게임 배율·손 접촉·기록 UI는 후속 대상이며 게임 코드·배포·저장은 변경하지 않았다.
