# 모아 길 이동 v3

- 모아의 소개 이동은 `TourPaths.js`가 실제 길 텍스처와 같은 둥근 모서리·노선·광장 타원으로 제한한다. 길 안쪽에 여유2를 두고12단위 격자 탐색/경로 정리를 수행한다. 잔디를 가로지르는 직선 단축은 사용하지 않는다.
- 정류장 플랫폼에서 길로 나오는 짧은 연결 이동 이후 길을 따라가며, 도착점은 해당 건물 앞 진입로의 가까운 보행 가능 지점이다. 플레이어는 기존대로 WASD로 직접 움직인다.
- 실제 충돌 검사에서 기존 길과 겹친 정류장 기둥·가구점 돌출부·동쪽 광장 벤치를 피하도록 길 연결부를 조정했다. 건물/NPC/벤치 위치는 바꾸지 않았다.
- 웹 및 기존 실행본에서 소개10구간을4월드단위 간격으로 표본 검사해 길 이탈0·충돌0을 확인했다. 자료는 routes.json. 기존 자동 테스트11개 통과.
- 앞선 v2의47% 감소 수치는 잔디 이동을 허용한 계산 기준이며, 현재 길 전용 이동 거리의 감소율로 사용하지 않는다. 소개 순서는 유지한다. 사용자 최종 시각·플레이 검수는 별도다.
