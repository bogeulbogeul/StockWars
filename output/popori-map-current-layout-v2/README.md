# 새 마을 배치 지도 v2

P2 · ✅ 지도 재제작·시각 확인·후속 사용자 요청으로 안내소 내장 지도 적용 / ⏳ 사용자 최종 플레이 검수

기존 글자 없는 색연필 지도 형식을 유지해 최신 건물9종·광장·산책로·정류장·게시판·벤치를 반영했다. 집/넓은 증권사/펍은 북쪽, 우체국/광장/잡화점은 중앙, 가구점/서점은 남쪽 양옆, 안내소/은행은 입구 쪽이다. 게시판은 안내소 오른쪽, 정류장 벤치는 차도 밖 잔디다. 옷가게와 집 앞 나무는 넣지 않았다.

`map.png`는 built-in image_gen으로 제작한 색연필 안내 지도이며 최종 프롬프트는 `prompt.txt`다. 기존 지도는 화풍 참고로, 게임 전경은 건물 외형/배치 참고로 구분했다. 현재 `townModelBuildings.js`·`townLandscapeLayout.js`·`townGardenProps.js`의 배치를 확인해 프롬프트에 반영했다. 지도는 읽기 쉬운 그림으로 재해석한 것이며 좌표 정밀 충돌 지도는 아니다.

글자/범례 없음·건물9종·넓은 파란 증권사·우체국 추가·안내소 옆 게시판·차도 위 벤치 없음·집 앞 나무 없음·시설 상대 위치를 시각 확인했다. 후속 요청 “마을 안내소 지도 업데이트 해줘”로 안내소 게임 GLB에 적용했다. 원본/이전 지도는 보존하며 적용·검증은 `../information-map-current-layout-v3/README.md`를 따른다.
