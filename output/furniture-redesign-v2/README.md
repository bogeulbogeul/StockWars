# 모던 프레임 가구점 재디자인 v2

P1 · ✅ 채택 시안 기반 네이티브 3D 제작 / ⏳ 사용자 최종 시각 검수·게임 적용

사용자 요청 “에셋도 이런식으로 변경해줘”에 따라 `furniture-redesign-concept-v1/concept.png`를 기준으로 기존 가구점 외관을 수정했다. 이전 곡면 지붕 대신 높은 왼쪽 입구 박공·낮은 오른쪽 교차 박공, 코코아 갈색 기와와 둥근 용마루를 제작했다.

- 각 지붕의 실제 교차선으로 기와/지붕 바탕을 절단하고 골에는 닫힌 클레이 마감을 넣었다. 앞뒤 처마·측면 목재·정면 가로보는 합집합으로 연결했다.
- 크림 벽·꿀색 목재·청색 유리·왼쪽 아치 양문·황동 손잡이·의자 부조를 유지하고 시안에 맞춰 재질과 간판 크기/깊이를 조정했다. 쇼윈도는 폭 8%, 높이 13% 확대했다.
- 문 중심과 상단 높이는 유지하고 하단만 계단 안에 연결했다. 측면/후면 창은 추가하지 않았다. 시설/실내/저장/충돌 코드는 변경하지 않았다.
- 결과: `Furniture-clean.glb`, `Furniture-redesign.blend`. 전체 사선·정면·후면·지붕 접합부·문 확대는 실제 모델 렌더다.
- `verify.py`로 GLB 재로딩·유한 좌표·접지·구형 지붕 제거·새 지붕/목재 닫힘·양문/쇼윈도/간판 수량을 검사한다. 결과는 `validation.json`을 따른다.

웹/기존 실행본에는 아직 교체하지 않았다. 게임 로딩·배율·충돌 검증과 사용자 최종 시각/플레이 검수는 후속 적용 단계다.
