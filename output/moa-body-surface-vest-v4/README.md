# 모아 몸통 표면 복사 조끼 v4 — 2026-10-25

**P1 (Major) · ✅ 몸통 표면 기반 재제작·GLB 재수입 렌더 / ⏳ 사용자 외형 검수.**

사용자가 승인한 방식에 따라 기존 조끼를 계속 줄이는 대신 실제 모아 몸통 면을 복사해 새 조끼를 만들었다. 소망이/모아 원본 몸체는 수정하지 않았다.

- `surface_vest.py`: 몸통 22,523정점·38,322면에서 조끼 영역을 추출한다. 앞트임·목둘레·팔 구멍·밑단의 잘린 경계를 부드럽게 하고 몸통 표면에 재투영한다. 내부 정점은 원래 몸통 곡선을 사용한다.
- 원래 피부 법선을 따라 0.006 원본 단위 띄우고 바깥쪽 두께 0.005를 준다. 둥근 테두리 반경은 0.004다. 몸체와 같은 그룹·웨이트를 복사했다. 테두리는 Body 본에 연결했다.
- AnnaVest 원본에서 올리브색을 실제 텍스처 표본으로 추출했다. **기존 조끼 메시·UV·원본 텍스처를 그대로 유지한 결과가 아니라, 그 색과 앞트임·둥근 테두리 방향을 사용한 새 몸통 표면 조끼**다.
- `surface-check.json`: 실제 복사 면 수·간격·두께·색·테두리 수 기록.
- `fit-check.json`: 몸체 원본 정점 변화 0. 기존 걷기·잎 본·기분 클립 보존.
- `moa.blend`, `moa.glb`: 새 편집 원본·전달 모델. 이전 v1~v3 및 사용자 첨부 원본은 보존한다.
- `front.png`, `side.png`, `back.png`와 반대 접지 걷기 정면·측면 4장을 내보낸 GLB 재수입으로 확인했다. 전체 동작의 무관통 검증 완료를 뜻하지 않는다.

게임·실행본에는 적용하지 않았다.
