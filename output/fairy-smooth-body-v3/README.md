# 매끈한 공통 몸통 v3 — 2026-10-22

P1 (Major) · ✅ 몸통/의상 곡면 보정·모션 검사·웹/로컬 실행본 리소스 반영 / ⏳ 사용자 최종 외형·플레이 검수.

사용자 측면 참고 `user-profile-reference.png`의 가슴에서 둥근 배·다리로 이어지는 형태를 기준으로 수정했다. v1의 폭 축소, v2의 다리 연결 보정에 이어 몸통 단면을 연속된 곡면으로 다시 구성했다. 단일 측면 이미지를 정밀 스캔한 모델이라는 뜻은 아니다.

## 형상

기존 97×64 단면의 위상·인덱스·웨이트를 유지하고 몸통 정점을 매끈한 타원 단면의 배 모양 곡면으로 재배치했다. 정규화 높이 u에 대해 반경은 `sqrt(1-u*u)*(1-.30*u)`를 최대 반경으로 정규화해 사용한다. 아래쪽이 조금 넓은 단일 볼륨이며 기존 높이별 반경 조합의 꺾임을 제거했다. 폭·깊이 최대치는 v2와 같고 위 끝은 머리 안쪽으로 .08 연장했다. 법선은 새 곡면에서 계산한다.

소망이·모아·토리·봉봉과 관련 11개 GLB에 같은 기준을 적용했다. 조끼·앞치마·끈도 몸통의 표면 변화에 맞추되, 두께와 여유를 유지하는 변위를 사용하고 위아래 극점 근처의 보정량을 줄였다. 초기 작업 중 발생한 앞치마 밑단의 과한 확대를 최종본에서 제거했다.

머리·얼굴·팔다리·발바닥·본·웨이트·모프·모션 키는 v2와 동일하다. `geometry-validation.json`과 `build.mjs`의 바이트 비교는 몸통/의상 위치·법선 이외의 바이너리가 바뀌지 않았음을 확인한다. 이전 제작본은 보존한다. 서로 겹쳐 연결한 기존 강체 몸통/팔다리 구조를 유지하며 하나의 용접 메시로 바꾸지 않는다.

## 확인

- `render.py`: 네 캐릭터의 정면·측면 실제 GLB 렌더 8장. `body-profile-inspection.png`는 같은 봉봉 모델의 의상을 숨기고 몸통을 보여주는 검사 렌더다. 게임에서는 의상을 유지한다.
- `scratch/check-fairy-smooth-motion.cjs`: 기존 애니메이션 33개(모델 간 중복 포함)와 토리 정지 자세, 총 1,104개 시점. 24fps 간격과 끝점에서 다리 윗단 32개 표본이 몸통 안에 남는지 검사하고, 양쪽 어깨 상부 표본 중 몸통과 겹치는 부분이 유지되는지도 검사했다. 이탈/연결 겹침 소실/비정상 좌표/브라우저 오류 0. 연속 시간의 모든 표면이나 모든 의상 접촉을 증명하는 검사는 아니다.
- 각 클립의 6개 시점 정면·측면은 `*-poses.png`. 걷기·먹기·점프·게걸음·앉기·졸기를 시각 확인했다. 실제 재생 영상은 `somangi-walk-preview.gif`, `moa-sit-preview.gif` 및 대응 WebM이다.
- `scratch/check-fairy-smooth-game.cjs`: 웹 및 실행본 리소스에서 기존 걷기·인사·먹기·점프·게걸음 전환과 집·잡화점·안내소·증권사 모델 로딩 확인. 로그는 `browser-web.log`, `browser-runtime.log`.
- `install.cjs`: 웹/실행본 리소스 11개 GLB와 제작본의 SHA-256 동일 검사. `install-validation.json`. 설치 프로그램 재빌드는 수행하지 않았다.

다른 여섯 주민의 신규 제작은 보류한 상태를 유지한다. 이번 작업은 현재 공통 몸체의 형상과 기존 모션 검증이다.
