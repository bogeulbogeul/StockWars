# 사선 중립 자세 수정 v2

사용자가 지적한 한쪽 무릎 굽힘·들린 발을 수정했다. 양다리는 자연스럽게 펴고 양발을 바닥에 둔 중립 자세다. 내장 image_gen으로 완성 프레임을 편집하고 sprite-gen의 연결 성분 추출로 분리했다. 원본·프롬프트는 `generation.json`, 사용 생성물은 `raw/neutral.png`다.

변경은 사선 걷기 중립 `right_walk[1]`과 이를 공유하는 정지 `right_idle[0]`뿐이다. A/B 접지를 포함한 다른 17논리 프레임은 v1과 RGBA가 정확히 같다. 신규 그림을 수동으로 늘이거나 다리를 그려 넣지 않았다. 시트 픽셀·중립 공유·여백·재생 순서·미리보기 렌더 경로 검사를 통과했다. 실시간 동작 연결·재질색 일관성과 게임 접촉은 별도이며 아직 게임 미반영 시안이다.

`preview.html`은 v1과 v2 비교, `neutral-comparison.png`는 왼쪽 v1 / 오른쪽 v2다. `apply.py`로 재조합한다. 복사한 `build.py`는 공통 조합 함수 제공용이며 이 폴더에서 단독 실행하지 않는다. 나머지 생성 원본과 전체 제작 이력은 `../dog-motion-rebuild-v1/`을 따른다.
