# 소파와 테이블 사이 옆걸음 통로

사용자 요청으로 안내소 소파는 유지하고 원형 테이블·상판 화분·러그를 왼쪽으로 28 게임 단위 이동했다. 테이블/화분 중심 X=114, 러그 X=150이다. 소파 프레임 최소 X≈277.5와 테이블 최대 X≈157 사이 실제 외곽 간격은 약 120.5다. 기존 반경 42의 충돌을 유지해도 통과 가능한 여유를 만들었다. 캐릭터 모델·체형·충돌 크기·자동 옆걸음 판정/속도는 변경하지 않았다. 장식 쿠션 제거와 두 자리 착석은 유지한다.

실제 걷기 검증 중 가이드북 상호작용에 공통 tryEnter 메서드가 없어 일반 실내 걷기가 중단되는 오류를 발견했다. InformationGuidebook에 아무 진입도 수행하지 않는 tryEnter()를 추가해 기존 걷기를 정상 연결했다.

웹과 기존 실행본 resources/web에 두 모듈을 반영했다. `scratch/check-information-sofa-gap.cjs`를 양쪽에서 실행해 W키로 X=220, Z=250에서 Z<-40까지 실제로 걸었다. 통로에서 자동 옆걸음 진입, 모든 기록 위치의 충돌 판정 유효, 통로 이탈 후 일반 걷기 복귀를 확인했다. 직접 좌표 설정은 테스트 시작점에만 사용했다. 각 passage.json에 프레임별 위치·옆걸음·충돌 판정을 기록했다. 두 자리 착석/일어서기·E키 착석·지도/창구 접근·가구 충돌·러그 통행 검사도 통과했다. JavaScript 오류는 0건이다. 실제 옆걸음 렌더를 열어 확인했다. 사용자 최종 플레이 검수·설치 프로그램 재빌드는 별도다.
