# 포포리빵 양 끝 곡면 보정 v4

사용자 정정에 따라 원본의 작은 둥근 끝을 복원한 [v5](../popori-bread-reference-ends-v5/README.md)가 후속 기준이다. v4는 작은 끝이 사라진 이전 이력이다.

2026-10-25 사용자 첨부 두 확대 이미지: 넓은 쪽의 납작한 끝과 좁은 쪽의 구슬 모양 연결이 인위적으로 느껴짐.

- [전체](preview.png) · [넓은 끝 확대](left-end.png) · [좁은 끝 확대](right-end.png)
- [GLB 재수입 확대](detail.png) · [GLB](item_popori_bread.glb) · [Blender 원본](Popori-bread.blend)
- [검증](validation.json) · [해시](manifest.json)

직선 X 간격으로 둥근 끝을 보간하던 방식은 끝에서 곡률이 고르지 않아 원형 마개처럼 보였다. v4는 각도에 따른 연속 곡면으로 넓은 끝부터 몸통까지 부드럽게 이어지게 했다. 좁은 쪽은 잘록한 목과 구형 돌기를 없애고 자연스럽게 가늘어지며 닫히는 한 덩어리 반죽으로 변경했다. 약한 비대칭과 얕은 바닥 접촉면을 유지한다. 단면·속재료·칼집은 추가하지 않았다.

구운 색·기공·거칠기·윤기 맵은 v3 파일을 그대로 사용했다. 종이 포장·꽃/잎 인쇄·조명·전체 촬영 기준도 유지했다. 재현하려면 이 폴더의 표면 PNG와 `build.py`를 사용한다. 표면 맵 제작은 이전 [v3](../popori-bread-baked-v3/prepare.py)를 따른다.

개별 GLB 재수입·정점 좌표·퇴화면·내장 이미지 디코딩을 확인하고 사용자 지적 두 끝을 각각 확대 렌더했다. 수치는 `validation.json`에 기록한다. 이번 v4를 후속 제작본으로 사용하며 v3는 이전 형상으로 보존한다. 게임 적용·사용자 최종 외형 검수는 별도다.
