# 소망이 먹기 측면 수정 v2

v1을 보존한 별도 수정본. 음식 높이와 팔 들기 경로를 올리고 고개 숙임을 조정했다. 원본 메시·웨이트를 유지하면서 어깨·겨드랑이 주변에 9개 보정 모프를 추가했다. UV 경계를 묶어 인접 관계를 계산한 뒤, 각 자세에서 연결부를 평활화하고 역 스키닝으로 보정값을 저장한다. 다른 걷기·앉기·게임 파일은 변경하지 않는다.

- `somangi-eat.glb`: 본 동작과 어깨 보정 모프를 한 장면 클립으로 내보낸 모델.
- `somangi-eat.blend`: 편집용 원본과 프리뷰 장면.
- `eat-side.gif`, `eat-front.gif`: 3초 루프 프리뷰.
- `validation.json`: 전체 73프레임·다리 고정·루프·원본 Basis 좌표·GLB 재수입 및 본/모프 채널 동시 내보내기 검사.

고정된 미소를 사용한다. 입 벌림·음식 소모·회복 효과는 포함하지 않는다. 런타임은 본 애니메이션과 함께 모프 애니메이션도 재생해야 어깨 보정이 유지된다. 이 파일은 게임에 설치하지 않았으며 최종 시각 채택은 별도다.

남은 시각 한계: 팔 아래 연결부의 각진 윤곽이 일부 남아 있다. 모프 평활화가 어깨·몸통 옆면에 국소 변형을 추가하므로 배 전체 무변형을 뜻하지 않는다. 최종 채택 전 시각 검수가 필요하다.
