# 정착 안내데스크 v1

P1 (Major) · ✅ 모델 제작 / ⏳ 사용자 아트 검수·안나 접촉·게임 적용

밝은 꿀색 목재의 둥근 상판, 크림색 전면 패널, 연초록 새싹 표식을 사용한다. 기존 안나 의자와 같은 재질값이다. 상판 소품은 아직 배치하지 않았다.

- `Information-desk.glb`: 독립 모델. 상판 기준점 `Application_Surface_Anchor` 포함
- `Information-desk.blend`: 편집 원본과 스튜디오 장면
- `front-right.png`, `rear.png`: 전후면 확인
- `room-preview.png`, `Room-desk-chair-preview.blend`: 최신 룸 틀과 안나 의자를 함께 배치한 미리보기
- `build_desk.py`, `manifest.json`: 제작 스크립트와 임시 치수/상태

폭 2.80·깊이 1.02·상판 높이 .97의 임시 제작 단위를 사용한다. 후면 중앙은 폭 1.45의 실제 빈 다리 공간이다. 의자는 룸 y=1.85, 데스크는 y=.92에 놓았다. 의자와 상판의 높이 차는 .405다. 실제 안나의 착석 자세·발 접지·상판 팔 접촉은 아직 검증하지 않았다. 게임과 기존 룸/의자 원본은 변경하지 않는다.
