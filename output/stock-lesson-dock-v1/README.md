# 초상화 없는 토리 하단 대사 — 2026-10-26

사용자가 하단 대사 시안을 채택하고 초상화 제외를 요청했다. StockLessonDock.js의 이름/첫 주식 수업/짧은 안내/다음 버튼을 주식 앱 하단에 전용 행으로 배치한다. 목록과 상세 본문만 스크롤하며 대사는 겹치지 않는다. desktop은 별도 grid 행, 작은 화면은 flex 하단이다. 수업 중 창은 최대 860px 높이로 공간을 확보한다.

첫날 trade 활동의 canTrade가 참이고 아직 첫 매수를 완료하지 않았을 때만 표시한다. 시장 목록·홈·차트·기업 정보·주문·계좌·거래 내역별 두 문장 안내를 제공하며 다음은 안내 문장만 넘긴다. 마지막 문장은 실제 선택/주문을 기다린다. 기존 수업장 이동/토리 설명·현물 1주·첫 6종목 조건·수수료 없음·일반 계좌 분리·성공 후 창 닫기/이야기 진행을 유지한다. 초상화나 추가 이미지 에셋은 없다.

scratch/check-stock-lesson-dock.cjs로 실제 StockApp/일반 소스/전시 활성 조건을 검사한다. 일반 상태 숨김·첫 매수 활성/완료 숨김·다음 문장·화면별 문장 전환·1280×900/390×844/844×390 본문과 대사 영역 겹침 없음·주문 버튼 접근·전원 닫기를 검증한다. 스크린샷 계좌는 독립 검증용이다. 웹과 기존 실행본 resources/web에 반영했으며 설치 프로그램 재빌드·실제 전체 전시 최종 플레이 검수는 별도다.
