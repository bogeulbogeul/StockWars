# 검은 글씨 홈 화면 버튼 v2

사용자 피드백으로 큰 연두색 버튼·집 아이콘·테두리·바깥 여백을 제거하고 투명 배경 검은 글씨의 홈 화면 버튼으로 변경했다. 하단 높이는 기본32px·낮은 화면28px로 축소했다. 공통 버튼이므로 8개 앱 모두 같은 형태이며 넓은 주식 화면에서도 유지한다. P 토글·launcher 숨김·홈 복귀는 유지한다.

웹 및 기존 실행본 resources/web의 PhoneHomeTemplate.js와 phone-home.css에 반영했다. scratch/check-phone-text-home.cjs로 8개 앱 PC/모바일 화면에서 표시·화면 내 배치·홈 복귀를 검증한다. 결과 및 실제 주식/소식 화면은 같은 폴더에 저장한다. 설치 프로그램 재빌드·사용자 최종 시각 검수는 별도다.
