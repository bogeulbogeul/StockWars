# 꽃잎 차 옆면 보정 v3

후속 윗봉합 끝 수정은 [v4](../petal-tea-seal-end-v4/README.md)를 따른다. v3는 수정 전 이력이다.

2026-10-25 사용자 피드백: 옆면이 이상해 다시 조정.

- [전체](preview.png) · [옆면 정측면](side.png) · [후면](rear.png) · [재수입 확대](detail.png)
- [상품 GLB](item_petal_tea.glb) · [Blender 원본](Petal-tea-paperbox.blend)
- [검증](validation.json) · [해시](manifest.json)

v2에서 옆면은 원본 일러스트의 작은 사선 조각을 확대·투시 보정해 문양이 늘어져 보였다. v3는 옆면의 실제 가로세로 비율(0.60:0.68)에 맞춘 꽃·잎 반복 인쇄를 별도로 구성했다. 원본의 크림 바탕·분홍 꽃·연두 잎 색을 따르지만 옆면 반복무늬는 재배치한 그림이다. 앞면·윗면의 기존 원본 인쇄와 몸통 크기는 유지했다.

옆면 상단의 평평한 삼각 덮개를 세 면이 안쪽으로 모이는 종이 접힘으로 바꿨다. 법선과 얇은 종이의 방향을 맞추고, 봉합 날개 아래의 간격을 줄였다. 뒷면에서 크림색 띠처럼 보이던 풀칠 겹침은 폭을 줄이고 외부와 같은 분홍색으로 정리했다.

개별 GLB를 재수입해 정점·퇴화면·내장 인쇄 이미지 로딩을 확인하고 전체·정측면·후면·접힘 확대를 렌더했다. 정확한 결과는 `validation.json`을 따른다. 기존 v2와 다른 상품을 보존하며 이번 v3가 꽃잎 차의 후속 제작본이다. 게임 적용·사용자 최종 외형 검수는 별도다.
