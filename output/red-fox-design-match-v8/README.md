# 붉은여우 디자인 기준 전 모션 확인·적용 v8

사용자가 첨부한 design-reference.png와 정면·사선·뒤 걷기, 운반, 두 앉기, 얼굴 초상화를 비교했다. 얼굴·귀·아이보리 무늬·눈빛과 선은 보존하고 평면적으로 처리됐던 주황/초콜릿 재질의 명암을 디자인 시트 기준으로 보완했다. 이전 v7의 강아지 명암 실험은 사용하지 않는다.

네이티브 이미지 편집은 행동별5행으로 수행했다. 생성된 몸/얼굴 형태 변경은 채택하지 않고 색 참고만 사용하여 기존 v6 재질 내부 RGB에 명암을 반영했다. 원본 시트 픽셀을 흐리거나 변형하지 않았다.3방향 중립·정지는 동일 PNG를 공유한다.

-10상태·19논리 프레임·16고유 그림·기존 재생 순서/160ms 유지.
-기존371색 안에서 주황/갈색의 공통 명암을 사용한다.
-전 프레임 알파·외곽 형태·몸/손발/꼬리 동작은 v6와 동일하다.
-눈·코·입·아이보리 세부와 재질 경계의 윤곽은 원본 RGBA를 보존한다.
-상점·플레이어 공통 붉은여우 슬롯에 설치, 설치 PNG/팔레트 바이트 동일.
-다른 숲속5종 보존, 관련 회귀18검사 통과.

시트/팔레트/정지 일치/렌더 경로 검사는 완료했다. 정적 비교와 자동 검사는 실제 브라우저 재생의 전체 색 연속성·게임 접촉 시각 검수 완료를 뜻하지 않는다.

generation.json에 도구·프롬프트·네이티브 원본, style-verification.json에 보존 검사, game-installation.json에 설치 기록을 보관한다.
