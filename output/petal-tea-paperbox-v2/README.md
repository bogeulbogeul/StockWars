# 꽃잎 차 — 종이상자 보정 v2

후속 옆면 수정은 [v3](../petal-tea-side-fix-v3/README.md)를 따른다. 이 폴더는 수정 전 제작 이력이다.

기준은 현행 상점의 `web/assets/items/packing-v1/items.png` 꽃잎 차 영역 `440,40,350,350`이다. 해당 그림의 인쇄 패널을 사각 투시 보정해 실제 상자 표면에 적용했다. 원본 꽃·잎·크림색 라벨·분홍색 외형을 유지하고, 기존 모델의 두꺼운 입체 배지와 부푼 모서리를 없앴다. 제품 전체를 평면 이미지로 대체한 것이 아니며 본체·접힌 어깨·삼각 접힘·윗봉합 날개는 각각 실제 입체 메시다.

얇은 종이 두께(상대 단위 약 0.004), 작은 모서리 베벨, 눌린 접힘선, 뒷면 풀칠 겹침·밑면 접기와 거친 무광 재질을 반영했다. 인쇄 그림은 종이에 평평하게 붙어 있고 원본 그림의 붓 표현과 하이라이트가 일부 포함된다. `prepare.py`는 원본 영역을 투시 보정하고 약한 종이 입자를 넣으며, `build.py`는 Blender 모델·GLB·실제 렌더를 만든다. PNG 인쇄 4개는 GLB와 Blender 원본에 내장되어 별도 파일 없이도 보인다.

GLB 헤더·파일 길이, Blender 재수입, 유한 정점 좌표, 퇴화면 0개, 내장 이미지 실제 디코딩을 검증한다. 정확한 삼각형 수·경계·해시는 `validation.json`에 기록한다. 확대 렌더는 내보낸 GLB를 다시 불러와 촬영한다. 사용자 최종 외형 검수는 별도다.

이번 개별 꽃잎 차를 기존 12종 모음의 꽃잎 차보다 우선하는 후속 제작본으로 사용한다. 꿀쿠키 v2와 다른 상품은 유지한다. 게임 상점 UI·웹/기존 실행본 적용·저장·가격은 변경하지 않았다. 월드 배율·충돌체·게임 성능 검증은 별도다. GLB는 상품만 포함하며 편집용 `.blend`는 검토용 조명·바닥·카메라도 포함한다.
