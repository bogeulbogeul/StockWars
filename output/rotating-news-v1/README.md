# 기업 정보 뉴스 카드·3분 교체·주가 반영 — 2026-10-28

## 동작

- 기업 정보 하단에 해당 기업의 관련 뉴스를 카드로 직접 표시한다. 카드의 기사 읽기는 기존 큰 소식 창에서 전문을 열고, 뒤로가기는 같은 기업 정보로 돌아온다.
- 기존288개 게임 기업 뉴스에서 기업별 현재 기사1건씩 무작위 선택한다. 각 기업에 관련 카드가 있도록 전체72개 기업에 각각 한 건을 제공한다. 처음부터 표시하며 게임 실행 시각(performance.timeOrigin) 기준180초마다 묶음을 교체한다. 바로 직전 기사와 같은 기사는 연속 선택하지 않는다. 이전 기사는 현재 뉴스에서 제거하며 읽던 기사가 만료되면 목록으로 돌아온다.
- 일반 시장과 타이틀의 별도 주식 체험에 적용한다. 첫날 이야기의 고정 가격1주 수업/전시 뉴스 소스는 변경하지 않았다. 기존 일반 시장의 로컬09/12/15/18/21 발행 이력은 삭제하지 않지만 일반 시장 화면은 새 세션 방식으로 사용한다.
- 일반 호재/악재는 약1.5~4%, 핵심 호재/악재는 약4.5~7%의 해당 종목 가격 충격을 적용한다. 기존 실시간 변동도 계속된다. 동일 발행 묶음은 엔진별 한 번만 적용하므로 새로 읽기/화면 재진입은 중복 가격 충격을 만들지 않는다. 뉴스 만료 시 가격을 되돌리지 않으며 다음 뉴스의 영향이 새로 적용된다. 뉴스 때문에 현금/보유 수량을 직접 지급/차감하지 않는다. 이후 손익과 지정가 체결은 기존 엔진의 시세·호가 규칙을 따른다.
- 엔진의 기존2.2초 틱에서 갱신하므로 발행 경계는 약3분이다. 긴 비활성 기간 뒤에는 현재 묶음만 제공하며 놓친 과거 뉴스 충격을 한꺼번에 재생하지 않는다. 세션을 닫은 후 재입장해도 실행 시각 기준 현재 묶음을 사용하고, 계좌는 기존 별도 초기화 규칙을 따른다.

## 구현

RotatingMarketNews.js(교체/가격 충격), SessionMarketNews.js(실행 시계·엔진별 중복 방지), PhoneStockSource.js·marketEngine.tick 연결. StockInfo.js·StockApp.js의 관련 카드/자동 갱신과 MountStockApp.js·StockNews.js의 전문 연결, NewsApp.js의 만료 처리. phone-stock.css 카드 배치. 뉴스 원문은 기존 자료를 재사용하며 데이터 주석만 새 사용에 맞췄다.

런타임 파일을 웹과 electron-app/dist/win-unpacked/resources/web에 동기화했다. 설치 프로그램은 재빌드하지 않았다.
