# 스마트폰 3D v1

2026-10-24 · P1 (Major) · ✅ 모델 제작·GLB 재불러오기·구조 검사 / ⏳ 사용자 외형 검수·게임 배치·손 접촉.

`reference.png` 오른쪽의 채택 시안을 기준으로 검은색 케이스·검은색 베젤·꺼진 검은색 액정·상단 수화부·측면 버튼·후면 단일 카메라를 제작했다. 케이스는 매끈한 무광, 액정은 약한 반사로 구분한다. 액정에 앱·문자·로고·발광은 없다.

- `StorySmartphone.glb`: 재질 포함 독립 모델. 외부 텍스처 불필요.
- `StorySmartphone.blend`: 편집 원본과 스튜디오. GLB에는 스튜디오 바닥·조명·카메라를 제외한다.
- `preview.png`, `back.png`, `front.png`, `side.png`: 실제 모델의 앞사선·뒤사선·정면·측면 렌더.
- `build.py`, `manifest.json`: Blender 5.2 재현 스크립트와 검사 결과.

임시 제작 치수는 H=1 기준 케이스 폭 0.18H·높이 0.32H·두께 0.026H다. 버튼과 후면 카메라 돌출을 포함한 외곽은 manifest에 기록한다. 원점은 세운 상태의 밑면 중앙이다. Blender 위쪽 +Z·정면 -Y, glTF 위쪽 +Y·정면 +Z다. 액정 중앙에 `Screen_Front_Anchor`를 넣었으며 액정 메시는 독립 재질이다. 실제 UI 연결·기능은 구현하지 않았다.

모든 메시의 유한 좌표·비매니폴드 모서리 0개·양의 부피를 검사하고 GLB를 재불러와 메시 수·기준점·치수를 확인했다. 게임 배율·수령/보유 동작의 손 접촉은 후속 검수 대상이다. 게임 코드·배포 에셋·저장은 변경하지 않았다.
