# 양옆 외곽 나무 밀도 조정 v4

P2 · ✅ 웹·기존 실행본 적용·자동 검증 / ⏳ 사용자 최종 시각 검수

“옆에 너무 빽빽하다. 평야가 안 보일 정도로 듬성듬성”이라는 요청에 따라 `townBoundaryProps.js`의 좌우 외곽 나무를 총154그루에서74그루로 줄였다. 각 측면은 기존4줄/77그루에서3줄/37그루다. 같은 줄의 남북 간격은 약84~88에서140게임 단위로 넓히고 앞/중간/배경 줄을 엇갈렸다. 두 줄만 남긴 검토본은 배경 빈틈이 커 현행으로 쓰지 않았다.

기존 나무 모델·배율 규칙·북쪽 숲·정원 나무·건물·게시판·정류장·모아·이동 경계·길을 유지했다. 웹과 기존 실행본 리소스의 해당 모듈을 동기화했다. 버스 도착 연출 전용의 먼 배경 숲은 이번 마을 양옆 나무 조정 범위와 구분해 유지했다.

`scratch/check-current-exteriors.cjs`를 웹·기존 실행본 양쪽에 실행해 로딩·건물 충돌·길 표본 차단0건·모든 입구 도달·시계·작은 화면·JavaScript 오류 없음 검사를 통과했다. `web-checks.json`, `desktop-checks.json`과 실제 게임 장면 검사 카메라 전경 `web-overview.png`를 저장했다. 모든 플레이 카메라 각도에서 배경이 완전히 가려짐을 보장하는 검증이나 사용자 시각 채택 완료를 뜻하지 않는다. 설치 프로그램은 재빌드하지 않았다.
