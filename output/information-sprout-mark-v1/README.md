# 안내소 벽걸이 새싹 마크 v1

P1 (Major) · ✅ 모델 제작 / ⏳ 사용자 검수·게임 적용

사용자 참고의 나무 원형 테두리·크림색 바탕·두 잎 새싹을 입체 메시로 제작했다. 둥근 테두리는 연속된 토러스이며 잎과 줄기는 바탕 앞쪽에 돌출되어 있다. 실내 뒤벽 중앙 z=2.03에 배치했다. 지름 .86은 임시 제작 단위다.

- `Information-sprout-wall-mark.glb`: 독립 모델
- `Information-sprout-wall-mark.blend`: 편집 원본/스튜디오 미리보기
- `mark.png`: 마크 단독 확대
- `room-preview.png`, `Office-wall-mark-preview.blend`: 최신 안내소 조합
- `build_mark.py`, `manifest.json`: 재현과 상태

화분은 사용자 선호 v2, 안나는 최신 짧은 조끼 v5, 가구는 통로 확보 v3를 유지한다. 게임은 변경하지 않았다.
