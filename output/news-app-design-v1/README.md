# 소식 앱 디자인 시안 v1

후속: 사용자가 이 디자인을 채택해 게임 적용을 요청했다. 실제 적용·검증 기록은 [게임 적용 v1](../news-app-game-v1/README.md)을 따른다. 아래 게임 미변경/적용 전 표기는 디자인 제작 당시의 이력이다.

2026-10-25 · P1 · ✅ 디자인 시안·브라우저 렌더 / ⏳ 사용자 채택·게임 적용

기존 아이보리·큰 글씨·평면 컬러 방향으로 뉴스 목록과 기사 읽기 두 화면을 제작했다. 실제 게임의 288개 뉴스·원문·출처와 현행 업종 공통 SVG를 사용했다. 목록은 검색·업종 가로 스크롤 필터·기업 표시·큰 제목·요약·기사 읽기로, 상세는 기업 표시·큰 제목·출처·원문·관련 종목 버튼으로 구성한다. 호재/악재 평가나 확정 가격 방향을 자동 표시하지 않는다.

`index.html`, `preview.css`, `preview.js`는 게임과 분리된 HTML/CSS 시안이다. 검색·필터·기사 선택은 미리보기에서 동작하며 관련 종목 버튼은 시안 안내만 표시한다. 실제 게임 파일·실행본·저장은 변경하지 않았다. Blender·이미지 생성은 사용하지 않았다.

`scratch/capture-news-design.cjs`로 288개 목록·업종 필터·검색·원문 3문단·JavaScript 오류 없음을 확인하고 `preview.png`를 렌더했다. 사용자 최종 디자인 채택과 게임 적용 완료를 뜻하지 않는다.
