## 파일과 사용

- `marshmallow-friend-rig.blend`: 텍스처 내장 편집 원본. MarshmallowFriend_Rig 선택 후 Pose Mode에서 본 조작.
- `marshmallow-friend-rig.glb`: 본·웨이트·텍스처·시험 액션 포함 전달본.
- `source.blend`: 제공 모델을 가져온 검사 원본.
- `front.png`, `side.png`, `back.png`, `angle.png`: 원본 외형 검사.
- `rig-rest.png`, `test-*.png`: 리깅 기본 자세와 변형 시험.
- `inspection.json`, `rig-report.json`, `validation.json`: 연결·웨이트·재수입 검사 수치.
- NLA 시험 트랙은 편집 파일에서 기본 mute 상태다. Action Editor에서 QA_LimbSwing, QA_ArmLift, QA_HeadTurn 중 하나를 선택하고 1~25프레임을 확인한다. 시험 액션은 완성된 걷기나 인사 동작이 아니다.

게임 파일과 다운로드 원본은 변경하지 않았다. `inspect_model.py`, `rig_model.py`, `validate_rig.py`는 Blender 5.2 백그라운드 실행으로 재현 가능하다.
