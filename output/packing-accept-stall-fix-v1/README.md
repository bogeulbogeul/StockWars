# 잡화점 알바 수락 멈춤 수정 — 2026-10-26

✅ 구현·재현 회귀 검사 완료. 사용자 최종 플레이 검수는 별도다.

## 재현과 원인

현재 모델에서 봉봉이의 몸 반경은 33이다. 기존 안내 경로는 플레이어를 사각형 장애물로 만들고 NPC 반경만큼 다시 확장했다. 플레이어가 대각선으로 가까이 있으면 실제 캐릭터 원형 충돌은 겹치지 않더라도 NPC의 출발점이 이 사각형 안에 들어갔다. 경로 탐색이 예외로 종료되어 대사창은 닫히고 작업대 안내는 시작되지 않았다.

기본 정면 위치에서는 성공했지만 `(0,160)`, `(-120,160)`, `(-180,100)`, `(-160,100)` 등 실제로 서 있을 수 있는 위치에서 재현했다. 좌표는 잡화점 내부 월드 X/Z다.

## 수정

- 플레이어 회피에 원형 몸 간격과 여유를 사용한다. 가구와 벽의 기존 충돌 범위는 유지한다.
- 왼쪽 통로가 막히면 작업대 앞쪽으로 안내한다. 설명을 닫은 뒤 같은 안전 경로로 걸어 돌아와 작업대 앞을 비운다.
- 모든 경로가 막히면 빈 화면에 멈추지 않고 봉봉이가 길을 비켜 달라고 말하며 WASD 입력을 허용한다. 플레이어가 이동하면 경로를 다시 검사한다.
- 봉봉이 안내 중에도 작업대 대기 상태를 유지해 다른 F 대화가 중복으로 끼어들지 않게 했다.
- 순간이동·몸 배율 변경 없이 기존 걷기와 가리키기를 사용한다. 포장 자동 시작은 추가하지 않으며 작업대에서 새 F 입력이 필요하다.

## 검증

- 관련 단위 테스트 7개 통과: 대각선 근접 4개 위치, 원형 간격, 앞쪽 대체 경로, 가구 우회, 작업대 F 범위.
- 실제 실내 모델 위치 검사에서 기존 경로 실패 4개→0개.
- `scratch/check-packing-accept-diagonal.cjs`: 웹/기존 실행본의 첫날에서 수락 위치 `(0,160)` 재현 회귀. 안내 대사→작업대 이동→F 시작→미완료 종료→새 F 재개 통과, 브라우저 오류 없음.
- `scratch/check-packing-accept-detour.cjs`: 기존 실행본 일반 모드에서 왼쪽 통로를 막는 `(-180,50)` 위치로 검사. 작업대 앞 대체 안내·복귀·실제 입력 이동·F 포장 시작 통과, 브라우저 오류 없음.
- 변경한 게임 소스 4개 웹/기존 실행본 SHA256 일치. 설치 프로그램 재빌드는 수행하지 않았다.
