# 토리의 기능별 첫 주식 안내 v2 — 2026-10-26

후속 사용자 요청: 이전 튜토리얼을 많이 참고해 기능을 하나하나 설명하고 정해진 예산 안에서 매수할 종목을 추천한다. 컴퓨터를 켜자마자 매수시키지 않고 회사 정보를 먼저 확인한다.

## 수업 흐름

컴퓨터에서 주식 목록 → 연습용 회사 선택 → 기업 정보 11단계 → 차트 6단계 → 주문 11단계 → 확인 완료 → 실제 매수. 하단에 단계 제목/번호·토리 대사·이전/다음을 제공한다. 해당 UI를 초록 테두리로 강조한다. 초상화는 없다. 홈 6·목록 10·계좌 6·거래 내역 4단계도 각 화면에서 볼 수 있다. 총 54개 설명이다. 회사 선택 때 기업 정보가 먼저 열리며 다른 회사를 선택하면 그 회사의 검토 단계를 초기화한다. 메뉴/탭을 수동으로 먼저 눌러도 기업 정보·차트·주문 안내 완료 전에는 첫 매수를 실행할 수 없다. 설명 버튼 자체는 매수하지 않는다.

참고: components/tutorial/compactAnnaLessons.js, annaLaterLessons.js의 주식 지분·가격·등락·차트 기간·시장가/지정가·매수/매도·평가/실현 손익·예산·체결/수수료·뉴스 기대 반영 순서. 현재 앱 이름/색/독립 소식 앱/거래 내역 탭/슬롯 폐지에 맞게 원고를 고쳤으며 구형 UI나 슬롯·능력치 수업은 복원하지 않는다. 기업 정보는 사업 개요·회사 ID/가격·PER·PBR·ROE·배당률·시가총액·52주 범위·위험도/변동성·관련 소식 순서다.

## 추천과 실제 주문의 일치

FirstTradeBudget.js를 표시와 주문 검증이 공통 사용한다. 예산=min(1500, 실제 현금), 0 미만/비정상 현금은 0이다. 기존 첫 6개 적격 종목 순서를 유지한다. 후보 카드에 회사/섹터 아이콘·1주 가격·실제 현금에서 가격을 뺀 잔액을 표시한다. 예산에 맞는 연습 후보이며 수익성/안전성을 보장하는 추천이 아니다. 현물 1주·시장가·수수료 없음·자격증·한 번만 매수·일반 계좌 분리·성공 후 기존 스토리 진행은 유지한다. 검토 완료는 세션 UI 상태이며 재개방/회사 변경 시 초기화한다.
