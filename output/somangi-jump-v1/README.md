# 소망이 제자리 점프 v1 — 2026-10-19

둥근 배·둥근 손끝 모델로 준비 → 이륙 → 공중 → 착지 → 기본 자세의 1.5초 `Jump` 클립을 제작했다. 기본 타원 눈과 미소를 유지한다. Root를 통째로 높이 이동시키며 최대 높이는 0.45다. 공중에서는 팔을 최대 30도 벌리고 다리 전체를 작게 회전한다.

준비·착지 때 몸통만 살짝 낮아 보이도록 Root를 낮추고, 다리 본 위치를 반대로 보정해 발을 바닥에 유지한다. 메시/본 스케일은 변경하지 않으며 배를 찌그러뜨리거나 다리 길이를 늘리는 방식은 아니다. 기존 모션 파일은 변경하지 않는다.

- `jump-front.gif`, `jump-side.gif`: 정면·측면 실제 재생.
- `somangi-jump.glb`, `somangi-jump.blend`: 단일 Jump 클립 모델과 편집본.
- `motion.json`, `validation.json`: 프레임별 높이와 준비/착지 값, 바닥 침투·다리 길이·배 형상·루프·GLB 재수입 검사.

게임 설치·점프 키·수평 이동 중 점프·장애물 넘기 판정은 포함하지 않는다. 이 파일은 Root 높이 이동을 클립에 포함하므로 추후 런타임 물리 높이와 중복 적용하지 않도록 연결해야 한다.
