`Space`로 정지·이동 중 점프한다. 공중 중복 시작은 차단하며 착지하면 이동 여부에 따라 걷기/기본 자세로 복귀한다. 먹는 중에는 점프하지 않는다. 일반 마을·실내와 전시의 도착 이동 구간에 연결했다. 전시 대화/선택 중에는 기존 입력 차단을 유지한다. 입력창·버튼·링크나 차단된 장면에서는 Space 기본 동작을 보존하고, Space가 다른 이동키로 설정된 경우 기존 키 배정을 우선한다.

기존 게임 모델, 걸음 속도·다리 연결 보정·얼굴·먹기·수평 이동/충돌은 변경하지 않는다. 점프로 벽·가구를 넘는 기능은 추가하지 않는다. 원래 지면의 이동 충돌 검사를 계속 사용한다. 코드로 생성하는 동작이므로 별도 모델 다운로드는 없다.
