# 소망이 먹기 — 둥글고 매끄러운 몸통 v20

P1 (Major) · ✅ 몸통 국소 보정·검사 / ⏳ 사용자 외형 검수

사용자 확대 이미지에서 몸통 옆과 아래에 남은 각진 굴곡을 부드럽게 다듬었다. v19에서 채운 허리 폭을 유지하는 방향으로 몸통 표면만 국소 평활화하고 부피를 보정했다. 보정량에는 부드러운 상한을 두어 몸통 비율이 크게 바뀌지 않도록 했다. 머리·얼굴·팔·손·발·먹기 동작과 머리 연결부는 유지했다.

- 실제 몸통 정점의 최대 이동: 0.00693 모델 단위.
- 181개 시점: 편집 구간 외 차이 최대 0.00000012, 머리 차이 최대 0.00000012, 손바닥 차이 최대 0.00000006.
- 머리·몸통 경계에 열린 변 0. GLB 재수입 후 연결 경계 정점 425쌍의 벌어짐 0.
- 빵과 머리의 삼각형 교차 0.

`somangi-eat.glb`는 전달용, `somangi-eat.blend`는 편집용이다. `eat-rear.gif`는 최종 GLB를 다시 불러와 촬영한 뒷모습이며, `detail-back/013.png`는 몸통 확대 촬영이다. 검사 결과는 `round-body-validation.json`, `export-junction-validation.json`, `export-validation.json`에 기록했다. 게임에 설치하지 않았고 이전 제작본을 보존했다.
