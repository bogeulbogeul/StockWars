# 소망이 바닥 웅크림 수면 v1

사용자 요청: “소망이가 첫날 바닥에 쭈그려 자는 애니메이션도 만들어줘.”

**P1 (Major) · ✅ 전용 모션 제작·접지/연결 시점 검사 / ⏳ 사용자 자세 검수·첫날 게임 연결.**

- 현재 `somangi-game-v1/somangi-walk.blend`를 사용한다. v43 계보의 원본 정점 좌표와 큰 머리·체형·통팔을 유지하고 v6 `sleepy` 얼굴을 GLB에 포함했다. 구형 소망이·NPC 모델을 복원하지 않는다.
- `FloorSleep_Down`: 3.2초. 서 있는 자세에서 바닥으로 내려와 발을 모으고 고개를 숙인다.
- `FloorSleep_Idle`: 4초 반복. 체형 스케일을 바꾸지 않고 몸과 고개가 작게 움직이는 호흡이다.
- `FloorSleep_Up`: 3.2초. 같은 위치에서 일어나는 복귀 동작이다.
- 기존 다리 본에 발 본을 추가하고 발목 영향도를 연속적으로 나눠, 접힌 다리에서도 발바닥이 편 자세를 유지한다. 팔꿈치 본·체형 변형·소품·의상은 추가하지 않았다.
- `somangi-floor-sleep.blend`는 제작 원본, `somangi-floor-sleep.glb`는 세 동작을 포함한 전달본이다. GLB는 원래 기준 높이와 축을 유지하며 바닥 Z는 -0.950641572다.
- `preview.mp4`는 잠들기와 호흡 한 주기, `sleep-idle.gif`는 호흡 반복이다. 영상은 실제 제작 리그의 검수용 스튜디오 렌더이며 게임 화면 캡처가 아니다.

## 검증 범위

`build.json`에 원본 정점 좌표 SHA256 보존을 기록했다. `verification.json`의 총147개 표본에서 바닥 최저점 오차는 약0.0000000601 원본 단위다. 잠들기→수면, 수면 반복 양끝, 수면→일어서기, 기본 자세 복귀의 정점 차이는 0이다. 모든 표본 좌표는 유한하다. 전체 자기 관통 검사나 실제 집 바닥·벽·가구 접촉 검수 완료를 뜻하지 않는다.

이번에는 제작 폴더에만 저장했다. 게임/기존 실행본 리소스·첫날 취침 시간·대사·저장·엔딩 흐름은 변경하지 않았다. 실제 첫날 취침에 연결할 때는 현재 걸어 도착한 위치를 유지하고, 바닥/주변 가구·입력 차단·표정 복귀를 검증해야 한다.
