# 사이퍼 증권 둥근 화분 v1

사용자 참고의 둥근 아이보리 몸체·파란 윗부분 띠·넓은 초록 잎을 Blender로 제작했습니다.
화분은 윗면이 열린 용기이며 흙은 테두리보다 0.04 낮게 배치했습니다.
7개 입체 잎과 가는 중앙 잎맥·줄기로 구성합니다.

- `Cipher-cozy-plant.blend/.glb`: 편집 원본/게임 모델.
- `plant-preview.png`: 독립 모델 렌더.
- `game-plants.png`: 로비 소파 옆 배치.
- 제작 스크립트와 `exterior_geometry.py`: 재제작용.

화분 반지름 약 0.274, 용기 높이 0.43. 게임은 100배로 기존 양쪽 화분 위치에 설치합니다.
소파 위치와 현관·문 동선은 유지하며 화분 몸체 충돌 반경을 28로 맞췄습니다.
게임/실행본에 반영했고 로비 회귀 및 이동/출입 검증을 통과했습니다.
