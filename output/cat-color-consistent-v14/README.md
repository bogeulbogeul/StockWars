# 고양이 전체 PNG 공통 RGB v14

사용자 요청에 따라 최신 v13의 모든 전달 PNG·모든 프레임에 공통 재질 RGB 기준을 베이크했다. 기존 제작 이력과 게임 파일은 덮어쓰지 않는다.

- 털 기본색은 RGB(65,59,62). 각 그림의 주 기본색 R값을 기준으로 밝기 편차를 보정하고 같은 연속 명암 램프를 사용한다.
- 볼털·가슴털의 미세한 경계를 보존하도록 명암 단계를 유지한다. 2색 강제 양자화와 프레임별 다른 팔레트를 사용하지 않는다.
- 눈썹·윤곽·분홍 귀·눈 흰자·호박색 홍채에도 같은 재질별 색상 변환표를 사용한다. 자세와 그림자 면적 자체는 변경하지 않는다.
- canonical sprite-gen recolor의 exact RGB 베이크 사용. 원본 PNG·spec·베이크 보고서는 bake-input/ 및 baked/에 보존한다.
- alpha·시트 좌표·프레임 순서·160ms 재생 유지 검사. 정지와 걷기 중립은 같은 픽셀을 공유한다. 정면 앉기는 v13에서 수정한 무릎 위 손 자세를 유지한다.
- 같은 명암 단계라도 각 자세의 그림자 면적 차이로 전체 평균 밝기는 완전히 같지 않을 수 있다. 프레임별 재질 기본색과 색상 기준을 고정한 버전이다.
- 게임에는 설치하지 않았다. 최종 외형 채택은 사용자 확인 후 별도다.

전달: sprite-sheet-alpha.png, manifest.json, frames/ 아래 PNG. overview.png는 전체16자세, preview.html은 강아지 비교 재생이다. validation.json과 png-color-audit.json에 일치 검사를 기록한다. lock_colors.py가 재질별 공통 변환과 베이크를 실행한다.
