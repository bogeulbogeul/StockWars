# 소망이 사용자 빨간 표시 기준 분리 — 2026-10-23

P1 (Major) · ✅ 표시 기준 재분리·원형/연결 검사·걷기 미리보기 / ⏳ 사용자 절단 위치·모션 검수.

입력은 얼굴 보정을 마친 `../somangi-face-smooth-v1/somangi-face-smooth.glb`, 절단 기준은 사용자가 올린 `reference-marked.png`다. 이전의 자동 연결 거리 경계를 대체해 표시한 목 아래·양팔 안쪽·아랫배 밑선의 정면 곡선을 모델 좌표에 대응시켰다. 정면 표시의 두께와 원근 때문에 정확한 3D 절단선 해석은 검수 이미지로 확인해야 한다. 측후면 경계는 같은 곡면 절단식을 적용해 닫았다.

## 형태와 구조

겉면 삼각형은 절단 경계에서 세분화만 하고 표면 위치·UV·법선을 보간해 유지했다. 체형·팔다리를 새로 만들거나 평활화하지 않았다. 추가 마감·안쪽 연결부는 원본 부피 내부에 있다.

메시 오브젝트는 하나이며 머리·몸통·양팔·양다리의 6개 연결 조각으로 구성된다. 목 아래 표시도 반영해 `Part.Head`/Head 본을 추가했다. 편집본의 `Part.Root`, `Part.Head`, `Part.Arm.L/R`, `Part.Leg.L/R` 그룹으로 선택한다. 절단 경계 양쪽은 같은 관절 가중치로 움직이며 주름 부근의 좁은 구간에서만 부드럽게 연결된다.

## 결과

- `somangi-rest.glb`: 정지 모델·리그, 메시 오브젝트 1개.
- `somangi-walk.glb`: 같은 구조의 `Walk_InPlace` 걷기 클립.
- `somangi-motion-ready.blend`: 편집본.
- `cut-boundary-review-front.png`: 실제 몸통 절단 경계의 빨간 검수 표시. 원본 모델·텍스처에는 빨간 표시를 넣지 않았다.
- `walk-preview.gif`: 새 GLB 재수입 후 정면·측면 걷기.

걷기 박자·보폭은 직전 원형 유지 버전과 같다. 이전 모델 걷기의 반대 팔·다리 교대를 참고한 0.75초 제자리 걷기다.

## 검사

`shape-validation.json`: 단일 메시·6개 조각. 편집본 원본 표면 거리 오차 0, 정지 GLB 재수입 오차 약 1.65e-7, 내부 추가 정점의 원본 부피 밖 돌출 0.

`seam-validation.json`: 절단 경계 공유 위치 2,040곳을 97개 시점에서 검사. 경계 양쪽 최대 간격 약 1.20e-7 모델 단위.

`validation.json`: 새 걷기 GLB 97개 시점. 루프 오차 0, 완전 고정 몸통 구간 형태 오차 약 9.31e-10, 지지 발 바닥 아래/위 오차 약 0.000225/0.000440 모델 단위.

정지 외형 보존과 관절의 운동 변형은 구분한다. 표본 검사가 모든 자세의 무간섭이나 최종 사용자 승인을 뜻하지 않는다. 게임·실행본·삭제한 캐릭터는 변경하지 않았다.

재현: Blender에서 `build.py`, `validate_shape.py`, `validate_seams.py`, `preview.py`, `render_review.py`를 실행하고 Pillow가 있는 Python에서 `make_previews.py`를 실행한다. 각 소스는 300줄 미만이다.
