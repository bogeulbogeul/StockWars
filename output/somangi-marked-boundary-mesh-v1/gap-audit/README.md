# 걷기 중 절단 경계 틈 검사 — 2026-10-23

P1 (Major) · ✅ 검사 완료. 모델 파일은 수정하지 않았다.

대상은 상위 폴더의 `somangi-walk.glb`다. SHA-256은 `report.json`에 기록했고 검사 전후 일치했다.

## 결과

내보낸 실제 GLB를 Blender로 재수입하고 한 주기의 601개 시점에서 같은 정지 위치를 공유하는 12,030개 정점 쌍을 비교했다. 목·양어깨에서 간격은 0, 양골반에서 최대 약 1.20e-7 모델 단위였다. 루프 오차도 0이었다. 검출 기준 2e-6보다 작아 절단 경계가 분리되는 현상은 검출되지 않았다.

정면·오른쪽·후면·왼쪽에서 주기별 8자세, 총 32장의 확대 렌더를 확인했다. 그림자를 없애고 흰색 불투명 표면/자홍색 배경으로 바꾼 진단 렌더 8장도 확인했다. 겨드랑이에는 팔과 몸 사이의 외부 공간이 있으며, 검게 보이는 안쪽 선은 접힘과 음영이 강조된 부분이다. 허벅지 윗선·골반에는 발을 들 때 접히거나 겹쳐 보이는 선이 남아 있다. 내부가 뚫려 보이는 절단면은 확인하지 못했다. 경계 연속성 통과가 이런 시각적 접힘이나 자기 교차가 모두 해결됐다는 뜻은 아니다.

## 증거

- `report.json`: 시간 표본·부위별 간격·대상 파일 해시·시각 검사 기록.
- `all-views.png`: 네 방향 × 여덟 자세 확대 모음.
- `findings.png`: 겨드랑이·허벅지·골반의 눈에 띄는 선 확대.
- `front/`, `right/`, `back/`, `left/`: 개별 원본 렌더.
- `diagnostic-*.png`: 그림자 없이 배경 관통 여부를 보는 진단 렌더.

사용자 요청은 검사이므로 외형·스키닝·모션·게임 파일을 수정하지 않았다. 이번 결과는 표본 기반 검사이며 모든 시점·모든 카메라에서의 완전한 무간섭 보장은 아니다.
