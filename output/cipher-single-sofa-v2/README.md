# 소망이용 1인 소파 크기 보정 v2

이전 v1 원본을 보존하고 폭/깊이를 12% 줄였습니다.
좌판 높이 49는 유지하고 그 위의 등받이·팔걸이 높이를 15% 낮췄습니다.
크기 약 폭 107·깊이 88·높이 92 게임 단위이며 파랑/아이보리·목재 다리를 유지합니다.

`Cipher-single-sofa.blend/.glb`는 수정본, `game-sofas.png`는 게임 배치입니다.
양쪽 소파 모델과 충돌 크기를 게임/실행본에 반영했습니다.
`../cipher-single-sofa-sit-check-v2/`에서 기존 모션의 정렬 보정과 표본 침범 검사를 다시 수행했고 표본 침범 0입니다.
해당 앉기 장면은 별도 프리뷰이며 게임의 실제 착석 기능은 아직 연결하지 않았습니다.
