# 소망이 빵 먹기·음료 마시기

## 후속 정측면 검수 — 어깨 보정 필요

사용자 지적에 따라 실제 GLB를 정측면에서 재촬영했다. `bread-side/016.png`, `drink-side/016.png`에서 팔을 들 때 어깨 뒤 연결부가 압축되어 접히고 주름처럼 찌그러지는 현상을 확인했다. 기존 접합부 간격 0은 연결 경계의 벌어짐 검사 결과이며 관절 주변의 자연스러운 곡면을 보증하지 않는다. 현재 동작은 어깨 변형 보정과 재검수가 필요하며 최종 채택 완료로 취급하지 않는다. 이번 검수에서는 모델·모션을 추가 수정하지 않았다.

검은 눈을 보정한 `../somangi-black-eyes-v1/somangi-black-eyes.blend`가 기준이다. 캐릭터의 정점·면·UV, 본·웨이트, 검은 눈 재질과 기본 텍스처를 유지한다. 두 동작을 각각 독립 GLB·Blender 파일로 제작했고, 게임 파일은 변경하지 않았다. 보류된 벤치 모션을 게임에 적용하지 않는다.

- `somangi-bread.glb` / `.blend`: `Eat_Bread` 3초. 두 손에 든 빵을 입으로 가져가 작게 고개를 움직이며 먹고, 다시 내린다.
- `somangi-drink.glb` / `.blend`: `Drink_Beverage` 3초. 한 손에 든 컵을 입으로 가져가 기울여 마시고, 다시 내린다.
- `bread-preview.gif`, `drink-preview.gif`: 각 동작의 정면·사선 반복 미리보기.

빵과 컵은 별도 소품 오브젝트다. 각 GLB는 캐릭터와 소품의 트랙을 하나의 클립으로 묶어 함께 재생된다. 시작·끝은 소품을 들고 있는 동일한 대기 자세라 반복 가능하다. 빵이 줄어들거나 입 모양이 바뀌는 연출은 넣지 않고 기존 외형을 유지했다.

`validation.json`은 각 GLB 181개 시점의 관절 접합부 간격, 바닥 침범, 시작·끝 자세 차이와 검은 눈 재질 설정을 기록한다. 메시·UV 해시는 원본과 일치한다. 소품 접촉과 외관은 실제 내보낸 GLB의 정면·사선 렌더로 확인하며 모든 자기 충돌을 자동으로 검증한 결과는 아니다.

두 동작의 정면·사선 렌더 총 144프레임에서 양쪽 눈 내부 영역 288개를 검사했다. 눈 내부 RGB 중앙값의 최대 채널은 1/255로 검게 유지됐다. 안티앨리어싱 경계는 제외하며 해당 스튜디오 조명에서 확인한 결과다. 상세 수치는 `eye-validation.json`에 기록했다.
