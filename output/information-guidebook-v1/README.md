# 안내소 지도 옆 가이드북

사용자 요청으로 지도 거치대 가까이에서 F키 또는 화면의 가이드북 보기 버튼으로 생활 가이드북을 읽을 수 있게 했다. 지도 모델의 실제 월드 경계에서 90 게임 단위 이내인지 검사하며, 원격 열기나 자동 이동은 추가하지 않는다. 첫걸음·마을 시설·주식·소식과 분석·생활과 조작 5개 목차를 제공한다.

아이보리 읽기 창에서 목차를 바꿔 읽고 Esc/닫기 버튼으로 같은 위치에 돌아온다. 열기/닫기에서 누른 이동키를 비우고 열린 동안 이동·점프·대사 진행을 막는다. 자동 도보·장면 전환·다른 모달·착석 중에는 열지 않는다. 안내소 창구 착석을 기다리는 전시 단계에서도 지도까지 직접 걸어가 읽을 수 있다. 읽기 자체는 스토리·보상·저장 상태를 변경하지 않는다.

`InformationGuidebook.js`와 `information-guidebook.css`를 추가했다. 공통 실내 장면은 방의 createInteraction 팩토리를 지원하며 안내소에서만 가이드북을 생성한다. 일반 안내소와 첫날 전시가 같은 구성 요소를 사용한다. 전시 키 처리는 가이드북을 먼저 확인해 기존 F 대사 진행과 충돌하지 않게 했다. 기존 지도·창문·새싹·가구 GLB는 변경하지 않았다.

`scratch/check-information-guidebook.cjs`는 준비된 실내의 충돌상 유효한 지도 접근 위치를 찾아 근접 시에만 표시·F키/버튼 열기·목차 변경·이동/대사 차단·Esc 닫기 후 실내 유지·재열기·390×844 화면 폭·실내 숨김 시 닫기를 검증한다. 테스트용 직접 좌표 설정은 검증 스크립트에만 있다. 실제 도보 입장 전체의 재검증을 의미하지 않는다. 웹/기존 실행본 모두 통과했고 checks.json과 실제 화면 PNG를 기록했다. 모바일 렌더를 열어 확인했다. 실행본에서 참조하지만 누락돼 로딩을 막던 기존 VillageMapIntro.js도 동일 모듈로 보완했다. 설치 프로그램 재빌드·사용자 최종 플레이 검수는 별도다.
