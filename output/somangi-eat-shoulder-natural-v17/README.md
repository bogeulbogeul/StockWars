# 소망이 먹기 — 어깨 접힘·후면 원본 곡선 보정 v17

P1 (Major) · ✅ 국소 보정·내보내기·검사 / ⏳ 사용자 외형 검수

팔을 들 때 반대편 옆면에 나타나던 굵은 접힘을 팔 표면에 한정해 매끈하게 다듬었다. 팔 전체의 표면을 둥근 공이나 다른 모양으로 교체하지 않고, 기존 메시를 국소 평활화한 뒤 부피를 보정했다. 손바닥 정점은 기존 위치에 고정했다. 원래 빵 잡기·크기 감소·먹는 입·웃는 입·검은 눈을 유지한다.

이전 몸통 보정에서 후면 허리 옆은 좁아지고 골반 옆은 넓어진 것을 원본 v3와 비교해 확인했다. 후면과 측면의 곡선을 원본 Root 표면에 맞춰 복원하고 연결부를 부드럽게 이어 주었다. 전면 배 중앙과 머리·얼굴·다리·머리 연결면은 이번 수정 대상에서 제외했다. 어깨 표면과 복원한 후면은 정점 위치가 바뀌므로 모델 전체가 이전 버전과 정점 단위로 동일하다는 뜻은 아니다.

## 검증

- 181개 시점: 편집 구간 외 정점 차이 최대 0.00000012, 머리 최대 0.00000012, 손바닥 최대 0.00000006.
- 머리 연결면의 아래 끝은 몸통 내부로 최소 0.003639 겹침. 연결면 자체의 위치·모션은 v16과 동일.
- 실제 GLB 재수입 후 181개 시점: 머리 경계 390개 지점, 재질 경계 정점 425쌍의 벌어짐 0.
- 빵·윗면 장식과 머리의 삼각형 교차 0.
- 원본과 비교한 후면 표본: z=-0.4,y=0의 옆 폭 편차는 0.01607 → 0.00101, z=-0.2,y=0.18의 편차는 -0.02126 → -0.00041 모델 단위로 감소.
