사용자의 추가 요청으로 모아·토리 조끼, 봉봉 앞치마·어깨끈·허리끈을 v4보다 몸에 가깝게 조절했다. 몸통·머리·팔다리·색/재질·본·웨이트·모션 키와 v4의 의상 길이는 유지한다. 의상 정점 위치와 법선 이외의 바이너리 보존을 `geometry-validation.json`에 기록했다.

조끼 여유는 `원래 여유 × .36 + .003`, 허리끈은 `× .34 + .003`, 어깨끈은 `× .36 + .003`으로 줄였다. 앞치마 앞판은 `× .40 + .004`, 뒤쪽은 리본을 구분할 수 있도록 최대 `× .60 + .004`를 사용한다. 원본 모델 좌표 기준이며 몸체를 줄이는 조절이 아니다. 조끼 정점 표본의 중앙 여유는 약 .0234에서 .0114로 줄었다. 주머니·테두리·리본의 돌출도 줄이되 식별 가능한 형태를 유지한다.

실제 GLB의 정면·측면·후면·사선 12장을 확인했다. `overview.png`는 왼쪽부터 모아·토리·봉봉이다. 기존 애니메이션 24개와 토리 정지 자세를 포함한 800개 시점에서 의상/몸통 간격, 다리 윗단과 어깨 연결을 검사했다. 정점 표본에서 의상이 몸통 내부에 들어간 경우와 연결 이탈, 브라우저 오류는 없었다. 자세별 최소 의상 여유 기준은 .006이며 이는 의도적으로 줄인 간격에 대한 검사 기준이다. 모든 표면 간 연속 충돌을 증명하는 검사는 아니다. `motion-validation.json`, `motion.log`, `*-poses.png`.
