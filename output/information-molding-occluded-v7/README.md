# 안내소 수평 몰딩 v7

P2 · ✅ 모델 수정·실제 렌더 / ⏳ 사용자 시각 검수·게임 적용

v6의 꺾인 연결부를 폐기하고 v4 원본에서 수평 몰딩을 다시 제작했다. 몰딩의 수평 형태를 유지하며 높이를 .10 내려 현관 처마 목재와 접촉시켰다. 현관 뒤쪽 구간은 X ±.728, Y -.875를 기준으로 정리해 기와 위 돌출을 없앴다. 지붕·문·창·계단과 나머지 254개 메시의 월드 정점 좌표는 유지했다.

몰딩의 닫힌 메시·절단 구간의 불필요한 잔존 부피를 검사했으며 전체/접합부/현관 실제 렌더를 저장했다. `Information-clean.glb`, `Information-horizontal-molding.blend`가 수정본이다. 웹·실행본은 교체하지 않았다. 시안과의 최종 일치 여부는 사용자 검수 대기다.
