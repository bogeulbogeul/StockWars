# 오프닝 기본 자동 진행 + 대사 클릭 — 2026-10-29

사용자 요청으로 오프닝은 입력 없이 재생되고 대사창을 누르면 남은 시간을 기다리지 않고 다음 대사/장면으로 넘어간다. Enter/Space 입력도 유지한다.

- CinematicDialogue: 선택적 autoAdvanceMs 옵션을 추가했다. 기본값0은 기존 클릭 전용이다. 수동 클릭 시 이전 타이머를 취소하고 새 대사의 대기를 다시 시작하며, 장면 교체/건너뛰기/종료 시 남은 이벤트·타이머를 정리한다. 로딩 중 빈 iframe에는 타이머를 걸지 않는다.
- OpeningSequence: 기존 그림별12/16/19/19/21/23초를 각 장면의 대사 수로 나눠 자동 진행한다. 기본 전체 그림 길이는 약110초이며 클릭하면 짧아진다. PNG/그림 애니메이션/대사 원문은 변경하지 않았다.
- BusArrival: 준비 완료 후5초→3초→8초로 세 문구/단계를 자동 진행하고 게임으로 연결한다. 문구 클릭은 즉시 진행하며 기존 전체 건너뛰기·로딩 제한·로딩 중 캔버스 숨김은 유지한다.
- 첫날 밤 등 다른 연출은 기존 클릭 전용이다. 자동 진행 옵션을 오프닝에만 전달한다. 게임 무음 정책은 유지한다.

세 JS 파일을 웹과 기존 실행본 리소스에 동기화했다. 설치 프로그램은 재빌드하지 않았다.
