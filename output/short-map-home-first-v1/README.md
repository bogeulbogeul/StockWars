# 초반 소개 단축·집 내부 우선 — 2026-10-25

✅ 구현 및 자동 검증. 사용자 최종 시각·플레이 검수는 별도다.

## 새 흐름

정류장 모아 깨우기 → 안내소로 직접 따라가기 → 문 열고 입장·맞은편 의자에 앉기 → 입주 신청/이름/휴대폰 → 지도 안내 4단계 → 모아와 집까지 걷기 → 모아 선입장 후 소망이 입장·집 내부 첫 공개 → 집에서 생활 자금 이야기 → 함께 나와 은행까지 걷기 → 계좌·정착 자금 상담 → 은행 밖에서 활동 순서 선택.

이후 잡화점 알바·토리 트레이닝룸 수업은 선택한 순서와 기존 기능을 유지한다. 경제 수치·서류/휴대폰 전달·수업·포장 시작 조건은 바꾸지 않는다.

## 변경

- 야외 소개 대사 34개와 건물별 반복 정지를 지도 대사 4개로 대체했다. 초기 이동 목적지는 가구점이 아닌 안내소다.
- 현대 지도와 같은 실제 마을 배치를 사용하고, 모아 대사에 따라 집·은행·잡화점·증권사 표식을 고정 강조한다. 안내 창에 별도 닫기 버튼을 추가하지 않고 기존 대화 삼각형으로 4단계를 넘긴다. 다른 시설은 지도에 위치만 남긴다.
- 집 내부 대사 5개를 은행보다 앞으로 이동했다. ‘집을 아직 안 봤다’는 은행 뒤 대사를 제거하고, 활동 선택은 은행 상담 뒤에 진행한다.
- 안내소의 기존 의자 내려오기·모아 선행 퇴장을 집 이동에도 재사용했다. 집에서 은행으로 출발할 때 플레이어가 걸어서 문 옆을 비우고 모아가 먼저 나간다. 외부에서 모아가 문 앞으로 충분히 나가 기다려 뒤따르는 플레이어와 겹치지 않게 한다.
- 안내 목적지에 플레이어가 먼저 서 있어도 모아가 밀고 들어가지 않고 가까운 위치에서 도착을 인정한다.
- 과거 대본과 순회 계획은 이관용으로 보존한다. 기존 방문자는 같은 대사/활동으로, 순회 중이던 방문자는 안내소 이동으로 이관하며 저장을 지우지 않는다.

## 검증

- 관련 단위 테스트 22개 통과. 두 활동 순서의 지도 4단계·집/은행/선택 순서·보상/시험/수면 조건·구 진행 이관·문/실내 경로·착석/카메라 회귀 검사 포함.
- `scratch/check-short-map-home-first.cjs`: 실제 지도 강조 4단계, 지도 닫힘, WASD 추종, 집 내부가 은행보다 먼저 나오는지, 집 퇴장 후 은행 도착 검증. 웹과 기존 실행본 리소스에 적용했다.
- `scratch/check-home-to-bank-departure.cjs`: 집 내부에서 문까지 걷기·모아 선행 퇴장·외부 합류 확인. 실행본 최종 대기 위치 수정 후 442개 표본, 오류 없음.
- 첫 야외 소개 34개→지도 4개. 첫 집 내부까지 계획상 진행 항목은 131→49로 줄었다.
- 기존 실행본 리소스를 동기화했다. 설치 프로그램 재빌드는 수행하지 않았다.

지도/집 내부 렌더는 `scratch/moa-short-map-intro.png`, `scratch/home-before-bank-intro.png`에서 확인했다.
