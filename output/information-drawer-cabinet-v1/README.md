# 안내소 낮은 서랍장 v1

P1 (Major) · ✅ 모델 제작 / ⏳ 사용자 검수·게임 적용

밝은 목재 상판·크림색 외함·연초록 서랍 앞판·둥근 목재 손잡이의 낮은 3단 서랍장이다. 안나의 의자 옆, 화면 오른쪽에 배치했다. 폭 .90·깊이 .70·높이 .86은 임시 제작 단위다. 의자와 옆 간격 .455, 뒷벽 하단 벽판과 .15를 확보했다.

- `Information-drawer-cabinet.glb`: 독립 모델. 서랍별 `Drawer_1_Slide`~`Drawer_3_Slide` 노드 포함
- `Information-drawer-cabinet.blend`: 편집 원본, 기본 서랍 닫힘
- `cabinet.png`: 단독 미리보기
- `drawer-open-check.png`: 위 서랍을 .22 꺼낸 형상 확인
- `room-preview.png`, `Office-cabinet-preview.blend`: 안나 의자 옆 배치
- `build_cabinet.py`, `manifest.json`: 재현과 치수/배치

서랍은 앞판만이 아니라 바닥·양옆·뒷판을 가진 분리된 상자다. 열림은 제작 확인용이며 게임 입력·애니메이션·아이템 보관 기능은 연결하지 않았다. 조합 장면은 최신 짧은 조끼 v5 안나를 사용한다. 기존 모델·게임은 변경하지 않는다.
