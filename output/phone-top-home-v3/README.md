# 상단 홈 화면 버튼만 유지 v3

사용자 요청으로 하단 홈 화면 버튼의 HTML·클릭 연결·CSS를 제거했다. 공통 앱 화면 위쪽의 ‹ 홈 화면 버튼을 유지한다. P 열기/닫기와 launcher 숨김은 유지하며 하단에 별도 내비게이션 공간을 예약하지 않는다.

웹 및 기존 실행본 resources/web의 PhoneHome.js, PhoneHomeTemplate.js, phone-home.css를 동기화했다. scratch/check-phone-top-home.cjs로 8개 앱 PC/모바일 크기에서 하단 버튼 없음·상단 버튼 표시·클릭 후 홈 복귀를 확인한다. 결과와 실제 화면은 같은 폴더에 저장한다. 설치 프로그램 재빌드는 하지 않았다.

## 사용자 확정

사용자가 최신 화면 확인 후 이대로 게임 적용을 요청해 현행 채택본으로 확정했다. 웹/기존 실행본 파일 해시 일치를 재확인하고 기존 실행본에서도 8개 앱 상단 홈 버튼을 검증했다.
