# 할 일 앱 2D 디자인 게임 적용 v1

사용자 확정 시안을 현행 스마트폰 할 일 앱에 연결했다. 아이보리 바탕·라벤더 진행도·큰 글씨·완료 체크·전체/진행 중/완료 필터·상세 설명·장소·단계·고정을 제공한다. 상단 ‹ 홈 화면/할 일 목록을 유지하며 하단 홈 버튼·프레임 X를 복원하지 않는다.

## 동작과 저장

- 직접 메모: 추가(1~80자, 최대100개)·완료/진행 중 전환·고정/해제·삭제. 별도 localStorage에 영구 저장하고 실패 시 현재 실행 적용/저장 불가를 안내한다. 날짜가 바뀌어도 메모를 자동 삭제하지 않는다.
- 일반 모드: 직접 메모를 사용한다. 종료된 SideQuestEngine/의뢰/칭호/경제 보상을 복원하지 않는다.
- 첫날 전시: 실제 flags를 읽어 생활 계좌·잡화점 포장·첫 주식·씨앗 심기·다이어리 기록을 표시한다. 초기에는 계좌만, 집에서 활동 순서를 고른 이후 나머지를 표시한다. 단계 완료는 bank/notice/packing/certificate/trade/pot/planted/diary/diaryWritten 기록으로 판단하고1초 주기로 갱신한다. 사용자가 스토리 할 일을 수동 완료하거나 보상을 받을 수 없다.
- 메모와 고정은 stockwars.phone.tasks.normal.v1 / stockwars.phone.tasks.exhibition.v1로 분리한다. 기존 스토리/경제 저장은 읽기만 하며 시안 예시 진행도나 항목을 실제 데이터로 주입하지 않는다.

## 적용·검증

synced-files.txt의8개 파일을 웹/기존 실행본 resources/web에 SHA256 일치로 반영했다. 설치 프로그램 재빌드는 하지 않았다.

node --test web/tests/phoneTasks.test.mjs:3개 통과. 재실행 복원·일반/전시 분리·손상 저장/저장 실패·실제 flag 읽기와 스토리 불변 검증.

scratch/check-phone-tasks.cjs: 웹/기존 실행본에서 메모 추가·완료·고정·필터·앱 재진입/페이지 재실행 복원·삭제·전시 단계/완료 자동 갱신·수동 완료 없음·고정 정렬·모바일 표시·상단 홈 복귀·기존 스토리 불변·모드별 저장 분리를 확인한다. web/desktop-checks.json과 실제 화면 PNG를 따른다. 검사용 전시 flag는 격리 브라우저 상태만 변경했다. 사용자 최종 시각/전체 플레이 검수는 별도다.
