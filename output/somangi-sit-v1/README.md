# 소망이 의자·벤치 앉기 — 2026-10-23

P1 (Major) · ✅ 앉기·유지·일어서기·외형/접합/좌판 검사·미리보기 / ⏳ 사용자 최종 모션 검수.

사용자가 의자·벤치 앉기를 선택했다. 입력은 관절 보정을 마친 `../somangi-joint-polish-v1/somangi-motion-ready.blend`다. 기존 외관·빨간 절단 경계·가중치·메시 구조를 수정하지 않고 본의 위치·회전 애니메이션만 추가했다.

## 결과

- `somangi-sit.glb`: 원본 모델과 아래 5개 클립.
- `somangi-sit.blend`: 편집본.
- `sit-preview.gif`: 내보낸 GLB를 재수입한 정면·측면 재생.
- `seated-angle.png`: 앉은 자세의 사선 검수 렌더.
- `sit-metadata.json`: 좌판 접촉 높이·좌판 범위·모션 정보.

| 클립 | 길이 | 용도 |
|---|---:|---|
| Sit_Down | 0.9초 | 서기에서 앉기로 전환 |
| Sit_Idle | 1.0초 | 앉은 자세 유지, 반복 가능 |
| Stand_Up | 0.9초 | 앉기에서 서기로 전환 |
| Sit_Cycle | 2.8초 | 앉기·유지·일어서기 전체 확인 |
| Walk_InPlace | 0.75초 | 기존 보정 걷기 유지 |

골반을 약간 뒤로 옮기고 몸을 부드럽게 숙였다가 앉은 자세에서 펴도록 했다. 짧은 다리는 앞으로 내밀며 골반 접합부가 좌판에 들어가지 않도록 앉는 동안만 높이를 보정한다. 양팔은 균형을 잡으며 앞쪽으로 조금 움직인다. 원래 메시의 정지 형태는 변하지 않는다.

기존 걷기는 원래 GLB의 애니메이션 데이터와 타이밍을 복사해 유지했다. 앉기의 30fps와 걷기의 32fps 제작 시간 차이로 인한 변속을 방지하기 위해 `preserve_walk.py`를 사용했다. 클립 대상 본의 바인드 변환이 같은지도 확인한다.

## 검사

`validation.json` 참조. 원본/앉기 편집본의 정점·면·UV 해시가 동일하다. 내보낸 GLB를 재수입해 281개 시점을 검사했고 절단 경계 간격 최대 0, 전체 앉기 사이클 시작/끝 오차 0이었다. 바닥 아래 최대 오차는 약 0.000117 모델 단위다.

검수용 좌판의 내부 영역에 들어간 정점은 검사 표본에서 0이었다. 좌판의 둥근 테두리와 0.003 모델 단위 접촉 여유를 제외한 상자 영역 검사이며, 임의의 실제 의자와의 완전한 접촉 검사를 뜻하지 않는다. 실제 의자·벤치 배치는 `sit-metadata.json`의 접촉 높이와 앞뒤 범위를 기준으로 맞춰야 한다.

미리보기의 회색 벤치는 검수용이며 GLB·캐릭터 편집본에 포함하지 않았다. 게임·실행본·기존 캐릭터 파일은 변경하지 않았다. 사용자 최종 시각 검수와 게임 연결은 별도다.

## 재현

Blender에서 `build.py`, `validate.py`, `preview.py` 순으로 실행하고 Pillow가 있는 Python으로 `make_previews.py`를 실행한다. `preview.py -- --quick`은 정면·측면·사선 주요 자세만 촬영한다. 본 작업은 `rig_utils.py`의 공통 회전/이동/외형 해시와 `preserve_walk.py`의 클립 보존을 사용한다. 각 소스 파일은 200줄 이내다.
