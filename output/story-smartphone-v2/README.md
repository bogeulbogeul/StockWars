# 스마트폰 3D v2 — 사용자 확대 참고 반영

2026-10-24 · P1 (Major) · ✅ 둥근 케이스·베젤/액정 삽입 구조 제작·GLB 검사 / ⏳ 사용자 외형 검수·게임 적용·손 접촉.

사용자가 제공한 `reference.png`의 둥글고 두툼한 검은 케이스와 안쪽에 들어간 액정 느낌을 반영했다. v1은 보존한다. 케이스 모서리 곡률과 옆면 라운드를 늘리고 실제 메시 절삭으로 베젤 자리·액정 자리를 만들었다. 액정은 베젤보다 안쪽에 놓이며 검은색과 낮은 반사를 유지한다. 버튼 모서리도 더 둥글게 했다. 앱·글자·발광은 없다.

`StorySmartphone.glb`는 재질 포함 모델, `StorySmartphone.blend`는 편집 원본이다. `preview.png`·`back.png`·`front.png`·`side.png`는 실제 메시 렌더다. 스튜디오는 GLB에서 제외한다. `build.py`로 Blender 5.2에서 재현하고 `manifest.json`에 검사 수치가 기록된다.

임시 H=1 기준 케이스 폭 0.18H·높이 0.32H·두께 0.029H다. 밑면 중앙 원점, Blender +Z 위쪽/-Y 정면, glTF +Y 위쪽/+Z 정면이다. 액정 연결점은 새 액정 위치로 맞췄다. 정확한 게임 배율·전달 동작·UI 연동은 후속 대상이며 게임 배포 파일은 변경하지 않는다.
