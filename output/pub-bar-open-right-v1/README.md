# 펍 바텐더 자리 — 오른쪽 개방 v1

주크박스 후속: 현관 오른쪽 벽에 짙은 오크 아치 몸체·황동 테두리·은은한 컬러 발광 아치·음악 카드 표시부·선택 버튼·사선 스피커 그릴의 빈티지 주크박스를 배치했다. `jukebox_geometry.py`와 `Pub-jukebox.glb`로 제작한다. ✅ 모델/배치 / ⏳ 재생 UI·음원·게임 상호작용 연결.

벽등 후속: 양쪽 창의 바 안쪽 옆 벽에 황동 고정판·꺾인 브래킷·고리·경사진 지붕·네 모서리 프레임과 따뜻한 발광 유리의 벽등을 추가했다. `wall_lantern.py` 및 `Pub-wall-lanterns.glb`로 제작한다. 미리보기 조명과 게임 런타임 조명 연결은 구분한다.

가구 세트 전진 후속: 소파·왼쪽 테이블/장식과 오른쪽 의자·테이블/장식을 모두 현관 방향(-Y)으로 .80 이동했다. 세트 내부 간격·옆걸음 통로 .615·쿠션 좌석 착석 불가는 유지한다.

현관 추가 확장 후속: 기존 확장보다 입구 쪽으로 1.20(바닥 세 줄)을 더 늘려 전체 깊이를 7.2→8.4로 조정했다. 바닥·벽·몰딩·앞 기둥·현관은 함께 연장하고 가구 위치는 유지했다.

창가 의자 간격 후속: 양쪽 의자를 각각 .54 뒤로 옮겨 상판·좌판 사이 약 .615의 틈을 확보했다. 소망이 키 1.0·채택 옆걸음 v4로 양쪽 통로를 검수하며 결과는 `dining-passage-validation.json`에 기록한다. 실제 게임 충돌·자동 옆걸음 전환 연결은 별도다.

반대쪽 창가 후속: 오른쪽 창가에 동일 원형 테이블·랜턴·화병과 버건디 의자 2개를 배치했다. `window_dining.py`와 독립 `Pub-window-dining.glb`로 제작하고 전체 룸 조합에 포함한다. 지하실 문 앞 통로는 유지한다. ✅ 모델 배치 / ⏳ 의자 착석·캐릭터 동선·게임 연결 검수.

랜턴 고리 후속: 반원 손잡이를 완전히 닫힌 둥근 황동 고리로 바꾸고 작은 고정 소켓에 아래쪽 원호를 연결했다. 입구 쪽에서 내부 구멍이 읽히도록 고리 방향을 조정했다.

화병 입구 후속: 목과 몸체에 실제 내부 홈을 뚫어 도자기 테두리·안쪽 벽·깊이가 보이게 수정했다. 흙이나 상단 마개 없이 줄기가 빈 입구 안으로 들어간다.

탁상 장식 후속: 원형 테이블 위에 작은 황동 랜턴·따뜻한 발광 중심·고리 손잡이와 둥근 갈색 화병·초록 잎 7개의 장식을 추가했다. `table_decor.py`에서 제작하며 테이블 독립 GLB와 조합에 포함한다. 미리보기 보조 점광원은 GLB에 내보내지 않는다.

원형 테이블 후속: 소파 앞에 따뜻한 오크 원형 상판·중앙 기둥·둥근 원반 받침의 테이블을 추가했다. 상판 높이 .775, 지름 1.20이며 소파와 가장자리 간격은 약 .48이다. `Pub-round-table.glb`와 최신 조합에 포함한다. 의자·탁상 장식은 별도다. ✅ 모델 제작 / ⏳ 캐릭터 접촉·게임 배치 연결.

쿠션 형태 되돌리기: 사용자 요청으로 비대칭 눌림·휘어짐·접힘을 취소하고 이전의 대칭 도톰한 쿠션으로 복원했다. 팔걸이에 기대는 방향·소파 전진 배치·첫 좌석 착석 불가 지정은 유지한다.

쿠션 솜 표현 후속: 팔걸이에 기대는 면은 얕게 눌리고 반대 면과 아래쪽은 도톰해지는 비대칭 곡면으로 수정했다. 휘어진 가장자리·아래 모서리의 작은 접힘을 적용해 팽팽한 평면 느낌을 줄였다.

소파 벽 간격 후속: 소파·쿠션·좌석 좌표 전체를 실내 쪽(+X)으로 .18 이동해 벽 몰딩과 겹치지 않게 했다. 좌석 착석 가능 여부는 유지한다.

팔걸이 쿠션·좌석 후속: 작은 쿠션을 입구 쪽 팔걸이 방향으로 기울였다. 쿠션이 차지한 첫 좌석은 `sittable:false`, 나머지 3좌석은 `true`로 GLB extras와 `sofa-seating.json`에 지정한다. 펍 실내는 제작 모델 단계이므로 실제 게임의 착석 선택·상호작용 연결은 아직 대기다.

작은 쿠션 후속: 등받이에 묻힌 둥근 블록 대신 중앙이 도톰하고 가장자리·네 모서리가 얇아지는 봉제 쿠션을 제작했다. 앞쪽과 위로 꺼내 비스듬히 기대고 둘레 봉제선을 추가했다. `sofa_pillow.py`에서 형상을 분리한다.

소파 부드러움 후속: 쿠션·베개에 세분화한 곡면과 부드러운 법선을 적용하고 좌판·등받이 두께와 둥근 모서리를 늘렸다. 오크 틀·팔걸이도 곡면 분할을 늘려 각진 띠를 줄였다.

소파 후속: 확장한 왼쪽 벽에 짙은 오크 틀·버건디 4칸 쿠션·둥근 팔걸이·작은 황토색 베개의 긴 소파를 추가했다. 좌판 높이는 약 .52, 전체 길이는 약 3.14이며 소망이 키 1.0 기준이다. `Pub-wall-sofa.glb`와 최신 조합에 포함한다. ✅ 모델 제작 / ⏳ 착석·캐릭터 접촉·게임 적용.

문틀·벽 몰딩 접합 후속: 개구부 절단으로 남았던 몰딩 끝의 검은 홈을 같은 목재 연결부로 메워 양쪽 문설주에 연결했다.

스페이드 접합 후속: 문양 상부와 하단 줄기 사이의 틈을 메우고 단일 메시로 결합했다.

문 위 간판 후속: 아치 위에 모서리를 꺾은 짙은 오크 간판과 얇은 금색 테두리·다이아/스페이드 문양을 추가했다. 닫힌 문과 원형 문고리 하나는 유지한다. 제작은 `door_sign.py`이며 조합 및 독립 문 에셋에 포함한다.

입구 확장 후속: 입구 방향으로 1.20(바닥 3줄)을 늘려 실내 깊이를 6.0→7.2로 조정했다. 바닥·양측 벽·연속 몰딩·앞 기둥/받침·중앙 출입구를 함께 연장하고 기존 바·스툴·창·지하실 문 위치는 유지한다. `room_extension.py`에서 원본 빈 룸을 변경하지 않고 조합에 반영한다. ✅ 모델 확장 / ⏳ 소파·식탁 배치·게임 동선 검수.

문 접합 후속: 문짝의 좌우 여유를 줄이고 문짝·문틀 앞면을 .115 앞으로 맞춰 하단 벽 몰딩 옆의 깊고 검은 틈을 정리했다.

지하실 문 후속: 뒤벽 오른쪽 기존 아치틀 안에 닫힌 짙은 오크 단문을 설치했다. 세로 판재 이음과 기본 원형 문고리 하나로 구성하며 열린 계단·간판은 추가하지 않았다. `Pub-basement-door.glb`는 독립 문짝, 최신 조합은 `Pub-bar-room-preview.blend`다. ✅ 모델 제작 / ⏳ 게임 이동·문 상호작용 연결.

달 메달 받침 제거 후속: 사용자 요청으로 원판 아래의 작은 목재 받침도 제거했다. 달 메달과 원형 테두리는 유지한다.

장식장 참고 형태 후속: 낮춘 가구 높이를 유지하면서 두툼한 오크 기둥·기둥 머리/띠·더 높은 곡선 상단·달 메달 하단 받침을 적용했다. 선반은 여유 있는 2단, 칸은 좁은 중앙과 넓은 양옆으로 정리했다. 제거한 병·맥주 탭·노란 봉은 복원하지 않는다.

소망이 기준 높이 후속: 소망이 키 1.0을 유지하고 카운터 상판을 1.07→약 .808로 낮췄다. 장식장 상부는 .30 내리고 스툴 좌판/방석은 .12 내렸다. 술통은 형태를 유지하며 90%로 축소해 낮춘 상판에 안착시켰다. 배치와 오른쪽 통로는 유지한다. `furniture_height.py`에서 비율 조정을 분리 관리한다.

의자 간격 후속: 사용자가 제작한 좁은 통로 옆걸음 모션을 고려해 스툴 3개를 카운터 쪽으로 .65 당겼다. 상판과 의자 사이 간격은 .60으로 조정했다(임시 모델 단위). 실제 옆걸음 접촉·충돌 검수는 별도다. 아래 1.25 통로 확보 기록보다 이 배치를 우선한다.

목재 띠 후속: 위·아래 굵은 띠를 왼쪽 곡선에서 옆면 뒤 끝까지 이어 둘렀다. 띠의 노출된 끝에는 둥근 마감을 추가했다. 오른쪽 작업 출입 통로는 유지한다.

스툴 후속: 노란 가로 받침을 제거하고 볼록한 버건디 방석·통통하고 둥근 오크 다리로 수정했다. 세 의자를 앞으로 옮겨 상판과 의자 사이 최소 1.25의 통로를 확보했다(임시 모델 단위). 실제 캐릭터 이동·충돌 검수는 별도다.

달 메달 접합 후속: 목재 원판 뒤를 장식장 받침 면까지 채우고 전면 금속 테두리·중앙판의 돌출을 줄였다. 원판과 같은 면에 겹치던 선반 부분을 원형으로 잘라 검게 표시되는 면 겹침을 제거했다. `moon-joint-close.png` 확대 확인.

선반 소품 제거 후속: 장식장 병 전체(몸체·목·뚜껑)를 제거해 선반을 비웠다.

상판 소품 제거 후속: 맥주 탭 전체와 받침 트레이를 제거해 상판을 비웠다.

하단 노란 줄 제거: 카운터 전면의 긴 황동 발받침 봉과 지지대를 제거했다. 스툴 자체의 가로 받침은 유지한다.

바깥 모서리 후속: 아일랜드 왼쪽 앞 모서리에 넓은 원호를 적용해 상판·몸체·하단 받침을 둥글게 맞췄다. 전면 목재 띠도 같은 곡선을 따라 감싸게 하고 왼쪽 패널 폭을 조정했다.

왼쪽 연결 후속: 장식장 하단 맨 왼쪽 서랍과 손잡이를 제거하고 아일랜드와 장식장을 안쪽 모서리가 둥근 목재 연결부로 이었다. 장식장 작업대 높이를 카운터에 맞춰 상판과 몸체를 각각 하나로 합쳤다. 오른쪽 출입 통로는 유지한다.

선반 상단 후속: 사용자 참고처럼 넓은 곡선 목재 장식·곡선 테두리와 중앙의 큰 다층 달 메달을 추가했다. 오른쪽 통로와 카운터/선반 배치는 유지한다.
