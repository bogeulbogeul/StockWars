# 소망이 — 사용자 벤치 앉기 제작

`C:/Users/bogeu/Downloads/Bench.glb`와 최신 `blank-buddy-walk-v3` 캐릭터를 사용한다. 벤치는 원래 비율을 유지한 1.5배 배율로 시험 장면에 배치하고, 레이캐스트로 좌판 표면 높이를 측정했다. 이 배율은 이번 접촉 시험용이며 게임 공통 가구 규격으로 확정하지 않는다.

## 동작

- `Bench_SitDown`: 1초 동안 벤치 앞에서 살짝 뛰어 올라앉는다. 짧은 다리는 골반에서 통째로 회전하며, 발·다리를 따로 늘이거나 이동하지 않는다.
- `Bench_Seated`: 1초 유지 자세. 짧은 발을 앞으로 내밀고 배와 머리 형태를 유지한다.
- `Bench_StandUp`: 앉기 경로를 반대로 따라 앞 바닥으로 내려온다.
- `Bench_Sit_Demo`: 올라앉기 → 유지 → 내려오기 3초 확인용 연결 클립.

벤치 원본·캐릭터 원본·기존 걷기 파일·게임 파일은 변경하지 않았다. 이번 앉기용 복사본에서 다리 본 시작점을 실제 골반 연결부로 맞췄다. 기존 걷기 리그와 병합은 별도 작업이다.

## 전달

- `somangi-bench-scene.glb`: 벤치와 캐릭터·모션을 포함한 접촉 확인 장면.
- `somangi-sit-character.glb`: 캐릭터·본·웨이트·앉기 클립만 포함. 벤치 배치값은 `seat.json` 참조.
- `somangi-bench-sit.blend`: 벤치·바닥·조명·카메라를 포함한 편집 장면. 25프레임의 앉은 자세로 저장했다.
- `bench-sit-preview.gif`: 실제 모델에서 렌더한 3초 연결 미리보기(12fps). 모션 키는 24fps다.
- `sit-angle.png`, `sit-side.png`: 앉은 자세 사선·정측면 확인.
- `validation.json`: 루프·다리 하단 길이·배 변형·좌판 접촉과 표본 프레임 벤치 침투 검사.

✅ 모션/시험 파일 제작. ⏳ 게임 상호작용 연결·접근 경로·전환·전체 프레임 충돌 검수. 이 장면의 Root 이동을 게임에서 중복 적용하지 않는다. 식물 장식·표정 교체는 포함하지 않았다.
