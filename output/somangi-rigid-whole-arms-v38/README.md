# 소망이 팔 전체 고정 모션 v38

팔 뿌리에서 발생하던 혼합 가중치를 제거했다. 양쪽 팔의 모든 정점을 각각 단일 팔 본에 100% 연결하여 관절 없이 통째로 회전·이동한다. 기본 메시 좌표와 토폴로지는 v37 그대로이며 기존 모션과 음식 축소 타이밍을 유지한다.

271개 반 프레임에서 팔 뿌리를 포함한 전체 팔을 단일 강체 변환과 비교했다. 최대 좌표 오차는 0.000000161이며 종료 자세는 기본 자세와 최대 0.000000060 차이다. verification.json 참고.

제한: 팔의 휘어짐을 제거한 결과 어깨 접합 경계가 옆에서 드러난다. 연결부까지 매끈한 최종본으로 간주하지 않는다. 게임에는 적용하지 않았다.
