# 우체국 박공 기와지붕 v2

P2 · ✅ 네이티브 지붕 변경 / ⏳ 사용자 최종 시각 검수·게임 적용

사용자 요청으로 기존 곡면 지붕을 테라코타 직선 박공 기와지붕으로 교체했다. 기존 폭/깊이/박공 꼭대기 높이를 유지하며 두께 있는 둥근 기와 128장·둥근 용마루 8개·연결 띠 9개를 만들었다. 단일 주 지붕이며 새 현관 지붕은 추가하지 않았다.

기존 벽과 새 삼각 박공을 합치고 목재 처마/가로보를 연결했다. 봉투 간판은 새 박공 안에 들어가도록 X/Z 80%로 맞추고 벽에 밀착했다. 우편함의 봉투는 공유 메시를 수정하지 않고 원래 크기/배치를 유지한다. 문·창·우편함·계단·기둥은 원본 정점 해시로 대조했다.

`PostOffice.glb`, `PostOffice-pitched-roof.blend`, 실제 전체/정면/후면/지붕/간판 렌더를 저장했다. `verify.py`는 GLB 재로딩·지붕/목재 닫힘·기와/용마루 수량·봉투/우편함 유지·유한 좌표·접지를 검사한다. 우체국은 마을 배치·게임 적용 전이며 이번 작업에서도 웹/실행본을 변경하지 않았다.
