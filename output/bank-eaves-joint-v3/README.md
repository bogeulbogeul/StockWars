# 은행 처마 접합부 v3

P2 · ✅ 네이티브 접합부 수정 / ⏳ 사용자 시각 검수·게임 적용

`bank-redesign-v2/Bank-redesign.blend`에서 현관 지붕과 본 지붕이 만나는 목재 마감을 정리했다. 현관 목재 측면을 X ±.728로 기와 외곽 ±.73 안에 넣고, 크림 박공판을 목재 안쪽으로 3% 줄였다. 현관 지붕 바탕판만 좌우 1.5% 안쪽으로 넣어 목재 옆에 금색 단면이 나오지 않게 했다. 기와 자체는 유지한다. 정면 가로 목재는 .048 뒤로 옮겨 기와 처마선과 맞췄다. 목재 테두리와 정면 가로 마감을 합집합으로 연결했다.

기와/용마루·동전·문·창·기둥·계단은 유지하며 변경 대상 이외 메시 정점 해시를 대조했다. 실제 전체·동일 접합부 확대·정면을 렌더했다. `verify.py`는 GLB 재로딩·목재 닫힘·기와 166장/용마루 수량·동전·유한 좌표를 검사한다.

수정본은 `Bank-clean.glb`, `Bank-eaves-joint.blend`다. 웹/기존 실행본은 교체하지 않았다.
