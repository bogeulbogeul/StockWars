# 소파 2인 착석 미리보기

최신 짧은 조끼 v5 안나의 `Seated`와 소망이 벤치 앉기 v2의 `Bench_Seated`를 소파 두 좌석에 배치했다. 기존 임시 배율 .65를 유지하며 몸통 하단 접촉 기준을 좌판 상단 .632보다 .001 위에 맞췄다. 테이블 간격과 장식 쿠션 없는 소파를 유지한다.

✅ 정지 자세 배치·시각 확인 / ⏳ 전체 메시 충돌·앉기/일어서기 전환·게임 적용

`sofa-two-seated.png`는 조합 렌더, `Office-sofa-two-seated-preview.blend`는 미리보기 장면, `fit-report.json`은 캐릭터 경계 기록이다. 기존 캐릭터 원본과 게임은 변경하지 않았다. 다리를 앞으로 모으는 기존 앉기 자세이며 바닥 접지 자세로 보정한 것은 아니다.
