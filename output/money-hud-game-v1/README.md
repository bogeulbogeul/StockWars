# 현금·총자산·수익률 HUD — 2026-10-25

사용자 승인에 따라 웹 및 기존 실행본 resources/web에 적용했다. 설치 프로그램은 재빌드하지 않았다.

## 후속: 계좌 개설에 따른 순차 공개

사용자 요청으로 첫날 전시에서는 은행 개설 완료(`flags.bank`) 전 HUD 전체를 숨긴다. 은행 계좌 개설 후 현금만 공개하고, 기존 증권사 계좌 이용 해금 시점인 투자 자격증 수령 완료(`flags.certificate`) 후 총자산·수익률을 아래에 추가한다. 신청서/시험 화면에 들어가는 것만으로 공개하지 않는다. 기존 두 플래그로 현재 세션의 진행 상태를 복원하며 처음부터 시작하면 다시 숨긴다. 전시는 기존 메모리 세션 정책대로 새로고침/종료 시 진행을 초기화하며 영구 저장을 추가하지 않는다. 잔액·주식·저장 구조·개설 절차는 바꾸지 않았다. 계좌 개설 상태가 없는 `demo=standard`도 HUD 전체를 숨긴다. 모든 경로에서 MoneyHUD의 기본값은 미개설이며 명시적 개설 완료 상태가 필요하다. 현금만 보일 때는 패널 높이와 음악 버튼 위치도 함께 줄인다.

- 오른쪽/위 24px, 폭 260px 아이보리 패널. 작은 화면은 여백 12px, 폭 226px. 게임 전체 배율을 상쇄해 글씨를 읽을 수 있게 유지한다.
- 은행 정면 간판의 금빛 원형 테두리·좌우 대칭 잎 2개·줄기 음각을 CSS로 재현했다. 현금은 큰 글씨, 아래에 총자산·수익률만 표시한다.
- 일반 게임은 marketEngine 상태/구독, 첫날 전시는 ExhibitionView.sync와 기존 exhibitionStockSource를 사용한다. 일반 계좌와 전시 계좌·저장을 혼합하지 않는다.
- 총자산은 각 기존 소스의 totalNetWorth다. 부채 차감 등의 새 산식은 도입하지 않는다. 수익률은 기존 주식 앱과 동일하게 totalProfitLoss / (initialCash || 5000) × 100이다. 생활 수입을 투자 수익으로 계산하지 않으며 실현 손익을 포함하는 새 누적 수익률이 아니다. 고정 시세 전시는 기존 소스가 평가손익 0을 반환하므로 0.00%다. 양수는 코랄/+ 기호, 음수는 파랑/− 기호, 0은 중립색이다.
- 타이틀/오프닝/도착 영상, 열린 dialog(스마트폰·게시판 등), 상점 구매, 전시 엔딩에서는 숨긴다. 일반 하단 대화 및 마을/실내에서는 유지한다. 표시 전용으로 이동·클릭을 가로채지 않는다. 음악 버튼을 HUD 아래로 옮겨 겹침을 피한다.
- 기존 폐기 HUD/스마트폰/거래 UI는 복원하지 않았다. 경제 계산·저장 스키마·모델·충돌은 변경하지 않았다.

## 검증

`node scratch/check-money-hud.cjs` 및 `node scratch/check-money-hud.cjs electron-app/dist/win-unpacked/resources/web` 통과. 두 대상 모두 마을 모델 194개 로드와 실제 렌더를 기다렸다.

타이틀 숨김, 우상단 24px 여백, 음악 버튼 비겹침, 세 항목 표시, 양수/음수/0 수익률, 스마트폰 및 상점 진입/복귀, 320/360px 화면 경계, 전시 독립 상태 표시를 확인했다. JavaScript pageerror는 양쪽 0건이다. `*-validation.json`과 `web-*.png`·`desktop-*.png`를 참고한다.

스크린샷의 금액은 독립 테스트 브라우저에서 표시 상태를 주입한 예시다. 사용자 저장을 변경하지 않았다. desktop 검사는 기존 실행본의 resources/web 파일을 Edge에서 제공해 검사한 것이며 Electron 프로세스 직접 실행 검사는 아니다. `synced-files.txt`의 5개 파일은 웹/실행본 SHA256이 일치한다. 사용자 최종 시각·플레이 검수는 별도다.
