# 건물 퇴장 문 개방·도보 연결 — 2026-10-25

사용자 요청: 건물에서 나올 때도 문이 열리고 캐릭터가 걸어서 나오도록 연결.

실내가 있는 집·잡화점·증권사·안내소·은행의 공통 `OnFootNavigation.leaveBuildingOnFoot`를 보완했다. 기존 일반 모드 입구 콜백과 전시의 `BuildingTravel.leaveStoryBuilding`은 같은 함수를 사용한다. 실내에서는 실제 가구/벽 충돌을 확인한 경로로 출입구까지 걷고, 마을 외관 화면을 먼저 표시한 뒤 경첩 문을 연다. 소망이는 문 안쪽 -10에서 문 밖 +190까지 145속도로 연속 이동하고, 몸이 나온 뒤 문을 닫는다. 열림/이동/닫힘 동안 재진입·반복 퇴장을 잠그고 완료/오류 시 입력 상태를 정리한다.

공통 코드에 남아 있던 폐기된 doorwayFade import/호출과 fadeAtDoor 옵션을 제거했다. 투명도를 바꾸지 않으며 앞서 적용한 검정 출입구·실제 경첩 축·계단 지지 높이를 유지한다. 실내/실외 좌표계 교체는 같은 출입구에서 외부 모델이 숨겨진 동안에만 수행한다. 마을의 임의 목적지로 옮기는 연출은 추가하지 않는다.

안내소·은행의 전시 동행 퇴장은 기존 실내 걷기를 유지하며, 외부 문이 열리는 모습을 먼저 보여준 뒤 모아가 문 안쪽에서 걸어나오고 소망이가 뒤따른다. 모아가 기다릴 공간을 비우도록 옆으로 이동하고, 소망이가 나온 뒤 문을 닫는다. 기다리는 외부 플레이어 위치를 scriptedWalking으로 고정하여 충돌 복구가 문 밖으로 밀어내지 않게 했다. 안내소의 기존 모아 외부 +100 즉시 표시를 문 안쪽부터 걷는 동작으로 바꿨다.

검증:
- 관련 Node 테스트 6개 통과. 외관 표시→문 열림→도보 퇴장→닫힘 순서, 입력 해제, 불투명 유지, 실제 실내 경로·검정 면 회귀를 포함한다.
- `scratch/check-building-exits.cjs`: 실제 실내 5곳의 나가기 실행. 집·잡화점·증권사는 전시의 원래 exit 콜백, 안내소·은행은 일반 모드와 같은 공통 콜백을 사용했다. 실내/실외 걷기·보이는 문 개방 중간 프레임·재질 변경 0·실외 프레임 이동 최대 7.25·문 밖 +190 도착·입력 잠금 해제·페이지 오류 0을 웹/기존 실행본 모두 확인했다. 결과는 `web-checks.json`/`executable-checks.json`이다.
- `scratch/check-companion-exit-walk.cjs`: 실제 안내소·은행의 전시 전용 퇴장을 호출해 모아 먼저/소망이 다음·보이는 문 개방·밖 +190 도착을 검사했다. 결과는 `*-companions.json`, 실제 렌더는 `*-*-exit.png`다.
- 기존 `scratch/check-all-building-walk.cjs`를 WALK_ONLY=home_office_tower로 실행해 일반 모드 실제 집 입장/나가기 콜백도 통과했다. 이 선택 실행은 일반 모드 다른 4개 건물의 별도 전체 왕복 검수 완료를 뜻하지 않는다.

변경한 런타임은 `OnFootNavigation.js`·`InformationExit.js`·`BankExit.js` 3개다. 기존 입구/전시 연결 파일의 현재 내용을 보존했으며 웹/기존 실행본 SHA256 일치를 확인한다. 실내가 없는 나머지 건물에 신규 실내나 퇴장 기능은 추가하지 않는다. 설치 프로그램 재빌드와 사용자 최종 시각·플레이 검수는 별도다.
