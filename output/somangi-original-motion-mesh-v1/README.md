# 소망이 원형 유지 모션 메시 — 2026-10-23

P1 (Major) · ✅ 원본 표면 유지·하나의 메시·관절 연결·걷기 검사 / ⏳ 사용자 최종 외형·모션 검수.

사용자는 팔·다리를 주름 경계에서 분리하되 전체를 하나의 메시 오브젝트로 만들고, 자연스럽게 움직이도록 하며 모양을 바꾸지 말라고 요청했다. 입력은 앞서 얼굴 보정을 마친 `../somangi-face-smooth-v1/somangi-face-smooth.glb`다. 걷기 v2의 새로 구성한 몸통·캡슐 팔이나 찢어진 첫 분리본을 사용하지 않았다.

## 구조

원본 표면 위의 연결 거리를 이용해 어깨·겨드랑이와 허벅지 주름 부근의 분리 경계를 정하고, 삼각형을 연속 등고선에서 나눴다. 원본 표면 위치·UV·법선을 보간해 유지하며 체형을 다시 만들거나 표면을 평활화하지 않는다. 절단 경계와 내부 마감에만 정점을 추가했다.

메시 오브젝트는 `Somangi_SmoothBody` 하나다. 내부적으로 몸통·양팔·양다리의 연결되지 않은 5개 조각이며 `Part.Root`, `Part.Arm.L/R`, `Part.Leg.L/R` 그룹으로 선택할 수 있다. 관절 본은 Root·양팔·양다리다.

숨겨진 마감과 짧은 안쪽 연결부를 원본 부피 안에 만들었다. 단순 강체 분리만으로는 관절 회전 시 틈이 생기므로 주름 부근의 좁은 구간에는 관절 가중치를 부드럽게 연결했다. 절단 양쪽의 경계는 동일한 가중치로 움직여 서로 떨어지지 않는다. 정지 형태는 유지하고 관절 주변은 동작에 따라 변형된다.

## 결과

- `somangi-rest.glb`: 정지 형태의 단일 메시·리그.
- `somangi-walk.glb`: 같은 메시와 `Walk_InPlace` 걷기 클립.
- `somangi-motion-ready.blend`: 편집본, 5개 조각·선택 그룹·관절 가중치 포함.
- `walk-preview.gif`, `front.gif`, `side.gif`: 내보낸 걷기 GLB를 재수입한 실제 재생.
- `somangi-rest-front.png` 및 right/back: 정지 모델 검수 렌더.

걷기는 이전 소망이 걷기의 반대 팔·다리 교대와 Root 접지 보정을 참고했다. 0.75초 주기·팔 ±18도·다리 ±20도의 제자리 걷기다. 실제 게임 이동 속도에 맞춘 발 고정 IK는 아니다.

## 검사

- `shape-validation.json`: 단일 메시/5개 조각. 편집본의 원본 표면 거리 오차 0, 정지 GLB 재수입 오차 약 1.65e-7 모델 단위. 내부 추가 정점의 원본 부피 밖 돌출 0.
- `seam-validation.json`: 절단 경계의 공유 위치 593곳을 97개 시점에서 검사. 움직이는 경계 양쪽 최대 간격 약 1.20e-7 모델 단위.
- `validation.json`: 걷기 GLB 97시점. 시작/끝 루프 오차 0, 관절 연결 구간 밖 몸통 형태 오차 약 2.99e-8. 발 접지 오차는 아래 약 0.000225/위 약 0.000440 모델 단위.

표본 검사는 모든 자세의 무간섭이나 사용자 최종 모션 승인을 뜻하지 않는다. 게임·실행본·삭제한 캐릭터 로더는 변경하지 않았다.

## 재현

Blender에서 `build.py`, `validate_shape.py`, `validate_seams.py`, `preview.py`를 실행한다. Pillow가 있는 Python으로 `make_previews.py`를 실행한다. `surface.py`는 원본 표면 분리·내부 마감·가중치 처리, `build.py`는 리그/걷기/내보내기, 나머지는 검사·미리보기 역할이다. 각 소스 파일은 300줄 이내다.
