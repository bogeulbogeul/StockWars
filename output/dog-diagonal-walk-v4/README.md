# 사선 걷기 A/B 수정 v4

뒤로 깊게 접혀 들린 발을 바닥 가까이 낮추고 무릎 굽힘과 보폭을 줄인 완성 자세를 내장 image_gen으로 새로 제작했다. A는 가까운 다리 전진·가까운 팔 후퇴, B는 가까운 다리 후퇴·가까운 팔 전진이다. 양 눈과 앞가슴이 보이는 앞오른쪽 사선 카메라를 유지했다. 원본·프롬프트는 `generation.json`, `raw/right_walk.png`다.

sprite-gen의 크로마 제거·연결 성분 추출 후 행 전체에 같은 배율을 적용했다. 기존 v3의 중립은 그대로 사용하고 새 접지 A/B만 적용했다. 사선 정지·초상화를 포함한 다른17논리 프레임은 v3과 RGBA가 정확히 같다. 재생은 0→1→2→1, 각160ms다. 팔다리 리깅·워핑·머리 덧붙이기는 하지 않았다.

새 A/B는 sprite-gen recolor로 v3의 공통 RGB279색에 베이크했다. 전체19논리 프레임의 비투명 RGB가 해당 목록에 속하며 목록 밖 색은0개다. 정적 자세·팔과 다리의 겹침·원점·출력 여백·미리보기 렌더 경로를 확인했다. 실시간 재생의 연결과 발 미끄러짐은 아직 최종 통과로 판정하지 않은 experimental 시안이며 게임 미반영이다.

`preview.html`: v3/v4 재생 비교. `walk-comparison.png`: 위 v3 / 아래 v4 자세 비교. `qa/right_walk.gif`: v4 재생. 이전 전체 제작 이력은 `../dog-rgb-face-v3/` 이하를 따른다. `build.py`는 공통 조합 함수 제공용이다. 재제작은 `prepare.py` → recolor → `publish.py` 순서로 실행한다.
