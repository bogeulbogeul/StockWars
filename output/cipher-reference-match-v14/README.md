# 증권사 전체 외관 시안 대조 v14 — 2026-10-25

사용자가 첨부한 전체 외관을 고정 기준으로 카메라·전체 실루엣·시설 세부·재질을 대조하는 작업을 요청했다. 원본은 `approved-reference.png`에 보존한다. 이번 결과는 **대조용 수정본**이며 완전 일치 완료/사용자 채택/게임 적용으로 기록하지 않는다.

## 수정한 부분

- 창: 공통 아치 조립체를 기준점 주위에서 가늘고 긴 비율로 조정했다. 정면 창의 간격을 시안에 맞춰 개별 조정하고 크림 외곽틀·황동 창살/팬라이트로 정리했다.
- 시계: 시계 면과 두 바늘·눈금·테두리를 함께 1.27배로 키웠다. 바늘 이름과 기존 회전 연결을 위한 노드는 보존했다. 게임 시간 동작을 이번에 검증한 것은 아니다.
- 문: 기존 상하 두 패널 대신 긴 세로 패널, 곧은 황동 양손잡이로 변경했다. 중앙 아치와 팬라이트·출입 바닥 높이는 유지한다.
- 계단: 중앙 단을 좁히고 양쪽에 단 높이를 따라 이어지는 닫힌 돌 받침 여섯 구간을 만들었다.
- 로고: 네 황동 막대와 얇은 상승선/화살표로 재구성했다.
- 재질/조명: 파란 지붕·유리의 색과 지붕 반사를 조정하고 Standard 색 변환에 맞춰 조명을 낮췄다. 무광 클레이와 기존 부드러운 모서리를 유지했다.

## 카메라·대조 결과와 남은 차이

`camera_fit.py`는 이미지의 지붕·박공·기초·문·계단 등 12개 수동 기준점을 사용한다. 정사영 대조 뒤 원근 카메라의 방향·거리·초점거리·프레이밍도 함께 탐색했다. 최적 후보는 장초점에 가까웠으며 기준점 RMS는 약 19.48픽셀이다. **원근 카메라 변경만으로 시안과 일치하지 않았다.** 이 값은 최종 메시의 표면 전체 유사도 점수나 시각 통과 판정이 아니다.

`comparison.png`: 왼쪽 시안 / 오른쪽 실제 3D 렌더. `overlay.png`: 두 이미지 50% 겹침. 원본은 폭 804, 렌더는 803픽셀이므로 대조 파일에서는 시안 오른쪽 테두리 1픽셀만 제외했다. 비율 변형·이미지 리터칭으로 차이를 숨기지 않았다.

겹침에서 중앙 지붕 뒤쪽 깊이/용마루 위치·좌우 처마 높이·건물 기초 위치·계단 비율 차이가 여전히 보인다. 해당 부위의 형상 재설계가 남아 있다. 이전 모델/평기와 두께 검사 결과를 전체 외관 일치 근거로 재사용하지 않는다.
