# 인벤토리·찌라시 수령 안내 게임 적용 — 2026-10-25

채택한 아이보리 인벤토리를 웹과 기존 실행본 resources/web에 적용했다. 설치 프로그램 재빌드는 하지 않았다.

- 가방 버튼 또는 기본 I키로 열고, I/Esc/닫기로 닫는다. 단축키 재지정 시 기존 게임 키 설정을 따른다. 검색 입력 중 I는 검색 문자로 처리한다.
- 분류 없는 한 목록, 상점 공용 itemIconHtml 이미지, 물건 하나당 한 칸, 총 30개. 게임 ItemEngine의 구매·지급 및 인벤토리 직접 추가에 모두 적용한다. 꽉 찬 가방은 결제 전에 구매를 거절한다.
- 이전 저장에 이미 30개를 넘겨 소유한 물건은 삭제하지 않는다. 30개 미만으로 줄이기 전까지 추가만 막는다. 기존 의상 보유 기록은 보존하되 폐기 의상 화면은 복원하지 않는다.
- 일반 모드는 기존 ItemEngine 보유품과 사용/소비/저장, 찌라시 해석/퀴즈를 연결한다. 기존 모듈의 데이터·이벤트·보상을 유지한다. 새 소셜 선물·가구 편집·능력치 도서 화면은 복원하지 않는다.
- 첫날 전시는 일반 계좌·보유품과 분리한다. 봉투 수령 완료 시 기존 대본의 코지페이 소문을 전시 가방에 1개 보관한다. 기존 소문 이야기/다음 진행은 유지하며 새 보상이나 실제 시장 이벤트를 붙이지 않는다. 전시의 세션 저장/새로고침 초기화 정책을 그대로 따른다.
- 찌라시가 새로 들어오면 “찌라시가 가방에 들어왔어요. [I] 키로 가방을 열어 확인하세요.”를 8초 표시한다. 재설정 키가 있으면 해당 키를 보여준다. 초기 저장 로드와 단순 재열람에는 중복 안내하지 않는다.
- 열린 가방은 네이티브 dialog로 게임 클릭을 막고 마을 입력 차단과 연결한다. 찌라시 열람은 가방 안의 기존 편지 화면이며 Esc는 편지부터 닫고 다음 Esc에 가방을 닫는다. 포장/스마트폰 등 다른 dialog가 열려 있으면 가방을 겹쳐 열지 않는다.
- 삭제 요청한 네 문구는 복원하지 않았다.
