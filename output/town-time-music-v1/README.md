# 마을 시간대별 게임 BGM v1

후속 사용자 요청으로 웹·기존 실행본에 적용했다. 현재 연결·6초 교차 전환·검증은 [게임 적용 기록](../town-time-music-game-v1/README.md)을 따른다. 아래는 음원 제작 당시의 기록이다.

게임 내 마을 플레이용 오리지널 연주곡 4개. 타이틀·광고용 「작은 잎의 내일」과 별도 제작했다. 현행 `web/js/data/townSkyPalettes.js`의 dawn/day/sunset/night 구분에 대응한다.

| 구분 | 제목 | BPM | 길이 | 편성 |
|---|---|---:|---:|---|
| 새벽 | 이슬이 깨우는 마을 | 72 | 80초 | 플루트·하프 계열·여린 패드 |
| 낮 | 햇살 따라 한 걸음 | 100 | 57.6초 | 목재 타악 선율·기타·가벼운 베이스 |
| 노을 | 노을빛 귀갓길 | 80 | 72초 | 전기피아노·기타·따뜻한 패드 |
| 밤 | 별이 머무는 창가 | 64 | 90초 | 펠트피아노·유리종·낮은 패드 |

모두 24마디·4/4, 보컬 없이 합성 악기로 만든 감상/게임 사용 후보 음원이다. 기존 곡·외부 녹음·샘플·사운드폰트를 가져오지 않았다. 악기명은 합성 음색의 방향을 설명하며 실연 녹음을 뜻하지 않는다.

## 파일과 반복 방법

각 `*-loop.wav`는 44.1kHz / stereo / PCM16이다. 파일 전체를 샘플 단위로 반복한다. 릴리스·공간계 잔향을 처음으로 순환 합산했으므로 앞뒤 무음을 삽입하거나 추가 페이드 처리하지 않는다. 무손실 WAV를 기준으로 사용하고, 손실 압축 시에는 인코더 지연/패딩과 루프 지점을 별도 검증한다.

각 `*-loop.mid`는 템포·박자·조성과 악기별 트랙을 담은 편곡 원본이다. MIDI는 잔향을 포함하지 않으며 WAV와 같은 음색/루프 경계를 자동 재현하지 않는다. `compose.py`는 numpy를 사용하는 재생성 스크립트다.

`manifest.json`에 샘플 수·정확한 루프 범위·피크·RMS·클리핑·경계 표본 차이를 기록했다. 4곡의 RMS를 맞추고 피크 여유를 확보했다. LUFS 측정이나 실제 청취 검수 완료를 의미하지 않는다. 경계 표본 차이는 파일 내부 최대 인접 표본 차이보다 작은지 검사한다. 음악적 연결감과 장시간 반복 피로도는 실제 청취로 최종 판단한다.

## 게임 연결 시 기준

기존 하늘이 결정한 dawn/day/sunset/night 상태를 재사용하고 별도 시간표를 만들지 않는다. 시간대 전환은 약 6초 교차 페이드로 시작해 청취 조정한다. Web Audio의 디코딩한 AudioBuffer 및 loopStart/loopEnd로 반복하면 정확한 샘플 루프를 유지하기 쉽다. 브라우저 재생은 사용자 시작 동작 후 활성화하고 탭 비활성·음악 음량·실내 정책은 통합 시 다룬다.

이번 결과는 음원 제작 및 파일 자동 검증까지다. 웹·기존 실행본·시간 서비스·게임 재생 코드는 변경하지 않았다. 타이틀/광고곡도 유지한다.
