# 강아지 기본 모션 재설계 시안 v1

2026-10-16 사용자 요청에 따른 기본 모션 디자인 후보. 기존 강아지의 연한 살구색 털·크림색 무늬·접힌 귀·갈색 눈을 외형 참고로 사용하고, 방향별 완성 자세를 새로 생성했다. 기존 게임 에셋과 나머지 7종은 교체하지 않았다.

## 구성

- 정면·앞오른쪽 사선·뒤 정지와 걷기: 걷기는 각각 3그림, 정지는 걷기의 중립 그림과 동일.
- 운반 4그림, 정면·사선 의자 앉기 각각 1그림, 정면 얼굴 초상화 1그림.
- 10개 기본 상태, 19논리 항목, 16개 고유 그림. 기존 강아지의 6개 꼬리 대기 확장은 이 기본 모션 시안에 포함하지 않으며 기존 게임에서는 유지된다.
- 걷기 재생은 A → 중립 → B → 중립, 각 160ms. 프레임 수와 속도를 바꿔 자세 오류를 숨기지 않았다.

## 걷기 자세 규칙

| 방향 | A | B |
|---|---|---|
| 정면 | 화면 왼발 전진 + 화면 오른손 전진 | 화면 오른발 전진 + 화면 왼손 전진 |
| 앞오른쪽 사선 | 가까운 다리 전진 + 가까운 팔 후퇴 | 가까운 다리 후퇴 + 가까운 팔 전진 |
| 뒤 | 화면 오른발 멀리 전진 + 화면 왼팔 멀리 전진 | 화면 왼발 멀리 전진 + 화면 오른팔 멀리 전진 |

같은 쪽 팔과 다리는 서로 반대 방향으로 움직인다. 운반은 양손을 물건 받침 자세로 유지하는 별도 행동이므로 자유 걷기의 팔 흔들기를 적용하지 않는다. 모든 발은 털로 덮인 형태이며 패드·젤리·별도 발바닥 면을 그리지 않도록 생성했다. 앞발 손가락 구분선은 유지한다.

## 제작과 검수 범위

도구는 내장 image_gen. 프롬프트와 원본 경로는 `generation.json`, `retakes.json` 및 추가 리테이크 기록을 따른다. `raw/`에는 조합에 쓰는 생성 원본이 있다. 강아지 승인 정면 정지를 외형·색 참고로, 이전 시트를 방향·구성 참고로 구분했다. `contralateral-pose-reference.png`는 가까운 쪽/먼 쪽 팔다리를 설명하는 도식이며 스프라이트 픽셀로 사용하지 않았다.

sprite-gen의 크로마 제거·연결 성분 추출·리사이즈 함수를 사용했다. 조합·원점 배치와 비교 페이지는 프로젝트의 기존 시트 방식에 맞춘 별도 스크립트다. 생성물을 같은 간격으로 잘라 추출하지 않았으며 팔다리 변형·리깅·정지 머리 덧붙이기·재색칠을 하지 않았다. 사선 접지 B는 반대 다리의 겹침이 반복되는 초기 행을 배제하고 별도로 재생성한 완성 자세다.

`verification.json`의 통과는 프레임 수·시트 픽셀·여백·중립 일치를 확인한 것이다. 정적 자세와 모아보기는 확인했지만 실시간 재생의 연결·발 미끄러짐·모션 간 재질색 변화에 대한 최종 통과를 뜻하지 않는다. 걷기는 experimental 후보이며 게임 내 이동·가구 접촉 검수도 별도다. 실패가 남으면 해당 방향·행동을 다시 생성해야 한다.

`preview.html`: 현재 채택본과 새 기본 시안 비교, 정지/걷기/운반/앉기/초상화 전환, 한 프레임씩 보기 및 90px 비교.

`dog/review-final.png`: 모든 고유 자세 모아보기. `dog/run/sprite-sheet-alpha.png`: 투명 PNG 시트. `dog/run/manifest.json`: 시안의 정확한 좌표와 재생 순서. 이 시안은 기존 6열 꼬리 대기 시트와 좌표가 다르므로 게임 atlas에 파일만 덮어쓰면 안 된다.
