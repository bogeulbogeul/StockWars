# 기존 색 복원 및 토끼 뒤 외형 수정

모션 보정 v1의 네이티브 재생성 과정에서 털색·그림자가 진해진 점을 수정했다. built-in image_gen으로 7종의 기존 완성 자세 보드를 편집했으며, 모션 수정 직전 승인색(`output/dog-motion-match-v1/<id>/before/`)과 정면 중립을 색·명암 기준으로 사용했다. 기존 모션 보정본은 자세 참고이며 승인색을 대신하지 않는다. 생성 7회의 실제 프롬프트·입력·원본 경로는 `generation.json`이다.

토끼는 최근 정면·사선의 둥근 볼·머리 형태를 뒤 걷기 3그림에 적용하고 뒤 정지도 새 중립과 공유했다. 뒤의 각진 볼털은 완화하고 긴 둥근 귀를 유지한다. 모든 동물의 발바닥 패드 금지와 토끼 운반의 하복부/허벅지 흰 패치 제거를 유지한다.

추출은 sprite-gen 크로마 제거·연결요소 분리, 보드 전체의 동일 등방 배율과 기존 모션 머리 기준점 정렬이다. 행을 어댑트한 뒤 요소를 추출했으며 고정 칸 자르기로 새 모션을 만들지 않는다. 기존 좌표·3그림·0→1→2→1·160ms를 유지한다. 얼굴/상체 띠 합성, 색 수 축소, RGB 정수 팔레트 교체나 대비 필터를 적용하지 않았다. 네이티브 연속 RGB를 유지한다. 강아지 PNG는 변경하지 않는다. 토끼 뒤 중립을 제외한 기존 중립·정지·앉기·초상화는 바이트 동일하다.

`preview.html`: 기존 승인색 / 진해졌던 수정본 / 복원본 동시 비교. `<id>/run/`: 시트·프레임·manifest·GIF·검수. `<id>/before/`: 이번 수정 직전 보존본. `*-review.png`: 전체 상태별 비교 보드.

4개 모션의 자세 보드, 외형/색/선/무늬/패드 없음, 프레임 잘림·공유 중립·시트 좌표·GIF 순서/시간을 확인했다. 실시간 브라우저 재생은 file URL 접근 제한 때문에 검수하지 못했다. 실제 게임 내 발 접지·발 미끄러짐·화물/가구 접촉과 모션 연속성의 최종 실재생 판정은 미검증이며 이동 모션은 experimental / needs-review로 기록한다. 고양이는 기존 게임 atlas에 반영하고 숲속 6종은 에셋 전달까지만 반영한다.
