# 소망이 입 앞 한입 먹기 v37

v36의 기본 외형을 유지하면서 빵을 입 가까이 올리고 고개를 조금 숙인 뒤, 빵을 내려 오물거리는 동작으로 변경했다. 4.5초 동안 세 번 먹고 기본 자세로 돌아간다.

## 동작과 연결

- 팔꿈치·아래팔 관절을 추가하지 않는다. 팔 본체는 팔 전체 회전·이동으로 움직이며 뿌리 연결부만 부드럽게 이어진다.
- 손은 처음부터 모은 간격을 유지하고 빵 크기를 따라 좁혀지지 않는다. 빵은 모든 축에서 같은 선형 비율로 3회 줄어들며 아래쪽 기준을 손 가까이에 둔다.
- 빵을 들 때 살짝 기울여 얼굴 앞에서 멈추고, 고개 숙임은 최대 약 12도다. 한입 뒤에는 빵을 내려 작은 입 움직임으로 씹는 느낌을 준다.
- 목의 움직임을 좁은 한 줄에 몰지 않도록 분산하고, 어깨 뿌리의 가중치를 국소적으로 최적화했다. 최종 모델은 일반 스키닝이며 실험용 보정 모디파이어나 새 관절을 포함하지 않는다.
- 원래 표면 법선은 유지했다. 최대로 들어 올리는 순간 어깨 뿌리에 얕은 주름이 약간 남아 있으며, 완전히 이음선 없는 연결을 달성했다고 주장하지 않는다.

## 보존과 검증

캐릭터 메시의 기본 정점 좌표 차이 0, 폴리곤 구조 동일. 머리 모양·얼굴 재질·검은 눈·기본 U자 미소를 유지한다. 본은 Body / Arm.L / Arm.R / Head 그대로다. 연결부 안쪽의 가중치는 수정했으므로 모든 팔 뿌리 정점이 강체인 모델이라고 주장하지 않는다. 뿌리 밖의 팔 본체와 머리는 강체 움직임을 유지한다.

`verification.json`은 271개 반 프레임 표본의 몸통 고정·팔 본체 유지·팔 끝쪽/얼굴·빵/얼굴·빵/몸통 표면 교차 검사다. 어깨 안쪽의 의도적인 겹침은 팔 끝쪽 검사에 포함하지 않는다.

`connection-check.json`은 같은 표본에서 원본 피부 재질의 연결부 삼각형을 검사한다. 극히 작은 퇴화 면은 제외하고, 변형된 면 방향을 가중 회전 기준과 비교해 접힘을 확인한다. 정면·좌우·뒤의 가림 여부도 별도 기록한다. 내부 보충 면까지 포함한 모든 표면의 무간섭을 증명하는 검사는 아니다.

최종 검사 결과: 271개 표본에서 검사 대상 연결면 뒤집힘 0, 팔 끝쪽/얼굴·빵/얼굴·빵/몸통 교차 0. 기본 메시 위치 차이 0이며 마지막 기본 자세의 최대 위치 오차는 약 5.97e-8 모델 단위다. 이 수학적 검사가 얕은 표면 주름이나 모든 조명에서의 음영까지 없음을 보장하지는 않는다.
