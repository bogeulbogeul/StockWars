# 소망이 어깨·목 연결 완화 v36

v35의 기본 메시 좌표·폴리곤·재질·모션 키는 유지하고, 어깨와 목의 좁은 연결부 가중치만 조정했다. 팔꿈치나 아래팔 관절을 추가하지 않는다. 팔 본체는 단일 팔 본에 고정하며 어깨 뿌리에서만 몸통과 부드럽게 이어진다. 머리 자체는 원래 형태를 유지하고 머리 아래의 몸통 연결부가 따라 움직인다.

어깨 연결의 범위는 원본 로컬 높이 -0.055~-0.155다. 목은 -0.10~-0.015 높이의 좁은 몸통 윗부분으로, 좌우·앞뒤 범위도 제한했다. 연결부 바깥의 팔 본체를 굽히거나 길이를 바꾸지 않는다. 모든 연결 가중치에는 양 끝의 변화가 완만한 곡선을 사용한다. 영향을 받는 정점 기록은 `connections.json`에 있다.

## 검증

- v35 대비 기본 메시 위치 차이 0, 폴리곤 구조 동일.
- 본은 Body / Arm.L / Arm.R / Head 그대로다.
- 181개 반 프레임 표본에서 연결부 밖의 팔 본체는 강체 유지, 고정 몸통의 위치 변화 0.
- 팔 본체 모서리 길이의 최대 상대 수치 오차 약 0.0081% 이하, 머리 약 0.0020% 이하.
- 팔 끝쪽/얼굴, 빵/얼굴, 빵/몸통의 표면 교차 표본 0. 어깨 안쪽의 의도적 겹침은 팔 끝쪽 검사 범위 밖이다.
- 마지막 기본 자세의 최대 위치 차이 5.97e-8 모델 단위.

수치는 `verification.json`을 따른다. 미리보기는 최종 GLB를 다시 불러온 렌더이며 게임에 적용하지 않았다.

`somangi-eat.blend`는 작업 원본, `somangi-eat.glb`는 내보낸 애니메이션이다. `eat-front.gif`와 `eat-both-sides.gif`는 정면·양쪽 옆 미리보기다.
