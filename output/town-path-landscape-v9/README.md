# 효율과 미관을 함께 다듬은 마을 길 v9

P2 · ✅ 웹·기존 실행본 적용·경로 비교/시각 확인 / ⏳ 사용자 최종 시각·플레이 검수

사용자 요청에 따라 v8의 주요 직결 효과를 유지하면서 접합부를 정리했다. 정류장 접근길을 안내소 앞 연결로에 합쳐 작은 삼각형과 중복 하단 루프를 없앴고, 서쪽 산책로의 불필요한 남쪽 끝을 잘랐다. 광장 남쪽 대각선은 중앙 T자 접근으로 정리하고 동서 연결길은 완만한 굴곡을 더했다. 기존 폭/둥근 모서리·건물 정면 여백·배치·속도180·도보/포장길·회피/충돌·대본은 유지한다.

실제 충돌/동일 탐색기로 v8과 v9를 비교했다. 정류장 측 `(1120,2355)`→안내소 앞은469.02→441.46으로약5.88% 단축, 안내소→집3404.24/안내소→은행954.24/은행→잡화점2741.17은 동일하다. 집→은행은 곡선 반영으로4238.01→약4242.37(약0.1%,180속도 기준약0.02초) 차이다. v8의 원래 정류장 측 비교 출발점 `(1200,2390)`과는 다르므로 v8 문서 수치에 직접 더해 단축률을 계산하지 않는다. 문 출입·플레이어 대기 시간은 포함하지 않는다.

`townLandscapeLayout.js`를 기존 실행본에 동기화했다. `scratch/check-direct-town-routes.cjs`를 양쪽에 실행해5구간 거리 비교·장애물 교차 없음·경로의 포장길 유지·JavaScript 오류 없음 검사를 통과했다. 첫날/회피곡선/추종 안내 테스트18개도 통과했다. `previous-routes.json`·`web-checks.json`·`desktop-checks.json`에 기록하고 `web-overview.png`로 실제 전경을 확인했다. 기존 지도 그림/내장 지도는 이번에 재생성하지 않았다. 설치 프로그램 재빌드는 별도다.
