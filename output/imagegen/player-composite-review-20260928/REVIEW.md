## 방법

사용자 첨부 몸체와 각 파츠의 최종 저장 PNG 7개를 원본 크기·좌상단 (0,0) 그대로 겹쳤다. 합성 순서는 뒤 헤어 → 몸체 → 반바지 → 신발 → 반팔 → 얼굴 → 앞 헤어. 위치/크기/색상 보정, 자동 트리밍, 피부 가림 마스크는 적용하지 않았다. 원본 에셋은 변경하지 않았다. 검수 비교 이미지는 50% 최근접 표시다. 생성 모델로 다시 그린 결과가 아니다.

- review-contact-sheet.png: A 전체 / B 헤어 숨김 / C 몸체+얼굴 / D 몸체+반바지+신발
- review.html: 원본 이미지를 내장한 레이어 토글 검수 화면. 브라우저 도구의 file URL 정책으로 자동 열기 검증은 수행하지 못했다.
- measurements.txt: 원본 알파 및 경계 측정치.
- audit.ps1: 측정 및 비교 이미지 재생성 스크립트.
