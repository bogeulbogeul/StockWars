# 정면 기본 캐릭터 수정 v2

사용자 피드백에 따라 PNG를 직접 픽셀 보정했다. 기존 v1은 보존했다. 새 생성 모델이나 생성 프롬프트는 사용하지 않았다.

- 앞머리 아래쪽 길이를 늘림. 정수리 위치는 유지하고 두 눈 영역은 투명하게 보호.
- 눈: 기존 팔레트 변환으로 섞인 입 색상을 제거하고 검정/중성 회색/흰색의 눈을 직접 다시 그림. 두 눈 위치는 유지.
- 입: 검은 잡색을 모두 제거하고 단일 입 색상으로 작은 미소를 그림.
- 반바지: 중앙 허리의 피부색 틈을 메우고 가랑이 경계를 정렬.
- 신발: 각 신발을 96×64 범위의 작은 단화로 정리. 기존 한쪽 약 120×88에 비해 축소. 끈, 점, 잔반사 제거; 기본색, 작은 윗면 명암, 윤곽선만 유지.
- 신발 몸체 가림 마스크는 y1016부터 적용. 발 원본은 유지.

parts/에는 파츠 7개와 마스크 1개가 있다. 투명 합성 PNG와 preview.png를 함께 제공한다. 모든 파츠는 1222×1287, 이 작업의 정리 격자는 8px, 알파는 0/255다. 게임 최종 해상도는 미확정이며 정면 정지 1프레임만 포함한다.

selection_parts.json의 순서로 (0,0)에 합성하고, 신발 착용 시 몸체에 shoes_body_hide_mask_idle_down.png를 차감한다. revise.ps1은 이전 정리본 폴더를 입력으로 쓰는 재현 코드다. verify.ps1과 measurements.txt에는 측정 결과를 기록한다.

아트 가이드와 파츠 가이드를 다시 읽고, 제공된 기준 화풍 및 기존 합성본을 확인했다. 이번 수정 합성본은 육안 검토했으며 게임 화면에서의 최종 크기 검증은 별도다.
