# 비율 보정 v3

사용자 기준 이미지와 최신 아트/파츠 가이드를 확인하고 기존 v2 파츠를 직접 보정했다. 코드 편집에 대한 기존 사용자 승인을 적용했으며 새 이미지 생성 프롬프트는 사용하지 않았다.

- 머리 피부·귀·얼굴·헤어 앞뒤를 동일한 72% 배율로 함께 축소. 목 결합점을 기준으로 정렬.
- 몸체와 상하의·신발·가림 마스크는 가로 86%, 세로 110%로 함께 조정. 접지점 y1080 유지.
- 정수리 본체부터 턱까지의 길이와 턱 아래 몸 길이가 비슷하게 읽히는 약 2등신을 목표로 수정. 위로 튀어나온 잔머리는 등신 계산에서 제외.
- 검정 눈/헤어, 흰 반팔, 검정 반바지, 작은 단화 유지. 입은 축소 중 소실을 막기 위해 작은 미소로 재정리.
- 픽셀 격자에 맞춰 최근접 재배치, 알파 0/255 유지. 원본 v2 보존.

parts/의 파츠 7개 및 몸체 가림 마스크를 selection_parts.json 순서로 조립한다. 모든 캔버스는 1222×1287이고 좌상단 (0,0)에 놓는다. 신발을 착용할 때 mask.alpha를 몸체 알파에서 차감한다. 마스크를 화면에 직접 그리지 않는다.

preview.png: 수정본 / comparison.png: 같은 배율과 접지선으로 좌측 이전, 우측 수정 / player_composite_idle_down.png: 투명 합성본.

build.ps1은 v2 폴더의 PNG를 입력으로 재현한다. verify.ps1과 measurements.txt에서 크기·반투명·눈 가림을 확인한다.

정면 정지 비율 수정본이며 원본 샘플의 눈매·헤어 필치를 완전히 재현했다고 확정한 것은 아니다. 실제 게임 해상도와 표시 크기는 미확정이다. 이번 비율에 맞춘 파츠끼리 사용하고 이전 몸체용 파츠와 혼합하지 않는다.
