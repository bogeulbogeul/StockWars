# 정면 기본 캐릭터 정리본

사용자가 코드 보정을 승인하여 기존 생성 PNG를 C# / System.Drawing으로 직접 정렬하고 정리했다. 원본은 모두 보존했다. 이 패키지는 정면 정지 1프레임의 조립 검수본이다.

## 포함 파일

- parts/: 몸체, 얼굴, 숏컷 앞뒤, 흰 반팔, 검정 반바지, 검정 신발의 독립 RGBA PNG 7개와 신발용 몸체 가림 마스크 1개.
- player_composite_idle_down.png: 실제 파츠와 마스크를 조립한 투명 합성본.
- preview.png: 배경 위 50% 최근접 미리보기.
- selection_parts.json: 합성 순서, 팔레트, 캔버스, 마스크 적용 방법.
- build.ps1 / verify.ps1: 보정 및 검수 코드. 재실행에는 기록된 원본 경로가 필요하다.
- measurements.txt: 실제 파일 측정 결과.

## 수정 사항과 검수

- 모든 파츠를 1222×1287 캔버스에 원점 유지, 자동 트리밍 없이 저장.
- 8px 정리 격자와 슬롯별 제한 팔레트 적용. 소재 3단계와 유색 윤곽선; 눈·입 추가색 허용. 피부 내부 작은 색상 잡음 정리.
- 반팔 어깨를 위로 맞추고 밑단을 y927로 단축. 반바지 밑단 y983, 신발 접지 y1088.
- 반투명 픽셀은 0개이며 모든 알파는 0 또는 255.
- 얼굴 마크 전체의 헤어 가림 0%. 상의가 하의를 덮는 면적은 기존 69.8%에서 44.6%로 감소.
- 신발 아래 발 피부는 별도 가림 마스크로 처리. 마스크 적용 영역의 발 피부는 100% 숨김. 맨몸 PNG에는 발을 유지한다.
- 합성 미리보기에서 어깨, 손, 반바지, 드러난 발목, 신발을 확인했다.

## 적용

모든 레이어는 같은 (0,0)에 놓는다. 신발 착용 시 몸체 알파에서 shoes_body_hide_mask_idle_down.png의 알파를 먼저 차감한 뒤 JSON 순서대로 합성한다. 마스크를 화면 위에 흰 그림으로 렌더링하지 않는다. 파츠마다 독립적으로 크기/위치를 조정하지 않는다.

이번 8px 정리 격자와 큰 PNG 캔버스는 납품본의 수치이며 프로젝트 최종 게임 해상도를 확정한 것이 아니다. 실제 게임 표시 크기, 다른 방향과 걷기, 다른 헤어·피부색 조합 및 엔진 연결은 이번 검수 범위에 포함하지 않는다. 문서의 전체 제작 명세 완료나 최종 게임 에셋 승인으로 표기하지 않는다.

지난 image_gen 시도와 프롬프트는 README.md에 보존했다. top_candidate.png와 shoes_candidate.png는 채택하지 않았다. 최종 정리본에는 새 생성 프롬프트 없이 사용자 승인하에 위 코드 보정을 사용했다.
