# 타이틀 복귀 크레파스 버튼

사용자 요청으로 기존 게임 시작 버튼을 참고해 별도 투명 PNG를 만들었다. 내장 image_gen 편집으로 노란 크레파스 색면·초록 이중 윤곽·손글씨를 유지하고 문구만 `타이틀 화면으로 가기`로 변경했다. 외곽 투명 여백만 trim했으며 배경 프레임에 합성하지 않는다.

- 원본 생성: `generated.png`, 전달본: `return-button.png` (2145×570, 알파 포함).
- 게임: `web/assets/title/flipbook-v1/return-button.png`.
- `SleepEnding.js`의 buttonImage 옵션으로 독립 HTML 버튼에 연결한다. 점선 포커스는 추가하지 않는다.
- 웹·기존 실행본 리소스 반영. 설치 프로그램 재빌드는 별도.

프롬프트 요약: 기존 시작 버튼의 모양·색·크레파스 결을 유지하고 문구를 한 줄 `타이틀 화면으로 가기`로 교체. 외부는 투명, 점선·그림자·3D 없음.
