# 소망이 단일 먹기 모션 — 음식 전체 축소

P1 (Major) · ✅ 단일 모션 제작·손 접촉·형상 보존 검사 / ⏳ 사용자 최종 시각 검수

사용자 요청으로 음료수 모션은 이번 결과에서 제외했다. 이전 제작 원본은 보존하고 이 폴더에는 컵·음료 오브젝트나 음료 마시기 클립을 넣지 않는다.

- `somangi-eat.glb`: 단일 `Eat_Bread` 3초 클립.
- `somangi-eat.blend`: 편집 원본.
- `eat-shrink.gif`: 실제 GLB를 재생한 정면 3초 반복 미리보기.

빵 전체의 가로·세로·깊이가 먹는 타이밍에 맞춰 100% → 82% → 64% → 46%로 작아진다. 베어 문 부분만 제거하는 이전 v4와 구분한다. 작은 빵도 손에 붙도록 한 손으로 받치는 기존 보정 자세를 사용하고, 고정된 손 표면 접촉점을 축소 기준으로 삼았다. 다른 팔은 편하게 내린다. 빵의 점수선과 재질도 함께 축소된다.

소망이의 기본 메시·법선·UV·검은 눈과 보정된 어깨 형상은 유지한다. 기준 체형의 휴지 형상 해시가 동일하다. 캐릭터의 형상 버퍼와 모프 재생 트랙은 기존 한 손 동작 원본과 바이너리 기준 동일하며, 새 신체 변형은 추가하지 않았다. 소품 애니메이션만 새로 맞췄다.

`validation.json`은 181개 시점에서 손 접촉 기준점 오차, 빵 배율의 단조 감소, 마지막 배율 및 음료 오브젝트 제외 여부를 기록한다. `export-validation.json`은 캐릭터 속성 버퍼 70개와 모프 트랙의 동일성을 기록한다. GLB의 캐릭터 모프 트랙과 빵의 transform 트랙을 함께 재생한다.

한 번 먹고 작은 빵이 남는 비반복 동작이다. GIF가 반복되면 새 빵으로 되돌아가며, 게임 파일은 변경하지 않았다.
