# 업적 앱 디자인 v1

사용자 후속 요청 “다음에 업적앱도 디자인하고 알아서 만들어줘”에 따라 별도 확인을 요구하지 않고 디자인/게임 적용을 이어갔다. 연한 금색 요약·파스텔 평면 배지·달성/진행 중 필터·조건/진행도 상세·상단 홈으로 구성했다. 동일 실제 컴포넌트를 격리된 예시 상태(3/8 달성)로 렌더링해 preview.png를 촬영했다. 게임에는 예시 달성 기록을 주입하지 않는다.

기존 구형 AchievementApp는 폐기된 의뢰/칭호 기능과 연결되어 있어 복원하지 않는다. 새 앱은 실제 현재 진행에서 읽는 별도 read-only 업적 화면이다. 게임 적용 기록은 ../achievements-app-game-v1/README.md를 따른다.
