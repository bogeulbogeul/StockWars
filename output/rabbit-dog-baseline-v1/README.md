# 유럽토끼 · 강아지 v9 공통 모션 스프라이트 v1

2026-10-17 사용자 요청으로 제작했다. `output/rabbit-design-2026-10-17-v1/design-sheet.png`를 외형 참고, 기존 유럽토끼 정면을 색 참고, 강아지 v9의 행동별 행을 자세·시점·순서 참고로 사용했다. 내장 image_gen으로 방향/행동별 완성 행을 생성했다. 원본과 전체 프롬프트는 `generation.json`, 교정 행은 `retakes.json`, 사용 이미지 원본은 `raw/`다.

## 구성

정면·앞오른쪽 사선·뒤 정지/걷기, 운반4그림, 정면·사선 의자 앉기, 얼굴과 긴 귀만 포함한 초상화다. 강아지와 동일10상태·19논리 항목·16고유 그림, 320×400셀·1280×4000시트다. 걷기는3그림을0→1→2→1,각160ms로 재생한다. 정지는 해당 걷기 중립과 동일 PNG다. 운반은 강아지의 사용자 확정 순서인 접지/통과/반대접지/반대통과를 따른다.

사선 B는 가까운 다리가 뒤로·가까운 팔이 앞으로 움직이고 먼쪽 팔은 몸통에 가린다. 뒷발은 발가락 선 없는 둥근 뒤꿈치다. 꼬리는 골반 뒤 중앙의 작은 아이보리 솜방울이며 A/B에서 약간 반대쪽으로 기울어진다. 초기 뒤 꼬리의 큰 강아지형 형태와 운반 마지막 통과 자세 반복은 리테이크로 수정했다. 앞·사선 발의 작은 손발가락 구분은 유지하고 모든 방향에 발바닥 패드·별도 발바닥 면을 추가하지 않았다.

## 색·추출·검수

sprite-gen 크로마 제거·연결 성분 추출을 사용하고 같은 행에는 공통 배율을 적용했다. 각 그림 높이를 개별적으로 늘여 맞추거나 팔다리 워핑·리깅·고정 머리 붙이기를 하지 않았다. 토끼 정면에서 몸256색·눈48색 후보의 중복을 합친 공통289색을 만들고 sprite-gen recolor로 전 프레임을 정규화했다. 디더링 없이 알파를 보존한다. `palette.json`, `palette.csv`가 정확한 RGB 목록이며 `baked-final/recolor.report.json`이 베이크 기록이다.

`verify.py`는 전체19항목의 시트 픽셀·여백·중립·RGB 목록과 강아지의 좌표/재생 구성 일치를 확인한다. `validate-preview.cjs`는 프리뷰 렌더 경로 검사다. 개별 자세의 팔/다리 겹침·뒤꿈치·꼬리 위치와 형태를 정적 보드에서 확인했다. 이는 실시간 동작 연결·발 미끄러짐·재질별 명암 분포 변화의 최종 통과를 뜻하지 않는다. 걷기는 experimental 시안이며 게임에는 아직 설치하지 않았다.

`preview.html`은 강아지 v9와 토끼의 동시 재생 비교다. `rabbit/review-final.png`는 전체 자세, `rabbit/run/sprite-sheet-alpha.png`는 투명 시트, `rabbit/run/manifest.json`은 좌표·재생, `qa/`는 각 걷기와 운반 GIF다. 기존 게임 토끼·다른 동물 파일과 캐릭터 기준은 교체하지 않았다.

재조합은 build → palette → sprite-gen recolor(baked-final) → publish → rear-palette → sprite-gen recolor(baked-rear) → merge-rear → publish → verify 순서다. 뒷모습에는 분홍 귀 안쪽·눈 색이 필요하지 않으므로 기존289색 중 털·크림·윤곽선 계열172색으로 제한한 추가 베이크를 사용한다. 초기 귀 색 혼입 결과는 최종본에 채택하지 않았다.
