# 고양이 옆 정지 윤곽 보정 v10

사용자가 지적한 꼬리 연결부 인근 몸통의 뾰족한 겹선·돌출부만 built-in GPT imagegen으로 매끈하게 수정했다. 원본 v9의 고양이 외형·볼털·가슴털·강아지 기준 셀 명암은 유지했다.

- ✅ 완료: 옆 정지와 같은 그림을 공유하는 옆 걷기 중립에 함께 적용.
- ✅ 완료: 해당 그림의 x198~241/y265~389 국소 창 밖 RGBA 동일 검사. 다른 동작과 다른 두 옆 걷기 자세는 그대로다.
- ✅ 완료: 원본 고양이 기본색·그림자색·윤곽색으로 국소 보정본 베이크. 시트 좌표·재생 계약·160ms 유지 및 정지/중립 동일 검사.
- ✅ 완료: 걷기/운반 GIF4재생 프레임·160ms 확인.
- ⏳ 대기: 사용자 외형 확인. 게임 설치는 하지 않았다.

sprite-sheet-alpha.png와 manifest.json이 전달본이다. before-after.png는 왼쪽 이전/오른쪽 수정 확대 비교다. outline-generated.png는 GPT 편집 원본이며, package_fix.py가 국소 수정만 최종 시트에 반영했다. 생성 요청: 기존 옆 정지의 꼬리 연결부 인근 허리 왼쪽의 불필요한 뾰족한 겹침을 자연스러운 둥근 윤곽으로 정리하고, 꼬리·팔·나머지 그림을 보존한다.
