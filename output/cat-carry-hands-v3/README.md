# 고양이 운반 손 표현 v3

2026-10-18 사용자 첨부 강아지 손 참고 반영. 기반은 `../cat-color-cleanup-v2/`이며 기존 보정본은 보존한다.

- ✅ 완료: 둥근 앞손·뒤손, 위쪽 엄지 돌기, 짧고 또렷한 손가락 곡선과 손의 앞뒤 겹침을 강아지 참고에 맞춰 국소 편집했다.
- ✅ 완료: built-in imagegen으로 만든 손 영역을 운반4그림의 기존 손목 위치에 맞춰 조합하고 고양이 디자인 시트의42색으로 sprite-gen 베이크했다.
- ✅ 완료: 지정 손 영역 밖 RGBA 동일, 다른9상태 전체 동일, 재생 좌표·운반4그림·160ms 동일 검사. 손 모양을 바꾼 영역의 실루엣/알파는 수정 범위에 포함한다.
- ⏳ 대기: 사용자 최종 손 표현 확인·게임 적용·실제 화물 접촉 검수.

`sprite-sheet-alpha.png`, `manifest.json`이 전달본이다. `right-carry.gif`와 `preview.html`에서 재생을 확인한다. `hand-comparison.png`는 위부터 강아지 참고 / 이전 고양이 / 수정 고양이, 왼쪽부터 운반0~3번이다.

생성 도구: built-in image_gen. 생성 원본 `hand-edit-generated.png` 전체를 설치하지 않고 손 영역만 사용했다. 생성 입력은 고양이 운반0번(편집 대상), 최신 강아지 운반0번과 사용자 강아지 손 확대(손 형태 참고)다. 정확한 요청은 `edit-prompt.txt`, 조합 영역·검증은 `package_hands.py`와 `validation.json`에 남긴다. 강아지의 밝은 털색을 복제하지 않는다.
