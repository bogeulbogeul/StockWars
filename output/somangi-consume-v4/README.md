# 소망이 음식 감소 연출

P1 (Major) · ✅ 제작·캐릭터 데이터 동일성·음식 감소 검사 / ⏳ 사용자 최종 시각 검수

사용자 참고: [친구모아 아파트 먹는 영상](https://www.youtube.com/watch?v=_grzDhus1O8). 먹는 구간의 손을 입 가까이 유지하는 흐름과 음식 감소만 참고한다. 영상 후반의 과장된 리액션이나 얼굴 디자인은 적용하지 않는다. 기준 모델은 `../somangi-eat-drink-grip-v3/`다.

- `somangi-bread.glb` / `.blend`: 기존 먹는 구간에 맞춰 3번 베어 문 자국이 생기고 남은 빵의 부피가 줄어든다. 빵 전체를 축소하지 않고 손에 닿는 아래쪽은 유지한다. 마지막에는 작은 빵 조각이 손에 남는다.
- `somangi-drink.glb` / `.blend`: 컵의 크기와 잡는 위치는 그대로 두고, 내부 음료 표면이 3차례 내려간다. 음료의 수면 반경은 컵 내부의 경사에 맞춰 줄인다.
- `bread-consume.gif`: 정면에서 본 빵 먹기, 3초 반복.
- `drink-consume.gif`: 컵 안 수위가 보이도록 위에서 비스듬히 본 음료 마시기, 3초 반복.

각 GLB는 1회 소비 동작이다. GIF 반복 시 처음의 온전한 빵·채워진 음료로 돌아가는 것은 미리보기 루프다. 실제 게임에서는 비반복 재생을 사용하거나 새 음식 제공 시 처음으로 재설정한다. 게임 적용은 하지 않았다.

## 보존과 검증

소망이의 기본 메시·법선·UV·모든 모프 형상과 모프 재생 트랙은 직전 GLB와 바이너리 기준 동일하다. 어깨 보정, 검은 눈, 손에 붙는 소품 루트의 위치·회전·배율 애니메이션도 변경하지 않았다. 손에 닿는 빵 아래쪽과 컵 외형을 유지하며 음식 자체에만 감소 연출을 추가했다.

`export-validation.json`은 각 캐릭터의 형상 속성 버퍼 70개와 모프 애니메이션 트랙의 동일성을 기록한다. `food-validation.json`은 빵 4단계의 메시 부피가 순차 감소하고, 각 단계 하나만 표시되는지 및 음료 수위가 순차 감소하는지 확인한 결과다. 실제 내보낸 GLB를 다시 불러와 렌더링해 확인한다. 음식 단계 전환과 음료 이동 트랙도 캐릭터 모프 트랙과 함께 재생해야 한다.
