# 강아지 기준 모션 보정

후속 수정: 사용자 검토에서 색이 진해지고 토끼 뒤 외형 갱신이 누락된 점을 확인했다. 최신 채택본은 `output/motion-color-restore-v2/`이며 이 폴더의 원본·run·ZIP은 수정 전 제작 이력이다. 이 폴더의 preview.html은 최신 after 이미지를 표시하도록 갱신했다.

강아지 원본을 변경하지 않고 고양이와 숲속 친구들 6종의 정면·사선·뒷걷기 및 운반 28개 행을 네이티브 이미지 편집으로 다시 제작했다. 기존 중립을 그대로 유지하여 총 63개 완성 프레임을 교체했다. 걷기 3그림, 재생 0→1→2→1, 프레임당 160ms와 기존 atlas 좌표는 유지한다.

generation.json은 28개 생성의 실제 프롬프트·참조·원본 경로다. 종별 *-native.png는 생성 원본이며 before/는 이번 작업 직전 사본이다. 추출은 sprite-gen의 크로마·연결요소 기능을 사용한다. 행마다 하나의 등방 배율과 강아지 대비 머리 기준점 이동만 적용한다. 꼬리를 포함한 전체 바운딩박스로 중심을 재계산하지 않는다. 머리·상체 합성 실험은 목 경계 때문에 제외했으며 최종본은 완성 네이티브 프레임이다. 리깅·프레임 보간·리타이밍은 사용하지 않는다.

preview.html은 강아지/보정 전/보정 후를 같은 박자로 비교한다. 4종 모션 보드의 색·외형·윤곽·발바닥 패드 없음과 프레임 경계/atlas 일치·중립 유지·GIF 프레임 및 시간을 확인했다. 브라우저 file URL 접근 제한으로 실시간 브라우저 시각 검수는 하지 못했다. 실제 게임 내 발 접지·미끄러짐·화물/가구 접촉과 물리 보폭은 미검증이다. 완전한 모션 품질 통과로 해석하지 않는다.

현재 채택본은 output/style-unification-v3/ 및 기존 종별 전달 경로에 반영한다. 고양이 게임 atlas에 반영하며 숲속 6종은 아직 게임에 통합되지 않았다. 강아지 PNG는 작업 전과 바이트 동일하다.
