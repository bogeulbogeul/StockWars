# 포포리빵 갓 구운 표면 v3

양 끝의 인위적인 형상 후속 수정은 [v4](../popori-bread-soft-ends-v4/README.md)를 따른다. v3 표면 맵은 유지하며 형상은 v4가 우선한다.

v2의 통빵 형태·끝부분·종이 포장·꽃/잎 인쇄를 유지하고 빵 표면만 수정했다. 넓고 흐릿한 구움 얼룩을 작은 황금빛/호박색/갈색 무늬와 미세한 구움 점으로 바꿨다. 잔잔한 기공 노멀과 거칠기 변화, 얇은 코팅 윤기로 매끈한 플라스틱 같은 반사를 줄였다. 새로운 단면·속재료·자른 칼집·장식은 추가하지 않았다.

구움 색·기공 노멀·거칠기는 UV 이미지로 만들어 GLB에 내장했다. 조명 하이라이트는 그림에 구워 넣지 않고 실제 렌더에서 계산한다. `prepare.py`가 고정 시드로 표면 맵을 재현하고, `build.py`가 원본과 GLB를 만든다. `verify.py`는 내보낸 GLB를 다시 불러와 파일 구조·유한 정점·퇴화면·이미지 디코딩을 검증하고 확대 렌더한다. 정확한 수치와 해시는 `validation.json`을 따른다.

v2는 이력으로 보존하고 이번 v3를 후속 제작본으로 사용한다. 다른 상품·게임 UI·저장·가격·실행본은 변경하지 않았다. 게임 적용과 사용자 최종 시각 검수는 별도다.
