# 상점 상품 12종 — 개별 수정본 목록

후속 사용자 요청으로 [게임 적용·진열 v1](../shop-items-game-v1/README.md)에 웹·기존 실행본 적용을 완료했다. 이 문서와 manifest의 `assets_only_not_deployed`/`deployed:false`는 제작 시점의 원본 감사 기록이며, 현재 배포 상태는 후속 적용 기록을 따른다.


2026-10-25. 사용자 피드백을 순서대로 반영한 최신 개별 제작본이다. 파일별 SHA-256이 실제 재수입 검증 기록과 일치함을 확인했다. 기존 일괄 제작본은 이력으로 보존한다.
