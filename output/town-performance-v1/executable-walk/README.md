# 기존 실행본 직접 실행 · 마을 이동 성능 검증 — 2026-10-25

✅ 완료. Edge에서 실행본 리소스만 여는 검사가 아니라 `electron-app/dist/win-unpacked/StockWars Demo.exe` 자체를 실행해 측정했다. 소스/배포 파일을 추가 수정하지 않았다.

## 실행 환경과 절차

- 실제 실행 경로와 SHA256은 `executable-hash.json`, 프로세스 ID는 `process-id.txt`에 기록했다.
- 실행본 식별: stockwars-electron/1.0.9, Electron28.3.3, Chromium120.0.6099.291.
- GPU: AMD Radeon(TM) Graphics, ANGLE Direct3D11. 콘텐츠1264×741, DPR1, document.hidden=false.
- 별도 테스트 프로필로 실행하고 실제 시작 버튼·인트로 건너뛰기를 눌러 마을에 진입했다. 낮 음악을 켠 상태로 첫 로딩과 음악 준비를 기다렸다.
- 대화 진행 대기는 이 테스트 세션 안에서만 해제했다. 이동은 실행본의 기존 WASD 입력과 SeatInteraction의 마을 걷기·충돌·SomangiPlayer 걷기 모션·따라가는 카메라를 그대로 사용했다. 대체 렌더러나 가짜 이동 루프는 사용하지 않았다.
- 각 구간 시작점 배치는 측정 밖에서 한다. 측정 구간에서는 실제 키 입력으로 약600게임 단위를 갔다가 시작점으로 돌아온다. 도착 판정을 만족한 프레임에서 키를 놓아 마지막 한 프레임 이동량 이내의 오차가 있다. 중간에 좌표를 순간이동시키거나 충돌을 끄지 않았다.
- 세 경로: 입구 연결로 `(1960,2290)`→`(1960,1690)`, 광장 남쪽 `(1450,1750)`→`(2050,1750)`, 북쪽 연결로 `(1300,1160)`→`(1900,1160)`.
- culling 꺼짐→켜짐→켜짐→꺼짐 순서로 각 경로를 총4회 왕복했다. 구간 시작 후700ms 준비 시간을 제외했다. 두 조건 모두 현재 다른 기능과 가림 판정 최적화는 유지되며, 화면 밖 렌더링 생략의 효과를 비교한다. 원래 배포 전체 코드를 통째로 롤백한 비교는 아니다.
- 계측은 실행 중인 Electron의 DevTools Protocol에 연결해 수행했다. Edge/Chrome 테스트 브라우저를 별도로 띄우지 않았다.

**이 실행본에서도 걷는 중 평균 성능과 긴 프레임 발생 빈도가 개선됐다.** 광장·북쪽은 긴 프레임이 크게 줄었다. 입구 연결로는 개선 후에도50ms 초과 프레임이 약10% 남아 있어, 프레임 드랍 완전 제거/고정60FPS로 판정하지 않는다. 이 장치·해상도·날씨·세 경로의 표본이며 다른 모든 상황의 보증은 아니다.

총1,868프레임 중1,856프레임에서 실제 좌표 변화와 walk 상태를 확인했다. 불법 충돌 위치0프레임, 화면 숨김0프레임, 관찰된 JavaScript 오류0건이다. `walk-results.json`에 프레임별 좌표·소요시간·걷기 상태·충돌·그리기 호출을 보존했고 `summary.json`에 합산 결과가 있다.

## 화면 보존과 종료

- 같은 실제 Electron 실행본에서 세 경로의 시작·중간·끝9개 지점마다 동일 프레임의 culling 꺼짐/켜짐 이미지를 비교했다. **9쌍 모두 픽셀 차이0개**다. `pixel-diff.json` 및 `*-baseline.png`·`*-optimized.png`를 참고한다.
- `entry-walk.png`·`plaza-walk.png`·`north-walk.png`는 실제 실행본의 경로 확인 화면이다. 대표 광장 화면도 직접 열어 검토했다.
- 계측 함수를 제거하고 culling을 켠 상태로 복구했음을 확인한 뒤 이번 테스트용 실행본을 정상 종료했다. 실제 게임/배포 소스나 저장 스키마는 변경하지 않았다.

## 자료 구분

`pilot-*`는 최초 고정 시간 키 입력으로 경로 길이가 달라졌던 탐색 측정이다. 최종 판정에는 사용하지 않았다. 최종 검증은 `walk.cjs`의 도착점 기반 측정과 `walk-results.json`·`summary.json`·`visual-check.cjs`·`pixel-diff.json`을 사용한다.
