# 은행 대기용 2인 소파 — 새 모델 v1

사용자가 제공한 Meshy Cedar Haven Sofa를 형태 참고로 삼아 새 지오메트리로 제작했다. 원본과 이전 최적화본은 보존했다.

- 일체형 U자 목재 프레임과 윗띠, 바닥까지 내려오는 양쪽 패널
- 얇은 좌판 받침, 긴 좌판 쿠션 1개와 낮은 등쿠션 1개
- 안팎 패널의 얕은 세로 홈, 무광 목재와 크림색 천
- GLB: 29,228 삼각형 / 880,768 bytes / 이미지 텍스처 없음
- Bank-sofa-native.blend: 조명·카메라를 제외한 편집 원본
- front-right.png, front.png, rear.png: 확인용 렌더
- build_sofa.py: 재제작 스크립트

GLB 구조와 세 방향 렌더를 확인했다. 게임 배치 및 실제 카메라에서의 검수는 아직 진행하지 않았다.
