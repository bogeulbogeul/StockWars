# 소망이 배 옆면 꺾임 보정 v13

이전 v12의 위치별 전환 보정에서 남던 배 옆면 눌림·각진 윤곽을 수정했다. 게임 및 실행본에는 설치하지 않는다.

## 최종 구성

- 원본 `somangi-eat-drink-grip-v3`의 몸통·다리 휴지 표면을 기준으로 하부 몸체를 연속 메시로 정리했다. 팔 아래 숨은 접힘은 내부로 정리하고 원본 단면을 참고한 보강 곡면과 합친다. 연결 경계는 닫힌 메시로 재구성하고 매끈하게 정리한다.
- 전체 몸통 가로 폭과 앞뒤 두께는 원본 기준에 맞춘다. 원본과의 차이 각각 0. 먹는 동안 하부 몸체 정점의 변위 0.
- 기존 얼굴·양팔의 모션 정점은 유지한다. source 16개 표본(1,7,…91프레임)과 차이 0. 손과 빵의 위치·축소 트랙도 유지한다.
- 원본 미소 텍스처를 그대로 표시한다. 먹는 구간에만 임시 가림과 세로 타원 입이 나타난다. 눈 재질은 기존 검은색 그대로다.
- 몸통·다리 연결을 재구성했으므로 **원본과 정점·토폴로지가 동일한 모델은 아니다**. 무광 몸체 색은 원본 텍스처에서 취하고 새 곡면의 UV 이음선이 드러나지 않게 단색 재질로 적용한다. 발 하부는 곡면 정리의 대상에서 제외하지만 표면 재샘플링은 적용된다.

`validation.json`: 원본 몸통 폭·두께, 얼굴/팔 모션, 하부 몸체 고정, 닫힌 하부 메시의 비다양체 경계 0 검사. 모든 삼각형 간 교차 검사는 아니다.

`somangi-eat.glb`를 재수입해 정면·왼쪽 정측면 각 36프레임의 3초 GIF를 촬영한다. 이전 제작 파일은 별도 폴더에 보존한다.
