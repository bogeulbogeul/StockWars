# 1인 소파 착석 동작 확인

기존 `somangi-bench-sit-v2`의 올라앉기·앉은 자세 유지·내려오기 모션을 새 1인 소파와 조합한 확인용 장면입니다.
게임과 같은 캐릭터 배율(1/1.95)을 사용하고 골반 접촉 정점으로 좌판 위치를 맞췄습니다.
기존 벤치용 발이 볼록한 쿠션에 들어가는 부분은 확인용 모션 복사본에서 다리 위치를 최대 게임 3.333 단위 위로 보정했습니다.
현재 게임용 걷기/인사/먹기/점프와 원본 벤치 모션은 변경하지 않았습니다.

- `sofa-sit-motion.gif`: 올라앉기·유지·내려오기 미리보기.
- `seated-angle.png`, `seated-side.png`: 착석 사선/측면 확인.
- `Sofa-somangi-sit-preview.blend`: 확인 장면/보정 모션.
- `fit-report.json`: 11개 시점, 캐릭터 정점 8개당 1개를 표본으로 본 팔걸이/등받이/좌판 침범 검사. 보정 후 표본 침범 0.

이는 접촉과 모션 확인용이며 게임의 F키 착석·일어서기 상태 전환은 아직 연결하지 않았습니다.
벤치용 이전 캐릭터 몸체를 재사용한 프리뷰이므로 최신 게임 몸체와의 정합·모든 프레임/정점 충돌 검수 완료를 뜻하지 않습니다.
