# 소망이 먹는 표정 — 2026-10-19

기본 타원 눈은 유지하고 입만 작은 검은 타원으로 벌린 한입 먹기용 표정이다. 기존 UV에서 입 주변 Base Color를 교체하며 메시·본·웨이트는 변경하지 않는다.

- `eating-front.png`, `eating-face.png`, `eating-angle.png`, `eating-side.png`: 실제 모델의 방향별 표정 렌더.
- `eating-basecolor.png`: 기존 UV에 적용하는 전체 Base Color 텍스처.
- `somangi-eating.glb`, `somangi-eating.blend`: 표정이 적용된 정지 자세 모델·편집본.

새 입체 구강이나 씹기 애니메이션을 추가한 버전은 아니다. 기존 먹기 v3의 머리도 같은 UV를 사용하므로 표정 텍스처를 교체할 수 있지만, 이번 산출물에서 먹기 클립의 시간별 표정 전환이나 게임 적용은 수행하지 않았다. 기본·웃는 표정과 기존 걷기·앉기·먹기 파일은 보존한다.
