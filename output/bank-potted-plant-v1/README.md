# 은행 크림 화분 v1

사용자 참고의 둥근 크림 도기, 넓은 초록 잎, 화분 옆으로 흐르는 덩굴잎을 네이티브 메시로 제작했다. 무광 단색 재질과 실제 두께를 가진 잎을 사용한다.

규격 약 .696×.735×.814. 게임 wave.glb 첫 프레임의 신체 높이 .97425(원본 배율 1/1.95) 대비 전체 높이는 약 .836H. 소망이와 함께 비교 렌더를 확인했다. H=1 정규화 환산 규격 약 .715×.755×.836H. 331,896 bytes, 이미지 텍스처 없음.

✅ 모델 제작·단독/소망이 비교 렌더 / ⏳ 룸 배치·게임 연결·사용자 검수. GLB와 Blender에는 화분만 포함하며 scale.png의 소망이·조명·바닥은 비교용이다.
