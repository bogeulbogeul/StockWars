# 봉봉 앞치마 허리끈 연장 v2

2026-10-22 · P1 (Major) · ✅ 양쪽 끈 연장·6방향 렌더·GLB 재수입 검사 / ⏳ 사용자 외형 확인·전체 모션 접촉 검수·게임 적용.

사용자 요청으로 짧은 허리끈을 봉봉의 둥근 몸에 맞춰 늘렸다. v1의 제공 Meshy 앞치마 메시·앞판·주머니·어깨끈·뒤 리본·UV·텍스처와 봉봉 몸체는 유지하고, 옆면에서 끊겨 보이던 허리끈에 좌우 연장 메시를 추가했다. 앞판 옆 테두리부터 기존 뒤 허리끈까지 몸 표면을 따라 이어진다. 연장 끝부분은 폭을 줄여 기존 끈에 겹쳐 연결하며, 원본 재질의 코랄 텍셀을 공유한다. Body 본을 함께 따른다.

- `Bongbong-long-ties.blend`: 편집 원본.
- `Bongbong-long-ties.glb`: 착용 모델·리그·기존 걷기 클립.
- `Apron-long-ties.glb`: 앞치마·연장 끈·공통 리그.
- `front.png`, `left.png`, `right.png`, `back.png`, `three-quarter.png`, `rear-quarter.png`: 실제 렌더.
- `extend.py`, `validation.json`, `export-validation.json`: 생성 및 검사 기록.

정면·양측면·후면·앞뒤 사선에서 끈 연결을 시각 확인했다. 내보낸 GLB를 다시 불러와 연장 메시 2개·단일 리그·걷기 클립을 확인했다. 원본 고밀도 앞치마 감면이나 게임 파일 교체는 하지 않았다. 기존 끈과 연장부는 별도 메시의 겹침 연결이며 용접한 단일 토폴로지를 뜻하지 않는다. 전체 모션에서 팔과 끈의 접촉 검수는 미완료다.
