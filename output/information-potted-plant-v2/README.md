# 서랍장 화분 v2

P1 (Major) · ✅ 메시 재조형 / ⏳ 사용자 검수·게임 적용

후속 사용자 선호 확인: v2가 더 예쁘다는 응답에 따라 안내소 후속 조합에는 이 버전을 사용한다. 게임 적용은 별도다.

긴 줄기와 흩어진 잎 대신 화분 중심에서 넓은 타원형 잎 9개가 짧고 풍성하게 모이도록 직접 메시를 만들었다. 잎은 두께와 완만한 굽힘을 가진 닫힌 입체 형상이며 끝을 둥글게 좁혔다. 화분은 통통한 크림색 도자기, 실제 안쪽 벽과 낮게 들어간 흙으로 구성한다. Meshy 생성본이 아닌 Blender 직접 조형본이다.

- `Small-potted-plant-v2.glb`, `Small-potted-plant-v2.blend`: 독립 모델/원본
- `plant.png`: 단독 확대
- `cabinet-detail.png`, `Office-plant-v2-preview.blend`: 서랍장 장식의 화분만 교체한 조합
- `build_plant.py`, `manifest.json`: 재현과 상태

다른 장식·가구·최신 안나·통로 확보 배치는 유지했다. v1과 게임 파일은 변경하지 않았다.
