# 정착 자금 대출 신청서 v1

은행 서식 제02호로 기존 BankApplication을 확장했다. 신청인·정착 자금·EXHIBITION.loan의 5,000잎·차곡이 담당을 표시하고 대출 원금/이자·상환 일정 미정/첫날 체험 청구 없음의 기존 설명을 유지한다. 안내 확인 체크 후 기존 이름 서명·1.5초 전달 연출을 거쳐 기존 next('loan')을 호출한다. 계좌 개설 서식은 유지하고 대출/저장/경제 산식은 변경하지 않았다.

웹과 기존 실행본에 3개 파일 반영. 설치 프로그램 재빌드는 하지 않았다. scratch/check-loan-application.cjs로 1280×900·390×844·844×390 화면 경계·이름 표시·확인 전 제출 차단·서명·지연 제출 검증 통과. 전시 상태 테스트 6개 통과. PNG는 독립 UI 렌더이며 게임 내 최종 플레이 검수는 별도다.
