현행 상점 공통 이미지 `web/assets/items/packing-v1/items.png`의 `1210,430,340,330` 영역을 직접 확인했다. 원본의 청록색 물방울 젤리·아래쪽의 연한 민트색·밝은 크림색 주름 종이컵을 따른다. 기존 짧은 원뿔형을 둥근 배와 부드럽게 좁아지는 꼭대기가 이어진 연속 곡면으로 변경했다.

젤리의 색 변화는 정점 색으로 내장했다. 약한 투과·굴절·코팅 재질을 사용하고, 흰 하이라이트는 그림을 붙이지 않고 실제 조명에서 만든다. 작은 표면 장식·별도 물방울·속재료·문자는 추가하지 않았다.

종이컵은 18개 주름과 물결 모양 윗단, 얇은 안팎 벽과 닫힌 바닥을 포함한다. 젤리 밑면은 컵 내부 바닥 높이 0.055에 맞춰 놓았다. 컵은 무광 크림색/밝은 종이색으로 구분하며 두꺼운 도자기 받침이나 접시는 사용하지 않는다. 상품 전체가 두 개의 네이티브 메시이고 외부 이미지 텍스처는 필요하지 않다.

GLB 파일 구조·Blender 재수입·유한 정점·퇴화면 0개를 검증하고 전체·재수입 확대·후면 렌더를 확인했다. 정확한 수치와 해시는 `validation.json`을 따른다. 투과 표현에는 glTF 전송 재질 확장을 지원하는 렌더러가 필요하며 게임 조명·성능 검증은 별도다.

이 개별 수정본을 기존 12종 모음의 이슬젤리보다 우선하는 후속 제작본으로 사용한다. 다른 상품·가격·보유 데이터·상점/포장 UI·기존 실행본은 변경하지 않았다. 게임 적용·사용자 최종 외형 검수는 별도다. GLB는 상품만 포함하고 `.blend`는 촬영용 조명·카메라·바닥도 포함한다.
