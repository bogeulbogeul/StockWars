# 모던 프레임 외관 디자인 시안 v1

이미지 디자인 시안이며 사용자 채택·실제 3D 모델 제작·게임 적용 전이다. 내장 image_gen으로 생성했다. `concept.png`가 결과다.

참고: 기존 가구점 `furniture-exterior-clean-v1/front-right.png`는 정체성/배치 참고, 사용자 안내소 채택 이미지는 무광 클레이 스타일/기와 완성도 참고로 구분했다. 현재 아트 가이드 확인 후 생성했다.

최종 프롬프트 요약: 단층의 넓은 비대칭 가구점, 높은 왼쪽 출입동과 낮은 오른쪽 쇼윈도 동, 곡면 대신 코코아 갈색 직선 박공 기와지붕과 둥근 용마루, 크림 벽과 꿀색 목재, 왼쪽 아치 양문/황동 손잡이, 오른쪽 가로 쇼윈도/두 세로살, 집 모양 의자 부조 간판, 측후면 창 없음. 부드러운 무광 클레이, 깨끗한 지붕 교차부, 전체가 보이는 정면 오른쪽 사선, 회색 스튜디오 배경. 캐릭터/화분/차양/문자 없음.
