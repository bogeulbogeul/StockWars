# 지도 거치대 두 선택지

사용자 요청으로 안내소 지도 근접 F/버튼 상호작용은 즉시 가이드북을 열지 않고 ‘지도 보기’와 ‘가이드북 보기’ 두 선택지를 제공한다. 지도는 실제 거치대 GLB의 현재 텍스처를 읽어 원본 방향으로 전체 표시하므로 별도 구형 지도 파일을 참조하지 않는다. 가이드북의 목차·페이지 넘김·원고는 유지했다.

지도/가이드북에서 ‘선택으로’ 돌아가 다른 자료를 열 수 있다. 각 화면의 Esc/닫기는 실내 같은 위치로 복귀하며, 선택/읽기 중 이동·대사 입력을 차단한다. 장소를 떠나면 선택창과 두 열람 창 모두 닫는다. 기존 도보·지도 모델·저장·보상은 변경하지 않았다.

웹/기존 실행본 resources/web의 InformationGuidebook.js와 information-guidebook.css에 반영했다. CSS 버전은 map-choice-v3다. `scratch/check-information-map-choice.cjs`로 양쪽 실제 브라우저에서 선택지 2개·지도 텍스처 1402px 표시·선택창 복귀·책 열기·이동/대사 차단·페이지 넘김·Esc/닫기·모바일 폭·장면 숨김 시 닫기를 확인했다. 실제 선택창/지도/가이드북 PNG를 기록하고 화면을 열어 확인했다. 설치 프로그램 재빌드·사용자 최종 플레이 검수는 별도다.
