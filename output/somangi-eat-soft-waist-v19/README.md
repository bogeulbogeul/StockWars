# 소망이 먹기 — 참고 뒷모습에 맞춘 완만한 허리 v19

P1 (Major) · ✅ 체형 보정·검사 / ⏳ 사용자 외형 검수

사용자가 새로 지정한 `reference-back.png`를 기준으로 허리의 잘록함을 줄였다. 등에서 몸통 아래쪽으로 완만하게 넓어지는 연속 곡선으로 바꾸고, 골반 크기를 더 키우기보다 허리 중간 폭을 채우는 방향으로 수정했다. 머리 크기·얼굴·팔·손발·먹기 동작은 유지했다.

몸통의 가로 폭만 보정했으며 앞뒤 두께와 높이 좌표는 유지했다. 기존 머리·몸통의 연속 연결면도 새 몸통 폭을 따르도록 갱신했다. 첨부 참고는 뒷모습의 몸통 윤곽 기준이며, 팔을 내린 참고 자세로 기존 먹기 동작을 교체하지 않았다.

## 검증

- 181개 시점에서 편집 구간 외 정점 차이 최대 0.00000012, 머리 차이 최대 0.00000012, 손바닥 차이 최대 0.00000006.
- 전체 앞뒤 두께·높이 좌표 차이 최대 0.00000012(부동소수점 정밀도 수준).
- 머리·몸통 경계에 열린 변 0. 실제 GLB 재수입 후 재질 경계 정점 425쌍의 벌어짐 0.
- 빵과 머리의 삼각형 교차 0.

`somangi-eat.glb`는 전달용, `somangi-eat.blend`는 편집용이다. `eat-rear.gif`는 최종 GLB를 다시 불러와 촬영한 뒷모습이다. 검사 결과는 `waist-validation.json`, `export-junction-validation.json`, `export-validation.json`에 기록했다. 게임에는 설치하지 않았으며 이전 제작본을 보존했다.
