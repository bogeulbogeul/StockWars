# 붉은여우 캐릭터 디자인 시트

기존 승인 붉은여우의 외형·주황 털·아이보리 얼굴/가슴/꼬리 끝·초코 갈색 손발을 참고한 정적 디자인 시안이다.

- `design-sheet.png`: 정면·앞사선·정측면·뒷모습, 얼굴/귀 전용 초상화, 꼬리 연결·매끈한 뒤꿈치 확대, 시각 색상표.
- 외형/색 참고: `../style-unification-v3/red-fox/run/frames/down_idle/frame-0.png`.
- 뒤 색 참고: 같은 run의 `up_idle/frame-0.png`. 꼬리 연결은 골반 뒤 중앙을 기준으로 표현한다.
- 레이아웃 참고: `../rabbit-design-2026-10-17-v1/design-sheet.png`. 토끼 외형·짧은꼬리 규칙은 복사하지 않았다.
- 내장 image_gen 사용. 전체 프롬프트·네이티브 원본은 `generation.json`에 기록한다.

정적 확인: 네 방향·큰 얼굴 초상화·발바닥 패드 없음·발가락 없는 뒤꿈치·긴 꼬리와 아이보리 끝 표현을 확인했다. 색상표는 시각 참고이며 런타임 RGB 확정표가 아니다. 기존 게임 붉은여우나 공통 모션 기준을 교체하지 않았으며 걷기 스프라이트 제작·모션 연속성 검수는 별도다.
