# 은행 계좌 개설 신청서 v1

입주 신청서의 종이 서식과 은행의 금빛 새싹 동전을 사용한다. 기존 전시 첫날 bank 활동에 연결했다. 입주 이름을 예금주로 안전하게 textContent 표시하고 생활 계좌·잎 보관 목적·차곡이 담당을 기재한다. 버튼 제출 시 기존 이름으로 서명하고 1.5초 후 기존 next('bank')를 호출한다. 중복 제출과 화면 교체 후 콜백을 막고 저장 실패 시 재시도할 수 있다.

계좌 상태·저장 구조·경제 규칙은 기존 그대로다. 대출은 다음 loan 활동으로 분리되어 있다. 이자·계좌번호·새 금융 기능은 추가하지 않았다.

웹/기존 실행본에 4개 소스를 동기화했다. 설치 프로그램 재빌드는 하지 않았다. scratch/check-bank-application.cjs에서 1280×900·390×844·844×390의 화면 경계·기존 이름 표시·서명·지연 제출을 확인했다. 기존 전시 상태 테스트 6개 통과. PNG는 독립 UI의 실제 브라우저 렌더이며 게임 내 최종 사용자 플레이 검수는 별도다.
