# 소망이 이전 먹기 모션 재사용

사용자가 2026-10-23 첨부 화면에서 지목한 `somangi-eat-drink-grip-v3/somangi-bread`의 캐릭터 움직임을 재사용한다. v6~v8의 경직된 팔 회전·몸통 파임 보정·겨드랑이 실험을 적용하지 않는다.

- 캐릭터: 이전 모션에서 평가한 91프레임의 **전체 정점 좌표**를 그대로 사용한다. 어깨·몸통·팔·머리·다리의 추가 변위 0. 휴지 자세의 좌표·UV도 유지한다.
- 양손: 이전 양손 자세 유지. 팔을 좁히면서 발생하던 겹침을 피하기 위해 캐릭터를 다시 변형하지 않는다.
- 빵: 균일 크기 100% → 95% → 90% → 85%. 작아지는 빵의 위치를 두 손 사이에서 조절해 접촉을 유지한다. 손바닥 패치 중심과 타원체 표면의 오차는 validation.json 참조. 삼각형 메시 전체의 충돌 검사는 아니다.
- 입: 기존 미소 영역만 피부색으로 가리고, 검은색 별도 표면 메시로 입 벌리기·씹기를 표시한다. 눈의 검은 무광 재질은 유지한다.
- 음료 모션 없음. 게임 설치 없음. `output/` 내 검토용 제작 결과다.

실제 내보낸 `somangi-eat.glb`를 다시 읽어 정면·왼쪽 정측면 각 36프레임, 3초 GIF로 렌더링한다.
