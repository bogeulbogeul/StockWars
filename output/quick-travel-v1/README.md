# 모아 빠른 이동·문 앞 F 입장

2026-10-26 사용자 요청 반영.

- 모아 안내 이동: 140ms 암전 → 위치/장면 전환 → 140ms 밝아짐. 추종/도착 대화 F 대기를 제거하고 안내 대화로 연결한다.
- 안내소/집/은행의 모아 동반 출입, 광장 벤치 이동/안내소 복귀도 걷기를 제거했다.
- 다섯 건물의 전시 입장은 문 앞의 새 F 입력을 기다린다. 목적지 이동 중 누른 입장 F는 재입력을 요구하지 않는다.
- 모든 외관 문은 근접/입퇴장 시 회전하지 않는다. 일반 모드의 기존 문 앞 F 입장 검사도 유지한다.
- 일반/전시 퇴장과 증권사 내부 방 이동은 빠른 페이드로 바꿨다.
- 웹과 electron-app/dist/win-unpacked/resources/web 동기화. 원본 모델과 게임 규칙은 유지. 설치 프로그램 재빌드와 사용자 최종 플레이 검수는 별도.
