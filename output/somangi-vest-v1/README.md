# 소망이 기본 조끼 v1 — 2026-10-25

**2026-10-25 후속 사용자 결정: 의상 커스텀 계획 폐기. 이 조끼는 미채택 제작 기록으로만 보존하며 게임에 적용하지 않는다. 아래 내용은 제작 당시 기록이다.**

P1 (Major) · ✅ 3D 기본형·교체용 UV/텍스처 제작·GLB 정면/측면/후면 렌더 확인 / ⏳ 사용자 외형 검수·먹기 접촉 검수·게임 적용.

사용자 요청 “일단 조끼 먼저 만들어줘”에 따른 제작본이다. 기존 의상 제거 방침에 대한 이번 요청 범위의 후속 제작이며 판매/UI 기능은 포함하지 않는다.

- 기준: `../somangi-game-v1/somangi-walk.blend`의 최신 소망이 체형·흰색·얼굴·통팔·걷기를 유지한다. 원본 몸체 정점 변경 0.
- 앞트임과 둥근 밑단을 가진 무광 베이지 조끼. 팔을 제외한 실제 몸통 단면에서 새 메시를 맞추고 Body 본에 연결했다. 기존 모아 제작 코드의 몸통 맞춤 절차를 재사용하며 모아 모델이나 게임 에셋은 복원하지 않았다.
- `somangi-vest.blend`: 편집 원본. `somangi-vest.glb`: 소망이와 조끼, 기존 걷기를 포함한 확인용 모델.
- `vest-basecolor.png`: 512×512 교체용 색·무늬 이미지. VestUV의 가로는 열린 앞판 한쪽→옆→등→반대 앞판, 세로는 밑단→어깨다. 같은 실루엣의 색·무늬는 이 이미지로 변형한다. 테두리 색은 별도 재질 값으로 조절할 수 있다.
- `front.png`, `side.png`, `back.png`, `three-quarter.png`: 최종 GLB를 다시 불러온 렌더. `walk-8.png`, `walk-23.png`: 걷기 두 자세 확인.
- `verification.json`: 원본 정점 보존 기록. 전체 동작의 연속 충돌 검증을 뜻하지 않는다. 먹기 및 게임 플레이 검수는 후속이다.

재현: Blender 5.2에서 `build.py` 실행. 기존 제작 원본과 게임/로컬 실행본은 변경하지 않았다.
