# 안내소 입장부터 은행 이동 직전 촬영

- 영상: information-before-bank.mp4, 약 113.12초, 1440×1000, 25fps, 무음.
- 현재 기존 실행본의 resources/web를 로컬 QA 브라우저로 제공해 실제 키보드/마우스 입력으로 플레이했다. 실제 Windows EXE 창 녹화는 아니다.
- 실제 정류장 출발→안내소 진입을 준비 과정으로 거친 뒤 영상은 안내소 입장 부분부터 보여준다. 신청서 수령/이름 작성/제출, 핸드폰 수령, P로 열기·Esc 닫기, 지도/생활 자금 대화, 모아 페이드 퇴장, 수령 후 W/S 이동, 출입문까지 직접 이동/F 퇴장, 야외 은행 이동 안내까지 이어진다. 은행까지 걷거나 은행 안에 입장하지 않는다.
- 진행 상태/좌표 주입, 배속, 중간 컷 없음. 앞쪽 준비 구간만 잘랐다. 원본 full-session.webm 보존.
- 스크립트 scratch/record-information-to-bank.cjs --packaged. 브라우저 오류 0건 assertion 통과. 종료 후 원격 video.path() 호출이 지원되지 않아 저장 단계 오류가 났으나, 완료된 브라우저 임시 원본을 보존해 MP4로 변환했다. entry-contact/review-contact/exit-review로 주요 장면 확인.
- 화면 검토만으로 사용자의 반대로 걷는 현상 해결을 확정하지 않는다. 25fps 녹화는 게임의 60FPS 성능 검증이 아니다. 새 게임 코드 변경은 없다.
