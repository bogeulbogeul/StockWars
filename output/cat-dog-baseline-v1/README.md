# 강아지 v9 공통 모션 기반 고양이 시트 v1

사용자 지시에 따라 강아지 v9의 각 방향·행동별 프레임을 동작 참고로 고정하고 검은 고양이를 새로 생성했다. 참고1은 기존 고양이 정면의 외형·고유 색·금색 눈·도도한 표정, 참고2는 해당 강아지 행의 자세·시점·팔다리 겹침·순서다. 강아지의 살구색·무늬·귀·꼬리를 고양이에 옮기지 않았다. `generation.json`에 내장 image_gen의 전체 프롬프트와 원본 경로를 보관하고 `raw/`에 사용 원본을 저장했다.

## 구성과 동작

강아지와 동일한10상태·19논리 프레임·16고유 그림이다. 320×400셀,1280×4000시트이며 좌표·상태별 그림 수·재생순서는 강아지 v9 manifest와 같다. 걷기3그림은0→1→2→1,각160ms다. 정지는 걷기 중립과 동일 PNG이며 운반4그림은 강아지의 사용자 확정 순서 그대로다. 정면·앞오른쪽 사선(양눈·가슴)·뒤, 두 방향 의자 앉기 및 얼굴·귀만 포함한 초상화를 제작했다.

사선 A는 가까운 다리 전진·가까운 팔 후퇴, B는 가까운 다리 후퇴·가까운 팔 전진이며 먼쪽 팔은 강아지 v9처럼 몸통 뒤로 가린다. 낮은 발 교대·각 어깨별 팔 연결·발바닥 패드 금지·운반 양손 받침을 명시했다. 별도 꼬리 대기 상태를 추가하지 않았다. 정지 프레임은 고정이고 걷기는 강아지의 포즈를 따른다.

## 색·추출·검수

sprite-gen 크로마 제거·연결 성분 추출과 동일 행 내 공통 배율을 사용한다. 고양이 정면 RGB에서 몸256색·눈48색 후보를 추출해 중복을 제거했다. 눈의 어두운 갈색 경계색이 검은 털에 갈색 점으로 매핑되는 초기303색 결과를 배제하고, 어두운 색은 중성 차콜로 제한한 최종273색을 고정했다. sprite-gen recolor로 모든 비투명 픽셀에 동일 최근접 색 규칙을 적용했다. 디더링·파츠 리깅·머리 붙이기·동작을 고치기 위한 로컬 팔다리 변형은 하지 않았다. 정확한 목록은 `palette.json`, `palette.csv`, 베이크 보고서는 `baked-final/recolor.report.json`이다.

개별 정적 자세와 팔다리 겹침을 검토하고 추출·잘림·알파·팔레트·중립 공유·강아지와 좌표/시간 구성 일치를 검사했다. 이 검사는 실제 재생의 연속성·색/명암 분포 변화·발 미끄러짐 통과 판정은 아니다. 걷기는 experimental 시안이며 게임 설치·접촉 검수는 별도다. 현재 게임 고양이는 변경하지 않았다.

`preview.html`은 왼쪽 강아지 v9, 오른쪽 새 고양이의 동시 재생 비교다. `cat/review-final.png`는 모든 고유 자세, `cat/run/sprite-sheet-alpha.png`는 투명 시트, `cat/run/manifest.json`은 좌표·순서, `qa/`는 행동별 GIF다. `export-verification.json`은 정적 검사 기록이다.

재조합은 build → palette → sprite-gen recolor(baked-final) → publish → verify 순서다. 이 시트는 새 고양이 제작본이며 사용자의 별도 채택 없이 강아지 기준을 대체하거나 게임에 설치하지 않는다.
