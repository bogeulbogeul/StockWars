# QA 범위

입력 역할: 기존 고양이 정면=외형/색, `refs/`의 강아지 v9 행=동작/시점/순서. 내장 image_gen으로 5개 행을 새로 생성했다.

| 상태 | 정적 검토 | 연속성 판정 |
|---|---|---|
| down_walk | 화면 왼발+오른손 / 중립 / 오른발+왼손 교대, 발바닥 패드 없음 | experimental, 실시간 재생 미관찰 |
| right_walk | A 가까운 다리 앞으로·팔 뒤로, B 가까운 다리 뒤로·팔 앞으로, 먼 팔 몸통 가림 | experimental, 실시간 재생 미관찰 |
| up_walk | 양발 교대·반대 팔 움직임, 얼굴 없음, 발바닥 패드 없음 | experimental, 실시간 재생 미관찰 |
| right_carry | 강아지 참조의 접지/통과/반대접지/반대통과 4자세, 양손 받침 | experimental, 실시간 재생 미관찰 |
| down_sit/right_sit | 두 무릎과 양손이 보이는 의자 자세, 별도 의자 없음 | 정적 시안, 좌석 접촉 미검수 |
| face_portrait | 얼굴·귀만 포함, 목·가슴 없음 | 정적 시안 |

강아지와의 좌표·상태 구성·재생 순서·시간, 알파, 여백, 중립 공유, 공통 RGB 포함 검사는 export-verification.json을 따른다. 이 검사는 실재생 중 명암 분포 변화나 포즈 연결의 최종 통과를 대신하지 않는다. 팔·다리 길이와 카메라를 정적 보드에서 검토했지만 실제 크기의 움직임·게임 이동·발 미끄러짐은 최종 채택 전 별도다. 실패가 보이면 해당 행을 재생성한다.
