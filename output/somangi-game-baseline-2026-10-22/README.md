큰 흰색 둥근 머리·검은 타원 눈·작은 미소·매끈한 둥근 배·짧은 팔과 다리·발을 유지한다. 현행은 매끈한 몸통 v3와 다리 연결 보정을 반영한 체형이다. 짧은 목과 어깨선을 새로 만든 이미지 시안은 이 기본형에 포함하지 않고 게임에도 적용하지 않는다.

`render.py`는 게임 GLB를 직접 불러와 애니메이션을 재생하지 않는 기본 휴지 자세에서 정면·정측면·후면을 동일 크기의 카메라와 조명으로 렌더한다. 실제 모델 촬영이며 게임 장면의 화면 캡처는 아니다. 조명과 배경은 검수용이다. 오른쪽 측면은 캐릭터 오른쪽에서 바라본 것으로 화면에서는 왼쪽을 향한다.

P1 (Major) · ✅ 현재 게임 기본형 지정·3방향 촬영·문서 반영. 이번 작업으로 게임 모델·본·기존 모션을 수정하지 않았다. 다른 주민의 새 모델 제작이나 어깨 시안 구현은 별개다.
