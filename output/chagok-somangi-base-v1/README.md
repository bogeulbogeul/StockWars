## 제작 및 검증 범위

소망이 원본 `output/somangi-game-v1/somangi-walk.blend`의 몸 메시 정점 좌표를 바꾸지 않고 피부 재질/텍스처만 변경했다. 맞춤이 완료된 토리의 안경 프레임을 가져와 갈색 재질로 교체했으며 씨앗 장식은 신규 메시다. 장식은 현행 Head 본에 연결했다. 원본 파일 SHA256 보존·몸 정점 좌표 완전 일치·GLB 내보내기/재수입·휴지 자세 4방향을 검사했다.

토폴로지 검사는 glTF 재질/UV/법선 이음 정점을 검사 메모리에서 병합해 경계·비다양체·면적 0 면을 확인한다. 메시 사이의 모든 관통이나 모든 모션의 접촉 검증을 뜻하지 않는다. 걷기 전달과 전체 동작의 사용자 검수·게임 배치는 구분한다. 얼굴 14종 전체의 별도 차곡 배포본은 이번 제작 범위가 아니다.
