# 은행 카운터·의자 접근 검수

현재 룸과 게임 crab.glb 13프레임 및 office-sit.glb 25프레임을 원본 배율 1/1.95로 비교했다. 룸 1단위=게임 100단위 가정 유지. 가구 배치와 게임 코드는 변경하지 않았다.

카운터는 U자이며 양끝이 y=1.0까지 나오지만 중앙 뒤끝은 y=.570이다. 좌판 앞은 .915이므로 실제 중앙 간격은 .345, 팔걸이 앞까지 .460이다. 전체 바운딩 박스의 .085 중첩은 양끝 날개 때문에 생기므로 중앙의 실제 중첩으로 해석하지 않는다.

실제 메시 삼각형 교차 검사에서 중앙 게걸음 경로 여러 위치에 가구 간섭이 확인됐다. 착석 최종 자세를 엉덩이 접점으로 좌판에 맞추면 좌판 접촉 외에도 등판과 머리/등 쿠션에 교차가 있다. 따라서 현재 배치의 자연스러운 게걸음 진입→착석은 통과 판정할 수 없다. 의자를 뒤로 빼고 착석 접점/등판 간격을 조정한 후 재검수가 필요하다.

✅ 정적 자세·샘플 경로의 메시 교차 및 렌더 확인 / ⏳ 연속 모션·충돌 여유·게임 입력 검증. 은행 룸은 게임 착석 등록이 없으며 증권사 전용 착석 구현만 존재한다. report.json의 경로 교차 검사는 삼각형 표면 교차이므로 내부 완전 포함 검출이나 모든 가능한 경로의 불가능성 증명을 뜻하지 않는다.
