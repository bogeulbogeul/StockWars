# 주식 앱 데스크탑 버전 — 2026-10-25

화면 너비 1000px 이상·높이 600px 이상에서 스마트폰의 주식 앱을 열면 중앙의 넓은 데스크탑 창으로 표시한다. 작은 화면은 기존 스마트폰 UI를 유지한다. 별도 설치 앱이나 구형 네온 거래 화면을 추가하지 않았다.

- 아이보리·파스텔 디자인, 왼쪽 홈/주식 거래/내 계좌 메뉴, 상단 두 시장 지수.
- 홈 자산 요약과 최근 종목 2열, 거래 목록 2열, 보유 종목 카드 2열.
- 종목 상세의 차트와 호가를 나란히 배치하고 기업 지표 4열 표시.
- 홈 화면 복귀·닫기·검색·관심·업종·정렬·기간·차트 확대·호가 선택·주문은 기존 컴포넌트와 엔진 사용.
- 금융 계산·지수·계좌·일반 저장 및 전시 초기화 정책 유지.

## 검증

`scratch/check-stock-desktop.cjs`로 웹과 기존 실행본 resources/web를 각각 확인한다. 1280×900의 넓은 창과 grid 배치, 검색 72종목·업종 필터·관심·매수/매도·수수료 미리보기·지정가 취소·레벨 제한·차트·기업 지표·소식 원문·리스너 해제·전시 첫 1주 매수/일반 계좌 분리 및 전시 저장 없음, 390×844와 844×390의 가격 겹침·주문 접근을 검사한다.

`web-*.png`와 `desktop-*.png`는 해당 리소스를 브라우저로 렌더한 화면이다. `*-checks.json`이 최종 검사 결과다. 사용자 계좌는 변경하지 않고 독립 브라우저 검증 상태에서 거래한다. 실행본 파일 목록은 `synced-files.txt`다. 설치 프로그램 재빌드와 사용자 최종 플레이 검수는 별도다.

## 주문 화면 잘림 수정

이전 주문 스크린샷은 긴 단일 열을 주문 버튼까지 자동 스크롤한 상태여서 위쪽 조건이 가려졌다. 주문 조건/결제 확인의 두 열로 배치하고 매수·매도를 안내/미체결 목록 앞으로 옮겼다. 주문 탭 진입 때 상세/본문 스크롤을 초기화한다. 작은 화면은 한 열을 유지한다. 1280×900에서 현물·주문 방식·수량·매수·매도 각각의 실제 경계가 상세 표시 영역 안에 있는지 검증하며 수정된 `web-order.png`·`desktop-order.png`를 제공한다.

## 섹터 필터 색상 통일

섹터 필터의 반복 파스텔 색을 제거하고 StockBrand.js의 아이콘 팔레트를 공통 참조한다. IT 파랑·엔터 분홍·인프라 청록·바이오 연두·우주 파랑·유통 황금·에너지 초록·금융 보라를 버튼 배경에 그대로 사용한다. 선택 상태에서도 색은 유지하고 진한 외곽선/굵은 글자로 구분한다. 전체/관심 버튼은 기존 색이다. 웹·기존 실행본에 적용하며 8개 필터를 차례로 선택해 실제 버튼/첫 종목 아이콘 배경 RGB 일치와 aria-pressed를 검사한다.

## 한 화면 표시 개선

데스크탑 창은 최대 1440×960, 화면 가장자리 여백 20px로 확장했다. 글자 크기는 유지하고 본문/지수/카드 간격을 줄였으며 1440px 이상은 종목 3열이다. 차트 높이는 240~400px로 제한해 호가/하단 내용 접근을 개선했다. 짧은 창은 주문 입력을 압축 배치한다. 종목 전체/긴 거래 내역 및 매우 낮은 창은 스크롤을 유지한다. `scratch/check-stock-layout.cjs`는 1280×900·1000×760·1920×1080에서 주요 주문 항목과 버튼의 표시 경계를 검사하고 모바일·거래도 검증한다. 별도 소식 앱 변경으로 기존 통합 검증의 구형 소식 상세 가정이 더는 맞지 않아 이번 레이아웃 검증은 해당 소식 구간을 제외했다. 섹터 전용 검증 결과는 `*-sector-colors.json`이다.

## 주문 창 빈 공간 축소

후속 피드백으로 주문 탭만 최대 1180×700 창을 사용한다. 거래 목록의 최대 1440×960과 분리해 아래쪽 과도한 빈 공간을 줄였다. 기본 주문 조건·결제액·매수/매도 표시와 1000×760·1280×900·1920×1080 및 모바일 회귀 검증을 통과했다. 웹과 기존 실행본 CSS가 일치한다.

## 홈·차트 여백 축소

후속 요청으로 홈 최대 1180×700, 차트 최대 1180×760 창을 사용한다. 차트 높이는 220~320px이며 호가 행과 제목 간격을 줄여 주문 이동 버튼까지 표시한다. 글자 크기는 유지한다. 레이아웃 검증은 홈 본문과 기본 차트/호가의 scrollHeight가 표시 높이 이하인지 확인한다. 작은 화면/긴 내용은 기존 스크롤을 유지한다.

## 내 계좌 내용 맞춤 높이

내 계좌는 고정 높이를 제거하고 내용의 실제 높이를 따르는 창으로 변경했다. 데스크탑 보유 카드를 3열로 정리하고 제목/슬롯/거래 내역 간격을 줄였다. 거래 내역을 펼치거나 보유 항목이 많아지면 화면 높이 안에서 본문이 스크롤된다. 모바일 배치와 계좌 계산은 유지한다. 실제 3개 보유 카드와 닫힌/펼친 거래 내역의 화면 경계를 검증한다.
