## 모션과 검증

새 모델의 메시·얼굴·재질을 사용하고 Root·양팔·양다리의 5개 본과 연결부 가중치를 추가했다. 다리는 약 ±21도, 팔은 다리 반대 방향으로 약 ±15도 움직인다. 회수하는 발은 조금 들어 올리고 매 프레임 양발의 최저점을 계산해 Root 높이를 보정한다. 이동 변위가 없는 제자리 걷기로 제작했다.

원본 모델을 임의로 다른 체형으로 바꾸거나 과거 모델의 팔·몸통 메시를 섞지 않았다. 연결부에는 스키닝 변형이 발생하며 모든 자세에서 원래의 강체 형상을 유지하는 방식은 아니다.

GLB 재수입 시 `Walk_InPlace` 클립이 존재하고 시작·끝 정점 오차는 0이었다. 97개 시점에서 비정상 좌표가 없었고, 발의 바닥 아래 최대 오차는 약 0.000165, 지지 발의 위쪽 최대 오차는 약 0.001615 모델 단위였다. 이는 표본 검사이며 실제 이동 속도에 맞춘 발 고정 IK나 모든 접촉의 무간섭을 보장하지 않는다. GIF는 내보낸 GLB를 다시 불러와 렌더링했다.

게임 파일·실행본·로더는 변경하지 않았다. 사용자 최종 시각 검수와 게임 연결은 별도다.

## 재현

Blender 백그라운드에서 `build.py`, `preview.py` 순으로 실행한다. Pillow가 있는 Python으로 `make_previews.py`를 실행해 GIF를 만든다. 빌드는 30fps에서 1~25프레임을 키로 사용하며 GLB 클립의 실제 시간 범위는 약 0.0333~0.8333초, 한 주기는 0.8초다.
