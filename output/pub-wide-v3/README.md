# 미드나잇 펍 좌우 확장 v3

P2 · ✅ 3D 제작본 좌우 8% 확장 / ⏳ 사용자 시각 검수·게임 적용

사용자 요청 “펍 옆으로 조금만 더 늘려줘”에 따라 `pub-redesign-v2/Pub-redesign.blend`의 건물 몸체·지붕·목재 구조·기초/계단을 X축으로 8% 넓혔다. 높이·깊이는 유지한다. 문·창·초승달·맥주 간판·랜턴은 크기를 유지하며 창/간판/랜턴의 좌우 위치를 조정했다. 굴뚝과 지붕 구멍/테두리는 접합 보존을 위해 같이 좌우 8% 확장했다.

수정본은 `Pub-clean.glb`, `Pub-wide.blend`이며 전체 사선·정면·후면 실제 렌더를 저장했다. `verify.py`의 GLB 재로딩·닫힌 지붕/마감·구성 수량·유한 좌표·접지 검사를 따른다. 웹·실행본은 교체하지 않았다.
