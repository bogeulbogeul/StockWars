# 소망이 외형 유지 관절 보정 — 2026-10-23

P1 (Major) · ✅ 관절·안쪽 마감 보정·외형/경계 보존 검사·걷기 검수 / ⏳ 사용자 최종 모션 검수.

사용자가 겨드랑이·허벅지 연결부의 접힘과 겹침을 수정하되 외관을 바꾸지 말라고 요청했다. 입력은 얼굴 보정을 마친 원본이며 빨간 선 절단식은 `somangi-marked-boundary-mesh-v1`과 동일하다. 기존 파일은 덮어쓰지 않았다.

## 변경

- 머리·몸통·팔·다리의 기존 외부 표면과 절단 정점을 이동하지 않았다. 체형·크기·UV·표정·재질을 유지한다.
- 관절 가중치의 전환을 더 완만한 5차 곡선으로 바꿨다. 겨드랑이와 허벅지의 좁고 급격한 접힘을 줄인다. 같은 절단 위치를 공유하는 정점에는 같은 가중치를 적용한다.
- 두 조각의 경계에 겹쳐 있던 불필요한 내부 마감 면을 제거했다. 외부 표면은 양쪽의 일치하는 경계와 가중치로 연속성을 유지한다. 개별 분리 조각은 단면이 열린 상태이며 전체는 하나의 메시 오브젝트 안에서 맞닿아 움직인다. 서로 다른 본으로 강체 회전만 하도록 바꾸면 틈이 생길 수 있으므로 현재 경계 가중치를 유지해야 한다.
- 허벅지 회전축을 실제 절단 경계의 중심으로 맞췄다. 뼈의 세로축을 정렬해 GLB 바인드 행렬의 수치 오차도 줄였다.
- 걷기 주기 0.75초·팔 ±18도·다리 ±20도와 교대 순서는 유지한다.

## 결과

- `somangi-walk.glb`: 수정된 걷기 모델.
- `somangi-rest.glb`: 정지 모델·리그.
- `somangi-motion-ready.blend`: 편집본. 하나의 메시, 머리/몸통/양팔/양다리 6개 조각과 Part.* 선택 그룹.
- `walk-preview.gif`: 실제 내보낸 GLB 재수입 후 정면·측면 걷기.
- `joint-before-after.png`: 같은 조명·같은 보행 시점에서 관절의 수정 전/후 비교.
- `rest-before-after.png`: 원본과 수정 정지 모델의 같은 카메라 비교.

## 검증

`preservation-validation.json`: 직전 빨간 선 기준 버전과 외부 표면/절단 정점을 각 부위별로 비교했다. 모든 부위의 최대 이동은 0이다.

`shape-validation.json`: 원본 표면 거리 오차 0, 정지 GLB 재수입 오차 약 1.10e-7 모델 단위. 단일 메시·6개 조각 확인.

`rest-image-comparison.json`: 같은 카메라·조명에서 원본/수정 정지 모델을 렌더링했다. 0~255 채널 기준 평균 절대 픽셀 차이는 약 0.00151이며 렌더 표본 오차를 포함한다.

`gap-audit/report.json`: 내보낸 GLB의 601개 시점과 동일 위치 정점 쌍 7,950개를 검사했다. 경계 간격 최대 0, 루프 오차 0. 네 방향×여덟 자세의 확대 렌더를 추가 확인했다. 겨드랑이 진한 선과 허벅지의 톱니 같은 접힘이 줄었으며 자연스러운 관절 주름·팔과 몸 사이의 공간은 남아 있다.

`validation.json`: 97시점 접지·몸통·루프 검사. 완전 고정 몸통 구간의 형태 오차 0, 발 지지 높이 오차 아래 약 0.000145/위 약 0.000472 모델 단위다. 사용자 최종 시각 승인이나 모든 자세의 무간섭을 보장하는 검사는 아니다.

게임·실행본·삭제한 캐릭터 로더는 변경하지 않았다.

## 재현

Blender에서 `build.py`, `validate_preservation.py`, `validate_shape.py`, `gap-audit/check.py`, `preview.py`를 실행한다. `gap-audit/render.py`는 네 방향 확대, `render_rest_comparison.py`는 정지 비교 촬영용이다. Pillow가 있는 Python으로 `make_previews.py`를 실행한다. 각 소스 파일은 300줄 미만이다.
