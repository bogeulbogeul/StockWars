# 미드나잇 펍 외관 스타일 정리

간판 벽 부착 후속: 지지대와 간판을 처마에서 아래로 내리고 측벽 면 안쪽 위치에 고정판을 설치했다. 지붕과 떨어진 벽 부착 방식이며 간판은 계속 정면을 향한다.

삼각 틀 굵기 후속: 세 변의 수직 안쪽 오프셋을 동일하게 계산해 좌우 사선과 하단 보의 폭을 일정하게 맞췄다. 모서리는 동일한 사선 접합을 유지한다.

입구 박공·달 후속: 따로 놓인 둥근 목재 봉과 하단 보를 닫힌 단일 삼각 틀로 교체했다. 꼭대기·양끝은 사선 접합으로 연결하고 크림색 받침은 틀 뒤에 넣었다. 달은 정확한 두 원의 교차점으로 양끝이 이어지는 연속 초승달로 재조형하고 박공 안 여백을 확보했다. `gable-close.png` 확대 확인.

손잡이 배치 후속: 각 손잡이를 중앙 틈에서 조금 띄우고 유리와 하단 패널 사이의 평평한 목재 구간으로 올렸다. 패널과 겹치지 않게 길이를 조정하고 위·아래 고정부를 추가해 문에 실제 연결했다.

유리 테두리 두께 후속: 목재 틀의 폭을 약 두 배로 넓혔다. 깊이·유리 사이 간격·문과 유리의 앞면 높이는 유지한다.

유리 틀 추가: 양쪽 유리 사이 목재 여백을 넓히고 각 유리 둘레에 얇은 목재 틀을 둘렀다. 유리 앞면 깊이·양문 틈·손잡이는 유지한다.

유리 단차 제거: 목재 양문에 실제 유리 구멍을 뚫고 유리 앞면을 문 앞면과 같은 깊이에 맞췄다. 겹친 면 없이 평평하게 연결하며 기존 유리 크기·양문 틈·손잡이를 유지한다.

유리 하단 축소: 윗 아치·폭·양문 분할을 유지하고 하단만 올려 세로 길이를 줄였다.

최신 문 분할: 덧댄 중앙 세로 막대를 제거했다. 문 몸체와 유리를 각각 좌우 독립 메시로 나누고 좁은 실제 세로 틈으로 양문 경계를 표현한다. 두 손잡이·작아진 유리·낮은 하단 패널은 유지한다.

문 깊이 정리: 사용자 정정에 따라 양문·가운데 구분·기존 두 황동 손잡이를 유지한다. 유리·중앙 분할대·하단 패널의 돌출을 줄여 바깥 아치틀 안에 들어간 일체감을 준다. `door-close.png` 확대 확인.

추가: 유리 폭·높이를 줄여 목재 여백을 넓히고 하단 패널은 낮은 단차·둥근 가장자리로 몸체와 부드럽게 이어지게 했다.

격자 끝 마감: 사선 창살 양끝을 아치틀·기둥·창턱 안으로 연장해 둥근 끝 단면과 경계의 틈이 노출되지 않게 했다. 격자 모양과 들어간 깊이는 유지한다.

창문 깊이 보정: 사선 격자는 유지하며 유리 면 가까이 후퇴시키고 두께를 줄였다. 끝부분은 아치틀까지 연결해 하나의 창 안에 끼워진 느낌을 준다. `window-close.png`에서 사선 확대 확인.

거품 정렬 재보정: 거품 폭을 잔 몸체 안쪽으로 맞추고 중심을 일치시켰다. 잔 앞면과 거품 앞면의 깊이 차이를 최소화하고 하단을 몸체와 겹쳐 사선에서 왼쪽으로 밀려 보이는 현상을 줄였다. `sign-close.png` 확대 렌더로 접합·정렬을 확인한다.

후속 간판 정정: 오른쪽 모서리 위쪽으로 돌출된 위치를 유지하되 앞면은 정면을 향하도록 벽과 평행하게 설치했다. 브래킷·매달림 연결부와 양면 맥주 표식을 유지하고 잔 위에 크림색 거품을 추가했다. 이전 수직 설치 방향은 사용하지 않는다.

집·증권사·정착 안내소처럼 네이티브 3D의 매끈한 무광 재질과 부드러운 모서리로 제작했다. 기존 펍의 버건디 기와·크림 벽·갈색 목재·중앙 아치 양문·격자 창·달 표식·맥주 간판·랜턴·굴뚝을 유지한다. 석재 줄눈과 거친 표면은 제거하고 후면은 창 없는 벽으로 구성한다.
