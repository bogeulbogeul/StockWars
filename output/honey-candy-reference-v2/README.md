원본은 현행 상점 공통 이미지 `web/assets/items/packing-v1/items.png`의 `1580,470,410,255` 영역이다. 밝은 꽃 모양 꿀사탕·중앙의 작은 꽃·투명한 중앙 포장·양쪽 금빛으로 비틀린 포장을 따른다. 기존 크림색 타원 몸통 위에 솟은 꽃 배지만 있던 모델을 실제 꽃 모양 사탕과 투명한 포장으로 분리했다.

사탕 바깥 여섯 꽃잎과 중앙의 작은 다섯 꽃잎은 각각 이어진 매끄러운 메시다. 중앙 포장지는 얇은 투명 막이며 양쪽 끝에서 모아진다. 두 금빛 끝은 좁은 묶음 구간에서 비틀린 후 납작하게 펼쳐지는 얇은 포장으로 제작했다. 두꺼운 원뿔 소품·외부 인쇄 이미지·그려 붙인 하이라이트는 사용하지 않았다. 꿀빛 보정을 위한 약한 발광과 코팅/투과 재질을 사용한다.

GLB 구조·재수입·유한 정점·퇴화면 0개를 검증하고 전체·재수입 확대·후면 렌더를 확인했다. 정확한 수치와 해시는 `validation.json`을 따른다. 투과 표현에는 glTF 전송 재질 확장 지원이 필요하고 게임 조명·성능 검증은 별도다.

이 개별 수정본을 기존 12종 모음의 꽃꿀사탕보다 우선하는 후속 제작본으로 사용한다. 다른 상품·가격·저장·상점/포장 UI·기존 실행본은 변경하지 않았다. 게임 적용·사용자 최종 외형 검수는 별도다. GLB는 상품만 포함하고 `.blend`는 촬영용 조명·카메라·바닥을 포함한다.
