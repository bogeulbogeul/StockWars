# 유럽토끼 얼굴 통일·다리 무늬 수정

built-in image_gen으로 정면 걷기3그림·정면 앉기·초상화를 수정한 사선 얼굴의 둥근 볼·턱선, 짧은 주둥이, 부드러운 눈매와 통일했다. 운반4그림의 하복부·골반·허벅지 흰 무늬는 첨부4개 이미지에 맞춰 주변 회갈색 털로 연결했다. 가슴·손·발끝·꼬리의 흰 무늬를 유지한다. 실제 프롬프트·생성 경로는 generation.json에 기록했다.

기존 프레임 보드에 네이티브 편집을 정합한 뒤 sprite-gen chroma 제거로 정리했다. 얼굴은 머리 영역만 채택해 몸을 보존하고, 운반은 지정 영역의 네이티브 RGB만 선택해 원래 알파·외곽선·다리 구분선을 유지했다. 등분 신규 모션 생성이나 리깅은 사용하지 않았다. 수정9고유자세 + 공유 정면 대기1 = 10논리 프레임이며 프레임 좌표·재생·걷기3그림·160ms를 유지했다. 사선 걷기·앉기·후면 상태는 직전 파일과 동일하다.

verification.json은 수정 영역 밖 픽셀 및 운반 알파 보존 검사다. preview.html에서 직전/수정본을 재생하고 comparison.png에서 비교한다. rabbit-sprites-v3.zip은 최신 시트·개별 프레임·manifest·GIF·검증과 프롬프트를 포함한다. 기존8종 미리보기와 전체ZIP도 갱신했다. 실제 게임 통합·가구 접촉 검수는 별도다.
