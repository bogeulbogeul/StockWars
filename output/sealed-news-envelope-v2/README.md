기준은 현재 적용된 `web/assets/items/paper-v4/sealed-news.svg`와 `output/shop-paper-items-v4/closed-envelope-and-lotto.png`의 닫힌 크림색 봉투·초록 잎 문양 봉인이다. 내부 종이·편지 내용·문자·주소는 추가하지 않았다. 기존 판 위에 원본 그림을 겹쳐 놓던 방식 대신 닫힌 종이 몸체와 실제 접힌 덮개·왁스 봉인으로 만들었다.

몸체는 0.010 상대 단위 두께의 얇은 봉투다. 둥근 모서리와 약한 종이 굴곡, 아래쪽 접힘과 닫힌 상단 덮개를 포함한다. 접힘은 종이 겹침과 재질 차이·실제 조명으로 보이며 원본 그림의 두꺼운 갈색 윤곽선이나 그려진 깊이를 덧붙이지 않았다.

초록 봉인은 약하게 물결치는 둥근 외곽·얕은 안쪽 테두리·세 잎과 연결된 줄기·작은 잎맥을 실제 메시로 표현했다. 봉인과 잎 부조는 얕게 몸체/왁스에 겹쳐 고정되어 있고 별도 떠 있는 배지로 두지 않았다. 외부 이미지 텍스처는 필요하지 않다.

최종 GLB의 파일 구조·Blender 재수입·유한 정점·퇴화면 0개를 검증하고 전체·재수입 봉인 확대·후면 렌더를 확인했다. 정확한 수치와 해시는 `validation.json`을 따른다. 사용자 최종 외형 검수는 별도다.

이 개별 수정본을 기존 12종 모음의 소식 봉투보다 우선하는 후속 제작본으로 사용한다. 다른 상품·2D 이미지·가격·저장·소식 개봉/지급 기능·상점/포장 UI·기존 실행본은 변경하지 않았다. 게임 적용은 별도다. GLB는 상품만 포함하고 `.blend`는 촬영용 조명·바닥·카메라를 포함한다.
