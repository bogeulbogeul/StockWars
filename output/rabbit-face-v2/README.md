# 유럽토끼 사선 얼굴 수정

고양이처럼 읽히던 사선 얼굴의 뾰족한 볼털·턱선과 눈매를 둥근 토끼 볼, 짧고 부드러운 주둥이와 둥근 눈매로 수정했다. built-in image_gen 편집을 사용했으며 실제 프롬프트와 생성 원본은 generation.json에 기록했다.

사선 걷기3그림, 운반4그림, 사선 앉기1그림과 공유 사선 대기1그림(총9논리 프레임)에 적용했다. 네이티브 편집본을 원본 보드에 정합하고 sprite-gen chroma 제거 후 머리 영역만 선택했다. 각 걷기·운반의 y=204 아래, 사선 앉기의 y=225 아래 픽셀은 기존 RGBA와 동일하다. 머리 영역의 색·그림체와 원래 코 색을 유지한다. 네이티브가 코를 밝은 분홍으로 바꿨고 색만 되돌리는 후속 편집도 요구를 지키지 않아, 코의 작은 영역만 기존 원본 픽셀로 복원했다. 색상 필터나 새 색을 칠하지 않았다. 후속 네이티브 색 편집본은 미채택이다.

정면·뒷모습·초상화와 다른 동물은 변경하지 않았다. 기존3프레임 걷기·A→중립→B→중립·160ms·시트 좌표·발바닥 패드 금지를 유지했다. verification.json에서 수정 영역 밖 픽셀과 유지 상태를 확인한다.

preview.html은 토끼 수정 직전/직후를 재생한다. comparison.png는 정지 비교이며 rabbit-sprites-v2.zip에 최신 토끼 시트·개별 프레임·manifest·GIF·프롬프트를 묶었다. 전체8종의 기존 보정 미리보기·ZIP도 갱신했다. 게임 통합과 가구 접촉 검수는 별도다.
