# 사이퍼 증권 둥근 데스크 v1

채택 시안의 둥근 양 끝·두툼한 크림 상판·파란 몸체·아이보리 타원 배지를 Blender로 제작했습니다.
배지에는 기존 외관과 같은 막대/상승 화살표가 겹치는 파란 로고를 넣었습니다.

- `Cipher-cozy-desk.blend`: 수정 가능한 원본.
- `Cipher-cozy-desk.glb`: 데스크와 배지/로고. 스튜디오 배경·조명 제외.
- `desk-preview.png`: 모델 렌더.
- `game-desk.png`: 게임 배치 화면.
- 제작 스크립트와 `exterior_geometry.py`: 재제작용.

Blender 크기 3.10 × 1.00, 상판 높이 0.72, 바닥 z=0.
게임은 100배로 기존 데스크 좌표에 설치합니다. 기존 폭/높이/충돌 영역을 유지합니다.
노트북은 기존 별도 런타임 모델이며 화면은 직원 쪽을 향합니다.
게임/실행본에 반영했으며 로비 이동·전광판·출입·화면 비율 회귀 검증을 통과했습니다.
