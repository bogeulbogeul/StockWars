# 증권사 박공·가로보·측면 모서리 통합 v23

사용자가 다시 지적한 박공 하단과 오른쪽 처마 모서리의 틈을 수정한다. 이전 보정에서 서로 다른 면의 높이를 맞추는 데 그쳐 오른쪽 끝에 접합선이 남았다.

- 분리되어 있던 삼각 틀·박공 앞면·뒤 채움·수평 가로보를 제거했다.
- 수평 하단부터 양쪽 경사면과 꼭짓점까지 이어지는 하나의 닫힌 외곽 솔리드를 새로 만들었다.
- 앞면 삼각 장식은 관통 구멍 대신 얕게 파인 막힌 홈으로 제작했다. 홈의 뒤쪽도 동일 솔리드의 면으로 닫힌다.
- 측면 처마와 앞 가로보의 오른쪽/왼쪽 모서리를 실제 메시 합집합으로 연결했다. 단순히 틈 뒤에 판을 추가하는 방식이 아니다.
- 해당 솔리드의 열린 경계 모서리와 비다양체 모서리 수가 모두 0임을 검사한다. 지붕 실루엣·시계·간판 마크·v22의 받침/접지 보정은 유지한다.

`front-right.png`: 실제 전체 렌더. `gable-detail.png`, `corner-detail.png`: 첨부와 같은 부위의 실제 모델 확대 렌더. `CipherSecurities-clock.glb`: 전달 모델. `CipherSecurities-solid-pediment.blend`: 편집 원본. `manifest.json`, `validation.json`: 변경 범위·해시·구조 검사.
