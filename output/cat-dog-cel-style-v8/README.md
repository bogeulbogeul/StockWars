# 강아지 그림체·셀 명암 기준 고양이 v8

2026-10-18 사용자 요청으로 전체 고양이 시트를 강아지의 간결한 셀 명암 표현에 맞췄다.

- 그림체·모션 참고: `../dog-rgb-motion-v1/sprite-sheet-alpha.png`.
- 고양이 외형·색·자세 원본: `../cat-style-unified-v6/`. 부드러운 명암의 v7은 사용하지 않았다.
- built-in GPT imagegen으로 기존16자세 모아보기를 편집하고, 생성된 셀 그림자 모양을 원본 고양이 털에 전달했다. 원본 알파·윤곽선·눈·분홍 귀·눈썹·손 모양·긴 꼬리 실루엣은 유지했다.
- 털은 기본 RGB(65,59,62), 그림자 RGB(51,45,48)의 공통 두 색면이다. 털의 중간 그라데이션 색은0개다. 생성 중간색·잡점은 단일 셀 그림자로 정리했다. 강아지의 주황색·흰 무늬는 가져오지 않았다.
- ✅ 완료: 전체10상태·16고유자세, 정지/걷기 중립 동일, 알파 동일, 털 외 픽셀 동일, 시트 좌표와 재생 계약 동일 검사.
- ✅ 완료: 네 걷기/운반 GIF의4재생 프레임과160ms 검증. 걷기 고유3그림의 A→중립→B→중립 순서 유지.
- ⏳ 대기: 사용자 최종 외형 확인. 게임 설치·실제 플레이 접촉 검수는 수행하지 않았다.

전달 파일은 sprite-sheet-alpha.png와 manifest.json이다. preview.html은 강아지와 나란히 재생하며 overview.png는16자세를 보여준다. validation.json에 프레임별 그림자 면적과 검증을 기록했다. 그림체의 최종 일치는 시각 판단 사항이며 같은 두 색 사용만으로 모든 프레임의 시각적 일치를 증명하지는 않는다.

cel-generated.png는 built-in GPT 편집 원본이며 완성 게임 시트가 아니다. build_sheet.py에서 자세와 색을 보존하면서 셀 그림자만 베이크했다. prompt.txt에 편집 요청을 보관한다. 기존 에셋과 게임 적용 상태는 변경하지 않았다.
