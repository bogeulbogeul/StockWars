사용자 지적에 따라 본 지붕 직사각형 영역과 현관 교차선 사이에 빠졌던 마지막 삼각 처마 구간을 버건디 맞춤 기와로 채웠다. 좌우 두 조각씩 총 네 개이며 두꺼운 블록 대신 .035 두께로 주변 경사에 맞춰 제작했다. 원본은 좌우 8% 확장 `pub-wide-v3/Pub-wide.blend`다.
