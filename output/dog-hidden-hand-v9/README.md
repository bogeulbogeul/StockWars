# 돌출된 왼손 제거 v9

**후속 게임 반영 완료:** 사용자 요청으로 `web/assets/characters/dog-baseline-v9/`에 동일 PNG·팔레트를 설치하고 v9 좌표·얼굴 초상화·운반 순서를 공통 렌더러에 연결했다. `game-installation.json`이 설치 원본 일치 기록이다. 아래 게임 미반영 문장은 제작·채택 당시 이력이다. v9에 없는 꼬리 대기 확장은 사용하지 않으며 실시간 플레이 접촉 시각 검수는 별도다.

**2026-10-16 사용자 지정: 이 v9 강아지 시트를 캐릭터 시트의 새 제작 기준으로 채택했다.** 정확한 적용 범위와 우선순위는 `Docs/DOG_SPRITE_BASELINE.md` 최상단을 따른다. 아래 시안 표기는 제작 당시 상태이며 현재는 기준 채택·게임 미반영 상태다. 채택은 추가 모션의 제작이나 실시간 동작·접촉 검수 통과를 뜻하지 않는다.

사용자가 지정한 v6 사선 걷기 B의 앞쪽 큰 오른팔은 유지하고, 그 아래 몸통 오른쪽 가장자리로 튀어나온 작은 왼손 조각을 제거했다. 내장 image_gen의 완성 프레임 편집 결과를 sprite-gen으로 추출·정렬하고 기존 RGB279색으로 베이크했다. 원본·프롬프트는 `generation.json`, `raw/shoulder.png`다.

사선 걷기 B만 교체했고 다른18논리 프레임은 v6 PNG 바이트 그대로다. 얼굴 전용 초상화, 사용자 지정 운반 순서, 중립, 재생순서와160ms를 유지했다. 모든 비투명 RGB가 기존 공통 팔레트에 포함됨을 검사했다. 게임 미반영 시안이며 정적 돌출 제거 확인과 실시간 모션 연속성 검수는 구분한다.

`shoulder-comparison.png`: 왼쪽 v6 / 오른쪽 v9. `preview.html`: 재생 비교. `verification.json`: 보존 검사. 중단된 v7·v8 시도는 채택하지 않고 v6에서 이어 제작했다. 재조합은 prepare → recolor → publish 순서다.
