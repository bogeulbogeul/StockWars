# 붉은여우 꼬리 중앙 고정 시안 v6

게임은 사용자 요청대로 v4로 복원했다. 이 시안은 게임 미설치다. v5의 추가 털 결·명암은 사용하지 않으며 기존 v4의 뒤 외형·색과 중립 꼬리가 기준이다. 꼬리는 골반 중앙의 연결점을 유지하고 둥근 쉼표형·왼쪽 위 아이보리 끝을 보존하며 작은 기울임만 허용한다.

생성·추출 결과와 보존 검증은 generation.json·preservation.json을 따른다. 뒤 접지A/B의 중앙 영역은 꼬리 및 가려졌던 몸·팔 연결선을 함께 네이티브 편집한 뒤 기존 RGB로 고정했다. 머리·귀(y175위)와 발(y302아래)은 v4 RGBA를 보존하고, 중립·뒤 정지 포함 다른17개 PNG도 바이트 동일하다. 전체 몸 픽셀이 동일하다는 뜻은 아니다. 기존3그림·160ms·371색과 시트 무결성·미리보기 렌더 검사를 통과했다. 실제 재생의 연결점·외형 연속성 검수 전에는 완료 판정을 내리지 않는다.
