# 전시 포스터 v2

최종: stockwars-poster-actual.png

내장 image_gen으로 아이보리 종이·초록 크레파스 제목·2D 소망이 포스터를 생성했다. 생성 프롬프트: 큰 STOCKWARS 제목, ‘작은 마을에서 시작하는 투자 이야기’, 중앙 게임 화면 프레임, 아래 평면 크레파스 소망이와 ‘직접 걸으며 만나는 마을, 나의 첫 투자’. 입체 장식·추가 풍경·기능 과장 없이 간결한 세로 포스터.

게임 화면의 생성 왜곡을 없애기 위해 최종 파일 중앙은 output/town-road-clear-v7/web-overview.png 원본 캡처로 직접 교체했다. 중앙 화면은 크기 조정만 했으며 생성 일러스트로 미화하지 않았다. 원본 캡처의 기록 시점은 해당 output 폴더를 따른다.

stockwars-poster.png는 합성 전 생성 중간본이며 최종 배포에는 사용하지 않는다. v1의 미화된 일러스트는 이번 교정으로 채택하지 않는다.
