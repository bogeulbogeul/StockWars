# 주식 차트 좌우 스크롤 — 2026-10-28

모든 기간의 차트를 가로로 넓히고 독립된 stock-chart-scroll 영역에 넣었다. 스크롤바·마우스 드래그·세로 휠의 가로 이동·트랙패드 기본 가로 스크롤·모바일 브라우저 기본 가로 스크롤을 지원한다. 키보드 포커스도 가능하다. Ctrl+휠은 브라우저 기본 동작을 유지하며 스크롤 끝에서는 페이지 세로 이동을 막지 않는다.

처음에는 최신 기록이 있는 오른쪽을 표시한다. 같은 기간의 실시간 갱신과 확대 전환에서는 기존 스크롤 위치를 복구하고, 기간/종목 변경 때는 새 범위의 최신 쪽을 표시한다. SVG viewBox·그래프 점·격자·축 라벨·교차선·툴팁 위치를 함께 넓혔으며 화면→SVG 좌표 변환은 getScreenCTM을 사용한다.

StockChart.js·phone-stock.css를 웹과 기존 실행본 리소스에 동기화했다. 설치 프로그램은 재빌드하지 않았다.
