# 게시판 열람 전용 v7

확정 디자인은 유지하고 게시판 내 공고 확인/잡화점으로 버튼을 제거했다. 공고 선택·상세·확대·복귀·닫기만 제공한다. 게시판 닫기는 자동 이동을 실행하지 않는다. 전시 notice 단계는 닫은 뒤 소망이의 기존 대화/다음 진행으로 이어지며 그 대화의 다음 입력에서 기존 스토리가 진행된다.

웹·기존 실행본 resources/web 적용, CSS/컴포넌트 요청 버전 readable-v7. villageBoard.browser.cjs에서 이동 버튼 부재, 목록/상세/확대, 확대 닫기는 열람 콜백 미실행, 게시판 닫기 콜백, Esc/모바일/JS 오류 0건 검사 통과. 사용자 최종 게임 플레이 검수는 별도다.
