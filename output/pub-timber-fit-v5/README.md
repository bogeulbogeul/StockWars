# 펍 모서리 목재 지붕 맞춤 v5

P2 · ✅ 네이티브 목재 수정 / ⏳ 사용자 시각 검수·게임 적용

사용자 요청으로 `pub-corner-tiles-v4/Pub-filled-corner-tiles.blend`의 기와 아래 사각 목재 돌출부를 제거하고, 마지막 모서리 기와의 경사/끝선을 따르는 목재 받침을 좌우에 제작했다. 수평 처마 연결부와 합치고 닫힌 표면으로 정리했다. 가려진 크림 박공판의 뒷모서리도 잘라 겹치는 면을 피했다.

지붕 기와·용마루·좌우 8% 확장·굴뚝·초승달·창/문·랜턴·간판·계단은 유지하며 변경 대상 외 메시 정점 해시를 대조했다. `verify.py`의 GLB 재로딩·새 지붕/목재 닫힘·기본 구성 수량·유한 좌표 검사를 따른다. 실제 전체/목재 확대/정면 렌더, `Pub-clean.glb`, `Pub-roof-fitted-timber.blend`를 저장했다. 웹·기존 실행본은 교체하지 않았다.
