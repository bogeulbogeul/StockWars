# 사이퍼 증권 원본 지붕·전체 비율 재제작 v20

사용자 후속 요청: “원본 이미지랑 아직 달라. 지붕 모양이랑 건물 전체 비율까지 이미지 그대로 맞춰줘.” 원본은 변경 없이 `reference.png`에 보존했다.

## 실제 3D 변경

- 앞 처마·뒤 처마와 기초의 여섯 모서리를 함께 측정해 원근 카메라와 벽·기초 치수를 계산했다. `calibration.json`의 여섯 기준점 투영 RMS는 약 0.37픽셀(1374×1145 원본 기준)이다. 이 수치는 지정한 모서리 오차이며 이미지 전체의 일치율을 뜻하지 않는다.
- v18 대비 좌우 벽 높이는 약 18.6% 낮추고, 기초 앞뒤 깊이는 1.96 → 약 3.19로 재설계했다. 카메라만 바꾼 것이 아니다.
- 중앙 박공의 세 꼭짓점·뒤 용마루와 좌우 지붕의 가로마루를 원본 위치에서 역투영해 별도의 실제 평면으로 만들었다. 중앙은 공유 용마루의 두 경사면, 양쪽 날개는 앞뒤 경사면과 외측 사면으로 구성한다.
- 기와는 실제 교차 평면에서 절단하며, 겹친 조각·중복 면 때문에 생기던 검은 띠를 제거했다. 분절된 둥근 용마루·두께가 있는 파란 처마·연속 삼각 프레임과 가로보를 제작했다.
- 원기둥 네 개는 수직·원형 단면을 유지하고 주두 고리가 보 아래에 드러나도록 높이를 다시 정했다. 기초·받침 하단은 Z=0에 닿는다.
- 기초 띠·받침은 실제 솔리드 합집합으로 정리하고, 후면은 박공에서 기초까지 닫힌 벽으로 연결했다. 중앙 벽 안에 묻히던 후면 안쪽 기둥은 제거해 끝 조각이 드러나지 않게 했다.
- 새 후면 벽과 겹쳐 검은 끝 자국을 만들던 구형 후면 벽도 제거하고 후면 렌더에서 재확인했다.
- 계단 폭은 약 2.69로 좁히고 동일 높이 세 단과 양쪽 돌 받침을 구성했다. 문 크기·창 크기/위치·시계/간판 위치도 원본에 맞춰 재측정했다.
- v19의 화면 케이지 변형 실험은 벽과 지붕을 흐트러뜨려 폐기했다. 이 모델에는 해당 변형을 사용하지 않았고 수직 벽·원기둥·평면 지붕을 새로 구성했다.

## 파일

- `CipherSecurities-clock.glb`: 실제 3D 에셋.
- `CipherSecurities-reference.blend`: 편집 원본과 원본 대조 카메라.
- `front-right.png`: 원본과 같은 1374×1145 화면의 실제 모델 렌더.
- `comparison.png`: 왼쪽 원본 / 오른쪽 실제 렌더. 두 이미지에 동일한 자르기·균일 축소만 적용했다.
- `overlay.png`: 원본과 실제 렌더의 50% 겹침. 모델 수정 결과를 가공해 숨기지 않는다.
- `front.png`, `rear.png`, `junction.png`: 정면·후면·지붕 접합부 실제 모델 렌더.
- `validation.json`, `geometry-validation.json`: GLB 구조·유한 좌표·네 수직 원기둥·시계/문 노드·기준점 투영 검사.

재현: Blender 5.2에서 `build.py`, `review.py` 순서로 실행하고 Python으로 `verify.py`, Pillow가 있는 Python으로 `compare.py`를 실행한다. `projection.py`는 기준점과 카메라, `roof.py`는 실제 경사면·기와·접합부, `build.py`는 외벽·문·창·기둥·계단을 담당한다. 모든 소스는 500줄 미만이다. 기존 제작 폴더의 공통 형상 함수를 재사용한다.

P1 (Major) · ✅ 원본 기준 지붕·건물 비율 재제작·실제 모델 대조·내보내기 검사 / ⏳ 사용자 최종 시각 검수·게임 적용.

기존 시계/문 노드 이름은 보존했으며 이번에는 게임 파일·저장·실내·시설 기능을 교체하지 않았다. 게임 배율·충돌·실시간 시계 동작은 적용 시 별도 검증 대상이다. 보이지 않는 후면은 현행 기준대로 창 없는 벽으로 만들었다. 조명·재질과 작은 세부까지 픽셀 단위로 동일한 복제라고 기록하지 않는다.
