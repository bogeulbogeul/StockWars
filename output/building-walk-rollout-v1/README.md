# 건물 도보 이동 통일 — 2026-10-25

✅ 구현 완료. 이전 `building-walk-audit-2026-10-25`의 누락 목록을 수정한 후속 적용 기록이다.

## 적용

- 집·안내소·은행 일반 입장을 문 접근→문 열기→걸어 들어가기로 연결했다. 잡화점·증권사의 기존 입장 걷기를 유지하고 문 개방 대기 중 위치 보정으로 뒤로 튀는 일을 막았다.
- 실내가 있는 5개 건물의 퇴장을 실내 출입구까지 걷기→외관 문 열기→밖으로 걷기→닫기로 통일했다. Esc와 공통 마을 복귀도 출입 동작을 우회하지 않는다.
- 멀리서 집/시설 열기 명령을 호출해 즉시 입장하는 경로를 차단했다. 이미 마을/집에 있는 상태에서 같은 화면을 다시 열어 위치를 초기화하지 않는다.
- 첫날 후반 장소 이동의 직접 좌표 대입과 대사용 실내 강제 배치를 제거했다. 집→게시판, 상점/증권사→벤치, 안내소·집 재방문도 실제 WASD 도착을 기다린다. 안내 카드는 이동을 시작하면 숨긴다.
- 전시의 공통 뒤로가기 목적지를 각 건물의 실제 외부 입구로 수정했다. 기존 모아 선행 안내소/은행 퇴장과 은행→집 추종 흐름은 유지했다.
- 증권사 내부 두 방도 문을 열고 문턱까지 걷고, 연결된 방 입구에서 안쪽으로 걸어온다. 저장 좌표나 로비 중앙으로 즉시 돌아오지 않는다. 문 개방 중에는 해당 문턱의 좁은 통로만 충돌 예외로 허용한다.
- 실내와 실외는 별도 좌표계이므로 문 경계에서 대응 입구로 연결한다. 목적지 건물/대화 위치로 플레이어를 이동시키는 기능은 아니다.
- 외관만 있는 가구점·쉼터·서점·우체국은 기존 마을 길로 접근한다. 이번 작업에서 새 실내를 제작하거나 폐기 기능을 복원하지 않았다.

## 검증

- 관련 단위 테스트 22개 통과: 실내 음수 좌표 경로 탐색·가구 우회·프레임별 연속 걷기·원격 증권사 입장 차단·기존 출입 및 전시 진행 회귀 검사.
- `scratch/check-all-building-walk.cjs`: 웹 5개 건물 일반 입장/퇴장 왕복 통과. 증권사 내부 두 방 왕복 통과. 기존 실행본 리소스로 같은 5개 건물 및 내부 방을 재검사했다.
- `scratch/check-story-building-walk.cjs`: 웹 및 실행본 리소스에서 집→게시판→잡화점→벤치→증권사→벤치→안내소→잡화점→집 이동 통과. 입력 없이 위치가 유지되는지 검사한 뒤 실제 WASD 이벤트로 도착시켰다. 이동 프레임은 구간당 약200~550개이며 브라우저 오류는 없었다.
- 변경한 게임 소스 17개는 웹/기존 실행본 SHA256 일치. 설치 프로그램 재빌드는 수행하지 않았다.
- 실제 플레이에서의 연출 속도·카메라·외형 접촉에 대한 사용자 최종 시각 검수는 별도다.
