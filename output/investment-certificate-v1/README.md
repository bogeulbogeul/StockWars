# 투자 자격증 v1

토리 증권사·청회색 결정 문양·이중 테두리·입주 이름·정보 읽기 3문항 이수·마을 주식 거래 범위·토리 인장의 종이 증서를 구현했다. 기존 certificate 활동에서 ACCOUNT_QUIZ를 모두 읽은 후 표시하며 수령 버튼은 기존 next('certificate')로 연결한다. 정답 수와 관계없는 발급 및 기존 분석력 계산·저장·투자 자격 조건을 유지한다. 새 능력치·수익 보장·실제 금융 자격증이나 별도 발급 번호를 추가하지 않았다.

웹/기존 실행본 소스 4개 반영. 설치 프로그램 재빌드 없음. scratch/check-investment-certificate.cjs에서 1280×900·390×844·844×390 화면 경계·이름·이수·수령 콜백을 확인했다. 전시 상태 테스트 6개 통과. PNG는 독립 UI 브라우저 렌더이며 최종 게임 내 사용자 검수는 별도다.
