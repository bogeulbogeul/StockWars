# 붉은여우 운반 연결선 v4

2026-10-17 후속: 사용자 요청으로 게임 상점·플레이어의 붉은여우 슬롯에 설치했다. PNG·팔레트는 이 폴더의 파일과 바이트 동일하며 다른 숲속5종은 유지했다. 얼굴 크롭 `[8,102,304,278]`, 표시 배율90/340을 적용하고 관련 회귀18검사를 통과했다. 아래 게임 설치 별도 표기는 제작 당시 이력이다. 실제 플레이 시각 검수는 별도다. 설치 기록은 game-installation.json을 따른다.

v3의 수평 머리 조합 경계와 v2의 팔 뒤 색 보정에서 손상된 연결선을 네이티브 이미지 편집으로 복원했다. 사선 걷기 얼굴을 참고하며 목·어깨·팔을 하나의 연결된 완성 그림으로 수정하고 운반4프레임을 추출했다. 머리 영역을 수평 절단해 붙이는 방식은 사용하지 않는다.

공통371색과4프레임·160ms·기존 순서를 유지한다. 귀 상단 높이의 프레임 간 차이는2px다. 다른15개 논리 프레임은 v3와 바이트 동일하다. RGB 포함·시트 좌표·잘림·미리보기 렌더 경로 검사는 통과했으며 실제 브라우저 재생 연속성 검수와 게임 설치는 별도다.

생성 도구와 최종 프롬프트는 generation.json, 추출·팔레트 처리는 export.py를 참조한다.
