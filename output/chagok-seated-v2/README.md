## 후속 실제 메시 교차 검사 — 좌판 겹침 발견

사용자 요청으로 배포 GLB와 은행 의자를 실제 게임 좌표/배율로 삼각형 교차 검사했다. **좌판과 차곡 하체가 겹친다.** `Executive_Seat`와 몸 메시에서 교차 삼각형 쌍 3,136개, 의자 안에 들어간 캐릭터 정점 32,964개, 표본 최대 침투 깊이 약 9.481 게임 단위가 확인됐다. 몸 높이 100을 기준으로 약 9.5%다. 좌판 안의 하체를 골반 기준점만으로 맞추면서 놓쳤으며 아래 초기 렌더/위치 검사 통과를 메시 비관통 통과로 해석하지 않는다.

등받이·팔걸이에서는 이 배치의 메시 교차를 발견하지 못했다. 이 결과는 삼각형 교차와 최근접 표면의 안쪽 정점 표본 검사이며 전체 침투 깊이의 해석적 최댓값은 아니다. [검사 스크립트](check_contact.py) · [검사 결과](contact-report.json). 이번에는 검사만 수행했고 게임/제작 모델은 바꾸지 않았다. **⏳ 하체/좌판 접촉 보정 필요.**

P1 (Major) · ✅ 착석 제작·웹/기존 실행본 리소스 반영·브라우저 검사 / ⏳ 사용자 최종 플레이 검수.
