# 구름 없는 시간대별 3D 하늘 v1

P2 · ✅ 웹·기존 실행본 적용·자동 검증 / ⏳ 사용자 최종 시각 검수

사용자 요청으로 `TownLandscapeTextures.js`의 고정 하늘/구름 그리기를 제거했다. 독립 `TownSky.js`와 데이터 `townSkyPalettes.js`에서 새벽(연보라·분홍·크림), 낮(하늘색·연청색), 노을(보라·분홍·살구), 밤(짙은 남색·푸른 회색)을 관리한다. 보이는 하늘 상단 영역 안에 수평선 색이 드러나도록 그라데이션 범위를 맞췄다. 별·달·추가 구름은 그리지 않는다.

`TownLandscape`의 공통 하늘이므로 일반 마을·전시 마을·버스 도착의 마을 장면에서 사용한다. 기존 `timeOfDayService.calculateTimeOfDay`의 지역/계절별 일출·일몰 판단을10초 간격으로 재사용하고 기존 수동 시간 선택이 있으면 따른다. 전시 스토리 노을 상태는 우선 적용한다. 지오로케이션 요청이나 별도 반복 타이머는 추가하지 않는다. 시간대 경계에서는12초 smoothstep 색 전환을 사용하고 기존 텍스처 한 장을 갱신한다.

이번 범위는 하늘 배경 색이다. 건물·지면 조명, 기존 시간 서비스 정책·실내·이동·날씨는 변경하지 않았다. 구형 UI는 연결하지 않았다.

웹과 기존 로컬 실행본에4개 모듈을 동기화했다. `scratch/check-current-exteriors.cjs`의 하늘 검사에서 네 팔레트가 서로 다름·하늘 각 높이의 가로 색상 균일(캔버스 디더링 오차2 허용)·전환 시작/중간/12초 종료를 확인했다. 기존 건물/길/입구/시계/작은 화면/JavaScript 오류 검사도 통과했다. 하늘 검사는 캡처 직전 브라우저 assertion으로 수행하며 실패하면 명령이 종료된다. `web-sky-*.png`, `desktop-sky-*.png`, `sky-four-times.png`는 시간대별 검사 카메라 실제 게임 렌더다. 설치 프로그램은 재빌드하지 않았다.
