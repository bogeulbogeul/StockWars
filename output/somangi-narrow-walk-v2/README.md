# 소망이 좁은 통로 걷기 v2

**폐기:** 사용자가 원한 동작은 앞으로 걷기가 아닌 게걸음이다. 후속은 [게걸음 v3](../somangi-crab-walk-v3/README.md)를 따른다. 게임에 설치하지 않는다.

✅ 옆으로 돌기·배 앞에 팔 모으기·짧게 디디기 제작 / ⏳ 사용자 시각 검수·게임 연결

기괴하다는 사용자 피드백을 받은 v1의 좌우 발 이동을 폐기했다. 기존 걷기 v4 몸체와 원본 얼굴을 사용하고, Root를 90도 회전해 몸 전체를 옆으로 돌린다. 두 팔은 어깨 연결을 유지한 채 손끝이 배 앞쪽으로 모이도록 회전한다. 다리는 위치·스케일을 바꾸지 않고 ±10도로 작게 회전시킨다. Root 높이로 접지를 보정한다.

- `somangi-narrow-walk.blend` / `somangi-narrow-walk.glb`: 편집 원본·게임용 모델.
- `Narrow_Enter`: 0.5초 몸 돌리기/팔 모으기.
- `Narrow_Walk`: 1초 짧은 걸음 반복.
- `Narrow_Exit`: 0.5초 원래 자세 복귀.
- `narrow-front.gif`, `narrow-angle.gif`: 진입→두 주기 걷기→복귀를 이어서 확인하는 제자리 프리뷰.
- `validation.json`: 97시점 다리 길이·배 형상·접지·루프·GLB 클립 검사. 다리 위치 이동 0, 루프 오차 0.

게임 이동 거리·통로 자동 감지·충돌 폭·속도 동기화는 연결 전이다. 제자리 프리뷰이며 실제 통과 장면 검수를 완료한 것은 아니다. 게임에 설치된 기존 동작은 교체하지 않았다. v1은 폐기 이력으로만 보존한다.
