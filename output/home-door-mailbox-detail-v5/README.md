# 집 문·우체통 디테일 v5

사용자의 문 표면 보정 방향과 “우체통 디테일도 좀 높여줘” 요청을 반영한 제작본이다. 현행 v4 집의 크기·지붕·창·문틀·원형 유리·손잡이 위치와 우체통의 오른쪽 배치를 유지한다.

- 문 하단의 돌출 사각 패널과 음각을 제거하고 문짝 원본을 복원한 뒤, 얇고 끝이 둥근 세로 홈 다섯 개를 실제로 절삭했다.
- 우체통은 기존 크기와 둥근 상부 실루엣을 유지하며 내부 공간과 깊이 있는 투입구, 작은 비 가림 턱, 연속 테두리와 앞문 안쪽 면을 제작했다.
- 봉투 표식에는 위쪽 접힘과 아래 모서리 선을 추가하고, 황동 원형 손잡이·고정판·연결대와 작은 경첩 두 개를 구성했다.
- 목재 기둥 아래 소켓·위쪽 받침·크림색 접지 받침을 맞물리게 구성했다. 우편 수신이나 보상 기능을 추가한 작업은 아니다.

`front-right.png`는 실제 전체 렌더, `mailbox-detail.png`와 `door-detail.png`는 실제 모델 확대 렌더다. `Home-with-right-mailbox.glb`는 결합본, `Home-redesign.glb`는 집 단독, `Mailbox-right.glb`는 지면 원점의 우체통 단독 에셋이다. 편집 원본은 `Home-door-mailbox-detail.blend`다.

세 GLB를 다시 불러 유한 좌표·지면 접촉·오른쪽 배치와 계단 여유를 검사한다. 정확한 결과는 `validation.json`, 파일 해시는 `manifest.json`을 따른다.
