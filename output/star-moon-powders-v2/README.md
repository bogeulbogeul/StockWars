# 별가루·달가루 — 종이봉지와 가루 보정 v2

현행 `web/assets/items/packing-v1/items.png`의 별가루 `450,405,300,355` 및 달가루 `840,405,300,355` 영역을 직접 확인했다. 밝은 금색/크림색 종이봉지와 네 갈래 별, 연보라색 봉지와 크림색 초승달·잎가지·띠를 따른다. 별가루의 기존 내부 ID `item_crypto_decoder`는 변경하지 않았다.

공통 봉지 구조는 아래쪽이 넓고 위가 좁아지는 열린 종이봉지다. 앞면의 완만한 굴곡, 옆면 안쪽 접힘, 실제 얇은 종이 두께·안감, 앞보다 높은 뒤쪽 입구와 안쪽으로 접힌 윗단을 포함한다. 이전 두꺼운 입체 라벨·솟아오른 표식·모서리 막대는 제거했다. 별·달·가지·띠는 선명한 평면 인쇄로 새로 구성했고 각 GLB에 해당 PNG 한 개를 내장했다.

가루는 봉지 안으로 이어지는 채워진 더미 위에 상품별 2,800개의 작은 결정 알갱이를 올렸다. 골드/크림 알갱이와 보라/연보라 알갱이를 구별하고, 입자들은 하나의 메시로 합쳤다. 별도 받침이나 떠 있는 원판 없이 가루 더미 가장자리가 입구 아래로 내려간다. 발광·공중 파티클·게임 효과는 추가하지 않았다.

두 개의 GLB를 각각 다시 불러와 파일 구조·유한 좌표·퇴화면 0개·내장 인쇄 이미지 디코딩을 검증하고 전체·재수입 확대·후면을 렌더했다. 정확한 메시/삼각형 수와 경계·해시는 `validation.json`을 따른다. `build.py`는 두 상품을 각각 원점에서 내보낸 후 `.blend` 검토 화면에서 나란히 놓는다. `prepare.py`는 인쇄 PNG와 편집 가능한 SVG를 재현한다.

이번 수정본을 기존 12종 모음의 별가루·달가루보다 우선하는 후속 제작본으로 사용한다. 다른 상품·가격·저장·효과·판매 UI·포장 퍼즐·기존 실행본은 변경하지 않았다. 게임 적용과 사용자 최종 외형 검수는 별도다. GLB는 상품만 포함하고 `.blend`는 촬영용 조명·바닥·카메라를 포함한다.
