# 비비안 잡화점 실내 디자인 v1

2026-10-19 · ✅ 시안 제작 / ⏳ 사용자 채택·3D 모델 제작·게임 적용·동선/접촉 검수.

외관의 코랄·크림·꿀색 목재와 매끈한 무광 재질을 이어가는 운영용 고정 배치다. 왼쪽 벽 상품 진열대와 낮은 중앙 진열대 → 오른쪽 뒤 포장대 → 오른쪽 앞 전달/계산대로 짧게 연결한다. 정면 중앙 입구와 중앙 통로를 비우고 뒤 벽에는 창을 두지 않는다. 오른쪽 측면에 아치 창을 둔다.

`concept.png`는 built-in image_gen으로 제작한 디자인 참고 이미지이며 실제 3D 에셋이나 검증된 충돌 배치도가 아니다. 이전 게임 실내는 변경하지 않았다. 정확한 룸 치수·통로 폭·상품 구성·상호작용 위치는 후속 제작에서 검증한다.

프롬프트 요약: 현행 외관을 색/재질/건축 스타일 참고로, 옛 실내는 잡화점 구성 참고로만 사용. 크림 벽, 코랄 포인트, 밝은 나무 진열대, 베이지 타일, 소형 음료 냉장고, 포장지/리본/종이봉투가 있는 작업대와 꽃 문양 계산대. 낮은 상품대와 열린 중앙 동선. 지붕을 제거한 3D 사선 전체 보기, 부드러운 조명, 캐릭터·문자·UI 없음.
