# 메신저 친구 추가·채팅방 만들기 시안 v2

사용자 요청으로 목록 상단에 친구 추가/채팅방 만들기 진입 버튼을 추가한 3화면 시안. 친구 추가는 정확한 ID 검색·결과 프로필·친구 요청·수락 대기 상태, 채팅방 만들기는 친구 다중 선택·선택 인원·선택적 방 이름·시작 버튼을 표현한다. 0명 선택 시 만들기 비활성. 플레이어 친구와 마을 주민 대화를 구분하며 예시 이름·ID만 사용한다.

브라우저 안의 시안 상태만 변경한다. 실제 친구 요청 전송·계정 검색·채팅방 저장·게임 적용은 하지 않았다. 기존 채팅 화면 디자인은 v1에 보존한다. 사용자 디자인 채택 여부는 별도다.
