## 사용자 요청 반영

오프닝 첫 번째(요정이 태어나는 밤) → 두 번째(나무 아래 소망이) → 마을/버스 도착 → 안내 캐릭터 대화 → 신청서 전달과 이름 입력·제출 → 휴대폰 수령 → 포장 **첫 상자 한 개만** → 보수/봉투 수령 → 증권사 트레이닝룸 → 기업 정보·차트·첫 매수 → 타이틀 순서다. 게임 표시는 기존 ‘모아’를 유지했다.

모두 이번 수정 요청에서 새로 촬영했다. 차트는 타이틀의 별도 시뮬레이션이 아니라, 이야기 진행으로 들어간 실제 증권사 트레이닝룸의 컴퓨터에서 촬영했다. 확대 차트 뒤로 증권사 벽/문/가구가 보인다. 이전 타이틀 배경 차트 컷은 사용하지 않았다.

신청서·휴대폰·보수·봉투는 물건을 내미는 동작이 끝나도록 기다린 후 수락하고, 수령 완료와 후속 화면까지 계속 녹화했다. 신청서 전달→작성/제출, 보수→봉투는 각각 연속 구간을 그대로 사용했다. 이 구간에는 편집 페이드나 중간 컷을 넣지 않았다. 전달 시작/수락/완료 시점은 marks.json에 있다.

포장은 첫 상자의 빈 상태부터 배치·완성 결과(1/3)까지 한 구간만 사용했다. 게임의 세 상자 규칙과 보상 조건은 바꾸지 않았으며 뒤 두 상자는 진행을 위해 실제 입력으로 완료하되 광고에는 넣지 않았다. 게임 상태·거래 수치 변경이나 타이틀 배경 합성은 하지 않았다.
