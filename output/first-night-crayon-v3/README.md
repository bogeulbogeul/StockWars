채택 파일은 [asleep.png](asleep.png)다. 기존 오프닝과 같은 크레파스 그림책 형식이며, 소망이는 맨바닥에 옆으로 누워 한 팔로 뺨을 받치고 다른 팔을 배 위에 둔다. 두 발은 몸 뒤쪽으로 모아 v2의 머리 아래 팔다리 겹침을 정리했다. 차가운 밤빛·빈 방·흙만 든 화분을 유지한다.

다이어리는 `../story-diary-v1/closed.png`의 세이지색 표지·짙은 초록 책등·빈 아이보리 라벨·베이지 책갈피를 따른다. 침대·이불·베개·새싹은 추가하지 않는다.

이 파일을 첫날 밤 수면 장면의 최신 채택 그림으로 사용한다. v1 앉은 그림과 v2 이전 누운 자세는 제작 이력으로 보존한다. 앞서 제작한 3D 수면 모션은 이 채택 대상이 아니다.

이번에는 채택 상태만 기록했다. 현재 게임의 v1 18초 취침 연출·타이틀 복귀·대사·음악·저장은 변경하지 않았다.
