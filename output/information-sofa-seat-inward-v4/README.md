# 안내소 소파 안쪽 착석

2026-10-26 사용자 요청으로 안내소 소파 두 자리의 앞쪽 오프셋을 약41→22로 줄여 소망이가 등받이 쪽으로 약19 게임 단위 깊게 앉도록 했다. SeatSurfaces의 선택적 forwardOffset을 두 좌판에만 지정했다. 소파 모델/배치·테이블/카펫 중앙 정렬·캐릭터 체형·다리 각도·다른 좌석 오프셋은 유지한다. 높이는 기존 좌판 접촉 계산으로 결정한다.

웹/기존 실행본 SeatSurfaces.js에 반영했다. `scratch/check-information-sofa-seat-inward.cjs`를 양쪽에서 실행해 두 자리 착석/일어서기·실제 E키·가구 충돌·동선/지도/창구 접근을 확인했다. JavaScript 오류는0건이며 실제 확대 착석 화면을 열어 확인했다. 사용자 최종 시각/플레이 검수와 설치 프로그램 재빌드는 별도다.
