# 소망이 표정 14종 · v5

사용자 요청으로 시무룩과 뿌듯함을 현행 표정 목록·비교표·개별 PNG/텍스처/GLB·ZIP·Blender 재질 라이브러리에서 제외했다. 이전 제작 버전은 이력으로 보존하며 이번 현행 구성에 포함하지 않는다.

기본 미소, 기쁨, 차분함, 궁금함, 놀람, 걱정, 울먹임, 삐침, 결심, 쑥스러움, 안도, 감동, 졸림, 맛있음의 14종이다. 나머지 PNG·텍스처·모델은 v4 파일과 해시가 동일하다. 외형·굵고 깔끔한 눈 곡선·U자 입·본·모션을 변경하지 않았다.

`expression-sheet.png`는 새 번호로 정리한 전체표다. `somangi-expression-textures.zip`은 개별 초상화와 UV 텍스처, `somangi-expression-models.zip`은 표정별 정지 GLB 14종이다. `somangi-expressions.blend`에서도 제외한 두 표정의 재질과 이미지를 제거했다. 원본 모션은 Blend에 보존하며 GLB는 표정 확인용 정지 모델이다. 게임 설치·표정 자동 전환은 포함하지 않는다.
