# 할 일 앱 2D 시안 v1

아이보리 화면·라벤더 진행도 카드·초록 선택 상태·검은 큰 글씨의 목록/상세 시안이다. 상단 ‹ 홈 화면 유지, 하단 홈 버튼/프레임 X 없음. 목록은 전체/진행 중/완료 필터, 진행도, 직접 할 일 추가를 제공한다. 상세는 설명·장소·단계·목록 상단 고정을 표현한다.

마을 생활 진행은 게임 플레이 자동 확인, 내 메모는 사용자 체크 방식으로 제안한다. 현재 항목·날짜·진행도는 시안용 예시이며 게임 사건/저장/보상과 연결하지 않았다. 사용자 디자인 채택 및 실제 게임 적용은 별도다.

scratch/capture-tasks-design.cjs로 필터(5/3/2), 상세 전환, 목록 고정, 직접 메모 추가, 페이지 오류 없음 검증 후 preview.png 촬영했다. 기존 게임 파일 및 실행본은 변경하지 않았다.
