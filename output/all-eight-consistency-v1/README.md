# 8종 전체 승인 외형·색·모션 비교

사용자가 오소리를 포함한8종 전체에 표정/입/색 일관성과 자연스러운 머리 움직임을 적용하도록 요청했다. 현재 승인된 강아지·고양이·붉은여우·시베리아다람쥐·너구리·유럽오소리·불곰·유럽토끼의 전체 방향·걷기·운반·앉기·초상화 및 강아지 꼬리 대기를 스냅샷하고 자세 보드로 비교했다.

승인된7종의 그림체/털색/고유 얼굴과 기존 자연스러운 자세 변화는 유지한다. 이7종은 새로 그리거나 색을 바꾸지 않았으며 PNG 바이트가 동일하다. 오소리는 앞선 색/입 보호 결과를 유지하되 걷기 접지6그림의 **완성된 몸 전체**를 중립 대비2px 아래로 정렬했다. 얼굴만 붙잡아 두는 고정을 추가하지 않는다. 머리·목·몸통은 같은 완성 그림으로 함께 움직이고 중립은 기존 원본이다. 걷기3그림·160ms·0→1→2→1, 좌우 반전과 기존 모션 수는 유지한다. 이 수정은 생성이나 리깅이 아닌 완성 프레임 등록/조합이다. 전용 스크립트는 프로젝트 수작업 어댑터이며 새 엔진 생성 기능이라고 주장하지 않는다.

모든170논리 프레임에 대해 투명 픽셀을 제외한 RGBA 색 값과 각 값의 개수가 직전 승인 프레임과 동일한지 검사했다. 오소리의 이동은 잘림 없이 되돌렸을 때 전체 RGBA가 동일한지도 검사한다. **이 검사는 새 색 변화가 유입되지 않았다는 증거이며, 기존 그림의 모든 시간적 색 변화/명암 차이가 제거됐다는 증거가 아니다.** 동일 팔레트 검사만으로 전체 색 일관성 통과를 주장하지 않는다. 그림체·색은 승인된 각 종의 기준을 유지하며 모든 동물을 같은 색으로 바꾸지 않는다.

전체 자세 보드의 외형·무늬·선·색을 비교했고 원본 보존·시트 좌표·공유 중립·GIF 순서/시간·렌더러 연결을 검사한다. 실시간 브라우저 재생 검수와 실제 게임에서의 발 접지/미끄러짐·가구/화물 접촉은 별도 미검증이다. 2px 이동이 최종적으로 자연스럽게 보이는지, 모든 동작에서 반짝임이 없는지는 실재생 판정 전이다. 따라서 이 작업을8종의 모든 동작 재생 품질 최종 통과로 표현하지 않는다.
