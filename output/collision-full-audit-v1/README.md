# 마을·실내 전체 충돌 점검 및 보정

P1 · ✅ 웹·기존 실행본 적용·자동 점검·대표 렌더 확인 / ⏳ 사용자 최종 플레이 검수

## 범위와 발견 사항

현재 마을 건물 9종·소품 185개(배경 숲 포함 194개), 집·잡화점·안내소·은행·증권사 로비·트레이닝룸·모의투자룸 7곳을 점검했다. 현재 코드에 적용된 봉봉이도 검사했으며 신규 캐릭터나 폐기 기능을 복원하지 않았다.

추가로 수정한 사항:

- 마을 소품의 X축 여유 28이 몸통/팔 외곽보다 작았다. 소품도 건물과 같은 월드 X/Z 원형 충돌 및 공간 셀 조회를 사용하도록 통일했다.
- 실제 스킨 정점을 17개 모션 시점에서 측정한 결과 걷기 반경 최대 31.226, 먹기 최대 40.232, 걷기 높이 최대 100.977이었다. 공통 몸통 반경을 38→42, 높이 클리핑 상한을 100→102로 늘려 실제 동작을 감쌌다. 모델 크기·자세는 바꾸지 않았다.
- 잡화점 봉봉이가 공통 NPC 등록에서 빠져 있었다. 기존 모델에 몸통 충돌을 연결했다.
- NPC의 캐시된 스킨 Box3 중심은 회전/자세 변화 후 실제 몸 중심과 다를 수 있었다. 실제 변형 정점에서 루트 기준 반경을 구하고 루트의 현재 월드 위치를 따라가도록 바꿨다. 모아의 원래 앉기/일어서기와 차곡이 확정 착석은 변경하지 않았다.
- 대화 장면의 직접 위치 배치와 렌더 직전에도 겹침을 보정한다. 마을에서는 모아의 새 위치/자세를 먼저 갱신한 후 소망이를 보정해 같은 렌더 프레임에 반영한다.

## 최종 결과

웹과 기존 실행본 각각 동일한 결과:

| 마을·실내 8방향 경계 표본 | 411,232개 |
| 유효 위치에서 충돌체 방향으로 접근 이동 | 3,971건 |

| 실내 초기 대화/진입 좌표 | 7곳 모두 유효 |
| JavaScript 오류 | 0건 |

마을 오브젝트의 대표 중심 중 플레이 경계 밖인 배경 숲 119개는 강제 배치 복구 검사에서 제외했다. 해당 오브젝트의 충돌 경계 표본 검사는 포함했다. 플레이 불가능한 외부 숲 안에 캐릭터를 강제로 배치해 복귀시키는 기능은 추가하지 않았다.

`web-baseline.json`과 `web-npc-measure.json`은 수정 전 진단이다. 초기 NPC Box3 기준 추정과 실제 정점 기준을 구분하며 최종 판정은 루트 기준 실제 정점 외곽을 사용한다. `web-final.json`·`desktop-final.json`이 최종 전체 점검 결과다.

## 실행 및 회귀 검증

```
node --test web/tests/storyCollisionPlacement.test.mjs web/tests/exteriorBuildingBodies.test.mjs web/tests/indoorWallBodies.test.mjs web/tests/indoorFurnitureBodies.test.mjs web/tests/characterBodies.test.mjs web/tests/townPropBodies.test.mjs
node web/tests/arrivalBench.browser.cjs web output/collision-full-audit-v1 final
node web/tests/arrivalBench.browser.cjs electron-app/dist/win-unpacked/resources/web output/collision-full-audit-v1 final
```

단위/회귀 테스트 13개 통과. `CollisionAudit.js`·`CollisionAuditScenes.js`는 실제 모델의 충돌 경계를 검사하고 실제 이동 함수를 호출한다. 원형/사각형의 모서리도 대각선 표본으로 검사한다. NPC는 실제 스킨 정점의 반경과 16방향 접근을 검사한다.

추가로 `output/collision-regression-v1/exterior-wall/`에서 웹·실행본의 건물 9곳 입구 도달과 실내 7곳 출구/복귀 문, 잡화점 계산대 접근을 확인했다. 첫 도착 벤치·모아 대화 접근 회귀 검사도 통과했다. 같은 폴더의 집 정면·잡화점 실제 렌더를 열어 확인했다.

기존 실행본 resources/web의 변경 모듈 8개를 웹과 동기화하고 해시 일치를 확인했다. 설치 프로그램은 재빌드하지 않았다. 저장·경제·기존 모델·건물 배치는 변경하지 않았다.

## 검증 한계

이번 결과는 현행 모델의 충돌 근사와 검사 표본에서 위험이 검출되지 않았다는 뜻이다. 전체 표면의 연속적인 메시-메시 비관통을 수학적으로 보증하거나 모든 위치를 수동 키보드 플레이했다는 의미는 아니다. 가구/외벽은 메시별 사각형, 벽은 삼각형별 투영 근사를 사용한다. 높은 처마·수관의 정상적인 화면 가림은 지면 충돌 누락과 구분한다. 사용자 최종 시각·플레이 검수는 별도다.
