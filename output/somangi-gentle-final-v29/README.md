# 원본 외형 기준 작은 먹기 모션 v29

사용자가 제안한 작은 먹기 방식의 실제 GLB 시안. 게임에는 설치하지 않았다.

## 동작
- 원본 계열 `somangi-black-eyes-v1`의 표면에서 시작했다. 머리·몸통·다리의 원본 정점은 고정한다. 기존 v20의 재구성 몸통을 사용하지 않는다.
- 처음부터 양손을 모은 채 작은 들썩임으로 먹는다. 손 간격은 음식 크기와 관계없이 고정한다. 팔은 단일 본 100% 가중치로 회전·이동하며 스케일·혼합 가중치로 늘리지 않는다.
- 빵은 초기 크기의 100% → 2/3 → 1/3 → 0으로 균등 축소한다. 작은 입 열기·씹기 뒤에는 원래 U자 미소가 나타난다.
- 1.9초에 빵이 사라지고, 이후 약 0.8초 동안 빈손을 내려 원본 기본 자세로 돌아온다.
- 팔을 내리는 경로에서 배를 가로지르지 않도록 필요한 만큼 앞쪽 여유를 둔다. 팔과 빵을 함께 보정한다. `clearance-path.json`.

## 형상과 접합부
원본 외부 좌표를 이동하지 않고 원래 절단부 안쪽에 고정된 접합 면을 추가했다. 머리/몸통을 새 체형으로 조형하거나 관절을 덮는 구체를 추가한 시안은 채택하지 않았다. 기존 조각의 같은 위치 정점은 각 부위 안에서 정리하고 법선을 재계산했다. 얼굴 텍스처·UV와 검은 눈은 유지한다. 숨겨진 어깨 부착부는 겹쳐 연결하며, 양측면에는 접합선의 음영이 일부 남아 있어 최종 미술 검수 대상이다. 원본 전체의 픽셀 단위 동일성이나 관절 안쪽까지 무교차라고 주장하지 않는다.

## 검증
`verification.json`: 181시점 검사.
- 원본 정지 표면 최대 최근접 거리 약 1.4e-7 모델 단위.
- 고정 몸통·머리·다리의 애니메이션 좌표 변화 0.
- 팔 표면 모서리 길이 변화 최대 약 0.066%: 작은 모서리의 부동소수점 오차를 포함한다. 전체 팔은 강체 변환이다.
- 숨겨진 부착부를 제외한 팔/얼굴, 노출 전완/몸체, 음식/얼굴의 표면 교차 시점 0.
- 식사 중 양손 가로 간격 변화 약 1.4e-6 모델 단위.
- 빵의 세 축 균등 축소 및 마지막 0 크기를 확인했다.

`eat-front.gif`, `eat-side.gif`, `eat-opposite-side.gif`, `eat-both-sides.gif`는 실제 내보낸 GLB를 재수입해 촬영했다. 단일 재생이며 마지막 원본 자세에서 멈춘다. 조명과 카메라는 사용자 첨부와 다르다.
