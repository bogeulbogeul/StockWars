`scratch/check-current-exteriors.cjs`를 웹과 기존 실행본 리소스에 실행해 통과했다. `web-checks.json`·`desktop-checks.json`에 9종 로딩/폭/충돌/문 앞 통로·건물 충돌 영역 겹침 0건·KST 시계·작은 화면·JavaScript 오류 없음 결과를 저장했다. 모든 길의 선분을 10단위 간격으로 표본 검사해 차단 0건, 20단위 격자 탐색으로 도착 지점에서 9종 모든 입구 앞까지 도달 가능함을 확인했다. 소품 전체의 메시 비관통이나 수동 실내 출입 검수 완료를 뜻하지 않는다.
