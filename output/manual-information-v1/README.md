# 모아 선행·안내소 직접 이동·대사 복원 — 2026-10-29

## 변경

첫 만남과 이름 대화 후 모아가 ‘안내소에서 입주 안내를 도와드릴게요. 저는 먼저 들어가서 기다리고 있을게요. 안내소 문 앞에서 F키를 눌러 들어오세요.’라고 안내한다. 모아 야외 모델을 숨기고 안내소 실내 모델을 기존 창구 의자에 앉혀 준비한다. 소망이는 현재 야외 위치에 남으며 WASD로 직접 안내소를 찾고 문 앞 F로 들어간다. 문을 열거나 모아와 플레이어를 함께 목적지에 배치하는 연출은 추가하지 않는다.

첫 목적지 이동의 DestinationWalk에 안내소 전용 목적지 가드를 연결했다. 다른 건물의 문 앞 F나 입구 쪽 이동 시 ‘우선 안내소로 가보자.’를 표시한다. 다른 건물로 입장하거나 원격 F로 안내소에 입장하지 않는다. 대사를 닫고 이동을 계속할 수 있다. 안내소 입장 뒤 기존 스툴 E 착석→모아 대화→신청서 흐름을 유지한다.

ShortDialogue 축약 적용을 기본 계획에서 해제해 기존 원문 대화를 복원했다. 정류장 첫 만남·다른 주민의 대화도 포함한다. 원문 중 폐기된 전체 마을 순회 안내는 복원하지 않고 현재 안내소 우선·지도4개 소개·집 우선 순서를 유지한다. 새 첫 이동 안내와 집 문 열기 문구 등 현재 동선에 맞는 소수 문장을 조정했다. 기존 활동26개·포장3상자/300잎·고정1주 수업·보상/예금/대출/저장 조건은 유지한다. 현재 본문은 포장 우선249줄·주식 우선244줄이며 전체 완주 시간은 이번에 측정하지 않았다.

기존 축약 대본은 ShortDialogue.js에 이관용으로 보존한다. 새 상태는 tourDialogueVersion3이며 버전2의 진행 위치는 같은 활동ID 또는 직전 활동 뒤의 대응 대사 구간으로 이관한다. 계좌/완료 플래그를 초기화하거나 이미 받은 보상을 다시 주지 않는다.
