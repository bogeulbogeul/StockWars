# 내 정보·서류 업데이트 2D 시안 v1

사용자 요청: 내 정보 앱 디자인, 서류를 하나씩 받고 서명할 때마다 정보 업데이트.

현행 입주 신청서(ResidenceApplication)·계좌 개설/대출 신청서(BankApplication) 흐름을 참고해 내 정보 / 받은 서류함 / 원본 내용 상세를 디자인했다. 아이보리·로즈 프로필 카드·파스텔 상태 표시, 상단 홈만 유지한다.

수령: 해당 서류가 서류함에 나타나며 서명 대기 표시. 서명·제출: 이름/입주 등록, 생활 계좌 개설, 정착 자금 대출이 해당 단계에서만 확정 정보로 반영된다. 서명 전 대출 신청 금액은 원본 내용에서 볼 수 있으나 확정 대출 항목에는 금액을 표시하지 않는다. 이전 서명 정보는 계속 유지한다. 서류 상세는 원본 서명 장소를 안내하며 앱 안에서 원본 절차를 우회해 서명하지 않는다.

이름·상태·기록은 시안 예시다. 실제 게임은 아직 변경하지 않았다. 향후 적용 시 완료 flags(nickname/bank/loan)와 수령 이벤트를 구분해 저장해야 하며 수령 즉시 서명 완료 처리하지 않는다. 계좌 번호·거주 상세 주소 등 실제로 없는 값은 생성하지 않는다. 휴대폰을 입주 신청서 서명 뒤 받는 현행 스토리 순서도 유지한다.

index.html의5단계 미리보기로 입주 서명→계좌 수령/서명→대출 수령/서명을 비교한다. capture-profile-design.cjs에서 단계별 서류 수·대기/완료·서명 전 확정 대출 금액 숨김·서명 후 금액 반영·필터·오류없음을 확인했다.

preview.png: 대출 서류 수령 후(아직 서명 전). signed.png: 대출 서명·제출 후 업데이트 상태. 사용자 디자인 확정과 실제 게임 적용은 별도다.
