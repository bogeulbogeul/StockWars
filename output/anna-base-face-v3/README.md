# 안나 새싹 앞면 홈 심화·후면 매끈함 — 2026-10-20

사용자 요청으로 새싹 앞면의 중앙 홈을 실제 정점 변형으로 더 깊게 팠다. 최대 추가 깊이는 약 0.012 모델 단위다. 뒷면은 중복 UV 정점들을 같은 위치로 움직이며 표면을 완화하고 부드러운 곡면으로 정리했다. 새싹의 기존 노멀/컬러 무늬는 제거하고 깨끗한 올리브색 무광 재질을 사용한다. 몸과 얼굴의 정점 및 얼굴 텍스처는 보존한다.
