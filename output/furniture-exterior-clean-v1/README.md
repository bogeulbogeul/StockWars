# 모던 프레임 외관 스타일 정리

2026-10-21 · P1 (Major)

측면 박공 후속: 오른쪽 흰 박공 앞면을 X=1.89에서 아래 측벽과 같은 X=1.67로 후퇴했다. 지붕과 목재 마감은 유지한다.

가로보 최신 통일: 정면 전체를 단일 가로보로 제작했다. 상단 1.455·하단 1.34·앞면 Y=-1.10으로 입구와 쇼윈도 구간을 통일했다. 중앙 기둥 상단은 가로보 뒤에서 겹쳐 연결되고 경사 테두리는 가로보 윗면에서 끝난다. 이전 단차 연결을 대체한다.

정면 서까래 연결: 입구 위 가로보 앞면을 오른쪽 처마와 같은 Y=-1.10으로 내밀고 두 목재를 메시 합집합으로 연결했다. 가로보는 입구 동의 폭에서 끝나도록 조정했다.

간판 마감 후속: 외곽 막대의 모서리 겹침을 없애고 목재 판 자체의 연속 테두리로 표현했다. 소파 부조는 12분할 라운딩과 부드러운 노멀을 적용했으며 다리는 동일 높이·수직 방향으로 좌판에 묻어 연결했다.

간판 후속: 벽에서 떨어진 설치를 벽 밀착으로 변경했다. 집 모양 외곽 전체 목재 테두리와 호두색 안쪽 바탕, 쿠션·팔걸이·짧은 목재 다리를 갖춘 크림색 의자 부조로 다듬고 돌출 깊이를 줄였다. `sign-close.png`에서 확대 확인한다. 사용자 최종 외형 검수 대기.

처마 절단 후속: 경사진 주 지붕 테두리의 하단 끝을 가로보 윗면에 맞춰 절단했다. 단순 메시 합치기로 남았던 하단 겹침을 제거했다. 접합부 확대 렌더: `eaves-joint-close.png`.

추가 확인: 경사 목재 뒤에 겹쳐 있던 쇼윈도 지붕 끝도 주 지붕의 끝 경계에서 잘라 검은 삼각형 단면을 제거했다.

처마 접합 정리: 별도 덧댐 블록을 제거하고 가로 마감을 한 길이로 연장했다. 앞뒤 깊이를 곡선 테두리와 맞추고 메시 합집합으로 연결했다. 오른쪽 기둥 위의 겹친 단면도 가로 마감 뒤로 정리했다.

처마 연결 후속: 쇼윈도 지붕 앞뒤 처마 하단에 연속 목재 마감을 추가했다. 주 지붕 접합부부터 오른쪽 곡선 나무 테두리까지 맞물리게 이어 흰 틈을 가렸다.

아치틀 접합 후속: 양쪽 세로틀 하단을 0.18에서 0.15로 내려 계단 윗면 0.16에 맞물리게 했다. 아치 시작 높이와 곡선·문·계단은 유지한다.

입구 최신 정정: 문·문틀 높이를 원래 비례로 복원했다. 상단 문턱은 지면부터 채운 높이 0.16 돌 몸체, 앞쪽 추가 계단은 높이 0.08로 구성했다. 넓은 하단 디딤판과 둥근 모서리로 두 높이를 연결하고 개선한 문고리는 유지한다. 앞선 문 하향 기록을 대체한다.

입구 후속: 떠 있던 문턱을 지면에 닿는 낮은 형태로 교체하고 문 전체를 0.155 내려 하단을 문턱 윗면에 맞췄다. 황동 손잡이는 부드러운 곡선·곧은 중앙부와 두 고정부로 재제작했다. 실제 플레이 입구 접촉·진입은 별도 검수 대상이다.

오른쪽 측벽 후속: 흰 벽 몸체의 둥근 모서리를 최소화하고 오른쪽 면과 가로 돌 기초를 모델 기준 0.09만큼 안쪽으로 후퇴했다. 왼쪽 경계·목재 기둥·개별 돌 받침은 유지한다.

뒤 모서리 기둥 후속: 뒤쪽 두 기둥에 정면과 동일한 돌 받침을 추가하고 목재 길이를 맞췄다. 총 다섯 받침은 바닥까지 닿고 목재는 윗면에 틈 없이 연결된다. 브라우저 검증도 받침 다섯 개 기준으로 갱신했다.

쇼윈도 후속: 가로 약 13%·세로 약 15% 축소, 네 면 테두리 동일 두께, 실제 개구부와 안쪽 유리판으로 변경했다. 건물 가로 확장을 보정해 테두리의 좌우·상하 실측 두께를 통일했다. 두 세로 창살은 위아래 프레임에 연결하고 하단 돌출 창턱은 제거했다.

돌 받침 접지 후속: 정면 세 돌 받침의 높이를 아래로 확장해 하단이 지면에 닿도록 수정했다. 받침 윗면과 목재 연결 높이는 유지한다.

기둥 최신 후속: 사용자 정정에 따라 정면 세 곳의 크림색 돌 받침을 복원했다. 목재 기둥은 처마 가로보 아랫면에서 돌 받침 윗면까지 이어지고 하단을 약간 묻어 모서리 마감에 의한 틈을 막았다. 기존 기초 띠는 유지한다. 브라우저 검증은 돌 받침 3개 복원을 확인한다.

작은 창 제거 후속: 정면 왼쪽 작은 창과 오른쪽 측면 창을 유리·창틀·창살·창턱까지 제거했다. 해당 위치는 기존 크림 벽이며 대형 쇼윈도와 양문 유리는 유지한다. 아래 측면 창 유지 설명은 최초 제작 기록이다.

가로 확장 후속: 사용자 요청에 따라 월드 X축으로 15% 넓혔다. 높이·깊이는 유지하고, 게임 표시 폭도 390 → 448.5로 변경했다. 아래 폭 390은 최초 제작 기록이며 현재 검증 기준은 448.5다.

집·안내소·잡화점·은행과 같은 매끈한 무광 재질과 부드러운 모서리로 가구점 외관을 제작했다. 갈색 기와, 크림 벽, 꿀색 목재, 비대칭 지붕, 의자 간판, 왼쪽 양문과 두 황동 손잡이, 오른쪽 쇼윈도와 측면 창을 유지한다. 거친 텍스처와 석재 줄눈은 제거하고 후면은 창 없는 벽으로 구성했다.
