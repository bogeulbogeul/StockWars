# 소망이 뒤쪽 연결부 명암 정리 v43

P2 (Polish) · ✅ 제작 파일 보정·원본 외형/모션 보존 검사·정면/후면 촬영 / ⏳ 사용자 외형 검수

v42의 뒤쪽 머리 하부와 어깨 안쪽 몸통 표면에 남은 명암 경계를 정리했다. 뒷면의 제한된 구간에서 표면 법선만 부드럽게 이어지도록 보정했다. 정점 좌표·메시 연결·웨이트·본·모션 트랙·재질은 변경하지 않았다. 팔 정점은 법선 보정에서도 제외했으며 어깨부터 손끝까지 단일 본으로 통째로 움직이는 방식을 유지한다.

`normal-edit.json`: 뒤쪽 연결부 정점 10,276개의 법선 보정. 좌표·웨이트 변화 0.

`unchanged.json`: v42와 전체 메시 132,191점의 휴지 좌표·면 구성·웨이트가 같다. 271개 반 프레임 시점에서 전체 메시의 움직이는 위치 차이도 0이다. 따라서 기존 외형과 팔의 강체 움직임을 그대로 보존한다.

`connection.json`: 389개의 머리-몸통 공유 경계에 열린 변 0. 271개 시점에서 연결부 면 뒤집힘 없음. `rigidity.json`은 팔 뿌리를 포함한 강체 변환 오차 최대 1.71e-7을 기록한다.

`eat-front-back.gif`는 최종 GLB를 다시 불러온 실제 정면/후면 모션 36프레임이다. `rear-junction-detail.gif`는 같은 촬영의 뒤쪽 연결부 확대다. 조명에 따른 자연스러운 머리 아래 그림자는 남긴다.

제작 결과만 새 폴더에 저장했다. 기존 v42는 보존했고 게임에 캐릭터 에셋을 복원하지 않았다.

## 양쪽 측면 모션 확인

동일한 최종 GLB를 변경 없이 좌·우 측면에서 각각 36프레임 촬영했다. `eat-both-sides.gif`는 같은 시점의 양쪽 모습을 나란히 표시한다. `side-junction-detail.gif`는 머리 밑·어깨 연결부를 확대한다. 머리·몸통 사이가 벌어지는 틈은 보이지 않으며 팔과 몸통이 만나는 옅은 그림자는 남아 있다. 모션과 형태의 자연스러움은 사용자 최종 확인 대기다.
