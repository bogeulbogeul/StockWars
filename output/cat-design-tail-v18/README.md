# 디자인 시트 외형 복원·뒤 꼬리 움직임 v18

최신 사용자 첨부 디자인 시트를 외형 기준으로 기존16자세 모아보기를 built-in GPT imagegen으로 편집했다. 강아지 RGB 시트는 선·셀 명암·모션 참고다.

- 둥근 얼굴·작은 주둥이·눈/귀·겹친 볼털·작고 뾰족한 가슴털깃·체형·긴 C자 꼬리를 디자인에 맞췄다. v17의 둥근 단색 가슴 패치를 털깃 형태로 교체했다.
- 뒤 걷기3그림의 꼬리는 오른쪽으로 휘는 형태를 유지하며 A는 몸 쪽으로 조금 모이고, 중립은 기본 곡선, B는 바깥쪽으로 더 퍼지는 곡선으로 편집했다. 기존 골반 연결을 참고했다. 자동 좌표 검사만으로 정확한 해부학적 뿌리 고정을 증명하지는 않는다.
- 앞 걷기의 과한 머리 기울임은 넣지 않았고, 정면 앉기는 두 손을 무릎 위에 올리는 자세를 유지했다. 뒤 귀는 어두운 뒷면, 등에 가슴털 무늬를 추가하지 않는다.
- 생성된 깨끗한 색면을 보존하고 강제 색상 임계값 변환은 사용하지 않았다. 아주 흐린 alpha 잡음만 제거했다.
- ✅ 투명 배경·10상태/16고유그림·셀 잘림 없음·기존 시트 좌표·재생 구성 동일 확인. 걷기 A→중립→B→중립과 운반4그림 모두160ms. 정지는 중립과 동일.
- 새 외형 편집본이므로 이전 픽셀/alpha/손발 접촉 동일을 주장하지 않는다. 게임 설치·실제 접촉 검수와 사용자 최종 채택은 별도다.

sprite-sheet-alpha.png, manifest.json, frames/가 전달본이다. preview.html은 강아지와 비교 재생, up_walk.gif는 뒤 걷기와 꼬리 움직임이다. references/user-cat-design.png는 첨부 참고, design-tail-generated.png는 GPT 원본, prompt.txt와 validation.json은 요청/검사 기록이다.
