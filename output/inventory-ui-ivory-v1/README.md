# 인벤토리 UI · 아이보리 v1

- 신규 UI: `web/js/components/inventory/InventoryUI.js`, `web/css/modules/inventory-ui.css`
- 미리보기: `web/inventory-preview.html` (웹 서버로 열기)
- 아이보리 패널, 세이지 선택 표시, 파스텔 SVG 아이콘, 분류/검색/선택 상세/수량/사용 버튼.
- 모바일은 목록 아래 상세 패널로 이어지며 스크롤한다. 네이티브 dialog의 Escape/초점 관리 사용.
- 예시 물건 8종은 디자인 확인용이다. 게임 보유품/아이템 효과/저장/기존 실행본에 적용하지 않았다. 기존 폐기 인벤토리 화면은 복원하지 않았다.
- 연결 API: new InventoryUI(container, { items, onAction, onClose }); open(), close(), setItems(items). 호출자는 표시 가능한 설명과 실제 사용 처리를 전달한다.
- 검증: `node scratch/check-inventory-ui.cjs` 통과. 분류, 검색 빈 결과, 선택, 보관 물건 버튼 비활성, 예시 액션, Escape, 재열기, 1280×900/390×844/844×390 경계 및 가로 넘침 확인. 브라우저 오류 없음.
- preview.png 및 모바일/가로 preview PNG는 실제 브라우저 렌더. 디자인 확정/게임 반영은 별도.

## 후속 수정 — 분류 없는 30개 가방
- 분류 탭/상세 분류 배지를 제거했다. 전체 물건을 한 목록으로 표시한다.
- 같은 종류도 수량 하나마다 한 칸을 차지하며 총 30개다. 예시 보유품은 19개, 빈칸은 11개다.
- 상단은 현재 개수 / 30개. 검색 시에도 전체 보유량 표시는 유지한다.
- setItems는 30개 초과나 잘못된 수량을 거부하고 기존 상태를 보존한다. addItem은 합계 30개까지 허용하고 31번째는 false를 반환한다. 생성 시 잘못된 보유품은 RangeError로 거부한다.
- 브라우저 검증: 30개 허용/31개 차단/초과 교체 시 기존 보유품 유지, 분류 없음, 검색/선택/닫기, 모바일/가로 화면 통과. preview PNG 갱신.
- 디자인 미리보기 범위이며 실제 게임 및 기존 실행본 연결은 아직 하지 않았다.

## 상점 이미지 공용 사용
- 새 인벤토리의 목록/상세 모두 상점 VivianCatalogView와 같은 itemIconHtml을 사용한다.
- 예시 물건도 실제 상점 이미지가 있는 꿀 쿠키/에너지 드링크/봉인된 찌라시/별가루/꽃잎차/달가루/포포리 빵/꿀 사탕으로 변경했다.
- PNG, SVG, 공용 아틀라스 이미지 디코딩/로딩과 실제 렌더를 확인했다. 종류 구분 없는 30개 제한과 삭제한 네 문구를 유지한다.
