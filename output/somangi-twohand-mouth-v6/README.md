# 소망이 양손 먹기·입 모션

P1 (Major) · ✅ 제작·손 접촉·입 동작 검사 / ⏳ 사용자 최종 시각 검수

사용자 요청에 따라 한 손 먹기를 양손 먹기로 바꾸고, 먹을 때 입이 열렸다 닫히도록 표현했다. 빵 전체는 100% → 82% → 64% → 46%로 축소되며 양손도 함께 모인다. 음료수는 포함하지 않았다.

- `somangi-eat.glb`: 단일 `Eat_Bread` 3초 클립.
- `somangi-eat.blend`: 편집 원본.
- `eat-twohand-mouth.gif`: 수정 GLB의 정면 반복 미리보기.
- `side-frames/`: 정측면 주요 자세 검수 이미지.

기준은 `../somangi-eat-drink-grip-v3/somangi-bread.blend`다. 원래 외부 표면 정점과 UV는 그대로 보존하며 연결부 안쪽에 마감 면을 추가했다. 기본 서기 Basis는 원래 좌표를 유지한다. 팔은 형태 자체를 축소하지 않고 이동·회전해 작아진 빵의 양쪽 접촉점을 따라간다. 동작 중 겨드랑이 안쪽 연결부에는 별도의 보정이 들어간다. 원래 파일과 게임 파일은 변경하지 않았다.

입 부분은 원래 미소 잉크를 피부색으로 정리한 뒤, 얼굴 곡면을 따라 움직이는 별도 검은 입 표면을 붙였다. 먹는 순간에는 타원으로 열리고, 씹는 구간에는 작게 여닫은 뒤 미소로 돌아간다. 눈의 검은 재질과 머리·몸통·다리의 기본 형태는 유지한다.

## 검증과 재생

`validation.json`: 181개 시점에서 양손 접촉 기준점과 빵 사이 최대 오차 약 0.00303 모델 단위(캐릭터 키 약 1.95 기준 약 0.16%)를 확인했다. 원래 표면 정점·UV의 휴지 좌표 차이는 0이며 추가한 안쪽 마감 면은 휴지 자세에서 원래 외피 밖으로 돌출하지 않는다. 입 표면 높이는 약 0.038~0.080으로 변하고 마지막에 닫힌다. 모든 자기 충돌을 검증한 결과는 아니며 정면·측면 렌더도 별도로 확인한다.

캐릭터·입의 모프 트랙과 빵의 transform 트랙을 함께 재생해야 한다. GIF 반복 시 빵 크기가 처음으로 돌아가는 것은 미리보기 루프다. 1회 소비 동작은 비반복 재생한다.
