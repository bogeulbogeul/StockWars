# 잡화점 창 아래 패널·하단 몰딩 접촉 v10

사용자 요청으로 양쪽 진열창 아래 목재 패널의 하단을 크림색 하단 몰딩에 연결했다. v9 지붕과 창문·창턱·패널 내부 장식·다른 시설 요소는 유지한다.

- 패널 윗면과 내부 장식 위치를 유지하고 하단 정점만 연장했다.
- 종전 하단 Z=0.165에서 0.100까지 내려 둥글게 마감된 몰딩 안쪽에 맞물리게 했다. 앞쪽 곡면에서도 틈이 보이지 않도록 실제 몰딩 표면과 접촉을 검사한다.
- `front-right.png`는 실제 전체 렌더, `window-panel-detail.png`와 `panels-front.png`는 실제 접촉부 확대 렌더다.
- 전달 모델은 `VivianStore-clean.glb`, 편집 원본은 `VivianStore-panel-contact.blend`다.
- `verify.py`는 패널 두 개 이외 메시의 월드 정점 해시가 v9와 같은지 검사하고, 하단 몰딩에 광선을 쏴 실제 표면과 패널이 맞물리는 깊이를 측정한다. GLB 재로딩 검사 결과도 `validation.json`에 기록한다.
