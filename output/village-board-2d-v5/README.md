# 에셋 형태 기준 2D 게시판 v5

NoticeBoard-clean.glb 제작 렌더 front.png를 기준으로 곡선 머리판·새싹 메달·양옆 둥근 기둥/머리 장식·돌 받침·하단 가로대·크기가 다른 종이 6장의 배치를 SVG로 재현했다. 큰 사각 제목판은 없다. 실제 내용 3개는 왼쪽 위/가운데 위/가운데 아래 종이에 연결하고 다른 3장은 원본의 빈 종이를 유지한다.

2D SVG와 HTML 버튼 사용. 실제 마을 GLB·배치·충돌 및 기존 근접 상호작용 코드는 변경하지 않았다. 공고 선택·확대·확인·복귀·Esc·모바일 가로 넘침 검사 및 SVG decode 통과. 실제 데스크톱/모바일 렌더 확인. 웹과 기존 실행본 resources/web 반영. 사용자 최종 시각/플레이 검수는 별도다.
