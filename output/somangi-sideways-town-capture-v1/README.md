# 실제 마을 외벽 통로 촬영

사용자 요청: 마을 건물 사이의 좁은 통로에서 옆걸음 진입과 일반 걷기 복귀 확인.

## 현재 배치에서의 제한

실제9개 건물의 충돌 영역과 통과 가능한 마을 위치를 검사했다. 서로 다른 두 건물이 양쪽을 막아 옆걸음 조건이 되는 통로는 발견되지 않았다. `passage-search.json`에 건물별 실제 충돌 외곽과 탐색 결과를 보존했다. 건물 배치를 옮기거나 임시 통로를 만들어 실제 기존 배치처럼 보여주지 않았다.

대신 기존 **우디 가구점 외벽과 마을 숲 경계 사이**의 실제 좁은 통로를 촬영했다. 이 위치는 두 건물 사이가 아니며 사용자에게도 이 차이를 알린다.

## 실제 게임 촬영

- 실제 `TownModelScene`, 기존 건물·나무·지면·카메라·충돌과 마을 이동 컨트롤을 사용했다. 게임 소스·모델·배치는 변경하지 않았다.
- X=562, 지면Z=3855→약4487에서 통과했다. `capture.json`에 실제28프레임 위치·동작·합법 판정을 기록했다.
- 자동 전환 결과는 `walk → sideways → walk`, 모든 촬영 위치가 기존 충돌 판정을 통과했고 실행 오류는 없다. 옆걸음 상태나 몸 방향을 강제로 지정하지 않았다.
- 촬영 전에 기존 대화 카메라가 일반 추적 카메라로 복귀하도록 기다렸다. 이야기 UI만 촬영 중 숨기고 실제 동작 상태를 왼쪽 위에 표시했다.
- `actual-town-passage.gif`: 30fps 촬영 원속도. `actual-town-passage-half-speed.gif`: 전환 확인용0.5배속. 두 영상 모두 첫/마지막 프레임은350/500ms 추가 유지한다.
- `three-phases.png`: 일반 걷기·옆걸음·일반 걷기 복귀의 실제 세 시점.

재현 도구: `scratch/find-town-sideways-passage.cjs`, `scratch/capture-town-sideways.cjs`, `../somangi-sideways-game-capture-v1/package.py`.
