## 산식

`INITIAL_STOCKS`의 각 기업 초기 가격을 고정 기준가격으로 사용한다. **지수 = 1,000 × 평균(현재가격 ÷ 기준가격)**이다. 따라서 기준가격 상태는 1,000pt, 16개 중 한 기업만 10% 오르면 1,006.25pt다. 절대 주가·시가총액과 무관하게 각 기업의 기준가격 대비 수익률이 1/16씩 기여한다. 자동 종목 교체·거래일별 재조정·배당 재투자·가격 조작은 추가하지 않는다.

직전 비교지수도 같은 기준가격과 `prevPrice`를 사용해 계산한다. 표시 등락률은 반올림하지 않은 현재/직전 지수 비율에서 계산하고, 포인트는 소수점 둘째 자리로 표시한다. 새 게임·앱 열기·주식 보유 여부로 기준을 재설정하지 않는다. 구성 기업의 시세가 누락/비정상이면 나머지 기업만으로 비중을 바꾸지 않고 시세 준비 중으로 표시한다.

일반 게임은 기존 시장 시세 갱신을 따라 표시한다. 전시는 기존 고정 시세에서 계산하므로 1,000pt이며, 등락률은 해당 데이터의 `prevPrice` 대비다. 전시·일반 계좌/보유·스토리 저장에는 지수 열람으로 인한 변경이 없다. 이전 주식 UI 적용 기록의 새싹 성장지수 ‘구성 준비 중’보다 이번 사용자 승인과 적용을 우선한다.

## 검증

`node --test web/tests/growthIndex.test.mjs`: 4개 통과. 정확한 16개 구성·위험도 분포·기준 1,000pt·동일 비율 상승의 동일 기여·비편입 종목 무영향·직전 지수 대비 등락률·누락/잘못된 시세·입력 불변을 검사했다.

`scratch/check-growth-index.cjs`를 웹과 `electron-app/dist/win-unpacked/resources/web` 양쪽에 실행했다. 1,000→1,006.25pt 실시간 UI 갱신·기존 리프 산식 일치·현금/보유 무변경·모바일 표시·전시 고정 시세와 저장 불변·JavaScript 오류 없음을 확인했다. `*-checks.json`과 `*-growth.png`·`*-mobile.png`는 강제 기준 시세를 사용하는 검증 결과다. 실제 플레이 시 지수는 당시 시세에 따라 달라진다.

`synced-files.txt`의 5개 게임 파일을 기존 실행본에 반영하고 SHA256 일치를 확인했다. 설치 프로그램 재빌드나 사용자 최종 플레이 검수 완료를 뜻하지 않는다.
