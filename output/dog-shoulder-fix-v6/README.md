# 사선 걷기 B 어깨 연결 수정 v6

한쪽 어깨에서 앞뒤 두 팔이 갈라지던 오류를 내장 image_gen으로 수정했다. 가까운 어깨에는 앞으로 흔드는 팔 하나만 연결하고, 먼쪽 팔은 반대편 어깨에서 몸통 뒤로 이어져 대부분 가려지도록 그렸다. 먼쪽 손 끝만 화면 오른쪽 몸통 가장자리 아래에 보인다. 원본·프롬프트는 `generation.json`, `raw/shoulder.png`다.

sprite-gen의 크로마 제거·연결 성분 추출·균일 배율 배치 후 기존279색 팔레트로 recolor 베이크했다. 사선 걷기 B 한 그림만 교체했으며 다른18논리 프레임은 v5의 PNG 바이트 그대로다. 사용자 지정 운반 순서, 얼굴 전용 초상화, 중립, A자세, 3그림·160ms는 유지했다. 모든 비투명 RGB의 공통 팔레트 포함을 검사했다.

`shoulder-comparison.png`는 왼쪽 수정 전 / 오른쪽 수정 후, `preview.html`은 재생 비교다. 정적 어깨 연결과 실루엣은 확인했으나 실시간 모션 연속성 최종 통과나 게임 적용을 의미하지 않는다. 재조합은 `prepare.py` → recolor → `publish.py` 순서다. 이전 제작 이력은 `../dog-carry-order-v5/` 이하를 따른다.
