# 봉봉 소망이 기반 이미지 시안 맞춤 — v5 · 2026-10-25

P1 (Major) · ✅ 머리장식 보정·몸체 정점 보존 / ⏳ 사용자 최종 외형 검수.

사용자가 지정한 [소망이 기반 이미지 시안](../bongbong-somangi-base-v1/front.png)에 맞춰 머리장식만 수정했다. v4의 넓게 벌어진 큰 꽃잎을 줄이고, 뒤쪽의 둥근 중앙 꽃잎 하나와 그 앞을 모아 감싸는 작은 좌우 꽃잎 두 개로 정리했다. 꽃잎 하단을 볼록하게 하고 끝은 부드럽게 좁혔다. 내부 연결 코어는 작게 뒤로 넣어 정면에 별도 연결판이 보이지 않게 했다. 단일 곡면 메시와 Head 본 연결을 유지한다.

실제 GLB 재수입 휴지 자세 렌더로 확인한다. 이미지 시안은 정면 외형 참고이며 측면은 이번 입체 모델의 검수 대상이다. 몸체 정점 변화 0·소망이 원본 해시 유지. 몸 색·얼굴·걷기는 유지하고 앞치마·새 의상을 추가하지 않았다. 이전 버전·게임·저장은 변경하지 않았다. 사용자 최종 외형 채택과 게임 적용은 별도다.
