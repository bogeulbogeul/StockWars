# 소망이 기반 모아 v1 — 2026-10-25

**P1 (Major) · ✅ 3D 제작·GLB 재수입 3방향 렌더 / ⏳ 사용자 외형 검수.**

사용자 요청에 따라 소망이의 색을 크림색으로 바꾸고 머리에 올리브색 잎 한 장과 짧은 줄기를 추가했다. 후속 요청으로 초록색 조끼를 추가했다. 책·새 표정은 추가하지 않았다.

## 색 통일 후속

사용자 요청으로 머리·팔 텍스처에 남은 기존 색 편차를 제거했다. 피부 텍스처와 몸통·다리 단색 재질은 동일한 sRGB `#FFDBA3`를 사용한다. 검은 얼굴 잉크·경계 픽셀과 잎은 유지한다. `moa.blend`, `moa.glb`, 3방향 렌더를 갱신했다. GLB 재수입 후 부위별 표면 샘플의 기본색 중앙값이 동일함을 `colour-check.json`으로 확인했다. 입체 조명에 의한 밝고 어두운 면은 남는다. ✅ 색 통일·색상값 검사·3방향 렌더 확인 / ⏳ 사용자 외형 검수.

## 잎 주름 후속

사용자 요청으로 잎 앞뒤에 중앙 잎맥 홈과 양옆 세 쌍의 얕은 주름을 실제 메시로 조각했다. 잎 외곽·올리브색·줄기·본 연결과 몸체는 유지했다. 원본과 GLB 및 3방향 렌더를 갱신했고, GLB 재수입 확대 `leaf-close.png`에서 부드러운 홈을 확인했다. ✅ 모델 수정·확대 렌더 확인 / ⏳ 사용자 외형 검수. 게임 미적용 상태 유지.

## 잎 본·기분 모션 후속

`Head > Leaf.Base > Leaf.Tip` 두 전용 본과 연속 웨이트를 추가했다. 줄기 아래는 머리에 고정하고 위쪽부터 부드럽게 기울인다. 기존 몸체 정점·걷기 트랙을 유지한다.

- 평온 `Moa_Leaf_Calm`: 2.4초 작은 흔들림.
- 기쁨 `Moa_Leaf_Happy`: 1.2초 경쾌한 흔들림.
- 슬픔 `Moa_Leaf_Sad`: 아래로 숙인 2.4초 미세 흔들림.
- 호기심 `Moa_Leaf_Curious`: 옆으로 기울인 2초 흔들림.
- 놀람 `Moa_Leaf_Surprised`: 세운 자세의 1초 떨림.

`leaf-moods.json`에 클립과 반복 시간을 기록했다. GLB의 기분 클립은 잎 두 본만, 걷기 클립은 기존 몸 본만 제어한다 (`leaf-track-check.json`). 런타임에서는 몸 걷기에 기분 클립을 겹쳐 재생하고 전환 시 크로스페이드한다. 실제 게임 기분 상태 연결은 미적용이다. `leaf-motion-check.json`은 재수입 GLB의 반복 시작·끝 정점 일치와 실제 변형을 검사한다. `leaf-happy.gif`는 기쁨 모션 미리보기다.

✅ 본·5종 클립 제작·GLB 재수입 검사 / ⏳ 사용자 동작 검수·게임 연결.

## 초록색 조끼 후속

앞이 열린 짧은 초록색 조끼를 현재 몸체 표면에 맞춰 추가했다. 둥근 두께 마감과 팔 구멍을 만들고 기존 Body 본에 연결했다. 원본 몸체 정점·색·잎 본·기분 클립·걷기를 유지하며 Blender/GLB와 앞·옆·뒤 렌더를 갱신했다. `vest.py`가 제작을 담당한다.

✅ 조끼 모델 제작·3방향 및 걷기 반대 접지 자세 4장 렌더 확인 / ⏳ 사용자 외형 검수·겨드랑이 내부 접촉 보정. 31프레임 자동 표면 검사는 안쪽 겹침 표본을 검출했다 (`vest-motion-check.json`). 전 동작 무관통 검증 통과로 기록하지 않는다. 게임 미적용 상태를 유지한다.

- 원본: `../somangi-game-v1/somangi-walk.blend` (v43 외형·v6 얼굴 기반).
- 외형 참고: `../anna-tpose-v2/front.png`의 크림색·올리브색 잎. 이번 요청의 단순 구성 우선.
- 소망이 원본 몸체 정점 좌표 변화 0. 얼굴·체형·본·기존 걷기 트랙 유지.
- 잎과 줄기는 기존 Head 본에 연결했다. 몸통의 단색 재질과 얼굴의 텍스처를 함께 변경했다.
- `moa.blend`: 편집 원본. `moa.glb`: 기본 미소·기존 걷기를 포함하는 전달 모델.
- `front.png`, `side.png`, `back.png`: 내보낸 GLB를 다시 불러온 실제 모델 렌더.
