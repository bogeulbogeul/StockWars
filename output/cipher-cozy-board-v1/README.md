# 사이퍼지수 둥근 전광판 v1

도톰한 아이보리 외곽과 파란 안쪽 프레임을 Blender로 제작했습니다.

- `Cipher-cozy-index-board.blend/.glb`: 편집 원본/게임용 테두리 모델.
- `frame-preview.png`: 테두리 렌더. 화면 내용은 미포함입니다.
- `game-board.png`: 실제 사이퍼지수·등락률·그래프를 연결한 게임 화면.
- 제작 스크립트와 `exterior_geometry.py`: 재제작용.

크기 4.84 × 2.03, 화면 영역 4.40 × 1.60. 게임에서 100배로 설치합니다.
현재 지수와 그래프는 기존 Canvas 화면을 별도로 연결하므로 정적 이미지로 굽지 않습니다.
게임과 실행본에 설치하고 시장 값 갱신 및 로비 회귀 검증을 통과했습니다.
