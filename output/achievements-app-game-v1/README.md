# 업적 앱 2D UI 게임 적용 v1

사용자 자율 진행 요청으로 파스텔 금색 배지 디자인을 만들고 현행 업적 앱에 적용했다. 목록/전체달성률·전체/달성/진행 중 필터·상세 배지/조건/진행도를 제공하고 실제 기록 변경을500ms마다 읽는다. 상단 홈·P 토글·launcher 숨김을 유지한다.

## 실제 판정과 보존

전시8개: 입주 서명·계좌 개설·투자 자격증·첫 매수·포장 완료·씨앗 심기·다이어리 기록·첫날 취침의 기존 flags를 읽는다. 전시의 기존 SessionStorage/재시작 정책을 유지하며 세션이 초기화되면 해당 업적도 실제 진행에 맞춰 초기화된다.

일반6개: 플레이어 레벨5/10, 분석력2/3, 숙련도 지급된 서로 다른 사건 정답1/10개. 기존 ItemEngine.playerLevel()/analysisProgress().totalCorrect를 읽는다. 저장된 성장/정답 이력에서 다시 판정하므로 앱 재진입·재실행에도 실제 기록이 반영된다. 퀴즈 열람이나 오답/숙련도0 이력을 정답으로 세지 않는다.

보상·돈·경험치·칭호·의뢰를 생성/지급/장착하지 않고 구형 UI도 복원하지 않는다. 기존 상태를 수정하거나 예시 업적을 추가하지 않는다. 별도 달성 시각/수령 기록을 꾸미지 않는다.

## 적용 및 검증

synced-files.txt의 웹/기존 실행본 파일 해시가 일치한다. 설치 프로그램 재빌드·서버 배포는 하지 않았다.

phoneAchievements.test.mjs: 전시3/8→4/8 실제 flag 반영·state 불변·일반 단계/정답 기록·부분 진행도 확인.
check-phone-achievements.cjs: 웹/기존 실행본에서 일반 플레이어 레벨/분석력 기록·전시3/8→4/8·필터·상세·자동 갱신·스토리 state 불변·모바일·상단 홈 복귀·페이지 오류0건 확인. PNG의 달성 상태는 격리 브라우저 검증값이다.

전체 회귀: phoneMap/phoneAchievements/phoneTasks/phoneProfile/keyBindings/settings/exhibition/analysisFiveLevels 합계28개 통과. check-phone-all-current.cjs는8개 앱 PC/모바일 상단 홈 복귀와 홈 프레임 폭 복원/잔여 앱 DOM 없음까지 검사한다. 사용자 최종 시각/전체 플레이 검수는 별도다.
