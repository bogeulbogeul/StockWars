# 안나 출입 통로 확보 v3

서랍장 중심을 좌우 ±1.30에서 ±2.15로 벌리고 데스크·소품·방문객 스툴/소망이를 함께 앞쪽으로 .60 옮겼다. 의자 옆 통로는 1.305, 서랍장 앞과 데스크 뒤 사이 가로 통로는 1.12다. 안나는 최신 짧은 조끼 v5를 유지한다.

✅ 배치 수정·양쪽 우회 경로 정적 간격 검사

⏳ 의자에서 일어나 옆 통로로 내려오는 전환·게임 충돌/이동 연결

걷기 너비 .86802의 절반에 .05 여유를 더한 반경 .4841의 원을 사용했다. 의자 옆에서 데스크 바깥으로 나오는 좌우 경로를 .01 간격으로 샘플링하여 가구의 실제 월드 바운딩 박스와 겹치지 않는지 검사했다. 이는 게임 경로 탐색이나 모든 모션의 메시 충돌을 검증한 것이 아니다. 의자 중심에서 시작하는 일어서기/하차 동작은 검사 범위에서 제외한다. 단위는 임시 모델링 단위다.

- `Office-walkway-preview.blend`: 최신 가구/캐릭터 조합
- `room-preview.png`: 수정 배치 미리보기
- `walkway-validation.json`: 경로·실측 가구 경계·검사 결과
- `adjust_walkway.py`: 재현

이전 가구 원본과 게임은 변경하지 않았다.
