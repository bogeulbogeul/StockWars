# 홈 화면 8개 앱 표시·고유 색상 v2 — 2026-10-25

사용자 피드백으로 주식 아이콘을 홈 화면에서 항상 표시한다. 기존에는 전시 투자 자격증 전 아이콘 자체를 숨겨 7개 앱만 보였다. 이제 8개 위치를 유지하고 자격증 전에는 주식 아이콘에 평면 잠금 배지를 표시한다. 누르면 자격증 안내를 제공하고, 자격증 후에는 기존 주식 앱을 연다. 주식 사용 자격 조건·휴대폰 수령 전 접근 제한·계좌/경제/저장은 유지한다. 사용자 이번 요청은 이전의 주식 아이콘 숨김 정책에 한해 우선한다.

주식 연두·소식 파랑·업적 노랑·메신저 살구·할 일 보라·내 정보 분홍·지도 민트·설정 회색의 서로 다른 8개 배경색을 사용한다. 실제 페이지 전환이 없던 하단 점 2개는 DOM/CSS에서 제거했다. 새 스크롤 페이지는 만들지 않았으며 기존 홈 복귀 막대는 유지한다. Blender·이미지 생성 없이 HTML/CSS/SVG를 수정했다.

`scratch/check-phone-home.cjs`로 양쪽 게임 리소스의 앱 8개/순서, 실제 배경색 8종, 점 요소 없음, 주식 아이콘 표시·잠금 안내·자격 전 진입 차단/자격 후 진입, 기존 열기·닫기·P·포커스·전시 첫 확인 진행과 세 화면 크기를 검사한다. 실제 렌더/결과는 `web-*.png`·`desktop-*.png`·`*-checks.json`을 따른다. `synced-files.txt`의 4개 파일은 웹/실행본 해시가 일치하며 설치 프로그램 재빌드는 하지 않았다.
