# 소망이 검은 눈 재질 보정

P1 (Major) · ✅ 제작·동일 조명 비교 / ⏳ 사용자 시각 검수

기준: `../somangi-bench-down-v1/somangi-bench-down.blend`. 최근 제작 모델의 눈이 따뜻한 조명에서 갈색으로 보이는 현상을 재현했다. 기존 텍스처의 눈·입 검은 영역이 적용된 면에만 별도 재질을 지정해 Metallic=0, Roughness=1, Specular IOR Level=0으로 설정했다. 눈과 입은 동일한 잉크 영역 판별을 사용한다. 기본색 텍스처, UV, 정점·면 구성, 본·웨이트, 몸체 재질을 유지한다. 원본 파일과 게임 파일은 변경하지 않았다. 보류된 앉기 작업을 게임에 적용하지 않았다.

`somangi-black-eyes.glb`와 `.blend`가 수정본이다. 기존 모션을 포함하며 걷기는 원본 GLB 트랙을 다시 넣어 보존했다. 재질 분리에 따라 GLB에는 두 재질 프리미티브가 있으나 Blender의 몸체 메시 오브젝트는 하나다.

`before-warm.png`와 `after-warm.png`는 같은 따뜻한 조명, `before-neutral.png`와 `after-neutral.png`는 같은 중립 조명에서 렌더링했다. 따뜻한 조명에서 몸 색이 따뜻하게 보이는 것은 유지하고 검은 잉크의 색 반사만 줄였다. 형상·UV 해시와 재질 지정 면 수는 `validation.json`에 기록한다. 내보낸 GLB의 텍스처 바이너리 해시 일치와 기존 클립 이름 보존도 확인했다.

## 걷는 동안 눈 색 확인

`walk-black-eyes.gif`는 수정 GLB의 원래 `Walk_InPlace` 클립(0.75초)을 정면·사선으로 재생한 따뜻한 조명 미리보기다. 방향별 18프레임, 총 36장에 대해 양쪽 눈 내부를 검사했다. 72개 눈 영역의 중앙 RGB값은 모든 채널이 0~2/255 범위로 검게 유지됐다. 경계의 안티앨리어싱 픽셀은 제외했다. 검사 결과는 `walk-eye-validation.json`, 실제 렌더 설정은 `walk-render.json`에 기록했다. 이 검사는 해당 조명·렌더러의 재생 결과이며 임의의 외부 렌더러까지 보장하는 검사는 아니다. 모델이나 기존 모션을 추가 수정하지 않았다.
