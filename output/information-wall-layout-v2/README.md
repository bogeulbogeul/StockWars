# 지도 거치대/게시판 배치 정정 v2

지도 거치대를 왼쪽 벽 몰딩보다 실내 쪽으로 이동해 뒷면과 몰딩 사이 간격을 확보했다. 게시판은 왼쪽 서랍장 중심 x=-2.15 위의 뒤벽으로 옮겼고, 화분/서류와 겹치지 않도록 .82배로 조정했다. 지도 면은 계속 비워둔다.

✅ 배치 수정·경계 확인 / ⏳ 사용자 검수·게임 적용

- `Office-wall-layout-v2.blend`: 최신 조합 장면
- `room-preview.png`: 전체 미리보기
- `placement.json`: 거치대/게시판 경계와 몰딩 간격
- `adjust_layout.py`: 재현 스크립트

독립 가구 원본·게임 파일은 변경하지 않았다.
