# 눈 오는 날 지면 적설 v2

P2 · ✅ 웹·기존 실행본 반영·자동 검증 / ⏳ 사용자 최종 시각·플레이 검수

사용자 요청에 따라 `TownGroundSnow.js`를 추가하고 `TownLandscape.js`에서 연결했다. 기존 지면 재질의 셰이더에 눈 색을 합성해 별도 지면 겹침/높이 변화 없이 잔디가 눈으로 덮이게 했다. 월드 좌표 기반의 완만한 패턴으로 얇은 눈부터 늘어나며 바닥 재중앙 이동 때 눈무늬가 미끄러지지 않는다.

눈 시작 시 얇은 덮임(.25, 눈 상태로 장면 생성 시 .35)을 표시하고 적설량은 활성 장면 경과시간당1/90씩1까지 증가한다. 눈이 그치거나 비/맑음으로 바뀌면 경과시간당1/180씩0까지 감소한다. 비활성/탭 복귀의 긴 간격은 최대5초씩 반영해 즉시 가득 쌓이거나 사라지는 것을 방지한다. 적설량은 장면 내 시각 상태이며 저장/현실 누적 적설량이 아니다.

길은 눈 합성 비율을72%, 버스 도로는92% 줄여 색과 차선을 구분되게 남겼다. 기존 지면 곡률·길 마스크·접촉 그림자·충돌/출입은 유지했다. 지붕/나무 적설·발자국·물리적 높이·경제 효과는 추가하지 않았다.

웹과 기존 로컬 실행본에2개 모듈을 동기화했다. `scratch/check-current-exteriors.cjs`의 양쪽 검사에서 적설량 증가·눈 그친 후 점진적 감소·눈 초기화·비/눈 이동·맑음 강수 숨김·동작 줄이기·기존 하늘 전환/시계/로딩/길/입구/작은 화면/JavaScript 오류 검사를 통과했다. `web-weather-snow.png`·`desktop-weather-snow.png`는 충분히 쌓인 상태를 강제한 검사 카메라 실제 렌더다. 설치 프로그램은 재빌드하지 않았다.
