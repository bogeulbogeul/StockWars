# 잡화점 지붕 완성도 보정 v9

사용자 요청으로 잡화점도 집과 같은 제작 방향의 둥근 용마루와 입체 기와로 수정했다. 현행 v8의 넓어진 지붕 경사면·코랄색·목재·차양·꽃 간판·문/창·계단은 유지한다.

- 납작한 용마루를 둥근 돔형 기와 9개와 겹침 띠 10개로 다시 제작했다. 아래 발은 지붕에 맞물리고 앞뒤 끝도 닫힌 실제 메시다.
- 경사면 기와는 잡화점의 넓어진 폭에 맞춘 144개 입체 타일로 제작했다. 지붕 접선 기준 두께 0.043, 라운드 0.011을 적용했다.
- `front-right.png`, `roof-detail.png`, `ridge-detail.png`는 실제 전체·지붕·용마루 렌더다. `VivianStore-clean.glb`는 전달 모델, `VivianStore-crafted-roof.blend`는 편집 원본이다.
- `verify.py`로 원본과 지붕 이외 메시의 월드 정점 해시가 같은지 대조하고, GLB 재로딩·유한 좌표·접지·문 십자살과 새 기와 수를 검사한다. 결과는 `validation.json`에 기록한다.
