# 사이퍼 증권 · 시계와 받침 수정본

- Clock_Hour / Clock_Minute의 원점을 시계 중심으로 정리했습니다.
- 시침과 분침이 시계 방향으로 움직이는 12초 GLB 애니메이션을 포함합니다.
- 모델 애니메이션은 12시간을 12초로 축약한 시연입니다. GIF는 같은 동작을 6초로 재생합니다.
- 실제 게임 시간과의 연동은 아직 하지 않았습니다. 시침 12시간/회전, 분침 1시간/회전으로 별도 제어할 수 있습니다.
- Blender 기준 회전축은 로컬 +Y이며, 기존 바늘 형상을 보존한 중심 원점입니다.
- 현관 받침 두께를 늘려 아래쪽 경계를 지면 z=0에 맞췄습니다.
- 기존 게임 에셋은 교체하지 않았습니다.

`CipherSecurities-clock.blend`: 수정 가능한 원본과 타임라인 애니메이션.
`CipherSecurities-clock.glb`: 외관과 시계 애니메이션.
`clock-motion.gif`: 시계 확대 동작 미리보기.
`front-right.png`: 받침 수정 후 전체 외관.
