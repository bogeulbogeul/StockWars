# 고양이 자연스러운 공통 명암 v7

2026-10-18 사용자 요청: v6의 통일된 색을 유지하며 디자인 시트처럼 자연스러운 명암을 복원한다.

- ✅ 완료: built-in GPT imagegen으로 기존 16자세 모아보기의 조명만 편집. 원 디자인 시트는 외형·명암 참고, v6는 자세·배치 편집 대상이다.
- ✅ 완료: 생성 결과의 명암 정보만 원본 털 영역에 부드럽게 전달했다. 원본 자세·투명도·윤곽선·손 표현·눈·귀·눈썹을 보존했다. 단순 사각 영역 붙이기는 사용하지 않았다.
- ✅ 완료: 같은 위쪽 왼편의 부드러운 광원, 기본 RGB(65,59,62), 그림자(51,45,48), 밝은 면(73,66,70)을 공통 적용. 프레임별 중간 밝기를 정규화하고 부드러운 중간색을 허용했다. 이전 42색 제한 양자화는 적용하지 않아 얼룩을 재도입하지 않았다.
- ✅ 완료: 머리·턱 아래·몸통·팔과 다리 겹침·꼬리의 부드러운 입체감 복원. 알파 동일·털 외 픽셀 동일·시트 좌표 동일·재생 계약 동일 검사 통과.
- ✅ 완료: 걷기 A→중립→B→중립, 운반4그림,160ms GIF 검증. 정지 그림은 해당 걷기 중립과 동일하다.
- ⏳ 대기: 사용자 최종 외형 확인 및 별도 게임 적용. 게임에는 설치하지 않았다.

전달본: sprite-sheet-alpha.png, manifest.json. overview.png는 전체16자세, preview.html은 강아지와 나란히 재생한다. validation.json에는 프레임별 털 평균색과 명암 면적을 기록했다. 같은 색 범위 사용은 그림자 위치가 프레임마다 픽셀 단위로 같다는 뜻은 아니다.

shading-generated.png는 GPT 원본이며 완성 게임 시트가 아니다. build_shading.py가 원본 털에 명암만 전달한 후 최종 시트를 만든다. 원본 v6와 게임 파일은 변경하지 않았다.
