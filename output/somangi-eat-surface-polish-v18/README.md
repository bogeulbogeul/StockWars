# 소망이 먹기 — 어깨·윗몸통 잔주름과 겹친 접합면 정리 v18

P1 (Major) · ✅ 국소 표면 보정·연결 재구성·181시점 검사 / ⏳ 사용자 외형 검수

사용자 확대 이미지의 팔 뿌리와 윗몸통에 남은 잔주름을 다시 정리했다. v17의 팔 평활화에서 제외되었던 팔 뿌리와 절단 링 주변까지 연결해서 다듬고 부피를 보정했다. 윗몸통은 표시된 높이 구간만 국소 보정했다. 머리·얼굴·손 위치·다리·배 아래쪽·후면 골반 곡선은 유지했다.

머리 아래에는 기존 몸통 상부와 v16의 연결면이 겹쳐 있는 문제가 있었다. 중복 연결면과 몸통 상부 캡을 제거하고, 머리 경계와 몸통 절단 경계를 공유 정점으로 연결한 연속 표면으로 재구성했다. 머리를 내리거나 키우지 않았다. 모션 중에도 같은 정점으로 연결되어 틈이 벌어지지 않는다.

## 검사

- 181개 시점에서 편집 대상 외 정점 차이 최대 0.00000012, 머리 차이 최대 0.00000012, 손바닥 차이 최대 0.00000006.
- 머리 경계 390변과 몸통 경계 475변 및 새 연결 링의 열린 변 0.
- 실제 GLB 재수입 후 181개 시점: 재질 경계로 분리된 머리 연결 정점 425쌍의 벌어짐 0.
- 빵과 윗면 장식의 머리 삼각형 교차 0.
- 윗몸통 국소 이동 최대 0.00903 모델 단위. 이번 보정은 접힘 구간의 형상을 다듬으므로 그 구간의 정점까지 원본과 동일하다는 뜻은 아니다.

`surface-validation.json`, `export-junction-validation.json`, `export-validation.json`에 검사 결과를 기록했다. `somangi-eat.glb`는 전달용, `somangi-eat.blend`는 편집용이다. `eat-side-detail.gif`, `eat-opposite-detail.gif`는 최종 GLB를 다시 불러와 촬영한 3초 길이의 접합부 확대 모션이다. 컬러 구역 이미지는 원인 확인용이며 캐릭터 색 변경 시안이 아니다. 게임에는 설치하지 않았고 이전 제작본은 보존했다.
