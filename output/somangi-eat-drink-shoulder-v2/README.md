# 소망이 먹기·마시기 어깨 보정

P1 (Major) · ✅ 기본 메시 보존·자세 보정 / ⏳ 사용자 최종 시각 검수

기준 외형은 `../somangi-black-eyes-v1/somangi-black-eyes.blend`다. 원래 메시의 정점·면·UV는 수정하지 않았으며 Basis 형상 해시가 동일하다. 얼굴 기본 텍스처와 검은 눈 재질을 유지한다. 기존 제작물과 게임 파일은 변경하지 않았다.

## 변경

팔을 올릴 때 목까지 끌려가던 영향을 줄이고, 과한 팔 들기 각도를 낮췄다. 어깨 주변은 부피를 보존하는 변형과 곡면 보정을 함께 사용해 뒤쪽 접힘과 팔 표면의 잔주름을 정리했다. 이 보정은 동작 중에 작동하며 기본 형태는 그대로다. 빵과 컵을 입에 가져가는 위치도 함께 맞췄다.

- `somangi-bread.glb` / `.blend`: 빵 먹기, `Eat_Bread` 3초.
- `somangi-drink.glb` / `.blend`: 음료 마시기, `Drink_Beverage` 3초.
- `bread-side/016.png`, `drink-side/016.png`: 수정 GLB를 직접 불러와 촬영한 정측면 핵심 자세.
- 각 `*-side/` 폴더의 다른 이미지는 시작·올리는 중·유지·내리는 자세 검수용이다.
- `bread-side-motion.gif`, `drink-side-motion.gif`: 수정 GLB를 직접 재생한 정측면 3초 반복 미리보기. 각각 36프레임이며 모델·모션을 추가 수정하지 않았다.

## 재생과 검증

수정된 표면을 GLB 모프 애니메이션으로 저장해 내보내기 후에도 보정 결과가 유지되도록 했다. **각 GLB의 모프/weights 트랙과 소품 트랙을 함께 재생해야 한다.** Blender 파일에는 제작용 본과 자세 애니메이션도 남겨 두었다. 원본 Basis로 돌아갈 때는 표면 모프 값을 모두 0으로 둔다. 기본 서기 형상과 동작용 보정 형상을 구분한다.

`validation.json`에는 각 GLB 181개 시점의 접합부 간격, 바닥 침범, 시작·끝 자세 차이 및 검은 눈 재질 유지 여부를 기록한다. 기본 메시·UV 보존은 원본 해시와 비교한다. 앞선 틈 검사만으로 놓쳤던 어깨 접힘은 실제 정측면 렌더를 별도로 확인한다. 모든 자기 충돌을 자동으로 증명하는 검사는 아니다.
