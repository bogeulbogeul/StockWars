# 은행 노란 기와 모서리 채움 v5

P2 · ✅ 네이티브 기와 수정 / ⏳ 사용자 최종 시각 검수·게임 적용

사용자 정정 “노란벽돌을 채워달라는 거였어”에 따라 v4의 크림색 벽체 채움은 사용하지 않는다. v3 원본에서 현관 기와와 본 지붕 처마 사이에 남은 삼각 영역을 같은 금빛 재질/경사의 맞춤 기와로 양쪽에 채웠다. 기와/바탕판은 단일 솔리드로 합쳤고 하단을 목재 윗선에 맞춰 다듬었다.

기존 메시 정점 해시를 유지했다. `verify.py`는 GLB 재로딩·새 기와 두 개의 닫힌 형상·기존 기와 166장 유지·유한 좌표를 검사한다. 실제 전체/접합부 확대 렌더와 `Bank-clean.glb`, `Bank-filled-gold-corner.blend`를 저장했다. 게임에는 아직 적용하지 않았다.
