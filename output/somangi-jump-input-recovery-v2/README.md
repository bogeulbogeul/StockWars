# 소망이 점프 입력 복구

사용자 보고: 게임 내 점프 기능이 사라짐.

**P1 (Major) · ✅ 수정·웹/기존 실행본 반영·실제 키 입력 검사 / ⏳ 사용자 최종 플레이 검수.**

## 원인과 수정

전시 도착이 끝난 뒤 화면의 키보드 캡처가 Space를 하위 캐릭터 조작에 전달하지 않았다. 실제로 점프 가능한 바닥에서 직접 모션 실행은 성공하지만 실제 Space는 기본 자세로 남는 것을 재현했다. `JumpInput.js`에서 전시가 소유한 Space 입력을 현재 마을/실내의 소망이에게 전달하도록 했다. 모아를 따라가는 중에도 플레이어가 직접 조작하는 구간이면 점프할 수 있다.

별도로 `canJumpAt` 훅이 없는 플레이어 어댑터에서는 누락을 불허로 간주하던 조건을 수정했다. 훅이 있으면 기존 머리 위 여유 판정을 사용하고, 없으면 기존 지면 `canStand`를 사용한다. 명시적 충돌 불허를 무시하지 않는다.

착석·스크립트 강제 이동·일반 장면 전환·미니게임·입력창·버튼/링크·휴대폰/모달의 입력 차단은 유지한다. 모델·본·정점·기존 점프 높이20/0.55초·걷기·착석 자세·저장은 변경하지 않는다.

## 검증

- `scratch/check-jump-input-recovery.cjs`: 실제 Space로 도착 이후 마을, 안내 동행 구간, 집·잡화점·안내소·은행·증권사 점프 재생을 확인한다. 입력창·바쁜 장면·자동 이동·착석·머리 위 여유 불허와 지면 훅 대체 판정도 검사한다. 웹과 기존 실행본 각각 확인.
- `web/tests/somangiJump.test.mjs`와 `web/tests/jumpCollision.test.mjs`: 최고점·정확한 착지·중복 시작·지지면·머리 위 장애물·공중 벽 통과 방지 등7개 통과.

기존 실행본 관련 모듈을 갱신했으며 설치 프로그램 재빌드는 하지 않았다.
