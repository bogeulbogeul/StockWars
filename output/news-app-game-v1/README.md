사용자가 `output/news-app-design-v1/preview.png`의 목록/기사 디자인을 채택해 게임 적용을 요청했다. `components/phone/news/`의 조정 모듈·템플릿과 `phone-news.css`로 구현하고 기존 `StockNews.js`의 진입/정리 계약을 유지했다. HTML/CSS/인라인 SVG를 사용하며 Blender·이미지 생성은 사용하지 않았다.

- 목록: 큰 제목·업종 공통 컬러 아이콘·파스텔 카드·요약·건수, 회사명/ID/제목 검색, 8업종 가로 스크롤 필터와 목록 세로 스크롤.
- 기사: 24px 제목·16px 본문·출처/기존 시각 문구·전체 원문·별도 기사 스크롤·고정 관련 종목 버튼. ‘뉴스 목록’으로 돌아가면 검색/필터/목록 위치를 유지하고 읽던 카드로 포커스를 돌려준다.
- 주식 기업 정보의 관련 뉴스는 종목 필터를 유지해 소식 앱으로 연결된다. 필터 해제로 전체 소식을 볼 수 있다. 기사에서 주식 상세로 복귀하며 투자 자격증 조건은 유지한다.
- 일반 게임은 기존 뉴스 소스의 발표/공시와 갱신을 따른다. 전시에서도 기존 288개 원고를 읽기 전용으로 제공한다. 가상의 새 날짜·주가 영향·자동 호재/악재 표시·새 거래/보상을 추가하지 않았다.

문자열은 이스케이프해 원문을 HTML로 실행하지 않는다. 새 기사 갱신 및 동일 기사 본문 갱신을 반영하고, 단순 시세 알림은 읽는 화면을 다시 만들지 않는다. 닫기/다른 앱/홈 복귀 시 시장 구독과 이벤트를 정리한다. 기존 원고·계좌·전시 스토리 저장은 변경하지 않는다.
