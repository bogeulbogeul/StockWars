# 잡화점 창 아래 장식 몰딩 밀착·통합 v11

사용자가 지적한 패널 앞에서 떠 있던 사각 장식 테두리를 수정했다. v10의 하단 몰딩 접촉과 v9 지붕을 유지한다.

- 종전의 가는 곡선 막대 테두리를 제거했다. 기존 테두리 중심 Y=-0.999가 패널 앞면 Y=-0.976보다 떨어져 있던 상태였다.
- 닫힌 둥근 사각 몰딩을 새로 만들고, 뒤쪽을 패널 내부로 넣었다. 안쪽 면의 뒤쪽도 연장해 패널에 충분히 맞물리도록 했다.
- 테두리·안쪽 면·패널을 실제 메시 합집합으로 통합했다. 양쪽 패널마다 연결 성분 1개, 열린 경계 0개, 비다양체 모서리 0개를 검사한다.
- 장식 이외 메시가 v10과 같은지 월드 정점 해시를 대조하고 GLB를 재로딩한다. 결과는 `validation.json`을 따른다.

`molding-detail.png`, `panel-front.png`는 실제 모델의 사선·정면 확대 렌더이며 `front-right.png`는 전체 모습이다. 전달 모델은 `VivianStore-clean.glb`, 편집 원본은 `VivianStore-integrated-molding.blend`다.
