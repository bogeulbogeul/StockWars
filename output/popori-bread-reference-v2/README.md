# 포포리빵 — 원본 통빵 보정 v2

더 맛있어 보이는 구운 표면 후속은 [v3](../popori-bread-baked-v3/README.md)를 따른다. 이 폴더는 표면 수정 전 이력이다.

2026-10-25 사용자 요청: 앞선 상품에 이어 포포리빵 다듬기.

기준은 `web/assets/items/packing-v1/popori-bread-v2.png`의 단면 없는 길쭉한 주황빛 통빵이다. 과거 잼 단면 이미지와 혼용하지 않았다. 넓고 둥근 한쪽 끝에서 반대쪽 작은 끝으로 좁아지는 윤곽을 연속 메시로 만들었고, 따로 붙인 구형 장식이나 잘린 면은 없다. 원본의 구운 색 변화는 정점 색으로, 윤기는 실제 표면 재질과 조명으로 표현했다. 2D 원본의 흰 하이라이트를 메시 위에 붙이지 않았다.

크림색 종이 트레이는 아래쪽이 좁아지는 얇은 벽·접힘·작게 굴곡진 절단 가장자리·바닥을 포함한다. 원본의 주황 꽃과 갈색 잎 문양을 평평한 인쇄로 별도 제작해 앞면에 적용했다. 인쇄는 GLB에 내장한다. 이전 두꺼운 트레이나 솟아오른 꽃·잎 장식을 사용하지 않는다.

GLB 파일 구조·재수입·유한 정점·퇴화면 0개·내장 인쇄 디코딩을 확인하고 전체/후면/재수입 확대 렌더를 확인한다. 정확한 삼각형 수·경계·해시는 `validation.json`을 따른다. 표면 세부 붓 터치의 완전 복제나 사용자 최종 외형 검수 완료를 의미하지 않는다.

이 개별 수정본은 12종 모음의 기존 포포리빵보다 우선하는 후속 제작본이다. 꿀쿠키·꽃잎 차·사과주스와 나머지 상품은 유지한다. 게임 상점·포장 퍼즐·저장·가격·기존 실행본은 변경하지 않았다. GLB는 상품만 포함하며 `.blend`는 조명·바닥·카메라를 포함한다. 게임 배율·충돌·실제 플레이 검수는 별도다.
