# 전체 앱 공통 홈 버튼 확인

사용자 요청으로 8개 앱의 하단 집 아이콘·홈 버튼 표시와 복귀를 점검했다. 현행 PhoneHomeTemplate의 공통 버튼이 이미 모든 앱 본문 밖에 배치되어 있어 앱별 복제 없이 동일한 버튼을 사용한다. 기존 phone-home-button-v1 적용본을 유지한다.

scratch/check-phone-all-apps-home.cjs: 주식·소식·업적·메신저·할 일·내 정보·지도·설정 각각 1280×900 및 390×844에서 열기, 하단 홈 버튼 표시·뷰포트 안 배치, 클릭 후 홈 화면 복귀를 검증한다. 웹/기존 실행본 결과는 각각 checks.json, 주식/소식 실제 PNG를 따른다. 준비 중인 앱은 기존 본문을 유지한다. 설치 프로그램 재빌드는 하지 않는다.
