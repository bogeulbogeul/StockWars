# 벤치 앉기 v2 — 실제 엉덩이 접촉

v1의 접촉 정점 선택이 다리 연결부를 포함해 몸통 아래의 엉덩이는 떠 보였다. 이번에는 Body 웨이트가 0.95를 넘는 아래 몸통 표면을 좌판 접촉 기준으로 사용한다. 몸을 좌판 위로 옮기고 앉은 높이를 낮췄다. 기준점과 선택 정점은 `seat.json`에 기록한다.

- 앉기용 복사본의 다리 회전 중심과 강체 다리 위치 보정을 조합해 발을 몸 앞에 모았다. 걷기 v3나 원본 메시를 변경하지 않았다. 스케일 변화 없이 다리 아래쪽·발의 실제 메시 길이를 검사한다.
- 연결부를 포함한 모든 다리 표면을 완전 강체로 판정하는 것은 아니다. 몸통과 다리 연결부는 스킨 블렌딩을 유지한다.
- 앉기 전용 복사본의 골반 밑면 277정점을 소폭 보정했다(최대 약 0.022 모델 단위). 좌판 안으로 들어가던 연결부를 정리한 것이며, 다리 아래쪽·발 정점과 기존 걷기/원본 모델은 수정하지 않았다.
- Body 표면을 기준으로 좌판 간격 약 0.001 모델 단위에 맞추고, 표본 프레임의 벤치 침투를 확인한다. 수치만으로 접촉을 판단하지 않고 측면과 사선 이미지를 확인했다.
- 올라앉기·유지·내려오기 4개 클립과 벤치 포함 장면/캐릭터 단독 GLB를 다시 저장했다.

## 파일

- `somangi-bench-scene.glb`: 벤치 포함 수정 장면.
- `somangi-sit-character.glb`: 수정 캐릭터와 앉기 클립.
- `somangi-bench-sit.blend`: 편집본.
- `bench-sit-side.gif`: 수정된 정측면 모션. 검은 눈을 보존한 공통 팔레트와 타임스탬프 기반 디코딩 검사를 사용한다.
- `sit-side.png`, `sit-angle.png`: 실제 엉덩이 접촉 확인.
- `validation.json`: 배 변형·다리 하단 길이·좌판 접촉·표본 프레임 침투·루프·GLB 재수입 검사.
