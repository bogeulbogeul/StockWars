# 소망이 접합면 정리 v42

P2 (Polish) · ✅ 제작 원본 보정·실제 GLB 촬영·수치 검사 / ⏳ 사용자 외형 검수

v41에서 머리 아래에 남은 이전 연결 면 563개를 제거했다. 열린 머리 밑단과 몸통 상부를 389개의 공유 경계로 연결해 겹친 면과 틈을 없앴다. 좁은 연결 구간의 곡면과 법선을 정리했으며, 팔은 어깨부터 손끝까지 단일 본으로 통째로 움직인다. 팔 관절이나 팔 혼합 웨이트를 추가하지 않았다.

머리 원본 9,044점과 양팔의 원래 가시 표면 3,974/4,182점은 좌표 변화 0이다. 접합부 아래 몸통 102,044점도 v41 대비 위치·웨이트 변화 0이다. 몸통 상단 연결 표면은 재구성했으므로 모든 정점이 원본과 같다는 의미는 아니다. 눈·미소 재질, 빵의 크기 감소와 기존 모션 트랙은 유지했다.

`connection.json`: 271개 반 프레임 시점에서 머리-몸통 공유 경계의 열린 변 0. 연결부 삼각형의 최소 면적 비율 0.5614, 최소 법선 내적 0.7228로 면 뒤집힘 없음.

`rigidity.json`: 팔 뿌리를 포함한 양팔의 강체 변환 오차 최대 1.71e-7. 마지막 자세 원위치 오차 1.26e-6.

`contacts.json`: 같은 271개 시점에서 팔 말단-머리, 빵-머리, 빵-고정 몸통 표면 교차 표본 각각 0. 어깨의 의도적인 내부 겹침은 이 검사에서 제외한다.

`appearance.json`, `preserved-torso.json`에 외형 보존 수치를 기록했다. `eat-both-sides.gif`는 최종 GLB를 다시 불러와 촬영한 양쪽 옆모습 36프레임이다. `junction-comparison.png`는 동일 카메라·조명·시점의 수정 전후 확대 비교다.

제작 결과는 이 폴더에만 보존한다. 폐기된 게임 캐릭터 에셋을 복원하거나 게임에 설치하지 않았다.

## 정면·후면 모션 확인

같은 GLB를 변경하지 않고 정면과 후면에서 각각 36프레임 촬영했다. `eat-front-back.gif`에서 팔을 들고 한입 먹은 뒤 내리는 전 과정을 볼 수 있다. 머리·몸통 사이 열린 틈은 보이지 않으나 후면 연결부 아래에 옅은 가로 명암 경계가 남아 보인다. 자연스러운 외형의 최종 채택 검수는 사용자 확인 대기다.
