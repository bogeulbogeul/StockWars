# 먹기 동작·입 표정 통합 v4 — 2026-10-19

팔 분리 수정본 먹기 v3에 입 벌리기·오므리기 표정을 결합했다. 빵을 들어 올리고 고개를 숙이는 기존 동작을 유지하며 먹는 구간에 두 번 입을 크게 벌렸다 오므린다. 앞뒤 구간은 기존 미소를 참고한 곡선 입으로 돌아온다. 표정이 완전히 가려지는 것을 줄이기 위해 먹는 동안 Food 소켓을 최대 0.055 낮췄다. 팔·머리·다리의 기존 회전 키는 유지한다.

- `somangi-eat.glb`: 본 동작·빵·입 모프를 함께 재생하는 단일 3초 `Eat` 클립.
- `somangi-eat.blend`: 편집용 모델과 프리뷰 장면.
- `eat-front.gif`, `eat-side.gif`: 정면·측면 통합 미리보기.
- `mouth-timing.json`: 프레임별 입 벌림·미소 복귀·빵 위치 보정값.
- `validation.json`: 73프레임 몸통/발 고정·팔 길이·어깨 겹침·입 포함 루프·본/모프 채널 및 GLB 재수입 검사.

입은 Head 본에 연결한 표면 메시의 `Mouth_Open`, `Rest_Smile` 모프다. 기존 입 텍스처는 비우고 눈은 유지한다. 입체 구강·음식 소모·게임 회복 효과는 포함하지 않는다. 런타임은 Eat 클립의 본과 모프 채널을 함께 재생해야 한다. 기존 먹기 v3와 걷기·앉기·표정 원본, 게임 파일은 변경하지 않았다.
