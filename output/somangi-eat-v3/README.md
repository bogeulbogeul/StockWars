# 먹기용 팔 분리 수정 v3 — 2026-10-19

사용자 승인 방향에 따라 팔을 별도 둥근 메시로 분리했다. 팔을 들 때 함께 늘어나던 겨드랑이 면을 제거하고, 어깨 끝이 몸통과 겹치도록 만들었다. 걷기 v3의 몸통 단면 크기를 참고해 매끈한 몸통을 재구성했다. 몸통·팔의 메시 구조와 표면은 변경되며 원본과 정점이 동일한 버전이 아니다. 머리·얼굴 텍스처·기존 발 형상은 보존한다.

- `somangi-eat.glb`: 8본, 별도 양팔·몸통·원본 머리/발·빵, 단일 3초 `Eat` 클립.
- `somangi-eat.blend`: 조명·카메라 포함 편집본.
- `eat-side.gif`, `eat-front.gif`: 정측면·정면 재생 프리뷰.
- `eat-rear-angle.png`: 뒤 사선 어깨 연결 확인.
- `validation.json`: 전체 73프레임의 몸통·발 고정, 팔 에지 길이, 어깨 겹침, 루프, GLB 재수입 검사.

양팔은 각 Arm 본에 100%, 새 몸통은 Body 본에 100% 웨이트를 부여했다. v2의 자세별 보정 모프는 제거했다. 양팔 에지 길이 오차는 약 1.2e-7이며 몸통 변형과 루프 오차는 0이다. 어깨 인근 팔 정점 중 몸통 안쪽에 들어가는 정점이 모든 검사 프레임에서 팔마다 최소 167개 존재한다. 이 검사는 겹침의 존재를 확인하며 모든 표면의 접촉 품질을 수학적으로 보증하는 검사는 아니다. 정면·측면 전체 루프와 뒤 사선 주요 자세를 별도로 확인한다.

고정 미소를 사용하며 입 벌림·음식 소모·회복 효과는 없다. 게임에는 설치하지 않았다. 기존 원본·걷기·앉기 파일은 변경하지 않는다. 최종 시각 채택은 별도다.

재생성: Blender로 `build.py` → `render_preview.py` → `validate.py` 실행 후 PIL/numpy Python에서 `make_previews.py` 실행. `structure.py`는 메시 재구성을 담당한다.
