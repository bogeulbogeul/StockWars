# 은행 안내 데스크 v1

완만한 ㄷ자 후속: 참고에 맞춰 양끝 되돌이 길이를 줄이고 안쪽 모서리 곡률을 넓혔다. 전체 깊이 1.12·안쪽 폭 2.60·후면 여유 1.76 임시 모델 단위이며 상판 장식 제거는 유지한다. 아래 깊은 ㄷ자 치수보다 우선한다.

데스크 후속: 사용자 요청으로 상판 위 곡선 난간과 황동 끝장식을 제거했다. 상판·몸체·받침을 뒤쪽이 열린 연속 ㄷ자 형상으로 재제작했다. 배치는 y=.35, 직원 자리 안쪽 폭 2.40·뒤 통로 1.36 임시 모델 단위다. 아래 최초 직선형/장식/이전 배치 기록보다 이 후속을 우선한다.

참고 이미지의 크림색 몸체·곡선 목재 상판·목재 받침·정면 몰딩·양끝 낮은 곡선 난간과 황동 끝장식을 제작했다. 창구 소품과 의자는 별도다.

- `Bank-service-desk.glb`: 독립 데스크, 룸 조합 위치 y=.70 포함.
- `Bank-desk-room-preview.glb`, `Bank-desk-room-preview.blend`: 기존 은행 룸에 배치한 조합.
- `room.png`, `desk-close.png`: 전체/확대 미리보기.
- `build_desk.py`, `manifest.json`: 재현 원본과 임시 치수/검증 기록.
