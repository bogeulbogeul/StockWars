# 타이틀 주식 시뮬레이션 체험 보강 — 2026-10-27

사용자 정정에 따라 광고 편집이 아니라 실제 게임의 ‘주식 시뮬레이션 체험하기’를 수정했다.

## 체험 흐름

1. 별도 가상 자금 5,000잎으로 시작한다. IT·에너지·소비재 바로가기로 업종을 비교하고, 기존 전체 종목·기업 정보·차트를 사용할 수 있다.
2. 원하는 종목과 수량을 직접 정해 매수한다. 실제 체결 전에는 뉴스 진행이 열리지 않는다. 시장가·지정가와 기존 호가/현금/수수료 규칙을 그대로 따른다.
3. ‘다음 뉴스 반영’을 세 번 누른다. 데이터센터 투자 확대→원자재 공급 차질→소비 회복 사건이 각 업종에 서로 다른 가격 영향을 준다. 영향은 플레이어 보유 종목에 맞춰 조작하지 않으며, 일반 실시간 시세 변화도 계속된다. 보유·추가 매수·매도 시점은 직접 선택한다.
4. 실제 매수와 매도를 한 번 이상 체결하고 세 뉴스를 반영하면 결과를 볼 수 있다. 최종 자산·손익/수익률·현금/남은 주식 평가액·체결 횟수를 표시한다. 남은 주식은 강제 매도하지 않고 마지막 시세로 평가한다. 결과 확인 후 시장을 정지하고 주문을 막으며 미체결 주문을 취소한다.
5. 거래 내역 확인, 새 5,000잎 계좌로 재도전, 타이틀 복귀가 가능하다. 화면 위 안내/자산은 유지하고 작은 화면에서는 안내 내부 스크롤을 사용한다.

뉴스는 이 체험 전용으로 작성한 게임 사건이며 실제 뉴스나 실제 주가가 아니다. 수익률이나 교수님의 평가를 보장하는 기능이 아니다. 첫날 이야기의 고정 가격 1주 수업과 별개이며 이야기/일반 계좌에 보상을 보내지 않는다. 기존 무음 정책을 유지한다.
