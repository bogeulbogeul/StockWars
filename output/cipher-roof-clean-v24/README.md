# 증권사 위쪽 지붕 정리 v24

P1 · ✅ 네이티브 지붕 재정리 / ⏳ 사용자 시각 검수·게임 적용

사용자의 위쪽 렌더 지적에 따라 `cipher-pediment-solid-v23/CipherSecurities-solid-pediment.blend`에서 지붕을 다시 제작했다. 중앙 용마루의 뒤쪽 X축 어긋남을 없애 앞 박공 꼭대기와 같은 X로 맞췄다. 정면 박공·시계·로고·문·기둥·계단과 건물 폭/깊이는 유지한다.

중앙 좌우 경사와 측면 모임지붕은 실제 평면의 높이 차로 나눴다. 반복 폴리곤 차집합으로 생기던 지그재그/잘린 조각을 제거하고, 같은 경계로 바탕판과 기와를 잘랐다. 기존 비뚤어진 크림색 측면/후면 반환부는 제거하고 직선 마감으로 교체했다. 중앙 뒤 벽을 새 지붕 폭에 맞춰 다시 만들고, 위로 드러나던 중앙 몸체/앞 벽의 상부를 지붕 안에 맞췄다. 정면·위쪽·교차부·후면을 실제 모델로 렌더했다.

결과는 `CipherSecurities-clock.glb`, `CipherSecurities-clean-roof.blend`다. `verify.py`는 GLB 재로딩·새 지붕 닫힘·유한 좌표·중앙 용마루 정렬·시계/문 노드 보존을 검사한다. 웹/실행본은 교체하지 않았다.
