v15에서 머리 밑과 몸통 사이에 남은 옆면의 틈을 연결면으로 막았다. 머리나 몸통을 이동·확대하거나 기존 표면 정점을 변형하지 않았다. 머리 경계의 기존 정점을 공유하는 연결면을 추가하고, 아래 끝은 몸통 안쪽으로 겹쳐 넣었다. 머리와 연결면의 윗단은 같은 정점을 사용하므로 머리 움직임을 그대로 따른다.
