# 미드나잇 펍 재디자인 v2

P1 · ✅ 채택 시안 기반 3D 에셋 제작 / ⏳ 사용자 최종 시각 검수·게임 적용

사용자 요청 “펍 에셋 이런식으로 변경해줘”에 따라 `approved-reference.png`의 버건디 박공지붕·용마루·현관 박공·격자창·초승달·랜턴·맥주 간판·굴뚝을 네이티브 모델로 반영했다. 원본은 `pub-exterior-clean-v1/Pub-clean.blend`다.

- 기와와 지붕 바탕은 두 박공의 교차선에 맞춰 절단하고 골에 닫힌 마감을 넣었다. 목재 가로보는 처마 뒤로 맞추고 현관 목재와 연결했다.
- 굴뚝은 시안처럼 앞쪽 경사면에서 보이도록 이동했다. 실제 굴뚝 크기로 기와를 잘라 내고 경사진 닫힌 버건디 테두리를 둘렀다.
- 측면을 덮던 두꺼운 목재 띠 대신 개별 앞뒤 기둥을 만들어 크림 벽이 보이게 했다. 기존 양문·유리/손잡이·격자창·랜턴·맥주 간판을 유지하고 초승달 크기/깊이를 새 박공에 맞췄다. 후면 창은 추가하지 않았다.
- 전체/정면/후면/지붕 접합부/굴뚝 확대는 실제 모델 렌더다. `Pub-clean.glb`, `Pub-redesign.blend`가 수정본이며 `verify.py`의 GLB 재로딩·기와/마감 닫힘·구성 수량·유한 좌표·접지 검사를 따른다.

웹·기존 실행본과 실내/저장/시설 기능은 변경하지 않았다. 게임 반영·배율/충돌/로딩 검증은 후속 적용 단계다.
