# 뒤쪽 숲 간격 조정 v5

P2 · ✅ 웹·기존 실행본 반영·자동 검증 / ⏳ 사용자 최종 시각 검수

사용자 요청에 따라 북쪽 나무를5줄/94그루에서3줄/45그루로 줄였다. 같은 줄의 동서 간격을185에서235게임 단위로 넓혔고, 앞줄13·중간15·배경17그루를 배치했다. 중간 줄을 반 칸 엇갈리고 남북 간격을 약210~220으로 두어 나무가 겹친 벽처럼 보이는 정도를 줄이면서 큰 배경 빈틈을 보완했다.

`townBoundaryProps.js`를 웹과 기존 실행본 리소스에 동기화했다. 양옆 v4 배치·건물·게시판·정원·모아·길·플레이 경계·나무 모델/배율은 유지했다. 버스 도착 연출 전용의 먼 배경 숲은 별도이며 이번 수정에서 변경하지 않았다.

`scratch/check-current-exteriors.cjs`를 양쪽 리소스에 실행해 로딩·건물 겹침 없음·길 표본 차단0건·모든 입구 도달·시계·작은 화면·JavaScript 오류 없음 검사를 통과했다. `web-checks.json`·`desktop-checks.json`과 검사 카메라 전경 `web-overview.png`에 결과를 저장했다. 모든 카메라에서 평야가 완전히 가려지는지 또는 사용자 최종 시각 검수가 끝났다는 뜻은 아니다. 설치 프로그램은 재빌드하지 않았다.
