# 이전 소망이 먹는 입 참고

`somangi-eat-reference-v9`의 캐릭터와 빵 모션을 유지하고 입만 수정했다.

참고: `somangi-chew-v1/open.png`, `somangi-eat-v7/eat-front.png`.
최대 벌림은 이전 씹기 모션의 반너비 .067, 반높이 .080인 검은 세로 타원이다. 한입 타이밍에 벌렸다 오므리며, 나머지 구간에는 미소를 표시한다. 얼굴 표면에 투영한 33열·9행 메시로 큰 입 안쪽이 얼굴에 가려지는 현상을 방지한다.

`check_unchanged.py`는 v9와 본체 모프 전체 좌표·UV 해시, 91프레임 빵 변환 행렬, 눈 재질의 동일성을 확인한다. 정면·옆면 GIF는 최종 GLB 재수입 렌더다. 게임에는 설치하지 않았다.
