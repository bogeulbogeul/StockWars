# 스토리 씨앗용 화분 3D v1

2026-10-24 · P1 (Major) · ✅ 모델 제작·GLB 재불러오기·구조 검사 / ⏳ 사용자 외형 검수·게임 배치·손 접촉·심기 연출.

사용자가 채택한 이미지 시안 왼쪽 화분(`reference.png`)을 Blender 메시로 제작했다. 둥근 테라코타색 테두리·아래로 좁아지는 몸체·받침·갈색 흙을 유지한다. 씨앗·새싹·식물은 포함하지 않는다. 이미지 생성물을 3D처럼 표시한 것이 아니라 실제 회전·편집 가능한 메시다.

- `StoryFlowerpot.glb`: 재질을 포함한 배포용 모델. 외부 텍스처 불필요.
- `StoryFlowerpot.blend`: 편집 원본과 렌더용 스튜디오. 조명·바닥·카메라는 GLB에서 제외한다.
- `preview.png`, `top.png`, `side.png`: 실제 제작 모델의 정사영 렌더.
- `scale-comparison.png`: 보존된 소망이 v8의 REST 자세와 같은 바닥에 놓은 제작 크기 비교. 게임 화면이 아니며 삭제된 캐릭터를 복원하지 않았다.
- `build.py`: 재현 스크립트(Blender 5.2 `--background --python`).
- `manifest.json`: 치수·삼각형 수·메시 검사·재불러오기 결과.

## 구조와 크기

`StoryFlowerpot` 루트 아래 `Pot_Hollow_Body`·`Saucer`·`Soil` 3개 메시와 `Plant_Anchor` 빈 기준점이다. 2026-10-24 사용자 후속 요청으로 흙 알갱이를 모두 제거하고 매끈한 평면의 갈색 흙으로 변경했다. 화분·받침·재질·크기는 유지했다. 받침을 포함한 바닥 중앙이 원점이며 glTF는 Y-up이다. 식물 연결점은 glTF `(0, 0.359, 0)`이다.

소망이 신체 높이를 H=1로 맞춘 임시 제작 치수는 폭/깊이 0.404H, 높이 0.399H다. 기준은 `output/somangi-neck-smooth-v8/walk.glb`의 REST `Somangi_Body` 정점 Z 범위(별도 성장 장식 제외), 원본 높이 약 1.899797, 제작 비교 배율 약 0.526372다. 게임 적용 배율·정확한 전시 위치·손 접촉은 미정이다. 비교용 캐릭터는 화분 원본/GLB에 저장하지 않는다.

## 검증 범위

원본 메시의 유한 좌표·비매니폴드 모서리 0개·양의 부피를 검사했다. 내보낸 GLB를 다시 불러와 메시 3개·기준점·전체 치수·바닥 원점을 확인했다. 위/옆/사선 렌더로 외형을 확인했다. 게임 로딩·출입 동선·씨앗 심기·성장 연동·운반 애니메이션은 아직 검증하지 않았다. 게임 코드·배포 에셋·저장은 변경하지 않았다.
