# NPC 그림체 변경

2026-10-16 사용자 요청: 인간형 NPC 캐릭터 시트 3종(비비안·관리소장 박씨·에이전트 K)과 해당 제작 문서를 삭제하고, 동물형 NPC 11명의 그림체를 현재 강아지·고양이에 맞춘다.

기존 개별 동물형 시트의 종·색·성격·안경·귀 피어싱을 유지한다. 샤일록은 나무늘보다. 이전 전체 모음의 악어를 재사용하지 않는다. 의상·신발을 새로 추가하지 않는다.

그림체 참고: `../npc-style-animals/unified-v2/dog/run/frames/down_idle/frame-0.png`, `../npc-style-animals/unified-v2/cat/run/frames/down_idle/frame-0.png`. 큰 머리, 짧은 몸통·팔다리, 둥근 앞발, 또렷한 짙은 윤곽선, 간결한 색면·셀 명암으로 통일한다. 종별 특징은 유지한다.

이번 전달물은 NPC별 외형 시트다. 정면·앞오른쪽 사선·뒤 전신과 정면 UI 얼굴을 포함한 표정 4종을 제공한다. 걷기 애니메이션·게임 런타임 시트 적용 완료를 뜻하지 않는다. 마을 RPG식 탑다운·실내 아이소메트릭 호환 검증은 별도다.
