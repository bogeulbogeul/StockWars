# 에이전트 K v4 · 공통 SD 비율 유지

사용자 보정: K도 다른 NPC들과 같은 비율을 유지해야 한다. 길게 늘린 v3는 미채택이다.

내장 image_gen으로 v2를 편집해 기존 큰 머리·짧은 몸통·팔다리 비율을 유지하고, 가는 눈과 홍채·각진 볼·정리된 턱선으로 날카로운 인상을 다듬었다. 안드레 v5와 기준 검은 고양이를 공통 SD 비율·그림체 참고로 제공했다. 러시안블루 털색과 은색 안경은 유지했다.

생성 결과를 열어 짧은 SD 몸 비율, 전신 3방향·얼굴 표정 4종과 안경을 확인했다. 모음은 `agent-k-sheet-v4.png`를 표시한다. v3의 성인형 비율 지침은 재사용하지 않는다. 게임 모션 연결은 별도다.
