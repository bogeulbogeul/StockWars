# 건물 이동 점검 — 2026-10-25

상태: 전체 걷기 전환 완료 아님. 이번 결과는 확인 기록이며 게임 이동 코드는 변경하지 않았다.

## 범위
현행 외관 9종, 일반 플레이 입장/퇴장 연결, 첫날 스토리 장소 전환, 증권사 내부 연결을 읽었다. 실내가 연결된 집·안내소·잡화점·은행·증권사 5종과 외관만 존재하는 가구점·쉼터·서점·우체국 4종을 구분했다. 미제작 실내를 복원하거나 새로 추가하지 않았다.

## 발견 사항
- 일반 플레이 집: WorldNavigation.enterOffice에서 바로 실내 show. 문 입장 걷기 없음.
- 일반 플레이 안내소/은행: InformationModelEntrance/BankModelEntrance에서 바로 실내 show. 문 입장 걷기 없음.
- 일반 플레이 잡화점/증권사: 외부 문 접근·문 열기·걷기 함수 연결됨.
- 일반 플레이 5개 실내 퇴장: 콜백이 마을을 표시하고 입구 좌표로 직접 복귀시킴. 실내에서 Esc를 누르면 문까지 걷지 않고 퇴장 가능.
- 증권사 트레이닝/모의투자룸: 로비 hide→실내 show, 복귀 시 저장 좌표 직접 복원.
- 첫날 안내소/은행/집/잡화점/증권사 첫 입장에는 외부 걷기 연결됨. 안내소→은행, 은행→집은 모아 선행·플레이어 추종 연결됨.
- 첫날 Scenes.show는 일부 실내→외부 전환과 재방문에서 기존 경로를 우회함. 예: 집→게시판, 잡화점/증권사→벤치, 후반 안내소/집 재방문. positions 분기의 좌표 대입과 입장 조건의 첫 방문 의존성이 남아 있음.
- 첫날 prepareRoom의 공통 뒤로가기 콜백은 실내 종류와 무관하게 homeOutside를 지정함.
- 첫날 증권사 실내는 placeSomangi에서 대화 위치로 직접 배치함.

## 검증
- 출입 경로·문·은행/안내소 퇴장 관련 단위 테스트 7개 통과.
- 집 첫 입장 실제 브라우저: 소망이 걷기 131개 표본, 모아 선입장 확인, 브라우저 오류 없음.
- 점검한 연결 소스 9개는 웹과 기존 실행본 리소스 SHA256 일치. 따라서 정적 점검에서 확인된 누락은 양쪽에 동일하게 남아 있음.
- 일반 잡화점 브라우저 검증 결과는 실행 로그 별도 확인.

사용자 요청의 '순간이동 없이 모든 건물 이동' 조건을 충족했다고 기록하지 않는다.

- 일반 잡화점 실제 브라우저 검증 통과: 입장 후 F 대화·작업대까지 직접 이동·F 작업 시작, 브라우저 오류 없음.
