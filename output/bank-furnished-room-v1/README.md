# 은행 가구 배치 룸 v1

최신 소파 v4·금고 경첩 v2·아치 창문 v1을 기존 책상/의자/금빛 새싹 간판/책상 소품 룸에 배치했다.

- 왼쪽 벽: 대기 소파, 안쪽을 향하도록 90도 회전
- 뒤 오른편: 금고, 책상 뒤 직원 영역
- 오른쪽 벽: 실제 아치 개구부를 낸 창문
- 중앙 출입구와 책상 접근 통로 확보

`Bank-furnished-room.blend`는 조명과 정면 카메라를 포함한 편집 원본이다. GLB는 카메라/조명을 제외한 룸 모델이다. `room.png` 정면 검수, `alternate.png`는 오른쪽 벽 일부를 숨긴 별도 검수 이미지다. 저장 원본의 벽은 유지된다.

✅ 모델 배치·GLB 구조·렌더·변환 좌표 유효성 및 신규 가구 중앙 통로 검사 / ⏳ 게임 런타임 연결·캐릭터 충돌·사용자 최종 검수. 기존 개별 모델과 이전 룸은 보존했다.
