# 증권사 최신 지붕 v24 게임 적용

P1 · ✅ 웹·기존 실행본 반영·자동 검증 / ⏳ 사용자 최종 시각·플레이 검수

사용자 요청 “증권사 새로 수정한 건물로 변경해줘”에 따라 `output/cipher-roof-clean-v24/CipherSecurities-clock.glb`를 웹과 기존 실행본의 같은 모델 경로에 전달했다. 원본/웹/실행본 SHA-256 일치는 `hashes.json`을 따른다. 제작 폴더의 미적용 기록은 당시 이력이며 이번 후속 적용으로 갱신된다.

새 지붕의 직선 용마루·교차선·중앙 벽 마감을 적용하고 현재 위치 `(1750, 1000)`·문 실측 배율·입구 기준점·실내·실시간 시계를 유지했다. 다른 건물/소품/하늘/구름/저장은 변경하지 않았다.

`scratch/check-current-exteriors.cjs`를 웹·기존 실행본 양쪽에 실행해 로딩·모델 폭/문 높이125/문 중심 정렬·충돌·길10단위 표본 차단0건·모든 입구 도달·건물 충돌 영역 겹침0건·뉴욕 브라우저 시간대에서 KST 네 시점 바늘 방향/1분 경과·작은 화면·JavaScript 오류 없음 검사를 통과했다. `web-checks.json`·`desktop-checks.json`에 기록했고 `web-cipher_securities.png`는 게임에 로드된 모델의 검사 카메라 렌더다. 설치 프로그램은 재빌드하지 않았다.
