# 은행 현관 옆 벽체 채움 v4

P2 · ✅ 네이티브 벽체 수정 / ⏳ 사용자 시각 검수·게임 적용

사용자 첨부의 현관 옆 처마 아래 빈 부분을 좌우 대칭 크림색 벽체로 채웠다. 기존 벽과 .045 깊이로 겹치게 합집합 처리했으며 목재 가로보 뒤까지 이어진다. 원본은 `bank-eaves-joint-v3/Bank-eaves-joint.blend`다.

벽 이외 메시 정점 해시 유지·벽체 닫힘을 빌드에서 검사했다. `verify.py`는 수정 GLB를 재로딩해 목재 닫힘·기와/용마루 수량·동전·유한 좌표를 검사한다. 실제 전체/벽체 확대 렌더, `Bank-clean.glb`, `Bank-filled-porch-wall.blend`를 저장했다. 웹·실행본은 교체하지 않았다.
