# 원형 고정 팔 모션 v24

사용자 요청: 원본 외형 유지, 팔 늘어남·접힘 제거, 얼굴 침범 방지, 양쪽 측면 동영상 확인.

v23 첫 프레임의 팔 표면을 기준으로 모든 팔 모프 데이터를 동일한 형태로 고정했다. 하나의 몸체 메시를 유지하며 양팔은 각각 단일 본에 100% 가중치를 주어 회전·이동만 한다. 팔을 구성하는 정점 사이 거리를 바꾸는 혼합 가중치·스케일 키는 사용하지 않는다. 손바닥이 이전 궤적을 따르도록 강체 회전을 맞추고, 양팔과 빵을 함께 조금 낮춰 얼굴과의 간격을 확보했다. 머리·몸통·다리·표정 형상은 변경하지 않았다. 빵의 초기 크기 기준 100% → 2/3 → 1/3 → 0 축소는 유지한다.

검증:
- 실제 GLB를 다시 불러와 181시점 검사. 팔 표면 모서리 길이 변화 최대 약 0.0173%로 부동소수점 오차 범위. 이전의 최대 118% 변형을 제거했다. `glb-rigidity-verification.json`.
- 팔 외 부분 9시점 비교: 최대 좌표 차이 0. `body-verification.json`.
- 181시점 표면 교차 검사: 노출 팔/머리 및 빵/머리 교차 시점 0. 의도적으로 묻힌 어깨 부착부(앵커 반경 0.18)는 제외한다. `contact-verification.json`.
- `eat-side.gif`, `eat-opposite-side.gif`: 내보낸 GLB를 다시 불러와 촬영.

제작 출력만 저장했으며 게임 에셋 삭제 상태를 변경하지 않았다. 마지막 음식 소멸 직전의 손과 음식 간격은 기존의 별도 미해결 항목이며 이번 작업에서 해결했다고 주장하지 않는다.
