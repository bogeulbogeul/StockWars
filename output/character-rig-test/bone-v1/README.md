# NPC형 캐릭터 본 걷기 프로토타입

`preview.html`은 별도 서버 없이 열 수 있는 좌우 비교 화면이다. 파츠 이미지와 리깅 코드를 내장하며 일시정지, 자세 넘기기, 기본 조립 자세, 본 표시, 속도, 주기 조절을 지원한다.

제작 그림은 `player-npc-style-v1.png`를 기반으로 image_gen에서 파츠화했다. 이전 정면 파츠를 재사용하지 않았다. 머리·헤어는 하나로 유지하며, 몸통/골반과 좌우 위팔/아래팔+손/허벅지/종아리/신발로 구성한다. 좌우는 캐릭터 해부학적 기준이며 오른쪽 3/4 그림의 왼쪽 화면 팔다리가 가까운 R이다. 원본과의 정확한 픽셀 일치는 보장하지 않는다.

`rig.js`의 파츠 사각형, 피벗, 기준 끝점은 제작 좌표다. root → torso/head, root → hip → thigh → calf → foot, torso → upper arm → lower arm/hand 구조를 계산한다. 다리는 2본 IK로 고정 길이를 유지하고 팔은 반대 스윙을 한다. 주기·길이·보폭은 이 프로토타입의 시험값이며 프로젝트 공통 제작 규격이 아니다.

파츠화는 AI 이미지 편집, 좌표·피벗·그리기 순서·관절 캡·클립 영역 및 IK 모션은 수동 작성한 코드다. 걷기 프레임은 AI가 개별 생성하지 않았다. `render.cjs`에서 같은 리그의 24개 자세를 SVG로 렌더하고 sharp로 PNG를 출력했다. GIF 패키징만 sprite-gen compose-gif를 사용했다. sprite-gen의 AI 걷기 파이프라인 결과로 표시하지 않는다.

240개 시점에서 본 길이 고정, 접지 발목 높이, 한 발 이상 지지, 주기 끝 연결을 수치 검증했다. 이 검증은 그림의 발바닥 모든 픽셀이나 게임 이동속도까지 보장하지 않는다. 자세 시트를 시각 확인했다. 브라우저에서 재생한 자연스러움의 최종 평가는 미완료다.

현재 한계: 관절 절단선·생성 색 테두리·보완 캡 색상·앞뒤 가림·머리 대비 체형 정밀 일치를 추가 정리해야 한다. 손목은 아래팔과 통합했다. 신발 두 그림의 발바닥 접지 미세 차이가 남을 수 있다. 왼쪽은 오른쪽 리그와 그림의 반전이며 헤어 비대칭도 반전된다. 한 방향 시험만 완료했고 다른 방향/생활 모션/마을 및 실내 적용은 미완료다. 최종 게임 에셋이나 런타임 도구 채택으로 취급하지 않는다.
