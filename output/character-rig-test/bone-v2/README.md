# 본 모션 재검증 v2

기존 실패한 bone-v1을 보존하고 새 폴더에서 재구현했다. `preview.html`은 이미지·코드 내장형으로 서버 없이 열 수 있다. 직립, 걷기, 택배 들고 걷기, 의자 앉기와 일어서기를 제공한다. 좌측은 반전이다.

## 제작 범위

- 머리·몸통·반바지는 기존 NPC형 파츠 그림 유지. 해당 파츠는 앞선 image_gen 편집 결과이며 원본과 픽셀 단위 일치하지 않음.
- 팔·다리·신발은 관절 틈과 잘못된 파츠 길이를 배제하기 위한 SVG 시험용 표현이다. 원본 팔다리의 최종 그림을 완성한 것이 아님. 같은 뼈 좌표에 최종 그림을 연결할 후속 단계가 필요함.
- 본은 골반 → 좌우 고관절 → 무릎 → 발목과 몸통 → 어깨 → 팔꿈치 → 손 연결로 계산. 변형 없는 두 본 IK 사용. 무릎은 진행 방향으로 굽힘. 양발은 반 주기 차이, 팔은 자기 다리와 반대 스윙.
- 택배는 별도 `cargo` 오브젝트이고 손 연결점에 맞춰 유지. 걷는 하체 공유. 집기·내려놓기는 미구현.
- 앉기는 시험 의자 한 종류에서 진입 → 유지 → 일어서기. 실제 룸 좌석/가림 연동은 미구현.
- 제작 좌표·보폭·기간·본 길이는 프로토타입 설정이며 공통 게임 규격으로 확정하지 않음.

## 검증

`verify.cjs`: 4모드 × 240자세, 팔/다리 길이 고정, 직립 무릎 정렬, 서로 반대의 발 전진 자세, 지지발 높이, 한 발 이상 지지, 걷기 끝 연결, 운반 손 연결점, HTML 모드/앉기/일어서기/프레임 제어 검증 통과. `poses.png`에서 직립·걷기 A/B·운반·앉기 시각 확인.

별도 게임 이동과의 발 미끄러짐, 최종 피부/의상/신발 형태, 옆·뒤 방향 제작, 실내외 연결, 실제 의자 충돌/가림은 검증하지 않았다. 브라우저 실재생의 미적 평가는 사용자 검토 대상이다. 시험 화면 구현을 게임 적용 완료로 표시하지 않는다.

## 재생산

번들 Node로 `render.cjs` 실행 → 같은 리그의 정적 자세 PNG와 내장형 HTML 생성. `verify.cjs`로 수치·UI 로직 검증. GIF는 sprite-gen compose-gif로 패키징(24프레임, 40ms로 반올림하여 GIF 주기는 0.96초; HTML의 원 모션 주기는 1.05초). 파츠 이미지 신규 생성이나 AI 걷기 프레임 생성은 이번 작업에서 하지 않았다.
