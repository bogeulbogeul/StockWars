# 좌우 걷기 시험 검수

- 생성: sprite-gen gen-set --provider codex, GPT 이미지 프레임. 본 리깅 결과가 아님.
- 전달: 8프레임 / 10 FPS / 256×320 셀. 모든 프레임 추출·아틀라스 구성 성공. 자동 inspect 오류·경고 없음.
- 기준: player-npc-style-v1.png의 오른쪽 3/4 시점. 순수 측면 또는 마을 적용 완료를 뜻하지 않음.
- 첫 시안: 무릎 과상승, 후반부 자세 반복. 모션 검수 실패.
- 수정 시안: 과상승은 감소. 그러나 팔의 반대 스윙이 거의 없고, 프레임 1–4와 5–8의 다리 실루엣이 비슷하게 반복되어 해부학적 양발 교대를 확실히 확인할 수 없음. 모션 판정 experimental / fail. 최종 게임 에셋 채택 보류.
- 머리·눈·의상은 대체로 일관되지만 원본과의 체형 정밀 일치와 발 접지·이동속도 일치는 미검증.
- 왼쪽: HTML에서 같은 오른쪽 프레임을 좌우 반전. 별도 생성 아님. 헤어의 비대칭도 함께 반전됨.
- 미리보기: 기본 속도, 느린 재생, 프레임 이동, 화면 이동, 두 시안 비교. 재생 속도 조절은 검수용이며 모션 결함 수정이 아님.
- 로컬 브라우저 자동 확인은 localhost 연결 시간 초과로 완료하지 못함. 외부 서버 없이 열 수 있도록 HTML에 이미지와 메타데이터를 내장함.
- 다음 판단: 사용자 재생 검토 후 반복 생성보다 본 애니메이션 또는 다른 모션 생성 경로와 비교할 가치가 있음.
