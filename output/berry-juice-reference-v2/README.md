현행 상점 `web/assets/items/packing-v1/items.png`의 베리 주스 영역 `1665,25,275,370`을 직접 확인했다. 원본의 둥근 병·좁은 목·붉은 주스·초록 뚜껑·금빛 목 띠와 초록 주름 덮개·크림색 베리 라벨을 기준으로 제작했다. 제작 명칭은 현행 카탈로그의 ‘꽃꿀 베리 주스’와 아이템 ID `item_berry_juice`를 따른다.

외부 유리벽·병 안의 주스·뚜껑·봉인 띠·물결 모양으로 접힌 초록 목 덮개는 별도의 실제 입체 형상이다. 목 덮개는 원주 전체가 이어진 하나의 접힌 메시다. 사과주스의 긴 병을 단순히 색만 바꾸지 않고 둥근 몸통으로 새로 만들었다.

라벨은 크림 바탕·얇은 테두리·붉은 베리 송이·초록 잎을 벡터로 다시 그렸으며, 병을 따라 감기는 얇은 종이에 인쇄했다. 곡면 투영 후에도 베리가 과하게 옆으로 늘어지지 않도록 인쇄 비율을 보정했다. 원본을 확대한 흐릿한 그림·인쇄에 구워진 가짜 깊이·두꺼운 입체 배지는 사용하지 않았다. PNG는 GLB와 Blender 원본에 내장했다.

GLB 헤더/길이·재수입·유한 정점·퇴화면 0개·내장 이미지 디코딩을 검증하고 전체·후면·목 덮개·재수입 라벨 확대 렌더를 확인했다. 수치와 해시는 `validation.json`을 따른다. 유리·주스의 투과 표현에는 glTF 전송 재질 확장 지원이 필요하며 실제 게임 조명 일치나 성능 검증은 별도다.

이 개별 수정본을 기존 12종 모음의 베리 주스보다 우선하는 후속 제작본으로 사용한다. 다른 상품·가격·보유 데이터·상점/포장 UI·기존 실행본은 변경하지 않았다. 게임 적용과 사용자 최종 외형 검수는 별도다. GLB는 상품만 포함하고 `.blend`는 촬영용 조명·카메라·바닥을 포함한다.
