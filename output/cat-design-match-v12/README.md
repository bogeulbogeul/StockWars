# 고양이 디자인 시트 외형 맞춤 v12

사용자 첨부 캐릭터 디자인 시트를 외형 기준으로 전체16자세를 다시 맞췄다. 강아지 RGB 시트는 선·제한적인 셀 명암·기존 모션 참고다. 중단된 v11 편집본은 사용하지 않았다.

- built-in GPT imagegen으로 기존16자세 모아보기를 편집했다. 고양이 디자인의 둥근 머리, 눈·눈썹, 귀, 겹쳐진 볼털, 작은 가슴털깃, 몸과 팔다리 비율, 긴 꼬리를 참고했다.
- 전체 그림을 다시 편집한 버전이므로 v10의 alpha나 자세 픽셀을 그대로 보존한 부분 패치가 아니다. 걷기/운반의 시점·자세 순서와 프레임 구성은 기존 자료를 참고했다.
- 생성 결과의 색을 보존했다. 강제2색 양자화는 털 경계를 얼룩처럼 만들기 때문에 적용하지 않았다. 투명 영역의 아주 흐린 alpha 잡음만 정리했다.
- ✅ 완료: 투명 배경,10상태·16고유자세, 기존 시트 좌표·재생 계약 동일 검사. 정지는 각 걷기 중립과 공유한다. 모든 그림의 alpha 경계는 셀 내부에 있다.
- ✅ 완료: 걷기3그림 A→중립→B→중립, 운반4그림,160ms GIF 생성·재생 길이 검증. 강아지와 비교 미리보기 확인.
- ⏳ 대기: 사용자 최종 외형 확인. 이전 그림과 손발 접촉 픽셀 동일·게임 접촉 검수 완료를 주장하지 않는다. 게임에는 설치하지 않았다.

전달: sprite-sheet-alpha.png, manifest.json. overview.png는 전체 자세, preview.html은 강아지 비교 재생이다. 디자인 참고는 references/user-cat-design.png에 보존했다. design-match-generated.png는 GPT 편집 원본, prompt.txt는 생성 요청, package_sheet.py는 기존 모아보기 셀의 atlas 재배치와 투명 잡음 정리, validation.json은 검사 기록이다.
