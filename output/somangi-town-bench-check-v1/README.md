# 현재 마을 벤치와 앉기 접촉 확인 — 2026-10-23

`web/assets/props/3d/Bench-clean.glb`를 직접 반입했다. 쉼터 동/서쪽 및 정원 벤치에 사용 중인 파일이며, 마을의 `townObjectScale.js`에 따라 좌판 높이 32 게임 단위가 되는 비율을 사용했다. 캐릭터는 보존된 기준 100/1.95 배율로 상대 크기를 맞췄다. 현재 게임에는 캐릭터가 설치되지 않은 상태이며 이번 장면은 게임 캡처가 아닌 Blender 검수 렌더다.

## 결과

기존 회색 임시 벤치용 앉기 위치를 그대로 사용하면 실제 벤치 좌판이 몸통/다리와 겹친다. 좌판 높이 차이는 캐릭터 원본 기준 약 0.42629, 게임 배율 기준 약 21.861 단위다.

캐릭터의 외형과 모션 키는 그대로 두고 검수 장면에서만 캐릭터 전체를 위로 0.42729 이동해 좌판에 맞췄다. 이 배치의 앉은 유지 자세에서는 벤치 내부로 들어가는 캐릭터 정점 표본이 0개였고 정면·측면·사선 렌더로 확인했다. 다리는 자연스럽게 좌판 앞에 뜬 상태다.

이 검사는 앉은 유지 자세의 좌석 배치 확인이다. 위쪽 보정을 모든 프레임에 그대로 적용하면 시작/끝의 서 있는 자세도 떠오르므로, 마을 벤치에서 앉고 일어나는 전체 전환은 별도의 높이 이동 경로가 필요하다. 현재 낮은 벤치용 진입/이탈이 실제 높은 마을 벤치에 맞춰 완료됐다는 뜻은 아니다.

- `aligned-front.png`, `aligned-side.png`, `aligned-angle.png`: 높이를 맞춘 실제 벤치 접촉 확인.
- `unaligned-angle.png`: 보정 없이 기존 위치에 둔 경우.
- `town-bench-seat-check.blend`: 실제 배포 벤치와 현재 캐릭터의 검수 장면.
- `validation.json`: 벤치 해시·게임/모델 배율·높이 차이·배치 전후 내부 정점 표본 수.

최근접 표면 법선으로 내부 정점을 표본 판정한 결과이며 모든 삼각형 간 완전한 무교차를 증명하는 검사는 아니다. 벤치 원본·캐릭터 모델·모션·게임 파일은 수정하지 않았다.
