# 안내소·집·잡화점 실제 경첩 회전 — 2026-10-25

세 건물의 문 개폐축을 GLB 경첩 오브젝트의 원점(핀 중심)으로 변경했다. 안내소·잡화점은 `Door_Brass_Hinge`, 집은 `Home_Door_Brass_Hinge`를 사용한다. 문짝 좌우 경계값 대신 실제 경첩 위치를 사용하며, 문 중심과 경첩의 상대 위치로 회전 부호를 결정한다. 안내소는 왼쪽 축에서 오른쪽 실제 경첩 축으로 수정했다.

기존 0.55초·86.4도 개폐, 문 부속품 동반 회전, 검은 실내 표현, 출입 동선은 유지한다. 모델 자체·은행·다른 건물은 수정하지 않았다. 변경한 런타임 3개 파일을 기존 실행본 resources/web에도 복사했고 SHA256 일치를 확인했다. 설치 프로그램은 재빌드하지 않았다.

검증: `node --test web/tests/homeDoor.test.mjs web/tests/doorwayTraversal.test.mjs` 5개 통과. `scratch/check-door-hinge-axis.cjs`는 실제 세 GLB를 불러와 이동·100배 확대·회전된 건물에서 두 경첩의 위치 고정, 양의 개방 각도, 모든 문 부속품의 닫힘 복원을 검사한다. 웹 검증에서 경첩 이동 오차는 최대 6.44e-13, 닫힘 위치 오차는 0이었다. 실행본 리소스도 동일 스크립트로 검사한다. 자동 기하 검증과 사용자 최종 시각·플레이 검수는 구분한다.
