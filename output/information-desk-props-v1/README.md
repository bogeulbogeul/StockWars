# 안내데스크 소품 v1

P1 (Major) · ✅ 소품 제작 / ⏳ 사용자 검수·상호작용·게임 적용

- `Document-tray.glb`: 앞쪽 손잡이 홈이 있는 나무 트레이와 종이 6장
- `Application-form-pen.glb`: 연초록 받침, 신청서, 서명 칸, 목재/황동 펜
- `Sprout-teacup.glb`: 속이 빈 크림색 찻잔, 고리 손잡이, 새싹 문양, 차, 받침
- `Desk-props-source.blend`: 소품별 분리 원본. 모두 로컬 바닥 z=0 기준
- `desk-detail.png`, `room-preview.png`: 데스크 확대와 룸 전체 배치
- `Room-desk-props-preview.blend`: 소품을 올려둔 조합 장면

문양과 간단한 신청서 선은 실제 형상으로 제작했다. 신청서에 읽을 수 있는 본문은 넣지 않았다. 게임의 서명 입력 UI는 별도 후속 작업이다. 펜과 찻잔 손잡이도 최종 GLB에서는 메시로 변환했다.

기존 데스크 상판 높이(.97)+룸 바닥(.022)에 맞춰 소품 루트를 z=.992에 배치했다. 좌측 트레이·중앙 신청서/펜·우측 찻잔으로 간격을 확보했다. 임시 제작 단위이며 실제 게임 축소 가독성·캐릭터 손 접촉은 미검증이다. 기존 게임과 룸/데스크 원본은 변경하지 않는다.
