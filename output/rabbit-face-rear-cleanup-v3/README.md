# 유럽토끼 v3 — 짧은 꼬리·코 색·초상화 눈

사용자 요청을 합쳐 토끼 v2를 국소 수정했다. 외형 참고는 `../rabbit-design-2026-10-17-v1/design-sheet.png`, 손발 자세와 재생 구성은 강아지 v9다.

- 디자인 시트처럼 위쪽 털끝이 있는 짧은 아이보리 솜꼬리로 맞췄다. 뒤 골반 중앙에 연결하고 독립적인 좌우 휘두르기를 없앴다. 세 뒤 걷기 그림에서 동일한 꼬리 RGBA를 사용하며 골반의 상하 리듬을 따른다. 정면·앞사선 가림은 v2 그대로다.
- 꼬리 아래 겹친 곡선·짙은 그림자를 기존 몸 기본색 RGB(202,162,137)으로 정리했다. 다리 사이 투명 영역·윤곽은 보호했다.
- 코 내부 기본색을 RGB(97,55,42)로 고정했다. 원래 검은 윤곽과 콧구멍은 유지한다. 코 내부 마스크 15논리 항목의 RGB 동일을 검증한다.
- 초상화 눈은 네이티브 편집으로 홍채·동공·흰 하이라이트를 단순하고 선명하게 만들었다. 기존 팔레트의 홍채 중간색이 적어 생기는 띠를 막기 위해 홍채는 기존 RGB(133,75,57)의 깨끗한 색면으로 정리했다. 얼굴·귀 외곽과 수정 영역 밖 털은 원본 그대로다.

## 결과

- `preview.html`: v2/수정본 동시 재생. 뒤 걷기부터 표시하며 정면·운반·초상화도 선택 가능.
- `rabbit/run/sprite-sheet-alpha.png`, `manifest.json`, `frames/`: 10상태·19논리 항목·16고유 그림. 320×400셀, 1280×4000시트.
- `rabbit/review-final.png`, `face-icon.png`, `qa/*.gif`: 자세·초상화·160ms 재생 파일.
- `palette.json`: v2와 바이트 동일한 기존 289색. 전체를 다시 칠하지 않았다.

## 제작·검증

내장 image_gen으로 뒤 주름 제거·초상화 눈·디자인 시트의 짧은 꼬리를 편집/생성했다. 프롬프트와 원본 경로는 `generation.json`, `tail-generation.json`에 있다. sprite-gen 공식 컴포넌트 추출기로 네이티브 그림을 분리했다. 네이티브 몸 전체는 사용하지 않았다.

수동 국소 단계는 `local-edits.py`의 눈 다각형·코 재질 마스크·뒤 수정 영역·꼬리 중앙 연결 좌표 등록이다. 기존 얼굴·몸을 고정한 채 이 부위만 sprite-gen 공식 recolor 베이크 후 조합했다. 코 색과 뒤 털색은 원본 RGB로 고정하고 눈·꼬리는 기존 팔레트만 사용했다. 꼬리는 짧은 부속 외형으로 동일 그림을 골반에 연결하며 팔다리를 리깅하거나 재생 속도로 동작을 대체하지 않았다.

`local-verification.json`: 모든 프레임 알파 동일, 국소 마스크 밖 RGBA 동일, 코 내부 RGB 동일, 뒤 걷기 꼬리 그림/RGB 동일, 팔레트 파일 동일, 좌표·재생 동일. `export-verification.json`: 팔레트 포함·잘림·시트/중립 공유 검사. `preview-verification.json`: VM 그리기 경로 검사. 정적 보존과 수치 검사는 라이브 모션 연속성 통과를 의미하지 않는다.

게임은 아직 교체하지 않았다. 강아지·고양이·다른 숲속 동물 런타임 파일은 변경하지 않았다.

재현: sprite-gen 전용 venv Python으로 `local-edits.py`, 생성된 네 종류 `*-spec.json`을 공식 `sprite-gen recolor`로 각각 `baked-*`에 베이크, `publish.py` → `verify.py` → `verify-local.py`. Node로 `validate-preview.cjs`를 실행한다.
