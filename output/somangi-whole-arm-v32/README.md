# 소망이 팔 전체 회전 시안 v32

사용자 요청에 따라 v31의 팔꿈치 분할·아래팔 회전을 폐기했다. 원본에서 다시 추출한 둥근 팔 전체를 어깨 기준으로 강체 회전시킨다. 팔꿈치 본·팔 중간 절단면·관절 구체는 없다. 몸통과 좌우 팔용 본 3개만 사용하며 팔은 단일 가중치 1로 움직인다. 팔 길이·굽힘을 애니메이션으로 바꾸지 않는다.

원본 머리·얼굴·몸통·다리는 고정한다. 팔 안쪽의 숨은 면과 어깨 연결 패치는 재구성했으므로 전체 원본 메시의 정점·위상이 완전히 동일한 결과는 아니다. 어깨 가까이에 미세한 경계가 남을 수 있다. 음식은 3회 같은 선형 비율로 작아지며 손 간격은 크기에 따라 좁혀지지 않고, 끝에는 기본 자세로 복귀한다.
