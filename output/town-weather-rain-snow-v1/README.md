# 비·눈 날씨 v1

P2 · ✅ 웹·기존 실행본 적용·자동 검증 / ⏳ 사용자 최종 시각·플레이 검수

사용자 요청으로 비와 눈 날씨를 3D 마을에 추가했다. 데이터/기존 서비스 연결은 `townWeatherProfiles.js`, 독립 강수 화면 셰이더는 `TownWeather.js`, 하늘 색조 전환은 `TownSky.js`, 공통 연결은 `TownLandscape.js`다. 기존 `weatherService.currentWeather.category`가 rain/snow를 전달하면 표시한다. thunderstorm은 비 표현으로 대응하고 새로운 위치 요청·외부 API 호출·날씨 추첨·구형 UI는 추가하지 않았다. 실제 지역 날씨 수신은 기존 서비스 정책을 따른다.

비는 가는 사선 빗줄기가 빠르게 내려오고, 눈은 크기/속도가 다른 두 층의 둥근 눈송이가 느리게 흔들리며 떨어진다. 맑아지면 강수 레이어가 서서히 사라진다. 동작 줄이기 설정에서는 강수 위치를 고정한다. 하늘은 비에 청회색, 눈에 옅은 회청색을 섞고 밤에는 밝아지지 않게 어두운 색조를 유지한다. 기존 시간대12초 전환·주황 노을·구름은 유지한다.

강수는 옥외 scene 안의 화면 공간 셰이더이며 DOM 입력을 막지 않고 실내 scene에는 추가하지 않는다. 일반 마을과 공통 TownLandscape를 쓰는 전시/도착 장면에 적용된다. 지면 젖음·쌓인 눈·지붕 적설·강수 소리·번개는 이번 범위에 포함하지 않는다. 조명·건물·배치·저장은 변경하지 않았다.

웹과 기존 실행본 리소스에4개 모듈을 동기화했다. `scratch/check-current-exteriors.cjs`를 양쪽에 실행해 비/눈 모드·실제1.5초 후 픽셀 변화·맑음에서 레이어 숨김·동작 줄이기 시간 고정·기존 하늘 전환/구름/로딩/길/입구/시계/작은 화면/JavaScript 오류 검사를 통과했다. 강수 assertion은 명령 내 브라우저 검사로 실행하며 실패 시 명령이 실패한다. 실제 렌더는 `web-weather-rain.png`, `web-weather-snow.png`, 비교는 `rain-and-snow.png`다. 설치 프로그램은 재빌드하지 않았다.
