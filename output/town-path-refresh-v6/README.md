# 길 배치 정리·집 앞 나무 제거 v6

P2 · ✅ 웹·기존 실행본 적용·자동 검증 / ⏳ 사용자 최종 시각·플레이 검수

사용자의 길 배치 수정·집 앞 나무 제거 요청을 반영했다. `townLandscapeLayout.js`의 반복 사각 순환로/가로 연결을 줄이고 정류장에서 광장 동쪽을 거쳐 증권사로 가는 본길과 서쪽 산책로를 중심으로 정리했다. 각 건물에는 짧은 진입로를 두고 광장 연결선은 광장 표면 안까지 이어지게 했다.

`TownLandscapeTextures.js`에서 길 기본 폭을68→54, 테두리74→58로 줄였고 본길은1.15배·서쪽 산책로1배·나머지 샛길0.76배로 구분했다. 코너 최대 반경은28→100으로 늘려 완만하게 연결했다. 눈이 쌓일 때도 공통 길 텍스처 마스크를 사용하므로 새 길을 따라 눈 덮임이 구분된다.

`townModelProps.js`의 집 앞 나무 `home_garden_tree`만 배포 목록에서 제거했다. 나무 모델 원본·외곽 숲·다른 정원 나무·집/건물/게시판/정류장 위치와 모아·기능·저장은 유지했다.

세 모듈을 웹과 기존 실행본에 동기화했다. `scratch/check-current-exteriors.cjs`를 양쪽에 실행해 집 앞 나무 부재·길 선분10단위 표본 및 둥근 모서리21개 표본의 차단0건·모든 입구 도달·건물 로딩/충돌/시계/작은 화면/JavaScript 오류 없음을 확인했다. `web-checks.json`·`desktop-checks.json`과 낮/맑음 검사 카메라 전경 `web-overview.png`를 저장했다. 캡처용 낮/맑음 지정은 검사 세션에만 적용하며 실제 시간/날씨 정책은 변경하지 않았다. 설치 프로그램은 재빌드하지 않았다.

검사 중 즉시 지정한 하늘색이 다음 프레임에 이전 색으로 되돌아가는 문제도 `TownSky.js`의 완료 시간 기준으로 보정해 양쪽에 동기화했다. 별도 `town-path-refresh-v6-sky-check` 검사에서 하늘/구름/강수/적설 전환 회귀 검증도 통과했다.
