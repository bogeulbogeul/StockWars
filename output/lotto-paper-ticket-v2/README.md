기준은 현재 적용된 `web/assets/items/paper-v4/lotto.svg`와 `output/shop-paper-items-v4/closed-envelope-and-lotto.png`의 연두색 가로 복권이다. 네잎클로버·양옆 가지·두 점선·번호 원 6개·양옆 절취 홈을 유지했다. 작은 원본 그림의 두꺼운 갈색 외곽선과 그려진 두께를 3D 위에 다시 붙이지 않고, 실제 얇은 종이와 선명한 인쇄로 재구성했다.

기존 두께 0.055의 판형 모델을 0.0035 상대 단위의 얇은 종이로 바꿨다. 폭 방향으로 약하게 휘어 있으며, 둥근 모서리와 양쪽 7개씩의 반원 절취 홈은 실제 메시 윤곽에 포함한다. 앞면 인쇄를 별도 사각 판으로 겹쳐 놓지 않고 동일 종이 메시의 UV에 적용했다. 뒷면은 인쇄 없는 연두색 종이이고 단면은 밝은 종이색이다.

인쇄는 편집 가능한 SVG와 고해상도 PNG로 다시 그렸다. 예시 번호는 원본의 `6·12·23·28·35·42`이며, 사용자에게 실제 발급된 번호를 표시하거나 추첨하는 기능을 추가한 것이 아니다. 게임 번호 발급·당첨 확인·아이템 ID·가격·저장은 변경하지 않았다. PNG는 GLB 안에 내장한다.

최종 GLB를 다시 불러와 헤더·파일 길이·유한 정점·퇴화면 0개·내장 인쇄 디코딩을 검증하고 전체·재수입 확대·후면 렌더를 확인했다. 정확한 수치와 해시는 `validation.json`을 따른다. 게임 적용과 사용자 최종 외형 검수는 별도다.

이 개별 수정본을 기존 12종 모음의 복권보다 우선하는 후속 제작본으로 사용한다. 다른 상품·기존 2D 아이템 그림·상점/포장 UI·기존 실행본은 변경하지 않았다. GLB는 상품만 포함하고 `.blend`는 촬영용 조명·바닥·카메라를 포함한다.
