## 원본과 수정

현재 상점의 `web/assets/items/packing-v1/items.png`에서 `20,40,390,350` 영역을 직접 확인했다. [참조 영역](reference.png)은 동일 원본에서 추출했다. 12종 모음의 기존 꿀쿠키보다 이번 개별 수정본을 후속 제작 기준으로 사용한다. 다른 11종은 수정하지 않았다.

분리된 구형 꽃잎 대신 하나로 이어진 둥근 여섯 꽃잎 쿠키를 만들었다. 진한 구운 테두리, 노란 금빛 윗면, 작은 구움 반점과 중앙의 다섯 꽃잎 호박색 꿀 장식을 반영했다. 꿀은 별도의 연속 메시와 코팅 재질이며 표면 반사는 실제 조명에서 나온다. 쿠키 4개는 2×2로 배치했다.

포장은 두꺼운 직육면체 트레이에서 얇고 아래쪽이 좁아지는 크림색 종이로 변경했다. 물결 모양 윗단·종이 두께·주름·내부 접힘과 쿠키를 받치는 종이 받침을 추가했다. 원본에 없는 초록 잎은 제거하고 앞면 중앙의 평면 주황 꽃무늬를 반영했다.

원본의 실루엣·색·대표 장식을 3D 형상으로 맞춘 결과다. 일러스트의 손그림 윤곽선·붓 터치까지 동일하게 복제한 것은 아니다. 새로운 AI 이미지나 원본 그림을 붙인 판형 쿠키를 사용하지 않았다. 모든 쿠키와 포장은 편집 가능한 네이티브 메시이며, 구운 표면의 색은 GLB에 포함되는 정점 색을 사용한다.

## 검증과 범위

GLB 헤더·길이, Blender 재수입, 쿠키 4개, 정점 좌표의 유한성, 면적이 없는 퇴화면 0개를 검증했다. 내보낸 GLB를 다시 불러와 확대 렌더하고 원본 파일의 전체/후면 렌더도 확인했다. 정확한 메시·삼각형 수와 해시는 `validation.json`을 따른다. 폴리곤 수를 제한한 모바일 최적화나 플레이 중 성능 검증은 별도다.

GLB는 상품만 포함하고, `.blend`는 검토용 조명·카메라·바닥도 포함한다. GLB Y-up, 원본 Z-up이며 게임 배율·충돌체는 정하지 않았다. 상점 UI·기존 실행본 적용과 사용자 최종 외형 검수는 별도다. 기존 상점 이미지·가방·포장 게임·가격·저장은 변경하지 않았다.

재현: Blender에서 `build.py`를 실행한다. 저장된 `.blend`를 열고 `verify.py`를 실행하면 GLB 재수입과 확대 렌더를 수행한다. `build.py -- rear`는 저장된 원본에서 후면 렌더를 만든다. `compare.py`는 Pillow로 원본과 실제 렌더를 나란히 배치한다.
