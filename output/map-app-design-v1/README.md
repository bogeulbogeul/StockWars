# 지도 앱 2D 시안 v1

사용자 요청으로 아이보리·파스텔 2D의 마을 지도/장소 선택 화면을 디자인했다. 상단 홈 화면만 유지한다. 현재 TOWN_MODEL_BUILDINGS 9개 위치와 villagePathRoutes, TOWN_PLAZA, TOWN_ARRIVAL을 직접 읽어 SVG 안내 지도로 투영한다. 옛 townLayout 건물 좌표나 폐기 옷가게를 쓰지 않는다. 건물 모양은 가독성을 위한 평면 픽토그램으로 재해석했다.

시설 이름 검색·전체/생활/금융/상점 필터·장소 클릭/키보드 선택·장소 안내·목적지 핀·확대/축소·배율 복원을 시연한다. 시설 이름/설명은 현재 기능 범위를 따르며 미구현 우체국 실내 등 기능을 약속하지 않는다. 내 위치는 도착 지점 기반 예시이며 실제 플레이어 추적과 연결하지 않았다. 목적지 표시는 핀만 놓고 길찾기·자동 이동·순간 이동을 실행하지 않는다. 주변 목록은 입구 주변 시설 안내이며 정밀 거리순 계산은 아니다.

scratch/capture-map-design.cjs에서9개 건물·금융2개 필터·검색1개·선택·목적지·배율 복원·페이지 오류없음을 확인하고 preview.png 촬영했다. 게임 적용 전 시안이다. 기존 게임 파일/실행본/안내소 벽 지도는 변경하지 않았다.
