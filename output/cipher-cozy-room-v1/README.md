# 사이퍼 증권 포근한 룸 v1

채택 시안에 맞춘 기본 룸을 Blender로 제작했습니다.
따뜻한 크림색 벽/큰 바닥 타일, 옅은 줄눈, 둥근 기둥과 몰딩, 낮은 파란 걸레받이와 벽등 두 개로 구성합니다.

- `Cipher-cozy-room.blend`: 수정 가능한 기본 룸 원본.
- `Cipher-cozy-room.glb`: 게임용 룸. 가구·캐릭터·문짝·전광판·엘리베이터 제외.
- `room-shell.png`: 기본 룸 렌더.
- `validation.json`: GLB 재불러오기 후 바닥·벽·양쪽 문 개구부 확인.
- 제작/검증 스크립트와 `exterior_geometry.py`: 재제작용.

바닥 10 × 7.6, 높이 3, 바닥 상면 z=0. Blender Z-up이며 게임은 100배로 설치합니다.
양쪽 문 개구부와 기존 가구 위치는 유지합니다. 천장과 앞벽은 고정 카메라용으로 열었습니다.
나가는 입구의 어두워지는 통로는 기존 런타임 모듈을 그대로 사용합니다.

게임/실행본에 기본 룸을 설치하고 기존 가구를 조합했습니다.
둥근 데스크·새 소파·엘리베이터 등의 후속 가구 제작이 끝난 상태를 뜻하지 않습니다.
