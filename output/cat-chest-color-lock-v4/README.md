# 고양이 가슴털 색 통일 v4

2026-10-18. `../cat-carry-hands-v3/`를 기반으로 모션 전환 시 가슴털 기본색이 달라지는 문제를 보정했다. 이전 버전은 보존한다.

- ✅ 완료: 정면·정측면 걷기, 운반4그림, 정면·아이소메트릭 앞사선 앉기의 보이는 가슴털 기본색을 현재 걷기의 RGB(65,59,62)/#413B3E로 고정했다. 정지는 수정 걷기 중립을 공유한다.
- ✅ 완료: 부위별 기본색 차이0, 가슴털 보정 마스크 밖 RGBA 동일, v3 손 영역 RGBA 동일, 전체 alpha·좌표·프레임 순서·160ms 동일 검증.
- ✅ 완료: 42색 팔레트 밖 색0. 뒤 모션과 얼굴 초상화는 원본과 동일하다. 뒤에서는 가슴털이 보이지 않는다.
- ⏳ 대기: 사용자 최종 색감 확인·게임 적용·실제 플레이 접촉 검수.

기존 짙은 털 경계·가림 선은 보존한다. 기본색 통일은 그 경계선까지 단색으로 없앴다는 뜻이 아니다. 정확한 대상 영역과 RGB 치환은 `lock_chest.py`, `baked/*report.json`, `validation.json`에 기록했다.

전달본: `sprite-sheet-alpha.png`, `manifest.json`. `preview.html`은 수정 고양이와 강아지의 동시 재생 화면이다. `chest-before-after.png`는 위가 이전·아래가 수정본이며, 왼쪽부터 정면 걷기 중립·정측면 걷기 중립·운반·정면 앉기·앞사선 앉기다.
