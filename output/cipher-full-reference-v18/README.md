# 사이퍼 증권 전체 이미지 기준 3D 에셋 v18

사용자 첨부 `ChatGPT 이미지 2026년 10월 25일 오전 07_10_47.png` 전체를 `reference.png`로 보존하고, 기존 제작 이력을 바탕으로 네이티브 3D 외관을 제작했다. 이미지 평면을 붙인 모델이 아니다.

- 넓은 단층 좌우 날개, 파란 기와와 분절 용마루, 중앙 시계 박공, 네 원기둥과 층진 주두·주초를 구성했다.
- 크림 벽, 황동 아치 창살, 중앙 아치 양문과 긴 패널·황동 손잡이, 상승 차트 간판, 세 단 계단과 양쪽 돌 받침을 포함한다.
- 지붕은 실제 경사면의 교차선으로 잘라 맞추며, 기존 중앙 벽의 상단도 지붕 아래로 맞춰 돌출을 제거했다.
- 시곗바늘과 출입 노드 이름을 유지했다. 게임 시간 연결·배율·충돌 검증이나 게임 적용은 이번 에셋 제작 범위에 포함하지 않았다. 기존 게임 파일·저장은 변경하지 않았다.
- 보이지 않는 후면은 현행 기준의 창 없는 벽으로 제작했다. 한 장의 이미지로 확정할 수 없는 깊이·후면은 3D 해석이다.

산출물: `CipherSecurities-clock.glb`(전달용), `CipherSecurities-reference.blend`(편집 원본), `front-right.png`·`front.png`·`rear.png`·`junction.png`(실제 모델 렌더), `validation.json`(내보내기 검사).

재현: Blender 5.2에서 `build.py` 실행 후 Python으로 `verify.py` 실행. 공통 형상 함수와 이전 제작 원본은 상위 output 폴더의 파일을 사용한다. 두 제작 소스 모두 500줄 미만이다.

전체 이미지의 지붕·기초·출입구 기준점을 함께 대조한 `full-fit.json`은 작업 보조 실측이며 완전 일치 판정이 아니다. 원본과 렌더 사이에 창·기초·원근과 세부 표면 차이가 남는다. 픽셀 단위 복제 또는 사용자 최종 시각 검수 완료로 기록하지 않는다.
