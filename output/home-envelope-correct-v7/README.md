# 우체통 편지봉투 표식 보정 v7

사용자가 지적한 끊어진 아래 사선과 어색한 봉투 표현을 수정했다. 집·문·v6 지붕·우체통 본체/배치는 유지한다.

- 기존의 떨어진 짧은 사선 세 개를 제거했다.
- 상단 삼각 덮개를 실제 얕은 종이 부조로 만들고, 연속된 V자 접힘을 넣었다.
- 아래 양쪽 접힘선은 상단 덮개 아래까지 이어진다. 덮개가 선의 안쪽을 가리는 구조라 보이는 끝이 자연스럽게 덮개 모서리에 맞닿는다.
- 선의 굵기와 색을 부드럽게 정리해 봉투 형태가 작은 크기에서도 읽히게 했다.

`envelope-detail.png`, `mailbox-detail.png`, `front-right.png`는 실제 모델의 봉투·우체통·집 전체 렌더다. 전달 모델은 `Home-with-right-mailbox.glb`, `Mailbox-right.glb`이며 편집 원본은 `Home-correct-envelope.blend`다. `Home-redesign.glb`는 집 단독 보존본이다.
