# 소파 앞 작은 원형 테이블 v1

P1 (Major) · ✅ 모델 제작·대기 공간 배치 / ⏳ 사용자 검수·착석/이동·게임 적용

착석 공간 후속: 테이블과 화분을 소파에서 .83 더 멀리 옮겨 테이블 중심 x=1.42에 놓았다. 소파 팔걸이의 가장 앞쪽과 테이블 끝 사이 간격은 .925로, 이전 약 .095보다 넓다. 러그도 앞쪽으로 옮겼다. 임시 제작 단위이며 실제 캐릭터의 앉기/일어서기 모션 충돌 검수는 아직 별도다.

사용자 참고처럼 둥근 목재 상판과 짧은 다리 3개를 가진 낮은 테이블을 제작했다. 기존 소파 앞에 원형 러그와 함께 배치하고 채택 화분 v2를 .65배로 줄여 상판 위에 놓았다.

- `Waiting-round-table.glb`, `Waiting-round-table.blend`: 독립 모델/원본
- `waiting-corner.png`: 소파/러그/화분과 배치
- `room-preview.png`, `Office-waiting-corner-preview.blend`: 전체 실내
- `build_table.py`, `manifest.json`: 재현/배치

테이블 지름 .86·높이 .43은 임시 제작 단위다. 오른쪽 앞부분 대기 공간에 두어 뒤쪽 데스크 우회 통로를 유지했다. 소파 주변 캐릭터 동작·정밀 충돌은 아직 검증하지 않았다. 기존 소파의 부드러운 쿠션/목재 접합 수정본을 사용한다. 게임과 원본 가구는 변경하지 않았다.
