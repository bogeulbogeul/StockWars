# 소망이 벤치에서 내려오기

P1 (Major) · ✅ 모션 제작·메시 비교·361시점 검사 / ⏳ 게임 적용

기준은 사용자가 점프 높이를 낮추도록 요청한 `../somangi-jump-sit-low-v2/` 모델과 착석 위치다. 기존 메시의 정점·면·UV를 수정하지 않았다. 원본 재질·텍스처와 본/웨이트를 유지하며 애니메이션만 추가했다. 기존 제작물과 게임 파일은 변경하지 않았다.

## 결과

- `somangi-bench-down.glb`: 기존 낮은 점프 착석과 새 내려오기 클립을 함께 포함.
- `somangi-bench-down.blend`: 편집 원본.
- `bench-down-preview.gif`: 실제 마을 벤치로 촬영한 정면·측면 미리보기.
- `Bench_Down`: 1.2초. 착석 → 낮은 이동 → 바닥 착지 → 서기.
- `Ground_Idle`: 1초 서기 유지.
- `Bench_Down_Preview`: 2.3초, 시작·종료 유지 포함.

기존 낮은 착석 궤적을 역방향으로 사용해 벤치 앞 바닥으로 내려온다. 루트가 앉은 높이 위로 추가 상승하는 양은 약 0.125(캐릭터 키 약 1.95 기준 6.4%)이다. 공중 이동은 0.55초이며 0.95초에 서기 자세로 복귀한다. 루트 이동이 포함되어 별도 배치 이동을 중복 적용하지 않는다. 벤치는 미리보기에만 포함한다.

## 검증

내보낸 GLB 361개 표본 시점에서 접합부 간격·바닥 침범·벤치 내부 정점 수를 검사한다. 시작 자세는 기존 `Town_Bench_Idle`, 종료 자세는 원본 서기와 정점 위치를 비교한다. 결과는 `validation.json`에 기록한다. 정점 표본 검사이며 모든 삼각형 간 연속 충돌을 증명하는 검사는 아니다. 정면·측면 렌더로 외관과 이동 경로를 추가 확인한다.
