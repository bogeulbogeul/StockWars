# 노드 은행 외관 스타일 정리

음각 내부 마감 후속: 원판을 단일 솔리드로 합쳐 내부 이중 턱을 제거했다. 잎·줄기도 하나의 절삭 형상으로 합치고 바닥 깊이를 통일해 접합부 겹침과 단차를 없앴다. 음각 경계는 미세하게 둥글게 마감했다.

간판 후속: 원형 간판의 뒷면을 박공 크림 벽에 밀착시켰다. 돌출된 초록 새싹 메시를 제거하고 금빛 원판에 잎 두 개와 줄기 모양의 얕은 음각을 실제 메시 절삭으로 표현했다. 음각 바닥도 금빛이며 초록색 덧붙임은 사용하지 않는다. `sign-close.png` 확대 확인.

문 마감 후속: 양문 아치의 끝점을 중앙 수직 경계에 정확히 맞춰 위아래 폭이 같은 좁은 틈으로 정리했다. 두 황동 손잡이는 같은 높이·간격의 곧은 손잡이와 매끄러운 곡선 연결부로 통일하고 위아래 고정구를 추가했다.

접합부 후속: 주 지붕 목재 테두리의 앞뒤 끝을 금빛 지붕과 같은 평면에 맞춰 돌출을 줄였다. 입구 박공의 곡선 테두리는 하단 목재 보의 윗면과 양끝 경계에서 정확히 잘라 맞추고 앞뒤 깊이를 통일했다. `roof-joint-close.png`·`porch-joint-close.png`에서 확인한다.
