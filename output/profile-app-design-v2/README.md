# 내 정보 분석력 포함 시안 v2

사용자 요청으로 프로필 카드 바로 아래에 하늘색 분석력 카드를 추가했다. 분석력 Lv.3 / 숙련도4/40 / Lv.4까지36 / 진행막대 / 퀴즈 정답 성장 안내를 표시한다. 중복되던 기본정보 표는 정리하고 이름과 등록 마을은 기존 프로필 카드에 유지한다. 서류함·수령 대기·서명 후 업데이트 흐름은 v1과 동일하다.

현재 확인한 web/js/engine/AnalysisGrowthMigration.js의 ANALYSIS_REQUIREMENTS=[0,20,30,40,60,0] 기준으로 Lv.3 요구량40을 적용했다. 과거 대화의4/16 예시 대신 현행 코드 기준을 사용한다. 숙련도4 자체는 시안 예시이며 사용자의 실제 저장 데이터가 아니다. 게임 성장 산식이나 상태를 수정하지 않았다.

scratch/capture-profile-design-v2.cjs로 5개 서류 단계·필터·서명 전후 반영·분석력 진행막대4/40 확인, 페이지 오류없음을 검증하고 preview.png(대출 수령 직후), signed.png(대출 서명 후)를 촬영했다. 게임 적용 전 시안이며 게임/기존 실행본은 변경하지 않았다.
