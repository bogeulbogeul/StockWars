# 오소리 입·프레임별 몸 색 변화 수정

v1은 승인 색 목록에 포함된다는 검사만 했으므로 프레임별 기본색/명암 분포 차이를 막지 못했다. 또한 앞 머리 고정이 y175에서 끝나 입 아래의 생성 선이 남았다. 이 결함을 인정하고 수정한다.

정면·사선의 입 전체 RGBA를 중립 원본의 넓은 직사각 영역으로 고정했다. 사선·뒤 포함 3방향 몸은 재질별 중립 RGB 중앙값을 기준으로 작은 채널 차이를 경계가 부드럽게 보정하고, 공통 몸통 중심 영역은 중립 RGB를 직접 공유한다. 팔/윤곽선/가림 영역은 공통 몸통 검사에서 제외한다. verification.json은 입 전체 RGBA 일치와 실제 공통 몸통 픽셀의 프레임간 RGB 차이0을 검사하며 단순 팔레트 포함 검사가 아니다. 몸 전체 모든 움직이는 픽셀이 동일하다는 뜻은 아니다.

built-in image_gen 편집은 색/재질 영역 참고를 제공하며 실제 프롬프트·원본은 generation.json이다. 크로마/연결요소 추출은 sprite-gen을 쓴다. 네이티브 재질 참고에서 회색/크림 영역을 확인하지만 최종 알파·걷기 자세는 v1을 보존하고 색 기준은 중립이다. 중립은 수정하지 않는다. 색 재질 경계의 안티앨리어싱 샘플을 전파한 시험과 평평한 색장 시험은 줄무늬/스타일 손실로 미채택했다. 채택은 작은 중립 기준 색 차이 보정과 부드러운 경계의 몸통 RGB 보호다. 리깅·리타이밍·프레임 추가는 없다.

새 걷기6접지 그림만 변경하며 다른 모션과 다른7종은 그대로다. 3그림·160ms·기존 순서 유지. 입/몸통 픽셀 비교와 자세 보드, 시트 좌표/잘림/공유 중립/GIF 검사를 수행한다. 실제 브라우저 재생 및 게임 내 접지 검수는 미수행이며 색 반짝임이 전체 동작에서 완전히 사라졌다고 정적 검사만으로 단정하지 않는다. preview.html에서 이전/수정본을 동일 박자로 비교한다.
