# 입주 신청서 UI v1

아이보리 종이·초록 새싹·마을/안내 담당 정보·신청인 서명란·12자 표시·제출 버튼으로 전시 첫날의 기존 nickname 단계를 교체했다. 입력 이름을 trim한 후 기존 상태와 next 흐름으로 전달한다. 빈 이름/공백 이름은 제출할 수 없다. clear 시 신청서 전용 패널 클래스를 제거한다.

웹과 기존 win-unpacked 실행본에 소스 5개를 동기화했다. 설치 프로그램 재빌드는 하지 않았다.

검증: 전시 상태 테스트 6개 통과. scratch/check-residence-application.cjs로 1280×900, 390×844, 844×390 패널 화면 경계, 공백 제출 차단, 이름 앞뒤 공백 제거 제출을 확인했다. 같은 폴더 PNG는 실제 브라우저의 독립 UI 렌더다. 게임 내 배경과 함께한 최종 사용자 플레이 검수는 별도다.

후속 간판 일치: information-sprout-mark-v1/mark.png와 build_mark.py, information-redesign-v2/README.md의 공통 간판 메시 재사용 기록을 확인했다. 신청서 SVG를 나무색 원형 테두리·크림 바탕·타원형 두 잎·둥근 줄기로 수정하고 웹/기존 실행본에 반영했다.

후속 소망 공란 연출: 이름 아래에 입력 없는 소망 칸을 추가했다. 유효 이름 제출 시 중복 제출을 막고 1.6초간 펜을 멈춘 안내, 2.2초간 공란으로 건넨 안내 후 기존 onSubmit을 호출한다. 화면이 교체된 경우 지연 콜백을 중단하며 소망 저장값은 추가하지 않는다. 웹/기존 실행본 반영. 3개 화면 크기·공란 유지·지연 제출 검증 통과.

후속 문구 삭제: 사용자 지정 두 문구(공란으로 신청서를 건넸다는 안내, 이 이름으로 첫 이야기를 시작한다는 안내)를 제거했다. 소망 공란과 제출 지연 연출은 유지하며 웹/기존 실행본에 반영했다.

후속 서류 스타일: 정착 서식 제01호·입주 신청용 표기, 정식 신청 문장, 항목별 표/서명선, 안내소 귀중을 적용했다. 모서리를 각진 종이 형태로 정돈하고 기존 안내소 문양·이름 입력·공란 소망·제출 연출을 유지했다. 웹/기존 실행본 반영 및 3개 화면 크기·제출 검증 통과.

후속 이름칸 포커스 축소: 이름 입력의 기존 3px 외곽 포커스 테두리를 제거하고 입력줄 하단의 2px 초록 선으로 대체했다. 웹/기존 실행본에 반영했다.
