# 봉봉 앞치마 직접 모델링 v1

2026-10-22 · P1 (Major) · ✅ 모델 제작·4방향 및 사선 렌더·GLB 재수입 검사 / ⏳ 사용자 외형 확인·전체 모션 접촉 검수·게임 적용.

소망이 걷기 v4 Blender 원본의 머리·몸·팔다리 정점 위치를 유지했다. 기존 얼굴 텍스처를 살리면서 살구색으로 틴트하고 머리 본을 따르는 코랄 꽃봉오리를 추가했다. 봉봉의 앞치마 없는 시안은 이미지뿐이므로 별도 Meshy 모델을 사용하지 않았다.

앞치마는 `../bongbong-apron-views-v1/`의 아이보리 앞판·코랄 테두리·둥근 주머니·어깨끈·허리끈·뒤 리본을 Blender 메시로 직접 제작했다. 앞판은 실제 몸 표면에서 바깥쪽으로 여유를 주어 구성하고 기존 Body 본에 연결했다. 뒤는 열린 구조이며 가슴판과 같은 천을 새로 덧대지 않았다. 원본의 몸 비율을 유지하므로 시안과 완전히 동일한 화면상 크기나 픽셀 윤곽을 의미하지 않는다.

## 파일

- `Bongbong-apron.blend`: 편집 원본. 몸과 앞치마가 별도 메시이며 카메라·조명 포함.
- `Bongbong-apron.glb`: 봉봉·꽃봉오리·앞치마·기존 Walk_InPlace 클립.
- `Apron-only.glb`: 앞치마와 공통 리그만 내보낸 파일. 애니메이션 제외.
- `front.png`, `left.png`, `right.png`, `back.png`, `three-quarter.png`: 실제 모델 렌더.
- `build.py`: 재생성 스크립트. `validation.json`, `export-validation.json`: 검사 결과.

## 검증 및 한계

앞치마는 평가된 두께·테두리·주머니·끈·리본을 모두 포함해 **3,864삼각형**, 꽃봉오리는 **864삼각형**이다. 재질은 앞치마 아이보리와 코랄 2개다. 기존 몸체는 **73,602삼각형**으로 유지하며 몸체 전체를 경량화한 작업은 아니다. 원본 4개 몸체 메시 정점 좌표 불변 검사를 통과했다.

GLB 재수입 시 단일 리그·앞치마·주머니·꽃봉오리·걷기 클립 존재를 검사했다. 정면·양측면·후면·사선 렌더로 착용 형태를 확인했다. 걷기 전체 구간 및 인사·먹기·앉기에서의 옷 관통·어깨끈 접촉은 후속 검수 대상이다. 제작 이미지와 모델을 게임 배포 경로에 설치하지 않았으며 기존 게임과 실행본 파일은 변경하지 않았다.
