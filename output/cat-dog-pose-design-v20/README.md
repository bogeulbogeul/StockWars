# 강아지 자세 원본 × 고양이 디자인 v20

사용자 재확정: 외형은 첨부한 고양이 캐릭터 디자인 시트, 모션은 채택 강아지 시트를 따른다.

이번 편집의 입력은 이전 고양이 모션 시트가 아니라 RGB 강아지의16자세 모아보기다. built-in GPT imagegen으로 각 강아지를 첨부 디자인의 고양이로 교체했다. 디자인 시트는 얼굴·귀·볼털·가슴털·체형·고유 색·긴 C자 꼬리 참고로, 강아지는 시점·몸 기울기·팔/손/발 자세·앉기·프레임 배치 참고로 구분했다.

- 정면 앉기는 강아지 정면 앉기 원본 한 칸에서 별도 교체 편집해 두 손이 무릎 위에 놓이는 자세를 다시 맞췄다.
- 뒤 반대 접지에서 짧고 둥근 강아지 꼬리처럼 나온 부분은 몸 자세를 유지하도록 요청하고 고양이의 긴 열린 C자 꼬리로 별도 편집했다.
- 뒤 중립의 아래로 늘어진 꼬리는 강아지 중립의 들어 올린 중앙 방향을 참고해 고양이 C자 꼬리로 별도 편집했다.
- 얼굴 전용 초상화는 귀와 얼굴만 포함한다. 가슴털·목을 붙이지 않는다.
- 이전의 임의 머리 회전·전역 색상 임계값 변환은 사용하지 않았다. 생성된 색과 털 묘사를 보존하고 분리된 alpha 잡음을 제거했다. 들린 뒤꿈치의 패드처럼 보이는 어두운 타원만 해당 그림의 털색으로 정리했다.
- 전체 기본 편집에는 같은94% 배율을 적용해 셀 여백을 확보했다. 뒤 꼬리 별도 편집은 이미 정렬한 대상에서 진행해 추가 축소하지 않는다.
- 투명 배경·셀 잘림 없음·10상태/16고유그림·강아지와 동일한 시트 좌표와 재생 계약 확인. 걷기3그림 A→중립→B→중립, 운반4그림,160ms 유지. 정지는 해당 중립을 공유한다.

AI 편집은 강아지와 관절 좌표가 픽셀 단위로 동일함을 보장하지 않는다. pose-comparison.png와 preview.html에서 각 자세를 나란히 비교한다. 게임 설치와 실제 접촉 검수·사용자 최종 채택은 별도이며 이번에는 게임에 설치하지 않았다.

전달본: sprite-sheet-alpha.png, manifest.json, frames/. references/는 외형/모션 입력을 보존한다. dog-template-cat-generated.png, front-sit-dog-template-generated.png, rear-b-cat-tail-generated.png는 GPT 원본이다. prompt.txt와 rear-tail-prompt.txt, package_sheet.py, validation.json에 요청·조합·검사 기록을 남긴다.
