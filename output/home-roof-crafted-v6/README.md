# 집 지붕 상부 완성도 보정 v6

사용자 첨부의 얇고 평평한 용마루를 중심으로 지붕 상부를 다듬었다. v5의 문 세로 홈·우체통 디테일과 오른쪽 배치, 집 벽·창·기존 지붕 경사면은 유지한다.

- 작은 평면 조각 같던 용마루를 두께와 곡면이 있는 돔형 기와 8개로 재제작했다. 이음부에는 라운드 겹침 띠 9개를 배치했다. 기와 발은 경사면 안에 묻히고 꼭대기는 둥글게 읽히도록 단면을 정했다.
- 경사면 기와 112개는 지붕 접선 기준 두께 0.043, 부드러운 모서리 0.011의 입체 타일로 제작했다. 원래의 7×8 배열과 무광 코랄색을 유지한다.
- 굴뚝과 만나는 기와는 실제 몸체 경계에서 절단하고, 같은 테라코타색의 닫힌 마감 고리를 맞물려 연결했다. 굴뚝·목재·기와에 뜬 부재를 추가하지 않는다.

`front-right.png`: 실제 전체 렌더. `roof-detail.png`, `ridge-detail.png`, `chimney-detail.png`: 실제 지붕·용마루·굴뚝 접합부 확대 렌더. 전달 파일은 `Home-with-right-mailbox.glb`, `Home-redesign.glb`, `Mailbox-right.glb`이며 편집 원본은 `Home-crafted-roof.blend`다.

`roof.py`는 실제 경사 기와·용마루·굴뚝 마감을, `build.py`는 원본 유지·내보내기·렌더를 담당한다. `verify.py`로 세 GLB를 재로딩해 유한 좌표·접지·오른쪽 우체통과 계단 여유를 검사한다. `manifest.json`과 `validation.json`에 수치·해시·검증 결과를 기록한다.
