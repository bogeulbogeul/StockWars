# 우체국 건물 간판 봉투 문양 통일 v4

P2 · ✅ 네이티브 마크 통일 / ⏳ 사용자 시각 검수·게임 적용

사용자 요청으로 건물의 봉투 마크도 집 앞 우체통의 최신 봉투 메시/재질로 교체했다. 몸체·상단 종이 덮개·V 접힘선·아래 두 접힘선의 비율을 유지한 채 간판 높이에 맞춰 균일 확대했다. 목재 테두리·금빛 인레이·간판 크기와 위치는 유지하며 종이 몸체는 붉은 바탕에 살짝 묻어 장착했다.

원본은 `post-office-envelope-match-v3/PostOffice-shared-envelope.blend`이며 우체국 앞 우체통의 통일된 문양도 유지한다. 변경 대상 외 메시 정점 해시를 대조했고 `verify.py`로 집 원본과 간판 문양 5부품 좌표 일치·GLB 재로딩·수집함 문양/프레임 보존·유한 좌표를 검사한다.

`PostOffice.glb`, `PostOffice-shared-envelope-sign.blend`, 전체/간판/봉투 확대 실제 렌더를 저장했다. 웹/기존 실행본은 교체하지 않았다.
