# 붉은여우 운반 얼굴 v3

사용자 요청에 따라 사선 걷기의 기존 완성 머리 그림을 운반4프레임에 조합했다. 얼굴 폭·턱·주둥이·눈·귀·윤곽선·RGB를 새로 해석하지 않고 그대로 사용한다. 대응은 걷기 A→중립→B→중립이며 운반 손발과 순서는 기존4그림을 유지한다.

프레임 y0–180은 대응 걷기와 RGBA 완전 동일, y181 이후는 운반 v2와 RGBA 완전 동일하다. 얼굴의 자연스러운 프레임별 변화도 걷기에서 유지된다. 다른 모션·기존371색·160ms 설정은 유지한다.

시트 무결성·RGB 포함·미리보기 렌더 경로 검사를 통과했다. 실제 브라우저 재생 검수와 게임 설치는 별도다.
