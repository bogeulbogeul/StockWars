# 은행 목재 서랍장 v1

사용자 참고의 낮은 목재 장식장을 양문 수납부와 오른쪽 3단 서랍으로 제작했다. 황동 손잡이·얕은 내부 패널·낮은 기단 구성. 위에는 장부 4권, 작은 크림 화분, 황동 잠금장식 보관함을 올렸다.

Bank-storage-cabinet.glb 및 .blend: 소품 포함. Bank-cabinet-only.glb: 가구 본체만. 문과 서랍은 정적 메시이며 열림 동작은 미구현.

가구 본체 폭 1.72, 깊이 .50, 상판 .805. 게임 wave.glb 첫 자세, 제작 배율 1/1.95, 측정 신체 H=.97425 기준 상판 높이 약 .826H. 소망이와 같은 바닥에 놓은 scale.png 비교.
