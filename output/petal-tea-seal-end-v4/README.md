# 꽃잎 차 윗봉합 오른쪽 끝 보정 v4

2026-10-25 사용자가 첨부한 확대 이미지의 윗날개 오른쪽과 그 아래 사선 끝을 수정했다.

원인은 원본 일러스트에서 잘라온 윗날개·앞쪽 경사면 인쇄의 오른쪽 가장자리에 포함된 짙은 원근 그림자였다. 이 그려진 접힘/구멍 표현이 실제 3D 접힘과 중복돼 붉은 틈이 깊게 벌어진 것처럼 보였다. 해당 두 인쇄면 오른쪽 띠의 가짜 깊이 음영을 인접한 분홍색 인쇄 바탕으로 이어 정리했다. 실제 종이 두께·봉합 구조·안으로 모이는 옆면 접힘과 v3의 꽃/잎 옆면 인쇄는 유지했다. 인쇄의 중앙 꽃과 몸통은 수정하지 않았다.

최종 GLB를 다시 불러와 파일 구조·유한 정점·퇴화면 0개·내장 인쇄 4개 디코딩을 검증하고 사용자가 지적한 모서리를 확대 렌더했다. 결과 수치는 `validation.json`에 기록한다. v3는 이력으로 보존하고 이번 v4를 후속 제작본으로 사용한다. 게임에는 적용하지 않았으며 사용자 최종 외형 검수는 별도다.
