# 실제 잡화점 통로 역방향·정지·재출발 검수

사용자 요청: 반대 방향 통과와 좁은 구간 중간 정지 후 자연스럽게 옆걸음 유지/재개 확인.

기존 잡화점 `VivianModelScene`의 같은 통로를 반대로 통과했다. X=-180, Z=160→-175이며 중간 Z≈-60에서 이동키를30프레임(1초) 해제하고 다시 W 이동 입력을 유지했다. 실제 룸 업데이트·모델·가구·카메라·충돌 판정을 그대로 사용했다. 옆걸음 상태나 몸 방향을 강제 지정하지 않았다. 게임 소스는 변경하지 않았다.

`capture.json`에 실제96프레임의 위치·현재 상태·좁은 통로 판정·방향·합법 위치 여부를 기록했다.

- 확인한 순서: `walk → sideways → idle → sideways → walk`.
- 정지30프레임 전부 좁은 통로 판정이 유지되고 실제 위치가 고정됐다.
- 정지 전·정지 중·재출발 후 몸 방향이 동일하며 반대로 뒤집히지 않았다.
- 재출발 시 옆걸음이 자동 재개되고 넓은 곳에 나오면 일반 걷기로 복귀했다.
- 모든 촬영 위치가 기존 충돌 판정을 통과했고 실행 오류는 없었다.

`reverse-stop-resume.gif`는 실제 게임 화면의 연속 촬영이다. 이야기 UI를 촬영 중 숨기고 검수용 현재 상태만 왼쪽 위에 표시했다. 이동/정지 구간은30fps이며 첫/마지막 프레임만350/500ms 추가 유지했다. `pause-comparison.png`는 정지 전·중·후 확대 대조다.

재현: `scratch/capture-sideways-in-game.cjs`에 `SOMANGI_CAPTURE_REVERSE=1`과 이 폴더의 `SOMANGI_CAPTURE_OUT`을 지정한다. GIF 조합은 `../somangi-sideways-game-capture-v1/package.py`에 이 폴더를 인자로 전달한다.
