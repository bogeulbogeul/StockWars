# 안내소 원형 러그 v1

P1 (Major) · ✅ 모델 제작 / ⏳ 사용자 검수·배치·게임 적용

사용자 참고의 크림색 원형 짜임과 연초록 테두리로 만든 독립 러그다. 동심원 짜임·초록 테두리·짧은 테두리 묶음은 메시로 표현했다. 지름 1.64·높이 약 .027은 안내소 임시 제작 단위다. 가구가 안정적으로 올라갈 수 있게 얇고 평평한 바닥판을 둔다.

- `Round-sage-rug.glb`, `Round-sage-rug.blend`: 모델/원본
- `rug.png`: 목재 바닥 위 미리보기
- `build_rug.py`, `manifest.json`: 재현과 상태

미리보기의 바닥·카메라·조명은 GLB에서 제외한다. 아직 실내 조합 장면에 배치하거나 게임에 적용하지 않았다.
