v5의 큰 삼각 단일 블록이 처마 밖으로 두껍게 내려와 어색하다는 후속 피드백을 반영했다. v3 원본에서 다시 제작해, 목재 외곽 X ±.728 안쪽인 ±.723에 얇은 맞춤 기와를 양쪽 두 조각씩 배치했다. 두께는 .035이며 별도 두꺼운 바탕판과 아래로 내려오는 합친 블록은 사용하지 않는다. 크림 벽체를 추가했던 v4는 계속 미사용이다.
