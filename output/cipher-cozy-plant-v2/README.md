# 둥글고 도톰한 잎 수정 v2

이전 화분 용기·파란 띠·낮게 넣은 흙은 유지하고 잎을 다시 제작했습니다.
얇고 뾰족한 7개 잎과 돌출 잎맥을 제거하고, 둥근 타원형 볼륨 잎 10개를 촘촘히 배치했습니다.
노출된 줄기와 가지를 줄이고 초록색 3종으로 잎의 방향을 구분합니다.

`Cipher-cozy-plant.blend/.glb`는 수정 원본/게임 모델, `plant-preview.png`는 렌더입니다.
기존 게임 모델 경로에 교체하고 실행본에 반영했습니다. 화분 배치/몸체 충돌과 로비 출입을 유지했습니다.
이전 v1 제작 파일은 보존합니다.
