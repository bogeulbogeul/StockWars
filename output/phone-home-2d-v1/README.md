# 스마트폰 2D 홈 화면 v1 — 2026-10-25

P1 (Major) · ✅ 웹·기존 로컬 실행본 반영 및 브라우저 검증 / ⏳ 사용자 최종 시각·플레이 검수

사용자가 채택한 `adopted-concept.png`의 검정 둥근 프레임·아이보리 화면·평면 파스텔 아이콘을 HTML/CSS/인라인 SVG로 구현했다. Blender·GLB·시안 PNG를 실제 UI로 사용하지 않는다. 앱 순서는 주식·소식·업적·메신저 / 할 일·내 정보·지도·설정이다. 소스는 `web/js/components/phone/`의 데이터·템플릿·컨트롤러와 `web/css/modules/phone-home.css`로 나눴다.

일반 게임에서는 오른쪽 아래 휴대폰 버튼 또는 P로 열고, ×·Escape·P·바깥 클릭으로 닫는다. 앱을 누르면 새 아이보리 앱 영역이 열리며 홈 버튼으로 돌아온다. 실제 로컬 시간·날짜와 기존 weatherService의 날씨를 읽는다. 게임 전체 zoom과 독립적인 크기로 표시해 작은 화면에서도 축소되지 않는다. 모달을 연 동안 마을 이동/출입 단축키를 막고, 닫으면 호출 버튼에 포커스를 돌려준다.

기본 전시 체험에서도 기존 휴대폰 버튼과 첫 휴대폰 확인 활동에 연결했다. 수령 전 휴대폰을 열지 못하며 투자 자격증 전 주식 아이콘을 숨기는 기존 조건을 유지한다. 메신저의 모아 연락처, 주식의 자산·매수 기록, 내 정보의 이름·계좌·대출 원금 조회는 전시 저장에서 읽는다. 휴대폰을 닫으면 첫 확인 활동이 기존대로 진행된다.

이번 범위는 홈 화면 적용이다. 업적·할 일·지도 등 새 앱 본문과 일반 게임 앱 본문은 준비 중 안내를 표시한다. 구형 네온 거래·메신저·설정·가방·프로필·칭호·의뢰 모듈을 재연결하지 않으며 새로운 업적/할 일 시스템이나 금융 기능은 구현하지 않았다. 기존 경제·보유·저장 자료는 변경하지 않는다. 이전 UI 제거 지시 중 스마트폰 홈 화면에 한해 이번 사용자 요청을 우선한다.

`scratch/check-phone-home.cjs`를 웹과 `electron-app/dist/win-unpacked/resources/web`에 각각 실행했다. 8개 앱 순서·클릭·홈 복귀·닫기·P·포커스 복귀·1280×900/390×844/844×390 크기·구형 화면 비표시·전시 수령/자격 조건·기존 계좌 조회·눈 날씨 아이콘·첫 확인 활동 진행을 검사했다. 각 `*-checks.json`과 실제 브라우저 `*.png`를 따른다. 전시 상태 테스트 `node --test web/tests/exhibition.test.mjs` 6개도 통과했다. 실행본에 빠져 있던 전시 의존 파일 Mode.js·Quiz.js와 전시 배율 처리를 포함한 GameViewport.js도 맞췄다. UI 12개·의존 3개, 총 15개 파일의 SHA256 일치를 확인했으며 설치 프로그램은 재빌드하지 않았다. 사용자 최종 시각·플레이 검수와 자동 검증을 구분한다.
