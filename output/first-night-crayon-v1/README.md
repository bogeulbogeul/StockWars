# 첫날 밤 · 크레파스 그림책 수면 장면

## 2026-10-25 게임 연결 후속

사용자 요청으로 기존 18초 시안을 `web/assets/ending/first-night-v1/`에 설치했다. 취침 완료 후 `SleepEnding.js`에서 연출을 재생하며, 종료하면 기존 타이틀 그림·프레임 애니메이션을 유지한 화면에 **타이틀 화면으로 가기** 버튼을 표시한다. 버튼을 누르면 skipOpening 임시 옵션을 제거하고 현재 게임 주소를 새로 열어 정상 게임 시작 타이틀로 복귀한다. 전시 세션 초기화 정책·일반 저장은 유지한다. 재생 중 버튼/Enter로 건너뛰지 않으며 끝난 뒤 클릭할 수 있다. 기존 다음 방문자 직접 재시작 패널은 이 화면으로 대체했다.

**P1 (Major) · ✅ 웹·기존 실행본 리소스 반영 / ✅ 웹 실제 18초 재생·버튼·타이틀 복귀 및 전시 엔진 테스트12개 통과 / ⏳ 사용자 최종 시각 검수.** 설치 프로그램은 재빌드하지 않았다. 아래 게임 연결 전 상태는 시안 제작 당시 이력이다.

사용자 정정: 3D 모션이 아니라 기존 오프닝 애니메이션과 같은 형식.

**P1 (Major) · ✅ 2D 그림·18초 연출 시안 제작 / ⏳ 사용자 시각 검수·게임 연결.**

- 기존 오프닝의 `journey-crayon.png`·`reflection-crayon.png`를 화풍/소망이 외형 참고로 사용했다. 크레파스·오일파스텔 질감, 펼친 그림책 테두리와 중앙 접힘을 유지한다.
- `awake.png`는 첫날 집의 나무 바닥에서 무릎을 모은 소망이, `asleep.png`는 같은 공간에서 고개를 숙이고 눈을 감은 후속 장면이다.
- 화분은 씨앗을 심은 흙만 있고 싹은 없다. 닫힌 다이어리·밤 창문을 함께 배치한다. 침대·이불·의상은 추가하지 않는다.
- `preview.html`은 기존 오프닝처럼 이미지 전환·느린 확대·밤빛·DOM 자막으로 만든 18초 연출이다. 동작 줄이기 설정에서는 최종 잠든 그림과 마지막 자막을 표시한다.
- 대사는 현재 첫날 취침 대사의 “오늘은 푹 자야겠다. 내일은 또 어떤 하루가 기다릴까…….”를 두 구간으로 나누어 표시한다.
- `preview.mp4`는 같은 두 그림과 전환을 담은 감상용 영상이다.

제작 시안만 저장했다. 오프닝 전체 길이·기존 첫날 취침·엔딩·음악·게임 리소스는 변경하지 않는다. 앞서 제작한 3D 모션은 이번 정정에 따른 채택본이 아니며 게임에 적용하지 않는다.
