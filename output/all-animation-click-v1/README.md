# 오프닝 외 연출도 대사 클릭으로 진행 — 2026-10-26

사용자 요청으로 이야기 연출의 다음 장면을 대사 클릭으로 진행하도록 통일했다.

- 버스 도착: 마을 전경→정류장 도착/하차→버스 출발/모아 발견의 3개 대사. 단계 내 동작은 재생하고, 다음 단계는 클릭한다. 마지막 자동 타이머 종료를 제거하고 전체 건너뛰기는 유지한다.
- 씨앗 심기: 씨앗 넣기→흙 덮기→물 주기→함께 자라자는 대사의 4단계. 동작이 끝나도 대사를 유지하고 마지막 대사 클릭에서만 완료 메시지를 한 번 전송한다. 모션 줄이기도 같은 클릭 순서를 사용한다.
- 신청서/휴대폰/보수/봉투/정착금/다이어리/쿠키: AnimationDialogue의 장면별 AbortSignal을 사용한다. 대사 클릭은 현재 동작을 끝 위치로 마무리하고 후속 동작을 즉시 정리한다. 실제 완료/보상은 기존 Activities.next/State.complete가 한 번만 처리한다. 기존 F 수령도 동일 완료 경로를 사용한다.
- 쿠키 먹기·드링크 마시기: 대사 클릭으로 다음 진행. 드링크는 2.2초 자동 닫기를 제거했다.
- 다이어리: 기록 중 본문 클릭으로 전체 기록 완성, 완성 후 본문 클릭으로 덮기. 완료 콜백은 한 번만 실행한다.
- 신청서/은행 제출 결과와 취침 전환: 고정 대기 대신 화면 문구를 클릭해 진행한다.
- 하품은 대사와 함께 재생하고 대사를 넘기면 동작을 정리한다. NPC 대화 패널은 본문 클릭도 다음 버튼과 동일하게 처리한다.
- 기존 오프닝·첫날 밤의 대사 클릭 유지. 이동·시험 정답 선택·포장 퍼즐·실제 주문·서류 검증은 애니메이션 클릭으로 우회하지 않는다.
- 전체 화면 씨앗/드링크/일기 뒤의 3D는 중단해 기존 60FPS 우선 정책을 유지한다.

## 적용/검증

웹과 기존 실행본 resources/web 동기화. 변경 JS 구문 검사 통과.

animationAdvance/cookieHandoff/diarySave/exhibition 테스트22개 통과: 애니메이션 조기 종료/후속 단계/잔여RAF 취소/예외 정리 및 기존 중복 보상 방지.

scratch/check-all-animation-click.cjs를 웹·기존 실행본에서 각각 실행: 12초 이상 기다려도 씨앗 장면 자동 종료 없음,4단계 클릭; 드링크 자동 종료 없음; 일기 완료/닫기1회; 다섯3D 전달 연출; 버스3단계 클릭 통과. 페이지 오류 없음.
scratch/check-animation-confirmations.cjs로 기존 실행본의 신청서/은행 제출 문구 클릭과 취침2단계 클릭/엔딩1회 확인.

설치 프로그램 재빌드와 사용자 최종 플레이 검수는 별도다.
