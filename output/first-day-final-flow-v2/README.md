# 첫날 데모 마무리 흐름 v2 · 2026-10-26

P1 (Major) · ✅ 구현 · 🔄 처음부터 플레이 검증 · ⏳ 사용자 최종 시각 검수

- 두 활동을 마친 광장 재회에서 쿠키·정착금·다이어리를 받은 뒤 작별하면, 모아가 길을 따라 안내소 문으로 들어가 의자에 앉는다. 플레이어의 잡화점·집 이동은 독립적이다.
- 첫 소식봉투는 가방에서 열어 읽은 뒤 내용 확인 퀴즈가 나온다. 오답은 재시도하고 정답 확인 후 진행한다. 이 스토리 연습 문제로 영구 분석력 보상을 임의 지급하지 않는다.
- 화분 구매·직접 퇴장 후 소망이가 피곤하니 집에서 쉬겠다고 말한다. 모아가 잡화점에 동행하거나 다시 말하지 않는다.
- 집에서는 I로 가방을 열어 씨앗용 화분의 사용하기를 눌러야 기존 제작 씨앗 심기 12초 애니메이션이 시작된다. 완료 전 planted 처리를 하지 않는다.
- 심기 후 J 다이어리 단축키 안내가 먼저 나온다. 직접 J로 열고 기록을 남겨 덮어야 다음으로 진행한다.
- 너무 졸려 자야겠다는 대사와 잠자기 버튼이 나온다. 잠자기 애니메이션 후 데모 종료 화면을 표시한다.

현재 검증:
- 대상 브라우저 UI: 찌라시 퀴즈 표시·오답·정답·확인 후 진행, I 화분 사용·씨앗 애니메이션·J 일기·잠자기 애니메이션·데모 종료 통과.
- 모아 실제 귀환: 광장→안내소 문→실내 착석 통과. 위치 137표본, 0.1초당 최대 이동 약21, 대형 위치 점프 없음.
- 처음부터 플레이 결과는 별도 최종 기록으로 추가한다.
