# 운반 프레임 순서 수정 v5

사용자가 첨부한 네 장의 순서에 맞춰 기존 v4 운반 프레임을 1기준 **3 → 2 → 1 → 4** 순서로 재배열했다. 새 시트의 운반 재생은 0→1→2→3, 프레임당160ms다. 개별 PNG·RGB·알파는 원본 바이트 그대로이며 다른 모션도 그대로다. 재생 순서뿐 아니라 시트의 실제 운반 칸과 개별 프레임 파일 순서도 함께 바꿨다.

`preview.html`은 이전/수정 순서 비교이며 운반 모션으로 열린다. `carry-order.png`는 첨부1~4에 대응하는 순서 모아보기, `qa/right_carry.gif`는 수정 재생이다. `verification.json`에 전체19논리 프레임 원본 파일 보존 검사를 기록했다. 게임 미반영 시안이다. 추가 이미지 생성이나 색 보정은 하지 않았다. 이전 전체 제작 이력은 `../dog-diagonal-walk-v4/` 이하를 따른다. 재조합은 `reorder.py`로 실행한다.
