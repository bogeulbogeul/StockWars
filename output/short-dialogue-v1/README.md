# 첫날 데모 대사 단축 — 2026-10-26

사용자 승인한 짧고 자연스러운 대사 방향을 실제 게임에 적용했다. ShortDialogue.js는 현행 계획에서 대사만 묶어 바꾸고 26개 활동의 ID·순서·완료 조건·장소 이동은 유지한다. 기존 집 우선 방문도 간단한 두 줄 소개로 유지한다. 이전 원문은 이관/기록용으로 보존하며 현행 일반 첫날 계획은 단축 대사를 사용한다.

- 잡화점 먼저 53줄, 주식 먼저 52줄. 모아의 다정한 말투·봉봉의 친근함·토리의 짧고 또렷한 설명을 사용한다.
- 이름 서명·휴대폰·은행/대출 조건 확인·포장 3상자·보수 300잎·소식봉투·시험 3문항·자격증·첫 매수·꿀쿠키·지원금/다이어리·화분·씨앗·일기·취침을 유지한다.
- 실제 문을 열어준다는 대사를 제거했다. 지도 소개는 한 문장씩, 집은 짧게 소개한다.
- 주식 하단 안내: 홈/목록/기업 정보/차트/주문 각 2단계, 계좌/거래 내역 각 1단계. 기업 정보→차트→주문 안내→확인 완료와 예산/현물1주/수수료없음 조건은 유지한다.
- 첫날 밤 첫 대사는 '낯설었지만, 조금은 알 것 같아.'로 수정했다. 클릭 진행은 유지한다.

웹·기존 실행본 resources/web에 반영. JavaScript 구문 검사, 포장/전시 테스트 22개 통과. scratch/check-short-dialogue.cjs로 실제 대사 표시·클릭·두 분기 계획·기업 정보 우선 안내·완료 해금 검증. 전체 플레이 소요 시간/사용자 최종 검수와 설치 프로그램 재빌드는 별도다.

대사집은 dialogue-packing.txt, dialogue-stock.txt에서 활동 사이 실제 출력 순서로 검토할 수 있다. 활동 중 서류/보상 수령 등의 별도 UI 문구는 각 기존 컴포넌트를 따른다.
