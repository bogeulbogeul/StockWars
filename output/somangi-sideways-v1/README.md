# 소망이 좁은 통로 옆걸음

2026-10-25 사용자 요청: 좁은 공간에서 옆으로 걷기 추가.

**P1 (Major) · ✅ 제작·웹/기존 실행본 반영·통로 동작/형상 검사 / ⏳ 사용자 최종 체감·시각 검수.**

## 동작

양쪽이 가까운 통로를 감지하면 몸을 이동 방향에 수직으로 돌리고 작은 옆걸음을 재생한다. 한쪽 벽만 가까운 곳에서는 전환하지 않는다. 잠시 멈추거나 후진해도 통로 안에서는 옆을 향한 방향을 유지하며 넓은 곳으로 나오면 일반 걷기로 복귀한다. 별도 수동 모드/3키는 추가하지 않는다.

통로 감지는 `SomangiClearance.js`의 기존 합법 위치 판정을 세 지점에서 검사한다. 두 지점 이상에서 양쪽이 가까워야 진입하며 진입/해제 여유를 다르게 해 반복 전환을 줄였다. 마을·도착·안내 동행·좌석 주변 이동은 공유 `moveTownBody`에, 실내는 기존 이동 처리에 연결한다.

옆걸음은 일반 걷기의75% 이동 속도이며 Shift로 급하게 달리지 않는다. 모션 주기는 원본0.75초, 게임 재생 배율1.1이다. 점프·착석·강제 자동 이동·먹는 동안은 통로 전환을 중지한다. 일반 이동 속도·점프 입력·기존 착석 기능은 유지한다.

벽·가구·NPC 충돌 크기나 실제 통과 가능한 범위는 줄이지 않았다. 기존에 몸이 들어갈 수 없는 틈을 통과시키는 기능이 아니다. 모델을 눌러 좁히지 않는다.

## 모델과 검증

- `somangi-sideways.blend`·`sideways.glb`: 보정된 걷기 원본의 동일 정점·연결부 웨이트·6개 본을 사용한다. 팔은 원래 내린 자세를 유지하고 다리 전체의 작은 좌우 회전만 사용한다. 새 관절은 추가하지 않는다.
- `verification.json`: 원본 정지 좌표132,191개 동일. 31시점의 상체·팔·발 표본 길이 최대 오차0.00000008 원본 단위 미만, 발 접지 변화0, 처음/끝 정점 오차0.
- `scratch/check-somangi-sideways.cjs`: 실제 `SomangiPlayer`, 이동 컨트롤러와42반경의 기존 벽 충돌로100폭 통로를 구성했다. 자동 전환·후진 방향 유지·정지·Shift 억제·통로 이탈 복귀·옆걸음 중 점프/착지·벽 통과 방지·한쪽 벽에서 일반 걷기 유지 확인. 웹·기존 실행본 각각 통과.
