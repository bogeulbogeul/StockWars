# 소망이 좁은 통로 옆걸음 v1

**폐기:** 사용자 피드백으로 이 모션은 채택하지 않는다. 후속은 [몸 회전·팔 모으기·짧은 디딤 v2](../somangi-narrow-walk-v2/README.md)다. 본 파일은 제작 이력으로만 보존하며 게임에 복원하지 않는다.

✅ 좌우 옆걸음 루프 제작 / ⏳ 사용자 시각 검수·통로 판정 및 게임 연결

기존 걷기 v4 외형·원본 미소·둥근 배와 손끝을 사용한다. 팔을 약간 앞으로 모으고 얼굴 방향을 유지한 채 옆으로 발을 벌렸다 모으는 1초 제자리 루프다. `Sidestep_Right`, `Sidestep_Left` 두 클립을 포함한다. 몸을 옆으로 세운 방향은 게임에서 캐릭터 회전으로 설정한다.

- `somangi-sidestep.blend`: 편집 원본.
- `somangi-sidestep.glb`: 좌우 클립을 포함한 모델.
- `sidestep-front.gif`, `sidestep-side.gif`: 오른쪽 옆걸음 정면·측면 프리뷰.
- `validation.json`: 양방향 루프 오차 0, 배 변형 0, 팔 길이 보존 및 발 바닥 관통 없음 검사.

발은 본 스케일을 고정하고 작은 위치 이동으로 옮긴다. 이동량은 반주기당 0.16 모델 단위이며, 게임의 실제 이동 속도에 맞춘 재생 속도·지면 고정·좁은 통로 자동 전환·충돌 폭 변경은 아직 연결하지 않았다. 기존 게임 걷기와 다른 동작 파일은 유지한다.
