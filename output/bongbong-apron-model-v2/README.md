# 봉봉 앞치마 시안 정합 수정 v2

2026-10-22 · P1 (Major) · ✅ 형태 수정·5방향 렌더·GLB 재수입 검사 / ⏳ 사용자 외형 확인·전체 모션 접촉 검수·게임 적용.

v1이 시안보다 좁고 각졌다는 사용자 피드백에 따라 별도 버전으로 수정했다. 앞판을 아래로 넓히고 밑단 모서리를 둥글게 만들었으며, 몸 실루엣을 그대로 감싸던 앞판에 여유를 주었다. 주머니 밑단은 각진 포물선에서 U자 곡선으로 변경하고 코랄 테두리와 어깨끈 폭을 늘렸다. 아이보리·코랄 재질과 프리뷰 색 변환도 조정했다. 기존 몸체 메시 정점 위치는 불변 검사를 통과했다.

`Bongbong-apron.blend`는 편집 원본, `Bongbong-apron.glb`는 착용 모델과 기존 걷기 클립, `Apron-only.glb`는 별도 앞치마와 공통 리그다. `front.png`, `left.png`, `right.png`, `back.png`, `three-quarter.png`는 실제 모델 렌더다. `build.py`로 재생성한다.

앞치마 평가 삼각형은 5,784개로 v1의 3,864개보다 늘었다. 둥근 외곽과 주머니를 표현하는 분할을 보강한 결과이며, 원본 몸체 73,602삼각형의 경량화는 수행하지 않았다. 검사는 `validation.json`과 `export-validation.json`에 기록했다. 앞판·주머니의 폭과 곡선을 시안에 가깝게 조정했으나 시안과 완전히 동일한 실루엣·조명·색으로 확정하지 않는다. 어깨끈과 옆면 여유는 후속 착용 검수 대상이며 게임 파일은 변경하지 않았다. v1은 이력으로 보존한다.
