# 프레임 드랍 1차 최적화 — 2026-10-26

## 적용

- StaticInstances: 같은 정적 geometry/material의 소품을 instanced draw로 묶는다. 원본 메시/이름/가림/충돌은 렌더 이후 그대로 복원한다. NPC/뼈/문/시계 바늘은 제외한다.
- 실내도 정적 인스턴싱과 기존 인덱스 묶음 렌더링을 사용한다. 준비 작업은 실내 로딩 단계에서 수행해 첫 표시 프레임의 추가 병합 부담을 줄인다.
- 은행 Bank_Continuous_Joined_Eaves와 쉼터 Porch_Continuous_Timber_Frame의 각 154만 삼각형을 렌더 전용 복사본 각 약4.6만으로 단순화했다. 원본 GLB·쿼리/충돌 정점은 변경하지 않았다. 원본 재질을 사용한다. 로드 실패 시 원본으로 표시한다.
- 곡면 마을 셰이더가 인스턴스의 실제 월드 좌표를 사용하도록 보완했다.
- 타이틀/스마트폰/숨긴 창 뒤의 마을·실내 GPU 렌더링을 중단하고 복귀 시 시간 기준을 갱신한다. 이동 속도·NPC/소망이 형태·보상/스토리·화면 해상도는 유지한다.

## 측정

1280×800, DPR1, headless Edge, 같은 실행 세션에서 기존 town batching을 포함한 이전 경로와 최적화 경로를 교대로 측정했다. 각 구간 1.2초 예열 후 약4초 측정. FPS는 해당 실행 환경의 표본이며 사용자 PC/모든 구간 60FPS 보장을 의미하지 않는다.

| 항목 | 수정 전 | 수정 후 |
|---|---:|---:|
| 마을 평균 FPS |48|52|
| 마을 프레임 p95 |50ms|33.4ms|
| 마을 draw calls |1,326|754|
| 마을 삼각형/프레임 |5,836,463|4,344,385|
| 안내소 평균 FPS |37|43|
| 안내소 draw calls |559|195|

독립 광장 표본에서 삼각형 7,264,176→4,279,360, draw calls 1,283→732. 최초 측정과 같은 세션 A/B 결과는 다를 수 있어 comparison.json을 우선한다. before.json/after-batching.json/after.json은 병목 분석 중간 표본이다.
