# 요정 공통 몸통 폭 조정 · 2026-10-22

사용자 요청: 봉봉 body-v3 정면·측면 시안의 좁은 몸통을 다른 캐릭터에도 적용하고 게임에 반영.

P1 (Major) · ✅ 소망이·모아·토리·봉봉 3D 수정 및 웹/로컬 실행본 리소스 반영 · ⏳ 사용자 최종 외형·모든 동작의 의상 접촉 검수.

## 적용

- `Eating_Torso`의 좌우 폭을 88%로 수정. 깊이·높이·머리·팔·다리·표정·장식·본·웨이트·기존 모션은 유지한다. 이미지 한 장의 형태를 정확히 복원한 모델이라는 뜻은 아니다.
- 모아/토리 조끼와 봉봉 앞치마·어깨끈·허리끈도 같은 폭으로 조정한다. 팔은 보존하므로 정면 시안에서 달라진 팔 위치까지 복제하지 않는다.
- 소망이 걷기·인사·먹기·점프·게걸음·의자 앉기 6종, 모아 벤치 앉기·졸기 2종, 토리, 안내소 내부에 포함된 모아, 봉봉 등 총 11개 GLB를 제작했다.
- 봉봉은 최신 앞치마 v3 모델을 잡화점 계산대 오른쪽에 배치했다. 기존 GLB가 머리/발의 살구색 곱셈을 누락한 점을 재질의 `baseColorFactor`로 수정했다. 얼굴 텍스처는 유지한다. 충돌 영역도 추가했다.
- `web/`와 `electron-app/dist/win-unpacked/resources/web/`에 반영했다. 설치 프로그램은 재빌드하지 않았다.

## 검증과 원본

`build.cjs`는 원본을 `original/`에 보존하고, 몸통/의상 위치·법선 버퍼만 변경한다. `validation.json`에 원본·결과 SHA-256, 클립 이름, 비대상 accessor 바이트 동일 검사를 기록한다. 머리 메시를 포함한 나머지 정점·UV·인덱스·본·모프·애니메이션 accessor는 원본과 같다.

`render.py`로 네 캐릭터 정면·오른쪽 측면의 실제 GLB 렌더 8장을 확인했다. `scratch/check-fairy-body-narrow.cjs`는 웹/실행본 리소스의 걷기·인사·먹기·점프·게걸음, 집·잡화점·안내소·증권사 모델 로딩, 봉봉 존재·충돌, 런타임/에셋 오류를 검사한다. 로그는 `browser.log`, `browser-runtime.log`, 화면은 `game-*.png`다. 전 프레임 의상 관통이나 모든 가구 접촉 검수는 별도다.

## 미제작 주민

우디·차곡·도란·보니·소담·두리는 현재 이미지 시안만 있으며 게임용 3D 모델이 없다. 이 주민들도 신규 모델 제작 시 큰 머리는 유지하고 본 공통 몸통 폭 기준을 따른다. 이번에 이 여섯 주민의 이미지·모델·게임 배치를 완료한 것으로 기록하지 않는다. 이전 외형·제작 원본과 폐기 상태는 보존한다.
