# 차도 벤치·꽃 정리 v7

P2 · ✅ 웹·기존 실행본 반영·자동 검증 / ⏳ 사용자 최종 시각·플레이 검수

사용자가 지적한 차도 위 `garden_bench_gate`를 `(1460,2450)`에서 정류장 뒤쪽 잔디 `(800,2190)`로 옮겼다. 주변 점검에서 차도/갓길과 겹치던 정류장 꽃 중심 `(770,2370)`도 `(770,2290)`으로, 입구 꽃 중심 `(1950,2350)`을 `(2100,2270)`으로 이동했다. 벤치 모델·정류장·모아·도로·건물·길은 변경하지 않았다.

`townGardenProps.js`를 웹과 기존 실행본에 동기화했다. `scratch/check-current-exteriors.cjs`에서 모든 배포 소품의 실제 Box3를 지면 좌표에 투영해 차도와 갓길 구간에 겹치는 소품이0건인지 검사했다. 양쪽 모두 `roadObstructions: []`이며 길 선분·둥근 모서리 차단0건·모든 입구 도달·로딩·시계·작은 화면·JavaScript 오류 검사도 통과했다. `web-checks.json`·`desktop-checks.json`에 저장했다. 설치 프로그램은 재빌드하지 않았다.
