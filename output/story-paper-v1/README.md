# 공통 신청서 3D v1

2026-10-24 · P1 (Major) · ✅ 종이 1장 제작·GLB 재불러오기·구조 검사 / ⏳ 사용자 외형 검수·게임 배치·전달/서명 접촉 검수.

입주 신청서·은행계좌 신청서·주식계좌 신청서에 공통 사용하기 위한 소품이다. `reference.png` 중앙의 단일 종이를 참고해 크림색 종이 1장과 회색 입력칸·서명선을 제작했다. 제목·실제 글자·도장·서명은 포함하지 않는다. 뒷면은 빈 종이다.

- `StoryApplicationPaper.glb`: 독립 3D 에셋. 종이 메시 1개와 인쇄 표시 메시 1개, 루트와 앞면 기준점. 텍스처 파일 불필요.
- `StoryApplicationPaper.blend`: 편집 원본·검수 스튜디오. 바닥·카메라·조명은 GLB에 포함하지 않는다.
- `preview.png`, `front.png`, `edge.png`: 실제 모델의 사선·정면·낮은 각도 렌더.
- `build.py`, `manifest.json`: Blender 5.2 재현 스크립트와 검사 기록.

임시 제작 크기는 H=1 기준 폭 0.29H·길이 0.41H·두께 0.0008H다. 종이를 평평하게 놓은 밑면 중앙이 원점이다. Blender 앞면은 +Z, 서류 상단은 +Y이고 glTF에서는 각각 +Y, -Z다. 글자처럼 보이는 선은 종이 표면보다 0.00001H 위의 평면 메시로 표현하며 실제 양각이 아니다. 정확한 게임 배율·손 접촉·서명 입력 UI·신청 종류별 표시 전환은 후속 적용 대상이다.

한 장인 종이의 폐곡면·양의 부피·유한 좌표를 검사하고 내보낸 GLB를 재불러와 메시 수와 치수를 확인했다. 인쇄는 의도적으로 열린 평면 메시다. 게임 코드·배포 리소스·저장은 변경하지 않았다.
