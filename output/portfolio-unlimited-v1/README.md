# 종목 보유 개수 제한 제거 — 2026-10-25

사용자 요청으로 종목 슬롯 5개 제한과 내 계좌 슬롯 표시를 제거했다. 시장가·지정가 등록/체결·공매도의 공통 검증에서 종목 개수 제한을 삭제했다. 호환용 portfolioSlots()는 Infinity, 화면 상태 portfolioSlots는 null이다. 기존 보유/저장 기록은 이관 없이 유지한다. 사용하지 않는 구형 계좌의 슬롯 표시를 숨기고 구형 안내 대본의 슬롯 수업도 제외했다. 폐기 화면을 복원하지 않았다.

현금·수량·수수료·레버리지/공매도 레벨 조건·전시 첫 매수 정책은 유지한다. 대기 주문 개수 한도는 보유 종목 제한과 다른 기존 규칙이다.

23개 관련 엔진 테스트 통과: 72개 종목 동시 보유·재연결 이후 매수/매도·기존 5개 슬롯 제공자가 있어도 신규 매수·즉시/대기 지정가 체결·신규 공매도·현금 부족 차단. scratch/check-stock-layout.cjs로 표시/거래 회귀를 확인한다. hashes.json의 5개 파일을 기존 실행본 resources/web에도 반영했다. 설치 프로그램 재빌드와 사용자 최종 플레이 검수는 별도다.

실제 통합 게임 시작 검증은 별도 진행 중인 DoorwayTraversal.js의 doorwayFade export 로딩 오류로 완료하지 못했다. 이번 변경과 무관한 해당 파일은 수정하지 않았다. 대신 scratch/check-unlimited-account.cjs로 게임 시작을 거치지 않고 실제 시장 엔진·ItemEngine·StockApp을 결합해 72개 전 종목 매수 및 계좌 카드 72개/슬롯 안내 없음의 브라우저 검증을 수행했다.

## 투자 비중 색상 통일

도넛 그래프와 범례의 순서 기반 색상 배열을 StockBrand.js의 sectorColor(key)로 교체했다. 종목 아이콘·검색 필터·투자 비중이 같은 섹터 색을 사용하며 보유 순서가 달라도 바뀌지 않는다. 8개 섹터의 실제 범례/도넛 CSS 색상이 공통 팔레트와 일치하는지 웹·실행본 리소스에서 검증했다.

## 거래 내역 별도 탭

사용자 요청으로 홈/주식 거래/내 계좌 다음에 거래 내역 탭을 추가했다. 계좌 하단의 접기 목록은 제거하고 historyScreen에서 최신순 체결 기록·수량·가격·수수료·현금·실현 손익·시각/거래 장소·개별 체결을 그대로 표시한다. 일반 계좌와 전시의 같은 컴포넌트를 사용하며 기존 저장/경제 계산은 유지한다. 가격 갱신 때 거래 내역 탭도 갱신하고 스크롤 위치를 보존한다. 72건 표시·계좌에서 내역 제거·탭 선택 상태·진입 시 스크롤 초기화·데스크탑/모바일 접근을 브라우저로 검증했다.

## 컴퓨터 끄기 버튼

사용자가 주식 앱 창 닫기로 동작을 확정했다. 데스크탑 왼쪽 메뉴 맨 아래에 전원 아이콘/컴퓨터 끄기 버튼을 추가하고 mountStockPhoneApp의 onClose를 PhoneHome.close에 연결했다. 실제 컴퓨터/게임 종료나 계좌 변경은 하지 않는다. 기존 close 이벤트의 앱 구독 해제를 사용한다. 모바일은 기존 닫기 버튼을 유지한다. 데스크탑 표시·모바일 숨김·클릭 후 dialog 닫힘/StockApp 정리를 브라우저로 확인했다.
