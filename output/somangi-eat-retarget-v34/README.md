# 소망이 작은 먹기 동작 v34

현재 v33 외형을 유지하고 폐기 직전 보존된 `character-assets-retired-2026-10-23/web/assets/characters/3d/somangi/eat.glb`의 팔·고개 회전 타이밍을 참고했다. 이어서 사용자가 준 [애플이 샌드위치 먹는 영상](https://www.youtube.com/shorts/qySJisd92ZM)을 브라우저에서 확인하고, 음식을 든 자세를 유지하는 작은 먹기 표현으로 진폭을 줄였다.

## 최종 동작

- 팔꿈치·아래팔 본 없이 팔 전체가 단일 가중치 1로 회전한다. 이전 모션의 변화량을 22%만 반영해 팔을 크게 올리지 않는다.
- 고개는 이전 변화량의 18%, 최대 약 5.02도로 작게 움직인다. 머리와 표정 메시가 함께 움직인다.
- 입은 작게 오물거리는 크기로 조정하고 원본 얼굴 표면에 다시 맞췄다. 쉬는 동안에는 원래 U자 미소와 검은 눈을 유지한다.
- 빵은 3회 같은 선형 크기 비율로 줄어든다. 손이 빵 크기를 따라 좁혀지지 않으며, 모두 먹으면 원래 기본 자세로 돌아간다.

## 검증

v33 대비 캐릭터 몸체 메시의 정점 좌표 차이 0, 폴리곤 구조 동일. 새로운 팔 관절은 없으며 본은 Body / Arm.L / Arm.R / Head다. 정지 외형을 다시 조형하지 않고 기존 메시의 회전 동작과 작은 입 표현만 수정했다.

181개 반 프레임 표본에서 팔 끝쪽/머리, 빵/머리, 빵/몸통의 표면 교차 표본은 0이었다. 의도적인 어깨 안쪽 겹침은 팔 끝쪽 검사에 포함하지 않는다. 고정 몸통 영역의 위치 변화는 0이다. 팔 모서리 길이 상대 수치 오차는 약 0.0067% 이하, 머리는 약 0.0020% 이하이며 스케일·팔 굽힘 키는 추가하지 않았다. 마지막 자세는 v33 기본형과 최대 1.20e-7 모델 단위 차이다. 수치는 `verification.json`을 따른다.
