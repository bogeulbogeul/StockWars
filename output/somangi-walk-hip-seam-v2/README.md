# 소망이 걷기 다리 연결 보정

사용자 요청: 걷는 동안 다리와 몸통 사이가 벌어져 보이지 않도록, 원본 외형을 유지해 수정.

**P1 (Major) · ✅ 제작·웹/기존 실행본 반영·자동 검사·실제 GLB 촬영 / ⏳ 사용자 최종 시각·플레이 검수.**

## 변경

기존 X=0 기준의 좌우 다리 웨이트 급변이 중앙 연결면을 서로 반대 방향으로 당겨 접었다. 상부는 몸통에서 두 다리로 연속적으로 섞고, 중앙에서 좌우 영향도도 부드럽게 섞는다. 아래쪽에서는 혼합 폭을 줄여 발은 기존 한 다리 본만 따르도록 했다. 원본 정점 좌표·토폴로지·본·걸음 속도·회전 키·머리·몸통·팔·얼굴은 변경하지 않았다.

제작 소스는 `../somangi-game-v1/build_walk.py`이며 수정 전은 `before.blend`·`before.glb`로 보존했다. 현재 모델은 `../../web/assets/characters/3d/somangi/walk.glb`다. 동일 GLB와 매니페스트를 기존 실행본에도 반영했다.

## 검증

- `hip-verification.json`: 원본 132,191개 정점 좌표 동일. 31시점에서 하체 열린 경계 0. 틈이 생기던 중앙 영역의 90도 초과 법선 변화는 최대178개에서0개로 감소했다.
- 중앙 외 작은 삼각면의 90도 초과 법선 변화는 최대7개가 남는다. 이 진단값을 전체 메시의 뒤집힘/교차 0건으로 해석하지 않는다. 실제 정면·측면 30프레임씩에서 기존 중앙 갈라짐이 보이지 않음을 확인했다.
- `../somangi-game-v1/walk-verification.json`: 원본 정지 좌표, 몸통·팔·발 길이, 반복 처음/끝 일치를 검사한다.
- `scratch/check-somangi-walk-height.cjs`: 웹·기존 실행본 각각61시점, 키 범위100~100.98 게임 단위·발 접지 오차0.025 게임 단위 이내·주기 처음/끝 정점 오차0. 이전 세로 누적 문제도 재검사했다.
- `walk-front.gif`·`walk-side.gif`: 실제 설치 GLB를 게임 로더로 촬영. 고정 배율, 40fps·0.75초 반복이며 게임 장면 캡처와 구분한다.
