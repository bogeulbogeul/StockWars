# 걷기 v2 — 배 형태 안정화

사용자 요청에 따라 v1의 눈색 수정 모델에서 다리 웨이트가 배를 끌어당기는 범위를 줄였다. 원본 메시·색상·무광 재질·7본·걷기 클립·보폭·재생 속도는 유지했다. v1 원본은 덮어쓰지 않았다.

- 배 중심은 Body 본을 따라 형태를 유지한다. 몸 전체의 작은 들썩임은 기존대로 유지한다.
- 다리 웨이트는 골반 아래의 짧은 연결 구간에서만 부드럽게 전환한다. 지지발·루프·GLB 재수입 검사는 `validation.json`에 기록한다.
- `belly-validation.json`은 배 중심 정점의 Body 본 대비 변형을 전후 비교한다. 범위는 z -0.63~-0.20, |x|<0.27이며 전체 모델 표면을 무변형으로 판정하는 검사는 아니다.
- 정면·측면 각각 24프레임을 실제 모델에서 렌더했다. GIF는 검은 눈 보존용 공통 팔레트를 사용하고 디코딩한 프레임의 어두운 픽셀 색을 다시 검사한다.

## 결과

- `somangi-walk.glb`: 수정된 웨이트·재질·걷기 클립.
- `somangi-walk.blend`: 수정 편집본.
- `walk-front.gif`, `walk-side.gif`: 수정 걷기 미리보기.
- `contact-sheet.png`: 정면·측면 주요 자세 비교.

✅ 모델 웨이트 수정·배 변형 비교·접지/루프 검사·GLB 재수입 확인. ⏳ 게임 이동·전환·실시간 검수는 별도다. 기존 파일과 게임 파일은 변경하지 않았다.
