# 게시판 2D 재디자인 v3

실제 게시판의 곡선 머리판·새싹 표식·나무틀·황동 압정을 HTML/CSS/인라인 SVG로 재해석했다. 3D 렌더 이미지를 UI 배경으로 사용하지 않는다. 밝은 아이보리 공고 3장과 상자/새싹/벤치 선화, 큰 제목과 설명을 사용한다. 모바일은 공고를 세로로 배치한다.

기존 근접 F키/버튼 열기, 공고 클릭 확대, 게시판 복귀, Esc 닫기, 이야기 확인 콜백을 유지한다. 원본 3D 게임 게시판과 배치·충돌·저장은 변경하지 않았다. 웹·기존 실행본 resources/web에 동일 소스 반영. 설치 프로그램 재빌드 없음.

검증: node web/tests/villageBoard.browser.cjs
데스크톱/390px 모바일, 공고 선택·확대·복귀·확인·닫기·가로 넘침 및 JS 오류 0건 통과. preview.png/mobile.png/notice.png는 실제 브라우저 렌더. 전체 게임 플레이 사용자 최종 검수는 별도다.
