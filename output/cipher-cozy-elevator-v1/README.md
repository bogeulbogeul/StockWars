# 사이퍼 증권 포근한 엘리베이터 v1

사용자 참고의 위쪽 모서리가 둥근 아이보리 외곽·파란 안쪽 프레임·은회색 양문·별도 원형 호출 버튼을 Blender로 제작했습니다.

- `Cipher-cozy-elevator.blend/.glb`: 수정 가능한 원본/게임 모델.
- `elevator-preview.png`: 모델 렌더.
- `game-elevator.png`: 게임 배치 화면.
- 제작 스크립트와 `exterior_geometry.py`: 재제작용.

외곽 폭 1.72·높이 2.26, 게임은 100배로 기존 현관 오른편에 설치합니다.
위/아래 버튼과 층 표시는 외형이며 실제 호출·문 열림·층 이동 기능은 아직 없습니다.
GLB에 스튜디오 배경/조명을 포함하지 않습니다.
게임과 실행본에 반영했으며 기존 충돌·현관/엘리베이터 접근·로비 출입을 검증했습니다.
어두워지는 나가는 입구 통로는 변경하지 않았습니다.
