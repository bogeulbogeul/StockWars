# 소망이 점프 착석 모션

## 낮은 점프 v2

사용자 피드백에 따라 이전 v1보다 점프 궤적을 낮췄다. 루트 최고 높이는 약 0.744에서 0.447로 낮아졌고, 공중 구간은 0.75초에서 0.55초로 줄였다. 벤치 착석 위치와 원본 메시·UV는 동일하다. 기존 v1은 별도 폴더에 보존했다.

- ✅ 완료: 실제 마을 에셋 `web/assets/props/3d/Bench-clean.glb` 높이에 맞춘 도약 → 착석 → 유지.
- ✅ 완료: 원본 메시 정점·면·UV 해시 일치. 외형을 수정하지 않고 기존 스키닝으로 동작.
- ✅ 완료: 내보낸 GLB 361개 시점에서 관절 경계 간격, 바닥 아래 정점, 벤치 내부 정점 검출값 0.
- ⏳ 대기: 게임 적용. 기존 게임 캐릭터나 마을 파일은 변경하지 않음.

## 파일과 클립

`somangi-jump-sit.glb`: 캐릭터와 애니메이션. 벤치는 미리보기에서만 사용.
`somangi-jump-sit.blend`: 편집 원본.
`jump-sit-preview.gif`: 정면·측면 동시 재생.

- `Jump_Sit`: 1.2초. 준비 후 점프하고 벤치에 착석.
- `Town_Bench_Idle`: 1초. 착석 유지.
- `Jump_Sit_Preview`: 2.3초. 시작·종료 유지가 포함된 검수용.
- `Walk_InPlace`: 이전 걷기 원본 애니메이션 보존.

## 배치와 검증 범위

벤치 원본의 상대 배율은 캐릭터 좌표계 기준 1.73333333이며 바닥 Z=-0.950643, 벤치 중심 Y=0.67693333이다. 점프 클립에 루트 이동이 포함되므로 별도 착석 오프셋을 중복 적용하지 않는다. 최종 루트 이동은 Y=0.28, Z=0.32229209이다.

형태 비교 기준은 `../somangi-sit-v1/somangi-sit.blend`의 메시다. 수치 검사는 샘플 시점의 정점과 벤치 표면을 대상으로 하며 모든 삼각형 간 연속 충돌을 증명하는 검사는 아니다. 정면·측면·사선 렌더도 함께 확인한다. 수치는 `validation.json`, 제작 설정은 `metadata.json`에 기록했다.
