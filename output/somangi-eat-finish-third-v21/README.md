# 소망이 먹기 — 세 번째 한입 후 음식 소진 v21

P1 (Major) · ✅ 수정·검증 / ⏳ 사용자 모션 검수

기존 세 번 먹기 모션에서 세 번째 한입을 마무리하면 빵과 윗면 장식이 모두 사라지도록 수정했다. 첫 두 번의 음식 크기 변화와 잡는 위치는 유지하고, 세 번째 구간(1.77~1.9초)에만 음식 전체의 소비 배율을 0까지 줄인다. 1.9초부터 클립 끝까지 음식이 없는 상태를 유지한다.

캐릭터·입·미소 가림면의 정점 및 모양 키 데이터는 v20과 해시가 동일하다. 음식의 기존 위치·회전·크기 트랙을 수정하지 않고 음식 하위의 소비 노드에 별도 배율을 적용했다. 음식과 장식 메시의 기존 상대 변환도 유지한다. 캐릭터 외형·팔·손·먹기 동작은 변경하지 않았다.

## 검증

- 첫 두 번의 음식 변환 차이 최대 0.000000002, 음식 위치·회전·기존 크기 트랙 차이 0.
- 최종 GLB 재수입 후 181개 시점 검사. 세 번째 한입 이후 67개 표본에서 소비 배율 0, 모든 음식 메시의 실제 폭·높이·깊이 0.
- 이후 프레임에도 음식이 다시 나타나지 않음.

`somangi-eat.glb`는 전달용, `somangi-eat.blend`는 편집용이며 검사 결과는 `validation.json`에 기록했다. `eat-three-bites.gif`는 마지막에 음식이 없는 상태로 끝나는 1회 재생 미리보기다. 게임에 설치하지 않았고 이전 버전을 보존했다.
