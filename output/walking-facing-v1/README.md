# 실제 이동 방향 기준 몸 회전

SomangiPlayer는 이동 중 실제 X/Z 좌표 변화로 몸 회전각을 계산하고 기본 facing도 함께 맞춘다. 대화/착석의 회전 고정은 이동 시 해제하며 기존 좁은 통로 옆걸음과 정지 대화 방향은 유지한다. W/S 키의 이동 좌표 방향은 변경하지 않았다.

`scratch/check-walking-facing.cjs`: 안내소→은행 이동 대기 상태를 준비하는 집중 fixture에서 실제 W/S 입력을 사용했다. W는 Z 감소/몸 회전 PI/뒷모습, S는 Z 증가/몸 회전 0/앞모습으로 일치함을 좌표·회전·스크린샷으로 확인했다. 브라우저 오류 0. 처음부터 전체 플레이 및 사용자 스크린샷 당시 상태의 완전 재현은 아니다. 관련 Node 테스트 19개 통과. 웹/기존 실행본 SomangiPlayer.js 동기화. 설치 프로그램 재빌드하지 않음.
