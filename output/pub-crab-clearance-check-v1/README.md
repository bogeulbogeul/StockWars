# 펍 의자 사이 게걸음 접촉 검수

2026-10-20 · P1 (Major)

현재 게임 채택 `somangi-crab-walk-v4`의 `Crab_Left`를 사용했다. 증권사처럼 룸 1단위=게임 100단위, 소망이 키 1.0을 가정하고 현재 의자 배치(카운터와 간격 .60) 사이 중앙 y=.30을 이동시켰다. 펍의 실제 런타임 배율은 아직 연결 전이다.

- ✅ 97개 위치/자세의 실제 변형 메시와 카운터·목재 띠·의자 메시를 삼각형 BVH로 검사: 교차 0건.
- 가장 좁은 보수적 여유: 약 .0392 룸 단위(위 배율에서 3.92 게임 단위). 타이트하므로 다른 캐릭터·애니메이션은 별도 검사한다.
- `crab-passage.gif`: 통과 과정을 압축해서 빠르게 재생한 24개 표본 영상. 걸음 위상은 이동 거리/게임의 13.5 기준에 맞췄으며 영상 속도가 실시간 게임 이동 속도를 뜻하지 않는다.
- `contact-sheet.png`: 통과 중 4개 위치.
- `validation.json`: 메시 접촉 결과, `Pub-crab-contact-preview.blend`: 검수 장면.
- `auto-proxy.json`: 기존 자동 게걸음 함수를 반경 22의 임시 펍 충돌 프록시로 검사한 결과. 의자 앞에서는 진입하고 의자 사이 빈 곳에서는 해제/재진입한다. 실제 펍 충돌 목록이나 실행 게임을 검수한 결과는 아니다.
