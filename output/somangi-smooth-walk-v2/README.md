# 소망이 걷기 v2 — 배 유지·팔 흔들림 — 2026-10-23

P1 (Major) · ✅ 구조 수정·GLB 재수입 97시점 검사·정면/측면 미리보기 / ⏳ 사용자 모션 검수.

사용자가 v1의 배가 잘리는 듯한 변형과 팔 움직임 부족을 지적했다. `output/somangi-walk-v4/build.py`의 이전 소망이 걷기와 `output/somangi-eat-v3/structure.py`의 몸통/팔 분리 방식을 참고했다. 과거 캐릭터 게임 리소스를 복원하지 않았고 현행 게임은 변경하지 않았다.

## 수정

- 배에 다리 가중치가 섞이던 v1의 연결 구조를 교체했다. 새 Meshy 모델의 실제 단면을 측정해 별도의 매끈한 몸통을 구성하고, 몸통은 Root 이동만 따라가며 형태를 유지한다.
- 얼굴을 다듬은 현재 모델의 머리·표정·다리·발을 사용한다. 허벅지 윗단을 몸통 안쪽으로 연장해 보행 중 연결이 벌어지지 않도록 했다.
- 팔은 몸통과 독립된 둥근 캡슐 형태로 구성했다. 현재 체형에 맞춰 어깨·길이·두께를 조정하고 어깨 윗단이 몸통에 묻히도록 했다. 원본의 모든 정점을 그대로 유지하는 스키닝 수정은 아니며 몸통·팔의 제작용 메시를 새로 구성했다.
- 이전 걷기의 다리 ±24도·양팔 ±18도 반대 교대·0.75초 주기·Root 접지 보정을 적용했다. v1의 별도 다리 들기 위치 트랙은 제거했다.

## 검증

내보낸 GLB를 재수입해 97개 시점을 검사했다. `validation.json` 참조.

- 몸통의 이동을 제외한 형태 오차: 약 7.51e-9 모델 단위.
- 머리/다리와 팔의 시작·끝 루프 오차: 0.
- 지지 발 바닥 아래 오차 최대 약 0.000375, 위쪽 오차 최대 약 0.000440.
- 각 다리 윗단에서 몸통 안에 들어간 정점 최소 653개, 각 어깨에서 최소 293개.
- 팔 정점의 움직임 최대 약 0.231 모델 단위, 비정상 좌표 없음.

겹침 정점 검사는 모든 표면의 완전한 무간섭이나 실제 이동 속도와 일치하는 발 고정 IK를 보장하지 않는다. GIF는 새 GLB의 재수입 결과를 촬영했다. 사용자 최종 시각 검수와 게임 적용은 별도다.
