# 소망이 어깨 연결 수정 시안 v31

기존 팔 분리 영역에 몸통 옆면이 포함되어 팔을 들면 어깨 접합면이 드러났다. 원본 어깨·위팔·머리·몸통·다리는 고정하고, 실제 아래팔 부분을 다시 분리해 회전하도록 변경했다. 원본 상체에 긴 접합 덮개를 추가하지 않는다. 팔꿈치 내부 연결면은 원본 팔 볼륨 안에 둔다.

아래팔은 강체 회전하며 양손 간격은 음식 크기에 따라 좁아지지 않는다. 작은 먹기 동작, 3회 동일 선형 크기 감소(1 → 2/3 → 1/3 → 0), 마지막 기본 자세 복귀를 포함한다. 빵은 얼굴에 직접 밀어 넣지 않는다. 빵의 앞뒤 두께를 줄이고 손 앞에 배치해 몸통 교차와 초기 손 사이 간격을 줄였다. 작아진 음식에 맞춰 손이 좁혀지지는 않는다.

## 검증

- 원본 기본 자세의 정점 위치 최대 차이: 8.72e-8 모델 단위.
- 181개 반 프레임 표본에서 어깨·위팔·머리·몸통·다리의 위치 변화: 0.
- 아래팔 모서리 길이 최대 상대 수치 오차: 약 0.041%.
- 아래팔/얼굴, 아래팔/몸통, 빵/얼굴, 빵/몸통 표면 교차: 모두 0개 표본.
- 음식이 있는 구간의 양손 좌우 간격 변화: 1.20e-6 모델 단위 이하.
- 팔꿈치 안쪽의 의도적인 연결 겹침은 충돌 검사에서 제외한다. 팔꿈치 경계에는 작은 이음선이 보일 수 있다.

`verification.json`은 Blender 작업 원본 검사다. 미리보기는 내보낸 GLB를 다시 불러와 렌더링한다. 게임에는 설치하지 않은 제작 시안이다.

- `somangi-eat.blend`: 편집 원본
- `somangi-eat.glb`: 내보낸 애니메이션
- `eat-front.gif`, `eat-both-sides.gif`: 정면 및 양쪽 옆 미리보기
