# 증권사 네 부위 틈 보정 v22

사용자가 첨부한 박공/파란 지붕 테두리, 오른쪽 외측 처마, 기둥 받침 사이, 기초 하단의 틈을 실제 메시로 보정했다. v21의 지붕 비율·간판 마크/여백을 유지한다. 게임 파일은 교체하지 않았다.

- 박공 앞면에 연속 삼각 채움 면을 넣어 파란 지붕 끝과 크림색 틀 사이를 연결했다. 새 면은 지붕 마감 뒤에 맞물린다.
- 양쪽 날개 바깥쪽 긴 처마 끝을 닫힌 파란색 마감으로 연결했다.
- 사선 모서리 기와는 윗부분 높이를 유지하면서 양쪽 발이 경사 지붕 안에 묻히도록 단면을 다시 제작했다. 모서리 기와 아래의 긴 검은 틈도 닫았다.
- 기둥 받침은 좌우 각 한 개의 연속된 닫힌 받침으로 정리해 맞닿은 베벨 사이의 세로 틈을 없앴다. 원기둥 네 개는 유지한다.
- 기존 기초 띠 하단이 모서리 발보다 높던 부분을 같은 Z=0 접지면에 맞췄다. 합쳐진 정점과 퇴화한 모서리를 정리했으며, 미리보기 바닥도 같은 면으로 맞췄다. 게임에서 모델 하단을 기준으로 접지해도 틈이 다시 생기지 않는 방식이다.

`CipherSecurities-clock.glb`는 전달 모델, `CipherSecurities-sealed-junctions.blend`는 편집 원본이다. `front-right.png`는 실제 전체 렌더이며 `gable-detail.png`, `right-eave-detail.png`, `plinth-detail.png`, `foundation-detail.png`는 네 부위의 실제 확대 렌더다. `manifest.json`에 변경 범위와 해시, `validation.json`에 GLB 구조 검사를 기록한다.
