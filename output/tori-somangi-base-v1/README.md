# 소망이 기반 토리 기본형 v1 — 2026-10-25

P1 (Major) · ✅ 모델 제작·몸체 정점 보존 검사·GLB 재수입 렌더 / ⏳ 사용자 외형 검수·게임 적용.

사용자 요청 “소망이 캐릭터 가져와서 토리 캐릭터 만들어줘”에 따라 최신 소망이 제작 원본 `../somangi-game-v1/somangi-walk.blend`를 가져왔다. 머리·몸통·팔·다리 정점과 기본 U 미소를 유지하고 청회색 몸 `#B8C2D9`로 변경했다. 현행 토리 `../agent-k-glasses-v6/Agent-K.blend`에서 둥근 안경과 파란 결정·받침만 가져와 현재 Head 본에 연결했다. 과거 토리 몸과 조끼는 가져오지 않았다. 의상 제작 중단 기준을 따른다.

세 이미지는 전달 GLB를 다시 불러온 실제 모델의 휴지 자세 렌더이며 같은 정투영 배율이다. 몸체 정점 변화는 0이고 두 제작 원본의 SHA256이 변경되지 않았음을 검사했다. 정면의 눈·안경 가독성, 정측면의 체형·안경 위치, 후면의 체형·결정을 시각 확인했다. 기존 걷기 트랙을 포함하되 모든 모션의 접촉 검사와 토리 전용 무표정·14종 표정은 이번 제작 범위에 포함하지 않는다.

웹·기존 로컬 실행본·저장은 변경하지 않았다. 이번 제작본은 사용자 채택 전이며 게임 적용과 구분한다. sprite-gen은 작업 진입 시 참고했으나 생성 이미지나 스프라이트가 필요한 작업이 아니므로 생성 파이프라인은 실행하지 않고 Blender의 기존 실제 3D 원본을 편집했다.
