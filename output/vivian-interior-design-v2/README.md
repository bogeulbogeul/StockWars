# 비비안 잡화점 실내 디자인 v2

2026-10-19 사용자 정정: 증권사 게임 화면처럼 입구에서 뒤벽을 향하는 정면 중심 3D 구조를 사용한다. 뒤벽은 수평, 좌우 벽은 양옆으로 이어지고 출입구는 하단 중앙이다. v1의 대각선 코너 구도는 대체한다.

✅ built-in image_gen 디자인 시안 제작 / ⏳ 사용자 시각 채택·실제 3D 모델·게임 적용·동선/접촉 검수.

외관의 코랄·크림·꿀색 나무와 무광 표면을 유지한다. 중앙 뒤쪽에 전달/계산대, 왼쪽 벽 상품 진열대, 뒤 왼쪽 음료 냉장고, 뒤 오른쪽 포장대, 오른쪽 벽 낮은 진열대와 측면 창을 배치한다. 후면 창은 없고 중앙 입구에서 계산대까지 통로를 비운다. 증권사의 엘리베이터·전광판·옆문을 잡화점 기능으로 승계하지 않는다.

생성 프롬프트 요약: 사용자 첨부 증권사 화면은 방 구조/정면 카메라 참고, v1은 배색/가구 참고로만 사용. 좌우 대칭으로 보이는 직사각형 방, 검정 외부 배경, 천장/앞벽 절개, 중앙 하단 입구, 벽 쪽 진열/포장 가구, 짧은 주문 작업 동선, 캐릭터·UI·문자 없음. 정확한 치수와 통로 폭은 후속 검증 대상.
