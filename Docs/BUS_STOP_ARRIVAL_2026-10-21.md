WASD 조작은 계속 가능하며 길을 비키면 모아가 재개한다.0.6초 이상 출구가 막히면 움직이기 전 안내에 길을 비켜달라는 문구를 표시하고 플레이어 실제 이동 후에는 다시 숨긴다. 웹/기존 실행본 반영. 실제 마지막 다음 버튼→예외 없음·플레이어 정지 유지·D로 비킨 뒤 모아 이동 재개와 기존 테스트11개를 확인했다.

### 후속: 플레이어 자동 우회
사용자 요청으로 길을 비켜달라고 기다리던 방식을 `TourDetour.js`의 국소 우회로 교체했다. 기본 길 경로에서 소망이와 간격이 부족하면 주변 지형/건물 충돌·소망이 몸체를 피하는 경로를 다시 찾아 앞쪽 길에 합류한다. 좁은 길에서는 소망이 주변의 제한된 구간만 길 가장자리 밖을 허용하고 마을 전체 잔디 지름길은 사용하지 않는다. 플레이어를 마을 전체의 고정 장애물로 처리해 큰 길을 왕복하지 않게 했다. 소망이 위치·방향·수동 이동과 F 대화·이동 시 안내 숨김은 유지한다. 웹/기존 실행본 가구점 마지막 다음 버튼부터 소망이x850/y2048 고정 상태에서 모아가 우회 후 길에 복귀하는 것과 기존 테스트11개를 확인했다.

### 후속: 대화와 무관하게 상시 가림 제거
사용자 요청으로 대화창 표시 조건을 제거했다. 이동/정지/대화 여부와 관계없이 화면 안의 소망이·모아를 카메라에서 가리는 사물과 접촉 그림자를 잠시 숨긴다. 화면 밖 NPC를 향한 시선으로 관계없는 배경이 사라지지 않도록 화면 범위를 확인하며 카메라가 나무/지붕 경계 안에 들어간 경우도 처리한다. 가림이 해소되면 원래 visible 상태로 복원하며 재질·위치·충돌은 유지한다. 웹/기존 실행본에서 대사창 없는 상태의 앞 나무7메시 숨김·재질 비변경·카메라 이동 후 기존 가시성/그림자 복원을 확인했다. 이전 대화 한정 정책보다 이번 요청을 우선한다.

### 후속: 대화 종료 후 카메라 흔들림 수정
ConversationCamera는 대화가 끝난 뒤 마지막 투샷 위치/회전을 고정해 이동 시점으로 복귀한다. 이전에는 복귀0.8초 동안에도 움직이는 모아로 투샷 중심/축을 다시 계산해 화면이 끌리거나 좌우 축이 바뀔 수 있었다. 대화마다 카메라 측면을 고정하고 smoothstep으로 진입0.8초·복귀1.1초 전환한다. 플레이어 위치/종료 방향·모아 이동은 유지한다. 모아가 소망이를 가로질러 이동해도 복귀 카메라가 정지한 모아 조건과 정확히 같은지 확인하는 회귀 테스트는 수정 전 실패/수정 후 통과했다. 기존 포함12개 테스트 통과, 실제 가구점 마지막 다음 버튼→출발 장면의 웹/실행본 프레임에서 예외 없음·플레이어 위치 유지도 확인했다. 최종 사용자 화면 검수는 별도다.


### 후속: 대화 종료 후 모아 기본 표정 복원
대화 후 소개 장소로 출발할 때와 이전 장소를 떠날 때 모아 표정을 기본 미소(smile)·차분한 잎(calm)으로 복원한다. 대화 중 표정 연출은 기존대로 적용하고 잠든 모아는 초기화하지 않아 sleepy/졸기를 유지한다. 웹/기존 실행본 가구점 마지막 다음 버튼에서 surprised 표정/잎을 calm+smile로 되돌리고 이동이 시작되는 것을 실제 브라우저에서 확인했다.

### 후속: 우회 이동 매끄럽게
모아는 앞쪽80월드단위까지 살펴 소망이에게 닿기 전에 우회 경로를 정한다. TourCurve는 추가 여유를 둔 우회 경로의 모서리를 곡선으로 연결하되 모든 표본과 연결 선분이 소망이/지형 충돌을 피할 때만 적용한다. 같은 위치의 소망이 때문에 우회 방향을 반복 재선택하지 않으며 실제 장애물 위치가24 이상 바뀔 때 재계산한다. 회전은 초당 최대4라디안으로 제한하고 앞쪽24단위의 진행 방향을 본다. 임시 정지에서도 걷기 모션을 초기화하지 않는다. 웹/기존 실행본 반영. 정지한 소망이를 밀지 않고 우회해 원래 길에 복귀, 프레임당 이동/회전 상한 검사 및 곡선 충돌 안전성 포함14개 테스트 통과를 확인했다. 최종 사용자 동작 검수는 별도다.

### 후속: 안내소 선입장·모아 착석·문 열기 안내
첫 마을 소개의 안내소 마지막 대사 뒤에는 InformationEntry가 실내를 준비하고 모아가 외부 문을 열고 먼저 걸어 들어간다. 외부 모아를 숨기고 실내 모아는 기존 Seat_Sage_Cushion 의자에 현재 모델의 whole-leg 앉기 자세로 배치한 뒤 문을 닫는다. 이후 화면 모서리에 WASD 이동·문 가까이 F로 열기 안내를 표시한다. 플레이어는 자동 입장하지 않으며 문에 가까운 새 F 입력에만 문이 열리고 기존 입주 신청 대화로 연결한다. 실내 모아 위치는 (0,43.6566,-217.5000), 원래 의자/모델을 사용한다. 가려진 외부 NPC 몸체는 충돌에서 제외하고 처음부터 다시 시작할 때 선입장 상태를 초기화한다. 웹/기존 실행본 반영. 실제 마지막 다음 버튼→모아 입장/착석→가이드 시점의 플레이어 위치 고정→멀리서 F 무효→WASD·근거리 F 입장→모아 앉은 상태/기존 대화 연결 및 실제 렌더를 확인했다. 기존 테스트14개 통과. 최종 사용자 시각·플레이 검수는 별도다.

### 후속: 안내소 실내에서 직접 모아에게 말 걸기
안내소 입장 직후에는 대사를 자동 표시하거나 소망이를 책상 옆으로 옮기지 않는다. 입구 spawn(0,235)에 두고 InformationTalk가 WASD 접근을 허용한다. 앉아 있는 모아의 책상 앞(거리310 이내·실내Z85 이하)에서 새 F 입력을 해야 기존 입주 대화가 시작된다. 책상으로 떨어진 거리를 고려하며 입구에서 누르는 F/키 반복은 무효다. 모아 착석·외부 문 안내와 신청서 흐름은 유지한다. 웹/기존 실행본에서 입장 직후 대사 숨김/입구 위치/모아 착석, 원거리F 무효, 실제 D-W-A 조작 후 (75.078,63.82) 책상 앞 근거리F 대화 연결 및 기존 테스트14개 통과를 확인했다.

### 후속: 오프닝 정류장 표시 복원
캐릭터 시야 가림 제거가 적용한 메시 숨김이 공유 마을을 빌리는 버스 연출에 남아 정류장이 사라지는 문제를 수정했다. ArrivalVillage에서 연출 활성화 직후 가림 상태를 reset하고 타이틀/오프닝 동안 TownModelScene 가림 제거를 적용하지 않는다. 일반 플레이의 상시 가림 제거는 유지한다. 웹/기존 실행본 반영. 버스 진입·정차·출발의 정류장 전체 메시 가시성, 출발 후 누군가 자는 자막/수면 효과·건너뛰기 제거를 실제 브라우저로 확인했다. 관련 오프닝/전시 테스트9개 통과.
