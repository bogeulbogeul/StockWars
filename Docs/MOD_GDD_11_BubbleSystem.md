# StockWars GDD: MOD_GDD_11. 스마트폰 Bubble 메신저 시스템 (Bubble System)

**버전:** v2.1.0 (챗 앱 공식 명칭 'Bubble' 적용)  
**핵심 컨셉:** 기존 스마트폰 메일 기능을 버블(Bubble) 앱 내 채널 및 개인 DM 형태로 통합하여 비동기적 알림, 정보 찌라시 공유, 보상 수령을 단일 메신저에서 처리하는 시스템  

---

## 1. 시스템 개요 (System Overview)
유저는 게임 내 스마트폰 UI의 **'Bubble' 앱**을 통해 친구와의 1:1 대화(DM), NPC와의 대화, 시스템 알림 수신, 금융 기관 경고 등을 모두 한눈에 확인하고 대처할 수 있습니다. 기존 메일 앱에서 제공하던 일방향 수신 알림 및 선물 수령 기능은 버블 앱 내부의 **'공식 채널(Bot)'** 대화방 형식으로 귀속됩니다.

---

## 2. 버블 메신저 대화방 구조 (Bubble Room Directory)

유저의 대화방 목록은 목적에 따라 아래 5가지 카테고리로 분류되며, 메시지 내에 첨부된 링크나 아이템을 클릭해 수령하는 방식을 채택합니다.

| 대화방 이름 | 발신 주체 | 성격 | 주요 대화 및 수신 내용 |
| :--- | :--- | :--- | :--- |
| 📢 **Node Finance (은행)** | 시스템 / 은행 | 단방향 채널 | 주간 이자 정산 리포트, 자산 압류(Seizure) 전 최종 경고 |
| 📊 **Cipher Securities (증권)** | 시스템 / 증권사 | 단방향 채널 | 신규 상장(IPO) 예고, 상장 폐지(Delisting) 안내, 마진콜 및 적색 수배 통보 |
| 📦 **Pawn Shop Barter (전당포)** | NPC 바터 | 단방향 채널 | 담보 대출 상환 기한(12시간/1시간 전) 만료 긴급 알림 |
| 👥 **친구 이름 (개인 DM)** | 친구 목록 내 유저 | 양방향 DM | 스테미너(Energy) 선물, 찌라시 복사본 공유 및 수령 |
| 👤 **Shadow (익명)** | 쉐도우 (Shadow) | 일시적 대화방 | 내부자 찌라시(확정형), 암시장 의상/가구 판매 제안, 특수 미션 제안 |

---

## 3. 대화방 데이터 구조 (Bubble Room & Message Data)

### 3.1. 대화방 정보 (BubbleRoom)
| 필드명 | 타입 | 설명 |
| :--- | :--- | :--- |
| **RoomID** | string | 대화방 고유 식별자 (GUID) |
| **RoomType** | Enum | SystemChannel, SocialDM, ShadowChat |
| **DisplayName** | string | 대화방 목록에 노출될 이름 |
| **LastMessage** | Message | 대화방 프리뷰에 노출될 최신 메시지 객체 |
| **UnreadCount** | int | 읽지 않은 메시지 개수 |

### 3.2. 메시지 정보 (Message)
| 필드명 | 타입 | 설명 |
| :--- | :--- | :--- |
| **MessageID** | string | 각 말풍선의 고유 ID |
| **Sender** | string | 발신자 이름 (NPC 혹은 친구 유저네임) |
| **Text** | string | 메시지 내용 (Rich Text 지원) |
| **Attachment** | Item/Gold | 메시지 말풍선에 포함된 수령 가능 재화/아이템 |
| **Timestamp** | DateTime | 메시지 전송 시각 |
| **ExpiryDate** | DateTime | 만료 시점 (TTL: 기본 7일, **Shadow는 1일**) |
| **IsCollected** | bool | 첨부파일(보상) 수령 여부 |

## 4. 특수 대화 채널 세부 로직

### 4.1. 쉐도우 비밀 대화방 (Shadow Chat)
음지에서만 접할 수 있는 **'검은 정보'**를 버블 메신저를 통해 유저에게 극비로 전송하는 특수 채널입니다.
- **프로필 연출**: 후드를 깊게 눌러쓴 미남형 실루엣 프로필 이미지 사용.
- **메시지 휘발성 (Self-Destruct)**:
  - **1일 만료**: 24시간 내에 읽지 않은 쉐도우의 메시지는 대화방과 함께 리스트에서 자동 파기됩니다.
  - **나가기 즉시 파괴**: 쉐도우 대화방에서 나가거나 버블 앱을 종료할 경우, 보안을 위해 대화 내역이 즉시 증발하여 흔적을 남기지 않습니다.

### 4.2. 금융 경고 및 알림 채널 (Institutional Alerts)
- **마진콜(Margin Call) 경고**: 공매도 유지 증거금이 **90%** 임계값에 도달하면 `📊 Cipher Securities` 채널로부터 붉은색 강조 알림 메시지가 실시간으로 발송됩니다.
- **적색 수배(Red Notice) 통보**: 횡령 확정 시 계좌 동결 및 적색 수배 통보 메시지가 동일 채널로 발송됩니다.

## 5. UI/UX 연출 가이드

### 5.1. 스마트폰 앱 인터페이스
- **아이콘**: 픽셀 아트로 그려진 귀여운 보라색 말풍선 아이콘 (`New_SocialIcon.png` 기반).
- **알림 배지 (Badge)**: 읽지 않은 메시지가 있을 경우 스마트폰 바탕화면의 Bubble 앱 아이콘 우측 상단에 빨간색 pips와 안읽은 숫자가 함께 노출됩니다.

### 5.2. 대화방 내부 연출
- **일괄 수령 (Collect All)**: 챗방 내부에서 첨부 파일이 포함된 메시지들을 하나하나 누르지 않고, 대화방 하단의 **'일괄 수령'** 버튼을 통해 한 번에 획득할 수 있습니다.
- **말풍선 인터랙션**: 첨부된 아이템을 클릭해 수령(IsCollected = true)하면 말풍선 내 수령 버튼이 "수령 완료" 텍스트로 비활성화되며, 투명도가 낮아집니다.
