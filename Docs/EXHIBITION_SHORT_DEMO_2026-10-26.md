# 전시 데모 단축 구성·대사 정리

2026-10-26 사용자 협의 기록. **기획 합의·대사 초안이며 게임 구현 완료 기록이 아니다.** 기존 첫날 이야기와 구현 이력은 [첫날 전시 문서](EXHIBITION_FIRST_DAY.md)에 보존한다. 이번 짧은 전시 구성과 충돌하는 과거 순서·동행·5상자 기준은 아래 결정을 우선한다.

## 확정한 체험 기준

- 짧은 전시 체험을 지향하며, 길어도 약 5분 안에 끝나는 구성을 목표로 한다. 처음 언급한 약 1분은 방향성이고, 신청서·이동·두 활동을 포함한 실제 소요 시간은 아직 검증하지 않았다.
- 버스에서 내려 모아를 만나는 장면부터 시작한다.
- 플레이어 이름은 특정하지 않는다. 원고 화자 표기는 `플레이어`로 하고, 이름은 기존 신청서에서 직접 입력한다. NPC 대사에는 고정 이름을 넣지 않는다.
- 신청서 작성·제출과 휴대폰 수령을 유지한다. 휴대폰은 지도·소식·계좌 등 여러 기능을 소개하고, 안내문을 따라 직접 열고 닫아본 뒤 진행한다. 아직 해금되지 않은 기능은 잠금을 유지한다.
- 모아는 장소 사이를 직접 걷는 동행 연출 대신 “먼저 가 있을게요”라고 안내한다. 페이드아웃 중 목적지 대기 상태로 바꾸고 같은 장소에서 페이드인한다. 플레이어는 직접 걸어서 목적지로 이동하며, 도착하면 모아가 기다린다.
- 장소·상황 전환에는 화면 전체 페이드아웃 → 장면 변경 → 페이드인을 사용한다. 캐릭터 재질을 반투명하게 만드는 효과가 아니다.
- 건물은 문 앞에서 F키 또는 화면의 ‘들어가기’ 버튼을 눌러야 입장한다. 근접·문 접촉만으로 자동 입장하지 않는다.
- 은행에서는 계좌 개설 후 대출을 직접 신청하고 입금·잔액을 확인한다.
- 주식 체험은 자격시험 3문항 → 결과 확인·자격증 수령 → 기업 정보·차트·주문 안내 → 첫 매수 순서다. 전부 정답이면 분석력 2, 그 외에는 1이며 자격증은 정답 수와 관계없이 지급한다.
- 은행 이후 모아는 포포리 나무 아래 벤치에서 기다린다. 이후 각 활동 장소로 먼저 가거나 플레이어를 따라가지 않는다.
- 주식과 잡화점 중 먼저 할 순서만 선택한다. **두 활동을 모두 완료해야** 모아에게 돌아와 정착금·다이어리를 받는다.
- 전시 포장 알바 목표는 **5상자에서 3상자**, 완료 보수는 **500잎에서 300잎**으로 줄인다. 300잎은 세 상자를 모두 완료한 한 회차의 보수다. 일반 모드 변경이나 패턴 난이도 구성 변경까지 확정한 것은 아니다. 화분 가격 변경은 아니다.
- 두 활동 완료 후 벤치의 모아와 소감을 나누고 **꿀쿠키를 먼저 받은 뒤 정착금·다이어리**를 받는다. 이후 플레이어가 씨앗을 떠올려 잡화점에서 화분을 산 뒤 집으로 간다.
- 잡화점에서 찌라시가 든 소식봉투를 받으면 포포리 나무 아래 모아에게 돌아가 인벤토리를 열고 내용을 확인한다. 잡화점 선행이면 확인 후 남은 주식 체험으로, 주식 선행이면 확인 후 두 활동 소감·보상으로 이어진다. 한 활동만 마친 상태에서는 꿀쿠키·정착금·다이어리를 지급하지 않는다.

## 전체 순서

귀가 후 마지막 순서는 **집 입장 → I키 인벤토리 → 화분 선택·사용 → 기존 씨앗 심기 연출 → 일기 작성 완료 → 잠자기 → 기존 취침 연출·데모 종료**다. 아래 이동 흐름의 집 도착에서 체험을 끝내지 않는다.

버스·모아 첫 만남 → 마을 안내소 → 입주 신청서 작성·제출 → 휴대폰 수령·기능 소개·열고 닫기 체험 → 은행 계좌 개설·대출 신청·입금 확인 → 활동 순서 선택 → 주식 자격시험·첫 매수와 잡화점 포장 3상자 모두 완료 → 포포리 나무 아래 벤치의 모아와 소감 대화 → 꿀쿠키 수령 → 정착금·다이어리 수령 → 씨앗 회상 → 잡화점 화분 구매 → 집으로 이동.

집을 은행보다 먼저 방문하는 기존 긴 첫날 순서는 이번 단축 구성에 사용하지 않는다. 은행 이후 활동 안내는 휴대폰 지도 및 각 장소의 담당자가 맡는다.

소식봉투 확인을 포함한 활동 분기:

- **잡화점 먼저:** 포장·300잎/소식봉투 수령 → 벤치의 모아 → 인벤토리에서 봉투 내용 확인 → 주식 자격시험·첫 매수 → 벤치 복귀·소감·보상.
- **주식 먼저:** 자격시험·첫 매수 → 잡화점 포장·300잎/소식봉투 수령 → 벤치의 모아 → 인벤토리에서 봉투 내용 확인 → 소감·보상.

## 전환 연출과 건물 입장

- 모아의 선행 안내 뒤 페이드아웃 중 모아의 대기 장소를 변경한다. 은행 이후 대기 장소는 포포리 나무 아래 벤치다. 플레이어의 위치는 그대로 유지한다.
- 입장은 **문 앞 도착 → ‘F 들어가기’ 안내 → F/화면 버튼 입력 → 페이드아웃 → 실내 전환 → 페이드인** 순서다. 원격 입력이나 문을 향해 걷기만 하는 것으로 입장하지 않는다.
- 건물 실내·외 전환과 신청서 제출·계좌 개설·보상 전달처럼 상황이 바뀌는 지점에 짧은 페이드를 사용한다. 대사 한 줄마다 또는 휴대폰을 열고 닫을 때마다 적용하지 않는다.
- 시작 조정값은 어두워지기 0.4초·장면 변경·밝아지기 0.4초다. 확정 시간은 아니며 실제 체험에서 조정한다. 전환 중 이동·중복 상호작용을 잠근다.
- 플레이어는 각 건물까지 직접 이동한다. 화면 페이드와 건물 입장 요구는 최신 단축안 기준이며, 기존 도보 출입 구현을 변경 완료했다는 의미가 아니다. 퇴장의 별도 상호작용 조건은 이번 협의에서 새로 정하지 않았다.

## 인물 말투

[현행 캐릭터 설정](CHARACTER_SETTINGS_AND_WISHES.md)을 따른다.

- 모아: 차분하고 다정하게 안내한다. 전시에서는 설명을 짧게 한다.
- 토리: 숫자와 기록을 좋아하며, 말이 짧고 또렷하다. 무뚝뚝하지만 성실하고 모르는 것을 아는 척하지 않는다. 가벼운 수익 약속이나 과도하게 들뜬 환영 말투를 쓰지 않는다.
- 봉봉: 붙임성 있고 손이 빠른 잡화점 주인. 포장을 도와준 것에 따뜻하게 감사한다.
- 차곡: 작은 금액과 거래 조건도 꼼꼼히 살피는 은행 담당자.

## 장면별 대사 초안

아래 문장은 구현 전 검토용 초안이다. 진행 순서와 지급 조건은 위 확정 기준을 따른다.

### 1. 버스 정류장

모아: “음… 버스가 도착했네요.”  
모아: “포포리에 오신 걸 환영해요. 저는 모아예요.”  
모아: “입주 안내부터 해드릴게요. 안내소에 먼저 가 있을게요.”

플레이어가 안내소까지 직접 이동한다.

### 2. 마을 안내소

모아: “잘 찾아오셨네요. 먼저 입주 신청서를 작성해주세요.”  
모아: “마을에서 사용할 이름을 적어주시면 돼요.”

기존 신청서를 열어 작성·제출한다.

모아: “접수됐어요. 포포리의 새 이웃이 되신 걸 환영해요.”  
모아: “이 휴대폰을 받아주세요. 마을 지도도 보고, 소식도 읽고, 계좌도 확인할 수 있어요.”  
모아: “한번 열어볼까요?”

휴대폰 수령 후 안내문: **“화면의 휴대폰 버튼을 눌러 열어보세요.”**

실제로 열면 안내문: **“자유롭게 살펴본 뒤 닫기 버튼을 눌러주세요.”**

열기·닫기를 모두 수행한 뒤 다음 대사로 진행한다. 계좌 등 아직 개설·해금하지 않은 기능은 기존 잠금 상태를 유지한다.

모아: “필요할 때 다시 열어보세요. 이제 은행에서 생활에 쓸 계좌를 만들어요.”  
모아: “은행에 먼저 가 있을게요.”

### 3. 은행과 활동 선택

차곡: “먼저 생활에 쓸 계좌를 만들어드릴게요.”

계좌 개설.

차곡: “계좌가 준비됐어요. 이제 정착에 필요한 자금을 대출 신청할 수 있어요.”  
차곡: “금액과 조건을 읽고 신청해주세요.”

대출 신청 화면 → 조건 확인·신청 완료 → 대출금 입금·잔액 확인. 계좌 개설만으로 대출 신청을 대신하지 않는다.

차곡: “대출금이 입금됐어요. 나중에 갚아야 할 돈이니 필요한 곳부터 써보세요.”  
모아: “이제 주식 투자와 잡화점 일을 경험해보세요. 어느 쪽부터 해도 괜찮아요.”  
모아: “저는 포포리 나무 아래 벤치에서 기다릴게요. 둘 다 해보고 찾아와 주세요.”

선택: **주식 투자 먼저 / 잡화점 알바 먼저**. 주식 선행이면 다음으로 잡화점을 안내한다. 잡화점 선행이면 모아에게 돌아가 소식봉투를 확인한 뒤 남은 주식 체험을 안내한다.

### 4. 주식 체험

토리: “토리야. 투자 안내를 맡고 있어.”  
토리: “투자는 처음인가? 먼저 자격시험부터 봐.”  
토리: “자료를 읽고 답하면 돼. 확인한 내용을 근거로 골라.”

기존 자격시험 **3문항 응시 → 결과 확인 → 자격증 수령**. 기존 15종 중 중복 없이 3문항을 선택하는 규칙을 유지한다. 3문항 모두 정답이면 분석력 2, 그 외에는 1로 시작하며 자격증은 모두 지급한다. 시험·자격증 수령 전에 첫 매수 단계로 넘어가지 않는다.

토리: “이제 회사를 살펴보자. 가격만 보지 말고, 무엇을 하는 회사인지부터.”

회사 선택 → 기업 정보 확인.

토리: “무엇을 하는 회사인지, 실적은 어떤지 확인해.”

차트 확인.

토리: “이건 지금까지의 가격이야. 앞으로의 가격을 보장하진 않아.”

주문 안내·확인.

토리: “1주 가격과 남을 돈을 확인해. 확인했으면 매수해 봐.”

첫 매수 완료.

토리: “거래됐어. 어떤 정보를 보고 샀는지 기억해 둬.”

### 5. 잡화점 포장 알바

잡화점에 들어오면 환영 대사를 표시한다. 입장만으로 알바를 시작하지 않는다.

봉봉: “어서 와요! 봉봉 잡화점이에요. 필요한 게 있으면 말해주세요.”

플레이어가 봉봉에게 다가가 직접 말을 걸면 포장 알바와 작업대 위치를 안내한다.

플레이어: “모아가 소개해줘서 왔어요.”  
봉봉: “아, 모아가 소개해줬군요! 마침 포장할 물건이 있었어요.”  
봉봉: “주문 세 상자만 같이 포장해볼까요?”  
봉봉: “포장은 저쪽 작업대에서 하면 돼요. 작업대 앞으로 가주세요.”

실제 작업대 위치를 안내 표시로 알려준다. 플레이어가 직접 작업대까지 이동하고, 작업대 근처에서 F키 또는 포장 시작 버튼으로 알바를 시작한다. 봉봉과 대화하거나 안내를 닫는 것만으로 원격 시작하지 않는다.

봉봉: “주문에 맞는 물건을 상자에 담아주세요.”

**3상자 포장 → 알바 보수 300잎·소식봉투 수령 → 잡화점 체험 완료.** 소식봉투는 누군지 모르는 사람이 남겨준 것으로, 보수와 함께 한 번만 전달한다. 발신자의 정체는 공개하거나 새로 정하지 않는다.

봉봉: “잘 담았네요! 덕분에 주문을 보낼 수 있겠어요.”  
봉봉: “여기 일한 몫으로 300잎이에요. 받아주세요.”  
봉봉: “그리고 이 소식봉투도 받아주세요. 어떤 분이 전해달라고 남기고 가셨어요.”  
플레이어: “누가요?”  
봉봉: “이름은 말씀하지 않으셨어요. 저도 처음 뵙는 분이었어요.”

보수와 소식봉투를 수령한다. 봉투는 기존 전시 세션 가방에 보관한다. 수령 뒤에는 **“포포리 나무 아래 모아에게 돌아가세요.”**라고 안내하고, 모아 앞에서 인벤토리 열기·내용 확인을 안내한다.

### 5-1. 모아에게 돌아가 소식봉투 확인

플레이어가 벤치의 모아에게 직접 말을 건다. 이 대화는 잡화점 체험 후에 진행하며 주식 체험 완료를 선행 조건으로 두지 않는다.

플레이어: “봉봉이 이 봉투도 줬어요. 누가 남겼는지는 모르겠대요.”  
모아: “소식봉투네요. 어떤 내용인지 같이 확인해볼까요?”  
모아: “받은 물건은 가방에 있어요. 가방을 열어보세요.”

안내문: **“I키를 눌러 인벤토리를 열어보세요.”** 기존 I키와 아이보리 인벤토리를 사용하며, 삭제한 화면 하단 가방 버튼을 다시 만들지 않는다.

인벤토리가 실제로 열리면 안내문: **“소식봉투를 선택해 내용을 확인하세요.”** 기존 아이템 상세·읽기 경로로 연결한다. 인벤토리만 열었다 닫는 것으로 확인 완료 처리하지 않는다. 내용 확인 전에 닫으면 같은 안내를 다시 제공한다.

봉투 내용 확인 후 안내문: **“확인을 마쳤으면 인벤토리를 닫아주세요.”** 인벤토리와 읽기 화면을 닫은 뒤 모아 대화를 이어간다.

모아: “이런 소문을 찌라시라고도 해요. 적혀 있다고 모두 사실인 건 아니니, 다른 정보도 함께 살펴보세요.”

잡화점을 먼저 체험했다면:

모아: “이제 증권사에서 투자도 배워보세요. 저는 여기서 기다릴게요.”

주식 체험도 이미 마쳤다면 다음의 소감 대화·꿀쿠키·정착금·다이어리 전달로 이어진다. 소식봉투 확인 안내는 완료 후 반복하지 않는다. 해석·퀴즈의 단축안 분량은 별도로 정한다.

### 6. 두 활동 완료 후 벤치로 복귀

두 활동을 모두 마친 플레이어가 포포리 나무 아래 벤치의 모아에게 직접 말을 건다. 아직 소식봉투 확인 안내를 마치지 않았다면 먼저 5-1 장면을 진행한다. 활동 선택 순서와 관계없이 확인 후 같은 소감 대화로 이어진다.

모아: “두 곳 다 다녀오셨네요. 처음 해보니 어땠어요?”  
플레이어: “상자 세 개를 채웠는데, 다 하고 나니까 좀 뿌듯했어요.”  
모아: “직접 일해서 받은 돈이라 더 그랬겠어요. 투자는요?”  
플레이어: “아직은 잘 모르겠어요. 그래도 제가 고른 회사라 자꾸 생각나요.”  
모아: “처음부터 다 알 필요는 없어요. 궁금한 걸 하나씩 알아가면 되죠.”  
모아: “여기 꿀쿠키예요. 오늘 여기저기 다니느라 애쓰셨어요.”

**모아가 꿀쿠키를 먼저 건넨다 → 플레이어가 수령한다.** 정착금·다이어리 전달보다 앞에 별도 수령 순서로 둔다. 먹기 조작이나 새로운 회복 효과는 이번 요청으로 추가하지 않는다.

플레이어: “고마워요. 마침 출출했어요.”  
모아: “새로운 생활에 보탬이 되도록 정착금을 준비했어요. 그리고 이 다이어리도 받아주세요.”

꿀쿠키 수령 다음에 정착금·다이어리를 수령한다. 한 활동만 끝냈으면 이 보상 장면을 시작하지 않으며, 이미 받은 꿀쿠키·정착금·다이어리는 다시 지급하지 않는다.

모아: “거창한 이야기가 아니어도 괜찮아요. 오늘 기억하고 싶은 일을 적어보세요.”  
플레이어: “오늘은 적을 게 좀 있겠네요.”

짧은 쉼. 플레이어가 문득 기억났다는 듯 반응한다. 씨앗의 출처나 종류를 새로 설정하지 않고, 기존에 가지고 있던 씨앗을 떠올리는 장면으로 한다.

플레이어: “아, 맞다. 씨앗!”  
모아: “씨앗을 가지고 계세요?”  
플레이어: “네. 심어보려고 했는데… 화분이 없네요.”  
모아: “화분은 봉봉 잡화점에서 살 수 있어요.”  
플레이어: “그럼 하나 사서 집에 가야겠어요.”  
모아: “좋아요. 어떤 싹이 나는지 나중에 들려주세요.”

화분 구매는 모아가 먼저 제안하는 과제 대신 플레이어가 씨앗을 떠올려 선택한 다음 행동으로 연결한다.

### 7. 화분 구매·귀가

플레이어가 씨앗을 심을 화분을 사러 잡화점으로 직접 간다.

플레이어: “씨앗을 심으려고요. 화분 하나 주세요.”

기존 화분 구매 화면으로 연결한다.

봉봉: “이 화분으로 골랐군요. 잘 챙겨드릴게요!”

플레이어가 집으로 직접 이동한다. 모아가 집 앞에서 다시 기다리는 이전 초안은 사용하지 않는다.

### 8. 집에서 화분 사용·일기·잠자기

집 문 앞에서 F키 또는 ‘들어가기’ 버튼을 눌러 입장한다. 귀가 후에도 플레이어가 직접 조작하며 다음 순서로 진행한다.

플레이어: “먼저 씨앗부터 심어야겠다.”

안내문: **“I키를 눌러 인벤토리를 열어보세요.”**  
인벤토리를 열면: **“화분을 선택하고 ‘사용’을 눌러주세요.”**

실제로 화분을 사용하면 기존 씨앗 심기 연출로 연결한다. 인벤토리를 열거나 화분을 선택하는 것만으로 완료하지 않는다. 사용 전에 닫으면 안내를 다시 제공한다. 새 배치 방식이나 심기 모션은 추가로 정하지 않는다.

플레이어: “어떤 싹이 날까.”  
플레이어: “아, 오늘 일도 적어둬야지.”

화분 사용·심기 완료 후 안내문: **“J키를 눌러 다이어리를 열고 오늘의 일기를 써보세요.”** 기존 일기 작성 기능을 사용한다. 일기를 실제로 작성 완료한 뒤 취침 단계로 진행하며, 작성 전에 닫았으면 다시 안내한다.

플레이어: “오늘은 처음 해본 게 많았네.”  
플레이어: “이제 좀 자야겠다.”

안내문: **“‘잠자기’ 버튼을 눌러 하루를 마무리하세요.”**

플레이어가 잠자기를 선택하면 기존 18초 취침 연출·채택한 앉은 자세 그림과 다이어리·음악·타이틀 복귀·전시 초기화 정책을 유지한다. 화분 사용과 일기 작성 전에 취침으로 건너뛰지 않는다. 이번 문서는 새 수면 그림이나 연출 시간 변경을 요청하지 않는다.

## 미정 사항과 구현 시 확인할 범위

- 은행 대출 신청은 필수 흐름으로 확정했다. 대출금과 벤치에서 받는 정착금은 별도이며 이번 협의에서 금액·이자·상환 조건을 새로 확정하지 않았다. 기존 문서의 5,000잎 대출·2,000잎 지원금 등을 새 합의로 간주하지 않는다. 신청 화면의 실제 조건은 적용 시 기존 명세와 대조한다.
- 알바 완료 시 익명의 사람이 남긴 소식봉투 지급·모아에게 돌아가 인벤토리를 열어 내용 확인·두 활동 후 꿀쿠키→정착금/다이어리 전달·귀가 후 인벤토리에서 화분 사용→일기 작성→취침은 확정했다. 소문 원고 변경과 해석/퀴즈의 단축안 분량, 노을 연출은 아직 확정하지 않았다. 기존 구현을 삭제하도록 승인한 기록이 아니다.
- 신청서 입력·휴대폰 열고 닫기·대출 신청·플레이어 이동·페이드·자격시험 3문항·주식 조작·포장 3상자를 포함해 양쪽 활동 순서로 시간을 측정해야 한다. 5분 내 완주가 검증된 상태가 아니다.
- 휴대폰을 실제로 열고 닫아야 진행하는지, 미개설 기능의 잠금이 유지되는지 확인한다. 근접만으로 입장하지 않는지, 문 앞 F/버튼 입력으로 한 번만 입장하는지, 페이드 종료 후 입력이 복구되는지 확인한다.
- 계좌 개설과 대출 신청·입금을 구분하고 중복 입금을 막는지, 시험 결과별 분석력과 자격증 지급 및 매수 선행 조건이 유지되는지 확인한다.
- 실제 적용 시 3상자 목표·진행 표시·대사·완료 판정·중단 후 재개를 함께 확인한다. 기존 진행 데이터 처리도 확인한다.
- 잡화점 입장 환영 대사와 봉봉에게 직접 말 걸기를 구분하고, 작업대 위치 안내 후 플레이어가 작업대로 이동해 시작하는지 확인한다. 화분 구매를 위한 재방문에서 완료한 알바를 다시 강제하지 않는다.
- 포장 완료 후 300잎과 소식봉투를 함께 수령하고 재대화·재방문 시 중복 지급되지 않는지 확인한다. 소식봉투가 전시 세션 가방에 보관되는지 확인한다.
- 두 활동 순서 모두에서 소식봉투 수령 후 모아에게 복귀→I키 인벤토리 열기→실제 봉투 내용 확인→닫기 순서를 확인한다. 조기 닫기 후 재안내, 확인 완료 후 반복 방지, 잡화점 선행 시 보상 없이 주식 체험으로 이어지는지 확인한다. 벤치 추가 방문·봉투 읽기 시간도 최대 5분 목표의 측정 범위에 포함한다.
- 두 활동 전 보상 차단·꿀쿠키→정착금/다이어리 지급 순서·각 보상의 중복 수령 방지·화분 구매에 필요한 잔액·기존 전시 초기화 정책을 확인한다.
- 귀가 후 실제 화분 사용·심기 완료→일기 작성 완료→잠자기 순서와 조기 닫기 후 재안내, 중복 화분 사용 방지, 기존 취침·타이틀 복귀를 확인한다. 귀가 후 조작·일기 작성·18초 취침도 최대 5분 목표의 측정 범위에 포함한다.
- 이번 작업은 문서 정리만 수행한다. 웹·기존 실행본·설치 프로그램과 게임 테스트는 변경하거나 재검증하지 않았다.
