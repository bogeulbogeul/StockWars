## 최신 성장 개편 — 분석력 단일화·캐릭터 레벨과 분리

**P1 (Major) · ✅ 완료: 기획 반영 / ⏳ 대기: 수치·UI·저장 이관 설계·게임 구현·검수.**

능력치는 **분석력만 남기고 Lv.1~5**으로 운영한다. 협상력·운용력·회복력과 레벨업 능력치 포인트 배분은 개편 기획에서 제거한다. 기존 시작 성향 능력 유지 지시보다 이번 후속 결정을 우선하며, 기존 저장의 능력치·성향·사용/미사용 포인트는 이관 설계 전 삭제하거나 환산하지 않는다. 수수료·보유 종목 한도·하트·알바 보수는 별도 공통 규칙으로 정하고 최종 수치는 후속 설계한다.

| 구분 | 캐릭터 레벨 | 분석력 |
|---|---|---|
| 의미 | 소망이의 생활 성장 | 찌라시 내용을 읽고 이해하는 능력 |
| 시작 | Lv.1 | 시작 정보 해석 테스트 결과로 결정 |
| 성장 | 생활 활동의 캐릭터 경험치 | 찌라시 읽기 후 해석 확인 퀴즈의 분석력 숙련도 |
| 효과 | 기존 소망이·화분 외형 성장 | 찌라시의 기본 표시 해석 2·4·6·8·10단계 |

캐릭터 레벨과 분석력은 독립적으로 관리한다. 캐릭터 레벨업으로 분석력을 올리거나 포인트를 지급하지 않으며, 분석력 상승으로 캐릭터 레벨·외형을 바로 올리지 않는다. 기존 캐릭터 Lv.20 상한·경험치 공식·외형 전환 구간은 유지한다. 생활 경험치의 구체 지급 활동·수치는 후속 설계하며 폐기한 물류·의뢰를 경험치 수급원으로 복원하지 않는다.

시작 테스트는 기존 4종 성향 보너스 대신 분석력의 출발 단계를 정한다. **4지선다 3문항에서 정답 0~1개는 Lv.1, 2개는 Lv.2, 3개는 Lv.3**으로 시작한다. 결과와 관계없이 계좌를 개설한다. [시작 테스트](CORE_GDD_08_CharacterCreation.md)를 따른다.

분석력은 단순 열람 횟수나 가루 사용 횟수로 올리지 않는다. 읽은 내용을 이해했는지 확인하는 퀴즈를 성장 경로로 삼는다. **사건당 1문항·정답 숙련도 +1·오답 후 재도전 정답도 같은 보상·플레이어별 사건당 1회 지급**을 채택한다. 사건 ID와 실제 표시 내용에 따른 출제 원칙은 [퀴즈 설계](MOD_GDD_18_QuizSystem.md)를 따른다.

**가루는 찌라시가 보이는 상세 수준을 바꾸는 상품이다.** 별가루는 지정 한 건 +1단계(최대 10), 달가루는 지정 한 건 10단계 표시를 유지한다. 플레이어 분석력·숙련도·캐릭터 경험치를 직접 올리지 않는다. 가루 사용 여부에 따른 퀴즈 참여 제한·보상 차등은 두지 않는다. 해석 표시와 퀴즈 성장은 별도 시스템이다.

| Lv.3 → Lv.4 | 40 | 90 |
| Lv.4 → Lv.5 | 60 | 150 |

정답 숙련도 +1·플레이어별 사건당 한 번 지급·오답 후 재도전 동일 보상을 유지한다. 승급 요구량을 차감하고 남은 숙련도는 다음 레벨에 보존한다. 최대 Lv.5에서는 초과 숙련도·대체 보상을 지급하지 않는다. 캐릭터 EXP와는 별개다.

시작 테스트의 기존 배점은 유지한다. Lv.1 출발은 정답 150개, Lv.2는 130개, Lv.3은 100개가 더 필요하다. 출발 숙련도는 0이며 시작 레벨을 정답 사건으로 만들어 지급 이력을 채우지 않는다.

기본 해석은 Lv.1~5에 각각 1·2·3·4·5단계다. 가루로 저장한 개별 해석 단계가 더 높으면 유지한다. 같은 사건의 사본·단계 상승·가루·재접속은 새 보상이 아니다. 구 version 1은 예전 레벨까지의 누적 요구량과 현재 숙련도를 합쳐 새 표에 1회 재배분하고, 모든 지급 이력은 그대로 보존한다. 구 Lv.10은 새 Lv.4·20/60으로 옮긴다. [상세 이관·검증](ANALYSIS_FIVE_LEVELS_2026-10-25.md)을 따른다.

## 1. 기존 구현 이력: 레벨과 시작 상태

시작 현금은 5,000G이며 웰컴 론은 미구현이다. 4대 기본 스탯은 0에서 시작해 성향 하나에 +1을 적용한다. Lv.1에서 시작하고 다음 레벨 요구 EXP는 `100 × 현재 레벨^1.5`다. 요구 EXP를 차감하며 최대 Lv.20까지 계산한다. Lv.3에서 강제 종료하지 않는다.

레벨업당 성장 포인트 1개를 배분한다. 미사용 포인트는 `max(0, 레벨 - 1 - spentLevelPoints)`다. 성향·해독 누적 등 별도 영구 증가가 있으므로 `SUM(Base_Blocks) == User_Level`을 저장 무결성 규칙으로 사용하지 않는다. 현재 배분 함수에는 스탯 저장값 5 상한이 없지만 단계별 효과를 계산하는 `statLevel`은 0~5로 제한한다. 이를 모든 보너스가 무제한으로 효율을 늘리는 체제로 해석하지 않는다.

과거 물류·수락 의뢰의 EXP 지급과 해독 10회마다 분석력 +1은 이전 성장 구조의 기록이다. 폐기된 물류·의뢰를 현행 수급원으로 사용하지 않으며, 개편에서는 해독 횟수 자동 성장을 퀴즈 기반 숙련도로 대체한다. 모든 일반 매매 수익을 EXP로 바꾸는 엔진이 연결된 것으로 간주하지 않는다.

## 2. 능력치 효과

### 분석력

**2026-10-22 상품 효과 후속 채택:** 달가루는 **지정한 찌라시 한 건의 유지 해석 단계만 최대치인 10단계**로 만든다. 플레이어 분석력·경험치와 다른 찌라시는 바꾸지 않으며 해당 찌라시에 효과를 유지한다. 이전 플레이어 분석력 MAX 기획을 대체한다. 후속 채택으로 분석력 Lv.1~10과 찌라시 해석 1~10단계를 대응시킨다. 플레이어 능력과 개별 찌라시의 유지 해석 값은 별도로 관리한다. 별가루의 한 건 유지 해석 +1 효과와 구분하며 정보 진위를 보증하지 않는다. [잡화점 상세](MOD_GDD_03_1_VivianStore.md)를 따른다. ✅ 기획 반영 / ⏳ 세부 설계·구현·검수 대기.

[찌라시 작성 가이드](RUMOR_AUTHORING_GUIDE.md)의 최신 기획은 해석 1~10단계다. 아래 1~5단계 효과는 기존 구현 이력이며 10단계 원고·코드·저장 이관은 대기다. 기존 구현은 해석 1~5단계를 사용한다. 읽을 수 있는 비유·단서를 제공하며 문자 가림률·진위 판별 확률로 표시하지 않는다. 각성제는 분석력 +2를 120분간 적용한다. 해독기는 열람 찌라시 한 건의 유지 해석 단계를 +1, 최대 5로 올린다. 표시 단계는 분석력과 유지 단계 중 높은 값이며 완전 해석도 진위를 보증하지 않는다. 전략적 오보 5% 자동 추첨은 현재 고정 원고의 구현으로 간주하지 않는다.

### 협상력

기본 단계당 거래 수수료를 0.01%p 감면하며 최저는 0이다. 협상가 성향의 추가 30% 할인은 단계 감면 후 적용한다. 기본 단계당 물류 골드 보상은 +5%다. 대출 이율·세금 감면은 미구현이므로 현재 혜택에 합산하지 않는다.

### 운용력

| 기본 효과 단계 | 보유 종목 슬롯 |
| :--- | ---: |
| 0 | 5 |
| 1 | 10 |
| 2 | 15 |
| 3 | 20 |
| 4 | 25 |
| 5 | 30 |

양수 수량의 서로 다른 종목을 슬롯 1칸으로 센다. 자산가 성향은 슬롯 +2를 더한다. 현행 `buyCap()`은 Infinity이므로 1만/5만/20만/100만/1,000만G의 종목별 투자금 한도는 적용하지 않는다. 현금·호가 잔량·슬롯·주문 조건은 계속 검사한다. 안정제의 주문 주수 한도는 기본 100주에서 110주로 늘지만 무한 투자금 Cap에 +10% 금액 제한이 생기는 것은 아니다.

### 회복력

기본값과 활성 비타민 +2를 합한 회복력이 0~1이면 최대 하트 3개, 2~3이면 4개, 4 이상이면 5개다. 최대치 증가 자체는 현재 하트를 채우지 않는다. 자연 회복·불굴 성향 회복 속도 2배·별도 일일 노동 횟수 제한은 사용하지 않는다.

| 기본 효과 단계 | 누적 물류 효과 |
| :--- | :--- |
| 1 | 관성 제어 +10% |
| 2 | 파손 게이지 증가 -15% |
| 3 | 찌라시 지급 확률 +5%p |
| 4 | 이동 속도 +10% |
| 5 | 노동 종료 시 체력 차감 면제 확률 10% |

노동 기본 비용·드링크·카페인 회복량은 각각 하트 1개다. 벤치는 아이템 시계의 KST 날짜당 한 번 최대치로 회복한다. 다음 날 진행도 최대치로 회복한다. [노동 명세](MOD_GDD_02_LaborJobs.md)를 따른다.

## 3. 성향과 외형

### 소망이 레벨 성장 외형 — 2026-10-18 후속 채택

**2026-10-19 성장 대사·화분 연동 후속:** Lv.3·7·12·20의 머리 위 외형 전환에 화분 속 식물의 성장 단계도 함께 맞춘다. [정령 제작 기준의 대응 표](SPIRIT_CHARACTER_BASELINE.md)를 따른다. 심기 전에는 머리만 성장하고, 나중에 심으면 현재 레벨 단계를 표시한다. 소망이와 안나의 짧은 반응은 [대사 원고·예약/중복 방지 기준](MOD_GDD_07_DialogueDB.md)을 따르며 화분 반응의 구체 대사는 후속 설계한다. 작업·거래 도중 대화로 중단하지 않고 안전한 시점에 안내하며, 안나가 없으면 다음 대화까지 반응을 예약한다. 외형 전환 자체는 지연하지 않는다. 월세·수익·엔딩의 별도 조건과 추가 보상은 만들지 않으며 기존 성장 수치·보상은 유지한다. ✅ 연동 기획 반영 / ⏳ 구현·검수 대기.

고정 소망 요정은 Lv.1~2 기본 머리 → Lv.3~6 잎 하나 → Lv.7~11 두 잎 새싹 → Lv.12~19 두 잎 가운데 꽃봉오리 → Lv.20 작은 꽃 개화의 5단계로 성장한다. 외형은 Lv.3·7·12·20에서 전환하며 구간 내에서는 유지한다. 정확한 외형·의미·제작 상태는 [정령 제작 기준](SPIRIT_CHARACTER_BASELINE.md)의 레벨 성장 외형 표를 따른다. 아래 동물 스킨 설명은 이전 기록이며 이 성장 표현을 대체하지 않는다.

외형 채택 당시에는 최대 Lv.20·경험치 공식·성장 포인트·성향 효과를 유지했다. 최신 개편은 캐릭터 레벨·경험치 공식·외형 전환을 유지하고 성장 포인트와 기존 성향 보너스를 제거하는 기획이다. 장식 자체의 추가 능력치는 도입하지 않는다. ✅ 외형 성장 기획 반영 / ⏳ 에셋·레벨 표시 연동·저장 복원·게임 검수 대기. 기존 성장 엔진에 외형 자동 전환이 구현됐다고 기록하지 않는다.

기존 구현 이력: 분석가·협상가·자산가·불굴은 각각 대응 기본 스탯 +1을 제공한다. 최신 기획에서는 시작 분석력 테스트로 대체한다. 2026-10-22 시작 칭호 기획은 폐기하며 시작 성향 능력은 유지한다. [폐기 범위·구현 상태](FEATURE_RETIREMENT_2026-10-22.md)를 따른다. 스킨의 동물 외형·테마를 성능 차이로 자동 연결하지 않는다.
