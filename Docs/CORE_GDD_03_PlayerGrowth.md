# CORE_GDD_03 유저 성장과 능력치

> 개정: 2026-10-16. 현재 구현과 확장 기획을 구분한다. 구 수치표의 투자금 Cap·노동 횟수·문자 가림·Lv.3 종료를 현행 규칙에서 제거했다.

## 1. 레벨과 시작 상태

시작 현금은 5,000G이며 웰컴 론은 미구현이다. 4대 기본 스탯은 0에서 시작해 성향 하나에 +1을 적용한다. Lv.1에서 시작하고 다음 레벨 요구 EXP는 `100 × 현재 레벨^1.5`다. 요구 EXP를 차감하며 최대 Lv.20까지 계산한다. Lv.3에서 강제 종료하지 않는다.

레벨업당 성장 포인트 1개를 배분한다. 미사용 포인트는 `max(0, 레벨 - 1 - spentLevelPoints)`다. 성향·해독 누적 등 별도 영구 증가가 있으므로 `SUM(Base_Blocks) == User_Level`을 저장 무결성 규칙으로 사용하지 않는다. 현재 배분 함수에는 스탯 저장값 5 상한이 없지만 단계별 효과를 계산하는 `statLevel`은 0~5로 제한한다. 이를 모든 보너스가 무제한으로 효율을 늘리는 체제로 해석하지 않는다.

물류·수락한 의뢰 보상이 EXP를 지급한다. 해독 10회마다 기본 분석력이 1 오른다. 모든 일반 매매 수익을 EXP로 바꾸는 엔진은 연결되어 있지 않다.

## 2. 능력치 효과

### 분석력

**2026-10-19 상품 개편 기획:** 다크넷 해독키를 대체하는 **달빛가루는 사용 즉시 플레이어 분석력 레벨을 MAX(현재 효과 상한 Lv.5)**로 만든다. 영구/기간제 여부·지속시간·만료 처리는 미정이다. 아래 기존 해독기의 찌라시 한 건 유지 해석 +1 효과와 구분하고, 정보 진위 보증은 추가하지 않는다. [잡화점 상세](MOD_GDD_03_1_VivianStore.md)를 따른다. ✅ 기획 반영 / ⏳ 세부 설계·구현·검수 대기.

[찌라시 작성 가이드](RUMOR_AUTHORING_GUIDE.md)의 해석 1~5단계를 사용한다. 읽을 수 있는 비유·단서를 제공하며 문자 가림률·진위 판별 확률로 표시하지 않는다. 각성제는 분석력 +2를 120분간 적용한다. 해독기는 열람 찌라시 한 건의 유지 해석 단계를 +1, 최대 5로 올린다. 표시 단계는 분석력과 유지 단계 중 높은 값이며 완전 해석도 진위를 보증하지 않는다. 전략적 오보 5% 자동 추첨은 현재 고정 원고의 구현으로 간주하지 않는다.

### 협상력

기본 단계당 거래 수수료를 0.01%p 감면하며 최저는 0이다. 협상가 성향의 추가 30% 할인은 단계 감면 후 적용한다. 기본 단계당 물류 골드 보상은 +5%다. 대출 이율·세금 감면은 미구현이므로 현재 혜택에 합산하지 않는다.

### 운용력

| 기본 효과 단계 | 보유 종목 슬롯 |
| :--- | ---: |
| 0 | 5 |
| 1 | 10 |
| 2 | 15 |
| 3 | 20 |
| 4 | 25 |
| 5 | 30 |

양수 수량의 서로 다른 종목을 슬롯 1칸으로 센다. 자산가 성향은 슬롯 +2를 더한다. 현행 `buyCap()`은 Infinity이므로 1만/5만/20만/100만/1,000만G의 종목별 투자금 한도는 적용하지 않는다. 현금·호가 잔량·슬롯·주문 조건은 계속 검사한다. 안정제의 주문 주수 한도는 기본 100주에서 110주로 늘지만 무한 투자금 Cap에 +10% 금액 제한이 생기는 것은 아니다.

### 회복력

기본값과 활성 비타민 +2를 합한 회복력이 0~1이면 최대 하트 3개, 2~3이면 4개, 4 이상이면 5개다. 최대치 증가 자체는 현재 하트를 채우지 않는다. 자연 회복·불굴 성향 회복 속도 2배·별도 일일 노동 횟수 제한은 사용하지 않는다.

| 기본 효과 단계 | 누적 물류 효과 |
| :--- | :--- |
| 1 | 관성 제어 +10% |
| 2 | 파손 게이지 증가 -15% |
| 3 | 찌라시 지급 확률 +5%p |
| 4 | 이동 속도 +10% |
| 5 | 노동 종료 시 체력 차감 면제 확률 10% |

노동 기본 비용·드링크·카페인 회복량은 각각 하트 1개다. 벤치는 아이템 시계의 KST 날짜당 한 번 최대치로 회복한다. 다음 날 진행도 최대치로 회복한다. [노동 명세](MOD_GDD_02_LaborJobs.md)를 따른다.

## 3. 성향과 외형

### 소망이 레벨 성장 외형 — 2026-10-18 후속 채택

**2026-10-19 성장 대사·화분 연동 후속:** Lv.3·7·12·20의 머리 위 외형 전환에 화분 속 식물의 성장 단계도 함께 맞춘다. [정령 제작 기준의 대응 표](SPIRIT_CHARACTER_BASELINE.md)를 따른다. 심기 전에는 머리만 성장하고, 나중에 심으면 현재 레벨 단계를 표시한다. 소망이와 안나의 짧은 반응은 [대사 원고·예약/중복 방지 기준](MOD_GDD_07_DialogueDB.md)을 따르며 화분 반응의 구체 대사는 후속 설계한다. 작업·거래 도중 대화로 중단하지 않고 안전한 시점에 안내하며, 안나가 없으면 다음 대화까지 반응을 예약한다. 외형 전환 자체는 지연하지 않는다. 월세·수익·엔딩의 별도 조건과 추가 보상은 만들지 않으며 기존 성장 수치·보상은 유지한다. ✅ 연동 기획 반영 / ⏳ 구현·검수 대기.

고정 소망 요정은 Lv.1~2 기본 머리 → Lv.3~6 잎 하나 → Lv.7~11 두 잎 새싹 → Lv.12~19 두 잎 가운데 꽃봉오리 → Lv.20 작은 꽃 개화의 5단계로 성장한다. 외형은 Lv.3·7·12·20에서 전환하며 구간 내에서는 유지한다. 정확한 외형·의미·제작 상태는 [정령 제작 기준](SPIRIT_CHARACTER_BASELINE.md)의 레벨 성장 외형 표를 따른다. 아래 동물 스킨 설명은 이전 기록이며 이 성장 표현을 대체하지 않는다.

현재 최대 Lv.20·경험치 공식·성장 포인트·성향 효과는 유지한다. 장식 자체의 추가 능력치는 도입하지 않는다. ✅ 외형 성장 기획 반영 / ⏳ 에셋·레벨 표시 연동·저장 복원·게임 검수 대기. 기존 성장 엔진에 외형 자동 전환이 구현됐다고 기록하지 않는다.

분석가·협상가·자산가·불굴은 각각 대응 기본 스탯 +1을 제공한다. 2026-10-22 시작 칭호 기획은 폐기하며 시작 성향 능력은 유지한다. [폐기 범위·구현 상태](FEATURE_RETIREMENT_2026-10-22.md)를 따른다. 스킨의 동물 외형·테마를 성능 차이로 자동 연결하지 않는다.

## 4. 해금과 확장 기획

공매도·2/3/5배 레버리지는 현재 `isLevel10Unlocked` 플래그로 차단한다. UI는 레벨 10 해금으로 안내하지만 실제 레벨 상승에 따른 자동 전환과 운용력 2 검사까지 연결되었다고 기록하지 않는다. 개발자 해금 토글은 일반 진행 조건의 구현 증거가 아니다. Lv.20 서밋·명성·기관은 현재 성장 엔진과 별도의 확장 검토 대상이다. [기관 기획](MOD_GDD_15_InstitutionSystem.md)을 참조한다.
