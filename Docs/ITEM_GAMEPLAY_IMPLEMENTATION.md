# 비비안 상품 기능 — 웹 데모 구현

2026-09-29. 15종을 상점 구매 → 인벤토리 사용 → 실제 효과로 연결했다. `web/js/engine/ItemEngine.js`가 효과와 시간 경계를 처리하고 `web/js/app/ItemGameplay.js`가 기존 매매·물류·체력·저장에 연결한다. 오른쪽 아래 **효과 · 정보 · 우편 · 로또**에서 상태, 해독 대상, 우편, 응모권을 관리한다.

회복약은 체력을, 강화약은 분석·운용·회복 스탯을 변경한다. 운용 강화는 주문 한도를 높이고 회복 강화는 물류 체력 비용을 줄인다. 퀵-패스는 물류를 즉시 완료하며 체력을 소모한다. 정기 보급품은 다음 날부터 7일간 드링크를 우편으로 보낸다. 유료 정보는 실제 종목의 예정 이벤트를 생성하고 해독기와 다크넷은 가려진 내용을 연다. 경보기는 폭락 24시간 전부터 알리고 방독면은 차트 노이즈를 완화한다. 탈출 캡슐은 다음 폭락 직전 보유 포지션을 청산한다.

## 임시 데모 수치

기획에서 확정하지 않은 연결 수치는 최종 밸런스가 아니다. 강화 지속시간 120분, 기본 주문 한도 100주/운용 강화 110주, 물류 체력 하트 1개, 퀵-패스 보상 560G·70EXP를 사용한다. 유료 정보 이벤트는 24시간 뒤 해당 종목 +8%, 블랙 스완은 시작 2일 뒤 최초 발생 후 7일 간격으로 -20%·노이즈 60초이다. 해독 10회마다 기본 분석력이 1 올라 비밀 상품의 해금 경로를 제공한다. 경보기 생존 조건은 이벤트 종료 시 순자산이 양수인 경우 집계한다.

## 시간과 저장

### 회복력 연동 (2026-10-04)

사용자 결정에 따라 소수점 체력을 폐지했다. 기본 스탯과 비타민 +2를 합한 회복력 0~1은 최대 하트 3개, 2~3은 4개, 4 이상은 5개이다. 노동은 1개 소모하고 드링크·카페인은 1개 회복한다. 최대치 증가 자체는 현재 체력을 회복하지 않으며, 비타민 만료 시 줄어든 최대치를 넘는 체력만 차감한다. 벤치의 하루 1회 완전 회복과 다음 날 회복은 현재 최대치까지 채운다. 기존 소수점 저장은 올림 후 최대치로 제한해 정수 하트로 이전한다. HUD는 채운 하트/빈 하트로 표시하고 최대치 변화를 반영한다.

KST 날짜로 일일 구매·카페인 제한을 갱신한다. 실제 시각에 게임의 하루 진행량을 더하며, 퀵-패스·버프·우편·추첨도 같은 시계를 따른다. 종료 중 도착한 우편과 추첨은 다음 로드 시 처리한다. 브라우저 localStorage의 `stockwars-item-gameplay-v1`에 인벤토리·효과·응모/수령 기록·시장·잔고를 함께 저장한다. 새 게임은 해당 상태를 초기화한다.

## 로또 범위

게임 골드만 사용하는 로컬 시뮬레이션이다. 1~45의 중복 없는 6개 번호, 토요일 21:00 추첨, 19:00~21:05 판매 중지, 판매액 50% 적립 및 풀의 75%를 6개 일치 응모권에 배분한다. 나머지와 미당첨 회차 금액은 이월한다. 추첨한 응모권은 가방에서 제거하고 결과·미수령 당첨금은 보존한다. 실제 서버 추첨·서버 공동 풀·조작 방지는 후속 서버 구현이 필요하다.
