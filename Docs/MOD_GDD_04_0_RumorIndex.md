## 04-0. 유니버설 찌라시 시스템 통합 가이드
본 문서는 StockWars의 활성 거래 상장 종목들에 대한 찌라시 명세서로 연결되는 통합 인덱스입니다.

### 현행 작성 기준 (2026-10-06)

사용자 결정에 따라 문자 가림을 폐기하고 **읽을 수 있는 수수께끼 → 업종과 흐름 → 사건·방향 → 기업과 근거 → 상세 정보**의 해석 5단계로 작성한다. [작성 가이드](RUMOR_AUTHORING_GUIDE.md)와 [현재 25종·125개 본문 CSV](Data/Rumors.csv)를 현행 기준으로 사용한다. 하위 섹터 문서의 Tier 1~3은 과거 소재이며, 아래 가림 비율은 이전 규칙으로 보존한다. 희귀도는 해석 단계와 별도이며 해독기는 선택한 찌라시 한 건의 유지 해석 단계를 1 올린다.

### 현재 데이터와 확장 원고

현재 지급·본문·희귀도·열람 가치는 [작성 가이드](RUMOR_AUTHORING_GUIDE.md)와 [데이터 CSV](Data/Rumors.csv)를 따른다. 해석은 5단계이며 해독기는 선택한 한 건의 유지 단계를 +1 올린다. Tier 1~3·가림률·5% 오보 자동 추첨은 아래 원고를 그대로 실행하는 규칙이 아니다. 물류 지급 확률은 [노동 명세](MOD_GDD_02_LaborJobs.md)를 따른다.

아래 섹터 파일은 이전 소재이며 현재 보상 전체 목록이 아니다. IPO·상장폐지 연동 시 문서 자동 이동/삭제를 구현 조건으로 요구하지 않는다.
