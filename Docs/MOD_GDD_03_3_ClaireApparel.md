## 1. 판매 단위

클레어 상점은 **동물 캐릭터 자체의 완성형 스킨**을 판매한다. 이 문서에서 스킨·스타일은 같은 판매 단위를 뜻한다. 동물의 종·얼굴·귀·꼬리·털색·무늬·체형을 포함한 전체 외형 하나가 상품이며, 사람의 의상 세트나 기존 동물에 입히는 옷 한 벌을 뜻하지 않는다. 구매하면 보유 외형 목록(기존 옷장)에 등록하고 캐릭터 전체 외형을 교체한다.

피부색·헤어·의상·신발·얼굴의 개별 선택·판매와 파츠 혼합 착용은 제공하지 않는다. 의상·소품을 모든 동물의 필수 구성으로 요구하지 않는다. 상품 카드에 **동물 캐릭터 전체 외형 변경**을 명시한다. 기존 파일명 `ClaireApparel`과 '의상 상점' 표기는 링크·구현 이력이며 사람 의상 판매 기준으로 해석하지 않는다.

## 2. 구매와 옷장

2026-10-16 사용자 지정: 첫 판매 테마 **숲속 친구들 6종의 개별 가격은 각각 5,000G**다. 상점 카드와 상세 미리보기에 같은 가격을 표시한다. 판매 일정은 미정이며 현재 UI의 구매 버튼은 판매 준비 중 상태를 유지한다. 다른 테마의 가격까지 일괄 확정하는 기준은 아니다.

1. 테마별 스타일 카드에서 완성된 캐릭터와 상품명을 확인한다.
2. 미리보기에서 동물의 종·얼굴·털색·무늬·귀·꼬리·전체 체형을 확인한다. 준비된 방향·걷기 미리보기도 제공한다.
3. 골드 가격과 해금 조건을 확인하고 해당 스타일을 확정 구매한다.
4. 보유 스타일을 옷장에서 선택하여 통째로 착용한다. 닉네임·투자 성향·성장·자산은 유지된다.

보유 스타일은 보유 표시하고 중복 구매를 막는다. 뽑기·무작위 결과·중복 분해·마일리지는 제공하지 않는다. [뽑기 폐기 정책](MOD_GDD_03_0_ShopIndex.md#acquisition-policy)을 따른다.

## 3. 테마와 출시 범위

스킨은 **일반·한정판으로 구분하지 않고 테마별로 한 달 동안 직접 판매**한다. 판매 기간이 끝나면 해당 테마의 신규 구매를 종료한다. 구매한 스타일은 판매 종료 후에도 옷장에서 계속 선택·착용할 수 있다. 상품 카드에 테마명과 판매 시작·종료 일시를 표시한다.

현재 판매 계획은 **테마당 서로 다른 동물 캐릭터 완성형 스킨 6종**이다. 각 스킨은 개별 직접 구매 상품이며, 6종 묶음 구매를 필수로 요구하지 않는다. 실제 디자인·상품명·가격은 후속 확정한다.

한 달의 달력상 계산 방식, 현실 시간·게임 시간 중 기준, 테마별 시작 일정·동시 판매 수와 복각 여부·주기는 후속 운영 설계에서 확정한다. 한 달을 임의로 30일 또는 매월 1일 교체로 고정하지 않는다. 무료 제공·초기 선택 외형은 상점 판매 테마와 구분한다.

테마는 **서로 어울리는 동물 캐릭터 6종의 묶음**이다. 기준 예시는 **숲속 친구들: 붉은여우·시베리아다람쥐·너구리·유럽오소리·불곰·유럽토끼**다. 기존 6종의 제작 기록은 `output/forest-friends/`와 [최신 보정 기록](../output/style-unification-v3/README.md)을 확인한다. 제작된 6종과 실제 판매·게임 통합 완료는 구분한다. 사람 직업·의복·색상 6가지를 나눈 구성을 동물 6종 대신 사용하지 않는다.

현재 기본 외형 참고는 강아지·검은 고양이다. 무료 제공·초기 선택 외형의 최종 수량과 대상은 별도 결정이며, 과거 **4종 제작 시작안은 현행 확정 수량이 아니다**. 무료·초기 외형과 테마당 판매 스킨 6종은 구분한다. 추가 테마 구성, 가격·레벨 해금·일일 진열 방식·할인율은 후속 밸런싱에서 확정한다. 기존 '부위별 6종 진열'과 '테마별 포함·제외 파츠' 규칙은 폐기한다.

소품이 있는 디자인은 완성형 스킨에 포함하며 별도 사은품 파츠로 지급하지 않는다. 기존 3개 프리셋 편의 기능을 유지한다면 파츠 조합 대신 완성형 스타일 ID를 저장한다.

### 3년 테마 계획과 폐기 이력

**3년간 36개 동물 테마·테마당 6종, 총 216개 판매 스킨 구성**의 [동물 테마 구성 제안](Data/ANIMAL_SKIN_THEME_PLAN_36.csv)을 작성했다. 숲속 친구들 6종은 기존 구성을 유지하며 나머지는 사용자와 검토할 제안이다. 운영 1~36개월차·연차는 출시 순서안이며 실제 출시일·달력 월·동시 판매·복각은 별도 결정한다.

목록의 동물명은 캐릭터 후보의 통칭이며 품종·동물군을 포함한다. 이름이 같은 후보의 중복은 피했지만 216개를 분류학적으로 서로 다른 생물 종으로 해석하지 않는다. 테마는 외형·분위기 큐레이션이며 실제 공동 서식·계통 분류를 보장하는 목록이 아니다. 초기 기본 강아지·검은 고양이를 판매 후보로 그대로 중복 등록하지 않는다. 같은 동물의 재등장·재판매 정책은 이번 제안으로 확정하지 않는다.

1~24개월차는 포유류 중심으로 현행 동물 기본형에서 체형을 보정하는 순서안이다. 25~36개월차는 해양 포유류·조류·파충류·양서류·공룡·해양동물로 확장한다. CSV의 제작검토·비고에서 공통 보행·운반·앉기 및 가림 검증이 필요한 항목을 표시한다. 공룡은 멸종동물 확장 후보이며 해양동물의 지상 캐릭터 표현과 함께 채택 여부를 검토한다. 확장 후보 때문에 기본 공통 모션을 삭제하거나 비행·수영·신규 전용 기능을 자동 추가하지 않는다. 가격·특별 모션·실제 외형 제작은 별도다.

사람 직업·의상 중심의 이전 36개 목록은 **미채택·폐기**했으며 테마 후보·출시 일정·제작 입력으로 재사용하지 않는다. 동물 테마 목록은 테마 ID·테마명·동물 6종·선정 상태·운영 순서를 CSV로 관리한다.

## 4. 능력치와 경제 시스템

### 공통 모션과 상품별 특별 모션

모든 스타일은 4방향 정지·걷기, 벤치 휴식, 의자 앉기, 침대 눕기, 미니게임 상자 옮기기를 지원한다. 추가 특별 모션의 포함 여부는 테마·상품별 구성으로 정하며 일반·한정판 구분 조건으로 사용하지 않는다. 모든 상품은 공통 모션을 모두 갖춰야 하며 생활 기능을 독점하지 않는다.

특별 모션이 포함된 상품에는 해당 모션의 내용과 발동 조건을 표시하고 구매 전 미리보기로 확인할 수 있게 한다. 구체적인 모션 종류·수량·발동 방식은 상품별로 정한다. 테마별 한 달 판매를 공통 적용하며, 가격·구체 일정·복각 정책은 별도 결정한다. 뽑기 폐기와 직접 구매 원칙은 유지한다.

특별 모션은 외형 연출이다. 그 자체로 이동 속도·거래 능력·회복량 등의 보너스를 추가하지 않는다. 제작 규격은 [스타일 제작 가이드 4절](part_separation_guide_512.md#4-방향가림연결점)을 따른다.

스타일은 플레이어 외형이며 별도 캐릭터 직업·고유 스킬을 도입하지 않는다. **기존 부위별 능력치, 세트 효과와 가격을 완성형 스타일에 합산·복사하지 않는다.** 외형 능력치를 없앨지 또는 별도 성장 시스템으로 이관할지는 아직 결정하지 않았으며, 스타일 교체 효과로 임의 구현하지 않는다.

상점 직접 구매를 통한 골드 소비와 기존 상점 구매액의 기업 매출 연동은 유지한다. 수치 밸런스는 새 상품 단위를 기준으로 검토한다.

## 5. 제작과 전환

에셋 기준은 [완성형 캐릭터 스타일 제작 가이드](part_separation_guide_512.md)를 따른다. 기준 외형을 고정하고 방향·행동별 완성 프레임을 직접 제작하여 스프라이트 시트로 전달한다. 같은 비율·접지점·동작 참고의 재사용은 검수 후 적용하며 유저의 부위별 혼합 착용은 도입하지 않는다. 프레임 좌표·재생 순서·시간·연결점을 메타데이터로 관리한다. 월드 적용에는 스타일마다 필수 방향·동작이 필요하다.

이전 파츠 카탈로그의 가격·스탯·얼굴/헤어/의상 판매 규칙은 폐기했다. 기존 보유 데이터의 실제 존재 여부와 이관 정책은 구현 전에 별도 확인한다.
