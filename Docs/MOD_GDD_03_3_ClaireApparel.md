# StockWars GDD: MOD_GDD_03_3 클레어 캐릭터 스타일 상점

**개정:** 2026-09-28 / 완성형 외형 선택·판매 전환
**상태:** 판매 단위 확정 / 상품·가격·해금 조건 세부 검증 예정

## 1. 판매 단위

클레어 상점은 **캐릭터 스타일**을 판매한다. 하나의 상품은 얼굴·피부색·헤어·상의·하의·신발·포함 장식을 합친 완성된 외형이다. 구매하면 해당 스타일이 옷장에 등록되고 전체 외형을 교체할 수 있다.

상의·하의·신발·헤어 단품 판매, 파츠별 착용, 독립 얼굴 구매는 제공하지 않는다. '의상'이라는 표시만으로 얼굴과 헤어까지 바뀌는 점을 숨기지 않고, 상품 카드에 **전체 외형 변경**을 명시한다.

## 2. 구매와 옷장

1. 테마별 스타일 카드에서 완성된 캐릭터와 상품명을 확인한다.
2. 미리보기에서 포함된 얼굴·헤어·의상·신발·장식 전체를 확인한다. 준비된 방향·걷기 미리보기도 제공한다.
3. 골드 가격과 해금 조건을 확인하고 해당 스타일을 확정 구매한다.
4. 보유 스타일을 옷장에서 선택하여 통째로 착용한다. 닉네임·투자 성향·성장·자산은 유지된다.

보유 스타일은 보유 표시하고 중복 구매를 막는다. 뽑기·무작위 결과·중복 분해·마일리지는 제공하지 않는다. [뽑기 폐기 정책](MOD_GDD_03_5_LuckyCapsuleGacha.md)을 따른다.

## 3. 테마와 출시 범위

기존 내추럴 스타터, 모던 다크, 코지 파스텔 등 테마는 완성형 디자인 후보로 활용한다. 기존 M/F 파츠 목록을 그대로 신규 상품 수량으로 전환하지 않는다. 스타일별 외형을 검토하여 실제 출시 목록을 확정한다.

초기 기본 외형은 소수로 시작하며 **4종은 제작 시작안**이다. 무료 제공·초기 선택 외형의 수량과 추가 상점 상품, 가격·등급·레벨 해금·일일 진열 수량·할인율은 후속 밸런싱에서 확정한다. 기존 '부위별 6종 진열'과 '테마별 포함·제외 파츠' 규칙은 폐기한다.

모자·액세서리 역시 스타일에 포함하며 별도 사은품 파츠로 지급하지 않는다. 기존 3개 프리셋 편의 기능을 유지한다면 파츠 조합 대신 완성형 스타일 ID를 저장한다.

## 4. 능력치와 경제 시스템

### 공통 모션과 한정판 구분

모든 스타일은 4방향 정지·걷기, 벤치 휴식, 의자 앉기, 침대 눕기, 미니게임 상자 옮기기를 지원한다. **추가 특별 모션은 한정판 스킨에만 제공**한다. 한정판도 공통 모션을 모두 갖춰야 하며 생활 기능을 독점하지 않는다.

한정판 상품에는 포함된 특별 모션의 내용과 발동 조건을 표시하고 구매 전 미리보기로 확인할 수 있게 한다. 구체적인 모션 종류·수량·발동 방식은 상품별로 정한다. 한정판 여부를 기존 가격 등급이나 판매 기간과 자동으로 동일시하지 않으며, 판매 일정·가격·복각 정책은 별도 결정한다. 뽑기 폐기와 직접 구매 원칙은 유지한다.

특별 모션은 외형 연출이다. 그 자체로 이동 속도·거래 능력·회복량 등의 보너스를 추가하지 않는다. 제작 규격은 [스타일 제작 가이드 4절](part_separation_guide_512.md#4-방향과-애니메이션)을 따른다.

스타일은 플레이어 외형이며 별도 캐릭터 직업·고유 스킬을 도입하지 않는다. **기존 부위별 능력치, 세트 효과와 가격을 완성형 스타일에 합산·복사하지 않는다.** 외형 능력치를 없앨지 또는 별도 성장 시스템으로 이관할지는 아직 결정하지 않았으며, 스타일 교체 효과로 임의 구현하지 않는다.

상점 직접 구매를 통한 골드 소비와 기존 상점 구매액의 기업 매출 연동은 유지한다. 수치 밸런스는 새 상품 단위를 기준으로 검토한다.

## 5. 제작과 전환

에셋 기준은 [완성형 캐릭터 스타일 제작 가이드](part_separation_guide_512.md)를 따른다. 제작용 파츠 분리와 본 기반 2D 리깅을 사용하며 같은 비율·동작 틀의 공유를 검증한다. 내부 파츠 합성은 허용하지만 유저의 부위별 혼합 착용을 뜻하지 않는다. 실시간 리깅/베이크 전달 방식은 후속 결정한다. 월드 적용에는 스타일마다 필수 방향·동작이 필요하다.

[이전 파츠 카탈로그](ARCHIVE_ClaireApparel_Parts_2026-09-28.md)는 디자인 이력용으로 보존한다. 그 문서의 가격·스탯·얼굴/헤어/의상 판매 규칙은 현행 상품 명세가 아니다. 기존 보유 데이터의 실제 존재 여부와 이관 정책은 구현 전에 별도 확인한다.
