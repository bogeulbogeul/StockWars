## 03-4.1. 도서 시스템 및 학습 정책

### A. 학습 프로세스 (Learning Process)
서점의 도서는 단순히 구매한다고 즉시 적용되지 않으며, **'현실 시간'** 기반의 독서 과정을 거쳐야 스탯이 영구적으로 상승합니다.

1.  **구매 (Purchase)**: 인벤토리의 소비창에 도서 아이템이 추가됩니다.
2.  **독서 시작 및 중단 (Start & Pause)**: 오피스의 가구(책상, 침대)를 통해 독서를 진행합니다.
    - **진행 방식**: 독서를 시작하면 현실 시간 타이머가 작동합니다.
    - **진도 저장 (Progress Save)**: 독서 도중 다른 활동을 위해 중단하더라도, 지금까지 **읽은 시간(진척도)은 아이템에 저장**됩니다. 
    - **이어 읽기 (Resume)**: 나중에 다시 독서를 시작할 때, 처음부터 읽는 것이 아니라 **남은 시간부터 이어서** 읽을 수 있습니다.
3.  **속독 기능 (Speed Reading) [NEW]**: 시간이 부족한 유저를 위해 스테미너를 사용하여 즉시 완독할 수 있는 선택지를 제공합니다.
    - **소모 비용**: **남은 시간 10분당 스테미너(Heart) 1개** 소모.
    - **사용 예시**: 30분짜리 심화 도서를 읽기 시작한 즉시 3개의 하트를 지불하면 즉시 완독 처리됩니다.
4.  **완독 및 강화**: 누적 현실 시간이 목표 시간에 도달하거나 속독을 완료하면, 스탯 블록이 영구 추가됩니다.

### B. 등급 및 학습 효율 (Book Tiers)
| 등급 | 요구 레벨 | 소요 시간 (누적 현실 시간) | 속독 비용 (Stamina) | 스탯 보너스 |
| :--- | :--- | :--- | :--- | :---: |
| **Basic (기초)** | Lv.1 이상 | **10분** | 하트 1개 | **+1 블록** |
| **Advanced (심화)** | Lv.3 이상 | **20분** | 하트 2개 | **+2 블록** |
| **Master (정점)** | Lv.5 이상 | **30분** | 하트 3개 | **+3 블록** |

## 03-4.2. 도서 카탈로그 (Book Catalog)

### 🟢 [Basic] 기초 이론 (Lv.1~2 지향)
트레이더로서 갖춰야 할 기본적인 지식을 제공합니다. (각 5,000 G)

| 도서 명칭 | 대상 스탯 | 상세 설명 |
| :--- | :---: | :--- |
| **차트 분석의 정석** | **분석력** | 캔들 차트와 기술적 지표의 기초를 다룹니다. |
| **현명한 자금 관리** | **운용력** | 파산하지 않는 자산 배분법을 학습합니다. |
| **트레이더의 명상록** | **회복력** | 뇌동매매를 억제하는 심리 조절법을 다룹니다. |
| **비즈니스 대화의 기술** | **협상력** | 상대방의 의중을 읽는 기초 협상법을 학습합니다. |

### 🔵 [Advanced] 실전 심화 (Lv.3~4 지향)
본격적인 전문 트레이딩을 위한 고성능 스탯을 제공합니다. (각 25,000 G)

| 도서 명칭 | 대상 스탯 | 상세 설명 |
| :--- | :---: | :--- |
| **알고리즘 매매의 원리** | **분석력** | 데이터 기반의 정밀한 필터링 로직을 구축합니다. |
| **레버리지와 시장 미시 구조** | **운용력** | 호가창과 유동성을 활용한 한도 극대화 전략. |
| **번아웃 방지 실전 가이드** | **회복력** | 극심한 하락장에서도 멘탈을 유지하는 고급 기술. |
| **찌라시 선별과 정보 로비** | **협상력** | 고급 정보원을 확보하고 유리한 계약을 이끌어내는 법. |

### 🟡 [Master] 정점의 지혜 (Lv.5 지향 - 데모 이후 해금)
시장을 지배하는 제국의 트레이더를 위한 도서입니다. (각 100,000 G)

| 도서 명칭 | 대상 스탯 | 상세 설명 |
| :--- | :---: | :--- |
| **퀀트 투자의 신기원** | **분석력** | 시장의 모든 노이즈를 제거하는 궁극의 분석안. |
| **자본의 제국: 무한 운용** | **운용력** | 보유 종목 수 제한을 초월하는 포트폴리오 관리. |
| **불멸의 강철 멘탈** | **회복력** | 어떤 손실에도 스테미너가 깎이지 않는 부동심. |
| **시장을 움직이는 목소리** | **협상력** | 모든 NPC를 자신의 편으로 만드는 절대적 협상력. |

## 03-4.3. 앤티그래비티 세미나 시스템 (Antigravity Seminar) [NEW]
매주 주말, 서점 중앙 홀에서 업계 전문가를 초빙하여 진행하는 특수 세미나 시스템입니다. (상세 내용은 [세미나 퀴즈 GDD](file:///c:/Users/Administrator/Documents/GitHub/StockWars/Docs/MOD_GDD_18_QuizSystem.md) 참조)

### A. 운영 정책
- **개최 시간**: 매주 **토요일 오후 14:00 ~ 15:00** (현실 시간 기준 1시간 동안 자유 입장 가능).
- **참여 조건**: 회당 **1,000 G** 참가비 소모.
- **진행 방식**: 
    1. 토요일 14:00 ~ 15:00 사이 서점 NPC '소피아'에게 참가비(1,000 G) 지불 후 입장. (1시간 내 자유 입장/퇴장)
    2. **3연속 퀴즈**: 명저 인용 퀴즈가 연속 3문제 출제됩니다. (문제당 30초 제한)
    3. **결과 산출**: 3문제를 모두 풀면 정답 개수에 따라 보상이 자동 정산됩니다.

### B. 세미나 참여 보상 (차등 지급)
정답 개수에 따라 트레이더의 역량 향상 폭이 달라집니다.

| 결과 | 보상 내용 | 버프 지속 시간 |
| :--- | :--- | :---: |
| **3/3 (Perfect)** | 버프 전체 + 프래그먼트(대) + 스탬프 1개 | 24시간 |
| **2/3 (Great)** | 버프 전체 + 프래그먼트(중) + 스탬프 1개 | 12시간 |
| **1/3 (Normal)** | 프래그먼트(소) + 스탬프 1개 (버프 없음) | - |
| **0/3 (Fail)** | 스탬프 1개 (위로 보상) | - |

### C. 세미나 출석부 (Attendance Stamp)
세미나에 참여할 때마다 '지식의 인장' 스탬프를 획득합니다. 누적 횟수에 따라 특별한 보상을 지급합니다.
- **4회 참여**: [희귀] 서재 전용 인테리어 소품 증정.
- **8회 참여**: [에픽] 고급 도서 50% 할인권 3매.
- **12회 참여**: [레전더리] **'통찰의 눈'** 얼굴 파츠 (상점 비매품).

## 03-4.4. 특수 상점 기능
- **도서 추천**: 현재 유저의 가장 낮은 스탯을 분석하여 적절한 도서를 UI 상단에 추천합니다.
- **베스트셀러**: 유저들이 가장 많이 구매한 도서에 전용 마크를 부여합니다.
- **중고 도서 매각**: 이미 읽은 도서를 소장용으로 보관하거나, NPC에게 저렴하게 되팔 수 있습니다.
