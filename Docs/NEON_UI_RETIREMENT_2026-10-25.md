# 구형 네온 UI 화면 제거

**P1 (Major) · ✅ 완료: 웹·기존 실행본 리소스·자동/브라우저 검증 / ⏳ 대기: 사용자 최종 시각·플레이 검수.**

사용자는 네온 스타일 교체 대신 UI 자체의 화면 제거를 선택했다. 이어서 스마트폰·거래·가방·설정까지 제거하면 해당 기능을 화면에서 이용할 수 없다는 설명을 받고 그 범위를 명시적으로 승인했다. 구형 화면을 새 스킨으로 교체하거나 대체 메뉴를 자동 제작하지 않는다.

## 제거 범위

- 상시 월세 패널은 게임에서 생성하지 않으며 전용 스타일 로딩도 제거했다. 월세 목표·정산 계산·저장은 유지한다.
- 구형 스마트폰 본체/버튼·거래·차트·뉴스 상세·월세 정산 화면·가방/찌라시 창·설정·프로필·친구·랭킹·서버 선택·캐릭터 등록·가구 편집·구형 증권사 화면을 비표시·비활성화한다. 열기/토글 메서드와 네이티브 dialog 열기도 차단해 P/I나 과거 호출로 다시 뜨지 않는다.
- 기존 컨트롤러·DOM 데이터 참조는 저장과 구형 계산 호환을 위해 보존한다. 해당 루트는 `hidden`/`inert`/`aria-hidden` 및 전용 표시 차단을 적용하며 화면 기능 진입은 종료한다. 모든 과거 소스·데이터 파일을 물리적으로 삭제했다는 의미는 아니다.
- 현재 3D 마을·실내·이동/출입·새 크레파스 대화·전시 스토리와 새 잡화점 화면은 유지한다. 새로운 기능 메뉴 제작은 별도다.

## 새 안내

후속 사용자 요청으로 마을 상단의 상시 `증권사 로비 시점 확인` 문구와 하단 공통 조작 안내를 제거했다. 증권사 문 앞의 상황별 F 입장 안내와 기존 이동·먹기·출입 조작은 유지한다. 공용 캐릭터의 하단 안내는 DOM에 부착하지 않고 실내 컨트롤러의 내부 참조만 보존한다.

기존 짙은 바탕과 청록 네온 테두리의 토스트 CSS를 삭제했다. 알림은 아이보리 바탕·차분한 갈색 본문·부드러운 모서리의 새 공통 모듈을 사용한다. 레벨업은 작은 새싹 표시와 `레벨 3이 되었어요`를 2.5초 보여준 뒤 사라지며 선택 버튼이나 추가 보상을 만들지 않는다. 하단 조작 안내와 간격을 확보한다. 옛 아이템 사용 네온 모달도 공통 알림으로 전환했다.

## 검증과 배포

- 전체 자동 검사 333개 중 330개 통과. 나머지 3개는 기존 봉봉 삭제 기대 검사 2개와 Node의 로컬 GLB fetch 제한이다.
- 실제 앱 초기화·타이틀/도착 건너뛰기·현재 마을 로딩 후 P/I 및 옛 화면 열기/토글 호출을 검사했다. 구형 화면 노출 0개, 네이티브 열린 dialog 0개, 월세 패널 생성 0개를 확인했다.
- 실제 레벨 상승으로 새 알림을 촬영하고 2.5초 후 닫힘과 같은 레벨 갱신 시 재등장하지 않음을 확인했다. JavaScript 예외 0건. 사용자의 원래 저장 대신 격리된 브라우저 테스트 저장을 사용했다.
- 웹과 `electron-app/dist/win-unpacked/resources/web/`에 화면 제거와 새 알림을 반영했다. 기존 실행본에는 전시 모드 부트스트랩 모듈이 없어 종전 시작 흐름을 유지하고 인터페이스 제거 연결만 추가했다. 이 때문에 두 `main.js` 전체가 동일하다고 보지 않는다. 두 리소스 모두 구형 루트 27개 중 화면 노출 0개·월세 패널 0개·열린 dialog 0개·JavaScript 예외 0건을 확인했다. 설치 프로그램 재빌드·Electron 직접 플레이 및 사용자 최종 검수는 별도다. 열려 있는 게임은 재시작해야 적용된다.
