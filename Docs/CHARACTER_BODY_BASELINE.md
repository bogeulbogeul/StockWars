## 2. 유지할 형태

| 부위 | 현재 기준 |
| --- | --- |
| 전체 | 큰 머리와 짧은 몸·팔다리의 둥근 요정 체형. 좌우 폭뿐 아니라 측면 두께도 함께 유지한다. |
| 머리 | 몸통보다 큰 매끈한 둥근 덩어리. 정면의 폭, 옆면의 볼륨, 후면의 곡선을 세 방향으로 대조한다. |
| 얼굴 | 검은 타원 눈 두 개와 작은 U자 미소가 기본. 얼굴 위치·크기는 현재 게임 텍스처를 기준으로 한다. 표정 14종은 별도 상태다. |
| 머리 아래·어깨 | 길게 드러난 사람형 목이 아니라 머리 아래에서 짧게 몸통으로 이어지는 형태. 새 목·어깨 시안을 이 사진에 덧씌우지 않는다. |
| 몸통 | 가슴부터 둥근 배·골반으로 이어진다. 정면 배 폭만 줄이거나 측면 배 두께만 임의로 늘리지 않는다. |
| 팔 | 어깨에서 손끝까지 짧고 통통한 단순한 형태. 기본 자세에서는 몸 양옆으로 비스듬히 내려온다. 모션은 팔꿈치 분절 없이 통팔 회전을 사용한다. |
| 다리·발 | 짧은 다리 두 개와 둥근 발. 골반 연결 위치·다리 간격·발 크기와 바닥 높이를 함께 유지한다. |
| 표면 | 현재 채택된 매끈한 무광 클레이 느낌. 거친 요철이나 피부 질감을 기본 조건으로 추가하지 않는다. |

이번 기준은 **의상 없는 몸 자체**다. 캐릭터 의상 신규 제작 중단 결정을 유지한다. 색·표정·장식이 다른 파생 캐릭터를 만들 때도 먼저 이 기본 체형과 정면/측면/후면을 대조하며, 체형 변경이 필요하면 별도 사용자 요청과 검수로 구분한다.
