# 현행 기업 뉴스 288건 게임 적용

**P1 (Major) · ✅ 완료: 웹·기존 실행본 리소스 적용·브라우저 자동 검증 / ⏳ 대기: 사용자 최종 플레이 검수.**

현재 72개 회사의 일반 호재·일반 악재·핵심 호재·핵심 악재 각 1건, 총 288건의 제목·요약·출처·본문을 게임 뉴스 데이터에 연결했다. [현행 원고](MOD_GDD_12_0_CorporateNewsIndex.md)와 [구조화 원고](Data/CorporateNews_Current.json)를 그대로 사용한다.

## 연결 방식

- `web/js/data/news/`의 업종별 8개 모듈과 `newsCatalog.js`가 뉴스 데이터를 제공한다. `stocksData.js`의 기존 `INITIAL_NEWS` 내보내기 계약을 유지하므로 시장 엔진·관련 종목 조회·기사 상세 참조가 같은 새 목록을 사용한다.
- 기존 초기 뉴스 5건을 새 288건으로 교체했다. 이전 5건은 `output/news-rollout-2026-10-25/previous-initial-news.js`에 보존했다. 종목 ID와 이름·본문을 원고와 대조했다.
- 288건은 초기 소식 모음이다. 서로 독립된 시나리오를 시간순 실황으로 오인하지 않도록 임의의 ‘몇 분 전’ 대신 ‘소식 모음’을 사용한다. 실제 날짜별 발행·무작위 발생·중복 방지 시간표는 추가하지 않았다.
- 뉴스 유형은 `뉴스`이고 호재·악재는 편집 분류다. 확정 등락률·발생 확률을 임의 부여하지 않으며 기존 일별 가격 계산은 유지한다. 찌라시의 진위·결말이나 퀴즈 정답과 연결하지 않는다.
- 구형 뉴스 화면·스마트폰·거래 화면의 제거 상태는 유지한다. 이번 적용은 뉴스 데이터 연결이며 현재 마을에서 뉴스를 읽는 새 화면을 만든 것은 아니다.
- 사용자 저장을 읽거나 수정하지 않았다. 현행 시장 엔진은 시작할 때 초기 뉴스 목록을 메모리로 가져온다. 실행 중인 게임은 재실행해야 새 목록을 사용한다.

## 검증·실행본

웹과 기존 실행본의 리소스를 각각 HTTP로 제공하고 실제 Chrome에서 `MarketEngine`을 초기화했다. 각각 288건·72개 회사·회사당 4건을 확인했고, 전 288건의 모든 원고 필드가 일치했다. 격리된 실제 `NewsDetailModal`에서 기사 제목과 본문 3개 문단 전부를 열어 대조했으며 엔진 초기화 후에도 새 목록을 유지했다. 양쪽 JavaScript 예외는 0건이다. 제거한 뉴스 화면을 실제 게임에 다시 표시한 검사는 아니다.

`electron-app/dist/win-unpacked/resources/web/`에 런타임 10개 파일을 동기화하고 SHA-256 일치를 확인했다. 설치 프로그램을 재빌드하거나 Electron 직접 실행·사용자 최종 플레이 검수를 완료한 것은 아니다.
