## 현행 기준과 데이터

- [최신 찌라시 작성·데이터 가이드](RUMOR_AUTHORING_GUIDE.md): 분석력 Lv.1~10·해석 1~10단계. 수수께끼 → 사건·핵심 조건 → 출처·경쟁·시점·정보의 한계.
- [현재 게임 데이터 CSV](Data/Rumors.csv): 기존 25개 사건·5단계 본문 125개를 유지한다. 웹 런타임은 JS 데이터를 사용하며 CSV 직접 로딩이나 10단계 구현 완료를 뜻하지 않는다.
- [현행 회사명 대응표](STOCK_NAMES_2026-10-22.md): 종목 ID를 기준으로 이름을 확인한다.

10단계 신규 원고·데이터·게임 구현·저장 이관·검수는 ⏳ 대기다. 최대 해석도 진위·수익을 보장하지 않는다.

## 과거 자료

이전 일반·IPO 업종별 원고는 현행 원고에서 제외했다. [과거 루머 보관 안내](Archive/Rumors_2026-10-25/README.md)에서만 찾아본다. 옛 이름·Tier·가림·확정 수익 표현을 신규 명세로 사용하지 않는다. 기존 게임 데이터·저장·IPO 구현 상태는 이번 문서 정리로 변경하지 않는다.
