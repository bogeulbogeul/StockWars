사용자가 v8의 정면을 확인한 뒤 “이정도면 괜찮아. 게임에 적용해줘.”라고 확정했다. 현재 원래 앉기 자세의 v6 GLB와 v8 배치 `(0, -103)`, 높이 `64.00000343`을 유지해 웹/기존 실행본 리소스 적용을 확정했다. 두 배포 경로의 모델 SHA256은 `c408eca14aee7789d6fc021147088b8a8275bb23b03c1286d10d4bd0b3025184`로 동일하고 배치 데이터도 일치한다. 아래 접촉 검사 기록은 보존하되 이번 채택을 이유로 새 자세/발 보정을 추가하지 않는다. ✅ 사용자 정면 외형 채택·게임 리소스 적용·기존 두 리소스 브라우저 검사 / ⏳ 사용자 최종 플레이 검수. 설치 프로그램 재빌드나 Electron 직접 실행을 뜻하지 않는다.
