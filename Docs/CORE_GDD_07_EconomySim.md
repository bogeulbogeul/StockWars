# CORE_GDD_07 현재 경제와 정산

> 개정: 2026-10-16. 현재 코드의 밸런스이며 장기 서비스의 최종 확정 수치표는 아니다.

## 2026-10-19 시작 자금 출처 변경 — 채택 기획

**P0 (Core) · ✅ 완료: 기획 반영 / ⏳ 대기: 경제 조정·구현·저장 이관·검수.** 새 도입에서는 기존 시작 자금 5,000G를 노드 은행의 정착 대출로 지급한다. 무료 시작 자금과 대출금을 합산하지 않으며 은행 지급 후 오피스 재지급을 막는다. 정착 지원금 2,000G는 기존 완료·건너뛰기 조건으로 별도 유지한다. 대출 원금은 수익이나 지원금으로 취급하지 않는다.

이자·상환 일정·연체 처리는 [금융 명세](CORE_GDD_04_FinancialInstitutions.md)의 미정 항목이다. 7일 차 현금 월세 5,000G와 대출 상환은 분리한다. 기존 저장의 채무 소급 부과는 하지 않는다. 아래 현재 코드 설명은 대출 구현 완료가 아니며, 순자산 표시·채무 저장·상환 처리와 첫 주 경제 균형은 후속 설계·검증한다.

## 1. 자금 유입과 소비

시작 자금 5,000G·튜토리얼 정착 지원금 2,000G를 중복 없이 지급한다. 노동·수락한 의뢰·주식 매도·배당·로컬 로또 당첨금이 현금에 반영된다. 매수·상점 소비·수수료·월세가 현금을 줄인다. 모의투자 경쟁룸의 자금·가상 배팅·가상 배당금은 메인 잔고에 합산하지 않는다.

물류는 60초 점수제로 S 800G/100EXP, A 560G/70EXP, B 320G/40EXP, C 100G/10EXP이며 협상력 골드 보정을 적용한다. 종전 Easy 2.5분/Normal 4분/Hard 6분 수익률 표는 폐기한다. 노동은 기본 하트 1개를 쓰고 일일 횟수 제한은 없다. 상세는 [노동 명세](MOD_GDD_02_LaborJobs.md)를 따른다.

## 2. 날짜와 첫 월세

**2026-10-19 최종 시간 정정:** 점심 도착·정착 후 선택한 첫 노동/투자 체험을 마치면 해 질 무렵으로 연출하고, 이후 첫 숙박을 완료해야 로컬 시간으로 전환한다. 남은 활동과 공통 자립 안내는 숙박 후에 진행한다. 아래 활동 전 숙박·활동 시작 시 전환 기록보다 [현재 튜토리얼 시간 흐름](CORE_GDD_10_TutorialSystem.md)을 우선한다. 경제 Day·월세·배당의 날짜 매핑은 계속 후속 설계 대상이다.

**2026-10-19 최신 점심 유지 정정:** 첫 숙박 후 점심으로 재개하고, 첫 노동 또는 투자 배우기를 시작하기 전까지 점심 연출을 유지한다. 첫 활동 시작을 로컬 시간 전환 경계로 설계하며 아래 첫 숙박 직후 전환 설명보다 우선한다. 정확한 전환 체크포인트·경제 Day 매핑은 후속 설계다. [튜토리얼](CORE_GDD_10_TutorialSystem.md)을 따른다.

**2026-10-19 시간 전환 채택 기획:** 아침 버스 출발·해 질 무렵 도착은 연출 시간이며 첫 숙박 후 일반 생활은 기기 로컬 현재 날짜·시각을 따른다. [도입 시간 명세](CORE_GDD_10_TutorialSystem.md)를 따른다. 아래 경제 Day·다음 날 조작은 기존 구현 기록이다. 로컬 날짜와 경제 Day의 매핑·첫 숙박의 경제 일수 처리·미접속 정산·배당/회복 주기는 후속 설계하며 첫 월세 5,000G와 대출 조건을 임의 변경하지 않는다. 도입 경과만으로 정산·보상·채무를 추가 처리하지 않는다. ✅ 시간 방향 기획 반영 / ⏳ 경제 날짜 상세 설계·구현·검수 대기.

시장은 Day 1에서 시작하고 다음 날 조작으로 최대 Day 7까지 진행한다. 다음 날 진행은 아이템 시계를 하루 앞당기고 하트를 현재 최대치로 채운다. 현실 자정 경과만으로 `market.day`가 자동 증가하는 구조가 아니다.

Day 7에 현금 5,000G 이상이면 월세를 한 번 차감하고 `rentSettlement`에 납부 결과를 저장한다. 주식 평가액은 납부 재원이 아니며 부족할 때 강제 매도하지 않는다. 이미 납부했다면 다시 차감하지 않는다. 현금 부족 시 미납 결과만 표시하며 자금 확보 후 다시 정산할 수 있다. 72시간 유예·현금 0 즉시 압류·Lv.3 암전 종료는 현재 규칙이 아니다.

## 3. 배당과 거래 수수료

다음 날 진행 시 보유 롱 포지션에 `round(현재 주가 × 수량 × 종목 dividend / 7)`를 지급한다. 숏은 이 배당 대상에서 제외한다. 현재 구현에는 월요일 00시 일괄 지급·72시간 보유 요건·모든 종목 고정 2.5% 배당 검사가 없다.

메인 거래 기본 수수료는 스마트폰·홈 0.15%, 증권사 0.01%다. 기본 협상력 단계당 0.01%p 감면 후 협상가 성향의 30% 추가 할인을 적용하며 최저 0이다. 실제 체결 가격·수량에 대한 금액은 주문 엔진을 따른다. [시장](CORE_GDD_02_MarketEngine.md)·[성장](CORE_GDD_03_PlayerGrowth.md)을 참조한다.

## 4. 로또와 시간

골드만 사용하는 저장 단위 로컬 로또다. 아이템 시계의 KST 토요일 19:00~21:05에는 판매를 막고 21:00 추첨분을 처리한다. 1~45 중 서로 다른 6개 번호, 판매액 50% 적립, 6개 일치 1등에 풀의 75%를 배분하며 나머지·미당첨 금액은 이월한다. 서버 전체 공동 풀·서버 권한 추첨은 구현하지 않았다.

아이템 시간은 실제 시각에 게임 진행 오프셋을 더한 값이다. 버프·패스·우편·추첨의 경과 시간은 순수 접속 시간 전용이 아니다. [기술 명세](CORE_GDD_06_TechnicalSpec.md)를 따른다.

## 5. 현재 시행하지 않는 장기 경제

은행 이자·적금·예금, 소득세·자산세·가구 경비 공제, 횡령·회생·신년 휴장은 확장 검토안이다. 현재 반복 정산이나 세금 차감이 구현된 것으로 기록하지 않는다. 예금 제공 여부, 적금 주간 1%와 4주 12% 간 충돌은 확정하지 않는다. 구 매매 수수료 2배·가구 버프 반감 등 회생 정책은 [전문 검토안](MOD_GDD_14_DebtRelief.md)에서 검토한다.

블랙 스완 기능은 엔진의 시험 로직과 별개로 현재 게임 연결에서 비활성화한다. 100일 전역 위기와 2일 후 최초·7일 간격 로컬 시험 로직을 현재 발생 일정으로 안내하지 않는다.
