# StockWars GDD: MOD_GDD_06. NPC 레지스트리 및 상호작용 (NPC Registry)

**버전:** v2.38.0 (2026.05.11 테마 상호작용 삭제 반영본)  
**기능:** NPC 프로필, 신뢰도 시스템, 안나의 개인 퀘스트 메커니즘

---

## 1. 메인 조력자: 안나 '사이퍼' (Anna Cypher)

### 1.1. 캐릭터 프로필
- **역할**: 전직 수석 애널리스트 출신의 개인 매니저 및 파트너.
- **성격**: 냉철한 현실주의자. 유저의 수익률뿐만 아니라 도덕적 선택(횡령 등)에 따라 태도가 변화함.
- **특수 모드**:
    - **오피스 룩 (06-24시)**: 정석적인 브리핑과 리스크 가이드.
    - **잠옷 룩 (00-06시)**: 하늘색 실크 잠옷 착용. 유저의 건강 염려 및 심야 시장 분석 지원.
- **외모**: 컬이 굵은 붉은색 단발머리(Bob), 초록색 눈. 기본 착장으로 레몬색 블라우스, 네이비 오피스 스커트, 갈색 단화를 착용. (의상 고정)
- **상호작용**: 유저의 자산 상태, 신뢰도(Reliability), 그리고 시장 상황에 기반한 전문적인 데이터 피드백 제공. **(물질적 선물 거부 정책: 안나에게는 아이템 선물하기 기능이 비활성화됩니다.)**

### 1.2. 안나의 선물 (Anna's Gifts)
신뢰도가 특정 수준 이상일 때, 안나가 유저의 메일함으로 선물을 보냅니다. 신뢰도 레벨이 높을수록 선물의 가치와 발동 확률이 상승합니다.

| 신뢰도 레벨 | 점수 기준 | 선물 해금 | 선물 구성 (예시) | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **LV 1** | 0 ~ 19 | - | - | 초기 신뢰 상태 |
| **LV 2** | 20 ~ 39 | **최초 해금** | 스테미너 드링크 1개 | 관계 형성 시작 |
| **LV 3** | 40 ~ 59 | 활성화 | 찌라시 조각 + 500G | 유능한 파트너로 인정 |
| **LV 4** | 60 ~ 79 | 활성화 | 희귀 찌라시 + 1,000G | 사적 유대감 형성 |
| **LV 5** | 80 ~ 100 | **프리미엄** | 대용량 Cash + 전용 소모품 | **'사이퍼의 서약'** 가능 |

- **트리거**: 실시간 48시간마다 신뢰도 체크 후 확률적 발동 (LV 2: 10% ~ LV 5: 30%).

### 1.3. 사이퍼의 서약 (Cipher's Vow: Hidden Route)
안나와의 관계를 단순한 파트너 이상으로 격상시키는 최종 히든 내러티브입니다.
- **해금 조건**: 
    1. 신뢰도 LV 5 (80점 이상) 달성.
    2. 누적 수익금 1,000,000 Gold 이상.
    3. 오피스 Lv.5 달성.
    4. **과거 파산(Bankruptcy) 및 안나의 구원 퀘스트 완료 이력**: 최소 1회 이상 밑바닥에서 안나의 도움으로 회생한 경험이 있어야 함 (서사적 유대감 증명).
- **서약 이벤트 (The Proposal)**:
    - **트리거 아이템**: **[다이아 반지 (Diamond Ring)]**
    - **획득 경로**: 모든 해금 조건(1~4번) 충족 시, **의상 상점(Tailored)** 목록에 매우 낮은 확률로 출현.
    - **유일한 수락 선물**: 안나는 일반적인 물질적 선물은 모두 거부하지만, **[다이아 반지]는 유일하게 수락**하며 이를 통해 서약 이벤트가 시작됩니다.
    - **커스텀 닉네임**: 서약 완료 시 안나가 유저를 부르는 호칭 직접 입력 (예: Partner, Honey 등).
- **최종 보상**: 
    - **전용 엔딩**: [CiphersVowEnding] 컷신 해금.
    - **영구 버프**: 모든 시장 분석 노이즈 완전 제거 및 수수료 0%.
    - **전용 업적**: **[사이퍼의 영원한 파트너] (Marrying Anna)** 업적 해금 및 골드 엠블럼 지급.

### 1.4. 신뢰도 관리 로직 (Reliability Management)
안나의 신뢰도는 유저의 투자 실력과 도덕적 성실함에 기반하여 실시간으로 증감합니다.

#### 1.4.1. 주요 상승 요인 (Affinity Gains)
| 활동 유형 | 세부 항목 | 신뢰도 점수 | 비고 |
| :--- | :--- | :--- | :--- |
| **트레이딩** | 종목 수익률 +20% 이상 달성 | **+5** | 종목별 최초 1회 |
| | 상장 빔(IPO) 예측 성공 매매 | **+8** | 고난도 성과 |
| **성장** | 서적(Data Ink) 1권 완독 | **+3** | 지적 성장 |
| | 세미나 퀴즈 3회 연속 정답 | **+5** | 주간 이벤트 |
| **성실성** | 대출 및 유지비 정기 상환 | **+4** | 주간 정산 시 |
| | 일일 브리핑 경청 (Interact) | **+1** | 매일 1회 한정 |
| **[주의]** | **아이템 선물하기** | **불가** | 안나는 물질적 보상을 거부함 (**[다이아 반지] 제외**) |

#### 1.4.2. 주요 하락 요인 (Affinity Losses)
| 활동 유형 | 세부 항목 | 신뢰도 점수 | 비고 |
| :--- | :--- | :--- | :--- |
| **리스크** | 전 재산 50% 이상 도박 손실 | **-15** | 경고 대사 출력 |
| | 마진콜(Margin Call) 발생 | **-10** | 전문성 결여 판정 |
| **부정/태만** | **횡령(Embezzlement) 적발** | **-50** | **치명적 (신뢰 붕괴)** |
| | 이자 및 유지비 체납 | **-10** | 신용 등급 하락 |
| | 7일 이상 방치 (Neglect) | **-5** | 누적 적용 가능 |

## 2. 신뢰도 시스템 (Reliability System)
유저의 행동(수익성, 성실도, 도덕성)에 따라 NPC와의 관계가 수치화되어 혜택이 제공됩니다.

| 등급 | 혜택 (Reward) | 안나의 태도 및 연출 (Tone) |
| :--- | :--- | :--- |
| **LV 0** | **[Wanted]** 상호작용 차단, 타운 시설 이용 제한. | **Hostile**. 등을 돌린 뒷모습 연출. |
| **LV 1** | 기본적인 시장 지표 데이터 제공. | 차갑고 사무적인 말투. |
| **LV 2** | 찌라시 해독 시간 10% 단축 보너스. | 살짝 부드러워진 어조. |
| **LV 3** | 매수/매도 적정 가격대 암시 가이드. | 유저를 '파트너'로 인정. |
| **LV 4** | 시장 폭락 시 1분 사전 경고 알림. | 개인적인 배려와 걱정 노출. |
| **LV 5** | 안나 상주 및 **'히든 티커'** 정보 해금. | 전적인 신뢰와 정서적 유대. |

## 4. 상호작용 및 죄와 벌 (Crime & Punishment)

### 4.1. Portrait 스위칭 및 리액션
- 상황에 따라 NPC 초상화가 **Standard, Smile, Angry, Pain**의 4가지 상태로 실시간 변화.
- 유저가 전 재산을 잃거나 도박에 탐닉할 경우 안나가 정기 브리핑을 거부하거나 신뢰도가 하락함.

### 4.2. 적색 수배 (Wanted System)
- **횡령 (15% 초과)** 시 수배 발동. 안나는 대화를 거부하며 등을 돌린 뒷모습으로 고정.
- **고의적 이자 미납**: 현금 보유 중에도 이자 미납 시 즉시 'Pain' 표정과 함께 신뢰도 1단계 강등.
- 수배 시 타운의 모든 상점 이용이 차단되며, 펍의 '안드레'를 통한 세탁이나 소팅 허브의 '속죄의 노동'으로 해제 가능.

### 4.3. 닉네임 호출 시스템 (Nickname Input Logic)
서약(Vow) 달성 후, 안나의 모든 스크립트 변수 `{PlayerName}`이 유저가 설정한 `{CustomNickname}`으로 교체됩니다. 이는 게임 전반의 다이얼로그 무드를 '사무적'에서 '사적'인 톤으로 전환시키는 핵심 장치입니다.
