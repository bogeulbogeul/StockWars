# StockWars GDD: MOD_GDD_06. NPC 레지스트리 및 상호작용 (NPC Registry)

## 주민 호감도·개인 이야기 배치안 — 2026-10-19

**P1 (Major) · ✅ 완료: 주민별 이야기·발동 조건 초안 작성 / 🔄 진행중: 세부 대사·호감도 균형 설계 / ⏳ 대기: 사용자 세부 검토·구현·검수.** 사용자 요청에 따라 주민 호감도와 개인 이야기를 연결한다. 아래 개별 사건은 이번 배치 초안이며 완성된 게임 콘텐츠나 최종 엔딩 확정으로 기록하지 않는다. 기존 ItemEngine 구매/해금용 `affinity`·안나 신뢰도 0~5와 별도로 설계하고 수치·저장을 자동 이관하지 않는다.

### 공통 단계와 발생 규칙

**2026-10-19 게시판 순차 안내 후속:** 시설 첫 방문·주민 부탁·전시·모임 안내는 스토리 조건이 충족될 때 하나씩 게시한다. 동시 해금 순서·읽음 처리·미구매/미완료 시 다른 안내를 막지 않는 규칙은 [게시판 명세](MOD_GDD_01_WorldFacilities.md)를 따른다. 공고 확인은 기존 이야기의 시작 계기이며 완료 조건·호감도를 대체하지 않는다. 안나의 직접 소개나 자발적 방문과 같은 사건 상태를 공유해 첫 만남·보상을 중복 처리하지 않는다. 모든 개인 대화를 게시판 방문 필수로 바꾸지는 않는다.

| 단계 | 관계 | 이야기 역할 |
| :--- | :--- | :--- |
| 1 | 처음 만난 사이 | 이름·역할·시설 소개. 별도 점수 요구 없음 |
| 2 | 익숙한 이웃 | 취향·일상·작은 부탁 |
| 3 | 가까운 사이 | 고민·미뤄둔 소망 공개 |
| 4 | 믿고 의지하는 사이 | 주민이 직접 도움을 청하고 함께 행동 |
| 5 | 소중한 사이 | 개인 이야기의 마무리·이후 일상 변화 |

- 표의 호감도는 최소 단계이며 조건은 별도 OR 표기가 없으면 모두 충족해야 한다. 각 주민의 3~5단계 이야기는 바로 이전 개인 이야기 완료를 요구한다. 하루 숫자·필요 점수·상승량은 아직 정하지 않는다.
- 입주 신청·정착 대출·첫 노동·투자 자격증·첫 매수·두 활동의 합류는 호감도 제한 없이 진행한다. 안나의 7일 차 월세/차 약속과 소지 씨앗 변화, Lv.3·7·12·20 성장 대사, 첫 가구 배치 안내도 호감도로 막지 않는다.
- 첫 만남·기본 안내는 [최신 튜토리얼](CORE_GDD_10_TutorialSystem.md)을 따른다. 정착 안내소가 첫 방문 건물이며 투자 TPT·자격증은 이후 증권사에서 진행한다. 아래 옛 도입 순서는 새 기준으로 대체한다.
- 그날 첫 안부 대화·주민 부탁·개인 이야기 참여로 관계를 쌓는 방향이다. 반복 대화/노동만으로 무제한 상승하지 않도록 설계하되 정확한 일일 한도는 미정이다. 다음 단계의 잠긴 이야기만이 유일한 호감도 획득 경로가 되지 않도록 한다.
- 구매 금액·수익률·대출 상환액은 호감도로 환산하지 않는다. 미접속·투자 손실·월세 미납으로 관계를 떨어뜨리지 않는다. 안나의 일반 선물 거부는 유지한다. 다른 주민의 선물 선호·효과는 후속 설계한다.
- 조건 충족 시 발생 가능으로 예약하고 표의 장소에서 대화/공고로 시작한다. 실제 작업·주문·거래를 끊지 않는다. 같은 주민의 긴 이야기는 하나씩 진행하며 후속 이야기는 다음 대화 기회로 넘긴다. 임의의 현실 날짜·시간대·만료 기한을 두지 않는다.
- 상태는 미발생 → 발생 가능 → 진행 중 → 완료로 구분하고, 중단 시 진행 중 상태를 복구한다. 완료 보상은 한 번만 처리한다. 표의 명칭은 원고 제목이며 런타임 ID·저장 키가 아니다. 공고는 읽기만 해서는 완료되지 않는다.
- 첫날 기본 체험 스킵은 별도 처리한다. 스킵 때문에 개인 이야기가 영구 잠기지 않도록 상시 재안내/체험으로 조건을 채울 수 있게 설계한다. 기존 저장에서 조건이 충족됐다고 추측해 일괄 완료하지 않는다.

### 안나 — 남의 시작을 돕던 사람이 자기 시작을 선택하기

1단계: 정류장 첫 만남·안내소 입주 신청·생활 안내. 첫 주 관계 장면은 개인 호감도와 별도로 유지한다.

| 단계·이야기 | 발동 조건·시작 장소 | 진행·완료와 변화 |
| :--- | :--- | :--- |
| 2 · 찾아가지 않은 차 | 공통 자립 안내 완료 + 안나 또는 비비안 호감도 2 이상 → 게시판의 비비안 공고 | 잡화점에서 안나가 주문한 차를 받아 안내소에 전달한다. 이미 주문한 물건의 심부름으로, 소망이가 사서 주는 선물이 아니다. 접힌 상담소 계획서를 발견하고 전달 대화로 완료. 비비안 2단계와 공유하는 사건이라 한 번만 진행 |
| 3 · 접어둔 계획서 | 공유 차 전달 완료 + 안나 3 이상 → 안내소 | 다시 시작할 사람을 돕고 싶지만 실패가 두려워 계획을 미뤘다는 말을 듣는다. 소망이는 정답을 주기보다 첫 정착 경험을 들려준다. 대화 완료 시 계획서를 함께 살펴볼 약속 |
| 4 · 처음 온 사람의 눈으로 | 이전 이야기 완료 + 안나 4 이상 + 첫 주 월세 결과/차 약속 장면 완료 → 안내소 | 안내문을 함께 읽고 소망이가 처음 막막했던 부분을 고른다. 안나가 상담을 작게 시도할 날짜를 정하겠다고 말하면 완료. 선택에 정답/오답이나 관계 감점 없음 |
| 5 · 첫 상담의 날 | 이전 이야기 완료 + 안나 5 이상 → 안내소 | 기존 안내소에서 작은 상담을 시도한다. 익명의 방문객 역할과 짧은 대화 연출을 후속 제작한다. 끝난 뒤 광장에서 소감을 나누며 개인 이야기 완료. 새 상설 건물·연애·전체 게임 엔딩을 자동 해금하지 않음 |

대표 마무리: 안나 “오늘도 모르는 질문이 있었어요. 그래도 다음에는 다시 들어볼 수 있을 것 같아요.”

### 비비안 — 모두를 챙기던 사람이 자기 몫도 챙기기

1단계: 게시판의 첫 구인 공고·잡화점 주문 포장 튜토리얼. 현재 2D 포장 퍼즐 규칙은 [노동 명세](MOD_GDD_02_LaborJobs.md)를 따른다.

| 단계·이야기 | 발동 조건·시작 장소 | 진행·완료와 변화 |
| :--- | :--- | :--- |
| 2 · 찾아가지 않은 차 | 안나 2단계와 같은 공유 조건·공고 | 차 전달 완료를 공유한다. 비비안이 상품뿐 아니라 찾아오는 주민을 기억한다는 것을 알게 된다. 다른 주민 쪽에서 먼저 완료했어도 재진행·중복 보상 없음 |
| 3 · 주인의 취향 | 공유 차 전달 완료 + 비비안 3 이상 → 잡화점 | 손님들의 취향을 줄줄 말하던 비비안이 정작 자기 취향에는 머뭇거린다. 자신의 쉬는 시간에 마실 차를 직접 고르고 대화를 마치면 완료 |
| 4 · 잠깐 쉬어도 괜찮아 | 이전 이야기 완료 + 비비안 4 이상 → 잡화점 | 소망이에게 휴식 전 마지막 주문을 도와달라고 부탁한다. 주문 한 건 전달 후 함께 쉬는 장면으로 완료. 실패하면 수정/재시도할 수 있고 호감도는 깎지 않음. 전용 주문의 점수·경제 보상은 후속 설계 |
| 5 · 내 몫의 한 잔 | 이전 이야기 완료 + 비비안 5 이상 → 잡화점 | 비비안이 이번에는 자신이 좋아하는 차까지 준비해 함께 광장으로 간다. 대화 완료 후 ‘자기 취향·쉬는 시간’ 관련 일상 대사가 열린다. 실제 가게 영업시간을 줄이거나 노동을 잠그지는 않음 |

대표 마무리: 비비안 “오늘은 내 것도 준비했어요. 내가 좋아하는 걸로요.”

### 줄리안 — 보기 좋은 공간에서 살기 좋은 공간으로

1단계: 모던 프레임 구경·취향 소개. 첫 가구 구매 후 배치 튜토리얼과 다음 방문의 감상 대화는 별도 호감도 제한 없이 진행한다.

| 단계·이야기 | 발동 조건·시작 장소 | 진행·완료와 변화 |
| :--- | :--- | :--- |
| 2 · 어떤 방이 좋아요? | 줄리안 2 이상 + 첫 가게 소개 완료 → 모던 프레임 | 휴식·작업·구경 등 좋아하는 공간을 이야기하고 전시를 함께 본다. 구매 없이 대화로 완료. 가구를 배치했다면 기존 첫 가구 감상을 중복하지 않고 반응만 달리함 |
| 3 · 남에게 보여줄 방 | 이전 이야기 완료 + 줄리안 3 이상 → 모던 프레임 | 줄리안의 방 스케치를 보며 멋진 모습만 고민하느라 자신이 어떻게 지낼지는 생각하지 못했음을 듣는다. 대화 완료. 새 NPC 주택 방문은 필수로 추가하지 않음 |
| 4 · 쉬는 자리 하나 | 이전 이야기 완료 + 줄리안 4 이상 → 모던 프레임 | 가게에 있는 샘플을 보며 줄리안이 쉴 공간을 함께 구상한다. 플레이어는 느낌을 말하고 최종 선택은 줄리안이 한다. 대화/스케치 확인으로 완료하며 상품 구매·기부 요구 없음 |
| 5 · 내가 앉을 자리 | 이전 이야기 완료 + 줄리안 5 이상 → 모던 프레임 | 줄리안이 완성한 작은 공간의 스케치를 보여주고 사용한 소감을 말한다. 대화로 완료하고 자기 취향에 관한 일상 대사를 추가. 선물 가구·무료 룸은 미확정 |

대표 마무리: 줄리안 “남에게 보여주려고 고른 게 아니라, 내가 쉬고 싶어서 골랐어요.”

| 단계·이야기 | 발동 조건·시작 장소 | 진행·완료와 변화 |

| 5 · 장부 밖의 하루 | 이전 이야기 완료 + 샤일록 5 이상 → 은행 | 샤일록이 쉬고 돌아온 시간을 떠올리며 자기 계획도 챙기겠다고 말한다. 대화 후 생활 목표에 관한 일상 대사 추가. 금리 감면·채무 면제·새 금융상품 없음 |

대표 마무리: 샤일록 “얼마를 썼는지보다, 어떻게 보냈는지가 더 기억나는 날도 있군요.”

### 추가 주민 이야기 — 펍·의상점·서점 (2026-10-19 후속 초안)

사용자 확인에 따라 펍·의상점·서점도 마을 방문과 주민 이야기 범위에 포함한다. 기존 담당자 안드레·클레어·소피아를 사용한다. 아래는 배치 초안이며 운영 기능·게임 구현 완료와 구분한다. 각 3~5단계는 해당 주민 호감도와 바로 이전 이야기 완료를 함께 요구하고, 장소에서 대화하여 시작한다. 첫 방문은 호감도 제한이 없으며 아래 소개 계기는 강제 출입 제한이 아니다. 다른 주민의 관계 단계는 요구하지 않는다.

#### 안드레 / 미드나잇 펍 — 남의 이야기를 듣던 사람이 자기 이야기를 꺼내기

| 단계·이야기 | 발동 조건·장소 | 진행·완료 |
| :--- | :--- | :--- |
| 1 · 일과 뒤의 자리 | 두 수입 활동·공통 자립 안내 후 안나가 소개 → 펍 첫 방문 | 안드레와 인사하고 주민들이 쉬는 공간을 둘러본다. 구매·음주·현실 야간 접속 요구 없음 |
| 2 · 단골이 앉는 자리 | 안드레 2 이상 + 첫 방문 완료 → 펍 | 주민마다 좋아하는 자리가 다르다는 이야기를 듣고 대화 완료. 사적인 비밀을 정보 보상으로 제공하지 않음 |
| 3 · 당신의 이야기는요? | 안드레 3 이상 + 이전 이야기 완료 → 펍 | 남의 이야기는 잘 듣지만 자기 이야기는 꺼내기 어렵다는 고민을 듣고 완료 |
| 4 · 한 곡을 고르는 일 | 안드레 4 이상 + 이전 이야기 완료 → 펍 | 작은 이야기 모임에 어울릴 음악 분위기를 함께 고른다. 안드레가 최종 선택하면 완료. 구매·새 리듬게임 요구 없음 |
| 5 · 오늘은 내 이야기 | 안드레 5 이상 + 이전 이야기 완료 → 펍 | 짧은 모임에서 안드레가 펍을 편히 머무는 곳으로 만들고 싶었던 이유를 말한다. 대화 후 자기 경험을 나누는 일상 대사 추가 |

대표 마무리: “오늘은 내가 조금 더 이야기해도 되겠어요?” 과거 정보 브로커·도박·수배 해제는 복원하지 않는다. 모임 참여 주민은 연출이며 별도 호감도 최대치 조건이 아니다.

#### 클레어 / 의상점 — 모두에게 맞추려다 잊은 자기 취향

| 단계·이야기 | 발동 조건·장소 | 진행·완료 |
| :--- | :--- | :--- |
| 1 · 진열창 너머 | 공통 자립 안내 후 게시판의 전시 구경 안내 → 의상점 | 클레어와 디자인 전시를 구경하고 인사. 플레이어 의상 구매·착용 요구 없음 |
| 2 · 눈에 들어온 색 | 클레어 2 이상 + 첫 방문 완료 → 의상점 | 색과 디자인 시안을 보며 취향을 이야기하고 완료. 답변은 대사에만 반영 |
| 3 · 남겨둔 스케치 | 클레어 3 이상 + 이전 이야기 완료 → 의상점 | 남들이 좋아할 디자인에만 맞추다 자기 취향을 접어두었다는 이야기를 듣고 완료 |
| 4 · 이번에는 내 취향으로 | 클레어 4 이상 + 이전 이야기 완료 → 의상점 | 클레어가 고른 디자인의 작은 전시를 준비하며 감상을 나눈다. 준비 대화로 완료. 재료 구매·기부 요구 없음 |
| 5 · 진열창 한가운데 | 클레어 5 이상 + 이전 이야기 완료 → 의상점 | 자신의 작품을 중심에 놓은 전시를 함께 보고 소감 대화로 완료. 스킨·의상 보상을 확정하지 않음 |

대표 마무리: “이번에는 내가 좋아하는 걸 제일 잘 보이는 곳에 뒀어요.” 의상점 존재·스토리 포함과 플레이어 외형 판매 정책은 구분한다. 기존 캐릭터 커스텀·스킨 판매 제거는 유지하며 실제 판매 대상·품목은 별도 결정한다. 인테리어 판매처를 모던 프레임에서 옮기지 않는다.

#### 소피아 / 데이터 잉크 서점 — 읽던 사람이 자기 이야기를 기록하기

| 단계·이야기 | 발동 조건·장소 | 진행·완료 |
| :--- | :--- | :--- |
| 1 · 궁금한 것을 찾는 곳 | 첫 찌라시 해석 안내 후 안나가 소개 → 서점 | 소피아가 모르는 말을 함께 찾아볼 수 있다고 안내. 구매·유료 세미나·현실 시간 독서 요구 없음 |
| 2 · 어떤 책을 찾나요? | 소피아 2 이상 + 첫 방문 완료 → 서점 | 궁금한 주제를 말하고 서가를 함께 살펴보면 완료. 출생의 비밀이나 투자 정답은 제공하지 않음 |
| 3 · 첫 문장이 없는 공책 | 소피아 3 이상 + 이전 이야기 완료 → 서점 | 자신의 글을 쓰는 데 망설이는 소피아의 공책을 발견하고 고민을 들으면 완료 |
| 4 · 오늘 있었던 작은 일 | 소피아 4 이상 + 이전 이야기 완료 → 서점 | 소망이가 작은 경험을 이야기하고 소피아도 하루를 한 문장 기록한다. 선택형 대화로 완료. 자유 글쓰기 입력 필수 아님 |
| 5 · 우리 마을의 첫 페이지 | 소피아 5 이상 + 이전 이야기 완료 → 서점 | 마을의 평범한 하루를 담은 첫 글을 함께 읽고 소감을 나누면 완료. 다른 주민 이야기 전체 완료 요구 없음 |

대표 마무리: “책에 없는 이야기라서 못 쓰는 줄 알았는데, 그래서 적어두고 싶어졌어요.” 도서 판매·스탯 상승·세미나의 상세 조건은 별도 설계한다.

세 주민에게도 공통 호감도·진행 상태·예약/중단/재개 규칙을 적용한다. 미방문자는 기본 소개를 먼저 받고, 시설을 늦게 방문해도 소개 기회는 만료되지 않는다. 후일담·보상량·새 외형·상품·운영시간·상세 연출은 미정이다. **P1 (Major) · ✅ 추가 배치 초안 작성 / 🔄 세부 설계 / ⏳ 구현·검수 대기.**

### 전체 주민 이야기의 진행 범위·후속 설계

각 주민 이야기는 독립적으로 진행한다. 다른 주민의 5단계 완료를 요구하지 않으며 전체 주민 호감도 최대치를 메인 엔딩 조건으로 확정하지 않는다. 공유 차 전달 사건만 안나·비비안의 선행 상태를 함께 기록한다. 기존 첫 주 서사는 차 전달이나 개인 이야기를 기다리지 않는다.

관계 단계별 포인트·반복 상승 제한·이야기 완료의 호감도 보상량·상태 저장 및 UI는 후속 설계다. 모든 단계에 물품·돈 보상을 붙이지 않는다. 개인 이야기 완료는 후일담·일상 대화 변화로 표현하고 기념품 지급은 별도 결정한다. 이벤트용 NPC 이동은 장면 연출로 처리하며 기존 영업·야간 상주 조건을 임의 변경하지 않는다.

## 안나의 현행 초반 관계 기획 — 2026-10-18 사용자 채택

**최신 첫 만남:** 안나는 ‘아직 무엇을 하고 싶은지 몰라도 괜찮다’는 정착 안내문을 쓴 담당자다. 안내문을 본 소망이가 버스로 오면, 버스 기사의 신규 정착자 연락을 받고 정류장에서 맞이한다. 출생의 비밀을 알고 기다리거나 씨앗·편지의 발신자로 확정하지 않는다. 첫 대화에서 소망이의 막막함을 받아준 뒤 안내소 등록 → TPT·출입증 → 작은 집·오피스로 안내한다. [튜토리얼 오프닝](CORE_GDD_10_TutorialSystem.md)이 대사 기준이다. 후속 선택 대화의 “그걸 정하고 와야 한다면… 시작하지 못할 사람도 있을 것 같아서요.”는 자기 꿈을 미루는 안나의 사정도 비춘다. 기존 관계 단계·상담소의 꿈은 유지한다. ✅ 기획 반영 / ⏳ 도입 구현·검수 대기.

**P0 (Core) · ✅ 완료: 서사 기획 반영 / ⏳ 대기: 게임 연결·검수.** 장면·대표 대사는 [소망 요정의 첫 일주일](CORE_GDD_10_TutorialSystem.md#4-소망-요정의-첫-일주일--2026-10-18-사용자-채택)을 따른다. 아래 과거 확장 원고보다 이번 초반 관계 방향을 우선한다.

- **역할:** 투자·생활 매니저로 신규 정착자를 돕는다. 기업 정보 읽기·생활비 관리·일·휴식을 안내하되 플레이어 대신 매매하거나 손실·월세를 대납하지 않는다.
- **태도:** 현실적이고 차분하며 처음에는 업무상 거리를 둔다. 태어난 소망을 모르는 플레이어에게 답을 강요하지 않고 선택을 기다린다. 손실을 냈다는 이유만으로 인격을 비난하거나 관계를 끊지 않는다.
- **개인 소망:** 한 번 실패한 사람도 다시 시작할 수 있는 정착 상담소를 만들고 싶다. 현재의 정착 지원 업무와 별개인 자기 계획이며, 준비 부족과 실패에 대한 두려움 때문에 미룬다. 새 시설·기능이 이미 운영 중이라는 뜻이 아니다.
- **초반 노출:** 오래된 계획서나 빈 점포를 바라보는 모습 정도로 암시한다. 처음부터 과거사를 길게 설명하지 않는다. 계획서의 세부 이력·상담소 개설 퀘스트는 후속 설계 대상이다.
- **관계 단계:** 담당자 → 실수도 이야기할 수 있는 사람 → 서로의 하루를 궁금해함 → 서로를 돌보고 내일을 약속하는 파트너. 첫 주는 이 단계까지이며 연애·결혼은 필수 진척이나 보상이 아니다.
- **상호 성장:** 주인공은 원하는 것을 몰라 머뭇거리고, 안나는 원하는 것을 알지만 실패가 두려워 머뭇거린다. 서로 자기 소망을 찾고 실행하도록 돕는다. 플레이어가 안나의 소망에서 태어났다는 설정은 확정하지 않는다.
- **시스템 경계:** 관계 단계는 서사 설명이며 신규 호감도 수치·선물 요구·수익률 잠금 조건을 신설하지 않는다. 기존 의뢰와 야간 표시 조건은 유지한다. 아래 신뢰도·서약·회생 확장안을 첫 주 선행 조건으로 사용하지 않는다.

## 1. 메인 조력자: 안나 '사이퍼' (Anna Cypher)

### 1.1. 캐릭터 프로필
- **역할**: 전직 수석 애널리스트 출신의 개인 매니저 및 파트너.
- **성격**: 냉철한 현실주의자. 유저의 수익률뿐만 아니라 도덕적 선택(횡령 등)에 따라 태도가 변화함.
- **특수 모드**:
    - **오피스 룩 (06-24시)**: 정석적인 브리핑과 리스크 가이드.
    - **잠옷 룩 (00:00 이상~06:00 미만)**: 하늘색 실크 잠옷 착용. **결혼 이벤트 ‘사이퍼의 서약’을 완료하기 전에는 이 시간대에 홈 오피스의 안나 치비 캐릭터가 나타나지 않습니다. 결혼 이벤트 완료 후에만 잠옷 차림으로 야간 오피스 상주가 해금됩니다.** 이벤트 시작, 반지 보유, 신뢰도 LV 5만으로는 해금되지 않습니다.
    - **시간 판정**: HUD 시계와 동일한 기기 로컬 시간을 사용합니다. 00:00에 미혼 안나를 숨기고 06:00에 다시 표시합니다. 하늘 배경 수동 전환은 이 조건을 바꾸지 않습니다.
    - **표시 범위와 우선순위**: 야간 숨김은 오피스의 치비 캐릭터에 적용합니다. 튜토리얼 대화창·초상화와 안내 진행은 유지하며, 튜토리얼의 정면 고정 규칙보다 야간 숨김 조건을 우선합니다. 숨겨진 동안 오피스 배회는 정지합니다.
- **외모**: 컬이 굵은 붉은색 단발머리(Bob), 초록색 눈. 기본 착장으로 레몬색 블라우스, 네이비 오피스 스커트, 갈색 단화를 착용. (의상 고정)
- **상호작용**: 유저의 자산 상태, 신뢰도(Reliability), 그리고 시장 상황에 기반한 전문적인 데이터 피드백 제공. **(물질적 선물 거부 정책: 안나에게는 아이템 선물하기 기능이 비활성화됩니다.)**

> **웹 데모 구현 현황 (2026.09.28)**: 로컬 시간 기반 야간 치비 숨김 및 `userProfile.annaMarriageCompleted === true` 표시 조건을 연결했습니다. 결혼 이벤트 진행·완료 상태의 영구 저장과 잠옷 스프라이트 전환은 후속 구현 대상이며, 현재 일반 플레이에서는 결혼 미완료로 처리합니다.

신뢰도가 특정 수준 이상일 때, 안나가 유저의 메일함으로 선물을 보냅니다. 신뢰도 레벨이 높을수록 선물의 가치와 발동 확률이 상승합니다.

### 1.3. 사이퍼의 서약 (Cipher's Vow: Hidden Route)
안나와의 관계를 단순한 파트너 이상으로 격상시키는 최종 히든 내러티브입니다.
- **해금 조건**:
    1. 신뢰도 LV 5 (80점 이상) 달성.
    2. 누적 수익금 1,000,000 Gold 이상.
    3. 오피스 Lv.5 달성.
    4. **과거 파산(Bankruptcy) 및 안나의 구원 퀘스트 완료 이력**: 최소 1회 이상 밑바닥에서 안나의 도움으로 회생한 경험이 있어야 함 (서사적 유대감 증명).
- **서약 이벤트 (The Proposal)**:
    - **트리거 아이템**: **[다이아 반지 (Diamond Ring)]**
    - **획득 경로**: 모든 해금 조건(1~4번) 충족 시, **의상 상점(Tailored)** 목록에 매우 낮은 확률로 출현.
    - **유일한 수락 선물**: 안나는 일반적인 물질적 선물은 모두 거부하지만, **[다이아 반지]는 유일하게 수락**하며 이를 통해 서약 이벤트가 시작됩니다.
    - **커스텀 닉네임**: 서약 완료 시 안나가 유저를 부르는 호칭 직접 입력 (예: Partner, Honey 등).
- **최종 보상**:
    - **야간 동거/상주 해금**: 결혼 이벤트 완료 후 00:00~05:59에도 안나가 잠옷 차림으로 홈 오피스에 나타납니다. 완료 상태는 저장 데이터에 영구 기록하며, 신규 게임은 미완료 상태로 시작합니다.
    - **전용 엔딩**: [CiphersVowEnding] 컷신 해금.

## 4. 상호작용 및 죄와 벌 (Crime & Punishment)

### 4.1. Portrait 스위칭 및 리액션
- 상황에 따라 NPC 초상화가 **Standard, Smile, Angry, Pain**의 4가지 상태로 실시간 변화.
- 유저가 전 재산을 잃거나 도박에 탐닉할 경우 안나가 정기 브리핑을 거부하거나 신뢰도가 하락함.

### 4.2. 적색 수배 (Wanted System)
- **횡령 (15% 초과)** 시 수배 발동. 안나는 대화를 거부하며 등을 돌린 뒷모습으로 고정.
- **고의적 이자 미납**: 현금 보유 중에도 이자 미납 시 즉시 'Pain' 표정과 함께 신뢰도 1단계 강등.
- 수배 시 타운의 모든 상점 이용이 차단되며, 펍의 '안드레'를 통한 세탁이나 소팅 허브의 '속죄의 노동'으로 해제 가능.

### 4.3. 닉네임 호출 시스템 (Nickname Input Logic)
현재 튜토리얼은 등록한 닉네임을 사용하며 서약 달성을 호출의 필수 조건으로 두지 않는다. 서약 후 별도 애칭·말투 변화는 확장 원고이며 미구현이다. 닉네임 입력·검증은 [캐릭터 생성](CORE_GDD_08_CharacterCreation.md)을 따른다.
