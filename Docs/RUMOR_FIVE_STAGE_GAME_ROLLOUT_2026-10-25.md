## 현재 표시와 출제

72개 회사·288개 사건의 5단계 본문 1,440개를 게임에 연결했다. 분석력 Lv.1~5는 해석 1~5와 일대일로 대응한다. 개별 가루 해석 단계가 더 높으면 그 단계를 표시하며 최대는 5다. 회사명은 새 원고의 공개 시점인 2단계부터 표시하고 구형 25종 원고의 기존 공개 기준은 유지한다.

864문항의 질문·보기·정답·해설은 유지하되, 구간을 **1단계 / 2~3단계 / 4~5단계**로 옮겼다. 각 구간의 최소 단계 본문으로 근거를 다시 기록하고 원고와 런타임 일치를 확인했다. 실제 표시 해석 단계에 해당하는 문항 하나만 출제한다. 기존 문항 ID·사건 ID를 변경하지 않고, 새 단계 세션 키로 구형 문제 제출을 거절해 재열람을 안내한다. 기존 시도 기록은 문제를 다시 열기 전까지 보존하고 지급 이력과는 별도로 관리한다.

정답 숙련도 +1·플레이어별 사건당 한 번 지급·오답 후 재도전 동일 보상을 유지한다. 이미 보상받은 사건은 가루·사본·선물·재구매·단계 변경·문항 변경·재접속 뒤에도 +0이다. 분석력 최대 Lv.5·승급 20·30·40·60·Lv.1 출발 정답 150개는 변경하지 않는다. 최대 분석력에서는 기존 무보상 복습 정책을 유지한다.

## 기존 가루 해석 이관

| 예전 개별 해석 단계 | 새 개별 해석 단계 |
|---|---|
| 1 | 1 |
| 2~4 | 2 |
| 5~6 | 3 |
| 7~8 | 4 |
| 9~10 | 5 |

새 원고가 보존한 예전 단계가 1·4·6·8·10이므로, 예전 공개 정보를 적어도 포함하는 새 단계로 올림 대응한다. 예전 2~3 또는 5·7·9단계는 더 적은 정보로 내리지 않고 다음 통합 단계에 포함한다. 가루 상품 수량·소비·가격·보유 ID·수량·읽기·금액·발행 기록을 바꾸지 않는다. 별가루는 개별 해석 +1·최대 5, 달가루는 개별 해석 5를 유지하며 분석력 자체를 올리지 않는다.

기존 `rumorSchema:2`·10개 본문 보유 건을 `rumorSchema:3`·5개 본문으로 1회 이관한다. 기존 본문·완독·개별 단계는 해당 보유 건의 `rumorTenStageArchive`에 보존한다. 인벤토리뿐 아니라 대기 배송·메일 안의 같은 원고도 이관하며 version 3은 재접속 때 다시 환산하지 않는다. 구형 25종처럼 이 구조가 아닌 보유 원고는 변경하지 않는다.

분석력 성장 상태·숙련도·사건별 `awarded`는 이 이관에서 수정하지 않는다. 이전 분석력 10레벨→5레벨 성장 이관은 [기존 성장 이관 명세](ANALYSIS_FIVE_LEVELS_2026-10-25.md)를 그대로 따른다. 성장의 레벨 환산과 개별 원고의 해석 환산은 별개다.
