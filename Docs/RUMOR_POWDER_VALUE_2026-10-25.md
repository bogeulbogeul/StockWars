# 가루 사용 시 찌라시 매각 가치 감소

**P1 (Major) · ✅ 완료: 웹·기존 실행본 리소스 적용·자동 테스트 / ⏳ 대기: 사용자 최종 플레이 검수.**

별가루·달가루로 선택한 찌라시의 추가 해석에 성공하면 그 보유 건의 현재 `price`를 매번 50% 감소시킨다. 소수점은 버리고 기존 찌라시 가치 하한 100잎을 유지한다. 100잎 미만으로 저장된 과거 값은 올리지 않는다. 예: 1,600→800→400→200→100잎. 달가루도 한 번 사용에 한 번 감소하며 건너뛴 단계 수만큼 반복 차감하지 않는다.

최대 해석·미열람·잘못된 대상·미보유 가루 등 사용 실패는 가격과 가루 수량을 변경하지 않는다. 다른 사본·다른 찌라시의 가치는 유지한다. 가루 사용은 정답 판정이나 분석력 숙련도를 만들지 않으며 기존 사건별 정답·오답 종료·지급 이력은 그대로다. 재접속 후 줄어든 가격을 유지하고 과거 가루 사용을 소급 차감하지 않는다. 기존 최초 열람 감가와 별도이며 재열람 자체의 추가 감가는 만들지 않는다.

가루 상품의 효과 안내와 사용 결과 메시지에 가치 감소를 반영했다. 과거 구형 보고서 자체의 해독·다크넷 키는 이번 추가 감가 대상이 아니다. 현재 찌라시 추가 해석 경로에서 별가루·달가루 사용에 적용한다.
