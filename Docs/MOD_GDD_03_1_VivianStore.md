## 오늘의 간식·주민 추천 — 2026-10-19

**P1 (Major) · ✅ 완료: 기획 반영 / ⏳ 대기: 상품 선정·진열 규칙·문구·구현·검수.** 가게에 다시 방문하고 먹거리를 고르는 재미를 위해 **오늘의 간식과 주민 추천 문구**를 우선 도입한다.

- **회복 상품:** 간식·음료·차·요정식 먹거리 자체가 기본 회복 상품이다. 하나의 회복 상품군으로 상시 판매하며 취향에 따라 선택한다. 상시 판매가 무제한 구매를 뜻하지 않으며 구매 제한은 회복 상품 밸런스 설계를 따른다.
- **오늘의 간식:** 상시 판매 중인 회복 상품에 붙이는 추천 표시다. 별도 상품군이나 교체 판매 매대가 아니며 추천이 바뀌어도 판매 목록은 유지한다. 추천 대상 수·교체 시각·선정 방식은 후속 설계이며 할인·추가 회복 효과·새 재화를 자동 부여하지 않는다.
- **주민 추천 문구:** 상품에 주민의 취향과 짧은 이야기를 담는다. ‘안나가 좋아하는 꽃잎 차’는 문구 예시이며 주민별 선호 상품은 별도 선정한다. 추천 표시만으로 호감도 보너스나 선물 효과를 확정하지 않는다.
- **후속 검토 후보:** 구매 먹거리의 선물 포장, 편지지·봉투·리본 같은 문구류는 주민 선물·편지 기능과 함께 설계한다. 비비안의 작은 부탁 완료 후 간식을 받는 시식 선물도 후보로 보관한다. 판매·보상 지급·수량·조건은 아직 확정하지 않는다.

이번 채택은 위 우선 도입 범위에 한정하며 달빛가루의 영구/기간제 여부 등 기존 미정 항목을 확정하지 않는다. 기존 상품·구매 상태·저장은 자동 변경하지 않는다.

## 카페인 삭제·달빛가루 효과 변경 — 2026-10-19

**P1 (Major) · ✅ 완료: 기획 반영 / ⏳ 대기: 세부 설계·구현·검수.** 회복 먹거리 종류가 충분하므로 초고농축 카페인을 개편 상품에서 삭제한다. 대체안이었던 ‘진한 꽃꿀’도 추가하지 않는다. 기존 보유품·저장의 처리 방식은 별도 설계하며 기존 구현 기록을 보존한다.

다크넷 해독키의 후속 상품은 **달빛가루**로 채택하고, 효과를 **사용 즉시 분석력 레벨 MAX**로 변경한다. 현재 단계별 효과의 상한은 Lv.5다. 사용자 표현에 따라 플레이어 분석력 레벨을 최대로 만드는 것으로 기록하며, 반짝가루의 찌라시 한 건 해석 +1 효과와 구분한다. 영구 상승인지 기간제 효과인지·지속시간·만료 처리·가격·해금 조건은 미정이다. 기존 ‘분석 Lv.5 + 해독 50회’ 조건과 4,000G를 자동 승계하지 않는다. 분석력 최대도 정보의 진위를 보증하지 않는다. 찌라시 오염·감가의 달빛가루 적용 방식은 별도 설계한다.

## 주간 로또 유지·분석 도구 형태 변경 — 2026-10-19

**P1 (Major) · ✅ 완료: 기획 반영 / ⏳ 대기: 제작·구현·검수.** 잡화점 개편에서도 주간 로또는 유지한다. 이번 결정은 기존 가격·추첨·판매 제한 변경이나 서버 구현 완료를 뜻하지 않는다.

**후속 채택: 암호 해독기의 새 이름·형태는 ‘반짝가루’다.** 찌라시에 가루를 뿌려 해석을 돕는 소모품으로 재디자인한다. 1개 사용 시 선택한 열람 찌라시 한 건의 유지 해석 단계 +1(최대 5) 효과와 분석력·진위를 바꾸지 않는 계약은 유지한다.

- 사용 후 종이에 가루가 묻어 더러워지고 물건의 가치가 떨어지는 설정을 채택한다. 정보 이해는 깊어지지만 찌라시의 매각 가치는 낮아지는 선택으로 설명한다.
- 현재 구현 기록은 **첫 열람 시 매각 가치 50% 감소**다. 반짝가루 사용에 따른 가치 감소의 발생 시점·감소율·반복 사용 누적 여부·기존 첫 열람 감가와의 관계는 후속 설계다. 기존 50%를 가루 사용마다 중복 적용하거나 기존 감가를 자동 대체하지 않는다. 실제 매입처·거래 방식도 별도 미정 상태를 유지한다.
- 기존 상품 ID·보유품·가격·효과·이미지는 구현 전까지 자동 변경하지 않는다. 아래 ‘암호 해독기’ 명칭과 카탈로그는 기존 구현 기록이며, 새 기획의 명칭은 반짝가루를 사용한다.

[노동 명세](MOD_GDD_02_LaborJobs.md)·[첫날 튜토리얼](CORE_GDD_10_TutorialSystem.md)을 따른다. 첫 연습은 손님 한 명·상품 1종·시간 제한 없이 제공하며 찌라시 해석 안내로 연결한다. 상품 판매 기능과 노동을 구분하고 작업 재고를 플레이어 구매 재화·소지품에서 임의 차감하지 않는다. 카메라는 [새 3D 시점](VISUAL_TRANSITION_PLAN.md)을 따른다.

> **2026-10-16 대조 결과:** 상품·효과의 실행 기준은 [ItemEngine](../web/js/engine/ItemEngine.js)·[카탈로그](../web/js/data/vivianStoreData.js)다. 일일 제한은 아이템 시계의 KST 날짜로 갱신한다. 일일·주간 분류가 상품 자체의 자동 교체·재입고 구현을 뜻하지 않는다. 블랙 스완이 현재 비활성이므로 관련 생존 해금·방독면·경보기·탈출 효과를 일반 플레이에서 검증 완료로 기록하지 않는다.
