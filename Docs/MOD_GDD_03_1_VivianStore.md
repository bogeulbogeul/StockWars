# StockWars GDD: [MOD_GDD_03_1] 비비안 잡화점 (Vivian's Store)

## 가게 주문 일터 연결 — 2026-10-18

**전당포 제외 후속:** 전당포는 초기 마을에서 제외하며 비비안 잡화점의 되팔기/매입 기능은 미정이다. 매입 대상·가격·환급률·재고 처리를 새 기획으로 확정하지 않는다. 기존 구매·소비와 가게 주문 노동 기능을 유지하며 전당포의 매각·담보 역할을 자동 승계하지 않는다.

**✅ 완료: 기획 반영 / ⏳ 대기: 구현·검수.** 비비안 잡화점을 첫 주문 노동 장소로 채택한다. 비비안과 대화 → 주문 확인 → 진열대 상품 선택 → 포장 → 손님에게 전달 → 보수 순서다. [노동 명세](MOD_GDD_02_LaborJobs.md)·[첫날 튜토리얼](CORE_GDD_10_TutorialSystem.md)을 따른다. 첫 연습은 손님 한 명·상품 1종·시간 제한 없이 제공하며 찌라시 해석 안내로 연결한다. 상품 판매 기능과 노동을 구분하고 작업 재고를 플레이어 구매 재화·소지품에서 임의 차감하지 않는다. 카메라는 [새 3D 시점](VISUAL_TRANSITION_PLAN.md)을 따른다.

> **2026-10-16 대조 결과:** 상품·효과의 실행 기준은 [ItemEngine](../web/js/engine/ItemEngine.js)·[카탈로그](../web/js/data/vivianStoreData.js)다. 일일 제한은 아이템 시계의 KST 날짜로 갱신한다. 일일·주간 분류가 상품 자체의 자동 교체·재입고 구현을 뜻하지 않는다. 블랙 스완이 현재 비활성이므로 관련 생존 해금·방독면·경보기·탈출 효과를 일반 플레이에서 검증 완료로 기록하지 않는다.
