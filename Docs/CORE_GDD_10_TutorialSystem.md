# CORE_GDD_10 게임 시작과 튜토리얼

> 개정: 2026-10-18. 소망 요정·고정 외형·집꾸미기·가게 주문 노동 기획을 반영했다. 아래 새 진행은 채택 기획이며 현재 웹·Electron의 물류 체크포인트를 교체한 구현 완료 기록이 아니다. 장면의 시점·제작은 [아트](ART_STYLE_GUIDE.md)·[룸 명세](ROOM_PACKAGE_GUIDE.md)를 따른다.

## 2026-10-19 씨앗 심기 전 화분 구매 — 후속 채택

**최신 성장 연동:** 화분에 심은 씨앗은 소망이의 머리 위 성장과 같은 레벨 구간에 맞춰 씨앗 → 잎 하나 → 두 잎 → 꽃봉오리 → 개화로 변한다. [성장 대응 표](SPIRIT_CHARACTER_BASELINE.md)를 따른다. 화분 구매·심기 전에는 머리 성장을 지연하지 않고 나중에 심으면 현재 단계로 표시한다. 첫 주 ‘내일의 약속’은 관계 장면으로 유지하지만 씨앗을 별도 단계로 성장시키는 조건으로 사용하지 않는다. ✅ 기획 반영 / ⏳ 제작·구현·검수 대기.

**스토리 전용 노출 후속:** 씨앗용 화분은 일반 상품 목록·상시 진열·일반 꾸미기 구매 목록에 나오지 않는다. ‘씨앗을 심을 준비’ 스토리가 활성화되고 아직 구매하지 않은 경우에만 비비안의 해당 이야기 대화에서 구매 선택지를 보여준다. 한 번 구매하면 그 선택지는 종료하고 귀가·심기 단계로 이어진다. 구매를 보류하거나 잔액이 부족하면 같은 스토리 단계에서 다시 진행할 수 있다. 스토리 완료 후 재판매 상품으로 열리지 않는다. 기존에 구매한 화분과 심은 씨앗을 삭제하거나 감추는 뜻은 아니며, 씨앗 이야기의 연출 대상으로 유지한다. 가격·정확한 스토리 시작 조건은 계속 미정이다. ✅ 기획 반영 / ⏳ 구현·검수 대기.

**P1 (Major) · ✅ 완료: 장면·구매 연결 기획 반영 / ⏳ 대기: 발생 시점·가격·배치 상세·구현·검수.** 씨앗을 심는 이야기 전에 **비비안 잡화점에서 화분을 구매**하는 장면을 넣는다. ‘씨앗을 심을 준비’ 안내 → 잡화점 방문·비비안과 대화 → 씨앗용 화분 구매 → 집으로 돌아와 씨앗 심기 순서다. 잡화점에서 사는 이 스토리용 화분은 기존 인테리어의 모던 프레임 전용 판매 정책에 대한 사용자 지정 예외다. 다른 가구·장식 판매처는 변경하지 않는다.

대사 원고: 소망이 “이 씨앗을 심어보고 싶은데, 화분도 팔아?” → 비비안 “마침 하나 남아 있어요. 마지막 화분인데, 이건 어때요?” → 구매 후 비비안 “어떤 싹이 날지 궁금하네요.” 귀가 후 화분에 씨앗을 심는 짧은 장면으로 연결한다. ‘마지막 화분’은 스토리 전용 일회 구매를 설명하는 대사다. 구매를 보류하거나 돈이 부족해도 다른 손님에게 팔리거나 사라지지 않고, 이 이야기에서 다시 구매할 수 있다. 씨앗의 정체·출생의 비밀이나 즉시 발아를 이 대사로 확정하지 않는다.

씨앗 심기 장면의 선행 조건은 해당 화분의 구매·보유 확인이다. 가격·판매 해금 시점·게시판 공고 연결 여부·심기 장면의 정확한 이야기 위치는 후속 설계한다. 돈이 부족하면 준비를 보류하고 다른 활동을 계속할 수 있으며 대납·무료 화분·추가 대출을 자동 지급하지 않는다. 이미 구매했다면 재구매를 요구하지 않는다.

빈 방에서도 심을 수 있도록 책상·선반 구매를 선행 조건으로 두지 않는다. 정확한 전시 자리는 지정 위치 방식에 맞춰 후속 설계한다. 모던 프레임의 첫 가구 구매·배치 튜토리얼과 별도 사건으로 관리한다. 구매·심기 완료를 저장해 재개 때 돈·화분·씨앗을 중복 차감/생성하지 않으며 소비/보관 방식은 구현 전 정한다. 씨앗의 외형은 위 레벨 연동 규칙을 따르며 화분 구매로 호감도·능력치·성장 단계를 올리지 않는다.

## 2026-10-19 첫 활동 완료·해 질 무렵·첫 숙박 — 최신 정정

**P0 (Core) · ✅ 완료: 시간 흐름 기획 정정 / 🔄 진행중: 경제 날짜 상세 연결 / ⏳ 대기: 구현·저장·게임 검수.** 첫 숙박은 일을 하거나 주식을 배우기 전이 아니라, **선택한 첫 활동을 마치고 해가 저문 뒤** 진행한다. 이전의 해 질 무렵 도착·활동 전 숙박·활동 시작 시 로컬 전환 설명은 이 흐름으로 대체한다.

**아침 버스 탑승 → 점심 무렵 마을 도착 → 정착 안내소 입주 신청·서명 → 마을 안내·빈 집 확인 → 생활 자금 상담·은행 → 입주·두 수입 방법 소개 → 선택한 첫 활동 체험 → 해 질 무렵 귀가 → 첫 하룻밤 → 로컬 시간 전환 → 남은 활동 체험·공통 자립 안내.**

도착·정착·첫 활동 안내와 체험 동안은 점심 연출을 유지한다. 첫 활동을 마치면 해 질 무렵으로 전환한다. 정확한 시각은 미정이며 실제 접속 시간이 도입 연출을 바꾸지 않는다.

| 먼저 선택한 활동 | 첫 저녁 전까지 | 첫 숙박·로컬 전환 이후 |
| :--- | :--- | :--- |
| 주민 부탁 | 게시판 비비안 공고 → 잡화점 첫 주문·보수·찌라시 수령 → 해 질 무렵 광장 벤치에서 안나와 재회·정보 해석·회복 안내 → 귀가 | 증권사 자격증·거래 기초·첫 매수 → 공통 자립 안내 |
| 주식 투자 | 증권사 자격증·거래 기초·첫 매수·계좌 확인 → 해 질 무렵 광장 벤치에서 안나와 재회 → 귀가 | 게시판 비비안 공고 → 잡화점 첫 주문·보수 → 찌라시 해석·회복 → 공통 자립 안내 |

첫 매수는 수익·매도까지 기다리지 않는다. 노동은 주문 성공·보수 확인과 연결 안내를 완료한다. 해 질 무렵 전환은 진행 중 작업·주문·대화를 끊지 않는 체험 마무리 경계에서 처리한다. 두 활동 모두 배우는 기존 결정은 유지하되 사이에 첫 숙박을 둔다. 지원금 2,000G는 양쪽 체험 뒤 공통 자립 완료 또는 기존 건너뛰기 처리에 한 번만 지급한다.

안나는 첫 활동 후 광장 벤치에서 재회해 “직접 해보니까 어땠어요?”라고 묻는다. 소감을 들은 뒤 “오늘 수고했어요. 꿀 쿠키 하나 먹을래요?”라며 꿀 쿠키 한 개를 건넨다. 소망이 “달아?” → 안나 “네. 먹으면서 잠깐 쉬어요.”로 이어지고 벤치에서 쿠키를 먹으며 쉰다. 노동 선행이면 받은 찌라시의 해석도 이 재회 장면에서 안내한다. 마무리 대사: “어느새 해가 지고 있네요. 오늘은 여기까지 하고 쉬어요. 다른 방법은 쉬고 나서 배워봐요.” 집에서 ‘오늘은 쉬기’를 선택하면 짧은 암전으로 하룻밤 경과를 표현한다. 실제 밤이 끝날 때까지 기다리게 하지 않는다. 첫 집은 가구 없는 빈 방이며 침대 구매·무료 침대 지급을 숙박 조건으로 추가하지 않는다. 휴식은 장면/메뉴로 제공한다.

**2026-10-19 꿀 쿠키 확정:** 첫 활동 종류·투자 수익·호감도와 관계없이 벤치 재회에서 **꿀 쿠키 1개**를 한 번 제공한다. 비비안 잡화점 판매 상품과 같은 먹거리이며 **사용 시 하트 1칸 회복**으로 확정한다. 최대 하트를 초과하지 않으며 최대 하트 증가 효과는 없다. 기존 튜토리얼 드링크 선물을 대체하고 중복 지급하지 않는다. 상품 가격·구매/사용 제한·아이템 ID·소지품 지급/즉시 먹기 처리·하트가 가득 찼을 때 사용 처리는 후속 설계한다. 회복 안내는 양쪽 분기 공통의 첫 재회에 배치하므로 투자 선행 후 두 번째 노동을 완료할 때 다시 선물을 지급하지 않는다. 첫 재회·선물 제공·먹기 완료를 구분해 저장하여 중단/재개·스킵·기존 드링크 수령 저장 이관 시 이중 지급을 막는다. ✅ 상품·효과·대사 기획 반영 / ⏳ 상세 처리·구현·검수 대기.

첫 숙박을 완료한 뒤 현재 기기의 로컬 날짜·시각·시간대를 읽어 일반 생활의 시계·하늘·조명에 반영한다. 깨어난 이후 실제 시간이 저녁이면 저녁 풍경이며 무조건 아침으로 고정하지 않는다. 이후 접속에도 현재 로컬 시간을 읽는다. 도입 연출의 시간 오프셋을 계속 누적하지 않는다.

점심 도입/첫 활동 후 해 질 무렵/숙박 후 로컬 시간 모드와 활동 순서·완료·첫 숙박 상태를 각각 저장하고 중단·재개 시 복원한다. 끝낸 활동·숙박·자금·자격증·보상을 반복 처리하지 않는다. 전체 스킵·기존 저장 이관·시간대 변경·날짜 경계 처리와 로컬 야간의 남은 필수 활동 접근은 구현 전 설계한다.

경제 Day·첫 월세·배당·체력 회복·대출 상환과 현실 날짜의 매핑은 후속 설계다. 버스 이동·연출 시간 변경·첫 숙박만으로 월세/상환 기한이나 정산을 임의 처리하지 않는다. 기존 ‘다음 날’ 코드를 로컬 날짜 연동 완료로 기록하지 않는다. 증권사 외관 시계의 KST 고정 표시는 생활 시각에 맞출 전환 대상이며 온라인 KST 제한·우편 배송 정책은 자동 변경하지 않는다.

## 2026-10-19 정착 안내소 첫 방문 — 최신 후속 채택

**P0 (Core) · ✅ 완료: 기획 반영 / ⏳ 대기: 동선·화면 구현·검수.** 정착 안내소는 소망이가 마을 도착 후 **가장 먼저 방문하는 건물**이다. 버스 정류장에서 안나를 만나 안내소로 이동하고 **마을 입주 신청서**를 작성한다. 안나의 “당신의 이름을 적어주세요.” 안내에 따라 ‘신청인 서명’ 칸에 이름을 입력해 닉네임을 등록한다. ‘태어난 소망’은 빈칸으로 둘 수 있다.

**버스 도착 → 안나와 첫 만남 → 정착 안내소·입주 신청서 서명 → 마을 안내·빈 집 확인 → 생활 자금 상담·노드 은행 → 입주·두 수입 방법 안내**로 정리한다. 마을 구경·집 확인을 신청서 작성보다 앞에 두었던 설명은 이번 결정으로 대체한다. 투자 성향 진단·자격증은 안내소에서 진행하지 않고 이후 증권사 체험에서 진행한다. 기존 대출·지원금·양쪽 수입 활동 체험·첫 가구 구매 후 배치 안내는 유지한다.

## 2026-10-19 빈 방·첫 가구 배치 튜토리얼 — 최신 후속 채택

**P0 (Core) · ✅ 완료: 기획 반영 / ⏳ 대기: 구매 트리거·배치 안내·저장·게임 검수.** 마을 구경 중 확인하는 집과 첫 입주 공간은 가구 없는 빈 방이다. 안나: “가구는 살면서 하나씩 채워가면 돼요. 모던 프레임에서 살 수 있어요.” 가구 구매는 첫날 강제 단계로 넣지 않고 플레이어의 구매 시점에 배치 안내를 연결한다.

**모던 프레임 첫 가구 구매 완료 → 배치 안내 대기 → 집 진입 → 집꾸미기 열기 → 구매한 가구 선택 → 호환 지정 위치 선택·미리보기 → 배치 확정·저장 → 안내 완료.** 기존 지정 위치 배치를 사용하며 자유 이동·회전은 추가하지 않는다. 취소·중단 시 구매한 가구를 잃지 않고 재개할 수 있도록 설계한다. 완료 후 반복 안내·중복 구매를 요구하지 않는다. 세부 보유/배치 규칙은 [룸 명세](ROOM_PACKAGE_GUIDE.md)를 따른다.

첫 가구의 종류·가격·구매 날짜는 미정이며 무료 지급·추가 지원금·새 완료 보상은 신설하지 않는다. 가구를 사지 않아도 주민 부탁·주식 투자·생활 진행을 계속할 수 있다. 기존 첫 활동 선택과 별도의 상황별 안내로 관리한다.

아래 ‘씨앗을 책상에 놓는’ 입주·첫 주 연출은 책상 보유를 전제하지 않도록 수정한다. 빈 방에서는 가져온 짐에서 씨앗과 편지를 꺼내 살펴보는 장면으로 표현한다. 화분에 심은 이후의 외형은 머리 위 성장과 같은 레벨 단계를 따른다. 내일의 약속은 관계 장면이며 별도 발아 조건이 아니다. 연출용 짐은 무료 가구 보상이나 꾸미기 상품이 아니다.

## 2026-10-19 주민 신청서 서명 — 최신 후속 채택

**P0 (Core) · ✅ 완료: 기획 반영 / ⏳ 대기: 화면·저장 연결·검수.** 마을 도착 후 첫 건물인 정착 안내소에서 작성하는 마을 입주 신청서의 **‘신청인 서명’** 칸에 이름을 입력한다. 이 서명이 플레이어 닉네임 등록을 겸하며 별도 이름 입력을 반복하지 않는다. 안나: “당신의 이름을 적어주세요.” → 이름 입력 → 신청서 제출 → “[닉네임]님, 마을에 오신 걸 환영해요.”로 연결한다. ‘태어난 소망’ 빈칸은 그대로 허용한다. 이름 입력·확인·이어하기 규칙은 [등록 명세](CORE_GDD_08_CharacterCreation.md)를 따른다.

## 2026-10-19 첫 활동 선택 분기 — 최신 후속 채택

**P0 (Core) · ✅ 완료: 기획 반영 / ⏳ 대기: 분기·게시판·자격증·저장 및 게임 검수.** 입주 후 안나가 두 가지 수입 방법을 소개하고 “어떤 것부터 해볼까요?”라고 묻는다. 선택지는 **‘주민 부탁 들어주기’ / ‘주식 투자하기’**다. 아래 첫 매수 후 잡화점으로 가는 고정 순서보다 이번 선택 분기를 우선한다.

**2026-10-19 벤치 재회 후속:** 어느 선택지를 골라도 목적지를 안내한 뒤 안나는 **“그럼 이따가 다시 광장 벤치에서 만나요.”**라고 말한다. 이후 플레이어가 해당 장소로 가고, 잡화점 일은 비비안, 투자 배우기는 K가 안내한다. 첫 활동 완료 후 목표는 ‘광장 벤치에서 안나 만나기’로 바뀐다. 활동 완료 전 벤치 방문만으로 후속 대화·숙박을 진행시키지 않는다. 재회는 실제 시각 약속이나 만료 제한이 아니라 완료 상태로 연결하며 중단 후에도 이어갈 수 있다. 안나의 이동·재회 표시와 중복 재생 방지는 구현 시 검증한다. 아래 동행 표현보다 이번 약속·재회 흐름을 우선한다. ✅ 기획 반영 / ⏳ 구현·검수 대기.

| 선택 | 진행 | 연결 대사 |
| :--- | :--- | :--- |
| 주민 부탁 들어주기 | 광장 쉼터 마을 게시판 → 비비안 공고 열람 → 잡화점 방문·첫 주문 → 보수·찌라시 → 광장 벤치에서 안나와 재회·해석·회복 안내 | 안나: “마을 게시판에 주민들의 부탁이 붙어 있어요. 먼저 살펴보세요. 그럼 이따가 다시 광장 벤치에서 만나요.” |
| 주식 투자하기 | 사이퍼 증권 방문 → K와 자격증 발급 → 거래 기초·첫 매수 → 광장 벤치에서 안나와 재회 | 안나: “사이퍼 증권에서 먼저 투자 자격증부터 만들어보세요. 그럼 이따가 다시 광장 벤치에서 만나요.” |

비비안의 공고 원고: **[잡화점 일을 도와주실 분을 찾습니다]** / “손님들의 주문을 함께 준비해주실 분을 구해요. 처음이어도 괜찮아요. 일하는 방법은 제가 알려드릴게요. 일을 마치면 보수를 드립니다. — 비비안 잡화점”. 공고에서 장소·할 일·보수 안내를 확인하고 가게로 이동한다. 보수 수치는 노동 명세의 후속 조정 대상이며 공고를 읽는 것만으로 완료 보상을 지급하지 않는다.

주민 신청과 투자 자격증 발급은 별개다. 주민 신청에는 닉네임·정착 확인을 두고, 기존 투자 TPT 3문항·트레이더 출입증 연출은 증권사 자격증 절차로 옮겨 활용하는 설계로 정리한다. 추가 시험·합격 점수·발급 비용은 신설하지 않는다. 기존 성향 보너스의 지급 시점·발급 전 능력치·출입증 저장과의 이관은 후속 설계한다.

**2026-10-19 양쪽 활동 순차 체험 후속 채택:** 첫 선택은 두 활동의 순서만 정한다. 정상 튜토리얼에서는 잡화점 일과 주식 투자를 모두 체험하며, 먼저 선택한 활동을 마치면 안나가 나머지 활동으로 안내한다. 주민 부탁을 먼저 고르면 매수·자격증을 노동 선행 조건으로 두지 않는다.

| 첫 선택 | 전체 진행 |
| :--- | :--- |
| 주민 부탁 들어주기 | 마을 게시판의 비비안 공고 → 잡화점 첫 주문·보수 → 찌라시 해석·회복 → 안나의 투자 안내 → 사이퍼 증권 자격증 발급 → 거래 기초·첫 매수 → 공통 자립 안내 |
| 주식 투자하기 | 사이퍼 증권 자격증 발급 → 거래 기초·첫 매수 → 안나의 주민 부탁 안내 → 마을 게시판의 비비안 공고 → 잡화점 첫 주문·보수 → 찌라시 해석·회복 → 공통 자립 안내 |

연결 대사: 잡화점 일을 먼저 마쳤다면 안나 “주민들을 돕고 보수를 받는 방법을 배웠네요. 이번에는 주식 투자를 배워볼까요? 사이퍼 증권으로 가요.” / 주식을 먼저 배웠다면 “주식 투자를 해봤으니, 이번에는 주민들을 돕고 보수를 받아봐요. 마을 게시판부터 살펴볼까요?”

첫 매수 체험은 매수 체결·계좌/거래 내역 확인까지이며 수익 발생이나 매도까지 기다리지 않는다. 잡화점 체험은 주문 전달·보수 지급을 확인하고 기존 찌라시 해석·회복 안내를 마친 뒤 다음 활동 또는 자립 안내로 연결한다. 양쪽 체험 후 생활비 분리·NPC 의뢰·칭호 안내를 거쳐 튜토리얼을 완료한다. 정상 진행 중 나머지 활동을 단순 선택 사항으로 남기지 않되 기존 일시 중단·재개·전체 건너뛰기 기능은 유지한다.

정착 지원금 2,000G는 전체 튜토리얼 완료 또는 기존 건너뛰기 처리 시 한 번만 지급하며 각 활동 완료 때마다 지급하지 않는다. 순서와 활동별 완료 상태를 별도로 저장해 재개 시 끝낸 활동·자격증·보수·찌라시·회복 선물을 중복 처리하지 않도록 설계한다. 정확한 체크포인트·저장 키·기존 저장 이관은 구현 전에 확정한다. **P0 (Core) · ✅ 기획 반영 / ⏳ 구현·검수 대기.**

기존 첫 매수의 현물 1주·가격 비조작과 첫 주문의 시간 제한 없는 연습 조건은 유지한다. 증권사 내 첫 매수 화면·스마트폰 연결, 분기별 온라인 채널 입장, 공고 열람·첫 주문·자격증·첫 매수의 개별 체크포인트 및 스킵/재개 처리는 구현 전 설계한다. 기존 K 모의투자 경쟁 안내를 자격증 시험으로 자동 전환하지 않는다. 시작 대출·월세·미정 상환 조건은 유지한다.

## 2026-10-19 이주·주민 신청·정착 대출 후속 채택

**P0 (Core) · ✅ 완료: 기획 반영 / ⏳ 대기: 대출 세부 설계·도입 구현·저장 이관·게임 검수.** 아래 2026-10-18의 도착 직후 등록·은행 방문 제외 설명보다 이번 순서를 우선한다. 중후반 이야기·출생의 진실·편지 작성자·엔딩은 이번 채택 범위에 포함하지 않는다.

**마을 광고 전단지 발견 → 버스 도착 → 안나와 첫 만남 → 마을 구경 → 지낼 집 확인 → 정착 안내소 주민 신청 → TPT·출입증 → 생활 자금 상담 → 노드 은행 정착 대출 → 입주·기존 첫날 안내**로 진행한다.

- 전단지는 새 주민 모집 광고다. 작은 집·일거리 안내와 “아직 무엇을 하고 싶은지 몰라도 괜찮습니다.”라는 문구를 보고 이주를 결심한다. 씨앗과 편지의 작성자는 안나로 확정하지 않는다.
- 안나는 먼저 광장·잡화점·모던 프레임·증권사·은행의 위치와 생활을 짧게 소개하고 지낼 집을 보여준다. 모든 건물의 실내 방문·기능 설명을 요구하지 않는다. 집을 본 뒤 소망이가 정착을 선택한다.
- 주민 신청서는 기존 닉네임 등록을 담는 화면이다. 고정 요정 미리보기·닉네임·신청 확인으로 구성하고, ‘태어난 소망’ 빈칸은 서사 표현으로 남긴다. 추가 필수 입력·성향 진단을 신설하지 않으며 기존 TPT 3문항과 출입증 발급을 유지한다.
- 안나는 “당분간 생활할 돈은 가지고 오셨어요?”라고 묻고 생활비와 집세를 함께 확인한 뒤 은행에 동행한다. 소망이의 별도 소지금 액수·추가 지급은 신설하지 않는다.
- 샤일록은 대출 조건을 설명하고 소망이가 확인한다. 안나는 절차를 돕되 보증인·대납자로 설정하지 않는다. 대출 화면은 원금·이자·상환 시기·총상환액을 알 수 있도록 설계한다. 구체적인 조건은 [금융 명세](CORE_GDD_04_FinancialInstitutions.md)의 후속 설계 대상이다.
- 기존 시작 자금 **5,000G의 출처를 정착 대출로 전환**한다. 기존 시작 자금과 대출금을 이중 지급하지 않는다. 튜토리얼 정착 지원금 **2,000G는 별도 유지**하고 완료·건너뛰기 시 중복 없이 지급하는 기존 조건을 유지한다.
- 입주 후 첫 매수 → 비비안 잡화점 첫 주문 → 정보 해석 → 회복 → 자립 순서를 유지한다. 은행 대화에서는 비비안의 일거리를 예고하되 이번 결정으로 첫 매수·주문의 순서를 바꾸지 않는다. 7일 차 현금 월세 5,000G는 대출 상환과 별개다.

도입은 첫날에 포함한다. 마을 구경의 보행 범위·온라인 채널 연결·대출 거절/보류·스킵 시 계약 확인·중단/재개 체크포인트는 구현 전 설계한다. 오피스에서 시작 자금을 다시 지급하지 않으며, 지급과 채무 기록의 중복 방지 및 기존 저장의 이관을 함께 검증한다. 문서 변경으로 기존 플레이어에게 채무를 소급 부과하지 않는다.

대표 대사: 안나 “그 칸은 비워둬도 괜찮아요.” → 소망이 “그래도 주민이 될 수 있어?” → 안나 “그럼요.” / 은행에서 샤일록 “그럼 처음 생활에 필요한 금액부터 계산해봅시다.”

## 1. 등록과 모드 선택

### 1.1. 마을에 오게 된 계기와 첫 만남 — 2026-10-18 사용자 채택

**P0 (Core) · ✅ 완료: 오프닝·등록 연결 기획 반영 / ⏳ 대기: 연출·대사·체크포인트 구현·검수.** 소망이는 누군가의 소망에서 태어났지만 자기 출생의 소망은 모르는 요정이다. 어느 날 새벽 오래된 나무 아래에서 깨어나, 곁에 놓인 씨앗과 편지를 발견한다. “네가 원하는 삶을 찾으면, 이 씨앗도 깨어날 거야.”라는 편지 외에는 단서가 없다.

며칠 동안 다른 요정들에게 묻지만, 각자 태어난 소망을 말하는 이들과 달리 자신에게는 아무것도 떠오르지 않는다. 이 과정은 짧은 회상으로 표현하고 플레이 가능한 며칠이나 추가 경제 일수로 계산하지 않는다. 정류장에서 다음 안내문을 발견하고 마지막 문장을 읽은 뒤 마을행 버스를 탄다.

> 새로운 시작을 준비하는 분께 작은 방과 정착 안내를 제공합니다.
>
> 아직 무엇을 하고 싶은지 몰라도 괜찮습니다.
>
> — 정착 안내 담당 안나

마을을 선택한 이유는 출생의 답이 보장되어서가 아니라, 답을 몰라도 받아줄 것 같아서다. 편지 작성자·출생의 원인·씨앗의 정체는 미정이며 안내문의 작성자 안나와 편지 작성자를 동일 인물로 확정하지 않는다.

| 첫 만남 | 안나: “정착 안내를 보고 오셨어요?” / 소망이: “하고 싶은 게 없어도 된다고 해서…” / 안나: “네. 아직 없어도 돼요. 우선 등록부터 할까요?” | 정착 안내소 등록 연출로 이동 |
| 등록 | 고정 요정 미리보기와 “이름은 정했어요?” → 플레이어 닉네임 입력 → ‘태어난 소망’ 빈칸을 보고 “좋아요. 나머지 빈칸은 살면서 채워도 돼요.” | 기존 TPT 3문항 |
| 성향·출입증 | “어떤 방식으로 선택하는 분인지 알아두려고요.” → 진단·기존 보너스 → 출입증 발급 | 안나가 작은 집·홈 오피스로 안내 |
| 첫 생활 | 씨앗을 책상에 놓고 시작 자금·생활 안내·7일 차 현금 월세를 설명 | 기존 첫 매수 → 가게 주문 → 정보 해석 → 회복 → 자립 |

‘소망이’는 기획상 캐릭터 이름이며 플레이어에게 강제로 부여하는 닉네임이 아니다. 등록 후 호칭에는 입력한 닉네임을 사용한다. 도착·등록을 첫날의 도입으로 묶고 기존 날짜·월세 기한을 연장하거나 버스 요금·추가 자금·보상을 신설하지 않는다. 첫 생활 목표는 ‘이 마을에서 일주일 살아보기’이며 출생의 비밀 해결은 첫날 완료 조건이 아니다.

등록 전 정류장·안내소는 도입 연출 공간으로 제공한다. 이후 오피스에서 스마트폰을 배우고 타운 채널을 선택하는 기존 순서를 유지하며, 도입 때문에 온라인 채널에 먼저 연결하거나 이동 퀘스트를 추가하지 않는다. 정확한 도입 화면 전환·실제 보행 범위는 구현 때 결정한다.

오프닝의 건너뛰기는 등록 화면으로 연결한다. 기존 안내 중단·재개·건너뛰기와 초기 자금·정착 지원금의 중복 방지를 유지한다. 이어하기에서 오프닝을 강제 재생하거나 닉네임·성향을 다시 입력시키지 않는다. 새 도입 체크포인트·기존 저장 이관은 구현 시 설계·검증한다.

후속 선택 대화에서 안내문에 그 문장을 넣은 이유를 묻는다. 소망이: “왜 아직 몰라도 된다고 썼어?” / 안나: “그걸 정하고 와야 한다면… 시작하지 못할 사람도 있을 것 같아서요.” 안나 자신의 미뤄둔 상담소 계획을 비추는 대화이며 필수 퀘스트·관계 수치 조건으로 추가하지 않는다.

### 1.2. 등록 이후 기존 진행 계약

고정 소망 요정 미리보기·닉네임 입력 → 투자 성향 진단 3문항 → 출입증 → 홈 오피스로 진행한다. 캐릭터 커스텀·스킨 선택은 제거하며 [캐릭터 생성](CORE_GDD_08_CharacterCreation.md)을 따른다. 새 UI와 서사의 게임 반영은 별도다. 새 게임·이어하기·로컬 데모/개발자 모드를 구분한다. 로컬 데모·개발자 모드는 온라인 마을·대결에 연결하지 않는다.

### 안나의 두 가지 수입 방법 안내 — 2026-10-19 사용자 채택

**P0 (Core) · ✅ 완료: 기획 반영 / ⏳ 대기: 대사·진행 연결 구현·검수.** 은행 정착 대출을 받고 입주한 뒤, 첫 매수 안내 전에 안나가 돈을 버는 두 가지 방법을 소개한다. 먼저 주민들을 돕고 보수를 받는 방법, 다음으로 주식에 투자해 수익을 얻는 방법을 설명한다. 두 가지 핵심 플레이를 소개하는 대화이며 기존 배당·보상 등 다른 자금 유입을 삭제하는 규칙이 아니다.

> 소망이: “여기서는 돈을 어떻게 벌어?”
>
> 안나: “크게 두 가지 방법이 있어요. 첫 번째는 주민들을 돕고 보수를 받는 거예요.”
>
> 안나: “비비안 씨 가게에서 주문을 준비하는 것처럼요. 주민들이 부탁하는 일을 해주고 보수를 받을 수도 있어요.”
>
> 안나: “두 번째는 주식에 투자하는 거예요. 회사의 주식을 사고, 산 가격보다 비싸게 팔면 수익을 얻을 수 있어요.”
>
> 소망이: “주식을 사두면 돈이 늘어나는 거야?”
>
> 안나: “가격이 내려가면 손해를 볼 수도 있어요. 생활에 필요한 돈은 따로 남겨두고, 회사와 가격을 살펴보는 것부터 배워봐요.”

이어서 안나가 “어떤 것부터 해볼까요?”라고 묻고 ‘주민 부탁 들어주기’ / ‘주식 투자하기’ 중 고르게 한다. 실제 체험은 문서 최상단의 선택 분기를 따른다. 첫 주문 이후 주민 의뢰 안내에서 다른 도움과 보수로 범위를 넓힌다. 투자 수익 보장·추가 대출·상환 조건을 이 대화로 신설하지 않는다.

### 첫 가게 주문의 안내

안나가 “오늘 비비안 씨 가게에 일손이 필요하대요. 같이 가볼까요?”라고 소개한다. 비비안은 “처음이니까 한 주문만 같이 해봐요. 주문표는 계속 볼 수 있어요.”라고 안내한다. 첫 연습은 손님 한 명·상품 1종·시간 제한 없이 2D 포장 퍼즐의 주문 확인 → 고정 진열대에서 상품 선택·상자로 끌기·회전·재배치 → 포장 → 전달을 익힌다. 작업에 사용하는 상품은 주문 전부터 화면 아래쪽에 고정 진열하고, 위쪽 손님의 주문표와 가운데 포장 상자를 함께 보여준다. 전달 전 잘못 고른 상품을 수정할 수 있다. **2026-10-19 후속 채택:** 조작 튜토리얼에서는 화남 게이지 상승·시간 경과 퇴장을 적용하지 않는다. 이후 본 게임에 다른 요정 손님을 추가하고, 손님이 기다리다 화남 한계에 도달하면 떠나면서 해당 주문을 취소한다. 정확한 손님 수·시간·취소 정산 및 첫날 후속 안내와 본 게임의 연결은 [노동 명세](MOD_GDD_02_LaborJobs.md)를 따른다. ✅ 기획 반영 / ⏳ 구현·검수 대기.

**2026-10-19 찌라시 수급 후속 채택:** 첫 조작 연습의 손님은 수상한 요정으로 한 번 확정 등장한다. 시간 제한·화남 상승 없이 주문을 완료하면 작업 보수와 정보 해석용 찌라시 1장을 지급하고, 손님은 떠나며 짧고 의미심장한 대사를 남긴다. 이는 기존 첫 안내용 보장 찌라시를 제공하는 이벤트이며 추가로 중복 지급하지 않는다. 본 게임에서는 수상한 손님이 확률적으로 등장하고 주문 성공 시 1장을 확정 지급하며, 화남 한계로 주문이 취소되면 지급하지 않는다. 정확한 등장 확률·퇴장 대사는 후속 설계한다. 안나는 “주문도 소문도, 들었다고 바로 다 안 건 아니죠. 무엇이 적혀 있는지 같이 읽어볼까요?”라며 소지품 열람·시간 단서·5단계 해석으로 연결한다. 이어 드링크·벤치·생활비 분리·자립 안내를 유지한다. 새 노동 보수·EXP·하트 수치는 [노동 명세](MOD_GDD_02_LaborJobs.md)에서 후속 조정한다. ✅ 기획 반영 / ⏳ 구현·검수 대기.

구현 시 물류 방문·박씨 대화·물류 점수 조건을 첫날 완료에서 제거하고 가게 주문 완료로 연결한다. 새 체크포인트·중단/재개·건너뛰기·첫 찌라시 중복 방지·구 저장의 물류 체크포인트 이관을 함께 설계·검증한다. 과거 물류 작업 기록을 새 주문 완료로 임의 환산하지 않는다.

### 첫 매수의 조건

추천은 성향·현재 시세·수수료를 포함한 구매 가능 여부를 사용하며 주가를 조작하지 않는다. 최초 주문은 추천 종목의 현물 1주로 안내한다. 구 Safety-First 최저가·강제 상승·차액 지원을 현재 규칙으로 사용하지 않는다. 구매 가능한 종목이 없으면 추천 재검토가 필요하며 별도 보조금을 약속하지 않는다.

### 첫 매도는 별도 후속 안내

첫 매수 체결가 대비 주가가 10% 이상 오르면 첫 투자 후속 안내 대상이 된다. 기본 안내를 끊고 강제 진행하지 않으며, 후속 안내에서는 매도 또는 계속 보유를 선택한다. 매도를 선택했을 때 실제 체결 수량·수수료 반영 손익을 보여준다. 5% 상승·필수 1주 매도·강제 상식 퀴즈를 졸업 조건으로 두지 않는다. 시간 단서 연습 문제는 유료 서점 세미나와 별개다.

### 중단과 보상

안내에는 이전/다음·일시 중단·체크포인트 재개·건너뛰기 경로가 있다. 현재 전역 이동 잠금 함수는 항상 false이므로 모든 기능과 종료를 일괄 차단하는 레일로드를 현행 규칙으로 기록하지 않는다. 각 화면의 단계별 입력 가드는 별도다.

초기 자금은 한 번 지급하며, 정착 지원금은 완료·건너뛰기 모두 2,000G를 중복 없이 지급한다. 안내 중 쓴 금액이 있으므로 현재 잔고가 항상 7,000G가 되는 것은 아니다. 회복 선물도 한 번만 처리한다. 가방이 가득 찬 경우 재시도가 필요하다.

## 3. 자립 이후

7일 차까지 월세용 **현금 5,000G**를 마련한다. 주식 평가액만으로 납부할 수 없다. 날짜는 다음 날 진행 조작으로 올리며 월요일 00시·신규 72시간 유예와 연결하지 않는다. 7일 차에 현금이 충분하면 한 번 차감하고 납부 결과를 저장한다. 부족하면 미납 결과를 표시하며 자동 파산·압류·Lv.3 강제 종료는 없다. [경제·정산](CORE_GDD_07_EconomySim.md)을 따른다.

현재 구현의 의뢰 제공자는 안나·박씨·에이전트 K다. 안나는 실현 손익·연승, 박씨는 물류 점수·무파손, K는 모의투자 승리 과제를 제공한다. 새 기획에서는 가게 주문 의뢰의 조건·보상과 기존 물류 의뢰의 존치·이관을 별도 설계한다. [업적·칭호](MOD_GDD_08_AchievementSystem.md)의 기존 수치를 새 노동에 자동 적용하지 않는다.

증권사에는 별도 K 이용 안내가 있다. 로비 → 실제 게임 계좌를 쓰는 트레이닝룸 → 별도 가상 계좌를 쓰는 경쟁룸 → K와 무료 3분 대결로 안내한다. 경쟁룸의 자금·배팅은 평소 잔고와 분리한다. [금융·증권사](CORE_GDD_04_FinancialInstitutions.md)를 따른다.

## 4. 소망 요정의 첫 일주일 — 2026-10-18 사용자 채택

**P0 (Core) · ✅ 완료: 컨셉·초반 서사 기획 반영 / ⏳ 대기: 대사·연출·저장 및 게임 검수.** 아래는 채택된 서사 설계이며 현재 실행 대사·트리거의 구현 완료를 뜻하지 않는다. 등록의 외형 선택을 제거하고 첫 노동만 가게 주문으로 교체한다. 첫 매수·정보 해석·회복·자립 순서와 시작 자금·정착 지원금·월세 조건은 유지한다.

### 4.1. 주인공의 출발점

소망 요정은 누군가의 간절한 바람에서 태어난다. 보통은 태어난 소망을 어렴풋이 알지만, 플레이어는 누구의 어떤 소망에서 태어났는지 모른다. 가지고 온 것은 싹이 나지 않는 씨앗과 “네가 원하는 삶을 찾으면, 이 씨앗도 깨어날 거야.”라는 편지다. 편지를 쓴 사람과 출생의 진실은 미정으로 남긴다. 안나의 소망에서 태어났다고 확정하지 않는다.

이야기의 중심은 ‘아직 자기 꿈이 없는 작은 요정이 남들의 꿈이 모인 마을에서 자기 삶을 만들어간다’다. 노동은 주민에게 필요한 일을 해보는 경험, 투자는 기업과 마을 바깥세상을 알아가는 활동, 찌라시 해석은 소문과 확인된 사실을 구별하는 경험으로 연결한다. 요정 능력이 주가 예측·수익 보장·보상 배율을 제공하지 않는다.

### 4.2. 등록과 첫날 장면

| 기존 진행 위치 | 추가할 이야기와 대표 대사 | 유지할 기능 계약 |
| :--- | :--- | :--- |
| 캐릭터 등록·닉네임 | 안나가 등록 서류의 ‘태어난 소망’ 빈칸을 보고도 캐묻지 않는다. “이름은 정했어요?” → 닉네임 입력 → “좋아요. 나머지 빈칸은 살면서 채워도 돼요.” | 추가 필수 입력 없이 기존 등록 순서 유지. 빈칸은 서사 표현이며 새 개인정보 입력 항목이 아님 |
| 성향 진단·출입증 | “어떤 방식으로 선택하는 분인지 알아두려고요.” 등록을 마치고 오피스로 안내한다. | TPT 3문항·진단·보너스 유지 |
| 오피스 환영 | 플레이어가 씨앗을 책상에 놓는다. “여기서는 원하는 걸 천천히 찾아도 돼요. 다만 그동안 지낼 곳과 생활비는 필요하죠.” | 시작 자금 5,000G. 이때부터 7일 차 현금 월세 5,000G를 알림 |
| 스마트폰·첫 매수 | “이 숫자 뒤에도 일하는 사람들이 있어요. 무엇을 만드는 회사인지 먼저 읽어볼까요?” 첫 체결 뒤 씨앗을 바라보지만 변화는 없다. “오늘 한 번으로 답을 찾기는 어렵겠죠.” | 성향·구매 가능 여부 기반 추천, 시장가 현물 1주. 강제 상승·씨앗 성장 보상 없음 |
| 타운·잡화점 주문 | 안나가 비비안의 일손 돕기를 소개한다. 비비안: “처음이니까 한 주문만 같이 해봐요.” 일한 뒤 안나: “첫 일은 어땠어요?” 선택 답변은 ‘힘들었어’ / ‘다시 하면 더 잘할 것 같아’. | 타운 입장 유지, 첫 주문 확인·선택·포장·전달로 교체. 답변으로 보상·성장 차등 없음 |
| 보상 찌라시 해석 | “그럴듯한 이야기와 확인된 사실을 나눠 봐요. 이 문장에서 실제로 알 수 있는 건 어디까지일까요?” | 소지품 열람·시간 단서 연습·5단계 해석 유지 |
| 드링크·벤치 | “오늘 처음 하는 일이 많았죠. 이거 마시고 잠깐 앉아요.” 플레이어: “더 해야 하는 거 아니야?” 안나: “내일도 할 수 있게 쉬는 거예요.” | 기존 한 번의 드링크 선물·바로 사용·벤치 안내 유지 |
| 자립 안내·완료 | “다음에 무엇을 할지는 직접 골라보세요. 궁금한 게 생기면 찾아오고요. 같이 살펴볼 수는 있으니까.” | 생활비 분리·NPC 의뢰·칭호 소개, 완료·건너뛰기 시 공식 정착 지원금 2,000G 중복 방지. 안나 사비로 바꾸지 않음 |

### 4.3. 2~6일 차: 행동에 반응하는 관계

아래는 첫 주 자유 진행 중 사용할 장면이다. 날짜별 강제 일과나 튜토리얼 완료 조건으로 만들지 않으며, 실제 행동 후 선택 대화로 제공한다. 행동이 없으면 해당 장면을 강제 재생하지 않는다.

| 계기 | 대사·연출 | 관계의 변화 |
| :--- | :--- | :--- |
| 첫 손실 후 대화 | “어떤 생각으로 샀는지부터 같이 볼까요?” | 실수도 이야기할 수 있는 상대 |
| 가게 주문 일을 하고 돌아온 뒤 대화 | “오늘은 일이 익숙해졌어요?” | 수익 외에 하루의 경험도 궁금해함 |
| 첫 NPC 의뢰 완료 | 의뢰 제공자와 내용에 맞는 반응. 비비안의 주문 관련 의뢰라면 “비비안 씨가 다음에도 부탁하고 싶다던데요.” | 주민에게 자기 자리가 생김. 새 의뢰 조건·보상 구현은 별도 |
| 씨앗에 관해 다시 질문 | “제가 아는 분에게도 물어봤는데, 아직 단서는 없어요.” | 안나도 업무 밖에서 마음을 쓰고 있음 |
| 기본 안내 이후 선택 대화 | 정착 안내서를 계속 고치는 안나에게 플레이어가 “내일도 할 수 있게 쉬는 거라며.”라고 되돌려준다. 안나: “…그 말, 기억하고 있었네요.” | 플레이어도 안나를 돌보기 시작함 |

첫 매수 체결가 대비 10% 상승 후 안내는 위 첫 매도 규칙 그대로 별도 발생한다. “목표에 도착했네요. 지금 팔아도 되고, 이유가 있다면 더 보유해도 돼요. 처음 생각과 달라진 게 있는지 확인해 봐요.” 상승을 기다리게 하거나 매도를 서사 필수 조건으로 만들지 않는다.

### 4.4. 7일 차: 첫 독립과 내일의 약속

월세 판정·차감·저장은 기존 경제 규칙을 사용한다. 결과별 대사 후 공통 관계 장면으로 합류한다.

- **납부:** “처음 왔을 때는 어디로 가야 할지도 몰랐는데, 벌써 일주일이네요. 이제 여기서 해보고 싶은 일이 생겼어요?” 답변은 ‘더 모으고 싶어’ / ‘주민들을 더 알고 싶어’ / ‘아직 모르겠어’. 정답·보상 차등 없이 모두 수용한다.
- **미납:** “이번 월세는 아직 못 냈어요. 지금 가진 현금과 주식을 나눠서 확인해 볼까요? 부족한 금액부터 알아야 다음 선택을 할 수 있으니까요.” 자동 퇴거·파산, 안나의 대납·추가 보조금·보장 수익을 넣지 않는다. 후속 납부·반복 정산 정책도 이 대사로 신설하지 않는다.
- **공통:** 플레이어 “내일도 와?” → 안나 “물어볼 게 남았어요?” → 플레이어 “그냥, 같이 차 마시려고.” → 안나 “…그럼 내일은 제 것도 준비해 주세요.”
- 이후 씨앗을 돌아보는 장면은 구매·심기 상태와 현재 레벨에 맞춰 표현한다. 심었다면 해당 성장 단계의 화분을, 아직 심지 않았다면 보관 중인 씨앗을 보여준다. 내일의 약속이나 월세 결과로 씨앗 껍질을 별도로 변화시키지 않는다. 양쪽 월세 결과 모두 관계 장면으로 이어지며, 씨앗에 경제 효과·스탯·판매 기능을 부여하지 않는다.

장면 구현 시 기존 안내의 중단·재개·건너뛰기를 유지한다. 선택 서사를 보지 않아도 거래·노동·월세는 진행된다. 이야기 장면은 재개 시 중복 재생되지 않도록 처리해야 하며, 정확한 트리거·저장 키·스킵한 장면의 재열람 방식은 구현 시 설계·검증한다. 안나의 야간 월드 표시 조건을 새 대사로 변경하지 않는다. 공통 장면은 대화 연출로 제공하고 실제 야간 방문·동거를 해금하지 않는다.

## 5. 폐기한 진행 요구와 미정 사항

- 사람 피부·헤어·의상 파츠 선택, 가구 드래그·R키 회전을 튜토리얼 필수 조건으로 사용하지 않는다.
- 집꾸미기 선택 범위는 [룸 명세](ROOM_PACKAGE_GUIDE.md)에 채택했다. 구체 온보딩 단계·대사·보상은 미정이며 룸·장식 구매를 졸업 조건으로 추가하지 않는다.
- 첫 월세 납부 이후 장기 진행·반복 정산·대출·회생의 연결은 별도 기획·구현 대상이다.
