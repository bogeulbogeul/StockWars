# CORE_GDD_10 게임 시작과 튜토리얼

> 개정: 2026-10-16. 현재 웹·Electron 진행을 기준으로 정리했다. 장면의 시점·제작은 [아트](ART_STYLE_GUIDE.md)·[룸 명세](ROOM_PACKAGE_GUIDE.md)를 따른다.

## 1. 등록과 모드 선택

캐릭터 선택·닉네임 입력 → 투자 성향 진단 3문항 → 출입증 → 홈 오피스로 진행한다. 외형은 동물 완성형 스타일이며 [캐릭터 생성](CORE_GDD_08_CharacterCreation.md)을 따른다. 새 게임·이어하기·로컬 데모/개발자 모드를 구분한다. 로컬 데모·개발자 모드는 온라인 마을·대결에 연결하지 않는다.

## 2. 첫 거래 안내의 현재 순서

| 구간 | 실제 진행 | 대표 체크포인트 |
| :--- | :--- | :--- |
| 1/4 오피스 | 환영·시작 자금 5,000G·HUD와 하트·메뉴 설명 | `welcome_1`, `welcome_2` |
| 2/4 스마트폰 | 스마트폰 → 사이퍼M → 주식 거래 → 추천 종목 → 차트·기업 정보·호가·주문 설명 → 시장가 1주 매수 → 내 계좌·거래 내역·뉴스 확인 | `open_phone`, `launch_stock_app`, `select_stock`, `buy_stock`, `portfolio_guide` |
| 3/4 타운·물류 | 스마트폰 닫기 → 문·이동 안내 → 타운 채널 선택·입장 → 비트 물류 → 박씨와 대화·첫 작업 | `go_town_proposal`, `server_enter`, `enter_logistics` |
| 3/4 정보·회복 | 보상 찌라시를 소지품에서 열람 → 시간 단서 연습·5단계 해석 설명 → 안나의 드링크 선물 바로 사용 → 벤치 회복 안내 | `rumor_inventory_guide`, `rumor_time_prediction`, `stamina_recovery_guide` |

실제 문장·화면 타깃·강조 순서는 [시나리오](../web/js/components/tutorial/annaTutorialScenario.js)와 [압축 안내](../web/js/components/tutorial/compactAnnaLessons.js)가 기준이다. [다이얼로그 DB](MOD_GDD_07_DialogueDB.md)의 과거 `TUT_00`~`TUT_07`는 현재 실행 ID가 아니다.

### 첫 매수의 조건

추천은 성향·현재 시세·수수료를 포함한 구매 가능 여부를 사용하며 주가를 조작하지 않는다. 최초 주문은 추천 종목의 현물 1주로 안내한다. 구 Safety-First 최저가·강제 상승·차액 지원을 현재 규칙으로 사용하지 않는다. 구매 가능한 종목이 없으면 추천 재검토가 필요하며 별도 보조금을 약속하지 않는다.

### 첫 매도는 별도 후속 안내

첫 매수 체결가 대비 주가가 10% 이상 오르면 첫 투자 후속 안내 대상이 된다. 기본 안내를 끊고 강제 진행하지 않으며, 후속 안내에서는 매도 또는 계속 보유를 선택한다. 매도를 선택했을 때 실제 체결 수량·수수료 반영 손익을 보여준다. 5% 상승·필수 1주 매도·강제 상식 퀴즈를 졸업 조건으로 두지 않는다. 시간 단서 연습 문제는 유료 서점 세미나와 별개다.

### 중단과 보상

안내에는 이전/다음·일시 중단·체크포인트 재개·건너뛰기 경로가 있다. 현재 전역 이동 잠금 함수는 항상 false이므로 모든 기능과 종료를 일괄 차단하는 레일로드를 현행 규칙으로 기록하지 않는다. 각 화면의 단계별 입력 가드는 별도다.

초기 자금은 한 번 지급하며, 정착 지원금은 완료·건너뛰기 모두 2,000G를 중복 없이 지급한다. 안내 중 쓴 금액이 있으므로 현재 잔고가 항상 7,000G가 되는 것은 아니다. 회복 선물도 한 번만 처리한다. 가방이 가득 찬 경우 재시도가 필요하다.

## 3. 자립 이후

7일 차까지 월세용 **현금 5,000G**를 마련한다. 주식 평가액만으로 납부할 수 없다. 날짜는 다음 날 진행 조작으로 올리며 월요일 00시·신규 72시간 유예와 연결하지 않는다. 7일 차에 현금이 충분하면 한 번 차감하고 납부 결과를 저장한다. 부족하면 미납 결과를 표시하며 자동 파산·압류·Lv.3 강제 종료는 없다. [경제·정산](CORE_GDD_07_EconomySim.md)을 따른다.

안나·박씨·에이전트 K의 의뢰는 대화로 수락한 뒤 기록을 쌓고 보상을 수령한다. 안나는 실현 손익·연승, 박씨는 물류 점수·무파손, K는 무료 연습 후 모의투자 승리 과제를 제공한다. [업적·칭호](MOD_GDD_08_AchievementSystem.md)를 따른다.

증권사에는 별도 K 이용 안내가 있다. 로비 → 실제 게임 계좌를 쓰는 트레이닝룸 → 별도 가상 계좌를 쓰는 경쟁룸 → K와 무료 3분 대결로 안내한다. 경쟁룸의 자금·배팅은 평소 잔고와 분리한다. [금융·증권사](CORE_GDD_04_FinancialInstitutions.md)를 따른다.

## 4. 폐기한 진행 요구와 미정 사항

- 사람 피부·헤어·의상 파츠 선택, 가구 드래그·R키 회전을 튜토리얼 필수 조건으로 사용하지 않는다.
- 룸 판매·선택의 구체 온보딩 단계·대사·보상은 미정이다. 룸 구매를 졸업 조건으로 추가하지 않는다.
- 첫 월세 납부 이후 장기 진행·반복 정산·대출·회생의 연결은 별도 기획·구현 대상이다.
