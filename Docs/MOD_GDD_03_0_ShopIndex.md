## 03-0. 상점 시스템 통합 가이드
본 문서는 StockWars의 각 상점별 전문 기획 문서로 연결되는 통합 인덱스입니다. 상점별 진열 정책은 각 전문 문서를 따릅니다. Modern Frame은 완성형 홈 테마 룸 직접 구매로 전환하며 이전 가구 단품 로테이션 수량·주기를 자동 적용하지 않습니다.

*   **상점 소비 주가 연동 (Brand-Linked Consumption)**: 현재 비비안 구매는 연결 종목이 있으면 로컬 주가를 구매 요청당 0.5% 올립니다. 구매액 비례 기업 매출·전 세계 공통 주가 연동은 확장 설계입니다. 스킨·룸 판매를 이 효과에 자동 연결하지 않습니다.
*   **스폰 정책**:
    *   **동물 스킨 상점**: 테마당 동물 캐릭터 6종을 한 달 동안 직접 판매하며 상세 기준은 전문 문서를 따릅니다. **룸 상점**: 진열 수량·주기·목록은 후속 결정입니다.
    *   **비비안 잡화점**: 현재 고정 카탈로그와 상품별 구매·해금 제한을 사용합니다. 서버 전체 공통 진열 갱신·글로벌 펌핑은 구현된 동작이 아닙니다.

## 공통 획득 정책: 럭키 캡슐·마일리지 폐기

## 1. 결정

럭키 캡슐 뽑기 시스템을 기획에서 제거한다. 플레이어가 원하는 외형과 구성품을 확인한 뒤 선택해서 획득하도록 한다. 기본 상품과 테마 상품을 확정 구매와 확률 획득으로 나누던 이전 정책은 폐기한다.

과거 확률표와 천장 규칙은 현행 기획으로 사용하지 않는다. 이 문서 개정은 코드 삭제나 기존 저장 데이터 이관 완료를 의미하지 않는다.

## 2. 함께 폐기하는 기능

- 픽업·상시 캡슐, 1회·10회 뽑기, 확률표와 확률 상승 배너.
- 2주 픽업 한정 운영, 상시 확률 풀 편입, 종료 임박 안내 및 뽑기 결과 연출.
- 픽업 스탬프, 사이퍼 토큰, 천장 교환, 중복 분해 보상, 시즌 종료 자동 전환.
- 럭키 캡슐 무료 티켓과 해당 티켓의 배당 보상 지급.
- 캡슐 플라자 머신 및 사이퍼몰의 뽑기 화면.
- 뽑기 비용의 주주 할인과 캡슐 소비 전용 주가 연동.

뽑기 전용 앱이나 시설을 별도 쇼핑 기능으로 자동 전환하지 않는다. 필요성이 생기면 별도 기획한다.

## 3. 아이템과 경제 연결의 처리

| 기존 항목 | 변경 기준 |
| :--- | :--- |
| 현행 판매 단위 | 동물 완성형 스킨·완성형 홈 룸을 골드로 직접 구매하는 기획. 구현 상태는 각 전문 문서를 따름 |
| 구 뽑기 의상 | 개별 사람 의상 상품을 자동 이관하지 않음. 동물 스킨 전문 기획으로 대체 |
| 구 뽑기 가구 | 단품을 룸 상품으로 자동 이관하지 않음. 룸 가격·보유 매핑·효과는 별도 결정 |
| 스킨 판매 기간 | 일반·한정판 구분 없이 테마별 한 달 직접 판매. 상세 기준은 의상 상점 기획을 따르며 기존 캡슐의 2주 판매 조건은 승계하지 않음 |
| 재화 소모처 | 의상·가구의 선택 구매와 수집으로 유지. 확률적 중복 획득을 소모처로 사용하지 않음 |
| 구매와 주가 연결 | 현재 비비안의 로컬 연결 효과와 장기 매출 연동 설계를 구분. 캡슐 소비 경로는 폐기 |
| 뽑기 전용 재화·티켓 | 신규 발행과 소모 기능을 만들지 않음. 기존 보유 데이터가 있다면 확인 후 별도 이관 정책 수립 |

기존 업적·이벤트의 확정 보상은 유지한다. 뽑기 폐기를 이유로 새 교환 재화나 무작위 상자를 추가하지 않는다.

## 4. 적용 범위와 후속 설계

- 본 결정은 의상·가구 획득용 럭키 캡슐과 그 부속 기능에 적용한다.
- 상점에서 판매 품목을 무작위로 진열하더라도, 구매 전에 상품과 가격이 확정되어 있으면 뽑기와 구분한다. 진열 로테이션 개편은 별도 결정이다.
- 클레어 상점은 동물 캐릭터 자체의 완성형 스킨을 테마당 6종씩 한 달 동안 직접 판매한다. 사람 의상 카탈로그를 현행 테마 후보로 승계하지 않는다. 개별 파츠 구매·보유 파츠 제외 구매 제안은 폐기한다. 보유 스타일의 중복 구매는 막으며 가격·할인·진열 수량은 후속 검토한다.
- 의상 능력치 분리나 외형 덮어쓰기는 아직 제안 단계이며 이번 결정으로 자동 적용하지 않는다.
- 복권·블랙잭 등 별개 콘텐츠와 이름에 '캡슐'이 포함된 소모품은 이번 의상·가구 뽑기 폐기의 대상이 아니다.
