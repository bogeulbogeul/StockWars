# 타이틀·개발자 모드·물류창고 폐기

## 2026-10-21 타이틀 후속 요청

소망이 크레파스 2D 시안과 `게임 시작` 버튼을 사용자 요청으로 재도입했다. `TitleScreen.js`와 `crayon-title.css`가 이미지와 실제 버튼을 연결한다. 현재 UI 비표시 모드에서는 기존 3D 마을로 진입하고, 일반 UI 모드에서는 기존 등록/이어하기 흐름을 호출한다. 아래 타이틀 폐기 기록은 이전 이력이며 개발자 모드·물류 기능 폐기는 유지한다.

**P0 (Core) · ✅ 완료: 코드·현행 기획에서 폐기 반영.**

- 타이틀 화면과 설정의 메인화면 복귀 버튼을 제거했다. 현재 UI 비표시 마을 확인 화면은 유지한다. 일반 UI를 켜면 기존 저장은 자동 이어하기, 저장이 없으면 신규 등록으로 진입한다.
- 개발자 도구 바, 개발자 시작 모드, 강제 레벨·날짜 조작, 테스트 친구·선물 경로를 제거했다.
- 비트 물류 건물·휴게실·박씨 안내·운반 미니게임·퀵패스 판매/사용·물류 의뢰와 전용 코드를 제거했다.
- 이전 물류 진행 체크포인트는 자립 안내로 연결하며 가상의 노동 완료나 노동 보상을 지급하지 않는다. 새 비비안 포장 퍼즐·찌라시·회복 안내는 구현 대기다.
- 과거 제작 에셋, 저장 내 보유 아이템·의뢰·칭호 기록은 삭제하지 않는다. 폐기된 패스는 사용할 수 없다.
- 메인 초기화, 마을 조정, 안나 튜토리얼의 큰 파일을 역할별 모듈로 분리했다. 레벨업에서 공유하던 효과음은 독립 모듈로 보존했다.

## 검증

- 폐기 기능·신규 등록/자동 이어하기·패스 보유 기록·모듈 연결 등 관련 테스트 통과.
- 전체 Node 테스트: **298개 중 295개 통과, 3개 실패**. 남은 실패는 기존 소망이 모델을 삭제 대상으로 보는 검사, Git LFS 포인터 상태의 건물 PNG, `HomeModelScene`을 제공하지 않는 마을 이동 테스트다.
- 브라우저: 마을 진입 확인. DOM에서 타이틀 0개, 개발자 바 0개, 물류 화면 0개 확인.
- **⏳ 제한:** 로컬 3D 모델 일부가 Git LFS 포인터이므로 건물·캐릭터 렌더링 및 실제 접촉 검수 완료로 보지 않는다.
- 기존 등록·프로필 파일 끝의 잘못된 `origin/main` 실행문을 제거해 초기화 차단 오류를 수정했다.
