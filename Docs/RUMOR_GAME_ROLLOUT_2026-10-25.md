# 72개 회사 찌라시 게임 적용

**P1 (Major) · ✅ 완료: 웹·기존 로컬 실행본 리소스에 72개 회사·288개 사건·2,880개 해석 본문 반영 및 자동 검증 / ⏳ 대기: 사용자 최종 플레이 검수.**

## 새 정보의 지급과 해석

[회사별 원고](Rumors/README.md)의 본문을 그대로 런타임으로 변환한다. 회사마다 호재 2개·악재 2개이며 브리즈파워 기존 계약설은 같은 사건으로 한 번만 집계한다. 게임은 `web/js/data/rumors/`의 회사별 모듈을 읽는다. `scratch/build-rumor-runtime.py`로 문서를 다시 변환할 수 있고, 테스트가 모든 단계의 원문 일치를 확인한다.

새 보상 추첨과 잡화점 소식 봉투는 이 288개 사건을 사용한다. 소식 봉투 가격은 1,000잎을 유지한다. 사건 ID와 개별 보유 ID를 분리해 같은 소문을 두 번 받아도 열람·가루·저장이 서로 영향을 주지 않는다. 새 소식 봉투는 종전의 고정 ‘24시간 뒤 +8%’ 보고서를 만들지 않는다.

분석력의 유효 범위와 새 찌라시 해석 상한은 1~10이다. 표시 단계는 분석력과 개별 유지 해석 단계 중 높은 값이다. 별가루는 선택한 한 건 +1·500잎, 달가루는 한 건 10단계·2,000잎이다. 이미 최대인 대상·미열람 대상·잘못된 대상에는 가루를 소비하지 않는다. 가루나 새 봉투 사용으로 분석력 자체를 올리지 않는다.

1~3단계에서 회사명을 미리 노출하지 않고 4단계부터 공개한다. 인벤토리 검색·설명도 현재 표시 내용으로 판단한다. 제목은 원고의 공통 제목을 쓰며 UI에 호재/악재 분류·예상 수익률·매수 정답을 자동 표시하지 않는다. 10단계도 정보의 진위나 주가 수익을 보장하지 않는다.

최초 열람의 기존 50% 매각 가치 감가와 재열람 가치 유지는 유지한다. 기존 희귀도 추첨 비중 50/28/15/6/1 및 가격 500/1,200/2,000/6,000/15,000잎을 유지한다. 새 사건의 희귀도는 문서 순서 기반의 고정 분산 배치이며 진위·수익과 연결하지 않는다. 개별 사건의 희귀도 배치와 경제 균형은 사용자 플레이 검수 대상이다.

## 저장 호환과 적용 경계

기존 25개 사건의 CSV와 구형 JS 원고는 보존한다. 신규 지급 풀에서는 제외하며 이미 저장된 보유 원고는 ID·수량·가격·본문·열람 상태를 덮어쓰지 않는다. 기존 원고는 이전 5단계 자료로 표시하고 기존 가루 상한 5를 유지한다. 이를 단순 배수 환산하거나 가상의 중간 문장으로 10단계처럼 보이게 하지 않는다.

기존 기본 분석력 값도 삭제·배수 환산하지 않는다. 유효 분석력만 1~10으로 제한하고 새 포인트 배분에서 10을 넘기지 않는다. 소망이 캐릭터 레벨 상한 20과 다른 능력의 저장은 유지한다. 과거 저장에 이미 생성된 데모 보고서의 예약 이벤트는 기존 계약대로 유지한다.

분석력 성장의 퀴즈 숙련도·시작 시험·기존 능력 포인트 개편 전체는 별도 설계다. 이번 적용은 현재 성장 경로를 유지하며 해석 범위·새 정보 데이터·가루·표시를 연결한 것이다. 새 288개 사건의 진위 추첨·후속 뉴스·발표일·주가 효과·분석력 퀴즈 보상은 추가하지 않았다. 원고 속 상대 시점은 발행 시점 기준 표현이며 아직 실제 발표 이벤트 예약과 연결하지 않는다.

## 검증

- 관련 자동 테스트 28개 통과: 전 회사 호재/악재 수, 모든 2,880개 원문 일치, 추첨에서 모든 사건 도달, 독립 보유, 가루 소모·상한, 기존 저장 복원, 새 봉투의 주가 이벤트 미생성.
- 전체 테스트 323개 중 320개 통과. `removedCharacterAssets.test.mjs`의 3개 실패는 이번에 수정하지 않은 봉봉 재도입 에셋을 삭제 상태로 기대하는 검사 2개와 Node의 로컬 GLB fetch 제한 1개다. 찌라시 검증 통과와 구분한다.
- 웹과 기존 실행본 리소스 각각 실제 브라우저에서 앱 초기화를 확인하고, 장면 오버레이를 분리한 실제 컴포넌트·게임 CSS로 288개 사건·2,880개 본문과 단계·가루 효과를 검사했다. 두 환경 모두 JavaScript 예외 0건. 화면 검사는 브라우저 컴포넌트 검사이며 전체 플레이 흐름·Electron 직접 실행 검수는 아니다.
- 기존 로컬 실행본 `electron-app/dist/win-unpacked/resources/web/`의 런타임 90개 파일을 동기화하고 SHA-256을 대조했다. 설치 프로그램을 재빌드하지 않았다. 이미 열려 있는 게임은 재실행해야 새 모듈을 읽는다.
