## 플레이 흐름과 문항

**후속 적용:** 문장 추출형 자동 문항을 [72개 회사·288개 사건의 집필 문항 864개](AUTHORED_QUIZ_GAME_ROLLOUT_2026-10-25.md)로 교체했다. 현재 단계 구간별 한 문항을 출제하며 아래 보상·성장·저장 규칙은 유지한다. 자동 문장 추출 설명·검증 건수는 최초 적용 이력이며 후속 문항 적용의 현재 검증 범위는 링크된 기록을 따른다.

새 10단계 찌라시를 열고 **해석 확인하기**를 누르면 같은 창 아래에 1문항·3지선다를 표시한다. 시간제한은 없고 출제 당시 읽은 본문을 다시 펼쳐 볼 수 있다. 나중에 풀거나 창을 닫아도 불이익이 없다. 분석력 단계와 현재 숙련도/다음 승급 요구량을 함께 표시한다.

72개 회사·288개 사건 모두에서 현재 해석 단계의 본문에 근거한 문항을 제공한다. 1~3단계는 비유와 제약, 4~6단계는 사건·조건·현재 상태, 7~10단계는 출처·범위·시점·정보의 한계를 확인한다. 문항은 표시된 문장의 근거를 추출하는 규칙으로 구성하며 별도의 미래 주가나 숨은 진위 메타데이터를 정답으로 쓰지 않는다. 모든 2,880개 단계 변형에 본문으로 뒷받침되는 답이 하나씩 있는지 검증했다. 개별 문항의 난도와 재미에 대한 사용자 검수는 별도다.

오답이면 감점 없이 본문의 근거와 해설을 안내하며 같은 문제에 재도전할 수 있다. 재도전 정답도 **분석력 숙련도 +1**이다. 첫 정답 후 해당 화면의 선택 버튼은 잠가 연속 제출을 막고, 다시 열면 복습할 수 있다. 승급하면 재열람 감가를 추가로 발생시키지 않고 본문 해석 단계도 갱신한다.

## 사건별 한 번 지급과 저장

지급 이력은 아이템 보유 ID가 아닌 원고의 **`rumorId`**로 저장한다. 같은 사건의 다른 사본·선물·재구매·가루 사용·해석 단계 상승·재접속으로 추가 지급하지 않는다. 같은 회사의 다른 호재/악재 사건은 각각 지급한다. Lv.10에서는 보상 없이 복습하고 초과 숙련도나 대체 재화를 만들지 않는다.

게임 저장의 `items.analysisGrowth`에 `version`, 영구 `level`, 승급 진행 `proficiency`, 사건별 `awarded`, 출제 기록 `quizzes`를 보관한다. 정답 이력과 성장량은 같은 상태에 함께 갱신해 기존 로컬 게임 저장에 한 번에 기록한다. 오답·정답 제출과 문제 열기는 기존 게임 저장 콜백으로 연결했다. 저장 공간을 사용할 수 없을 때는 기존 게임의 세션 전용 저장 경고를 따른다.

미완료 문제의 표시 단계가 같으면 오답 시도 후에도 같은 문제를 복원한다. 단계가 달라진 상태에서 다시 문제를 열면 현재 본문으로 다시 출제하며 지급 이력은 유지한다. 예전 문제 키로 제출하면 거절한다. 출제 후 같은 화면을 풀고 있는 동안은 그때의 본문을 근거로 해설하며, 승급 후에도 ‘출제할 때 읽은 본문’을 따로 확인할 수 있다.

## 성장 수치와 기존 이용자

| 승급 목표 | 단계마다 필요한 추가 정답 |
|---|---:|
| Lv.2~3 | 6 |
| Lv.4~6 | 10 |
| Lv.7~9 | 16 |
| Lv.10 | 20 |

Lv.1 출발의 누적 승급 지점은 **6·12·22·32·42·58·74·90·110개**다. 출발 Lv.2는 104개, Lv.3은 98개 정답이 필요하다. 캐릭터 레벨 EXP와 분석력 숙련도는 별도로 유지한다. 임시 분석력 아이템 효과나 가루를 사용해도 영구 단계와 숙련도를 바로 올리지 않는다.

기존 저장은 영구 기본 분석력 값을 1~10으로 제한해 출발 단계로 삼고, 숙련도 0·보상 이력 없음으로 한 번 초기화한다. 기존 기본 능력치 값·해독 횟수·사용/미사용 포인트·원고·수량·가격·열람 기록은 삭제하거나 배수 환산하지 않는다. 기존 25종 원고는 읽기를 유지하며 새 퀴즈 보상을 자동으로 붙이지 않는다. 이미 읽은 새 288종 원고는 퀴즈를 풀 수 있지만 과거 열람만으로 숙련도를 지급하지 않는다.

분석력은 더 이상 캐릭터 레벨업 포인트나 구형 보고서 해독 횟수로 직접 성장하지 않는다. 분석력 포인트 선택은 비활성화하고 퀴즈 성장 안내를 표시한다. 분석력 이외의 능력·공통 규칙 개편은 공유 엔진의 별도 작업을 유지하며, 이 기록은 그 개편 전체를 이번 퀴즈 작업의 성과로 포함하지 않는다. 과거 능력치와 포인트의 보존은 현행 엔진의 이관 규칙을 따른다. 신규 계좌 신청의 시작 분석력 시험 UI 전체는 별도 구현이며, 이번 적용이 해당 절차까지 완성했다는 뜻은 아니다.
