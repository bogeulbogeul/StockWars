# 소망이 기준 마을 오브젝트 크기 — 2026-10-21

**P1 (Major) · ✅ 기준·게임 크기 적용·웹/로컬 실행본 검증 / ⏳ 사용자 최종 시각·착석/승하차 검수.**

소망이의 기존 `SOMANGI_HEIGHT = 100`과 모션별 원본 단위는 유지한다. `web/js/data/townObjectScale.js`에서 소망이 키 대비 크기를 한곳에서 관리한다. GLB 원본을 재변형하지 않고 마을과 도착 연출에서 동일한 배율을 사용한다.

| 항목 | 소망이 기준 | 적용 |
| --- | --- | --- |
| 건물 문 높이 | 1.25배 | 건물별 채택 GLB의 문 실측으로 전체 균등 배율 조정 |
| 버스 문 높이 | 1.4배 | 기존 약 0.66배에서 확대, 바퀴 회전 거리에도 새 배율 적용 |
| 정류장 내부 여유 높이 | 1.4배 | 쉼터 전체 배율 조정 |
| 벤치 좌판 | 0.32배 | 일반 벤치 통일, 쉼터 내장 벤치만 별도 수직 조정 |
| 꽃 | 약 0.18배 | 꽃무리별 기존 크기 변주 유지 |
| 일반 나무 | 2.7배 | 정원 나무 통일, 경계 나무 크기 변주 유지 |
| 포포리 | 6.5배 | 일반 나무와 위계 구분 |
| 주민 게시판 | 1.5배 | 읽을 수 있는 높이로 확대 |

건물 배치 좌표·회전·ID는 유지한다. 집의 비대칭 문 오프셋은 배율에 맞게 함께 바꾼다. 모델을 따라 자동 계산되는 접지·건물 충돌은 새 크기를 사용한다. 실내 방·가구·캐릭터 모션·저장·경제 데이터는 이번 마을 크기 조정 대상이 아니다. 버스는 여전히 도착 연출에서만 사용하고 상시 배치하지 않는다.

`scratch/check-town-scale.cjs`에서 전체 로딩·정의 폭 일치·건물 문 높이·쉼터 좌판·버스 문·건물 입구 접근을 검사하고, 소망이를 나란히 놓은 `output/town-somangi-scale-v1/comparison.png`와 `verification.json`을 생성한다. `scratch/check-bus-arrival.cjs`로 오른쪽→왼쪽 이동·바퀴 회전·정차·모바일·종료 후 실제 마을 보존을 확인한다. 로컬 실행본 리소스를 동기화하며 설치 프로그램은 재빌드하지 않는다.
