# StockWars GDD: MOD_GDD_11. 스마트폰 메일 시스템 (Mail System)

**버전:** v1.0.0 (초안 구축)  
**핵심 컨셉:** 코지(Cozy) 스마트폰 앱을 통한 비동기적 정보 및 재화 수령 시스템  

---

## 1. 시스템 개요 (System Overview)
유저는 게임 내 스마트폰 UI의 **'Mail' 앱**을 통해 시스템 알림, 친구의 선물, 시장의 주요 소식을 확인하고 수령할 수 있습니다. 이는 유저가 오프라인일 때 발생한 사건들을 피드백하는 핵심 창구로 기능합니다.

---

## 2. 메일 데이터 구조 (Mail Data Structure)

| 필드명 | 타입 | 설명 |
| :--- | :--- | :--- |
| **MailID** | string | 각 우편의 고유 식별자 (GUID) |
| **Type** | Enum | System, Social, Market, Event, **Shadow** |
| **Sender** | string | 발신자명 (NPC 이름 혹은 친구 유저네임) |
| **Title** | string | 우편함 리스트에 노출될 제목 |
| **Content** | string | 메일 상세 본문 (Rich Text 지원) |
| **Reward** | Item/Gold | 수령 가능한 아이템 혹은 재화 데이터 |
| **ExpiryDate** | DateTime | 만료 시점 (TTL: 기본 7일, **Shadow는 1일**) |
| **IsRead** | bool | 읽음 여부 상태 체크 |

---

## 3. 카테고리별 세부 내용

### 3.1. 시스템 메일 (System)
- **발신자**: Node Finance, 안나(Anna), 시스템 관리자
- **내용**: 
    - 주간 이자 정산 요약 리포트.
    - 자산 압류(Seizure) 전 최종 경고 알림.
    - 튜토리얼 완료 보상 및 이벤트 상금.
- **담보물 매각 임박 긴급 알림 [v3.10.0]**:
    - **트리거**: 담보 대출 상환 기한 만료 **12시간 전** 및 **1시간 전** 자동 발송.
    - **발신자**: `전당포 바터(Barter)`
    - **제목**: `[긴급] 맡기신 물건의 소유권이 이전될 예정입니다.`
    - **내용**: 기한 내 미상환 시 즉시 몰수 및 재판매가 진행됨을 경고하여 유저의 긴급 상환 유도.

### 3.2. 소셜 메일 (Social)
- **발신자**: 친구 목록 내 유저명
- **내용**:
    - 친구가 보낸 **스테미너(Energy) 선물**.
    - 친구가 공유한 **찌라시 복사본** (클릭 시 인벤토리로 이동).

### 3.3. 시장 메일 (Market)
- **발신자**: Cipher Securities, 시장 분석국
- **내용**:
    - **신규 상장(IPO)** 예고 및 개시 알림.
    - 보유 종목의 **상장 폐지(Delisting)** 및 정리 매매 개시 통보.

### 3.4. 기관 금융 긴급 알림 (Institutional Alerts) [v3.5.0]
- **마진콜(Margin Call) 경고**: 
    - **트리거**: 공매도 유지 증거금이 **90%** 임계값 도달 시.
    - **내용**: "[긴급] 마진콜 발생 위험. 증거금이 부족합니다. 즉시 담보 보충이 필요합니다."
- **적색 수배(Red Notice) 통보**: 
    - **트리거**: 횡령 확정 시 즉시 발송.
    - **내용**: "[통보] 계좌가 동결되었습니다. 횡령 혐의로 적색 수배가 발동되었습니다."

### 3.5. 쉐도우 메일 (Shadow - Secret) [NEW]
쉐도우는 일반적인 루트로 접하기 힘든 **'검은 정보'**를 메일을 통해 은밀하게 제안합니다.

- **발신자**: `쉐도우(Shadow)` 또는 `익명의 발신자(Unknown)`
- **내용**: 
    - **내부자 찌라시**: 특정 종목의 급등/급락이 확정된 고급 정보 (해독 불필요).
    - **비밀 거래 제안**: 암시장에서만 구할 수 있는 Legendary 의상/가구 판매 링크.
    - **특수 미션**: 시장 교란(특정 종목 집중 매수 등)을 조건으로 한 거액의 보상 제안.
- **특수 시스템 (휘발성/보안)**:
    - **만료 시간**: 발송 후 **24시간** 내에 읽지 않으면 자동으로 파기됩니다.
    - **자동 삭제 (Self-Destruct)**: 메일 확인 후 메일 앱을 종료하거나 메인 화면으로 나가면 해당 메일은 즉시 삭제되어 증거를 남기지 않습니다.
- **비주얼 연출 (Visual Concept)**: 
    - **프로필 아이콘**: 얼굴의 상당 부분이 그림자나 후드에 가려져 신비감을 주지만, 살짝 드러나는 날카로운 콧날과 수려한 턱선 실루엣을 통해 **압도적인 미남(Handsome)**의 인상을 전달.
    - **폰트 및 색상**: 보라색 또는 다크 그레이 톤의 전용 테마를 사용하여 일반 메일과 시각적으로 즉시 분리.

## 4. UI/UX 연출 가이드

### 4.1. 스마트폰 앱 인터페이스
- **아이콘**: 픽셀 아트로 그려진 빈티지한 봉투 모양 아이콘.
- **배지 (Badge)**: 읽지 않은 메일이 있을 경우 스마트폰 홈 화면 앱 아이콘 우측 상단에 빨간색 pips 노출.
- **알림 사운드**: 드로이드 풍의 낮은 톤 비프음 (코지(Cozy) 감성).

### 4.2. 주요 기능 인터페이스
- **일괄 수령 (Collect All)**: 하단에 고정된 버튼으로 모든 [Social] 선물을 한 번에 수령 및 삭제.
- **삭제 (Delete)**: 클릭한 메일 우측 상단의 'X' 버튼으로 개별 삭제. 읽은 메일은 자동으로 투명도가 낮아집니다.

---

## 5. 기술적 고려 사항
- **Asynchronous Data**: 유저가 오프라인일 때 서버(혹은 백엔드 로직)에서 생성된 메일 정보를 로그인 시점에 데이터 동기화.
- **TTL (Time To Live)**: `ExpiryDate`가 경과한 데이터는 DB 및 클라이언트 리스트에서 즉시 소멸 처리하여 데이터 무결성 유지.
