# 버스 도착 연출 — 2026-10-21

**P1 (Major) · ✅ 최신 모델·오프닝 후 도착 연출·웹/로컬 실행본 반영·브라우저 검증 / ⏳ 사용자 최종 시각 검수.**

사용자 요청으로 버스는 마을 상시 오브젝트로 설치하지 않고 오프닝 이후의 별도 도착 연출에서만 표시한다. 크레파스 오프닝이 끝나거나 오프닝을 건너뛰면 버스 도착 연출로 연결하고, 도착 연출 종료 또는 건너뛰기 후 기존 게임 시작 흐름을 실행한다. 기존 마을 배치·노선 데이터는 변경하지 않는다.

- 채택 제작본: `output/popori-bus-v24/Popori-bus-animated.glb`.
- 게임 리소스: `web/assets/cinematics/bus/Popori-bus-animated.glb`.
- 진입: `web/js/app/TitleScreen.js` → `arrival/BusArrival.js`.
- 도착 연출: `arrival/BusArrivalView.js`와 `ArrivalVillage.js`. 실행 중인 실제 마을 장면을 재사용하며, 마을 건물·포포리·정류장·도로·하늘과 기존 배치를 그대로 보여준다. 별도의 평면 도로·빈 배경은 제거했다. 독립 검수에서는 동일한 현행 마을 정의와 조경 렌더러로 로드한다. 전경 카메라로 마을과 도로 위 버스를 함께 보여주며, 버스만 연출 종료 시 제거한다. 마을 모델·재질은 해제하지 않는다.
- `ArrivalForest.js`는 도착 전경의 외곽 나무 뒤·좌우 빈 평야를 기존 일반 나무 메시의 인스턴스로 가린다. 마을 안 잔디·남쪽 도로는 보존하며, 연출 종료 시 배경 숲도 제거한다. 상시 마을 배치·이동 경계는 변경하지 않는다.
- 버스는 반드시 화면 오른쪽에서 왼쪽으로 전진한다. 차체를 -X 방향으로 돌리고 +X에서 진입한다. 5초간 감속 이동하고 2.5초간 도착을 표시한 뒤 게임으로 전환한다. 이동 거리와 바퀴 원본 반지름 0.39에 현재 `TOWN_BUS_MODEL_SCALE`을 곱한 반지름, `Wheel_Roll` 클립 길이를 연결해 바퀴를 회전하며 정차하면 회전도 멈춘다. 소망이 기준 크기는 [마을 오브젝트 크기](TOWN_OBJECT_SCALE.md)를 따른다.
- 모션 감소 설정에서는 정차 상태만 2초간 표시한다. 로딩 실패·15초 초과 시 게임 진입을 계속한다. 종료·건너뛰기 시 렌더 루프·리사이즈 감시·GPU 리소스를 해제한다.
- 문 개방·소망이 하차·버스 상시 운행·운임 기능은 이번 적용 범위에 포함하지 않는다.

`scratch/check-bus-arrival.cjs`로 타이틀 → 오프닝 → 도착 → 시작 콜백, 이동/바퀴 회전, 정차 후 회전 정지, 모바일·모션 감소·즉시 건너뛰기와 종료 정리를 확인한다. 로컬 실행본 `electron-app/dist/win-unpacked/resources/web/`도 같은 파일로 동기화한다. 설치 프로그램은 재빌드하지 않는다.
