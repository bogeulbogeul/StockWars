## 레벨에 따른 소망 성장 외형 — 2026-10-18 후속 채택

소망이는 레벨에 따라 머리 위 외형이 아래 5단계로 성장한다. 몸·얼굴의 기본 디자인은 유지하고 머리 위 소망의 성장으로 진행을 표현한다. 아래 몸체 장식 미정·추가하지 않음 설명보다 이번 사용자 결정을 우선한다. 자유 외형 선택이나 스킨 판매가 아닌 레벨 연동 성장 표현이다.

| 레벨 | 머리 위 외형 | 의미 |
| :--- | :--- | :--- |
| Lv.1~2 | 장식 없는 둥근 머리 | 아직 자기 소망을 모르는 소망이 |
| Lv.3~6 | 짧은 줄기 끝에 작은 잎 하나 | 처음 움튼 소망 |
| Lv.7~11 | 잎 두 장이 펼쳐진 새싹 | 마을에 뿌리내리는 중 |
| Lv.12~19 | 두 잎 가운데 작은 꽃봉오리 | 자기 소망을 키워가는 중 |
| Lv.20 | 작은 꽃 한 송이 개화 | 충분히 성장한 소망이 |

외형 전환은 Lv.3·7·12·20 도달 시 발생하며 같은 구간에서는 유지한다. 레벨 기준은 [유저 성장](CORE_GDD_03_PlayerGrowth.md)을 따른다. 꽃의 색·종류, 줄기·잎·꽃 크기, 정확한 부착점·흔들림, 전환 연출은 후속 시각 설계 대상이다. 능력치 보너스나 경험치 요구량 변경을 이번 외형 결정에 추가하지 않는다.

제작 시 몸체·기본 본·생활 모션은 공통으로 유지하고 머리 본을 따라가는 단계별 장식으로 구성하는 방안을 우선 검토한다. 실제 분리 구조·장식 본 필요 여부는 모델 검수 후 정한다. 작은 게임 화면의 단계 구분, 방향별 가림, 머리 회전·앉기에서의 접촉을 검수한다. 새 비율의 [3방향 시안](../output/spirit-proportion-views-v2/front.png)은 제작 시안이며 이번 성장 단계의 완성 에셋이나 최종 모델로 간주하지 않는다.

**✅ 완료: 5단계·레벨 구간·의미 기획 반영 / ⏳ 대기: 성장별 시안·모델·전환 구현·저장 연동·게임 검수.** 기존 GLB·리그·게임 파일은 자동 변경하지 않는다.
