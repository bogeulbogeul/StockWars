## 적용과 보존 범위

사건 ID는 런타임 원고 식별자로 사용하며 개별 보유 ID와 분리한다. 제목은 회사·방향을 미리 밝히지 않고, 낮은 단계에도 사업 기회나 위험의 제약을 남긴다. 후속 뉴스·퀴즈·수급과 사건 결과는 사건 연동 설계에서 정한다.

[기존 게임 CSV](../Data/Rumors.csv)의 25개 사건·5단계 본문과 구형 보유 기록은 보존한다. 신규 지급은 회사별 288종·10단계 런타임을 사용하며 구형 원고를 합산하지 않는다. [예전 루머 보관 자료](../Archive/Rumors_2026-10-25/README.md)를 현행 제작 원고로 복원하지 않는다.
