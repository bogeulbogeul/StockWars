    - **Tier 2**: "정부 빅데이터 사업, 데이터 스파크가 독점 계약할 것 같아. 상장 후에 주가 제대로 점프할 기회야."
    - **Tier 3**: "내일 오전 9시, 국가 데이터 통합 플랫폼 단독 수주 공시 예정. 데이터 스파크 상한가 랠리 시작됩니다."
- **[악재] 개인정보 유출로 인한 징벌적 과징금**
    - **Tier 1**: "야, 거기 보안 뚫렸대. 우리 정보 다 털려서 난리 났다는데? 당분간 조심해."
    - **Tier 2**: "데이터 스파크 보안 서버가 해킹당했어. 수천억 대 과징금 두들겨 맞으면 회사 존속이 위험하다더라."
    - **Tier 3**: "개인정보 유출 및 서비스 중단 공시 예정. 경영진 책임론 대두되며 주가 하한가 직행합니다."

    - **Tier 3**: "글로벌 빅테크 G사와 Core-X 엔진 라이선스 계약 체결 공시 임박. AI 코어는 이제 독보적인 대장주야."
