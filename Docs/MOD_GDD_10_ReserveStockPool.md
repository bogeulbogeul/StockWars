# MOD_GDD_10 예비 종목과 IPO 확장 검토

> 개정: 2026-10-16. 현재 자동 IPO·상장폐지 대체 풀은 미구현이다. 이전 12종/24종 혼용·중복 상장 기사·깨진 문장은 폐기하고 현행 후보표에서 제외했다.

## 현재 실행 데이터

일반 시장은 [stocksData.js](../web/js/data/stocksData.js)의 72종, 온라인 대결은 [arena-stocks.json](../Server/presence/arena-stocks.json)의 72종을 사용한다. 대결이 예비 풀에서 12종을 무작위로 뽑는 것은 현재 동작이 아니다.

## 후보 원고와 채택 조건

[IPO 찌라시 인덱스](MOD_GDD_19_0_IPORumorIndex.md)의 8개 섹터 원고는 제작 소재다. 에어 택시/스타 택시, 에이아이 인슈어런트/세이프 트러스트, 드론 딜리버리/퀵 딜리버리, 마인드 셋/젠 진 등 이전 자료의 이름을 같은 회사로 자동 병합하지 않는다. 고유 StockId·표시명·업종·현재 상장 여부와 기업 뉴스 원고를 대조한 뒤 실제 후보를 확정한다. 현재 CSV 보상에 이름만으로 추가하지 않는다.

상장가 산식·상장 24시간 변동성 1.2~1.5배·12시간 전 공지·상장폐지 후 자동 편입은 재검토 대상이다. 확정되지 않은 후보 수·초기가·발행량·배당을 현행 경제에 적용하지 않는다. 기존 찌라시·보유 주식·주문·저장 ID를 삭제하거나 재사용하는 정책은 별도 설계한다.
