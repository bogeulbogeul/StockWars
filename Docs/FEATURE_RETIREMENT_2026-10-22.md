# 기존 서브 퀘스트·칭호 기획 폐기 — 2026-10-22

**P1 (Major) · ✅ 완료: 기획 폐기·게임 코드/UI/대사 제거·자동 검증 / ⏳ 대기: 배포판 사용자 플레이 검수.**

사용자 요청으로 기존에 기획한 서브 퀘스트와 칭호를 폐기한다. 이전 문서의 도입·확장·재설계 예정 문구보다 이 결정을 우선한다. 새 서브 퀘스트나 대체 보상 시스템은 이번에 채택하지 않는다.

## 폐기 범위

- NPC 수락형 서브 퀘스트의 조건·진행·수령·보상 기획: 실현 수익, 매도 연승, 물류 점수·무파손, 토리 대결 승리 과제 등.
- 게시판의 선택 의뢰·주민 부탁을 퀘스트로 제공하는 기존 기획. 시설 소개·구인 안내 등 일반 안내문은 유지한다.
- 시작 성향·의뢰·공개/히든 업적·친구 관계·축제에서 획득하는 모든 기존 칭호와 칭호 도감·수집률·장착·프로필/랭킹 표시 기획.
- 튜토리얼의 서브 퀘스트·칭호 소개 및 이를 전제로 한 진행 조건.

## 유지 및 기록 보존

**같은 날 성장 개편 후속:** 아래 시작 성향 능력 유지 문구는 의뢰·칭호 제거 당시의 구현 범위 기록이다. 이후 사용자는 분석력 단일화·시작 분석력 테스트·캐릭터 레벨과 별도 성장을 채택했다. 신규 기획은 [성장 명세](CORE_GDD_03_PlayerGrowth.md)의 최신 개편을 우선한다. 이번 문서 갱신으로 기존 성향 효과의 게임 제거·저장 이관이 완료된 것은 아니며, 의뢰·칭호 폐기와 과거 기록 보존은 유지한다.

필수 튜토리얼, 첫 투자, 잡화점 포장 알바와 보수, 생활비 안내, 정착 지원금·일기장, 7일 차 월세 목표는 유지한다. 시작 성향의 기본 스탯 효과는 칭호와 분리하여 유지한다. 일반 주민 대화·관계·우편 교류와 칭호 외 독립 업적/엠블럼 전체의 폐기를 이번 결정으로 확대하지 않는다. 다만 폐기된 서브 퀘스트·칭호를 자동 복원하는 근거로 사용하지 않는다.

과거 기획 원고·제작 에셋·내부 ID·저장 내 의뢰 진행/수령·보유 칭호 기록은 이 작업에서 삭제하거나 이관하지 않는다. 과거 명칭과 수치는 이력이며 현행 제작 입력이 아니다.

## 구현 상태

후속 사용자 요청으로 게임 내 기능도 제거했다. ItemGameplay의 의뢰 생성·이벤트 기록·보상 지급·칭호 장착 연결을 제거하고, 모아·토리 의뢰 선택지와 수령 대사, 서브 퀘스트 탭, 휴대폰 칭호 도감, 프로필·친구·랭킹 칭호 표시, 튜토리얼 소개를 제거했다. 월세 목표·접기와 토리의 연습 대결은 유지한다. 시작 성향 능력은 유지하되 시작 칭호를 새로 저장하지 않는다.

`SideQuestEngine.js`는 이전 호출에도 수락·진행·보상·장착을 거부하는 비활성 호환 경계로 남긴다. 기존 저장의 의뢰/칭호 필드는 읽어서 보상으로 복원하거나 삭제·초기화하지 않는다. 기존 데이터·비사용 UI 모듈·제작 에셋은 이력 보존용이며 게임 진입점의 의존성에서 제외했다.

검증: 관련 Node 테스트 **56개 통과**. 기존 저장 재로드 후 완료/미수령/수령 의뢰의 추가 진행·골드/EXP 지급 차단, 칭호 보유/장착 비활성화·저장 보존, 성향별 스탯 중복 방지, 튜토리얼·친구·랭킹·토리 안내 회귀와 런타임 의존성 제외를 확인했다. Headless Edge 브라우저에서 휴대폰의 남은 앱과 화면 이동, 월세 진행률·접기, NPC의 구 의뢰 콜백 미호출, 프로필 칭호 제거를 검증했다. 설치형 배포 빌드와 사용자 직접 플레이 검수는 이번에 수행하지 않았다.
