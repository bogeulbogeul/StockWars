# 능력치 개편 게임 적용

사용자 후속 요청으로 레벨업 시 선택 창 없이 2.5초 알림을 표시한다. 실제 화면 검토 후 기존 네온 알림을 폐기하고 아이보리 바탕·새싹 표시와 `레벨 3이 되었어요` 문구로 교체했다. 여러 레벨을 한 번에 올리면 최종 레벨을 한 번만 알리고, 동일 레벨의 반복 갱신이나 저장 재접속 시에는 다시 알리지 않는다. 게임 초기화 때 알림 기준도 초기화한다. 웹·기존 실행본 리소스에 반영했다. 구형 화면의 후속 폐기 범위는 [네온 UI 화면 제거](NEON_UI_RETIREMENT_2026-10-25.md)를 따른다.

**P1 (Major) · ✅ 완료: 웹·기존 로컬 실행본 리소스 적용 및 자동 검증 / ⏳ 대기: 사용자 최종 플레이 검수.**

사용자 요청으로 레벨업 능력치 포인트 선택 창·지급·배분을 종료했다. 분석력은 기존 해석 확인 퀴즈로만 영구 성장한다. 능력치 개편부터 적용한다는 후속 선택에 따라 머리 위 잎·꽃과 화분 외형의 제작/성장 연결은 이번 작업에 포함하지 않았다. 캐릭터 레벨 상한 20과 150 기반 경험치 곡선은 유지한다. Lv.10 금융 기능 자동 해금은 이번 작업에서 추가하지 않았다.

## 공통 규칙

- 기존 기본값인 종목 슬롯 5칸·하트 3개·회복 1칸·노동 체력 1칸·주문 100주를 공통으로 적용한다. 장기 경제 수치 확정과 구분한다.
- 장소별 기본 수수료와 알바 원래 보수는 유지하고 옛 협상력 할인/보수 가산·운용력/성향 슬롯 가산·회복력 하트 가산/체력 소모 면제를 중단했다.
- 기존 초과 보유 주식은 청산하거나 삭제하지 않는다. 기존 종목 거래는 유지하며 빈 슬롯 없는 신규 종목 매수만 제한한다.
- 프로필·트레이더 자격증·튜토리얼의 옛 능력/성향 보너스 안내를 제거했다. 성향 기록 자체는 보존한다.

## 저장 호환

기존 `baseStats`, `spentLevelPoints`, `appliedTrait`, 성향 프로필, 보유 아이템은 유지한다. 최초 로드 때 `legacyAbilities`에 원래 능력치·배분 포인트·미사용 포인트·체력·강화 이력을 보관하고 `abilityRetirementVersion: 1`로 중복 이관을 막는다. 활동 중 체력은 공통 상한 3개를 적용하므로 옛 추가 하트 원값은 이 보관 기록에서 확인한다. 포인트는 새 능력이나 숙련도로 자동 환산하지 않는다. 분석력의 기존 퀴즈 이관/지급 이력은 유지한다.

옛 안정제·비타민은 사용 요청을 거부하며 수량을 소비하지 않는다. 이미 저장된 운용/회복 강화 만료 시각도 삭제하지 않지만 현행 능력에 적용하지 않는다. 옛 분석력 강화 상품의 120분 임시 효과와 별가루·달가루의 한 건 해석 효과는 유지한다.

포인트 API는 과거 호출 호환을 위해 0점/실패를 반환하며 `PlayerTrait` 호환 함수도 상태를 변경하지 않는다.

사용자 후속 요청으로 연결만 해제해 두었던 능력 선택 UI 자체도 삭제했다. 웹과 기존 실행본 리소스에서 `LevelUpNotice.js`, 전용 효과음 `LevelUpAudio.js`, `level-up.css`를 제거하고 이 UI를 직접 불러오던 과거 테스트도 정리했다. 기존 레벨·경험치·보관된 포인트 기록은 유지한다. 삭제 후 관련 검사 9개와 두 리소스의 실제 브라우저 초기화·레벨업·저장 복원을 재검증했다.

## 검증

- 관련 자동 검사 39개 통과: 레벨업·재접속 무포인트, 옛 능력치/포인트 이력 보존, 분석력 퀴즈의 독립 성장, 공통 수수료·슬롯·하트·노동 규칙, 아이템 보존, 프로필 표시, 옛 초과 슬롯 보유 주식 유지·추가 매수/매도.
- 전체 자동 검사 335개 중 332개 통과. 나머지 3건은 기존 `removedCharacterAssets.test.mjs`의 봉봉 삭제 기대 검사 2개와 Node의 로컬 GLB fetch 제한이다. 이 작업에서 캐릭터 에셋은 변경하지 않았다.
- 실제 앱 초기화 후 프로필 표시, 레벨업 뒤 포인트 창 미생성, 저장/새로고침 복원, 데스크톱/390px 화면과 JavaScript 예외 없음을 웹·기존 실행본 리소스에서 확인했다.
- 기존 실행본은 `electron-app/dist/win-unpacked/resources/web/`의 변경 리소스만 동기화했다. 설치 프로그램 재빌드·Electron 직접 플레이 검수는 별도다. 실행 중인 게임은 재시작해야 적용된다.
