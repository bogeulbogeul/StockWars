## 대본과 체험 범위

단일 기준 원고는 2026-10-22 커밋 `dbfe8ce5`의 [초반 대사집 Word](../output/opening-dialogue-v1/포포리_마을_초반_대사집_v1.docx), [도착~첫 활동 선택](../output/opening-dialogue-v1/opening.txt), [첫 활동~첫날 취침](../output/opening-dialogue-v1/activities-and-ending.txt)이다. 웹의 `assets/exhibition/`에 원문을 보관하고 장별 대사를 읽어 사용한다. 단순히 기존 GDD의 대표 대사만 이어붙인 버전이 아니다.

타이틀 → 버스 도착 → 정류장의 모아 → 마을 구경 → 입주 신청·이름 서명 → 휴대폰 수령 → 은행 생활 계좌·정착 대출 → 집 내부·활동 순서 선택 → **포장 알바와 투자 체험 모두 완료** → 찌라시 설명 → 노을·꿀 쿠키 → 안내소 지원금·다이어리 → 봉봉에게 화분 구매 → 귀가·씨앗 심기 → 첫 기록 → 바닥에서 휴식·암전 → 체험 종료.

포장 선행이면 알바·봉투·찌라시 설명 뒤 투자로, 투자 선행이면 첫 매수·벤치 안내 뒤 알바·찌라시 설명으로 연결한다. 두 활동 사이에 숙박·쿠키·노을을 넣지 않는다. 7일 데모는 별도 기존 모드로 보존하며 이 전시 모드에서는 Day 2~7이나 월세 정산으로 넘어가지 않는다.

## 현재 조작과 장면

**2026-10-24 정류장 첫 상호작용 후속:** 도착 직후 이동 안내문을 표시하고 WASD·방향키 또는 화면 방향 버튼으로 모아 근처에 다가간다. 가까이에서 F 또는 ‘모아에게 말 걸기’를 **세 번 각각 입력**하면 깨어난다. 첫 번째는 “으음…… 구름이…… 폭신해…….”, 두 번째는 “그 베개는…… 내 건데…….”라는 잠꼬대를 하고 세 번째에 기존 “……음?” 첫 만남 원고로 연결한다. 단순 접근·멀리서 입력·키 길게 누르기는 대화 횟수를 올리지 않는다. 대화 횟수·접근 위치를 전시 저장에 보관하고 재접속·일시 중단 시 복원한다. 이전 진행 저장은 도입을 되돌리지 않는다. 삭제한 모아/소망이 모델 대신 기존 카메라 기준점과 모아 위치 안내 표식을 사용한다. **P0 (Core) · ✅ 이동·세 번 상호작용·저장 연결 / ⏳ 사용자 최종 체험.**

- 기본 `index.html`은 첫날 전시 모드로 시작한다. `?demo=standard`는 기존 일반 모드, 기존 `?scene=...`는 아트 검토 경로를 유지한다. `?demo=first-day&skipOpening=1`은 도착 연출을 생략하는 검수 경로다.
- 전시 모드는 **안내형 장면 전환과 대화·선택**으로 이동한다. 각 장소의 기존 3D 배경을 재사용하고 다음 버튼/Enter로 대사를 진행한다. 자유 보행·NPC 추적·접촉 연출이 완료된 버전은 아니다.
- 휴대폰은 수령 후, 보유 잎은 은행 계좌 개설 후, 자산·주식앱은 투자 자격증 발급 후 공개한다. 잠긴 금융 항목을 자리표시자로 노출하지 않는다.
- 기존 포장 퍼즐의 5개 상자를 실제로 채워야 알바가 완료된다. 닫으면 이어서 진행하고 완료 후 보수와 봉투를 별도로 받는다.
- 투자에서는 최신 채택한 정보 읽기 3문항을 사용한다. 오답도 자격증 발급을 막지 않고 정답 수에 따라 시작 분석력 Lv.1~3을 기록한다. 원고의 이전 성향 질문 설명은 이 최신 결정에 맞춰 조정했다.
- 기존 종목 데이터에서 감당할 수 있는 회사 6곳의 소개·가격을 읽고 현물 1주를 확인 매수한 다음 거래 내역을 확인한다. 전시 계좌의 표시 가격은 고정하며 실제 시장·온라인 계좌에 영향을 주지 않는다.
- 씨앗 심기는 CSS 화분/씨앗 연출, 취침은 서술·휴식 대기 후 암전으로 연결한다. 소망이의 실제 3D 심기·눕기 모션을 구현했다고 간주하지 않는다.
- 2026-10-23 삭제한 소망·모아·봉봉·토리의 모델·모션과 대체 캐릭터 형상은 복원하지 않는다. 현행 빈 카메라 기준점·건물/룸 배경·화자 이름으로 체험한다. 우체국 소개는 대본에 포함하되 우체국 건물 배치를 새로 확정하지 않는다.

## 전시 전용 경제와 미정 항목

정착 대출 원금 5,000잎·정착 지원금 2,000잎은 기존 기획을 따른다. 대출은 별도 원금으로 표시한다. 미정인 이자·상환 일정은 체험에서 청구하지 않으며 확인 화면에서 이를 안내한다.

원고의 미정 연결을 위한 **전시용 임시 설정**은 알바 보수 500잎·화분 100잎·첫 매수 수수료 0잎이다. `State.js`와 첫 매수 확인 화면에서 관리하며 장기 경제 명세의 확정값으로 승계하지 않는다. 전시에서는 다른 소비·반복 매수 없이 진행해 필수 화분 구매에 필요한 잔액을 보장한다. 자산은 전시 현금+보유 주식 표시 가격 합계이며 순자산/부채 산식 개편을 의미하지 않는다.

첫 찌라시의 미작성 본문은 코지페이의 ‘다음 달 새 결제 서비스 소문·공식 발표 미확인’이라는 체험용 원고로 연결했다. 실제 뉴스·시장 가격 이벤트·수익 보장에 사용하지 않는다. 다이어리는 원고의 첫 기록을 확인하는 연출이며 자유 글쓰기 기능을 추가하지 않는다.

## 저장과 다음 방문자

`stockwars.exhibition.first-day.v1`에만 이름·진행 위치·활동 순서·계좌/휴대폰/자격증·포장 상태·대출·주식·획득/구매/심기/기록 완료를 저장한다. 재접속은 이어서 하기/새로 시작하기를 제공한다. 금액 변경과 단계 진행을 함께 저장하고 재지급을 방지한다. 일반 게임 저장·온라인 가입/닉네임·기록 삭제 API를 사용하지 않는다.

취침 뒤 **다음 방문자 · 처음부터**로 전시 회차만 초기화한다. 진행 중에는 ‘처음부터’ 확인 화면을 제공한다. 기존 7일 완주의 전체 기록 삭제·일기장 종료 API와 분리한다.
