# StockWars 그래픽·시점 전환 계획

**결정일:** 2026-09-28  
**상태:** 시점 및 코지 SD 픽셀 화풍 확정 / 프로토타입 및 에셋 교체 미착수

## 1. 결정과 이유

홈 오피스의 아이소메트릭, 마을의 횡스크롤, 건물 내부의 탑다운이 섞이면서 장소 이동 시 공간을 읽는 방식이 달라지는 문제가 있었다. 에셋이 많이 쌓이지 않았고 앞으로 개발할 공간이 더 많다는 점을 고려해, 원래 원했던 픽셀아트와 비스듬한 탑다운으로 통일한다.

현재 기준은 [아트 가이드](ART_STYLE_GUIDE.md), 장소별 기획은 [씬·UI 명세](CORE_GDD_05_ScenesUI.md), 공간 기능은 [월드 시설](MOD_GDD_01_WorldFacilities.md)을 따른다. 과거 에셋 프롬프트, 개발일지, 데모 보고서의 이전 시점·화풍은 제작 당시 기록이며 새 제작 기준이 아니다. 이번 문서 개정은 런타임 구현 완료를 의미하지 않는다.

## 2. 확정 범위와 미정 범위

- **확정:** 홈 오피스·마을·건물 내부의 픽셀아트 및 비스듬한 탑다운 통일, 실내외 캐릭터·가구 기본 비율 일관성, 거래 UI 가독성 우선.
- **유지:** 시설의 역할, 거래·성장 시스템, 기존 홈 오피스 8×8 논리 그리드와 가구 점유 규칙. 타일 수와 타일의 픽셀 해상도는 별개다.
- **검증 후 확정:** 타일·스프라이트 해상도, 약 2등신 목표 내 정확한 몸체 픽셀 치수, 애니메이션 프레임 수·속도, 화면 배율, 벽 장식·가구 방향별 표현과 가림 처리. 캐릭터 제작 방식은 [파츠 가이드](part_separation_guide_512.md)의 프레임별 픽셀 스프라이트와 교체 파츠를 기본으로 한다.
- **별도 검토:** 비트 물류의 사이드뷰 전용 미니게임. 일반 공간의 시점 통일은 확정하되, 미니게임까지 변경할지와 물리·조작 재설계는 아직 결정하지 않았다.

## 3. 전환 순서

1. 홈 오피스 한 방과 짧은 마을 거리를 같은 픽셀·시점 기준으로 제작한다.
2. 캐릭터 이동과 문을 통한 왕복, 책상 상호작용과 거래 UI 열기를 연결한다.
3. 실제 플레이 크기로 검토하고 아트 가이드의 미정 제작 수치를 확정한다.
4. 확정된 규격으로 마을 건물과 대표 상점 내부를 제작한 뒤 다른 공간으로 확대한다.
5. 기존 에셋은 교체 시점에 참조와 사용 여부를 확인한다. 이전 프롬프트나 에셋을 새 규격으로 오인하지 않도록 관리한다.

## 4. 검증 체크리스트

- [ ] 실내외 캐릭터 기본 비율, 픽셀 밀도, 이동 방향이 일관된다.
- [ ] 상하좌우 이동과 출입구 진입·복귀가 자연스럽다.
- [ ] 책상의 상판·앞면과 캐릭터 얼굴이 읽히며 바닥 축이 대각선으로 바뀌지 않는다.
- [ ] 벽·가구 뒤에서 플레이어 위치를 파악하고 이동할 수 있다.
- [ ] 8×8 배치와 가구 점유·회전을 새 시점에서도 이해할 수 있다.
- [ ] 거래 UI의 숫자·차트가 실제 화면 크기에서 선명하다.
- [ ] 픽셀 경계가 화면 배율이나 카메라 이동으로 흐려지거나 흔들리지 않는다.
- [ ] 타일 크기, 캐릭터 비율, 애니메이션 프레임 수·속도를 검증하여 문서에 확정했다.

기존 데모 체크리스트의 완료 표시는 이전 구현 실적이다. 새 그래픽 전환 완료 여부는 위 항목으로 별도 확인한다.
