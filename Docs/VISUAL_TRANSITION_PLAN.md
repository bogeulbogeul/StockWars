# StockWars 그래픽·시점 전환 계획

**개정일:** 2026-09-28
**상태:** 탑다운 뷰 통일 최우선 / 최종 화풍·캐릭터 제작 보류 / 구현 완료 여부 별도 검증

## 1. 결정과 범위

장소별 아이소메트릭·횡스크롤·탑다운 혼용을 해소하고 홈 오피스·마을·일반 건물 내부를 **비스듬한 탑다운(3/4 시점)**으로 통일한다. 픽셀아트를 필수로 고집하지 않고 깔끔함과 가독성을 우선한다.

캐릭터 외형·최종 화풍은 후속 결정이며, 제작 방식은 파츠 분리 후 본 기반 2D 리깅으로 확정한다. 완성 에셋을 기다리지 않고 임시 플레이어·가구·건물로 검증한다. [아트 가이드](ART_STYLE_GUIDE.md), [씬·UI 명세](CORE_GDD_05_ScenesUI.md), [월드 시설](MOD_GDD_01_WorldFacilities.md)이 현행 기준이다. 문서 개정은 런타임 전환 완료를 뜻하지 않는다.

- **지금 확정:** 공통 시점, 화면 가로·세로 공간 축, 상하좌우 이동, 실내외 상대 크기 일관성, 거래 UI 가독성.
- **기존 기능 유지:** 시설 역할, 거래·성장, 홈 오피스 8×8 논리 그리드, 가구 점유·회전. 타일 수와 표현 해상도는 별개다.
- **후속 결정:** 최종 화풍, 캐릭터 외형·비율, 해상도, 픽셀/비픽셀 표현, 리깅 도구·실시간 리깅/베이크 전달 방식, 모션 길이·키 포즈·속도, 팔레트·윤곽선·명암.
- **캐릭터 기능 유지:** 완성형 스타일 선택·판매와 얼굴 독립 선택 제외. 4방향 정지·걷기, 벤치 휴식, 의자 앉기, 침대 눕기, 상자 운반은 공통 요구이며 특별 모션은 한정판 전용이다. 제작은 후속 단계다.
- **별도 검토:** 비트 물류 등 미니게임의 시점·물리·조작 변경. 마을 확장·탈것은 이번 범위에 추가하지 않는다.

## 2. 1차 검증 구간과 순서

**홈 오피스 → 문 → 짧은 마을 거리 → 대표 건물 내부 → 마을·홈 오피스 복귀**

1. 같은 시점의 임시 바닥·벽·가구·건물과 임시 플레이어를 배치한다.
2. 카메라 배율·사물 상대 크기와 상하좌우 이동·충돌을 맞춘다.
3. 출입구 위치·진입 판정·복귀 위치를 연결한다.
4. 가구·건물 앞뒤 그리기 순서와 벽·지붕 가림을 확인한다.
5. 책상·시설 상호작용과 거래 UI를 실제 플레이 크기로 확인한다.
6. 구간 검증 후 다른 일반 공간에 공통 규칙을 적용한다.

## 3. 뷰 통일 완료 기준

- [ ] 홈 오피스·마을·대표 건물 내부가 같은 비스듬한 탑다운 시점이다.
- [ ] 바닥 축이 화면 가로·세로로 유지되고 상판·전면·이동 통로가 구분된다.
- [ ] 실내외 임시 플레이어·사물의 상대 크기와 카메라 배율이 일관된다.
- [ ] 이동·충돌·출입구 진입과 왕복 복귀 위치가 자연스럽다.
- [ ] 가구·건물 앞뒤 가림 순서가 맞고 플레이어 위치를 파악할 수 있다.
- [ ] 기존 8×8 가구 배치·점유·회전을 새 시점에서 이해할 수 있다.
- [ ] 책상·시설 상호작용과 거래 UI의 글자·숫자·차트가 명확하다.
- [ ] 확인한 공간·남은 공간·미해결 문제를 기록한다.

픽셀 밀도, 최종 캐릭터 완성, 전 스킨 모션 제작은 이 단계의 완료 조건이 아니다. 이전 데모·이미지 생성 완료를 뷰 통일 완료로 간주하지 않는다.

## 4. 후속 아트 제작

뷰 통일 검증 이후 깔끔함·UI 조화·제작 비용을 기준으로 최종 화풍을 비교하고 파츠 분리·본 기반 2D 리깅으로 캐릭터 제작을 재개한다. [제작 가이드](part_separation_guide_512.md)의 모션 기능 요구는 후속 검증한다. 기존 픽셀 프롬프트·마네킹 시트·웹 모션 테스트는 실험 이력으로 보존하고 최종 규격으로 자동 채택하지 않는다.
