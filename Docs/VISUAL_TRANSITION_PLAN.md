**마을은 RPG식 탑다운, 홈 오피스와 일반 건물 내부는 아이소메트릭**으로 구성한다. 마을에서는 길 찾기와 시설 접근성을, 실내에서는 가구의 입체감과 꾸미는 재미를 강조한다. 기존 전 공간 탑다운 통일 방침을 대체한다. 픽셀아트를 필수로 고집하지 않고 깔끔함과 가독성을 우선한다.

현행 캐릭터는 강아지·검은 고양이와 숲속 친구들 같은 동물 외형이며 [아트 가이드](ART_STYLE_GUIDE.md)와 [시트 기준](DOG_SPRITE_BASELINE.md)을 따른다. 미제작 에셋의 세부 외형·전체 배경 화풍은 후속 결정이며, 제작 방식은 방향·행동별 완성 프레임의 직접 제작과 스프라이트 시트 전달로 확정한다. 완성 에셋을 기다리지 않고 임시 플레이어·가구·건물로 검증한다. [아트 가이드](ART_STYLE_GUIDE.md), [씬·UI 명세](CORE_GDD_05_ScenesUI.md), [월드 시설](MOD_GDD_01_WorldFacilities.md)이 현행 기준이다. 문서 개정은 런타임 전환 완료를 뜻하지 않는다.

- **지금 확정:** 마을의 RPG식 탑다운(건물 정면·지붕이 함께 보임), 홈 오피스·일반 실내의 아이소메트릭, 실내외 시각적 일관성과 거래 UI 가독성.
- **검증 시작안:** 실내 고정 시점, 화면 방향에 대응하는 이동 입력, 문 진입 시 짧은 화면 전환, 실내 앞쪽 벽 생략. 전환 방식·시간, 벽·높은 가구의 숨김·투명화 범위는 검증 후 확정한다.
- **기존 기능 유지:** 시설 역할, 거래·성장, 이동·충돌용 논리 그리드와 고정 가구 상호작용. 자유 배치·회전은 완성형 룸 선택으로 대체한다. 타일 수와 표현 해상도는 별개다.
- **후속 결정:** 투영 각도·타일 비율, 두 시점의 캐릭터 그림·시트 공유 범위와 추가 방향별 그림·모션 필요 여부, 미제작 에셋·배경의 세부 화풍·해상도와 추가 전달 규격. 채택된 동물의 외형·색·선·비율 및 걷기3프레임·160ms·운반4자세는 기존 기준을 유지하며 추가 모션만 별도 설계한다.
- **캐릭터 기능 유지:** 완성형 스타일 선택·판매와 얼굴 독립 선택 제외. 4방향 정지·걷기, 벤치 휴식, 의자 앉기, 침대 눕기, 상자 운반은 공통 요구이며 특별 모션은 상품별 구성으로 정한다. 스킨은 동물 캐릭터 전체 외형이며 테마당 6종·한 달 판매를 적용한다. 일반·한정판 구분은 없다. 기존 제작분과 미제작 모션·게임 적용 검수는 구분한다.
- **별도 검토:** 비트 물류 등 미니게임의 시점·물리·조작 변경. 마을 확장·탈것은 이번 범위에 추가하지 않는다.

## 2. 1차 검증 구간과 순서

**짧은 마을 거리 → 집 입구 → 홈 오피스 책상 → 마을 복귀 → 대표 건물 내부 → 마을 복귀**

1. RPG식 탑다운 마을과 아이소메트릭 홈·대표 시설 각 1종의 임시 완성형 룸을 준비한다. [룸 명세](ROOM_PACKAGE_GUIDE.md)에 따라 배경·필요한 가림·HTML/CSS 표시·상호작용·이동 데이터를 묶는다.
2. 카메라 배율·사물 상대 크기와 화면 방향 기준 이동·충돌을 검증한다. 동일 임시 캐릭터의 두 시점에서의 접지·방향·외형 호환을 확인한다.
3. 출입구 위치·진입 판정·복귀 위치를 연결하고 짧은 화면 전환으로 시점 변화가 자연스러운지 확인한다.
4. 가구·건물 앞뒤 그리기 순서와 벽·지붕 가림을 확인한다.
5. 책상·시설 상호작용과 거래 UI를 실제 플레이 크기로 확인한다.
6. 구간 검증 후 다른 마을·일반 실내에 장소별 규칙을 적용한다.

## 3. 실내외 시점 연결 검증 완료 기준

- [ ] 마을은 건물 정면·지붕이 보이는 RPG식 탑다운, 홈 오피스·대표 실내는 아이소메트릭이다.
- [ ] 마을의 가로·세로 동선과 실내의 대각선 바닥 축에서 이동 입력이 혼동되지 않고 이동 통로가 구분된다.
- [ ] 실내외 임시 플레이어·사물의 상대 크기와 카메라 배율이 자연스럽고 캐릭터 공유 가능 범위·추가 제작 필요를 기록했다.
- [ ] 마을에서 집에 들어가 책상까지 이동하고 복귀할 때 시점 전환·조작·충돌·복귀 위치가 자연스럽다.
- [ ] 가구·건물 앞뒤 가림 순서가 맞고 플레이어 위치를 파악할 수 있다.
- [ ] 고정 가구의 접근·앉기·눕기·이탈과 이동·충돌을 검증했다.
- [ ] 룸 배경·CSS 요소·클릭 영역·가림이 배율 변경 후에도 정렬된다.
- [ ] 홈 테마 교체·실패 복구·보유 데이터 이관 정책을 검증하고 미완료 항목을 기록했다.
- [ ] 책상·시설 상호작용과 거래 UI의 글자·숫자·차트가 명확하다.
- [ ] 확인한 공간·남은 공간·미해결 문제를 기록한다.

픽셀 밀도, 최종 캐릭터 완성, 전 스킨 모션 제작은 이 단계의 완료 조건이 아니다. 이전 데모·이미지 생성 완료를 실내외 시점 연결 검증 완료로 간주하지 않는다.

## 4. 후속 아트 제작

현재 제작·채택된 동물 외형은 유지한다. 추가 캐릭터와 미제작 모션은 현행 동물 기준·깔끔함·UI 조화·제작 비용을 검토하고 방향·행동별 완성 프레임을 직접 제작하여 시트로 구성한다. 실내외 연결 검증이 기존 동물 제작·채택을 취소하는 조건은 아니다. [제작 가이드](part_separation_guide_512.md)의 모션 기능 요구는 후속 검증한다. 기존 픽셀 프롬프트·마네킹 시트·웹 모션 테스트는 실험 이력으로 보존하고 최종 규격으로 자동 채택하지 않는다.
