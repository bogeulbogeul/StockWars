# StockWars GDD: MOD_GDD_02. 노동(Job) 시스템 및 미니게임 상세

## 최신 채택·플레이 시제품: 제공 상품 포장 퍼즐 — 2026-10-21

현행 플레이·상품 규격·20개 패턴·완료 UI 논의는 [포장 알바 기획 정리](PACKING_JOB_DESIGN.md)에 통합했다. 사용자는 알바 후 비비안이 ‘어떤 손님이 전해 달라고 맡긴 찌라시 봉투’를 건네는 방향을 제안했다. 보수·봉투를 함께 보여주는 완료 창과 개봉·정보 수첩 보관은 제안 단계다. 지급 확률·빈도·기존 수상한 손님 이벤트와의 관계·저장 연결은 미정이며 아직 구현하지 않았다.

**패턴 확장 후속:** 고정 상품 방향·점유 크기를 유지한 조합 10개를 추가해 총 20개다. 상자 크기와 상품 구성이 중복되지 않으며, 세션당 작은 상자 3개(16칸 이하)·큰 상자 2개를 섞어 중복 없이 제공한다. 모든 조합의 완전 채움과 추첨 가능성을 검증했다. 아래 10개 제작 기록은 확장 전 이력이다.

**그림과 점유 칸 일치 후속:** 모든 상품은 그림의 기본 방향에 맞춘 고정 점유 크기를 사용한다. 패턴 때문에 병을 가로 칸에 넣거나 빵을 세로 칸에 넣지 않는다. 10개 해답을 다시 구성했으며 회전 없이 빈칸을 전부 채운다. 반짝가루·달빛가루는 1×1, 꽃꿀 사탕은 2×1로 변경했다. ✅ 코드·10개 해답·5상자 연속 드래그 검증 / ⏳ 사용자 최종 플레이 검수.

**조작 단순화 후속:** 사용자 채택으로 회전 버튼·R키·드래그 중 회전을 제거했다. 플레이어는 상품 위치만 정하며 ‘모두 꺼내기’와 개별 상품 반환도 기본 방향을 유지한다. 아래 회전 조작 설명은 이전 이력이다.

**P0 (Core) · ✅ UI·플레이 구현 및 자동 검증 / ⏳ 사용자 플레이 검수·경제·첫날 연결.** 사용자가 상품을 미리 제공하고 상자에 맞춰 담는 방식과 화면 시안을 채택했다. 이 결정은 아래 고정 진열대 선택·화남 게이지·시간제한·손님 대기/취소 규칙보다 우선한다.

- 주문에 필요한 물건을 상자 옆에 제공한다. 드래그 또는 상품 선택 후 칸 클릭으로 놓고, 재배치·개별 반환·모두 꺼내기를 지원한다. 회전은 없다. **빈칸 없이 상자를 전부 채워야 성공한다.** 같은 상품은 준비 공간에서 수량 배지로 묶어 표시하되 독립된 조각으로 하나씩 담는다. 예시 정답과 다른 유효 배치도 인정한다.
- 난이도를 선택하지 않는다. 검증된 20개 패턴의 상자 크기·상품 조합을 무작위로 섞어 한 게임에서 여러 상자를 포장한다. 이번 시제품은 중복 없는 5건이며 작은 상자 3건·큰 상자 2건을 섞는다. 5건은 플레이 검증용 값이다.
- 화남 게이지와 시간제한은 없다. 완료 수를 표시하고 한 상자 완료 후 다음 상자를 열며, 목표 달성 후 결과·다시 하기·나가기를 제공한다.
- 잡화점 개편 상품을 사용한다. 꿀 쿠키·꽃잎 차 2×2, 사과 주스 1×3, **포포리빵 3×1**, 꽃꿀 베리 주스 1×2, 허브 차·꽃꿀 사탕 2×1, 이슬 젤리·반짝가루·달빛가루 1×1. 포포리빵은 기존 도토리빵을 대체한다. 실제 판매 카탈로그·아이템 ID·보유품은 이번 시제품으로 자동 이관하지 않는다.
- UI 비표시 3D 마을에서는 잡화점 앞 F 또는 안내 버튼으로 진입하고, 일반 모드에서는 기존 상점의 포장 알바 버튼으로 연다. [독립 플레이 화면](../web/packing.html)과 `?scene=packing` 직접 진입도 제공한다. 기존 마을·상점 동작과 저장 데이터는 유지한다.
- 이번 실행 중 나갔다 돌아오면 진행을 유지한다. 앱 종료·새로고침을 넘는 저장은 미구현이다. 보수·하트 차감·EXP·수상한 손님·찌라시 지급·첫날 튜토리얼은 후속 범위이며 이번 플레이 시제품에서는 지급/차감하지 않는다.

패턴 데이터는 [PackingData.js](../web/js/components/packing/PackingData.js), 배치 판정은 [PackingLogic.js](../web/js/components/packing/PackingLogic.js), 화면·검증 기록은 [제작 기록](../output/packing-ui-v1/README.md)을 따른다. 수상한 손님 성공 시 찌라시 1장이라는 기존 방향은 보존하되 게이지로 떠나는 규칙은 위 최신 결정으로 폐기한다.

2026-10-19 최신 폐기: **타이틀 화면·개발자 모드·비트 물류창고와 박씨 물류 노동을 폐기**한다. 물류 미니게임·직원 휴게실·퀵패스 판매/사용·물류 의뢰·개발자 테스트 친구/선물·강제 성장 조작을 게임에서 제거한다. 과거 제작 에셋·저장 보유 기록은 보존하며 재도입 근거로 사용하지 않는다. 현재 UI 비표시 마을 진입은 유지한다. 일반 UI에서는 저장된 게임 자동 진입 또는 신규 등록으로 연결하며 새 도입 연출은 후속 구현이다. 폐기된 물류 및 보상 전제 안내는 건너뛰고 자립 안내로 연결하며, 비비안 포장 퍼즐·첫 찌라시·회복 안내의 새 구현 완료를 의미하지 않는다. **P0 (Core) · ✅ 코드·기획 폐기 반영 / ⏳ 새 잡화점 노동·도입 구현.**


## 최신 채택: 고정 상품 진열·2D 포장 퍼즐·손님 대기 — 2026-10-19

**P0 (Core) · ✅ 완료: 기획 반영 / ⏳ 대기: 상세 규칙·구현·경제 조정·게임 검수.** 잡화점 노동은 주문 상품을 선택하고 회전·배치해 상자에 담는 **2D 포장 퍼즐**로 제작한다. 아래 캐릭터가 진열대 사이를 직접 이동하는 이전 방식보다 우선한다. 이미지 시안은 화면 구성 참고이며 최종 에셋·퍼즐 규격의 확정을 뜻하지 않는다.

- **화면 구성:** 음식 조립 게임처럼 화면 위쪽 포장대 건너편에는 요정 손님, 가운데에는 포장 상자, 아래쪽에는 고정 상품 진열대를 배치한다. 손님 머리 위 주문표에 상품 그림·수량을 표시하고 화남 게이지를 함께 보여준다. 사용자 참고 이미지는 화면 배치·주문 처리 방식 참고이며 음식·조리 기능이나 캐릭터 외형을 그대로 도입하는 뜻은 아니다.
- **고정 상품 진열:** 해당 작업에서 사용하는 상품을 주문이 오기 전부터 모두 진열한다. 상품 위치는 주문마다 바꾸지 않아 위치를 익히고 빠르게 선택할 수 있게 한다. 주문별로 필요한 상품만 별도 준비 트레이에 제공하는 이전 시안 대신, 공통 진열대에서 필요한 종류·수량을 직접 골라 상자에 끌어 담는다.
- **포장 흐름:** 주문 확인 → 고정 진열대에서 상품 선택 → 상자 안에 끌기·회전·재배치 → 주문 종류·수량과 겹침/상자 범위 확인 → 포장 완료·전달 순서다. 상품 위치를 익혀 선택하는 재미와 상자 안의 공간을 활용하는 퍼즐을 결합한다. 잘못 담은 상품은 전달 전에 꺼내거나 수정할 수 있다.
- **첫 시제품 공급 방식:** 진열대에서 상품을 꺼내도 같은 상품을 계속 선택할 수 있으며 재고 소진·수동 보충 조작은 넣지 않는다. 개인 소지품을 차감하지 않는 미니게임용 공급으로 검증한다. 최종 재고·경제 연동 정책은 별도 설계한다.
- **조작 튜토리얼:** 첫 손님 한 명과 시간 제한 없이 고정 진열대에서 주문 상품 찾기·끌어 담기·회전·재배치·포장 완료/전달을 익힌다. 이 구간에는 화남 게이지가 상승하지 않고 손님이 시간 경과로 떠나지 않는다.
- **본 게임:** 조작 튜토리얼 이후 다른 요정 손님을 추가한다. 포장대 건너편에 손님 모습을 보여주고 주문표와 화남 게이지를 함께 확인할 수 있게 한다. 손님 추가는 채택하되 동시 등장 수·대기열·등장 간격은 후속 설계한다.
- **대기와 취소:** 본 게임에서는 기다리는 시간이 길어질수록 해당 손님의 화남 게이지가 상승한다. 한계에 도달하면 손님이 떠나고 해당 주문은 취소된다. 한계 이후에도 포장을 완료할 수 있거나 속도 보너스만 사라지는 방식은 채택하지 않는다.
- **후속 설계:** 게이지 상승 시작 시점·속도·표정 단계, 취소된 주문의 상품/상자 회수·보수·하트 처리, 전체 작업 종료 조건을 정한다. 주문 취소를 전체 게임 실패나 추가 금전 벌금으로 자동 확대하지 않는다. 상품 모양·상자 크기·일반 작업 시간·보상 수치는 퍼즐 검증 후 조정한다.

### 찌라시 수급: 수상한 요정 손님 — 2026-10-19 후속 채택

- **등장:** 본 게임의 일반 손님 사이에 수상한 요정 손님이 확률적으로 등장해 상품을 주문한다. 정확한 등장 확률·빈도·중복 등장·장기 미등장 보장 여부는 미정이다.
- **성공 보상:** 수상한 손님의 주문을 완료·전달하면 찌라시 **1장을 확정 지급**한다. 등장 이후 보상에 별도의 확률 판정을 하지 않는다. 일반 손님 주문마다 무작위 찌라시를 지급하는 방식 대신 특별 손님 이벤트를 기본 수급 경로로 삼는다.
- **퇴장 대사:** 성공한 손님은 떠나면서 짧고 의미심장한 말을 남긴다. 분위기나 정보 해석의 단서를 제공하되 특정 종목의 상승·투자 수익을 보장하지 않는다. 정확한 대사·외형·찌라시 종류와 선정 규칙은 후속 설계한다.
- **주문 취소:** 본 게임에서 화남 한계에 도달하면 일반 손님과 같이 떠나며 주문이 취소되고 찌라시를 지급하지 않는다.
- **첫 조작 튜토리얼:** 첫 연습 손님을 수상한 요정으로 한 번 확정 등장시킨다. 시간 제한·화남 상승 없이 조작을 익힌 뒤 주문 전달 → 찌라시 1장·퇴장 대사 → 기존 정보 해석·회복 안내로 연결한다. 기존 첫 안내용 보장 찌라시를 이 이벤트로 제공하며 별도로 중복 지급하지 않는다.

✅ 수급 방향 기획 반영 / ⏳ 확률·대사·보상 데이터·구현·게임 검수 대기. 본 게임 진입 시점과 첫날 후속 안내 사이의 연결은 별도 설계하며, 일반 주문 완료를 튜토리얼 졸업 조건에 자동 추가하지 않는다.

**P0 (Core) · ✅ 완료: 기획 반영 / ⏳ 대기: 구현·경제 조정·게임 검수.** 아래 물류 단일 노동·사이드뷰·60초 점수표·퀵패스는 기존 구현 및 이전 설계 기록이다. 새 노동의 수치·조건으로 자동 승계하지 않는다.

### 기본 작업
노동의 중심을 주민 가게의 주문 처리로 바꾼다. 첫 가게는 비비안 잡화점이며 비비안이 작업을 안내한다. **주인과 대화 → 작업 시작 → 주문 확인 → 진열대에서 상품 선택 → 포장대에서 준비 → 손님에게 전달 → 보수·짧은 대화** 순서다. 주문표는 상품 그림·이름·수량을 작업 중 계속 표시한다.

- 첫 연습은 손님 한 명·상품 1종부터 시작하고 제한 시간 없이 안내한다. 전달 전 잘못 고른 상품을 다시 고를 수 있다.
- 일반 작업은 짧은 제한 시간 안에 주문을 처리한다. 숙련 이후 상품 종류·수량·동시 주문을 단계적으로 늘린다. 정확한 시간·상품 수·해금 조건은 미정이다.
- 완료 주문의 기본 보수 + 정확도·속도 보너스를 사용한다. 하트는 작업 비용으로 유지하며 시작 전에 하트 비용·예상 소요 시간·기본 보수를 표시한다. 금액·EXP·비용·보너스 공식은 첫 주 현금 월세와 함께 검증한다.
- 시간 종료·중단·오배송 시 부분 정산과 하트 반환, 상품 재고·개인 소지품의 관계는 후속 설계한다. 새 주문 상품을 기존 소지품에서 임의 차감하지 않는다.
- 미니게임은 위 2D 포장 화면을 사용한다. 마을·일반 실내의 3D 생활 시점과 구분하며 주문표·상품·상자·손님 상태를 명확하게 보여준다.

- 주문 내역을 정확히 읽는 경험을 찌라시의 단서 읽기로 연결한다. 노동 대사·물동량은 주가 예측을 보장하지 않는다.

## 1. 노동 시스템 개요
플레이어는 타운 내 노동 구역에서 주식 자본금 및 경험치(EXP)를 확보할 수 있습니다. 숙련도에 따라 주가 복선을 담은 **'찌라시 정보'**를 추가 보상으로 획득 가능합니다.

## 2. 환경 및 상호작용 (World Setting)
- **시설 단일화**: 타운 내 모든 노동 미니게임(편의점, 치킨집)을 폐지하고, **비트 물류(Bit Logistics)**를 유일한 노동 구역으로 확정하여 유저 동선을 단순화합니다.
- **NPC 상호작용**: 관리소장 **박씨(Manager Park)**가 상주하며, 유저의 자산 상태나 수익 현황에 따라 무뚝뚝하거나 냉소적인 피드백을 실시간으로 제공합니다.
- **시각적 긴장감**: 노동 중에도 화면 상단 티커를 통해 실시간 기업 뉴스가 흐르도록 설계하여, 시장의 흐름을 놓치지 않게 만듭니다.

## 3. 조작 및 물리 엔진 (Gameplay Physics)

### 공통 캐릭터 모션 (2026-09-28 확정)

상자 옮기기는 판매 테마·특별 모션 포함 여부와 관계없이 모든 스킨의 필수 기본 모션이다. 상자를 든 정지(`box_carry_idle`)와 이동(`box_carry_walk`)을 지원하며 집기·내려놓기·파손에 맞게 상태를 전환한다. 별도 전환 프레임 수, 방향 수, 가속 시 재생 방식은 최종 미니게임 조작과 함께 검증한다.

상자는 공통 화물 오브젝트이며 방향·프레임별 손 위치와 가림 순서를 맞춘다. 스킨별 운반 속도·충돌·보상 차이를 만들지 않는다. 상세 제작 기준은 [스타일 제작 가이드](part_separation_guide_512.md)를 따른다. 아래 기존 밀기 동작의 별도 모션 채택과 사이드뷰 전환 여부는 아직 미정이다.
- **화물 운송 시스템**: **사이드뷰 (Side-view)** 시점에서 캐릭터가 화물을 목적지(지정된 하차 지점)까지 밀거나 운반하는 선형적 방식입니다.
- **가속 및 관성**: **[Shift] 키**를 사용하여 가속할 수 있으나, 가속 시 화물의 관성이 커져 조작이 까다로워집니다.
- **파손 게이지 (Reset & Sensitivity)**:
    - **초기화**: 새로운 화물을 집어 드는 시점마다 게이지는 **0%로 초기화**됩니다. (화물별 개별 관리)
    - **민감도**: 가속([Shift]) 시 게이지가 차오르는 속도가 매우 빠르며(High Sensitivity), 조작 미숙 시 순식간에 파손 한계치에 도달합니다.
    - **실패**: 게이지가 100%에 도달하면 화물이 즉시 파손되어 해당 세션의 최종 작업량 산정에서 제외됩니다.

## 4. 디자인 의도
- **몰입감**: 단순 반복 노동이 아닌, 물류의 조작 피드백(운반, 관성, 파손 게이지)을 통해 노동의 '숙련도'를 체감하게 함.
- **경제 밸런스**: 난이도와 보상을 비례하게 설계하여, 플레이어가 자본금 확보를 위해 더 높은 난이도의 미니게임에 도전하도록 유도.

---

### 5. 작업량 기반 등급 판정 및 보상 (Result-based Reward)
- **제한 시간**: 세션당 **60초 (1분)** 고정.
- **등급 판정**: 운송 횟수가 아닌 누적 점수로 결정한다. 한 번에 1/2/3/4개 운반 성공 시 1/3/6/8점을 더한다. 파손 수는 별도로 집계하며 파손 한 번만으로 최종 등급을 C로 고정하지 않는다.

| 최종 등급 | 판정 기준 (누적 점수) | 현금 보상 | 경험치 (EXP) | 찌라시 확률 |
| :--- | :--- | :--- | :--- | :--- |
| **S (Excellent)** | **30점 이상** | **800 G** | 100 EXP | 30% |
| **A (Good)** | **18~29점** | **560 G** | 70 EXP | 15% |
| **B (Normal)** | **10~17점** | **320 G** | 40 EXP | 5% |
| **C (Below)** | **10점 미만** | **100 G** | 10 EXP | 0% |

- **최저 보상**: 최종 점수가 10점 미만이면 C등급 기본금 100G를 지급한다. 화물 개별 파손과 세션 최종 등급을 구분한다. 골드에는 기본 협상력 단계당 +5%를 적용한다.

---

## 6. 확률적 특수 메커니즘 (Special Odds)
- **황금 기회 (Golden Opportunity)**: **S등급 달성 클리어 시**에만 **0.002%** 확률로 발동하며, 기본 보상 **10배 잭팟(8,000G, 협상력 보정 전)**을 지급합니다. 현행 잭팟 코드에는 별도 전설 아이템 지급이 없습니다.
- **정보 수급**: 첫 작업은 찌라시를 확정 지급하며 이후에는 등급 확률을 사용한다. 작업 시작 시각의 KST 22:00~02:00에는 기본 지급 확률이 2배다. 회복력 보너스는 별도 적용한다. 보상은 소지품에 추가하고 [현행 찌라시](RUMOR_AUTHORING_GUIDE.md)에서 해석한다.
- **체력 연동**: 기본 하트 1개를 소모하며 별도 일일 노동 횟수 제한은 없다. 기본 회복력 5단계는 종료 시 10% 확률로 체력 차감을 면제한다. 최대 하트·회복은 [성장 명세](CORE_GDD_03_PlayerGrowth.md)를 따른다.

## 7. 현재 노동 패스와 확장안

비비안 1일권 1,500G·7일권 8,000G를 사용하면 유효 기간 중 즉시 완료를 선택할 수 있다. 현재 보상은 고정 560G·70EXP이며 골드는 협상력 보정을 적용한다. 기본 체력 1개를 쓰고 수수료는 0%, 찌라시는 지급하지 않는다. 역대 최고 기록을 재사용하지 않는다.

누적 100회·회복력 5의 영구 자동화, 일반 위탁 수수료 20%→10%는 미구현 검토안이다. 현재 패스의 비용·보상과 합산하지 않는다.
