# CORE_GDD_02 현재 시장과 거래 엔진

> 개정: 2026-10-16. 일반 게임 시장과 온라인 모의투자를 구분한다. 장기 희소성·IPO·서버 단일 시장은 현재 구현과 별개의 확장 검토 대상이다.

## 1. 시장과 데이터

일반 게임은 클라이언트 `MarketEngine`의 72개 초기 종목을 사용한다. ID·이름·초기 주가·업종·티어·배당의 실제 기준은 [stocksData.js](../web/js/data/stocksData.js)이며 별도 Markdown 표를 실행 원본처럼 중복 관리하지 않는다. 초기 뉴스도 같은 파일에서 시작한다. 기사·찌라시 원고의 종목 수와 현재 거래 종목 수를 합산하지 않는다.

약 2,200ms 가격 틱에서 변동성 티어별 무작위 가격 변화와 합성 호가 유동성을 갱신한다. 차트·호가·대기 주문 체결이 같은 notify 흐름에 반영된다. 초기 차트 이력도 생성 데이터다. 전 세계 유저의 거래를 한 서버 가격에 모은 메인 시장은 현재 구현이 아니다.

추천 종목은 현재 시세·성향·구매 가능 여부로 고른다. 튜토리얼을 위해 가격·상승률을 보장하거나 강제로 낮추지 않는다. 첫 매수·후속 안내는 [튜토리얼](CORE_GDD_10_TutorialSystem.md)을 따른다.

## 2. 주문과 비용

시장가와 지정가를 구분한다. 시장가는 현재 호가 잔량에 따라 실제 체결 가격·수량이 달라질 수 있으며 일부 체결 또는 미체결될 수 있다. 지정가는 지정 조건·제출 시 검증과 이후 호가·자원 검사를 따른다. 현재가 한 점에서 모든 주문을 무제한 체결하는 체계가 아니다.

**2026-10-22 수수료 통일 기획:** 증권사와 주식앱은 같은 게임 계좌·동일한 수수료 정책을 사용한다. 현장 방문 할인은 없애며 공통 기본 요율은 후속 확정한다. 스마트폰·홈 0.15%·증권사 0.01%는 기존 구현 기록이다. 같은 조건의 거래에는 기존 협상력·성향 보정을 동일하게 적용한다. ✅ 기획 반영 / ⏳ 요율 확정·코드 반영·검수. 보유 슬롯·주문 주수·현금·보유 수량·레버리지 조건을 검사한다. 종목별 투자금 Cap은 현재 Infinity다. 정확한 스탯·해금 상태는 [성장 명세](CORE_GDD_03_PlayerGrowth.md)를 따른다.

공매도와 2/3/5배 레버리지는 해금 플래그로 차단한다. 운용력 2·서밋 Lv.20·기관 설립을 동시에 요구하는 구안은 현재 검사와 다르다. 자동 레벨 해금과 서버 신용 대출·마진콜까지 구현되었다는 뜻은 아니다.

## 3. 합성 유동성과 기록

고스트 유동성은 가격 변화 방향에 따라 매수·매도 호가 잔량을 조정하고 목표 물량 차이를 보충한다. 별도 AI 지갑·가짜 사용자 거래 기록·서버 소각 잔고는 만들지 않는다. [OrderMatching](../web/js/engine/OrderMatching.js)·[고스트 설계 범위](MOD_GDD_13_GhostTrader.md)를 따른다.

일반 시장·실제 체결·거래 기록과 온라인 대결 서버의 가상 주문을 섞지 않는다. 온라인 대결은 별도 [arena-stocks.json](../Server/presence/arena-stocks.json)의 72종 데이터를 쓰며 예비 풀에서 12종을 무작위 선정하는 구안이 아니다. 기간·가상 배팅·순위는 [증권사 명세](CORE_GDD_04_FinancialInstitutions.md)를 따른다.

## 4. 배당과 진행

현재 시작 자금은 고정 5,000G이며 시장 물가지수에 따라 자동 조정하지 않는다. 다음 날 조작·일별 배당·7일 차 현금 월세는 [경제 명세](CORE_GDD_07_EconomySim.md)를 따른다. 특정 시각 07~17시 영업을 현재 모든 주문의 거래 가능 시간으로 적용하지 않는다.

현재 일반 게임은 블랙 스완을 비활성화한다. 100일 전역 위기·168시간 추세 PRNG·유통량 40% 고정 희소성·주가에 따른 자동 상장폐지·예비 풀 자동 IPO·서킷 브레이커는 장기 설계 이력이며 현재 작동하는 규칙이 아니다. 원고를 채택하려면 저장·서버·시간·체결을 함께 설계한다.
