## 📌 [슬라이드 8] 3. 최종 데모 완성 목표: 5-Step 튜토리얼 (Tutorial System)

### 🎨 화면 레이아웃 & 비주얼
- **중앙**: 5단계 튜토리얼 진행 시퀀스 카드 (Step 1 ➔ Step 5)
- **하단**: 하단 핵심 기술 구현 명세 박스

### 📝 슬라이드 텍스트 내용
```text
[STEP 01: 오리엔테이션 & 오피스 등록]
· 매니저 안나의 환영 인사 ➔ 오피스 닉네임 설정 ➔ 초기 시드(5,000G) 지급 확인

[STEP 02: 첫 주식 매매 (정보 매매)]
· 저위험 추천 종목 1주 매수 가이드 ➔ 실시간 속보 뉴스 확인 및 선 그래프 체결 학습

[STEP 03: 노동의 가치 (시드 마련)]
· 타운 '비트 물류' 이동 ➔ 60초 상하차 알바 1회 수행 ➔ 등급별(S/A/B) 보상 수령

[STEP 04: 기력 회복 & 상점 이용]
· '비비안 잡화점' 이동 ➔ 에너지 드링크 구매 및 사용 학습 (스태미너 회복)

[STEP 05: 튜토리얼 수료 & 독립]
· 정착 지원금(2,000G) 즉시 지급 ➔ 모든 UI Lock 해제 및 멀티 자유 플레이 전환

[TECHNICAL SPECIFICATION]
· UI Punch-through Masking System: 지정 UI 영역 펄스 하이라이트 및 클릭 안내 마스킹 구축
· Step State Persistence: 튜토리얼 진행 단계별 상태 저장 및 복원 기능 완성
```

## 📌 [슬라이드 9] 4. 개발 중 직면한 문제점 및 해결 방안 (Troubleshooting)

### 🎨 화면 레이아웃 & 비주얼
- **구도**: 3개의 가로 카드 박스 (PROBLEM ⚠️ ➔ SOLUTION ⚙️)

### 📝 슬라이드 텍스트 내용
```text
[ISSUE 01: 실시간 UI 최적화]
⚠️ PROBLEM: 주가 틱 갱신 및 뉴스 수신 시 드로우콜 급증 및 프레임 드랍 발생
⚙️ SOLUTION: 오브젝트 풀링(Object Pooling) & Dirty Flag 패턴 도입으로 불필요한 UI 재렌더링 방지

[ISSUE 02: 검색 및 스크롤 성능]
⚠️ PROBLEM: 24종(확장 72종) 주식 리스트 실시간 필터링 시 버벅임
⚙️ SOLUTION: 뷰 재활용(Recycle View) 메커니즘 & Throttling(갱신 주기 제어) 기법 적용으로 스크롤 최적화

[ISSUE 03: UI 계층 및 팝업 간섭]
⚠️ PROBLEM: PC 화면에서 스마트폰 창, 차트 팝업 중첩 시 클릭 뚫림 현상
⚙️ SOLUTION: 동적 Canvas Sorting Order & Raycast Blocker 시스템 구축으로 계층 간 입력 완벽 제어
```

### 🎤 발표 대본 (Pitching Script)
> "개발 과정에서 실시간 주가 틱 갱신에 따른 프레임 드랍과 UI 팝업 중첩 이슈가 발생했습니다. 이를 오브젝트 풀링, Recycle View, 동적 Raycast Blocker를 구축하여 최적화와 안정적인 UI 터치 환경을 확보했습니다."
