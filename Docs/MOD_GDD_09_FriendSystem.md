- 광장 채널·동시 수용 인원·동기화·현장 대화 UI·개방 시점은 후속 설계한다. 마을 방문은 아래 초대 기반 방문 채택을 따르며, 집 실내 방문 범위·권한은 별도 설계한다.
- 기존 온라인 친구·DM·선물 구현은 공간 분리 및 공용 광장 구현 완료의 근거가 아니다. 기존 기록·보유권을 보존하며 변경이 필요한 이관은 별도로 설계한다.

## 개인 마을 초대·방문 — 2026-10-20 후속 사용자 채택

**P1 (Major) · ✅ 완료: 기획 반영 / ⏳ 대기: 상세 정책·UI·동기화·구현·게임 검수.** 개인 마을은 소유 유저가 다른 유저를 초대하고, 초대받은 유저가 방문하는 공간으로 만든다. 초대 방문 중에는 마을 주인과 방문자의 모습이 같은 마을에 함께 보인다. 불특정 유저가 모이는 공용 만남 광장과 구분하며, 개인 마을이라는 성격을 유지한다. 앞서 미정으로 남겼던 마을 방문 허용 방향은 이번 채택으로 확정한다.

- 기본 흐름: 마을 주인이 유저 초대 → 초대받은 유저가 수락 → 초대한 유저의 마을 방문 → 방문 종료 후 자신의 마을로 복귀.
- **2026-10-20 광장 초대 연결 채택:** 공용 만남 광장에서 상대 유저를 선택해 ‘내 마을로 초대’를 보낼 수 있다. 상대가 수락하면 초대한 유저의 개인 마을 방문으로 연결한다. 주인이 광장에서 자신의 마을로 이동하는 시점·동행/합류 방식·입장 실패 및 연결 중단 처리는 후속 설계한다. 광장 초대 대상의 친구 한정 여부는 미정이며, 초대를 보내는 것만으로 상대를 이동시키지 않는다.
- 다른 유저의 모습은 초대 방문이 성립한 경우에 표시한다. 무초대 공개 입장은 이번 채택에 포함하지 않는다. 방문은 선택 사항이며 정착·첫 활동·필수 진행 조건으로 추가하지 않는다.
- 초대 대상의 친구 한정 여부·초대 UI·유효 기간·동시 방문 인원·주인 접속 조건·초대 취소/퇴장·연결 중단 시 복귀·차단 정책은 후속 설계한다.
- 집 실내 출입, NPC·상점·노동·투자 이용, 가구/장식 조작, 아이템 전달과 보상·진행 저장 권한은 미정이다. 방문 허용을 마을 주인의 자산·배치·이야기 진행 변경 권한으로 확대하지 않는다. 기존 편지·선물 정책은 유지한다.
- 아래 과거 ‘방 구경’은 이번 마을 방문 기획의 구현 완료나 실내 방문 확정 근거로 사용하지 않는다. 기존 저장·보유권을 보존하고 방문 세션·상태 동기화와 저장 경계는 구현 전에 설계한다.

공용 만남 광장의 초기 배치는 **중앙 상징물·벤치와 테이블·사진 명소·귀환 지점과 사이퍼 증권 본점**으로 구성한다. 본점의 구체 기능은 후속 설계한다. 광장에서 만나 머무르기 → 상대 선택·내 마을 초대 → 수락 후 개인 마을 방문을 교류 흐름으로 둔다. 귀환 지점은 자신의 마을로 돌아가는 경로이며 다른 유저의 마을 방문에는 초대 수락 절차를 적용한다. [배치 요소·미정 범위](MOD_GDD_01_WorldFacilities.md)를 따른다. ✅ 기획 반영 / ⏳ 상세 설계·구현·검수 대기.

## 우체국·집 앞 우편함 — 2026-10-19 사용자 채택

### 여행 중인 집주인의 편지·기념품 — 2026-10-21 사용자 채택

플레이어 집의 집주인은 세계여행 중 가끔 소망이에게 편지나 기념품을 보낸다. 편지에는 여행지의 풍경·만난 사람·작은 경험과 안부를 담고, 일부 편지에는 기념품을 첨부할 수 있다. **집 앞 우편함에서 편지 열람·첨부 기념품 수령**으로 연결하며 휴대폰 선물함에 중복 지급하지 않는다. 도입에서 발견한 씨앗·편지와는 별개의 여행 우편이다.

정확한 발송 주기·첫 도착·현실/게임 날짜 기준·여행지·본문·기념품 종류/수량·장식 가능 여부·효과·보관/만료·답장 조건은 후속 설계한다. 집꾸미기용 기념품으로 정할 경우 기존 지정 위치 장식 규칙을 따른다. 도착·열람·첨부 수령 상태를 구분하고 재접속/재열람 때 중복 지급을 막도록 설계한다. 기존 월세·대출·정착 지원금 조건은 유지한다.

**P1 (Major) · ✅ 완료: 여행 우편 설정·수신 경로 기획 반영 / ⏳ 대기: 상세 콘텐츠·발송/수신·저장·게임 검수.**

### 공통 우편 정책

**P1 (Major) · ✅ 완료: 기획 반영 / ⏳ 대기: 상세 정책·건물/우편함 제작·구현·이관·게임 검수.** 우체국에서 편지를 쓰고 선물을 보내며, 집 앞에 설치한 우편함에서 도착한 편지와 선물을 받는다. 우체국 도입 시 휴대폰 내 선물 보내기 기능을 제거하고 우체국으로 옮긴다. 아래 현재 Bubble 선물함·서버 선물 기록은 기존 구현 상태이며 전환 완료를 뜻하지 않는다.

| 대상 | 채택한 이용 방향 | 후속 설계 |
| :--- | :--- | :--- |

- Bubble의 친구·DM 역할은 유지한다. 새 편지·선물의 발송과 수신은 우체국·우편함이 담당하며, 휴대폰에서 같은 선물을 중복 발송/수령하지 않도록 설계한다. 휴대폰의 우편 도착 알림 여부는 미정이다.

- 기존 미수령 선물·발송 기록·보유권은 보존하고 이관 및 중복 지급 방지를 구현 전에 설계한다. 아이템 센터의 시스템 우편·드링크 배급까지 자동 이전하지 않는다.
- 우체국 담당 주민은 [두리의 확정 외형·역할](MOD_GDD_06_NPCRegistry.md)을 반영했다(2026-10-21). 우체국 상호·위치·개방 시점·졸업 전시회 포함 여부는 미정이다. 편지지 선택·편지 전시 등 세부 꾸미기는 이번 결정으로 확정하지 않는다.

## 1. 친구 목록 및 기본 기능 (Friendship)

- **친구 추가**: 유저 ID 조회 및 아레나 대결 종료 후 매너칭찬 기반 추가.
- **방 구경 (Home Visit)**: 친구의 홈 오피스를 방문하여 가구 배치와 오피스 레이아웃을 감상.
- **에너지 선물 (Gifting)**: 하루 1회 친구에게 스테미너(Energy) 선물 가능. (받는 유저의 **스마트폰 Bubble 앱(개인 DM)**으로 전달되며, 일일 5회 수령 제한)

### 1.1. 우호도 시스템 (Affinity System) [NEW]
친구와의 지속적인 교류를 통해 **우호도(FP, Friendship Point)**를 쌓고 관계 등급을 높일 수 있습니다.

| 등급 | 명칭 | 해금 조건 | 특징 |
| :--- | :--- | :--- | :--- |
| **Lv.1** | **면식 (Acquaintance)** | 친구 추가 시 | 기본 상태. 에너지 선물 가능. |
| **Lv.2** | **교류 (Interaction)** | 누적 100 FP | 찌라시 공유 시 보너스 확률 발생. |
| **Lv.3** | **신뢰 (Trust)** | 누적 500 FP | **추가 소셜 혜택 제공** — 특별 칭호는 [2026-10-22 기획 폐기](FEATURE_RETIREMENT_2026-10-22.md) |
| **Lv.4** | **혈맹 (Blood Alliance)** | 누적 1,500 FP | 찌라시 공유 일일 횟수 증가 (최대 2회). |

#### 우호도(FP) 획득 방식
- **에너지 선물 보내기**: +10 FP (일 1회)
- **찌라시 공유하기**: +20 FP (일 1회)
- **배 아픈 알림 상호작용** (무제한):
    - **🥳 (축하)**: +5 FP
    - **😒 (새침/질투)**: +1 FP
    - **😡 (싫어요)**: 0 FP
- **친선 주식 대결 참여**: +50 FP (회당)

### 1.2. 친선 주식 대결 (Friendly Match) [NEW]
친구들과 실력을 겨루며 우호도를 쌓는 소규모 경쟁 모드입니다.
- **방 생성 및 초대**: 방장이 친구 목록에서 최대 3명을 초대하여 **최대 4인** 대결 방을 개설할 수 있습니다.
- **게임 규칙**: 아레나의 기본 규칙을 따르되, 랭킹 점수 대신 **우호도(FP)**와 소정의 게임 재화만을 보상으로 획득합니다.
- **상호작용**: 대결 도중 전용 이모티콘을 사용하여 실시간으로 감정을 표현할 수 있습니다.

## 2. 배 아픈 알림 시스템 (The Envy Notification)

친구가 큰 성공을 거두었을 때 실시간으로 푸시 알람이 발생하여 유저의 경쟁심을 자극합니다.

| 트리거 (Trigger) | 노출 메시지 (Example) | 상호작용 (Interaction) |
| :--- | :--- | :--- |
| **주식 상한가 적중** | "친구 OOO님이 [종목명]으로 +15% 수익을 냈습니다!" | **🥳 / 😒 / 😡** |
| **도박장 잭팟** | "친구 OOO님이 블랙잭 5연승 잭팟을 달성했습니다!" | **🥳 / 😒 / 😡** |
| **자산 등급 상승** | "친구 OOO님의 신용등급이 [Silver]로 상승했습니다!" | **🥳 / 😒 / 😡** |
| **스타일 수집 알림 (재설계 대기)** | "친구 OOO님이 동물 스킨을 수집했습니다!" | **🥳 / 😒 / 😡** |

## 3. 정보 공유 매커니즘 (Information Loop)

- **찌라시 공유 (Rumor Sharing)**:
    - 보유한 찌라시 중 하나를 선택하여 친구에게 전송 (일일 1회).
    - 친구의 **스마트폰 Bubble 앱(개인 DM)**으로 전달되며, 보낸 사람의 찌라시는 사라지지 않고 복사본이 생성됩니다.

## 4. 소셜 기반 랭킹 (Social Leaderboard)
- **자산왕**: 친구 목록 내 보유 Gold 순위.
- **수익왕**: 최근 7일간의 수익률 랭킹.
- **스타일왕**: 가구/의상 수집 점수에 따른 랭킹.
