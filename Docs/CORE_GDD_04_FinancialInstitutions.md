현재 코드의 옵시디언은 엘리베이터 위층의 회원 전용 공간 안내이며 가입 절차·조건·혜택은 준비 중이다. 이번 채택은 본점 전용이라는 장소 구분의 확정이며 가입 조건·비용·혜택·제공 서비스·층별 구조·담당 NPC를 확정하거나 가입/이용 구현 완료를 의미하지 않는다. 서밋·공매도·수수료 우대 등 기존 확장안을 옵시디언 혜택으로 자동 승계하지 않는다.

본점/개인 마을 증권사 분리 구현 시 기존 로비의 회원 안내·엘리베이터 접근을 본점 전용 정책에 맞춰 정리한다. 기존 제작 원본·저장 기록은 보존하며 현재 코드에 안내가 있다는 이유로 개인 마을에 옵시디언을 유지하지 않는다. 구현 상태 근거: [현재 회원 안내](../web/js/components/CipherCanvasLobby.js).

본점 전용 기능 중 옵시디언은 위 후속 채택으로 확정한다. 그 밖의 개인 마을 증권사와의 역할 구분·실내 진입·담당 NPC·개방 조건·거래/보상 정책은 후속 설계한다. 아래 기존 경쟁룸·아레나·수수료·금융 기능을 본점에 자동 배정하지 않는다. 기존 저장·경제 수치는 변경하지 않으며, 건물 추가 기획과 실제 구현 완료를 구분한다. [광장 초기 구성](MOD_GDD_01_WorldFacilities.md)을 따른다.

## 2026-10-19 정착 대출 후속 채택

**P0 (Core) · ✅ 완료: 기획 반영 / ⏳ 대기: 조건 설계·구현·검수.** 첫날 안나가 생활 자금을 묻고 노드 은행에 동행한다. 샤일록이 조건을 설명하고 플레이어가 확인해 정착 대출을 받는다. 아래 은행 대출 전체 미정·첫날 은행 방문 제외 기록보다 이번 결정을 우선한다.

- 기존 시작 자금 **5,000G를 정착 대출 원금으로 전환**한다. 무료 시작 자금에 추가하는 지급이 아니다. 은행에서 한 번 지급하고 오피스에서는 잔액만 안내한다.
- 튜토리얼 정착 지원금 **2,000G는 별도 유지**한다. 기존 완료·건너뛰기 지급 조건과 중복 방지 원칙을 유지한다.
- 이자율·이자 발생 기준·상환 개시일·기한·분할/조기 상환·연체 처리는 미정이다. 무이자·첫 주 상환·자동 차감·담보·압류를 임의 확정하지 않는다. 7일 차 현금 월세 5,000G와 대출 상환은 별개다.
- 계약 화면에는 원금·이자·상환 시기·총상환액을 표시하도록 설계한다. 안나는 절차를 도우며 보증·대납하지 않는다. 거절/보류·스킵·재개 시 계약 확인과 지급/채무 기록의 일관성은 후속 설계 대상이다.
- 기존 저장에 채무를 소급 부과하지 않는다. 추가 대출·예금·적금·은행 월세 자동 이체는 계속 미정이다. 첫 주 생활비·노동 수입·투자 여력과 상환 부담을 함께 검토한다.

장면과 주민 신청 순서는 [튜토리얼](CORE_GDD_10_TutorialSystem.md)을 따른다. 아래 현재 구현 설명은 이 기획의 게임 적용 완료를 뜻하지 않는다.

## 1. 현재 증권사

**2026-10-19 신규 도입 기획:** 안나의 ‘주식 투자하기’를 선택하면 사이퍼 증권에서 K와 투자 자격증 발급부터 진행한다. 주민 등록과 분리한 절차이며 기존 TPT·출입증 연출의 활용·이관은 [등록 명세](CORE_GDD_08_CharacterCreation.md)를 따른다. 이후 거래 기초·첫 매수로 연결한다. 발급 비용·합격 시험·경쟁룸 승리를 새 조건으로 확정하지 않는다. 아래 현재 구현 기록과 구별한다. ✅ 기획 반영 / ⏳ 구현·검수 대기.

로비·트레이닝룸·모의투자 경쟁룸과 에이전트 K 이용 안내를 제공한다. 트레이닝룸의 HTS는 스마트폰과 **같은 게임 계좌**를 사용한다. 거래 수수료 기본값은 증권사 0.01%, 스마트폰·홈 0.15%이며 협상력 보정 후 주문 금액에 반영한다. 장소 이름이 트레이닝룸이어도 무료 가상 자금 계좌라는 뜻이 아니다.

경쟁룸은 **별도 가상 계좌**로 AI 또는 온라인 상대와 겨룬다. 현재 설정은 3/5/10분, 시작 자금 10,000/100,000/1,000,000G다. 배팅은 0G 또는 시작 자금의 1~10% 범위에서 100G 단위로 설정한다. 같은 시작 자금에서 종료 시 총자산으로 순위를 매긴다. 온라인 공동 1위는 가상 풀을 나누며 실제 게임 잔고 지급은 0이다. 기존 24~48시간·실제 참가비 100~5,000G 독식·0.01% 플랫폼 수수료·명성 100/300 지급을 현재 경쟁룸에 적용하지 않는다.

K 이용 안내 뒤 무료 연습은 3분·100,000G·배팅 0G다. 현재 일반 플레이 레벨 20을 경쟁룸 진입 조건으로 두지 않는다. 상층 회원 가입·서밋은 준비 중이며 공매도 해금의 현재 구현은 [성장 명세](CORE_GDD_03_PlayerGrowth.md)를 따른다.

## 2. 현재 월세 정산

현재 메인 목표는 7일 차 현금 5,000G 월세 납부다. 배당·날짜·일회 차감·미납 처리는 [경제 명세](CORE_GDD_07_EconomySim.md)를 따른다. 이 목표를 은행 대출금 상환·월요일 실시간 금융 정산·압류 엔진과 합치지 않는다.

### 기존 구현 상태와 전당포 검토

노드 파이낸스와 바터 전당포는 현재 마을 데이터에서 `available: false`다. 대출·적금·담보 설정·이자 납부·압류 거래는 구현된 이용 흐름이 아니다. 남아 있는 안내 콜백·건물 그림만으로 서비스를 운영 중이라 기록하지 않는다.
