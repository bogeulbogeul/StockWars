# StockWars GDD: [MOD_GDD_18] 세미나 퀴즈 시스템 (Seminar Quiz)

## 주식 계좌 신청 퀴즈 — 2026-10-22 채택 원고

**P1 (Major) · ✅ 완료: 3문항·정답·해설·시작 분석력 배점 채택 / ⏳ 대기: UI·저장 연동·게임 구현·검수.** 사이퍼 증권에서 계좌를 신청할 때 사용하는 시작 테스트다. 아래 반복 찌라시 퀴즈 및 서점 세미나와 구분한다.

주식 용어 암기보다 **수치·조건·출처를 꼼꼼히 읽고 연결하는 능력**을 평가한다. 실제 게임 종목 코지페이(`COZYPAY`)·리프에너지(`ECOBATTERY`)·이음네트웍스(`SCONNECT`)를 사용한다. 다음 지문은 시험용 예시 상황이며 실제 시장 뉴스·계약·시세 이벤트로 적용하지 않는다.

### 진행과 배점

- 총 3문항, 문항별 4지선다·단일 정답이다. 수치 해석 → 조건 비교 → 근거의 한계 판단 순서로 진행한다.
- 정답 0~1개는 **분석력 Lv.1**, 2개는 **Lv.2**, 3개 모두 정답이면 **Lv.3**으로 시작한다. 캐릭터 레벨은 Lv.1로 유지한다.
- 결과와 관계없이 계좌를 개설한다. 오답으로 계좌 개설을 막거나 별도 비용을 부과하지 않는다. 이후 분석력은 플레이 중 퀴즈로 성장한다.
- 최초 제출 결과로 시작 단계를 정하고 같은 시험을 반복해 시작 분석력을 올리는 흐름은 두지 않는다. 제출 단위·중단/재개·정답과 해설 공개 시점·저장 키·기존 이용자 이관은 구현 전 설계한다.
- 읽기 후 일반 퀴즈의 문항 수·보상량 미정 상태를 이 시작 시험의 확정 배점과 혼동하지 않는다.

### 1. 코지페이 — 거래가 늘면 수입도 늘까요?

> 코지페이의 지난달 결제액은 1,000만 잎, 수수료율은 2%였어요.
> 이번 달 결제액은 1,500만 잎으로 늘었지만, 행사로 수수료율을 1%로 낮췄어요.
> 이 문제에서는 결제 수수료 수입만 비교해요.

**이번 달 수수료 수입은 지난달과 비교해 어떻게 달라졌나요?**

① 결제액이 늘었으므로 50% 증가했어요.

② 수수료율이 절반이므로 50% 감소했어요.

③ 20만 잎에서 15만 잎으로, 25% 감소했어요.

④ 결제액 증가와 수수료율 감소가 상쇄되어 같아요.

**정답: ③.** 결제액과 수수료율을 함께 계산해야 해요. 한쪽 수치만으로 수입을 판단할 수 없어요. 검산: 1,000만 × 2% = 20만, 1,500만 × 1% = 15만, 감소율 = 5만 ÷ 20만 = 25%.

### 2. 리프에너지 — 주문을 전부 처리할 수 있을까요?

> 리프에너지는 다음 달 납품할 소재 120상자를 주문받았어요.
> 현재 재고는 20상자이고, 기존 시설은 다음 달 납품일까지 최대 80상자를 생산할 수 있어요.
> 새 시설은 60상자를 추가 생산할 수 있지만, 가동 승인은 아직 나지 않았어요. 다른 공급 방법은 없어요.

**현재 정보로 가장 적절한 판단은 무엇인가요?**

① 주문을 받았으니 120상자 납품이 확정됐어요.

② 기존 시설과 재고만으로는 20상자가 부족해, 전량 납품은 새 시설의 승인과 생산 일정에 달려 있어요.

③ 새 시설의 생산량을 더하면 충분하므로 승인 여부는 중요하지 않아요.

④ 새 시설 승인이 나지 않았으므로 주문 전체가 취소돼요.

**정답: ②.** 현재 확보 가능한 물량과 아직 조건이 붙은 생산 능력을 구분해야 해요. 기존 시설과 재고로는 최대 100상자이며 주문량보다 20상자가 부족해요. 새 시설 승인만으로 납기 내 생산까지 보장되지는 않아요.

### 3. 이음네트웍스 — 같은 소문이 여러 곳에 나오면?

> 게시판 세 곳에 “이음네트웍스가 새 통신망 계약을 따냈다”는 글이 올라왔어요.
> 확인해 보니 세 글 모두 같은 익명 게시물을 옮긴 것이었어요.
> 마을은 “이음네트웍스를 포함한 두 회사와 협의 중”이라고 안내했고, 이음네트웍스는 “현재 확정된 계약은 없다”고 밝혔어요.

**가장 근거가 탄탄한 판단은 무엇인가요?**

① 세 게시판에 올라왔으니 서로 다른 세 곳에서 계약을 확인한 셈이에요.

② 회사가 확정 계약이 없다고 했으니 앞으로도 계약할 가능성은 없어요.

③ 두 회사가 협의 중이므로 계약 가능성은 정확히 50%예요.

④ 게시물 수가 늘어도 독립된 근거가 늘어난 것은 아니며, 현재는 협의 중이라는 사실까지만 확인할 수 있어요.

**정답: ④.** 정보의 개수보다 출처와 확정 범위가 중요해요. 후보가 둘이라는 이유만으로 확률을 계산할 수도 없어요.

## 찌라시 읽기 후 해석 확인 퀴즈 — 2026-10-22 후속 기획

**P1 (Major) · ✅ 완료: 성장 연결·가루 역할 구분 문서 반영 / ⏳ 대기: UI·문항·보상·저장 설계·구현·검수.** 아래 서점 세미나와 독립된 일반 찌라시 읽기 기능이다. 세미나의 참가비·일정·타이머·보상은 가져오지 않는다.

찌라시 읽기를 마친 뒤 퀴즈 UI에서 내용을 이해했는지 확인하고 **분석력 숙련도**를 얻는 흐름으로 설계한다. 캐릭터 레벨 경험치와 분석력 숙련도는 분리한다. 문제는 소문에 적힌 대상·사건·시점·불확실성을 묻고, 소문의 실제 진위나 이후 주가를 맞히게 하지 않는다.

문제와 해설은 플레이어에게 실제 표시된 해석 단계에서 풀 수 있도록 작성한다. 가루로 더 자세히 보이는 경우도 그 표시 내용을 기준으로 하며 숨겨진 상위 단서를 정답으로 요구하지 않는다. 20단계까지 읽었어도 사실 확인이 끝났다는 뜻은 아니다.

**가루는 표시 상품이고 퀴즈는 성장 과정이다.** 가루 사용 자체로 숙련도를 지급하지 않으며, 사용 여부로 퀴즈 보상을 줄이거나 참여를 막지 않는다.

### 제안·미정 사항

- `[해석 확인하기]` 버튼으로 같은 창 아래 퀴즈 카드를 여는 방식은 제안이다. 자동 노출 여부·닫기·나중에 풀기·읽기 완료 판정은 후속 UI 설계에서 정한다.
- 한 장당 1문항·3지선다, 정답 시 숙련도와 해설, 오답 감점 없이 단서 안내·재도전은 제안이다. 문항 수·형식·재도전 보상·정확한 지급량은 미확정이다.
- 한 장당 한 번 보상하는 방향은 제안이다. 같은 사건의 다른 사본·해석 단계 상승·재열람·재접속을 포함한 중복 지급 방지 기준과 저장 키는 구현 전에 정한다.
- 가루 사용 여부와 무관하게 같은 보상 정책을 적용한다. 캐릭터 레벨 보상·투자 수익 보장·새 의뢰나 칭호는 추가하지 않는다.

성장 규칙은 [유저 성장](CORE_GDD_03_PlayerGrowth.md), 단계별 공개 정보는 [찌라시 작성 가이드](RUMOR_AUTHORING_GUIDE.md)를 따른다.

> **2026-10-16 대조 결과:** 현재 서점은 미개방이다. 아래 인용 퀴즈·참가비·주말 보상은 확장 검토안이며 첫 거래 튜토리얼의 시간 단서 연습·K 이용 안내와 별개다. 세미나 시간·보상은 [서점 검토안](MOD_GDD_03_4_Bookstore.md)에서 관리한다. 1시간 내 자유 입장은 무료 참가라는 뜻이 아니다.

## 18.1. 시스템 개요
매주 토요일 14시에 개최되는 '앤티그래비티 세미나'의 핵심 콘텐츠입니다. 유저는 유명 경제/경영 명저의 인용구를 바탕으로 한 퀴즈를 풀며 지식과 보상을 동시에 획득합니다.

### A. 퀴즈 진행 로직
1.  **운영 시간 내 입장 (Open Entry)**: 세미나 개최 시간(1시간) 동안은 언제든 입장 및 퇴장이 가능합니다. 단, 보상은 3문제를 모두 풀었을 때만 지급됩니다.
2.  **3연속 퀴즈 (Triple Quiz)**: 한 번의 세미나 참여 시 총 **3개의 무작위 퀴즈**가 연속으로 출제됩니다.
3.  **시간 제한**: 각 문제당 답변 선택까지 **30초**의 시간 제한이 부여됩니다. (총 90초 소요)
4.  **성공 기준**: 3문제 중 정답 개수에 따라 보상이 차등 지급됩니다. (3/3: 퍼펙트, 2/3: 우수, 1/3: 보통, 0/3: 실패)
5.  **힌트 시스템**: 명성 등급이 높거나 특정 도서를 이미 완독한 경우, 오답 2개를 제거하는 '소피아의 조언' 힌트를 사용할 수 있습니다.

## 18.3. 퀴즈 문제 은행 (Example Pool)

### Q1. [투자 철학] 벤자민 그레이엄
- **인용구**: "투자자는 ( )씨의 기분에 휘둘려서는 안 된다. 그는 매일 아침 당신에게 찾아와 주식 가격을 제시하지만, 그의 조언을 따를 의무는 없다."
- **질문**: 괄호 안에 들어갈 벤자민 그레이엄이 고안한 가상의 인물은?
- **보기**: A. 리스크 씨 / B. 마켓 씨 (Mr. Market) / C. 패닉 씨 / D. 그리드 씨
- **정답**: **B. 마켓 씨 (Mr. Market)**
- **해설**: 시장의 변동성을 감정적인 인물로 묘사하여, 가격에 일희일비하지 말라는 교훈을 줍니다.

### Q2. [경제 이론] 아담 스미스
- **인용구**: "우리가 저녁 식사를 기대할 수 있는 것은 정육점 주인이나 빵집 주인의 ( ) 때문이 아니라, 그들이 자신의 이익을 챙기려는 욕구 때문이다."
- **질문**: 아담 스미스가 국부론에서 강조한, 시장 경제를 움직이는 동력은?
- **보기**: A. 자비심 / B. 애국심 / C. 이기심 (Self-interest) / D. 협동심
- **정답**: **C. 이기심 (Self-interest)**
- **해설**: 개인의 이기적 욕구가 '보이지 않는 손'에 의해 사회 전체의 이익으로 연결된다는 시장 경제의 핵심 원리입니다.

### Q3. [실전 매매] 피터 린치
- **인용구**: "백미러만 보고 운전하면 사고가 나듯, 과거의 ( )만 보고 투자하면 반드시 실패한다."
- **질문**: 전설적인 펀드 매니저 피터 린치가 경계한 투자 태도는?
- **보기**: A. 수익률 / B. 재무제표 / C. 뉴스 / D. 차트 패턴
- **정답**: **A. 수익률**
- **해설**: 과거의 화려한 수익률이 미래의 성공을 보장하지 않으므로, 기업의 펀더멘털을 보라는 조언입니다.

### Q4. [심리학] 모건 하우절
- **인용구**: "돈에 있어서 가장 중요한 기술은 골대를 옮기지 않는 것이다. 즉, ( )을/를 아는 것이다."
- **질문**: '돈의 심리학'에서 강조한, 탐욕을 멈추기 위해 필요한 마음가짐은?
- **보기**: A. 대박 / B. 손절 / C. 충분함 (Enough) / D. 인내
- **정답**: **C. 충분함 (Enough)**
- **해설**: 만족할 줄 모르는 탐욕이 모든 성과를 잃게 할 수 있다는 경고입니다.

### Q5. [투자 철학] 워렌 버핏
- **인용구**: "남들이 ( )할 때 탐욕을 부리고, 남들이 탐욕을 부릴 때 ( )하라."
- **질문**: 가치투자의 대가 워렌 버핏이 강조한 역발상 투자 원칙에 들어갈 단어는?
- **보기**: A. 환호 / B. 두려워 (Fearful) / C. 매수 / D. 외면
- **정답**: **B. 두려워 (Fearful)**
- **해설**: 시장의 공포가 극에 달했을 때가 오히려 기회이며, 모두가 열광할 때가 가장 위험하다는 격언입니다.

### Q6. [매매 심리] 앙드레 코스톨라니
- **인용구**: "투자자는 ( )을/를 가진 사람이어야 한다. 주식을 산 뒤에는 수면제를 먹고 몇 년 동안 푹 자라."
- **질문**: 코스톨라니가 주식 시장의 소음에서 벗어나기 위해 강조한 덕목은?
- **보기**: A. 분석력 / B. 인내심 (Patience) / C. 기민함 / D. 과감함
- **정답**: **B. 인내심 (Patience)**
- **해설**: 단기적인 시세 변동에 흔들리지 말고 자신의 판단을 믿고 기다리는 힘이 수익을 만든다는 뜻입니다.

### Q7. [투자 전략] 존 템플턴
- **인용구**: "투자에서 가장 위험한 네 단어는 바로 '( )'이다."
- **질문**: 강세장과 약세장의 반복 속에서 역사가 반복됨을 망각하게 만드는 이 위험한 문구는?
- **보기**: A. 이번엔 다르다 (This time it's different) / B. 지금이 기회다 / C. 곧 반등한다 / D. 무조건 오른다
- **정답**: **A. 이번엔 다르다 (This time it's different)**

- **UI**: 픽셀 아트 스타일의 고급스러운 양피지 문서 형태의 팝업창.
- **BGM**: 세미나 진행 중에는 긴장감 있으면서도 지적인 느낌의 클래식 음악으로 전환.
- **효과음**: 정답 선택 시 경쾌한 종소리, 오답 시 소피아의 아쉬워하는 말풍선 연출.
