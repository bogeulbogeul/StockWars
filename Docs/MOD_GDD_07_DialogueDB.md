> 개정: 2026-10-16 — 안나·타운 대사와 관리 규칙을 한 문서로 통합.
> 아래 대사는 기획 원고이며 게임 적용 완료 목록이 아니다. 튜토리얼 진행·ID는 [튜토리얼 명세](CORE_GDD_10_TutorialSystem.md), 찌라시 표현은 [작성 가이드](RUMOR_AUTHORING_GUIDE.md)를 우선한다. 구 가구 배치·절세·테마 개수 조건은 [룸 전환](ROOM_PACKAGE_GUIDE.md)에 맞춘 재검토 대상이며 신규 룸 효과로 자동 적용하지 않는다. NPC 외형은 [NPC 레지스트리](MOD_GDD_06_NPCRegistry.md)를 따른다.

## 2026-10-18 소망 요정 초반 대사 기준

**버스 도착 오프닝 후속:** 안내문의 “아직 무엇을 하고 싶은지 몰라도 괜찮습니다.”, 정류장 첫 만남, 안내소 등록·닉네임·TPT·출입증 및 집 안내의 대사는 [튜토리얼 1절](CORE_GDD_10_TutorialSystem.md)을 단일 기준으로 사용한다. 안나는 정착 안내문 작성자이며 씨앗 곁 편지의 작성자로 확정하지 않는다. ‘소망이’는 기획상 이름이고 등록 이후 호칭은 플레이어 닉네임이다. ✅ 원고 기획 반영 / ⏳ 실행 ID·연출·게임 연결 검수 대기.

**✅ 완료: 기획 반영 / ⏳ 대기: 런타임 연결·검수.** 새 초반 장면·대표 대사는 [튜토리얼의 소망 요정 서사](CORE_GDD_10_TutorialSystem.md#4-소망-요정의-첫-일주일--2026-10-18-사용자-채택), 안나의 태도·개인 소망은 [NPC 레지스트리](MOD_GDD_06_NPCRegistry.md)를 단일 기준으로 사용한다. 아래 옛 대사와 충돌하면 새 초반 기획을 우선한다. 이 문서에서 실행 ID나 보상 조건을 임의로 추가하지 않는다. 안나는 손실을 함께 검토하고 휴식을 권하며, 첫 주 관계를 수익률·연애 성립으로 평가하지 않는다.

## 소망이 머리 위 성장 대사 — 2026-10-19 사용자 요청

**P0 (Core) · ✅ 완료: 대사 기획 반영 / ⏳ 대기: 성장 외형·대사 트리거·저장·게임 검수.** [성장 명세](CORE_GDD_03_PlayerGrowth.md)의 Lv.3·7·12·20 외형 전환에 각 한 번의 짧은 대화를 연결한다. 아래 대사는 이 이벤트의 기준 원고이며 실행 ID는 아직 정하지 않는다.

| 도달 레벨·외형 | 소망이 | 안나 | 소망이의 답 |
| :--- | :--- | :--- | :--- |
| Lv.3 · 잎 하나 | “안나, 내 머리에 뭐가 났어!” | “작은 잎이네요. 조금씩 자라고 있었나 봐요.” | “더 자라려나? 자꾸 만져보고 싶어.” |
| Lv.7 · 잎 두 장 | “이번엔 잎이 하나 더 생겼어.” | “처음 잎이 났을 때는 깜짝 놀랐잖아요.” | “응. 이제는 다음 모습이 궁금해.” |
| Lv.12 · 꽃봉오리 | “잎 사이에… 꽃봉오리야?” | “그러네요. 어떤 꽃이 필까요?” | “빨리 보고 싶지만, 조금 더 기다려볼래.” |
| Lv.20 · 개화 | “안나, 봐! 꽃이 피었어!” | “잘 어울려요. 직접 보니까 어때요?” | “좋아. 나한테 이런 꽃이 필 줄은 몰랐어.” |

- 레벨 기준은 그대로 유지하며 수익·월세 납부·가구 구매·특정 주민 퀘스트를 추가 조건으로 삼지 않는다. **2026-10-19 후속:** 화분에 심은 씨앗은 머리 위 외형과 같은 성장 단계로 변한다. [단계 대응·늦은 심기 처리](SPIRIT_CHARACTER_BASELINE.md)를 따르며, 화분 반응 대사는 후속 설계한다. 미구매·미심기 상태에서 이미 화분을 관찰한 것처럼 말하지 않는다. 이 대화로 출생의 비밀·소망의 정체·엔딩을 확정하지 않는다.
- 외형 전환 직후 대화를 예약하고 주문 작업·거래 입력·다른 필수 대화 중에는 끼어들지 않는다. 안나가 현장에 없으면 원격으로 말하거나 순간이동시키지 않고 다음 안나와의 대화에서 반응을 보여주는 방식으로 설계한다. 외형 성장을 안나 만남까지 보류하지 않는다.
- 단계별 대사 완료 상태를 보관해 재접속·재입장마다 반복하지 않는다. 여러 단계를 한 번에 넘기거나 안나를 만나기 전에 추가 성장하면 현재 외형의 최신 대화를 우선하고 이전 외형을 현재처럼 묘사하는 대화를 연달아 재생하지 않는다. 이 경우 Lv.7의 ‘처음 놀랐던’ 대화는 Lv.3 대화를 본 경우에만 사용하고, 미열람 시 안나 “작은 잎 두 장이 나란히 자랐네요.” / 소망이 “다음 모습은 어떨까?”로 대체한다.
- 기존 저장의 첫 로드에서 과거 성장 이벤트를 전부 신규 발생시키지 않는다. 정확한 예약·완료/생략 저장 키·스킵·이관은 구현 전에 설계한다. 대사 보상·추가 능력치·레벨 상한 변경은 없다.

## 공통 관리 규칙

- 용어는 글로벌 사이퍼·선물 지수·시장·증시로 통일한다.
- 안나는 `ANN_`·`BRIEF_`, 튜토리얼은 `TUT_`, 타운은 NPC 이름 기반 ID를 사용한다.
- 기능 조건·금액은 해당 시스템 전문 문서가 기준이다. 대사만으로 보상·해금·경제 규칙을 추가하지 않는다.
- 신규 대사는 아래 해당 절에 추가하고 실제 런타임 연결 여부는 별도로 검증한다.

## 2. 대사 연출 및 우선순위 가이드 (UX & Priority Guide)

### 2.1. 다이얼로그 우선순위 처리 로직
1. **단일 출력**: 한 번에 하나의 대사만 출력하며, 큐(Queue) 내 가장 높은 순위부터 처리합니다.
2. **강제 인터럽트**: P0 등급 상황 발생 시 하위 등급 대사를 즉시 캔슬하고 P0를 출력합니다.
3. **순차 처리**: 동일 등급 대사들은 발생 시점 순서대로 큐에 적재합니다.

### 2.2. 텍스트 및 UI 연동
- **타이핑 효과**: 1글자당 0.05초 딜레이 적용.
- **키워드 강조**: 종목명/수익률/골드 액수는 상승(Cyan), 하락(Red) 색상으로 하이라이팅.
- **초상화 전환**: 대사의 ID/Emotion에 따라 채택된 NPC 초상화(Standard, Happy, Pain, Angry, Smile, Hostile) 연동.

---

## 3. 확장 가능성 (Technical Scalability)
- **멀티어 (Multi-Language)**: 동일 ID에 언어 코드(`KR`, `EN`) 추가로 로컬라이징 대응.
- **랜덤 배리에이션**: 동일 상황에 3개 이상의 대사를 배치하여 반복 지루함 해소.
