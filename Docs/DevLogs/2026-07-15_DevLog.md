# 개발 일지 (Dev Log) - 2026-07-15

## 1. 개요
* **목적**: 주식 거래 화면의 주가 그래프에 그라데이션 채우기 영역과 동적 축 라벨을 더해 고품격 비주얼로 업그레이드하고, 그래프 클릭 시 화면 전체에 더 상세한 차트를 노출해주는 상세 차트 팝업 시스템 구현.

---

## 2. 주요 변경 사항

### A. 차트 하단 그라데이션 채우기 구현 (`UIGradientAreaChart.cs`)
* **기능**: 차트 라인 하단부를 반투명 그라데이션으로 정밀하게 채워주는 커스텀 UI Graphic 컴포넌트 개발.
* **구현 방식**:
  * Unity UI의 `MaskableGraphic`을 상속하여 `OnPopulateMesh` 메서드를 오버라이드.
  * CPU/GPU 성능 최적화를 위해 단일 드로우 콜(Single Draw Call)로 삼각형 메쉬를 구성하여 렌더링.
  * 상단(주가)은 반투명 하늘색(`alpha = 35%`), 하단은 완전 투명(`alpha = 0%`)으로 지정하여 자연스럽게 페이드아웃되는 그라데이션 연출.

### B. 올인원 주식 그래프 컨트롤러 구현 (`UIStockChart.cs`)
* **기능**: 가격 라인 그리기, 영역 그라데이션 채우기(`UIGradientAreaChart`), X/Y축 라벨 업데이트 및 클릭 이벤트 처리를 한 곳에서 일괄 수행하는 통합 매니저.
* **상세**:
  * **Y축 가격 라벨**: 데이터 최솟값과 최댓값을 기준으로 라벨 개수만큼 단계를 균등 분할하여 가격을 표시.
  * **X축 시간 라벨**: 현재 스마트폰 시간(`DateTime.Now`)을 기준으로 과거 간격(분)을 계산하여 실시간으로 dynamic하게 시각 포맷팅.
  * **인터랙션**: `IPointerClickHandler` 인터페이스를 구현하여 차트 영역 클릭 시 `StockMarketAppController`를 경유해 상세 팝업창을 즉각 띄움.

### C. 상세 주식 차트 팝업 개발 (`UIDetailedChartPopup.cs`)
* **기능**: 메인 거래 화면의 그래프를 탭했을 때 활성화되는 오버레이 형식의 대형 상세 차트 팝업.
* **내용**:
  * 종목 로고, 회사명, 주식 코드, 현재가, 실시간 등락률(+/-%) 표시.
  * 내부에 대형 `UIStockChart`를 포함하여 고해상도로 가격 추이를 관찰할 수 있도록 처리.
  * 닫기 버튼 이벤트 바인딩.

### D. 컨트롤러 및 거래 페이지 연동
* **`StockMarketAppController.cs`**:
  * `UIDetailedChartPopup` 멤버 변수 추가 및 `ShowDetailedChartPopup(stockId)` 내비게이션 메서드 작성.
  * 매 초마다 호출되는 `RefreshAppUI` 내부에 상세 차트 팝업이 활성화되어 있을 경우 팝업의 데이터도 실시간 동적 갱신되도록 갱신 주기 연동.
* **`UITradePage.cs`**:
  * 기존의 단순 꺾은선만 그리던 `UIMiniLineChart` 대신 새로 개발된 `UIStockChart`를 필드로 사용하도록 업그레이드.
  * 거래 페이지가 초기화되거나 업데이트될 때 실시간 등락 상태에 맞춰 선 및 그라데이션 채우기의 테마 색상(상승=하늘색, 하락=빨간색)을 자동 동기화.
