# 📝 StockWars 개발 로그 (2026-06-15)

## 📌 1. 개발 요약
* **개발 목표**: 주식 상세 거래 페이지(`Page_Trade`)의 탭 제어 자동화, 수량 조절기 키보드 연동, 자금 초과 시각적 경고 구현 및 종합 지수 Marquee 효과 연동.
* **주요 작업**:
  * 매수/매도 탭 클릭 시 거래창(`Trading Panel`), 정보 탭 클릭 시 호가창(`Info Panel`)이 즉시 반응하도록 상호 전환 로직 구현
  * 수량 조절기(`QtySelector`)를 `TMP_InputField` 기반으로 개편하여 키보드 직접 타이핑 지원 및 무한 이벤트 루프 예방
  * 보유 예수금/주식 초과 시 총액 텍스트 빨간색 변경 및 최종 거래 실행 버튼 비활성화(회색 변조) 안전장치 추가
  * 종합 지수 라벨 한글화(`" 글로벌 사이퍼 지수"`) 및 붉은 띠 틀을 벗어나지 않고 가로로 무한 스크롤되는 `UITickerMarquee` 시스템 구현
  * 최근 조회 목록(최대 3개) 데이터 파이프라인 연동 및 홈 화면 최근 조회 카드 연계 완료

## 🛠️ 2. 주요 구현 사항

### 💻 탭 연동 및 거래창 스위칭 (`UITradePage.cs`)
* **일체형 탭 연동**:
  * 호가창 상세 화면에서 [매수] 또는 [매도] 버튼을 누르면 거래 패널(`TradingPanel`)이 즉시 켜집니다.
  * 거래 패널 상단에 탑재된 [정보] 탭을 클릭하면 거래 패널이 꺼지고, 호가 및 차트를 다시 보여주는 호가 패널(`InfoPanel`)로 매끄럽게 교체됩니다.
* **최종 주문 실행 버튼 컬러 보정**:
  * 기존 상단 탭용 파스텔톤 컬러(`_buyActiveTabColor`)가 하단 대형 버튼에 오적용되어 색상이 탁해 보였던 문제를 해결했습니다.
  * 매수 버튼은 쨍한 코랄 레드(`_buyButtonColor`), 매도 버튼은 도저 블루(`_sellButtonColor`)로 인스펙터 설정값 그대로 올바르게 채색되도록 수정했습니다.

### ⌨️ 수량 조절기 키보드 직접 입력 연동 (`UITradePage.cs`)
* **텍스트 필드 개편**:
  * 기존 단순 텍스트 오브젝트였던 `_qtyText`를 `TMP_InputField` 컴포넌트로 업그레이드했습니다.
  * 클릭하여 원하는 수량을 직접 키보드로 입력할 수 있으며, `+` 및 `-` 버튼을 누를 때에도 입력창 내부 값이 동기화되어 실시간 연동됩니다.
  * 사용자가 키보드로 값을 칠 때 입력 콜백(`onValueChanged`)이 발생하고, 스크립트 내부에서 텍스트를 재보정할 때의 재귀 호출 무한 루프를 막도록 이벤트 리스너 차단 필터를 추가했습니다.

### 🚨 예수금 및 보유량 초과 경고 (안전장치)
* **초과 한도 시각화**:
  * 유저가 수량을 늘려 매수 총액이 가진 자금(`WalletManager.Instance.GetCash()`)을 초과하거나, 매도 수량이 실제 보유 수량보다 많아질 경우, **`총 금액: [수치] G`** 텍스트의 색상이 경고용 **네온 빨간색**으로 즉시 변경됩니다.
* **주문 버튼 비활성화**:
  * 경고 상황 발생 시 하단 매수/매도 주문 버튼이 즉시 비활성화(`interactable = false`)되며, 버튼 배경색 또한 차분한 **회색(Grey)**으로 변해 잘못된 거래 체결을 완벽히 방지합니다. 수량이 정상 범위로 돌아서면 즉각 정상 컬러와 상태로 복구됩니다.

### 📋 최근 조회 목록 연동
* 호가창 상세 진입 시 `RecentViewedStockIds` 리스트의 최상단에 해당 주식 ID를 인서트하고 중복 제거 및 최대 3개로 슬라이싱 처리하여 홈 화면의 "최근 조회 목록" 영역과 실시간으로 연동되도록 작업했습니다.

### 📈 글로벌 사이퍼 지수 한글화 및 무한 스크롤 마키(Marquee) 효과 (`UITickerMarquee.cs`)
* **지수 라벨 한글화**:
  * 메인 상단의 종합 지수 안내 텍스트를 `"Global Cipher Index"`에서 더욱 친숙한 **`" 글로벌 사이퍼 지수"`**로 한글화했습니다.
* **레이아웃 보존형 스크롤 구현**:
  * 기존 앵커/피벗을 직접 변조할 때 발생하던 RectTransform 너비 유실(세로 줄바꿈 현상)과 정렬 이탈 문제를 해결하기 위해, 원래 앵커와 Y좌표 위치를 고스란히 보존하는 `localPosition` 기반 이동 로직으로 변경했습니다.
  * `enableWordWrapping = false` 설정을 연동하여 텍스트가 가로로 아무리 늘어나도 줄바꿈이 되지 않도록 핫픽스했습니다.
* **틀 밖 이탈 차단 (마스킹)**:
  * 지수 텍스트에 `RectMask2D`를 씌우고 실제 흐르는 영역은 런타임에 내부 자식 오브젝트(`ScrollingText_Child`)로 자동 위임하여 복제하는 구조로 고도화했습니다.
  * 붉은색 지수판 띠 배경은 안전하게 제자리에 고정되고, 흐르는 텍스트는 붉은 띠 영역의 좌우 한계를 넘어가면 마스크에 의해 깔끔하게 잘려(Clipped) 보이지 않게 처리되었습니다.
