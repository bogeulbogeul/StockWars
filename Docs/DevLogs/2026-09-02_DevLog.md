## 2. 주요 변경 사항

* C++ 서버에서 1초마다 브로드캐스팅되는 `MarketTick` 패킷을 유니티 전역 이벤트(`OnMarketTickReceived`)로 바인딩.
* 종합 사이퍼 지수, 종목 리스트 카드, 등락률 파스텔 배지, 순자산 평가 그래프가 C++ 서버 틱에 맞춰 실시간으로 반응하도록 구축.

### B. C++ 서버 주식 체결 엔진 구현 (`MarketSimulator.h` / `MarketSimulator.cpp`, `main.cpp`)
* 유니티에서 발송한 JSON 주문 패킷(`BuyOrder`/`SellOrder`)을 C++ 소켓 레벨에서 수신 및 마스킹 해제(`DecodeWebSocketFrame`).
* **동적 런타임 종목 등록 시스템 (Fail-safe)**: GDD 72종 상장 주식 종목 코드(`AURORAAERO`, `VISUALART`, `AQUAENERGY` 등) 주문 수신 시 C++ 서버 메모리에 동적 자동 등록 및 오더북 체결 연산 처리.
* **체결 완료 패킷 발송**: 체결 단가 및 총 비용 연산 후 `OrderResult` JSON 패킷을 해당 클라이언트에 1대1 직렬화 송신.

### C. 유니티 계좌 잔고 및 포트폴리오 자동 정산 (`UITradePage.cs`, `StockWarsNetworkClient.cs`)
* C++ 서버로부터 `OrderResult` 수신 시 `WalletManager`에서 예수금 차감/입금 및 주식 보유 수량을 자동 갱신하고 "1주 매수 체결 완료!" 로그 연출.
