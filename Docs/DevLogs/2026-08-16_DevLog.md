## 2. 주요 변경 사항

### A. Pure C++ WinSock2 / WebSocket 게임 서버 구축 (`Server/StockWars.Server.CPP`)
* **WinSock2 네트워크 아키텍처 (`main.cpp`)**:
  * Windows C++ `ws2_32.lib` 네트워크 라이브러리 초기화 (`WSAStartup`) 및 8080 포트 바인딩 (`bind`, `listen`, `accept`).
  * **RFC 6455 웹소켓 핸드셰이크 엔진**: `Sec-WebSocket-Key` 수신 후 GUID 매직 스트링 결합 ➡️ SHA-1 해시 ➡️ Base64 인코딩 응답을 Pure C++로 직접 연산하여 유니티 소켓 수락 처리.
  * **멀티스레드 세션 관리 (`std::thread`, `std::mutex`)**: 접속 유저마다 독립 스레드 할당 및 스레드 안전 동기화 구현.
  * **C++ 학습용 한글 주석**: 포인터(`*`), 소켓 구조체, SHA1 해시, 스레드 동기화 흐름을 후일 코드 분석 및 네오플 면접 대비가 가능하도록 정성스러운 한글 주석으로 해설.

### B. C++ 주가 변동 시뮬레이터 엔진 (`MarketSimulator.h` / `MarketSimulator.cpp`)
* Modern C++ 난수 생성기(`std::mt19937`) 및 실수 분포(`std::uniform_real_distribution`)를 통한 24개 대표 주식 종목의 1초 주가 틱 파동 연산.
* `std::lock_guard<std::mutex>`를 통해 멀티스레드 자원 보호 적용 및 JSON 패킷 직렬화 구축.

### C. MSVC 컴파일러 빌드 옵션 최적화 (`StockWars.Server.CPP.vcxproj`)
* `/utf-8` 컴파일러 플래그를 추가하여 MSVC(Code Page 949) 환경에서 C++ 한글 주석으로 인한 `C4819`, `C2447` 구문 오류 차단 및 100% 정상 컴파일 환경 달성.
