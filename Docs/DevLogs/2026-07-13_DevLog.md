# 📝 StockWars 개발 로그 (2026-07-13)

## 📌 1. 개발 요약
* **개발 목표**: 홈 화면 내 자산(AccountCard) UI 요소 실시간 정보 한글 연동 및 최근 조회 목록(RecentListScrollView) 가로 스크롤 카드 레이아웃 정교화.
* **주요 작업**:
  * 내 자산 상세 필드(`TotalAssetVal`, `TodayProfitText`, `StockValueText`, `CashValueText`)를 `StockMarketAppController.cs`에 매핑 및 출력 텍스트 한글화("자산 현황", "당일 손익", "주식 평가액", "보유 현금")
  * 자산 카드 하단의 불필요한 실시간 변동 차트(`NetWorthChart`) 자동 생성 로직을 제거하여 깔끔한 텍스트 중심 레이아웃 구현 지원
  * 최근 조회 목록 카드 프리팹(`StockCard_Recent`)의 찌그러짐 현상 해결 및 가로 스크롤 구조 확립 (`Horizontal Layout Group` 내 크기 강제 제어 옵션 제거)
  * 최근 조회 목록 카드 텍스트(회사 이름 등) 잘림 현상 제거를 위한 텍스트 상자 크기(Height) 확보 및 스크롤 뷰 상하 여백 정밀 조정 (`Top = 420`, `Bottom = 60`으로 세로 영역 확장)
  * 주가 등락률의 실시간 요동을 완화하기 위해 비교 대상 틱 간격(`_historyCompareIntervalTicks`, 기본 60틱/1분) 추가 및 등락 절대값/퍼센트 계산 연동
  * 최근 조회 카드의 배경색을 코드 기반 섹터 컬러 지정에서 프리팹 고유 디자인 단색으로 유지하도록 변경

## 🛠️ 2. 주요 구현 사항

### 💳 내 자산 UI 한글 데이터 바인딩 및 차트 분리
* **출력 텍스트 라벨 한글화 (`StockMarketAppController.cs`)**:
  * 플레이어 자산 현황을 보다 직관적이고 친근하게 전달할 수 있도록 출력 포맷을 한국어 라벨로 수정했습니다.
  * `자산 현황: G 5,000`, `보유 현금: G 5,000`, `주식 평가액: G 0` 형식으로 출력되며, 수익과 손실 상태에 따라 글자 색상이 실시간으로 변경됩니다.
* **미니 선형 차트 자동 생성 제거**:
  * 유저의 레이아웃 기획에 맞추어, 기존 코드에서 강제로 차트 오브젝트(`NetWorthChart`)를 생성하여 띄워주던 로직을 지웠습니다. 이제 인스펙터 창에서 차트 항목을 비워두기만 하면 깔끔하게 텍스트 정보로만 자산 카드가 렌더링됩니다.

### 📋 최근 조회 목록 가로 레이아웃 및 카드 정밀화 (`StockCardUI.cs`)
* **가로 스크롤 레이아웃 최적화**:
  * `Content` 오브젝트의 `Horizontal Layout Group`에서 자식 크기 강제 제어(`Control Child Size` / `Child Force Expand`) 옵션을 해제하여, 개별 최근 조회 카드(`StockCard_Recent`)의 고유 디자인 크기(`120 x 170`)가 왜곡 없이 정상 렌더링되도록 픽스했습니다.
* **텍스트 영역 컷오프(잘림) 예방 및 여백 조정**:
  * 회사 이름 텍스트가 줄바꿈되거나 가격 텍스트와 겹치는 현상을 방지하기 위해 텍스트 박스의 세로 크기를 확보하고 자동 줄바꿈 방지 및 폰트 크기 비율을 균형 있게 제안했습니다.
  * 스크롤 뷰 바깥으로 카드가 삐져나가 하단 바와 겹쳐 보이거나 하단부 텍스트가 마스킹에 잘려 보이지 않는 버그를 Rect Transform의 상하 여백을 `Top = 420`, `Bottom = 60`으로 여유롭게 재설정하여 해결했습니다.
* **등락률 틱 단위 변동성 완화**:
  * 매 초마다 지수 및 가격 등락 폭이 불안정하게 변하던 문제를 해결하기 위해, 비교 대상을 60틱(1분) 이전의 과거 가격과 대조하도록 `_historyCompareIntervalTicks` 로직을 추가하여 실시간 가격 흐름의 변동성을 안정적으로 노출시켰습니다.
* **배경색 원래 감성 보존**:
  * 인스펙터에서 섹터별로 덮어씌워지던 파스텔 색상 렌더링을 코드 단에서 완전히 배제하여, 기획에 맞춘 일관성 있는 단색 카드 디자인을 온전히 보존했습니다.
