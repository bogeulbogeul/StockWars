## 🛠️ 2. 주요 구현 사항

### 💻 주식 상세 거래 컨트롤러 (`UITradePage.cs`)
* **매수/매도 모드 스위칭**:
  * 선택 탭에 따라 하단 대형 버튼의 스킨 색상(매수: 빨강/핑크 계열, 매도: 파랑/하늘 계열) 및 텍스트(`BUY △` / `SELL ▽`) 실시간 변경.
* **실시간 계산 수식**:
  * 수량 조절 시 거래 예상 금액에 플레이어 기본 거래 수수료($0.15\%$) 및 영구 능력치 할인율(Fee Discount)을 차감 반영하여 실시간 최종 결제액(`Value`) 도출.
* **5단계 미니 호가창 렌더링**:
  * 현재가 기준 상위 2단계 매도(Ask) 잔량, 하위 2단계 매수(Bid) 잔량을 대칭 정렬하여 출력.
  * 미니 호가창 내 특정 가격 행을 클릭할 시 우측 거래 가격에 클릭한 호가가 즉시 연동되는 편의 기능 추가.
* **거래 트랜잭션 바인딩**:
  * `WalletManager` 잔고 검증을 통해 예수금 부족 시 경고 처리 및 매수 체결.
  * 포트폴리오 데이터 대조 후 보유 물량 부족 시 경고 처리 및 매도 체결.

## 🔍 3. UI 레이아웃 트러블슈팅 및 해결 과정

### 🚨 Issue 1: 가로 정렬 그룹 내 자식 오브젝트의 강제 배치 찌그러짐 현상
* **원인**: 테두리 판인 `QtySelector_Border`가 `QtySelector` 내부 자식으로 혼입되어 가로 정렬 그룹이 테두리 이미지 자체를 정렬 대상으로 판단, 전체 버튼이 왼쪽으로 구겨짐.
* **해결**: 하이러키 구조를 `Border (부모) ➡️ Selector (자식)`로 정상 정렬하고, `Rect Transform`의 앵커 프리셋을 `Alt + Stretch`로 초기화하여 영역을 맞춤.

### 🚨 Issue 2: 버튼 크기 고정 불가 및 강제 가로 확장
* **원인**: `Horizontal Layout Group` 내의 `Child Force Expand (Width)`가 켜져 있어 수동으로 기입한 버튼 크기가 1:1:1로 뭉개짐.
* **해결**: `Width` 강제 확장을 해제하고, 개별 버튼에 `Layout Element`를 부착해 `Min Width`를 `28`로 고정, 중앙 수량창의 `Flexible Width`를 `1`로 주어 가변 영역을 확보.

### 🚨 Issue 3: 개별 라운드 모서리로 인한 틈새(하얀 구멍) 비침
* **원인**: 개별 요소의 둥근 모서리가 만나며 테두리 안쪽에 하얀 빈틈이 생기고, 부모 `Mask` 컴포넌트의 흰색 그래픽이 삐져나옴.
* **해결**:
  1. 부모 `Mask` 컴포넌트의 `Show Mask Graphic` 옵션을 체크 해제하여 투명화 처리.
  2. 내부 자식 버튼과 수량창의 `Source Image`를 `None`으로 비워 완전한 직사각형으로 변경.
  3. 사각형 요소들이 가로 간격 `0`으로 달라붙은 뒤 부모 프레임에 맞춰 바깥 외곽만 매끄럽게 잘려 나가도록(클리핑) 유도하여 해결.
