## 2. 주요 변경 사항

### A. 2D 마을 씬(`TownScene`) 지면 및 경계 제어 카메라 시스템 구축
* **Warm Doodle 그래픽 테마 적용**:
  * 메인 스마트폰 UI와 일체감을 이루는 따뜻한 베이지/크림 톤(`#E8D3B0`)과 다크 브라운 라인아트(`#54311A`) 9-Slice 스프라이트 바닥 구축.
  * 3개 분할 에셋(`ground_left`, `ground_mid`, `ground_right`) 기반의 수평 보도블럭 지면 배치.
* **경계 제한 2D 카메라 컨트롤러 (`TownCameraController.cs`)**:
  * 키보드(`A`/`D`, 방향키) 및 마우스/터치 좌우 드래그 스크롤 기능 구현.
  * **뷰포트 테두리 하드 클램프 (Viewport Edge Clamp)**: 카메라 화면 테두리가 마을 바닥 끝 밖으로 단 1px도 나가지 않도록 `LateUpdate` 물리 하드 락 적용.
  * **보도블럭 자동 경계 감지 (Auto-Detect)**: `TownBlock` 내 보도블럭 스프라이트의 좌/우 끝 픽셀 좌표를 자동으로 측정하여 경계(`MinX`, `MaxX`)를 100% 자동 세팅하는 알고리즘 탑재.
* **유한 패럴랙스 배경 (`BoundedParallaxBackground.cs`)**:
  * 카메라 이동에 맞춰 원경/중경 레이어가 시차(Parallax)를 두고 움직이다, 마을 양끝 도달 시 배경도 부드럽게 맞춰 정지하는 기능 탑재.

### B. C# .NET 8/9 웹소켓 서버 구축 (`Server/StockWars.Server`)
* **서버 아키텍처 및 통신 환경**:
  * `Server/StockWars.Server/` 위치에 C# .NET 8/9 콘솔 서버 프로젝트 구축.
  * 초경량 고성능 웹소켓 라이브러리(`Fleck`)를 도입하여 `ws://127.0.0.1:8080` 포트 기반 실시간 소켓 리스너 시작.
* **1초 실시간 주가 틱 시뮬레이터 (`MarketSimulator.cs`)**:
  * GDD 규격 대표 주식 종목들의 랜덤 워크 변동성 알고리즘을 1초마다 연산.
  * 접속된 모든 유니티 클라이언트에게 1초마다 실시간 주가 변동 패킷(`MarketTick`)을 일괄 브로드캐스팅(Broadcast)하는 엔진 탑재.

### C. 유니티 실시간 네트워크 클라이언트 연동 (`StockWarsNetworkClient.cs`)
* **네트워크 클라이언트 스크립트 작성**:
  * C# 내장 `ClientWebSocket`을 활용하여 `ws://127.0.0.1:8080` C# 서버 접속 처리.
  * 윈도우 환경에서 `localhost` 주소가 IPv6(`::1`)로 우회 접속 실패하는 현상을 강제 IPv4(`127.0.0.1`)로 보정하는 안전장치 적용.
* **실시간 틱 파싱 및 전역 이벤트 시스템**:
  * 서버에서 1초마다 수신되는 주가 틱 JSON 패킷을 파싱하여 콘솔에 틱 데이터를 표시하고, `OnMarketTickReceived` 전역 이벤트를 파이어하여 인게임 UI 및 차트와 연동 가능한 구조 완성.

### D. GDD 기술 명세서 업데이트 (`CORE_GDD_06_TechnicalSpec.md`)
