# 예전 루머 원고 보관 — 2026-10-25

**P1 (Major) · ✅ 완료: 과거 원고 분리·현행 인덱스 정리.**

일반 업종별 8개와 IPO 업종별 8개 원고를 현행 원고에서 제외하고 보관한다. 당시 인덱스 2개도 함께 보존한다. 옛 회사명·이전 별칭·Tier 1~3·가림·확정 수익 표현은 제작 이력이며 신규 제작에 직접 사용하지 않는다. 일부 회사명이 갱신되어 있어도 문서 전체가 현행 채택 원고라는 뜻은 아니다. 원문은 보관 경고와 이동에 필요한 상대 링크 보정 외에는 유지했다.

현재 기준은 [작성 가이드](../../RUMOR_AUTHORING_GUIDE.md)의 분석력·해석 1~10단계와 수수께끼에서 정보 추리로 이어지는 방향이다. 사건 아이디어를 재사용할 때는 현재 종목 ID·이름과 주장·근거·남은 조건을 검토하고 새 원고로 집필한다. 이번 이동은 게임 원고 삭제나 신규 원고 채택을 뜻하지 않는다.

[현재 게임 데이터 CSV](../../Data/Rumors.csv)와 웹 런타임·저장은 유지한다. 현재 게임 5단계 구현과 10단계 기획은 구분한다.
