## 2026-10-25 최신 채택 — 분석력·찌라시 10단계

**P1 (Major) · ✅ 완료: 기획 문서 반영 / ⏳ 대기: 원고·데이터·게임 구현·저장 이관·검수.** 분석력은 **Lv.1~10**, 찌라시 해석은 **1~10단계**로 줄인다. 기존 20단계 기획과 아래 과거 표기보다 이번 채택을 우선한다. **1~3단계 수수께끼 → 4~6단계 사건·핵심 조건 → 7~10단계 출처·경쟁·시점·정보의 한계**로 이어지며, [작성 원칙과 10단계 예시](../../RUMOR_AUTHORING_GUIDE.md)를 따른다. 최대 해석도 진위·수익을 보장하지 않는다.

별가루는 지정 한 건 +1(최대 10)·500잎, 달가루는 지정 한 건 10단계·2,000잎이다. 플레이어 분석력 자체와 다른 찌라시는 바꾸지 않는다. 읽기 후 표시된 내용으로 푸는 퀴즈 성장·가루 사용 여부에 따른 보상 차등 없음은 유지한다. 시작 테스트의 Lv.1~3 배점과 캐릭터 레벨 상한 Lv.20도 유지한다. 현재 게임 해석 상한은 5단계이며 기존 저장·본문을 자동 환산하지 않는다. 성장 속도·숙련도 요구량·이관은 후속 설계한다. 아래 날짜별 기록의 수치는 이 최신 채택 기준으로 갱신하거나 과거 이력으로 구분한다.

> **2026-10-22 회사명 갱신:** 현재 72종과 대응되는 회사명은 [새 이름 대응표](../../STOCK_NAMES_2026-10-22.md)를 반영했다. 아래 확장·과거 원고의 채택 및 구현 상태는 바뀌지 않으며, 괄호의 영문명은 이전 별칭이다. 미매핑 예비 종목은 이름 변경 대상에서 제외한다.

## 04-0. 유니버설 찌라시 시스템 통합 가이드
본 문서는 StockWars의 활성 거래 상장 종목들에 대한 찌라시 명세서로 연결되는 통합 인덱스입니다.

### 기존 5단계 작성 기준 (2026-10-06 이력)

사용자 결정에 따라 문자 가림을 폐기하고 **읽을 수 있는 수수께끼 → 업종과 흐름 → 사건·방향 → 기업과 근거 → 상세 정보**의 해석 5단계로 작성한다. [작성 가이드](../../RUMOR_AUTHORING_GUIDE.md)와 [현재 25종·125개 본문 CSV](../../Data/Rumors.csv)를 기존 5단계 구현 기준으로 사용한다. 하위 섹터 문서의 Tier 1~3은 과거 소재이며, 아래 가림 비율은 이전 규칙으로 보존한다. 희귀도는 해석 단계와 별도이며 해독기는 선택한 찌라시 한 건의 유지 해석 단계를 1 올린다.

### 현재 5단계 구현 데이터와 확장 원고

현재 지급·본문·희귀도·열람 가치는 [작성 가이드](../../RUMOR_AUTHORING_GUIDE.md)와 [데이터 CSV](../../Data/Rumors.csv)를 따른다. 해석은 5단계이며 해독기는 선택한 한 건의 유지 단계를 +1 올린다. Tier 1~3·가림률·5% 오보 자동 추첨은 아래 원고를 그대로 실행하는 규칙이 아니다. 물류 지급 확률은 [노동 명세](../../MOD_GDD_02_LaborJobs.md)를 따른다.

아래 섹터 파일은 이전 소재이며 현재 보상 전체 목록이 아니다. IPO·상장폐지 연동 시 문서 자동 이동/삭제를 구현 조건으로 요구하지 않는다.
