수수께끼로 관심을 끌고 정보 추리로 투자 판단을 이어간다. 1~3단계는 비유에서 업종·기업 후보를 좁히고, 4~6단계는 사건과 핵심 조건을 이해하며, 7~10단계는 출처·경쟁·시점·정보의 한계를 살핀다. 단계마다 의미 있는 단서가 더 명확해져야 하며 문장만 바꾸거나 같은 내용을 반복해 단계를 채우지 않는다.

각 원문은 주장·근거·남은 조건을 갖춘다. 낮은 단계에도 위험과 조건의 단서를 남기고 핵심 조건은 중간 단계까지 드러낸다. 상위 단계에서 기존 단서를 뒤집거나 미확인 전언을 확정 사실로 바꾸지 않는다. 높은 해석은 원문을 자세히 이해하는 능력이며 진위 판정이나 매수 정답이 아니다. 무료 뉴스·마을 관찰과 비교해 투자·관망을 판단할 여지를 남긴다.

## 해석 1~10단계 — 2026-10-25 후속 채택

**P1 (Major) · ✅ 완료: 10단계 확장 기획 반영 / ⏳ 대기: 단계별 원고·데이터 확장·게임 구현·저장 이관·검수.** 아래 5단계 표와 데이터 설명은 기존 구현 이력이다. 신규 제작은 해석 1~10단계를 기준으로 하며 5단계를 두 번씩 반복해 10단계로 표시하지 않는다.

- 분석력은 플레이어의 능력이고 해석 단계는 개별 찌라시를 읽는 상세 수준이다. 분석력 Lv.1~10에 대응하여 기본 해석도 1~10단계로 설계한다. 난도별로 5단계에 대응시키던 제안은 적용하지 않는다.
- 표시 단계는 분석력과 해당 찌라시에 유지된 해석 단계 중 높은 값을 사용하고 1~10으로 제한한다.
- 별가루는 지정한 찌라시 한 건의 해석을 +1단계, 최대 10단계까지 올려 유지한다. 달가루는 지정한 한 건을 즉시 10단계로 만들어 유지한다. 둘 다 플레이어 분석력이나 다른 찌라시는 바꾸지 않는다.
- 1단계에도 추리 가능한 단서를 남기고, 단계가 오를 때마다 비유의 의미·대상·사건·시점·근거 등 원문에 있는 정보가 더 구체적으로 읽히도록 작성한다. 10단계는 원문의 상세 내용을 모두 읽는 상태다. 정확한 단계별 공개 항목과 본문은 후속 집필·검수 대상이다.
- 모든 단계는 같은 사건을 설명하며 기존 단서와 모순되지 않아야 한다. 높은 단계에 새 사건·없는 수치·확정 수익을 덧붙이지 않는다. 10단계도 정보의 진위를 보증하지 않는다.
- 기존 5단계 원고·CSV·JS 데이터·저장을 보존한다. 기존 유지 단계와 유료 찌라시 기본 단계의 이관은 후속 설계하며 단순 배수 환산을 확정하지 않는다. 10단계 데이터 형식과 런타임 연동도 구현 전 정한다.

## 읽기·표시와 분석력 성장의 분리 — 2026-10-22

분석력은 기본적으로 보이는 해석 단계이고, 별가루·달가루는 **지정한 찌라시가 보이는 상세 수준만 변경**한다. 가루 사용 자체로 분석력 숙련도나 캐릭터 경험치를 올리지 않는다. 캐릭터 레벨과 분석력은 독립적으로 성장하며, 분석력의 성장 경로는 읽기 후 해석 확인 퀴즈다.

퀴즈는 실제 표시된 단계의 내용으로 풀 수 있어야 한다. 가루 사용 여부로 참여를 막거나 보상을 차등 지급하지 않는다. **사건당 1문항·정답 숙련도 +1·재도전 동일 보상·사건당 한 번 지급**을 채택한다. UI 노출 방식과 단계별 문항·저장 설계는 [퀴즈 설계](MOD_GDD_18_QuizSystem.md), 시작 테스트와 성장 분리는 [성장 명세](CORE_GDD_03_PlayerGrowth.md)를 따른다. 문서 반영과 실제 퀴즈 구현 완료를 구분한다.

## 기준 데이터 (기존 구현)

[Rumors.csv](Data/Rumors.csv)는 현재 웹 데모에 적용된 25개 사건과 해석 단계별 본문 125개를 정리한 CSV다. 한 행은 한 사건이다. 같은 종목의 호재와 악재는 별도 RumorId를 갖는다. 유료 찌라시는 구매 시 종목이 정해지는 동적 공급 계약 정보이므로 고정 25종 목록에 포함하지 않는다.

기존 문서에 기재된 `Assets/Data/Resources/Rumors.csv`는 계획 경로이며 실제 파일은 없었다. 현행 CSV 경로는 `Docs/Data/Rumors.csv`다. 웹 런타임은 아직 JS 데이터를 읽으며 CSV를 직접 읽지 않는다. `RuntimeStatus=ImplementedText`는 본문과 보상 추첨에 적용되었다는 의미다. 해당 사건의 시세 이벤트 연동이나 신뢰도 추첨까지 구현됐다는 의미가 아니다.

## 기존 구현의 해석 5단계 (이력)

| 단계 | 작성 기준 | 제공하는 단서 |
|---|---|---|

| 2 | 업종을 밝히고 기업·방향은 간접 표현한다 | 업종과 대략적인 흐름 |

모든 단계는 완전한 문장으로 읽힌다. `[REDACTED]`, 검은 박스, 글자 흐림, 단어 삭제로 본문을 채우지 않는다. 낮은 단계에서도 추리할 단서는 남긴다. 사건·방향·시점은 단계가 올라가도 동일해야 하며 다른 사건으로 바꾸지 않는다. 수치가 없는 원문에 임의의 목표가나 시각을 추가하지 않는다. 소문 속 과장과 실제 게임 효과를 구분한다.

제목·인벤토리 설명·효과·툴팁·검색·알림도 현재 공개 단계에 맞춰 제공한다. 낮은 단계 본문 밖에 종목명이나 수익률·매수 전략을 정답으로 노출하지 않는다.

## 희귀도와 해독기

**2026-10-22 달가루 후속 채택:** 달가루는 사용자가 지정한 찌라시 한 건의 유지 해석 단계를 **10단계**로 올리고 해당 정보에 유지한다. 플레이어 분석력·경험치와 다른 찌라시는 바꾸지 않으며 진위도 보증하지 않는다. 별가루의 한 건 +1과 구분한다. [상품 상세](MOD_GDD_03_1_VivianStore.md)를 따르며 10단계 원고 제작·게임 구현·검수는 대기다.

**2026-10-19 후속 기획:** 암호 해독기를 **별가루**로 재디자인한다. 찌라시에 뿌려 해석을 돕고 가루가 묻어 종이가 더러워지므로 매각 가치가 떨어지는 설정이다. 유지 해석 단계 +1·분석력과 진위 불변 계약은 유지하며, 최신 후속 기획의 상한은 10단계다(기존 구현 상한 5). 아래 첫 열람 50% 감가는 현재 구현 기록이다. 가루 사용 감가의 시점·수치·누적 여부와 첫 열람 감가의 관계는 별도 설계하며 중복 차감이나 기존 저장 변경을 자동 적용하지 않는다. [상품 기획](MOD_GDD_03_1_VivianStore.md)을 따른다. **P1 (Major) · ✅ 기획 반영 / ⏳ 세부 설계·제작·구현·검수 대기.**

아이템 희귀도와 해석 단계는 별도 값이다. 높은 희귀도를 확정 수익·큰 폭등·높은 해석 단계로 자동 연결하지 않는다. 현재 밸런스는 다음과 같다.

| 희귀도 | 종류 수 | 등급 획득 확률 | 미열람 기본 매각 가치 |
|---|---:|---:|---:|
| 일반 | 10 | 50% | 500G |
| 고급 | 8 | 28% | 1,200G |
| 희귀 | 4 | 15% | 2,000G |
| 영웅 | 2 | 6% | 6,000G |
| 전설 | 1 | 1% | 15,000G |

찌라시 보상을 받았을 때 등급을 먼저 추첨하고 해당 등급에서 사건을 균등 추첨한다. 물류의 찌라시 지급 확률과 야간 2배는 이 추첨 이전에 적용된다. 첫 열람 시 매각 가치는 절반으로 떨어진다. 기존 보관함에 저장된 아이템의 가격·희귀도는 소급 변경하지 않는다. 유료 상품의 구매 가격 2,000G는 별도다. 일반은 이미 퍼지는 정황, 고급은 발표 전 근거, 영웅은 더 이른 제보, 전설은 사건 연결과 반전 조건을 담는다. 시세 이벤트를 추가로 발생시키는 기능은 이번 데이터 밸런스 작업 범위에 포함하지 않는다.

CSV의 BasePrice는 미열람 기본 매각 가치, RarityWeight는 등급 전체의 추첨 가중치다. RarityWeight를 각 사건의 확률로 더하면 안 된다. 현재 코드의 가격은 거래 매대의 실제 판매 가격과 구분한다.

기존 5단계 구현 기록: 암호 해독기 1개는 선택한 열람 찌라시 한 건의 해석 단계를 1 올리고 해당 정보에 유지한다. 최대 5단계이며 분석력 자체와 진위를 바꾸지 않는다. 실제 표시 단계는 분석력과 해당 찌라시의 유지 단계 중 높은 값을 사용한다. 유료 찌라시의 기본 유지 단계는 3이다. 종전의 해독률 50%는 문자 가림 비율로 표시하지 않는다.

완전 해석은 진위 보증이 아니다. 기획의 전략적 오보 5%와 현재 런타임의 실제 구현 여부를 구분한다. 문장에 경고가 있다고 신뢰도 시스템이 구현된 것으로 기록하지 않는다.

## CSV 열

RumorId는 사건 식별자, StockId는 종목 식별자다. StockName·Sector·Type·Rarity·Timeframe·ExpectedChange는 제작용 메타데이터이며 낮은 해석 단계의 UI에 그대로 노출하지 않는다. Level1Text~Level5Text는 단계별 본문이다. RuntimeStatus와 Source는 적용 범위와 원본 코드 위치를 기록한다. UTF-8 BOM, 표준 CSV 인용 규칙으로 저장한다.

기존 `MOD_GDD_04_1`~`04_8`, `MOD_GDD_19_1`~`19_8`의 Tier 1~3 문장은 원본 소재로 보존한다. 기존의 10배·상한가 확정·무조건 매수 같은 표현을 확정된 수익 조건으로 옮기지 않는다. 추가 사건은 최신 1~10단계 기준으로 집필한다. 기존 CSV의 5개 본문 열만으로 신규 10단계 제작·적용이 완료되었다고 기록하지 않는다.
