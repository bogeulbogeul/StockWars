# 가구 제작 기본 기준 — 소망이 크기

2026-10-21 사용자 채택. **P1 (Major) · ✅ 완료: 공통 제작 기준 문서화 / ⏳ 대기: 개별 가구 치수 확정·제작/보정·게임 접촉 검수.**

## 1. 공통 원칙과 적용 범위

**모든 가구는 소망이의 크기를 기준으로 제작한다.** 집·시설 실내·개인 마을·공용 만남 광장의 가구, 판매용·운영용·장식용 가구, 독립 모델과 룸에 통합된 가구에 동일하게 적용한다. 사람의 실물 가구 치수나 방의 빈 공간만 보고 크기를 정하지 않는다.

소망이가 자연스럽게 앉고, 손을 뻗고, 앞뒤로 지나갈 수 있는 비율을 우선한다. 시설별 디자인·재질·용도는 유지하되 서로 다른 제작본을 한 장면에 놓았을 때 크기 기준이 일치해야 한다. NPC가 사용하는 가구도 소망이 기준을 공유하고 해당 NPC의 접촉을 추가로 확인한다.

## 2. 기준 캐릭터와 단위

- 최신 채택 소망이 모델과 모션은 [소망이 제작 기준](SPIRIT_CHARACTER_BASELINE.md)을 따른다. 과거 동물 캐릭터·사람 체형·이전 2D 픽셀 높이를 새 3D 가구의 크기 기준으로 사용하지 않는다.
- 동일한 기본 서 있는 자세에서 발바닥 접지면부터 머리 본체 상단까지의 높이를 비교 기준 `H`로 기록한다. 머리 위 성장 장식은 신체 높이와 분리해 기록하고 가림·상부 여유 검수에 포함한다.
- 제작 장면에서는 기준 캐릭터를 `H=1.0`으로 정규화해 가구 치수를 `H`에 대한 비율로 기록한다. 모델 원본 전체 높이·장식 포함 바운딩 박스와 이 신체 기준을 혼동하지 않는다.
- 기준 모델 경로·버전·측정 자세·측정 범위·원본 높이·제작 배율·게임 변환 배율을 함께 남긴다. 모션마다 캐릭터를 다시 확대/축소하지 않는다.
- 현재 게임의 `SOMANGI_HEIGHT / 1.95` 변환과 은행·펍의 임시 비교 단위는 기존 구현/검수 기록이다. 이를 모든 룸의 확정 단위로 간주하지 않으며 실제 측정 기준과 대응을 확인한다.

## 3. 가구별 확인 항목

| 종류 | 소망이 기준으로 맞출 항목 |
| --- | --- |
| 의자·스툴·소파·벤치 | 좌판 높이·깊이·폭, 앉은 엉덩이와 좌판 접촉, 발 위치, 등받이·팔걸이 간섭, 착석 진입/이탈 공간 |
| 책상·테이블·창구·카운터 | 서기/앉기 용도에 맞는 상판 높이, 손이 닿는 범위, 하부 무릎·발 공간, 의자와의 간격 |
| 침대·휴식 가구 | 누운 몸의 길이·폭, 매트리스 접촉 높이, 머리·발 여유, 오르내리는 공간 |
| 수납장·선반·금고·진열대 | 몸 대비 전체 크기, 손잡이·사용 지점 높이, 문/서랍 동작 공간, 앞쪽 이용 공간 |
| 야외 가구·그 밖의 가구 | 용도에 맞는 접촉 위치, 몸·팔·머리 장식의 여유, 통행 폭과 인접 가구 간격 |

높은 선반이나 큰 금고처럼 의도적으로 큰 가구도 소망이와 나란히 비교한다. 직접 사용하는 지점과 장식·보관 영역을 구분한다. 좌판·상판 높이 등의 공통 숫자는 이번 문서에서 임의 확정하지 않고 실제 자세 비교로 정한다.

## 4. 제작과 검수 순서

1. 가구를 만들기 전에 최신 기준 소망이를 같은 바닥·같은 단위의 제작 장면에 놓는다.
2. 정면·측면에서 전체 비율과 사용 지점을 맞추고, 실제 룸 시점에서도 크기와 가독성을 확인한다.
3. 용도에 맞는 걷기·착석·눕기·손 동작으로 접촉을 확인한다. 대응 모션이 없으면 해당 항목을 대기로 기록한다.
4. 가구 앞뒤·모서리·가구 사이에서 이동, 충돌, 가림과 출입 동선을 확인한다. 필요한 좁은 통로는 게걸음 자세도 확인한다.
5. 게임에 적용한 배율에서도 같은 비율과 접촉이 유지되는지 확인한다. 정적 비교 렌더와 실제 게임 검수 결과를 각각 기록한다.

가구별 제작 기록에는 **기준 소망이 파일/자세·H 측정값·가구 폭/깊이/높이와 H 대비 비율·좌판/상판/사용 지점 높이·배율·비교 이미지·접촉 검수 상태**를 남긴다. 캐릭터를 작게 만들거나 룸 전체를 비균일 변형해 부적절한 가구 크기를 숨기지 않는다.

## 5. 기존 제작본과 관련 문서

기존 가구도 이후 수정·재배치·게임 적용 시 이 기준으로 확인한다. 이번 문서 작성만으로 기존 모델·배치·저장·보유권을 변경하거나 검수 완료로 기록하지 않는다. 크기 보정이 필요하면 기존 원본을 보존하고 수정본과 변경 치수를 기록한다.

룸 구성·지정 위치 배치·상호작용은 [룸 제작 명세](ROOM_PACKAGE_GUIDE.md), 외형과 재질은 [아트 가이드](ART_STYLE_GUIDE.md)를 함께 따른다. 과거 임시 치수나 2D 높이 기록보다 이 문서의 소망이 기준 원칙을 우선한다.
