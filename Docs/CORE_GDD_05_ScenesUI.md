# StockWars GDD: CORE_GDD_05. 씬 기획 및 UI/UX 인터페이스 (Scenes & UI)

## 생활 진행에 따른 UI 순차 공개 — 2026-10-21 사용자 채택

처음부터 생활·금융 UI를 모두 보여주지 않고 소망이가 실제로 도구와 자격을 얻을 때 공개한다. 안내자는 **모아(이전 이름 안나)**이며 은행 담당자는 차곡, 투자 안내자는 토리다. 아래 기존 HUD·스마트폰 전체 노출 및 도입 순서와 충돌하면 이번 기준을 우선한다.

| 진행 상태 | 새로 공개하는 UI·기능 | 계속 숨기는 항목 |
| :--- | :--- | :--- |
| 마을 도착·도입 시작 | 대화·선택지·이동/상호작용 등 현재 장면에 필요한 최소 안내 | 휴대폰 호출 UI·앱 화면·보유 잎·자산·주식앱 |
| 모아가 휴대폰을 건네고 수령 완료 | 휴대폰 호출 UI와 사용 가능한 생활 기능 | 은행 계좌 개설 전 보유 잎, 투자 자격증 발급 전 자산·주식앱 |
| 노드 은행에서 차곡과 계좌 개설 완료 | 보유 잎 잔액 표시·조회 | 투자 자격증 발급 전 자산 표시·주식앱 |
| 개인 마을 사이퍼 증권에서 토리에게 투자 자격증 발급 완료 | 자산 표시와 주식앱 진입·사용 | 별도 조건이 있는 후속 기능은 기존 조건 유지 |

잠긴 항목은 비활성 아이콘·물음표·0잎 같은 자리표시자를 상시 나열하지 않고 숨긴다. 휴대폰 안에서도 자격증 전 주식앱은 표시하지 않는다. HUD·단축키·다른 메뉴의 우회 진입에도 같은 조건을 적용한다. 잔액은 보유 잎, 자산은 투자 보유분을 포함한 자산 정보로 구분하며 자산의 계산식·채무 반영 방식은 기존 금융/경제의 미정 상태를 유지한다.

은행 계좌 개설은 잔액 UI 공개 계기이고 정착 대출 계약·지급은 별도 상태다. 계좌를 만들었다는 이유로 자금을 추가 지급하지 않는다. UI를 숨기는 동안에도 실제 잔액·자산은 그대로 보존하고 표시값을 0으로 덮어쓰지 않는다. 날짜·시각·하트·미니맵 등 나머지 HUD의 개별 공개 시점은 후속 설계하며 초기 일괄 노출을 확정하지 않는다. 필수 대화·이동 안내와 설정 접근을 막는 연출로 사용하지 않는다.

휴대폰 수령·계좌 개설·자격증 발급 완료 상태를 각각 저장하고 재접속 때 복원한다. 대화창을 열거나 건물에 들어간 것만으로 해금하지 않으며 완료 직후 해당 UI를 공개한다. 기존 저장·전체 스킵의 상태 이관은 별도로 설계하고 미해금으로 인한 영구 진행 차단·중복 지급을 방지한다. 단순 잔액 보유·매수 기록만으로 세 상태를 일괄 추정하지 않는다.

**P0 (Core) · ✅ 완료: 공개 조건·기획 반영 / ⏳ 대기: UI·진입 제한·저장·스킵/기존 저장 이관 구현·게임 검수.** [튜토리얼 동선](CORE_GDD_10_TutorialSystem.md)·[금융 절차](CORE_GDD_04_FinancialInstitutions.md)를 따른다.

## 화폐 표시 단위 — 2026-10-21 사용자 확정

화폐는 **잎**으로 표시한다. 가격·잔고·자산·주가·보수·월세·대출·보상 안내에서 `300잎`, `5,000잎` 표기를 사용한다. `G`, `Gold`, `골드`는 현행 표시명으로 사용하지 않는다. 숫자·계산·저장 값은 그대로 유지하며 퍼센트·수량·경험치 단위는 변경하지 않는다. [경제 표기 기준](CORE_GDD_07_EconomySim.md)을 따른다. **P1 (Major) · ✅ 문서 반영 / ⏳ 게임 UI·대사 적용·검수 대기.**

2026-10-19 최신 폐기: **타이틀 화면·개발자 모드·비트 물류창고와 박씨 물류 노동을 폐기**한다. 물류 미니게임·직원 휴게실·퀵패스 판매/사용·물류 의뢰·개발자 테스트 친구/선물·강제 성장 조작을 게임에서 제거한다. 과거 제작 에셋·저장 보유 기록은 보존하며 재도입 근거로 사용하지 않는다. 현재 UI 비표시 마을 진입은 유지한다. 일반 UI에서는 저장된 게임 자동 진입 또는 신규 등록으로 연결하며 새 도입 연출은 후속 구현이다. 폐기된 물류 및 보상 전제 안내는 건너뛰고 자립 안내로 연결하며, 비비안 포장 퍼즐·첫 찌라시·회복 안내의 새 구현 완료를 의미하지 않는다. **P0 (Core) · ✅ 코드·기획 폐기 반영 / ⏳ 새 잡화점 노동·도입 구현.**


## 상점 3D·인벤토리 2D 아이템 표시 — 2026-10-19

**P1 (Major) · ✅ 완료: 기획 반영 / ⏳ 대기: 에셋·상세 UI·구현·검수.** 상점 UI의 아이템은 3D로 보여주고, 인벤토리에서는 같은 아이템을 간결한 2D 아이콘으로 표시한다.

- 상점에서는 상품의 입체적인 형태와 특징을 확인할 수 있게 한다. 가격·효과·보유 여부 등 구매 정보는 읽기 쉬운 UI로 함께 제공한다. 회전·확대 조작, 목록과 상세 보기의 구성, 렌더링 방식은 후속 설계다.
- 인벤토리에서는 작은 크기에서도 식별 가능한 2D 아이콘과 수량·선택 상태를 표시한다. 색·실루엣·대표 표식을 상점의 3D 외형과 일치시킨다.
- 동일 아이템 ID에 상점용 3D 표현과 인벤토리용 2D 표현을 연결한다. 두 표현이 별도 상품·보유권으로 나뉘지 않으며 구매·사용·저장 계약은 공유한다.
- 아이콘 제작 방식·크기·파일 형식은 후속 검증으로 정한다. 이 결정은 기존 2D 상품 포장 퍼즐의 표현 방식을 변경하지 않는다.

## 2. 핵심 씬 구성 (Main Scenes)

### 2.0. 장소별 시점 및 그래픽 기준 (2026-09-28)
- **마을은 RPG식 탑다운, 홈 오피스와 일반 건물 내부는 아이소메트릭**으로 구성한다.
- 마을은 건물 정면과 지붕이 함께 보이고 길은 화면 가로·세로를 중심으로 구성한다. 실내는 바닥의 두 축이 화면 대각선으로 보이며 가구 상판·앞면과 이동 통로를 읽기 쉽게 구성한다. 투영 각도·타일 비율은 후속 검증한다.
- 실내외 캐릭터·가구의 상대 크기를 조율하고 화면 방향에 대응하는 이동 입력을 검증한다. 동일 캐릭터 그림·시트의 공유 가능 여부와 추가 방향별 그림·모션 필요 여부는 검증 후 정한다. 마을의 가로로 긴 동선은 가능하되 횡스크롤 전용 시점은 사용하지 않는다.
- 장소의 개성은 배치·색감·공간 크기로 표현한다. 픽셀아트는 필수 조건이 아니다. 현행 동물 캐릭터 기준은 [아트 가이드](ART_STYLE_GUIDE.md)와 [시트 명세](DOG_SPRITE_BASELINE.md)를 따르고, 채택 시트 또는 임시 에셋으로 마을 → 집 입구 → 홈 오피스 책상 → 마을 복귀 → 대표 건물 내부의 시점 전환·이동·출입구·가림을 먼저 검증한다.
- 검증 시작안: 실내 고정 시점, 문 진입 시 짧은 화면 전환, 앞쪽 벽 생략. 전환 방식·시간과 높은 가구·벽의 가림 처리는 검증 후 확정한다.
- 제작 기준: [아트 가이드](ART_STYLE_GUIDE.md). 전환 상태와 검증: [전환 계획](VISUAL_TRANSITION_PLAN.md).

### 2.1. 홈 오피스 (Home Office)
- **기능**: 안나와의 소통, 찌라시 분석, 완성형 테마 룸 선택·고정 가구 상호작용, **편의 매매(0.15% 수수료)**.
- **특징**: 유저의 성장이 가장 시각적으로 드러나는 공간.

홈과 일반 건물 내부는 [완성형 룸 명세](ROOM_PACKAGE_GUIDE.md)에 따라 배경·필요한 가림 레이어·HTML/CSS 동적 요소·상호작용 지점을 묶어 구성한다. 화면 표시와 클릭 영역은 같은 룸 좌표 변환을 사용한다. 전광판 데이터·시설 이용 판정은 게임 로직에서 처리하며 장식 효과는 이동 입력을 가로채지 않는다.

### 2.2. 사이퍼 증권 (Cipher Securities)
- **주요 구역**:
    - **트레이딩 플로어 (Public)**: 유저들이 모여 실시간으로 매매하고 정보를 나누는 로비. 대형 디지털 전광판과 공유 터미널 배치.
    - **아레나 룸 (Competitive)**: 방 코드를 통해 입장하는 단기 수익률 경쟁 공간.
    - **서밋 라운지 (Private)**: 레벨 20 이상 전용. 공매도 및 거액 운용 전용 밀실.
- **시각 연출**: 벽면을 가득 채운 주가 티커, 바쁘게 움직이는 유저 아바타들, 개장 시 울리는 경쾌한 종소리.
- **특징**: 전문 트레이더로서의 현장감과 다른 유저와의 경쟁심을 동시에 자극하는 허브 공간.

### 2.3. 타운 (The Town)
- **주요 시설**:
    - **금융/거래**: 노드 파이낸스(은행), 사이퍼 증권(증권사).
    - **상점/보급**: 비비안 잡화점(잡화), 데이터 잉크(서점·미개방), 살롱 드 테일(스타일 공간), 모던 프레임(룸 상점 기획·미개방).
    - **정보/노동**: 비비안 잡화점 주문 노동(구현 대기). 미드나잇 펍은 미개방·재도입 미정.
- **운영 정책**: 동적 채널링 시스템을 통해 구역당 최대 50명의 유저를 수용하며, 쾌적한 커뮤니티 환경을 유지함.

## 3. UI/UX 시각 체계

### 3.1. 색상 및 톤 (Color Palette)
- **상승**: Cyan (#00EAFF) - 사이버틱한 희망과 활력.
- **하락**: Red (#FF4B4B) - 긴박한 위기와 리스크.
- **금융 UI**: 짙은 그레이/블랙 바탕의 정보 패널을 사용할 수 있으나 숫자와 차트 가독성을 우선한다. 글자·차트에 픽셀 표현을 강제하지 않는다. 이 색상 규칙은 월드 배경 전체를 네온 스타일로 바꾸는 규칙이 아니며, 월드는 아트 가이드의 장소별 시점·깔끔함·가독성을 따르며 최종 화풍은 후속 결정한다.

### 3.2. 스마트폰 및 알림
- **Memo 앱**: 현재 준비 중이다. 찌라시·독서 로그 자동 보존이 구현된 것으로 기록하지 않는다.
- **Bubble 앱**: 친구·DM·선물함을 제공한다. 금융권 긴급 채널·안나 선물·모든 아이템 우편의 통합은 확장안이다. 아이템 센터 우편은 별도다.
- **푸시 알림**: 마진콜 90% 도달, 블랙 스완 전조 발생 시 즉시 노출.

## 4. 특수 연출 (Atmospheric FX)

### 4.1. 글리치 및 노이즈 (Glitch)
- 시장 위기, 정보 해독 실패, 적색 수배 시 UI 전체에 도트 노이즈 및 화면 떨림 효과 적용.

### 4.2. 블랙 스완 연출
- 오피스 메인 전광판에 오류 메시지가 가득 차고, 비상 붉은 조명이 점멸하며 안나의 표정이 'Pain'으로 고정됨.
