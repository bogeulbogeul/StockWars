# StockWars 교수님 회의용 변경 사항 요약

**2026년 10월 25일 · 기존 기획 및 이전 구현과 현재 개발 방향 비교**

StockWars는 투자 시뮬레이션에 마을 생활을 결합해 왔다. 최근에는 **고정 주인공 소망이의 정착 이야기, 부담이 적은 생활 활동, 정보의 출처를 읽고 판단하는 투자 경험**을 중심으로 방향을 구체화했다. 첫날 전시 체험과 주요 외형 변경, 회사별 찌라시 확장은 게임에 반영했으며, 생활 단서가 며칠에 걸친 투자 판단으로 이어지는 7일 구성은 앞으로 연결할 범위다.

비교 기준은 최근 변경 전의 문서와 구현 기록이다. ‘기존’에는 과거 기획도 포함하며, 교수님께 마지막으로 시연한 특정 버전과의 비교는 아니다.

## 1. 주요 변경 사항 한눈에 보기

| 꾸미기 | 캐릭터 외형·의상 선택을 포함 | 집의 룸 테마·벽·바닥·지정 위치 가구에 집중 | ✅ 의상 기능 제거 / ⏳ 집꾸미기 확장 |

| 정보와 수익 | 구형 소식 봉투의 고정 ‘24시간 뒤 +8%’ 보고서 | 새 봉투는 확정 수익·주가 이벤트를 생성하지 않음 | ✅ 신규 봉투 변경, 기존 보유 보고서는 보존 |

| 데모 목표 | 7일 데모 기획 및 기존 일반 모드 | 현재는 첫날 전시를 제공하고, 생활 단서 중심 7일 체험을 별도로 설계 | ✅ 첫날 / ⏳ 새 7일 구성 |

✅ 완료는 해당 구현·반영 범위를 뜻한다. 최종 사용자 플레이 검수와 설치 프로그램 재배포 완료를 뜻하지 않는다.

## 2. 변경의 중심은 플레이 경험의 연결

### 캐릭터 선택에서 소망이의 정착 이야기로

기존에는 여러 동물 외형과 스타일을 고르는 방향이 있었지만, 현재는 소망이를 고정 주인공으로 삼는다. 외형 선택 대신 마을에 도착해 주민을 만나고 생활을 시작하는 경험에 집중한다. 꾸미기의 중심은 집으로 옮겼으며, 의상 커스텀·스킨 판매·옷가게는 제작 범위에서 제외했다.

**현재 반영:** 소망이의 3D 모델·걷기·먹기·표정 14종, 등록 외형 선택과 의상 착용 기능 제거. 모아도 기본형 모델·표정 14종·잎 기분 모션 5종을 정류장과 안내소에 적용했다.

**앞으로 할 일:** 집꾸미기 선택 범위 확장과 장면별 캐릭터 동작·접촉·가림 마감. 모아의 자율 이동·앉기·졸기 몸 모션은 미구현이다.

### 물류 운반에서 부담이 적은 포장 퍼즐로

기존 물류창고 노동을 제거하고, 잡화점에서 상품을 상자에 빈틈없이 담는 활동으로 바꿨다. 필요한 상품을 미리 제공하고 회전·시간제한·화남 게이지를 두지 않아 공간 배치에 집중하게 한다.

**현재 반영:** 20개 패턴 중 5상자를 완성하는 퍼즐, 첫날 활동 연결, 전시 보수·봉투 전달. 포장과 투자 중 먼저 체험할 활동을 선택해도 두 활동을 모두 완료한다.

**앞으로 할 일:** 반복 노동의 보상 균형과 생활 중 관찰한 단서가 투자 판단으로 이어지는 연결. 전시 알바 보수 500잎은 임시값이다.

### 정보량 확대와 확정 수익 안내의 축소

기존 25종·5단계 원고에서 **72개 회사마다 호재 2개·악재 2개, 총 288개 사건·2,880개 본문**으로 신규 지급 콘텐츠를 확장했다. 새로운 찌라시는 10단계로 읽으며, 별가루는 한 건 +1단계, 달가루는 한 건 10단계로 해석한다.

**현재 반영:** 새 보상·잡화점 소식 봉투에 회사별 원고를 연결했다. 1~3단계에는 회사명을 숨기고 4단계부터 공개한다. UI가 호재·악재 분류나 예상 수익률·매수 정답을 자동 표시하지 않는다. 10단계로 읽어도 진위나 수익은 보장하지 않는다.

**앞으로 할 일:** 후속 뉴스·사건 전개와 투자 판단을 연결하고 분석력의 퀴즈 숙련도 성장을 개편한다. 새 사건의 실제 주가 효과·발표 예약·진위 추첨은 아직 연결하지 않았다. 기존 보유 25종은 5단계 자료로 보존하며 단순히 10단계로 환산하지 않는다.

## 4. 현재 시연할 수 있는 범위와 다음 목표

### ✅ 완료 현재 첫날 전시

타이틀·버스 도착 → 모아와 첫 만남 → 마을 소개·입주 → 휴대폰·계좌·정착 대출 → 포장 알바와 투자 체험 → 찌라시 안내 → 지원금·일기장 → 화분·씨앗 → 첫 기록·취침 → 종료

두 활동 순서의 브라우저 완주와 저장 재개·중복 지급 방지 검증 기록이 있다. 투자 체험은 전시 계좌의 고정 표시 가격으로 진행한다. 첫날의 회사별 콘텐츠 확장이 곧 실시간 사건·시세 연동 완료를 뜻하지는 않는다.

전시 전체는 안내형 대화·장면 전환 중심이며, 자유 보행·NPC 추적·접촉 연출 전체를 완성한 상태는 아니다. 씨앗 심기는 화면 연출, 취침은 서술·암전으로 구현했다.

### 🔄 진행중 생활 단서를 투자 판단으로 연결하는 기획

**7일 데모와 7일 차 현금 월세 2,000잎은 채택한 조건**이다. 구체적인 사건·일별 구성은 다음과 같은 미채택 제안이다.

| 제안 사례 | 플레이어가 비교할 내용 | 의도하는 경험 |
|---|---|---|
| 밀리베이커리 주문 증가 | 주문량뿐 아니라 원재료 가격·할인 조건 확인 | 많이 팔리는 것과 이익이 늘어나는 것을 구분 |
| 코지페이 소문 확산 | 여러 주민의 말이 같은 익명 글에서 시작됐는지 확인 | 반복해서 들은 말과 독립된 확인을 구분 |
| 월세와 투자 선택 | 현금·보유 주식·생활비를 함께 확인 | 수익 기대와 생활 유지 사이에서 선택 |

현재의 차이는 ‘생활과 투자 입문을 한 흐름으로 연결했다’는 점이다. 다음 목표는 ‘생활에서 얻은 근거로 투자하거나 관망하고, 이후 결과를 돌아본다’는 반복 구조를 완성하는 것이다.

## 5. 다음 개발 우선순위와 교수님께 논의할 사항

| 우선순위 | 앞으로 할 작업 | 완료를 판단할 기준 |
|---|---|---|
| P0 Core | 7일 사건·일별 체험 구성 확정 | 첫날 이후 정보·선택·후속 확인이 연결됨 |
| P0 Core | 경제·거래·날짜·저장·월세 정산 통합 | 선택이 달라도 7일 정산·종료까지 진행 가능 |
| P1 Major | 정보 해석 성장·집꾸미기·공간 상호작용 보완 | 성장과 생활 변화가 실제 플레이에 반영됨 |
| P2 Polish Post | 관람자 체험·화면·배포 마감 | 설치·재실행·저장·완주 검수 완료 |

위 구현 작업은 **⏳ 대기**이며, 첫날 이후 사건 구성은 **🔄 기획 검토중**이다. 정착 대출 5,000잎·지원금 2,000잎은 첫날에 반영했지만, 이자·상환 일정·정식 거래 수수료율은 후속 설계 대상이다. 전시의 화분 100잎·첫 매수 수수료 0잎도 임시값이다.

**오늘 확인받고 싶은 질문**

1. 고정 주인공·정착 이야기·포장 노동으로 좁힌 방향이 기존보다 명확하게 전달되는가?
2. 다음 개발을 새 기능 추가보다 생활 단서와 투자 판단의 연결에 집중하는 것이 적절한가?
3. 전시에서 변경 효과를 보여주려면 어떤 장면과 판단 사례를 우선 시연해야 하는가?
