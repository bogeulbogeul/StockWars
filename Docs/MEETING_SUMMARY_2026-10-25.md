# StockWars 교수님 회의용 개발 요약

**회의일 2026년 10월 25일 · 현재 개발 결과와 향후 계획**

StockWars는 작은 요정 소망이가 포포리 마을에 정착해 노동과 투자, 주민과의 교류를 경험하는 생활형 투자 게임이다. 현재는 **마을 도착부터 첫 투자·포장 알바·첫날 취침까지 연결한 전시 데모**가 구현되어 있다. 다음 개발의 중심은 **생활에서 얻은 단서를 비교하고 투자 판단에 활용하는 7일 체험**이며, 구체적인 일별 구성은 검토 중인 기획안이다.

## 1. 기획 의도와 핵심 경험

금융 정보를 숫자와 거래 화면으로만 접하는 대신, 마을의 일상과 연결해 이해하도록 한다. 플레이어는 일을 해서 생활비를 마련하고, 주민의 말과 뉴스의 출처를 비교하며 돈의 사용을 결정한다. 투자 수익뿐 아니라 정착과 관계, 집꾸미기를 통해 생활의 변화를 느끼는 방향이다.

**목표 플레이 흐름**

마을 생활·노동 → 단서 발견 → 다른 출처와 비교 → 투자 또는 관망 → 결과 확인·회고 → 다음 생활의 선택

현재 데모에는 생활과 투자 각각의 입문 체험이 연결되어 있다. 생활 단서가 며칠에 걸친 투자 판단과 결과로 이어지는 반복 구조는 앞으로 구현할 범위다.

| 구분 | 현재 채택한 방향 |
|---|---|
| 주인공·배경 | 고정 외형의 소망 요정, 포포리 마을 정착 이야기 |
| 화면 | 3D 캐릭터·건물이 있는 마을과 실내 |
| 생활 활동 | 잡화점 포장 퍼즐, 주민과 대화, 집꾸미기 중심 |
| 투자 경험 | 첫 거래 학습, 정보 해석, 생활비를 고려한 선택 |
| 목표 데모 범위 | 게임 내 7일, 7일 차 현금 월세 2,000잎 |

프로젝트 이름은 전시까지 **StockWars**를 유지한다. 「소망 한 줌」은 이름 변경 후보이며 확정 이름이 아니다.

## 2. 현재 구현된 첫날 데모

**✅ 완료 — 웹 전시 흐름 구현 및 기존 검증 기록 확인**

타이틀·버스 도착 → 모아와 첫 만남 → 마을 소개·입주 신청 → 휴대폰·생활 계좌·정착 대출 → 집 방문 → 포장 알바와 투자 체험 → 찌라시 안내·주민 교류 → 정착 지원금·일기장 → 화분 구매·씨앗 심기 → 첫 기록·취침 → 체험 종료

| 항목 | 현재 체험할 수 있는 내용 | 구현 범위 |
|---|---|---|
| 진행·선택 | 포장 먼저 / 투자 먼저를 선택하고 두 활동을 모두 체험 | 안내형 대화·장면 전환 중심 |
| 포장 알바 | 상품을 드래그해 상자에 빈틈없이 배치 | 20개 패턴 중 5상자, 회전·시간제한 없음 |
| 투자 입문 | 정보 읽기 3문항, 회사 소개·가격 확인, 현물 1주 매수·내역 확인 | 전시 전용 계좌와 고정 표시 가격 |
| 정보·UI | 휴대폰·잔액·주식앱의 단계적 공개, 첫 찌라시 설명 | 일반 시장과 연결된 사건 전개는 별도 개발 |
| 첫날 마무리 | 화분 구매·씨앗 심기·첫 기록·취침 | 씨앗 심기는 화면 연출, 취침은 서술·암전 |
| 저장 | 진행 위치·활동·계좌·거래·획득 상태 복원 | 전시 회차 저장, 다음 방문자 초기화 |

현재 기본 실행은 **Day 1 취침에서 끝난다.** 기존 일반 모드는 별도로 보존되어 있지만, 이를 새로운 7일 체험의 완성으로 집계하지 않는다. 전시 전체의 자유 보행·NPC 추적·접촉 연출, 실제 3D 씨앗 심기·눕기 모션은 미완료다.

### 전시에서 사용하는 경제 수치

| 구분 | 수치 | 상태 |
|---|---|---|
| 정착 대출 | 원금 5,000잎 | 채택 기획, 첫날 전시 반영 |
| 정착 지원금 | 2,000잎 | 대출과 별도로 첫날 전시 지급 |
| 첫 월세 | 7일 차 현금 2,000잎 | 목표 7일 데모의 채택 조건 |
| 알바 보수·화분·첫 매수 수수료 | 500잎·100잎·0잎 | **전시용 임시값**, 장기 경제 확정값 아님 |

대출 이자·상환 일정과 공통 거래 수수료율은 후속 설계 대상이다. 전시에서는 미정인 이자를 청구하지 않는다.

## 3. 캐릭터와 공간의 개발 결과

**✅ 완료 — 아래 에셋의 웹 및 기존 로컬 실행본 리소스 반영**

| 대상 | 적용 결과 | 남은 확인 |
|---|---|---|
| 소망이 | 마을·실내 모델, 걷기·먹기, 표정 14종 | 사용자 최종 외형·플레이 검수, 앉기 등 추가 행동 |
| 모아 | 조끼 없는 크림색 몸·초록 잎, 표정 14종·잎 기분 모션 5종, 정류장·안내소 대화 연결 | 사용자 최종 검수, 자율 이동·앉기·졸기 몸 모션 미구현 |
| 집 | 문·창·지붕 외관과 오른쪽 우체통 적용 | 우체통 수신 기능은 미구현 |
| 정착 안내소 | 초록 박공지붕·현관·목재 기둥·패널 문 적용 | 최종 시각·실제 출입 플레이 검수 |
| 잡화점·증권사·서점 | 최신 채택 외관과 문·지붕 접합 마감 반영 | 건물별 최종 시각·실제 출입 플레이 검수 |

토리·봉봉의 3D 캐릭터는 아직 복원하지 않았다. 대사·기능 유지와 캐릭터 모델 적용은 구분한다.

## 4. 앞으로 구현할 핵심 계획

### P0 Core 7일 플레이 연결

**🔄 진행중 — 7일 범위는 채택, 생활 단서 중심 일별 구성은 기획안 검토 단계**

첫날 이후에도 생활·정보·투자·회고가 이어지도록 설계한다. 아래 일별 구성과 사건은 **미채택 제안**이며 아직 게임에 구현하지 않았다.

| 구간 | 제안하는 체험 | 개발할 내용 |
|---|---|---|
| Day 1 | 정착과 첫 투자·포장 알바 | 기존 첫날 체험에 생활 단서 연결 |
| Day 2~3 | 주문 증가와 원가 상승을 함께 관찰 | 주문 메모·주민 대화·뉴스·시세 연결 |
| Day 4 | 소문의 반복과 독립된 확인을 구분 | 출처 비교·자료 해석·판단 수정 |
| Day 5~6 | 월세와 투자에 쓸 돈을 함께 고려 | 생활비 표시·후속 뉴스·선택 기록 |
| Day 7 | 월세 정산과 판단 돌아보기 | 현금·주식 평가액·부채 구분, 회고·종료 |

**사건 제안 예시:** 밀리베이커리의 주문이 늘어도 원재료 가격과 할인 조건에 따라 이익은 달라질 수 있다. 코지페이 소문이 여러 곳에서 들려도 같은 익명 글의 재인용일 수 있다. 이를 통해 ‘좋은 소식이 곧 수익 보장은 아니다’와 ‘여러 번 들은 말도 출처 확인이 필요하다’를 체험하게 한다.

후속 거래는 매수·매도·보유·관망을 선택할 수 있도록 제안한다. 수익률 최고 기록이나 특정 종목의 정답 맞히기를 완주 조건으로 두지 않는 방향이다.

### P0 Core 경제와 저장 검증

**⏳ 대기**

- 전시 임시 보수·가격과 정식 7일 경제 수치를 조정한다.
- 노동·소비·거래 선택에 따른 월세 납부 가능성과 정산 처리를 확인한다.
- 날짜 전환, 거래·지급 중복 방지, 저장 복원, 데모 종료를 하나의 체험으로 검증한다.

### P1 Major 정보 해석과 생활 확장

**⏳ 대기**

- 분석력 Lv.1~10과 찌라시 해석 10단계 기획을 원고·데이터·게임에 연결한다. 현재 해석 구현 상한은 5단계다.
- 집꾸미기는 룸 테마·호환 벽과 바닥·지정 위치 가구·장식을 선택하는 방향으로 확장한다. 자유 배치·회전은 도입하지 않는다.
- 장면 이동·출입·대화 가림·캐릭터 접촉과 실제 플레이 흐름을 다듬는다.

### P2 Polish Post 전시 마감

**⏳ 대기**

실제 관람자의 체험 시간과 막히는 지점을 확인하고 화면 가독성·연출을 조정한다. 최종 배포 설치 프로그램을 다시 만들고 설치·실행·저장·완주를 검수한다.

의상 커스텀·스킨 판매·옷가게, 서브 퀘스트·칭호, 물류 노동·개발자 모드는 현재 제작 범위에서 제외한다.

## 5. 검증 현황과 오늘 논의할 사항

| 구분 | 확인된 범위 | 남은 범위 |
|---|---|---|
| 첫날 흐름 | 두 활동 순서의 브라우저 완주, 저장 재개·중복 방지·작은 화면 검사 기록 | 사용자 최종 체험·이해도·체험 시간 |
| 캐릭터 | 표시·표정·걷기·먹기·대화 연결 등 대상별 검사 기록 | 외형 만족도·수동 플레이 접촉 검수 |
| 변경 건물 | 웹·기존 실행본의 모델 동기화, 로딩·배율·충돌·입구 앞 통로 검사 기록 | 실제 수동 출입·전체 장면 시각 검수 |
| 배포 | 기존 로컬 실행본의 관련 리소스 갱신 | 설치 프로그램 재빌드·최종 배포본 전체 검수 |

검증 표는 기존 작업 기록을 요약한 것이며 이번 문서 작성 중 테스트를 다시 실행한 결과는 아니다.

**교수님께 확인받을 핵심 질문**

1. 생활에서 얻은 단서를 비교해 투자하는 구조가 게임의 중심 재미로 충분히 전달되는가?
2. 7일 데모는 기능을 추가하기보다 주 사건 1개와 비교 사건 1개를 끝까지 연결하는 범위가 적절한가?
3. 전시에서는 생활의 정서적 경험과 정보 판단 과정 중 어느 쪽을 더 강조하는 것이 좋은가?

다음 개발 우선순위 제안은 **7일 사건 구성 확정 → 경제·저장 연결 → 관람자 완주 검수 → 배포 마감**이다.
