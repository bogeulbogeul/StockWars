# StockWars 기획 기능 변경 비교

**교수님 회의용 · 2026년 10월 25일**

**변경의 중심은 선택할 기능을 늘리는 것에서, 마을에 정착하고 일하며 정보를 읽고 판단하는 경험을 연결하는 것으로 옮겨갔다.**

비교 기준은 문서에 남은 이전 기획·구현이다. 과거 기획이 모두 구현됐다는 의미는 아니며, 교수님께 마지막으로 시연한 특정 빌드와의 비교는 아니다.

## 1. 이전과 현재의 기획 기능 비교

| 기능 | 이전 기획·방식 | 현재 기획·방식 | 플레이 경험의 차이 | 현재 상태 |
|---|---|---|---|---|
| 주인공과 목표 | 동물 캐릭터·스타일 선택 기획 | **고정 주인공 소망이의 마을 정착** | 외형 선택보다 주민 관계와 생활의 흐름에 집중 | ✅ 주인공 적용·외형 선택 제거·첫날 연결 |
| 꾸미기 | 의상·스킨 등 캐릭터 외형 선택 포함 | **집꾸미기 중심**: 룸 테마·호환 벽/바닥·지정 위치 가구·장식 | 자기 취향을 생활 공간에 반영 | ✅ 의상·옷가게 제거 / ⏳ 집꾸미기 확장 |
| 노동 | 물류창고의 운반 노동 | **잡화점 포장 퍼즐**: 제공된 상품으로 상자를 빈틈없이 채움 | 운반 대신 공간 조합에 집중, 회전·시간제한·화남 게이지 없음 | ✅ 퍼즐·첫날 연결 |
| 첫날 구성 | 등록·투자·노동을 안내하는 기존 튜토리얼 | **도착→입주→포장·투자→씨앗·첫 기록→취침** | 기능을 배우는 과정이 하루의 정착 이야기로 이어짐 | ✅ 첫날 전시 구현 |
| 활동 순서 | 기존 튜토리얼의 안내 흐름 | **포장 먼저 / 투자 먼저 선택**, 두 활동 모두 체험 | 체험 순서를 선택하되 필수 학습은 동일 | ✅ 두 분기 연결·검증 기록 |
| 능력치 성장 | 레벨업 포인트와 여러 능력치 배분 | **분석력은 해석 확인 퀴즈로 독립 성장**, 포인트 배분 종료 | 배분 선택 대신 읽은 내용을 이해하는 행동으로 성장 | ✅ 개편 적용 |
| 정보 콘텐츠 | 기존 25종 사건·5단계 원고 | **72개 회사·288개 사건**, 사건마다 5단계 본문 | 더 다양한 회사·사건의 조건과 정보 한계를 읽음 | ✅ 신규 지급·판매 반영 |
| 이해도 확인 | 기존 열람·해독 흐름 | **실제 읽은 단계의 퀴즈 1문항**, 해설·재도전 제공 | 읽은 내용의 근거를 확인하며 학습 | ✅ 단계별 총 1,440문항 적용 |
| 성장 보상 | 포인트 배분·구형 해독 횟수 직접 성장 경로 | **사건별 최초 정답 숙련도 +1**, 분석력 Lv.1~5 | 같은 소문의 사본 반복보다 다른 사건을 이해하는 데 의미 부여 | ✅ 중복 지급 방지·성장 연결 |
| 정보와 수익 | 구형 소식 봉투의 고정 ‘24시간 뒤 +8%’ 보고서 | **신규 봉투에 확정 주가·수익을 연결하지 않음** | 자세히 읽는 것과 수익 보장을 구분 | ✅ 신규 봉투 변경, 기존 보유 보고서 보존 |
| 생활비 부담 | 7일 차 첫 월세 5,000잎 | **7일 차 첫 월세 2,000잎** | 첫 주에 마련해야 하는 현금 부담 감소 | ✅ 기존 정산 흐름 반영 / ⏳ 새 7일 생활과 통합 검수 |
| 선택 활동의 범위 | NPC 의뢰·서브 퀘스트·칭호 등 | **관련 기능 폐기**, 생활·노동·투자·집꾸미기에 집중 | 수락·보상·칭호 수집보다 핵심 활동에 집중 | ✅ 제거 반영 |

✅ 완료는 해당 기능의 반영 범위이며 최종 사용자 플레이 검수·전체 배포 완료와 구분한다.

## 2. 성장과 정보 판단은 어떻게 달라졌나

**현재 구현된 흐름**

찌라시 획득 → 현재 해석 단계의 본문 읽기 → 해석 확인 퀴즈 → 근거·해설 확인 → 최초 정답 숙련도 획득 → 분석력 상승 → 더 높은 단계의 정보 읽기

| 규칙 | 현재 방식 |
|---|---|
| 분석력과 해석 | 분석력 Lv.1~5와 기본 해석 1~5가 일대일 대응 |
| 정답 보상 | 사건별 최초 정답에 숙련도 +1 |
| 오답 | 감점 없이 해설 확인·재도전, 재도전 정답도 같은 보상 |
| 반복 제한 | 같은 사건의 다른 사본·다른 단계·재구매로 보상 추가 획득 불가 |
| 성장량 | 다음 승급에 20·30·40·60개, Lv.1부터 최대까지 누적 정답 150개 |
| 가루 | 선택한 찌라시의 해석을 높이는 수단, 영구 분석력 자체는 올리지 않음 |
| 캐릭터 레벨 | 분석력과 별도로 유지, 캐릭터 상한 Lv.20 |

**기획상 의미:** 정보를 많이 보유하는 것뿐 아니라, 읽은 정보의 조건·출처·현재 상태를 이해하는 행동에 성장 보상을 준다. 퀴즈의 정답은 본문 해석이며 미래 주가나 매수 정답이 아니다.

## 3. 현재 완성한 연결과 앞으로 만들 연결

| 구분 | 플레이 흐름 | 상태 |
|---|---|---|
| 첫날 정착 | 도착·입주·계좌 → 포장과 첫 투자 → 지원금·씨앗·첫 기록·취침 | ✅ 첫날 전시 구현 |
| 정보 학습 | 찌라시 → 본문 이해 퀴즈 → 분석력 성장 → 해석 확장 | ✅ 신규 사건에 적용 |
| 생활과 투자 | 마을에서 단서 발견 → 다른 출처 비교 → 매수·매도·보유·관망 → 후속 소식·결과 확인 → 회고 | 🔄 구체적 7일 사건 구성 검토 / ⏳ 통합 구현 |
| 생활 공간 | 노동·투자·소비 선택 → 집꾸미기로 생활 변화 표현 | ⏳ 집꾸미기 확장·경제 연결 |

현재 기본 전시는 **첫날 취침에서 끝난다.** 기존 일반 모드의 7일 차 정산·종료 처리가 존재하는 것과, 새로운 생활 단서 중심 7일 플레이가 완성된 것은 구분한다.

### 다음 단계의 사건 제안

아래는 아직 채택되지 않은 7일 구성 제안이다.

| 사례 | 플레이어가 판단할 내용 | 체험 목표 |
|---|---|---|
| 밀리베이커리 주문 증가 | 주문은 늘었지만 재료비·할인 조건도 함께 확인해야 하는가? | 주문량·매출·이익·주가를 구분 |
| 코지페이 소문 확산 | 여러 곳의 이야기가 실제로는 같은 익명 글의 재인용인가? | 반복 노출과 독립된 확인을 구분 |
| 월세와 투자 | 투자 기대가 있어도 생활비를 현금으로 남겨야 하는가? | 수익 기대와 생활 유지 사이의 선택 |

신규 찌라시 콘텐츠 적용은 완료했지만, 해당 사건의 발표 시점·후속 뉴스·실제 주가 효과·회고까지 자동 연결한 상태는 아니다.

## 4. 유지하는 것과 줄인 것

| 구분 | 기획 범위 |
|---|---|
| 유지 | 첫 투자·정보 해석·회복·자립, 노동, 집꾸미기 방향, 7일 데모·월세 목표 |
| 변경 | 고정 주인공, 포장 노동, 퀴즈 기반 분석력 성장, 월세 인하 |
| 제거 | 의상·스킨 선택/판매·옷가게, 물류 노동, 서브 퀘스트·칭호, 능력치 포인트 배분 |
| 추가 연결 예정 | 생활 단서·출처 비교·투자 선택·후속 확인·회고의 7일 반복 구조 |

**경제 조건:** 정착 대출 원금 5,000잎과 별도 지원금 2,000잎은 유지한다. 첫날 전시의 알바 보수 500잎·화분 100잎·첫 매수 수수료 0잎은 임시값이다. 대출 이자·상환 일정·정식 공통 거래 수수료율과 반복 노동 균형은 후속 설계 대상이다.

**전시 운영:** 현재 첫날 진행은 실행 중에만 유지하고 새로고침·종료 시 초기화한다. 일반 게임의 저장·기존 보유 기록과 전용 설정 저장은 별도다.
