## 최신 전당포 범위 — 2026-10-18 사용자 채택

전당포는 초기 마을에서 제외한다. 아래 비활성 시설·담보·처분 설명은 기존 구현 및 이전 검토 기록이며 초기 제작 요구가 아니다. 은행 대출·상점 되팔기/매입은 미정으로 유지하고 전당포의 기능을 다른 시설에 자동 이관하지 않는다. 바터를 수집가·벼룩시장 상인으로 바꾸는 아이디어는 후보이며 역할·시설·일정을 채택한 것이 아니다. 기존 데이터는 문서 변경만으로 삭제하지 않는다. ✅ 기획 반영 / ⏳ 구현·검수 대기. 현행 생활 루프는 [주문 노동](MOD_GDD_02_LaborJobs.md)·[집꾸미기](ROOM_PACKAGE_GUIDE.md)를 우선한다.

> 개정: 2026-10-16. 현재 이용 기능과 미구현 펍·전당포를 구분한다.

## 1. 현재 생활 루프

거래·물류로 자금을 마련하고 드링크 또는 벤치로 체력을 회복한다. 현재 자연 회복·일일 노동 횟수 제한은 없다. [노동](MOD_GDD_02_LaborJobs.md)·[성장](CORE_GDD_03_PlayerGrowth.md)을 따른다.

외형은 동물 완성형 스타일, 홈은 고정 배치 룸 단위다. 옷장·외형 선택 UI가 남아 있더라도 사람 의류 파츠·명품 옷 세트·스킨 능력치 판매를 다시 도입하는 근거로 사용하지 않는다. [스킨](MOD_GDD_03_3_ClaireApparel.md)·[룸](MOD_GDD_03_2_JulianFurniture.md)을 따른다. 기존 상호작용과 보유 데이터는 별도 이관 정책을 적용한다.

친구 요청·DM·선물·모의투자 대결은 [친구](MOD_GDD_09_FriendSystem.md)·[Bubble](MOD_GDD_11_BubbleSystem.md)·[증권사](CORE_GDD_04_FinancialInstitutions.md)에서 관리한다.

## 2. 현재 주간 로또

비비안에서 골드로 구매하고 아이템 센터에서 번호·추첨·수령을 관리하는 로컬 시뮬레이션이다. 시간·가격·판매 제한·풀 분배는 [경제](CORE_GDD_07_EconomySim.md)와 [비비안](MOD_GDD_03_1_VivianStore.md)을 따른다. 서버 전체 자본 공동 풀과 TV 강제 추첨 연출은 현재 기능이 아니다.

## 3. 미구현·재검토 콘텐츠

미드나잇 펍·바터 전당포는 마을 데이터에서 비활성 상태다. 과거 발표 자료에는 펍 영구 취소, GDD에는 운영 중인 시설로 기재되어 서로 충돌한다. 현재는 미이용 시설로 분류하며 재도입 여부는 미정이다. 건물·안내 문구가 남았다는 이유로 제작 재개를 확정하지 않는다.

브로커 확정형 정보 거래·블랙잭·도박에 따른 호감도 감소·신분 세탁·담보대출은 현행 기능이 아니다. 유료 찌라시는 비비안에서 별도 구현되어 있으므로 펍 정보 거래의 구현 증거로 사용하지 않는다.

전당포의 담보 비율·이율·기한·아이템 처분은 재설계 대상이다. 구 수치를 룸·동물 스킨 담보·매각·버프 소멸 정책으로 자동 승계하지 않는다.
