# 찌라시 작성·데이터 가이드

최종 개정: 2026-10-06. 사용자 결정에 따라 본문을 가리는 방식 대신 읽을 수 있는 수수께끼와 비유를 사용한다.

## 기준 데이터

[Rumors.csv](Data/Rumors.csv)는 현재 웹 데모에 적용된 25개 사건과 해석 단계별 본문 125개를 정리한 CSV다. 한 행은 한 사건이다. 같은 종목의 호재와 악재는 별도 RumorId를 갖는다. 유료 찌라시는 구매 시 종목이 정해지는 동적 공급 계약 정보이므로 고정 25종 목록에 포함하지 않는다.

기존 문서에 기재된 `Assets/Data/Resources/Rumors.csv`는 계획 경로이며 실제 파일은 없었다. 현행 CSV 경로는 `Docs/Data/Rumors.csv`다. 웹 런타임은 아직 JS 데이터를 읽으며 CSV를 직접 읽지 않는다. `RuntimeStatus=ImplementedText`는 본문과 보상 추첨에 적용되었다는 의미다. 해당 사건의 시세 이벤트 연동이나 신뢰도 추첨까지 구현됐다는 의미가 아니다.

## 해석 단계

| 단계 | 작성 기준 | 제공하는 단서 |
|---|---|---|
| 1 | 기업명·사건을 비유로 돌려 말한다 | 이름의 연상, 물건의 용도, 현장 정황 |
| 2 | 업종을 밝히고 기업·방향은 간접 표현한다 | 업종과 대략적인 흐름 |
| 3 | 사건·방향·시점을 밝히고 기업명·수치는 남겨 둔다 | 후보 종목을 좁힐 근거 |
| 4 | 기업명과 구체적인 사건 근거를 밝힌다 | 기업과 촉매, 남은 수치의 불확실성 |
| 5 | 원문의 상세 정보를 읽을 수 있다 | 데이터에 포함된 수치·시점·근거 |

모든 단계는 완전한 문장으로 읽힌다. `[REDACTED]`, 검은 박스, 글자 흐림, 단어 삭제로 본문을 채우지 않는다. 낮은 단계에서도 추리할 단서는 남긴다. 사건·방향·시점은 단계가 올라가도 동일해야 하며 다른 사건으로 바꾸지 않는다. 수치가 없는 원문에 임의의 목표가나 시각을 추가하지 않는다. 소문 속 과장과 실제 게임 효과를 구분한다.

제목·인벤토리 설명·효과·툴팁·검색·알림도 현재 공개 단계에 맞춰 제공한다. 낮은 단계 본문 밖에 종목명이나 수익률·매수 전략을 정답으로 노출하지 않는다.

## 희귀도와 해독기

아이템 희귀도와 해석 단계는 별도 값이다. 높은 희귀도를 확정 수익·큰 폭등·높은 해석 단계로 자동 연결하지 않는다. 현재 밸런스는 다음과 같다.

| 희귀도 | 종류 수 | 등급 획득 확률 | 미열람 기본 매각 가치 |
|---|---:|---:|---:|
| 일반 | 10 | 50% | 500G |
| 고급 | 8 | 28% | 1,200G |
| 희귀 | 4 | 15% | 2,000G |
| 영웅 | 2 | 6% | 6,000G |
| 전설 | 1 | 1% | 15,000G |

찌라시 보상을 받았을 때 등급을 먼저 추첨하고 해당 등급에서 사건을 균등 추첨한다. 물류의 찌라시 지급 확률과 야간 2배는 이 추첨 이전에 적용된다. 첫 열람 시 매각 가치는 절반으로 떨어진다. 기존 보관함에 저장된 아이템의 가격·희귀도는 소급 변경하지 않는다. 유료 상품의 구매 가격 2,000G는 별도다. 일반은 이미 퍼지는 정황, 고급은 발표 전 근거, 영웅은 더 이른 제보, 전설은 사건 연결과 반전 조건을 담는다. 시세 이벤트를 추가로 발생시키는 기능은 이번 데이터 밸런스 작업 범위에 포함하지 않는다.

CSV의 BasePrice는 미열람 기본 매각 가치, RarityWeight는 등급 전체의 추첨 가중치다. RarityWeight를 각 사건의 확률로 더하면 안 된다. 현재 코드의 가격은 거래 매대의 실제 판매 가격과 구분한다.

암호 해독기 1개는 선택한 열람 찌라시 한 건의 해석 단계를 1 올리고 해당 정보에 유지한다. 최대 5단계이며 분석력 자체와 진위를 바꾸지 않는다. 실제 표시 단계는 분석력과 해당 찌라시의 유지 단계 중 높은 값을 사용한다. 유료 찌라시의 기본 유지 단계는 3이다. 종전의 해독률 50%는 문자 가림 비율로 표시하지 않는다.

완전 해석은 진위 보증이 아니다. 기획의 전략적 오보 5%와 현재 런타임의 실제 구현 여부를 구분한다. 문장에 경고가 있다고 신뢰도 시스템이 구현된 것으로 기록하지 않는다.

## CSV 열

RumorId는 사건 식별자, StockId는 종목 식별자다. StockName·Sector·Type·Rarity·Timeframe·ExpectedChange는 제작용 메타데이터이며 낮은 해석 단계의 UI에 그대로 노출하지 않는다. Level1Text~Level5Text는 단계별 본문이다. RuntimeStatus와 Source는 적용 범위와 원본 코드 위치를 기록한다. UTF-8 BOM, 표준 CSV 인용 규칙으로 저장한다.

기존 `MOD_GDD_04_1`~`04_8`, `MOD_GDD_19_1`~`19_8`의 Tier 1~3 문장은 원본 소재로 보존한다. 기존의 10배·상한가 확정·무조건 매수 같은 표현을 확정된 수익 조건으로 옮기지 않는다. 추가 사건을 채택할 때 이 가이드에 맞는 5단계 본문을 작성하고 CSV에 한 행으로 추가한다.
