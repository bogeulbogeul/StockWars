## 1. 제작 방식과 우선순위

**기준 외형을 고정한 뒤 방향·행동별 완성 프레임을 직접 생성·편집하고 스프라이트 시트로 추출·정렬·조합한다.** 리깅·본 기반 애니메이션은 사용하지 않으며 파츠 분리를 제작 필수 단계로 요구하지 않는다. 게임에서는 완성 프레임을 재생한다.

마을의 RPG식 탑다운과 홈 오피스·일반 실내의 아이소메트릭 연결 검증을 먼저 진행한다. 동일 캐릭터 시트의 두 시점 호환과 추가 방향·모션 필요 여부를 검증한다. 채택된 동물 시트 또는 임시 플레이어로 이동·충돌·출입구·가림을 확인한다. 이미 제작·채택된 동물 외형까지 보류 상태로 되돌리지 않으며 추가 에셋의 제작·게임 적용 완료는 별도로 확인한다.

선택·구매·착용 단위는 동물 캐릭터 자체의 완성형 스킨(스타일) `styleId`다. 종·귀·꼬리·털색·무늬·체형을 포함한 전체 외형이며 사람 의상 세트가 아니다. 테마는 숲속 친구들처럼 동물 6종으로 구성하고 한 달 동안 판매한다. 판매 정책과 계획 상태는 [스킨 상점](MOD_GDD_03_3_ClaireApparel.md)을 따른다. 피부·얼굴·헤어·의상·신발의 독립 선택·판매를 도입하지 않는다. 외형 교체로 닉네임·레벨·자산·관계 등 플레이어 데이터가 바뀌지 않는다.

## 3. 프레임 제작·추출·조합

### 3.1. 강아지 화풍과 동일 모션으로 다른 동물 제작 (2026-10-18)

**강아지의 각 완성 프레임을 자세 틀로 삼고, 확정한 새 동물의 외형을 그 자세에 맞춰 직접 생성·편집한다.** 텍스트로 같은 화풍·걷기를 요청하는 것만으로 자세 일치를 보장하지 않는다. 리깅·본 애니메이션을 도입하지 않으며, 어긋난 프레임은 국소 수정 후 다시 비교한다.

| 참고 자료 | 사용하는 기준 |
| :--- | :--- |
| 최신 RGB 강아지 시트 | 윤곽선 굵기·표현, 눈 묘사, 읽기 쉬운 색면과 절제된 명암 등 화풍 |
| 강아지의 해당 방향·행동 프레임 | 시점, 몸통 기울기, 팔·다리 교대, 어깨 연결·가림, 접지·보폭, 상하 리듬과 재생 순서 |
| 새 동물의 확정 정면·디자인 시트 | 얼굴, 귀·주둥이, 종별 체형, 털색·무늬·눈·코 색, 꼬리 형태와 길이 |

1. **정면 외형 확정:** 강아지와 어울리는 큰 머리·짧은 몸과 팔다리의 표현으로 새 동물의 정면 중립을 먼저 정한다. 종별 특징을 보존하고 이 그림을 전 방향·행동의 외형·색 기준으로 삼는다. 이미 승인된 외형이 있으면 그것을 우선한다.
2. **정측면 걷기 시험:** 강아지 정측면 걷기3그림과 새 동물의 확정 외형을 함께 참고해 A·중립·B를 제작한다. 같은 순서·160ms로 나란히 동시 재생해 보폭·팔 스윙·손발 교대·몸의 상하 리듬을 비교한다. 정측면 걷기를 아이소메트릭 앞사선으로 바꾸지 않는다.
3. **행별 확장:** 시험 행이 통과하면 아래 구성으로 방향·행동별 완성 프레임을 제작한다. 실패한 행이나 프레임만 수정하고 승인된 외형·색을 매번 새로 생성하지 않는다.
4. **정렬·조합:** 중립에서 정한 균일 배율을 전체 상태에 적용하고 공통 발밑 원점으로 정렬한다. 발을 드는 자세의 높이 차이는 유지하며 프레임마다 키를 같게 늘이지 않는다. 앉기는 서 있는 키로 확대하지 않는다. 실제 좌표와 손/화물·좌석 연결점은 manifest에 기록한다.
5. **재생 검수:** 강아지와 같은 타이밍으로 비교하고, 새 동물의 방향·행동 전환을 실제 표시 크기로 재생한다. 얼굴·머리 크기·팔다리 길이·색·선의 튐, 발 미끄러짐, 팔 연결과 가림, 루프 연결을 확인한다. 정적 좌표·팔레트 검사를 실재생 통과로 대신하지 않는다.

| 제작 상태 | 구성·재생 |
| :--- | :--- |
| 정면·오른쪽 정측면·뒤 걷기 | 방향별3고유그림, A→중립→B→중립, 각160ms |
| 방향별 정지 | 해당 걷기 중립과 동일 픽셀 공유 |
| 오른쪽 정측면 운반 | 강아지 해당4자세·순서 유지, 각160ms. 상자는 별도 오브젝트 |
| 정면·아이소메트릭 오른쪽 앞사선 앉기 | 방향별1그림 유지 자세. 진입·이탈은 별도 제작 범위 |
| 얼굴 초상화 | UI용 정면 얼굴1칸, 걷기와 분리 |
| 왼쪽 | 오른쪽 그림과 원점·손/화물 연결점을 함께 반전. 비대칭 외형은 별도 확인 |

꼬리는 종별 디자인을 따른다. 짧은꼬리는 골반에 대한 아래 연결부를 유지하고 위쪽만 작게 기울이며, 강아지의 긴 꼬리 외형·큰 흔들림을 복제하지 않는다. 종별 색은 공통 팔레트로 유지하되 강아지의 RGB나 색 수를 강제하지 않는다. 발바닥 패드는 추가하지 않고 기존 손가락 구분선은 유지한다.

제작 기록에는 사용한 강아지 시트·manifest, 새 동물 외형 기준, 행별 원본·수정본, 최종 투명 시트·manifest, 동시 재생 미리보기와 미완료 항목을 남긴다. **외형 승인·모션 제작·게임 설치·실제 플레이 접촉 검수는 각각 구분한다.** 이 절차 정리는 신규 이미지 제작이나 삭제된 캐릭터의 복원을 뜻하지 않는다.

### 3.2. 추출·조합 공통 절차

1. 기준 외형과 필요한 방향별 정지 그림을 고정한다.
2. 한 방향·한 행동의 자세를 먼저 제작하고 동작을 검수한다. 방향·행동별 행으로 생성·편집하여 실패한 행만 다시 제작할 수 있게 한다.
3. sprite-gen의 추출 단계로 배경 제거·완성 프레임 분리·공통 좌표 정렬을 수행한다. 생성 시트를 고정 간격으로 자르는 것만으로 추출을 대체하지 않는다.
4. 투명 프레임을 시트와 manifest로 조합하고 실제 크기 애니메이션으로 확인한다.
5. 승인된 방향·행동을 확장한다. 프레임 수·해상도·재생 속도는 요청과 검증 결과로 정하며 임의로 확정하지 않는다.

프레임마다 머리·몸통·팔다리 길이·의상·꼬리·색이 변하지 않도록 확인한다. 공통 스케일과 발밑 원점을 유지하며 매 프레임 높이를 같게 늘이지 않는다. 그림의 바운딩 박스를 충돌 영역으로 자동 사용하지 않는다.

- 2026-10-17 최신 짧은꼬리 제작: 아래 연결부를 골반에 고정하고 위쪽만 작게 좌우로 기울인다. 토끼는 A 왼쪽 → 중립 가운데 → B 오른쪽 → 중립 가운데, 기존3그림/160ms다. 다른 종은 자체 꼬리 형태와 비율을 유지하며 기울임 크기를 검수한다. 연결부는 몸의 상하·회전을 따르되 미끄러지지 않는다. 몸·손발·색·크기는 유지하고 정지 반복·추가 행동 프레임을 자동으로 만들지 않는다. 토끼 현재 참고는 `output/rabbit-tail-tip-sway-v5/`다.
- 2026-10-17 추가: 짧은꼬리 동물은 종별 디자인 시트의 꼬리 길이·형태·연결점·가림을 따른다. 강아지 v9의 몸·손발·재생 구성을 유지하면서 긴 꼬리의 큰 좌우 휘두르기를 복제하지 않고 골반 움직임을 작게 따라가게 한다. 뿌리는 골반 뒤에 연결하며 화면의 고정 좌표에 붙이지 않는다. 정면·사선 노출은 카메라와 몸의 가림으로 결정한다. 토끼의 구체적 노출과 공통 검수는 [종별 꼬리 제작 규칙](DOG_SPRITE_BASELINE.md#종별-꼬리-제작-규칙)을 따른다.
- 앞·뒤·좌·우 정지와 걷기를 지원한다. 정면 그림의 회전·늘이기로 모든 방향을 대체하지 않는다.
- 대칭 디자인은 좌우 반전을 검토하되 비대칭 장식·광원·손잡이와 화물 연결점을 확인한다.
- 실내외 시점에 맞는 방향별 프레임과 월드의 가구·건물 앞뒤 가림을 검증한다.
- 발밑 원점, 좌석·침대 정렬점, 손/화물 연결점을 프레임 좌표와 함께 기록한다. 상자·의자는 별도 오브젝트로 유지한다.

### 5.1. 걷기 검증

2026-10-15 사용자 재확정: **걷기는 기존 3프레임 체제를 유지한다.** 접지 A·중립·반대 접지 B를 A→중립→B→중립으로 재생한다. 강아지·고양이는 프레임당160ms를 유지한다. 신규 걷기도 3프레임을 기본으로 제작하며 사용자의 명시적 변경 요청 없이 프레임 수를 늘리지 않는다. 8프레임 비교 시안은 미채택이다. 운반 등 다른 행동은 각 행동의 기존 기준을 따른다.

서로 반대인 접지 자세 A/B와 필요한 통과 자세를 먼저 만든다. 양발은 번갈아 전진하고 같은 쪽 팔과 다리는 반대로 움직인다. 동물 채택본의 3자세 구성은 해당 기준 문서를 따른다. 프레임을 늘리거나 재생 속도를 바꾸는 것으로 잘못된 자세를 숨기지 않는다.

실제 표시 크기에서 양발 교대·무릎 굽힘·접지·발 미끄러짐·형태 일관성과 첫/끝 연결을 확인한다. 재생 순서·프레임 시간은 이동 속도와 함께 검증한다. 중간 프레임을 보간한 경우에도 손발 겹침·잔상·외형 변형을 확인한다.

### 5.2. 생활·운반·특별 모션

- 벤치 휴식과 의자 앉기는 별도 모션으로 유지한다. 가구 배치에 필요한 방향을 검증하고 무조건 4방향으로 확정하지 않는다.

- 특별 모션의 종류·발동·반복·중단 조건은 상품별로 정하며 다른 스킨의 공통 기능을 제한하지 않는다. 회복 등 게임 효과를 제작 방식 변경으로 추가하지 않는다.
