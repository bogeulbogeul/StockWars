# StockWars 캐릭터 파츠 분리·2D 리깅 제작 가이드

> **개정:** v5.0 / 2026-09-28 — 제작용 파츠 분리 및 본 기반 애니메이션 채택
> **상태:** 2D 리깅 제작 방식 확정 / 탑다운 뷰 통일 우선 / 최종 외형·화풍·도구는 후속 결정
> **관련 문서:** [아트 가이드](ART_STYLE_GUIDE.md), [전환 계획](VISUAL_TRANSITION_PLAN.md), [캐릭터 생성](CORE_GDD_08_CharacterCreation.md), [스타일 상점](MOD_GDD_03_3_ClaireApparel.md)

기존 링크를 유지하기 위해 파일명은 유지한다. 파일명의 512는 현행 해상도가 아니다. 이전의 '완성 프레임만 내보내기', '런타임 파츠 조립 없음'을 제작 방식의 필수 규칙에서 해제한다.

## 1. 확정한 제작 방식과 우선순위

캐릭터 그림을 움직일 부위별로 분리하고 **본을 심어 움직이는 2D 리깅**을 사용한다. 파츠의 회전·이동과 필요한 변형으로 모션을 제작한다. 프레임마다 전체 캐릭터를 새로 그리는 방식을 기본 제작 방식으로 요구하지 않는다.

홈 오피스·마을·건물 내부의 **비스듬한 탑다운 뷰 통일이 먼저**다. 현재는 임시 플레이어로 이동·충돌·출입구·가림을 검증하며 최종 캐릭터 제작은 그 뒤에 진행한다. 이번 결정은 제작 방식의 확정이며 즉시 캐릭터 제작을 재개하거나 최종 화풍을 확정하는 결정이 아니다.

유저가 선택·구매·착용하는 단위는 기존의 완성형 스타일인 `styleId`를 유지한다. 제작용 파츠·본·슬롯은 내부 구조이며, 피부·얼굴·헤어·의상·신발의 독립 선택·판매 기능을 자동 도입하지 않는다. 외형 변경으로 닉네임·레벨·자산·관계 등 플레이어 데이터가 바뀌지 않는다.

## 2. 참고 자료와 적용 범위

![제작용 파츠 분리 참고](References/character-parts-rigging-reference.jpg)

사용자가 '놀러와 마이홈처럼 파츠 분리 후 본을 심는 방식'의 참고로 제공한 자료다. 머리·몸통·헤어·의상·팔다리를 분리하여 한 캐릭터를 구성하는 제작 구조를 참고한다. 이 이미지로 해당 게임의 실제 도구·본 구조·런타임 구현을 단정하지 않는다.

첨부 캐릭터의 복장·색·얼굴·정확한 비율을 그대로 최종 디자인으로 채택한 것은 아니다. 최종 외형과 화풍은 깔끔함·가독성을 기준으로 후속 검토한다. [이전 픽셀 참고](References/player-compact-pixel-style-reference.png), 회색 마네킹과 걷기 시트는 실험 이력이다. 기존 동작 참고는 손발 위치·교대·겹침 검수에만 사용한다.

## 3. 제작용 파츠 분리 시작안

다음은 리깅 검증을 위한 분리안이며 파츠 수를 확정한 상품 목록이 아니다. 디자인과 모션에 필요한 경우만 더 세분화한다.

| 부위 | 분리 기준 |
| :--- | :--- |
| 머리·얼굴 | 머리 기본 면과 표정용 요소를 필요에 따라 분리. 제작용 얼굴 레이어는 유저의 얼굴 선택 슬롯이 아님 |
| 헤어 | 앞머리·뒷머리, 긴 머리·묶음 머리 등 독립적으로 움직이거나 가려지는 부분 |
| 몸통·골반 | 상체와 골반을 기준으로 팔·다리 연결. 의상 아래 가려진 몸체는 필요한 범위까지 그림 |
| 팔·손 | 캐릭터 기준 좌우 각각 위팔·아래팔·손을 시작안으로 검증. 단순 디자인은 통합 가능 |
| 다리·발 | 좌우 각각 허벅지·종아리·발을 시작안으로 검증. 신발은 발 움직임에 맞게 연결 |
| 의상·장식 | 소매·치마·코트 자락·모자·가방 등 회전·변형·가림이 필요한 단위로 분리 |

- 원본은 편집 가능한 레이어 형태로 보존하고 분리 이미지에는 투명 배경을 사용한다.
- 관절을 돌려도 틈이 보이지 않도록 연결부와 가려진 면을 여유 있게 그린다.
- 피벗은 실제 어깨·팔꿈치·손목·골반·무릎·발목 위치를 기준으로 설정한다.
- 파츠마다 축소·정렬을 따로 하지 않는다. 공통 좌표·원점·스케일과 파츠별 오프셋을 기록한다.
- 원본 비율과 팔다리 길이를 유지한다. 움직임을 강조하려고 한쪽 팔다리를 과하게 어둡게 칠하지 않는다.
- 좌우는 캐릭터의 해부학적 좌우로 명명하고 화면 앞/뒤 가림 순서와 구분한다.

## 4. 본·방향·가림 기준

기본 검증 구조는 `root → 골반 → 몸통 → 목/머리`, 몸통 아래 좌우 팔, 골반 아래 좌우 다리다. 헤어·치마·장식 보조 본, IK, 메쉬 변형 사용 여부와 본 개수는 도구 선택 및 프로토타입 이후 정한다.

- 같은 체형의 스타일은 가능한 범위에서 본 이름·기준 자세·접지점·모션을 공유한다. 체형·의상 차이로 보정이 필요할 수 있으므로 자동 호환을 보장하지 않는다.
- 앞·뒤·좌·우 정지·걷기를 지원한다. 하나의 정면 그림을 회전·늘이기만 해서 모든 방향을 만들지 않는다.
- 방향별 그림과 앞뒤 헤어·팔·다리의 표시 및 가림 순서를 준비한다. 방향별 별도 리그 또는 공통 리그에 그림 교체를 적용할지는 검증 후 결정한다.
- 대칭 디자인은 좌우 반전 재사용을 검토할 수 있으나 비대칭 장식·광원·손잡이 방향은 별도로 확인한다.
- 손 모양이나 관절 실루엣이 본 회전만으로 해결되지 않으면 필요한 대체 그림을 사용한다.
- 스타일 내 파츠 그리기 순서와 월드의 캐릭터/가구/건물 앞뒤 정렬을 함께 검증한다.

## 5. 모션 요구

| 용도 | 요구 |
| :--- | :--- |
| 선택창·상점 | 정면 정지 미리보기. 이것만으로 월드 적용 완료라 표시하지 않음 |
| 기본 이동 | 모든 스타일의 앞·뒤·좌·우 정지와 걷기 |
| 생활 | 모든 스타일의 벤치 휴식, 의자 앉기, 침대 눕기 |
| 미니게임 | 모든 스타일의 상자 운반 정지·이동 |
| 특별 모션 | 한정판에만 추가. 공통 모션을 대체하거나 기능상 이득을 주지 않음 |

### 5.1. 걷기 검증

먼저 한 방향에서 서로 반대인 접지 자세 A/B를 만든다. 같은 쪽 팔은 다리와 반대 방향으로 흔들리고, 양발이 번갈아 전진해야 한다. 이후 내려앉음·통과·올라감 등 필요한 키 포즈를 보간해 루프를 만든다. 본 회전만 자동 보간했다고 자연스러운 걷기로 간주하지 않는다.

머리·몸통 형태, 팔다리 길이, 무릎 굽힘, 손발 교대, 발 미끄러짐, 접지, 첫/끝 연결을 실제 크기로 확인한다. 클립 길이·키 수·재생 속도는 이동 속도와 함께 검증한다. 이전의 방향당 걷기 4프레임·총 20프레임 계산은 리깅 제작량 기준이 아니다.

### 5.2. 생활·운반·특별 모션

- 벤치 휴식과 의자 앉기는 별도 모션으로 유지한다. 가구 배치에 필요한 방향을 검증하고 무조건 4방향으로 확정하지 않는다.
- 발바닥 기준점 외에 좌석·침대 정렬 기준점과 가구 앞뒤 가림 순서를 기록한다. 눕기는 서 있는 캐릭터 전체를 단순 회전하는 것으로 대체하지 않는다.
- 진입 → 유지 → 이탈 상태와 이동 입력에 따른 중단·복귀를 검증한다. 전환 클립 구성·시간은 후속 결정이다.
- 상자는 별도 화물 오브젝트로 유지한다. 손/화물 연결 기준점과 앞뒤 그리기 순서를 기록하고 집기 → 운반 정지/이동 → 내려놓기를 검증한다.
- 물류 미니게임의 방향·조작 전환 여부, 집기·내려놓기 전환 및 기존 밀기 모션 범위는 별도 검토한다.
- 특별 모션의 종류·발동·반복·중단 조건은 한정판별로 정하며 일반 스킨의 기능을 제한하지 않는다. 회복 등 게임 효과를 제작 방식 변경으로 추가하지 않는다.

## 6. 파일·런타임 계약

편집 원본, 분리 이미지, 리그/스킨 정의, 애니메이션 클립, 미리보기와 메타데이터를 구분해 관리한다. 도구·런타임·파일 확장자·아틀라스 규격·해상도는 미정이다. 특정 제품이나 라이선스 도입을 확정하지 않는다.

본 애니메이션 제작은 확정한다. 게임에서 실시간 리깅을 실행할지, 제작된 모션을 시트로 베이크할지는 성능·호환성·방향 전환 검증 후 정한다. 베이크는 전달 방식의 선택이며 전체 그림을 프레임마다 다시 생성하는 제작 방식으로 회귀하는 뜻이 아니다.

메타데이터에는 스타일 ID·미리보기·리그 버전·방향별 그림 연결·지원 모션·루프/전환/중단·접지/가구/화물 기준점·그리기 순서·검수 상태를 기록한다. 보유/착용은 완성형 스타일 ID 단위로 유지하며 제작용 본/파츠를 상품 슬롯으로 노출하지 않는다.

## 7. 뷰 통일 이후 제작 순서와 완료 기준

1. 대표 캐릭터 1종의 외형·정면/측면/후면 비율을 정한다.
2. 제작용 파츠를 분리하고 관절 여유 면·피벗·본·그리기 순서를 설정한다.
3. 한 방향 정지·걷기의 A/B 자세와 루프를 먼저 검증한다.
4. 나머지 방향과 생활·상자 운반 모션, 가구 대응을 검증한다.
5. 선택창·상점·월드에서 같은 외형인지 확인하고 다른 스타일로 확장한다.

- [ ] 파츠 연결부가 벌어지거나 관절이 비정상적으로 꺾이지 않는다.
- [ ] 방향 전환과 모션 중 머리·몸통·팔다리 비율과 접지점이 일관된다.
- [ ] 손발 교대·보간·루프와 이동 속도의 관계를 실제 플레이 크기로 확인했다.
- [ ] 방향별 헤어·팔·의상과 월드 가구/건물의 가림 순서가 맞는다.
- [ ] 모든 스타일의 공통 모션과 가구/화물 정렬·진입·이탈을 검증했다.
- [ ] 특별 모션은 한정판에만 연결되며 기능상 이득이 없다.
- [ ] 외형 교체 시 플레이어 진행 데이터가 유지된다.
- [ ] 파츠 원본·리그 제작 완료·런타임 적용 완료를 구분해 기록했다.

기존 에셋과 저장 데이터는 임의 삭제·변환하지 않는다. 전환 시 실제 사용 여부와 필요 이관을 별도 확인한다.
