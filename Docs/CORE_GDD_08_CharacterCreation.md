# StockWars GDD: CORE_GDD_08. 캐릭터 생성 시스템 (Character Creation)

> **2026-10-16 대조 결과:** 현재 UI는 닉네임 최대 10글자와 강아지·검은 고양이 완성형 스타일 선택 → TPT 3문항 → 출입증 순서다. 원고의 추가 연출은 구현 상태와 구분한다. [현재 UI](../web/js/components/CharacterCreation.js)를 참조한다.

**버전:** v2.1.0 (2026-10-16 동물 캐릭터 스킨 기준 정리)
**핵심 컨셉:** 사이퍼 증권(Cipher Securities) 트레이더 등록 및 출입증 발급 연출

---

## 1. 시스템 개요 (System Overview)
유저는 게임을 처음 시작할 때 자신의 가상 아바타와 투자 성향을 설정합니다. 이는 코지(Cozy) 감성의 빈티지한 키오스크 UI 형태를 띠며, 완료 시 유저의 정보가 담긴 '트레이더 출입증'이 출력되는 연출과 함께 게임 본편(홈 오피스)으로 진입합니다.

---

## 2. 캐릭터 커스터마이징 흐름 (UX Flow)

### 2.1. 단계별 설정

1. **기본 스타일 선택:** 완성형 동물 캐릭터 목록에서 스킨 하나를 선택한다. 동물의 종·얼굴·털색·무늬·귀·꼬리·체형이 포함된 전체 외형이다.
2. **미리보기:** 선택한 전체 외형을 확인한다. 피부색·헤어·얼굴·신발 등을 개별 선택하는 단계는 없다.
3. **닉네임 및 성향 설정:** 기존 닉네임 입력과 투자자 성향 테스트를 진행한다.
4. **등록:** 선택한 스타일과 플레이어 정보를 저장하고 출입증을 발급한다.

기존 성별별 골격 선택 단계는 완성형 스타일 선택으로 대체한다. 게임의 별도 성별 데이터가 필요하다면 후속 설계하며, 성별 선택을 파츠 조합 절차로 사용하지 않는다.

### 2.2. 초기 외형 명세

- 기본 외형은 같은 플레이어가 사용할 스타일이며 별도 직업·고유 스킬을 가진 인물이 아니다.
- 피부색 5종 × 헤어 4종 조합과 공통 기본 의상 고정 규칙은 폐기한다. 각 스킨은 동물 자체의 완성 디자인을 갖는다. 옷·헤어가 필수인 사람형 외형으로 해석하지 않는다.
- 현재 기본 외형 참고는 강아지·검은 고양이다. 초기 선택·무료 제공의 최종 수량과 대상은 미정이며 과거 4종 시작안을 확정값으로 사용하지 않는다.
- 이후 옷장에서 외형 전체를 바꿀 수 있다. 외형 교체로 닉네임·투자 성향·성장·자산을 초기화하지 않는다.
- 제작 기준은 [완성형 스타일 가이드](part_separation_guide_512.md), 구매는 [클레어 스타일 상점](MOD_GDD_03_3_ClaireApparel.md)을 따른다.
- 선택창 정면 미리보기와 실제 월드에서 필요한 4방향·동작 에셋의 완료 상태를 구분한다.

## 3. 투자자 성향 테스트 (Trader Personality Test - TPT) [NEW]
유저는 직접 성향을 선택하는 대신, 빈티지 키오스크에서 진행되는 3가지 질문에 답변하여 자신의 초기 투자 성향을 진단받습니다. (답변 결과에 따라 4대 능력치 중 하나에 **+1 블록** 보너스 부여)

### 3.1. 현재 진단과 보상

현재 질문은 주식 하락 시 행동·여윳돈 사용·수익 이후 행동의 3문항이다. 각 문항의 4개 선택지가 분석·협상·운용·회복에 대응한다. 가장 많이 고른 성향을 적용하며 동점이면 코드의 순서(분석→협상→운용→회복) 중 먼저인 항목을 택한다. 랜덤 재추첨이 아니다. 정확한 문장은 [성향 테스트 코드](../web/js/components/character/PersonalityTestStep.js)를 따른다.

| 성향 | 시작 기본 스탯 | 현재 부가 효과 |
| :--- | :--- | :--- |
| 예리한 분석가 | 분석력 +1 | 해석 단계에 반영, 진위 보증 아님 |
| 베테랑 협상가 | 협상력 +1 | 단계 수수료 감면 뒤 추가 30% 할인, 대출 기능 미구현 |
| 공격적 자산가 | 운용력 +1 | 기본 단계 슬롯에 추가 +2칸, 투자금 Cap 없음 |
| 불굴의 트레이더 | 회복력 +1 | 회복력 단계 효과. 자연 회복 속도·노동 골드 가산 아님 |

시작 칭호는 성향으로 획득하며 칭호의 장착·해제는 시작 스탯을 바꾸지 않는다. 자세한 계산은 [성장 명세](CORE_GDD_03_PlayerGrowth.md)를 따른다.

## 4. 연출 및 UX 가이드

### 4.1. 화면 구성
- **중앙**: 아바타 실시간 프리뷰. 현행 동물 캐릭터와 [시트 기준](DOG_SPRITE_BASELINE.md)의 채택 외형을 사용한다. 실내외 시점 연결·UI 적용의 검수 상태는 별도로 확인하며 픽셀 표현을 필수로 요구하지 않는다.
- **하단**: 각 단계별 선택 버튼 및 진행 바.
- **최종**: '트레이더 등록(Register)' 버튼.

### 4.2. 트레이더 출입증 발급 (ID Card Ceremony)
1. 등록 완료 시, 지지직거리는 도트 프린터 효과음 발생.
2. 화면 하단에서 유저의 얼굴, 닉네임, 성향이 인쇄된 **[트레이더 출입증]** 에셋이 슬라이드 업.
3. 안나의 목소리(혹은 텍스트): "환영합니다, [Name] 트레이더님. 당신의 전용 오피스가 준비되었습니다."
4. 출입증을 클릭하면 화면이 화이트 아웃되며 홈 오피스로 전환.

## 5. 데이터 연동 및 무결성
- **초기 자산**: 5,000G 현금. 웰컴 론 10,000G은 미구현 검토안이며 현재 등록 보상으로 합산하지 않는다.
- **스탯 반영**: 선택 성향은 프로필과 아이템 상태의 `baseStats`·`appliedTrait`로 적용하고 현행 로컬 저장에 보존한다. 서버 `User_Stats` DB 저장 완료를 뜻하지 않는다.
