# ROADMAP 02: 핵심 마일스톤 (체크리스트)

**개발 기조:** 픽셀 아트에서 일반 2D (HD) 스타일로 그래픽 방향성을 전면 개편함에 따라, 무리한 공모전(GIGDC) 출품 일정을 폐기하고 게임 본연의 퀄리티와 코어 시스템 완성에 집중합니다. 6월은 **스마트폰 UI 및 주식시장 기초 메커니즘 구축**에만 전념하며, 나머지 일정은 여유를 두고 순차적으로 진행합니다.

---

## 🗓️ 6월 목표 (June Goal)

### 📱 Phase 1: 스마트폰 UI 및 주식시장 메커니즘 개발
- [ ] 우측 하단 스마트폰 아이콘 및 애니메이션(팝업/슬라이드) 구현
- [ ] 스마트폰 코어 앱(1): 메일(Mail) 앱 UI 프레임워크 구축 및 읽음/안읽음 처리
- [ ] 스마트폰 코어 앱(2): 뉴스(News) 앱 속보 알림 및 아카이브 리스트 UI 연동
- [ ] 실시간 마켓 피드 시스템 연동 (주가 갱신 패킷 수신 및 데이터 동기화)
- [ ] 주식 매수/매도 트랜잭션 로직(100% 즉시 체결, 수수료, 수량 슬라이더) 구현
- [ ] 자산 연동: 매매 체결 후 개인 지갑(Gold) 잔고 갱신 로직 및 드르륵 숫자 연출 구현
- [ ] 개인 포트폴리오 창(총자산, 평가손익, 평단가, 수익률 그리드 등) UI 조립

---

## 🗓️ 7월 이후 목표 (Mid-to-Long Term)

### 🖥️ Phase 2: 오피스 UI 정돈
- [ ] 2D 아늑한 오피스 배경 일러스트 렌더링 및 마스터 캔버스 앵커 셋업
- [ ] 주가 실시간 선/봉 차트 렌더러 오피스 내 팝업 윈도우로 통합 및 배치
- [ ] 하단 종목 무한 스크롤 티커 UI 셋업 및 등락에 따른 색상 글로우 효과 추가
- [ ] 상단 정보 바(디지털 시계, 요일 흐름 등) 레이아웃 셋업
- [ ] 팝업 윈도우 스냅 및 화면 활성화 시 배경 흐림(가우시안 블러) 효과 등 편의성 처리

### 🏙️ Phase 3: 타운 씬 배치하기
- [ ] 타운(Town) 구역의 전체 맵 구조 설계 및 네비게이션 매니저 구축
- [ ] 실제 씬 이동 대신, 장소 이동 시 배경 이미지가 즉시 교체되는 스위칭(Fade) 시스템 구현
- [ ] 타운 맵 내 입장 가능한 주요 구역(오피스, 증권사, 상점 등) 진입 상호작용 버튼 배치
- [ ] 아직 미구현된 구역 진입 시도 시 "준비 중" 토스트 팝업 알림 출력 로직 추가

### 📦 Phase 4: 물류창고 미니게임 시스템 개발
- [ ] 물류 창고 내부 2D 배경 일러스트 적용 및 장소 진입 연동
- [ ] 노동(알바) 미니게임의 공통 UI 프레임(제한시간, 점수 등) 및 조작 메커니즘 구현
- [ ] 미니게임 관련 오디오 자원(BGM, 물건 적재음, 백사장 호통 앰비언트 등) 연동
- [ ] 미니게임 종료 시 일급(Gold) 및 경험치/피로도 증감을 표시하는 정산 팝업 완성

### 👩‍💼 Phase 5: 안나 캐릭터 도입
- [ ] 오피스 화면 한편에 안나(Anna) 2D 스탠딩 일러스트 고정 배치 및 가벼운 대기(Idle) 모션 추가
- [ ] 안나 캐릭터 대화(Dialogue) UI 창 디자인 적용 및 기본 텍스트 출력 시스템 연동
- [ ] 안나를 통한 초반 시스템 튜토리얼 툴팁 및 주요 이벤트 알림 기능 구축

### 🏦 Phase 6: 증권사 건물, 일반 주식, 멀티 게임 기반 주식 시스템 마련
- [ ] 증권사 2D 내부 배경(대형 전광판, 트레이딩 데스크) 및 에이전트 K 일러스트 적용
- [ ] 증권사 장소 전용 BGM 및 현장감 있는 앰비언트 사운드 추가
- [ ] 에이전트 K와의 대화 및 주식 아레나(유저 간 멀티플레이 경쟁) 매칭 진입 UI 구현
- [ ] 코어 외 일반 주식 종목(장기 투자용) 리스트 추가 및 거래창 확장 확립

### 🏪 Phase 7: 타운 상점 및 주요 공간 디자인 및 배치
- [ ] 옷가게(클레어), 가구점(줄리안), 서점, 은행 등의 2D 배경 리소스 적용
- [ ] 상점별 인벤토리 팝업 및 아이템 구매 UI(아이템 목록, 가격표, 구매 버튼) 구현
- [ ] 플레이어가 옷/가구 구매 시 즉시 씬 인테리어/스킨에 반영되는 데이터 연동 뼈대 마련
- [ ] 은행 진입 시 금융 서비스(대출 승인/상환) UI 프레임워크 셋업
