# 비비안 판매 아이템 반영 가구

내장 imagegen으로 5종 재제작. `prompts.md`에 사용 프롬프트와 참고 역할 기록.

- 냉장고: 에너지 드링크, 고농축 카페인.
- 진열대: 비타민, 안정제, 각성제.
- 이용권 매대: 퀵패스, 드링크 배급권, 주간 로또, 유료 정보 봉투.
- 벽 선반: 암호 해독기, 다크넷 키, 디지털 방독면.
- 계산대: POS, 블랙 스완 경보기, 정보 봉투.

아이템 정면 이미지는 외형 참고로만 사용하고 가구 시점에 맞춰 다시 그렸다. v3 가구의 방향·점유 영역을 유지하며 전체 1254×1254 원본과 기존 타일 축 보정 메타데이터를 적용한다. 원본 파일을 단독 크롭하거나 가로·세로를 따로 늘리지 않는다.

일반 플레이의 가구 정리 UI는 제거한다. 제작 도구는 `new VivianStoreModal(container, callbacks, {allowLayoutEditing:true})`로 명시적으로 켠 개발 화면에만 제공한다. 기본 미리보기 또한 일반 플레이 모드다. 기존 저장 가구 배치는 유지한다.

카펫 근처에서는 나가기 버튼이 표시되고, 멀어지거나 구매창·편집 모드에서는 숨겨진다. 버튼 또는 F 키로 퇴장한다.
