# 비비안 잡화점 통합 룸 v1

## v8 게임 적용 완료

기본 룸을 `vivian-room-with-squirrel-v8.png`로 교체하고 별도 비비안·양손·계산대 합성 레이어를 제거했다. 플레이어를 가리는 필요한 가구 영역과 CSS 시계만 별도 표시한다. 이미지에 포함된 비비안은 이번 사용자의 명시적 통합 요청에 따른다.

계산대, 식료품 진열대, 냉장고 각각 2대, 생활용품 매대, 중앙 진열대, 바구니, 직원 전용 공간을 고정 static 폴리곤 body로 기록했다. 플레이어 접지 타원과 폴리곤 가장자리 충돌 및 세부 이동 검사로 가구 관통을 막는다. 벽 선반·시계는 wall 레이어의 고정 fixture로 기록하며 아래 바닥의 이동을 차단하지 않는다. 바닥 외곽은 별도 이동 경계다. 별도 물리 엔진 패키지를 추가한 것은 아니다.

클릭 → 접근 이동 → 도착 후 기능 실행을 연결했다. 식료품 진열대·음료 냉장고·중앙 진열대는 기존 일일 상품 탭, 생활용품 매대·벽 장비 선반은 주간 상품 탭, 계산대는 기본 구매창을 연다. 가까이서 F 이용도 같은 기존 구매 기능을 사용한다. 바구니·화분은 고정 장식/장애물로 유지하며 새 경제 효과나 장바구니 시스템을 만들지 않는다. 출입 매트는 접근 후 퇴장, 벽시계는 실제 시간 CSS 바늘을 유지한다. 키보드 이동·바닥 클릭·퇴장으로 대기 상호작용을 취소한다.

검증: 관련 Node 테스트 16개 통과. 브라우저에서 각 진열대 접근·구매 탭, 실제 게임의 잡화점 진입·계산대 구매창·내부 복귀·퇴장을 확인했고 JavaScript 오류는 없었다. 전체 접근 지점 사이 왕복 경로, 가구 모서리 충돌, 기존 구매·가격·아이템 효과 회귀를 검증했다. `output/vivian-room-package/integrated-v8-game.png`, `integrated-v8-mobile.png`, `integrated-v8-verification.json`에 화면과 결과를 저장했다. 아래 과거 미적용·분리 레이어 기록은 이력이다.

## 비비안 포함 통합 생성 v8

사용자 요청으로 비비안을 별도 합성하지 않고 방 이미지에 함께 그린 `vivian-room-with-squirrel-v8.png`를 내장 image_gen으로 생성했다. `vivian-room-with-squirrel-v8.prompt.txt`에 프롬프트를 기록했다. clean-v4는 방 배치·그림체, 다람쥐 cashier-v1은 외형, 사용자 에이전트 K 캡처는 계산대 뒤 직원의 자세·깊이 관계 참고로 전달했다. 이번에는 사용자가 명시한 방식에 따라 NPC를 통합 그림에 포함하며 일반적인 캐릭터 분리 제작 규칙의 영구 변경을 뜻하지 않는다.

시각 확인: 비비안의 몸통과 꼬리는 계산대 뒤에 있고 팔·손이 상판 뒤쪽에 닿도록 함께 그려졌다. 시계 바늘 없는 판, 입구 옆 외곽선 안의 바구니, 기존 가구 배치와 그림체를 유지했다. 이 파일은 새 생성본으로 저장했으며 아직 런타임의 clean-v4 및 분리 NPC 레이어를 교체하지 않았다.

## v4 — 전체 재생성 및 게임 적용

최신 v7: 몸통은 계산대 상판 전체 뒤에 표시하고, 같은 캐릭터 이미지의 양손·팔 일부만 별도 클립 레이어로 상판 위에 표시한다. 그 위에 앞판과 단말기를 다시 합성한다. 몸통을 상판 위에 통째로 올리던 v6 방식을 대체한다. 직원 사각형 시작 (220,355), 크기는 유지. 캡처 `output/vivian-room-package/cashier-behind-counter-v7.png`.

최신 v6 합성 보정: 사용자 제공 에이전트 K 계산대 참고처럼 상반신과 손을 상판 위에서 보이게 하고 아래 몸만 앞판에 가리도록 변경했다. NPC의 가림에는 상판 전체 대신 고객 쪽 가장자리·앞판과 단말기만 사용한다. 플레이어 이동용 가림 영역과 직원용 앞판 영역은 구분한다. NPC 사각형 시작은 (220,375)다. 최신 캡처는 `output/vivian-room-package/cashier-agent-k-v6.png`이며 아래 v3~v5 배치 기록을 대체한다.

상판 접촉 보정: 직원 사각형을 (195,395)로 이동해 상판 뒤쪽에 더 가깝게 붙였다. 계산대 가림은 유지하고 얼굴 아래 몸통이 뒤쪽 테두리로 이어지도록 조정했다. 최신 캡처는 `output/vivian-room-package/cashier-contact-v5.png`다.

레이어 수정: 직원 위치·크기는 유지하고 계산대 가림 폴리곤에 뒤쪽 청록 테두리와 상판 전체를 포함했다. 배경 → 직원 → 계산대 상판·앞판·모니터 순서로 표시해 몸통이 상판 위로 덮어 그려지던 문제를 해결했다. 직원 얼굴은 상판 위쪽에서 보이고 몸통·손은 계산대 뒤로 가려진다. 최신 캡처: `output/vivian-room-package/cashier-layer-v4.png`.

사람 비비안 배치 기준 재적용: 초기 사용자 스크린샷처럼 직원 얼굴이 계산대 왼쪽 1/3, 모니터 왼쪽에 오도록 위치를 맞췄다. 다람쥐 이미지 사각형의 시작은 원본 좌표 (185,380)이며 크기와 가림 구조는 유지했다. 손·하반신은 계산대 뒤에서 가리고, 구매 안내도 같은 직원 위치로 옮겼다. 캡처: `output/vivian-room-package/cashier-human-placement-v3.png`.

비비안 배치 후속 보정: 원본 좌표에서 왼쪽으로 15px, 아래로 60px 이동해 계산대에 붙였다. 계산대와 모니터를 하나의 외곽으로 묶어 빈 공간까지 가리던 마스크는 상판·모니터·결제 단말기의 별도 폴리곤 합집합으로 변경했다. 브라우저에서 얼굴과 몸통이 빈 배경으로 잘리지 않고 계산대 뒤에서 이어지는 것을 확인했다. 검증 캡처는 `output/vivian-room-package/cashier-position-v2.png`다.

사용자 요청에 따라 내장 image_gen으로 v3 배치·그림체를 유지하며 전체를 다시 그려 표면의 얼룩과 누적 편집 흔적을 정리했다. 게임 기본 룸은 `vivian-room-package-clean-v4.png`이며 생성 프롬프트는 `vivian-room-package-clean-v4.prompt.txt`다. v1~v3은 이력이다.

`web/js/components/store/VivianRoomPackage.js`가 통합 배경, 기존 투명 다람쥐 `vivian-squirrel-cashier-v1.png`, 계산대 가림, 이동 장애물·출입·계산대 접근 좌표를 공유한다. 유저 플레이에서는 구 가구 배치 저장을 읽거나 덮어쓰지 않는다. 명시적 기존 개발 편집 옵션은 구 에셋 편집 환경으로 남겨 두었다.

바닥 가로 대각선 실측 근삿값 1336px와 8칸·공통 한 칸 67.5를 사용해 원본 표시 배율을 1336/(8×67.5)로 환산했다. 플레이어 H=90에 같은 룸 배율을 적용한다. 이미지 원본의 줄눈을 공통 정밀 그리드로 검수 완료했다는 뜻은 아니다. 이동과 충돌은 생성 이미지의 가구를 실측한 폴리곤으로 판정하며, 캐릭터 발밑과 가구 앞 경계를 비교해 필요한 부분만 원본에서 가림 합성한다.

시계는 원본의 바늘 없는 시계판에 CSS 시침·분침·초침을 합성한다. 기존 `VivianClock.js`의 로컬 실제 시간 초기값과 CSS 연속 회전을 사용하고 재입장 때 동기화한다. 비비안 인사와 구매창 초상에도 같은 다람쥐 에셋을 적용했다. 표현별 별도 다람쥐 초상은 이번에 제작하지 않았다.

검증: 관련 Node 테스트 19개 통과. 실제 Chrome에서 통합 배경·NPC 로드, 계산대 가림, CSS 바늘 이동, 900×600/480×800의 레이어·플레이어 발밑 정렬을 확인했다. 실제 `web/index.html`의 잡화점 진입, 계산대 도착 후 F로 구매창 열기, Esc로 내부 복귀, 입구 도착 후 F로 퇴장까지 통과했고 브라우저 JavaScript 오류는 없었다. 구매·가격·아이템 효과는 기존 로직을 유지한다. 검증 결과와 캡처는 `output/vivian-room-package/`에 저장했다.

## v3 — 외곽선 안쪽 배치와 동적 시계 준비

최신 제작본은 `vivian-room-package-v3.png`다. 내장 image_gen으로 바구니 전체를 출입 매트 안쪽 바닥으로 이동했다. 시각 확인에서 바구니·손잡이·접지 그림자가 룸 외곽선 안에 있고 매트와 겹치지 않는다. 기존 바구니 자리의 바닥과 외곽선도 복원했다.

시계는 CSS 동적 표시를 위해 바늘과 중심 핀을 제거하고 테두리·바탕·눈금을 유지했다. 추후 시침·분침·초침을 별도 DOM/CSS로 합성한다. 초기 각도와 시간 동기화는 JavaScript에서 공급하고, 시계 표면에 맞는 공통 룸 변환을 적용해야 한다. 실제 시간/게임 시간 선택과 CSS 시계 구현은 아직 확정·적용하지 않았다. 시계 중심은 원본 이미지 기준 약 (252,373)이며, 합성 전 정밀 표면 좌표를 검증한다.

프롬프트는 `vivian-room-package-v3.prompt.txt`에 기록했다. 이전 버전은 이력으로 보존하고 게임 적용·그리드 정합 검증은 아직 미완료다.

2026-10-14 사용자 요청으로 기존 배치와 독립된 새 고정 배치를 제작했다. 내장 image_gen을 사용했으며 첨부 스크린샷을 그림체·색상·아이소메트릭 시점 참고로 사용했다.

## 크기와 검증 상태

캐릭터 H=90과 공통 셀 67.5×38.2를 제작 목표로 전달했다. 생성 결과의 바닥 폭은 요청된 1080 이미지 픽셀보다 넓으므로 프롬프트의 2배율을 실제 캘리브레이션 값으로 사용하면 안 된다. 원본 해상도를 논리 룸 크기로 간주하지 않는다. 게임 적용 시 바닥 교차점·가구 상판 높이와 H=90 캐릭터를 비교하여 균일 표시 배율을 정해야 한다. 비균일 압축으로 맞추지 않는다.

현재는 통합 이미지 제작본이며 게임의 기존 비비안 룸을 교체하지 않았다. 새 배치의 이동·충돌·가림·계산대 접근·출입 및 줄눈의 정밀 정합 검증은 미완료다. 기존 배치 저장·아이템·경제 효과는 변경하지 않았다. 게임 적용 완료 또는 공통 그리드 검수 완료 에셋으로 표시하지 않는다.
