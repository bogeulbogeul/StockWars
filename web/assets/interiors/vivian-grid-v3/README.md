# 가구 축 정렬 및 잘림 수정

2026-09-29, 내장 imagegen으로 냉장고·계산대·상품 진열대·책 매대·바구니·벽 선반 6종 재생성. 기존 이미지는 디자인 참고용이며 타일 축은 ROOM_GRID 기준이다. 프롬프트는 `prompts.md`.

실제 PNG는 모두 1254×1254. 기존 1280 가정과 추정 크롭을 제거했다. `VivianSpriteGeometry.js`가 측정한 바닥 모서리 기울기를 ±41/85로 보정하고, 변환된 전체 캔버스를 포함하는 표시 영역을 계산한다. 높이 방향은 수직을 유지하며 표시 시 가로·세로 배율이 동일하다. 원본 PNG만 별도 사용하면 각도 보정이 포함되지 않으므로 scene 메타데이터를 함께 사용한다.

화분·시계는 기존 그림을 유지하되 전체 원본을 표시한다. 룸과 카펫은 v2를 사용한다. 현재 저장된 사용자의 가구 배치 좌표는 유지한다.

검증: 원본 크기 일치, 전체 캔버스 표시, 가구 양 축과 타일 축 평행, 이동·출입·충돌 자동 테스트. 브라우저에서 실제 타일 그리드와 전체 외곽을 확인했다.
