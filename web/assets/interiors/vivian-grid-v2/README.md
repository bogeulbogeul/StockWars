# 비비안 잡화점 그리드 에셋

> 가구 6종과 표시 메타데이터는 `../vivian-grid-v3/README.md`의 각도·잘림 수정본으로 교체됐다. 이 폴더의 룸·카펫·화분·시계는 계속 사용한다.

2026-09-29 재생성. 룸 1개와 개별 투명 소품 9개. 생성 프롬프트는 `prompts.md`.

- 적용 기준: `IsometricRoomGrid.js`의 8×8, 원점 (768,345), 축 (85,41), (-85,41).
- 1×1: 냉장고, 화분, 바구니. 1×2: 상품 진열대, 출입 카펫. 2×1: 책 매대.
- 계산대 예약 영역 2×2: 뒤쪽 u 행 1×2는 직원 공간, 앞쪽 u 행 1×2는 계산대. 비비안 캐릭터 자체는 별도 제작 대상.
- 벽 시계는 왼쪽 벽, 선반은 오른쪽 벽에 부착.
- PNG는 생성 원본. 적용 시 `VivianInteriorScene.js`의 접지점·크롭·크기 메타데이터를 함께 사용한다. 원본 여백을 포함한 이미지 크기를 점유 칸으로 취급하지 않는다.
- 생성 룸의 타일 수·줄눈은 정확하지 않아, 런타임에서 쉘을 보정하고 동일 논리 그리드로 64개 바닥 타일을 렌더링한다. 룸 PNG 단독을 충돌 그리드 기준으로 사용하지 않는다.
- 카펫의 원본 접지면은 SVG affine 변환으로 두 칸 안에 맞춘다. 글자나 출구 화살표는 없다.
- 실제 미리보기의 그리드 모드에서 바닥 정합·카펫 점유·가구 배치를 확인했고 이동/출입 테스트 12개를 통과했다.

외부 건물과 캐릭터 이미지는 이번 교체 범위에 포함하지 않는다.
