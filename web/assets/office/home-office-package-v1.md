# 기본 홈 오피스 룸 패키지 v1

- 이미지: `home-office-package-v1.png`, 1254×1254 RGBA. 기존 생성 시안의 책장을 옷장으로 교체한 통합 룸.
- 구현: `OfficeRoomPackage.js`. 원본 좌표와 SVG 균일 배율 0.5를 배경·입력·이동·가림에 공유한다. 원본의 바닥 모서리를 측정한 룸별 투영으로 기존 그리드와 구분한다. 생성 이미지의 줄눈은 균일한 수학적 그리드의 최종 검수 결과가 아니다.
- 문: 접근 후 기존 서버 선택 → 마을 이동. 옷장: 접근 후 기존 보유 옷장 창. 컴퓨터: 접근 후 기존 스마트폰 주식 앱.
- 고정 장애물: 옷장·책상·의자·화분. 접근 경로는 장애물을 피하고, 수동 이동/씬 이탈/모달 표시 시 대기 동작을 취소한다. 키보드 설정의 이동/F 키와 SVG 버튼의 Enter/Space 접근을 지원한다.
- 물리 충돌: `HOME_RIGIDBODIES`의 static 바닥 다각형과 kinematic 플레이어 타원(원본 좌표 반경 48×26)을 사용한다. SVG 발밑 그림자 22×11을 원본 배율로 환산하고 여유를 더했다. 이동은 0.04 논리 단위 이하로 분할해 관통을 차단하며 수동 이동은 장애물 옆으로 미끄러질 수 있다. 충돌 내부의 시작·복귀 위치는 가장 가까운 안전 위치로 복구한다.
- 배경과 동일한 원본을 필요한 가구 영역에 잘라 캐릭터 뒤쪽 가림으로 사용한다. 의자 앉기 애니메이션과 모니터 실시간 화면 합성은 이번 버전에 없다.
- 기존 가구 보유·배치 저장 키는 삭제·환산하지 않는다. 고정 룸에서는 구 배치 그림/충돌을 적용하지 않고 편집 진입을 안내로 대체한다. 새 룸 판매·경제 효과 이관은 포함하지 않는다.
- 검증: 룸 투영, 출입 및 모든 기능 접근 경로, 장애물 목적지 거부를 자동 테스트한다. 실제 브라우저의 옷장 열기/F키·컴퓨터·출입·씬 이탈 취소·마을 왕복을 확인한다.
